### REQ-0126: State History Pseudostates (Shallow & Deep History) Restoration Semantics

#### 1. Normative Statement

The spatio-temporal dynamics solver, state machine compiler, and discrete transition execution engine of Subsystem 6 shall model, validate, and verify Shallow History (`[H]`) and Deep History (`[H*]`) pseudostate semantics, enabling interrupted composite states and orthogonal regions to record their active sub-state configurations upon exit and deterministically restore their previous execution states upon re-entry.

  Specifically, the state machine compiler, history validator, and configuration restoration engine shall strictly enforce the following structural, algebraic, and operational invariants:
  1. **Taxonomy and Containment Scope of History Pseudostates**:
     - State machine pseudostates shall be partitioned to include two explicit history kinds: Shallow History (`Kind::ShallowHistory`, designated `[H]`) and Deep History (`Kind::DeepHistory`, designated `[H*]`).
     - Every history pseudostate $`h \in \mathcal{P}_{\text{history}}`$` must be directly owned by an enclosing exclusive composite state (`$`S_{\text{comp}} \in \mathcal{S}_{\text{xor}}`$`), an orthogonal composite state (`$`S_{\text{orth}} \in \mathcal{S}_{\text{orth}}`$`), or an orthogonal region (`$`R \in \mathcal{R}`$).
     - A history pseudostate declared at the root level of a state machine ($`s_{\text{root}}`$) or within an atomic leaf state shall be deterministically rejected at compile time with diagnostic error code `E0400` (`HistoryPseudostateAtRoot`).
     - Within any single composite state container or orthogonal region scope, there shall exist at most one Shallow History pseudostate and at most one Deep History pseudostate. Declaring multiple history pseudostates of the identical kind within the same container scope shall be deterministically rejected with diagnostic error code `E0400` (`DuplicateHistoryPseudostateKind`).
  2. **Mandatory Default Transition & Well-Formedness Invariants**:
     - Every history pseudostate $`h \in \mathcal{P}_{\text{history}}`$` must declare exactly one outgoing default transition `$`T_{\text{default}} \in \mathcal{T}_{\text{default}}`$` such that `$`s_{\text{src}}(T_{\text{default}}) = h`$.
     - If a history pseudostate declares zero outgoing default transitions ($`|\{ \tau \in \mathcal{T} \mid s_{\text{src}}(\tau) = h \}| = 0`$), the compiler shall deterministically reject the model at compile time with diagnostic error code `E0400` (`HistoryPseudostateWithoutDefaultTransition`).
     - If a history pseudostate declares more than one outgoing transition ($`|\{ \tau \in \mathcal{T} \mid s_{\text{src}}(\tau) = h \}| \gt 1`$), the compiler shall deterministically reject the model at compile time with diagnostic error code `E0400` (`MultipleHistoryDefaultTransitions`).
     - The target state of $`T_{\text{default}}`$` must be an immediate child state of the enclosing container (`$`s_{\text{tgt}}(T_{\text{default}}) \in \mathcal{C}_{\text{parent}(h)}`$). Any default transition targeting an external state, an ancestor state, or an unrelated orthogonal region shall be rejected with diagnostic error code `E0400` (`InvalidHistoryDefaultTarget`).
     - The default transition $`T_{\text{default}}`$` must be an unconditional, spontaneous transition: its trigger event must be empty (`$`e_{\text{trig}} = \epsilon`$`) and its guard condition must be tautological (`$`g \equiv \text{true}`$). Any guarded or event-triggered default transition originating from a history pseudostate shall be deterministically rejected with diagnostic error code `E0400` (`ConditionalHistoryDefaultTransition`).
  3. **Non-Occupational Semantics & Boundary Constraints**:
     - History pseudostates are transient control flow markers and cannot be occupational states: an active discrete state machine configuration $`C`$` shall never contain a history pseudostate (`$`C \cap \mathcal{P}_{\text{history}} = \emptyset`$).
     - Transition traversals through history pseudostates shall execute in zero discrete simulation time ($`\Delta t = 0`$).
     - History pseudostates shall not declare internal behaviors, entry actions, do-activity behaviors, or exit actions. Any declaration of entry, exit, or do actions on a history pseudostate shall be deterministically rejected at compile time with diagnostic error code `E0400` (`HistoryPseudostateWithActions`).
     - Transitions entering a history pseudostate may originate from any external state or internal sub-state, but transitions exiting a history pseudostate are strictly limited to the mandatory outgoing default transition $`T_{\text{default}}`$.
  4. **History Configuration Recording upon Composite State Exit**:
     - Every composite state container $`S_{\text{comp}}`$` and orthogonal region `$`R`$` containing a history pseudostate shall bind a dedicated history configuration register `$`\mathcal{H}(S_{\text{comp}})`$.
     - Prior to the first entry into $`S_{\text{comp}}`$`, the history register is uninitialized (`$`\mathcal{H}(S_{\text{comp}}) = \emptyset`$).
     - Whenever an active composite state $`S_{\text{comp}}`$` is exited via an outgoing transition whose target lies outside `$`S_{\text{comp}}`$ (or an ancestor transition evacuating the hierarchy), the execution engine shall capture the exact active sub-configuration of descendant states immediately prior to exit:

```math
\mathcal{H}(S_{\text{comp}}) \leftarrow C \cap \text{descendants}(S_{\text{comp}})
```

     - If $`S_{\text{comp}}`$` reaches a final state (`$`s \in \mathcal{S}_{\text{final}}`$`) or executes an explicit history reset action (`$`\text{Action::ResetHistory}(S_{\text{comp}})`$`), the history register is cleared (`$`\mathcal{H}(S_{\text{comp}}) \leftarrow \emptyset`$).
  5. **Shallow History Restoration Semantics (`[H]`)**:
     - When a transition enters Shallow History pseudostate $`h_{\text{shallow}} \in \mathcal{P}_{\text{shallow}}`$` of container `$`S_{\text{comp}}`$:
       * If $`\mathcal{H}(S_{\text{comp}}) = \emptyset`$` (uninitialized or reset), the execution engine executes default transition `$`T_{\text{default}}`$`, entering `$`s_{\text{default}} = s_{\text{tgt}}(T_{\text{default}})`$.
       * If $`\mathcal{H}(S_{\text{comp}}) \ne \emptyset`$`, the state machine enters the unique direct child state `$`s_{\text{child}} \in \mathcal{H}(S_{\text{comp}}) \cap \mathcal{C}_{S_{\text{comp}}}`$ that was most recently active upon exit.
       * If $`s_{\text{child}}`$` is itself a composite state, its deeper nested sub-state configuration is NOT restored from `$`\mathcal{H}(S_{\text{comp}})`$`; instead, `$`s_{\text{child}}`$` executes its designated initial transition `$`T_{\text{init}}(s_{\text{child}})`$ to recursively resolve child sub-states down to active leaf states.
  6. **Deep History Restoration Semantics (`[H*]`)**:
     - When a transition enters Deep History pseudostate $`h_{\text{deep}} \in \mathcal{P}_{\text{deep}}`$` of container `$`S_{\text{comp}}`$:
       * If $`\mathcal{H}(S_{\text{comp}}) = \emptyset`$` (uninitialized or reset), the execution engine executes default transition `$`T_{\text{default}}`$`, entering `$`s_{\text{default}} = s_{\text{tgt}}(T_{\text{default}})`$`. If `$`s_{\text{default}}`$ is composite, its initial transitions are recursively evaluated down to active leaf states.
       * If $`\mathcal{H}(S_{\text{comp}}) \ne \emptyset`$, the state machine fully restores the entire recorded active configuration subtree:

```math
C_{\text{restored}} = \mathcal{H}(S_{\text{comp}})
```

         Every previously active intermediate composite state and active leaf state within $`\text{descendants}(S_{\text{comp}})`$ is simultaneously restored without executing initial transitions.
  7. **Orthogonal Region History Restoration**:
     - If Deep History is declared on an orthogonal composite state $`S_{\text{orth}}`$, history restoration reconstructs the entire active configuration across all constituent orthogonal regions simultaneously:

```math
\forall R_i \in \mathcal{R}(S_{\text{orth}}), \quad |C_{\text{restored}} \cap \text{Leaves}(R_i)| = 1 \land (C_{\text{restored}} \cap \text{Leaves}(R_i) = \mathcal{H}(S_{\text{orth}}) \cap \text{Leaves}(R_i))
```

     - If Shallow History is defined within an individual orthogonal region $`R_i`$`, it operates strictly within `$`R_i`$`, restoring `$`R_i`$'s immediate active child upon region reactivation.
  8. **Lifecycle Action Execution Order during History Entry**:
     - Transition and lifecycle action ordering during history entry shall strictly follow:
       * Step 1: Transition action $`A_{\text{trans}}`$ of the incoming transition is executed.
       * Step 2: The container entry action $`\text{entry}(S_{\text{comp}})`$` is executed (if `$`S_{\text{comp}}`$ is not already active).
       * Step 3: If history is uninitialized, the default transition action $`A_{\text{default}}`$ is executed, followed by entry actions along the path to the target state.
       * Step 4: If history is active, entry actions of restored states are executed in top-down hierarchical order from the outermost restored sub-state down to the active leaf states.
  9. **The 5 Executive Architectural Directives Compliance**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every history pseudostate, default transition, history configuration register, and restoration path record AST node shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical DEAP namespace OID and node fully qualified topological path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(u))`$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel validation of history pseudostate well-formedness, default transition coverage, scope consistency, and restoration path invariants across independent packages or state machines shall execute strictly on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: State identifiers, pseudostate names, event symbols, action names, and fully qualified path segments shall be interned into the deduplicated global symbol interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The state machine solver shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When semantic violations occur (`E0400`), diagnostics shall accumulate in the error sink buffer $`\mathcal{D}_{\text{sink}}`$`, substitute typed error sentinels (`$`\bot_{\text{history}}`$`, `$`\bot_{\text{trans}}`$`, `$`\bot_{\text{config}}`$`), and continue validating subsequent declarations. If accumulated diagnostics reach capacity `$`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully in accordance with REQ-0013 and REQ-0016.
     - *Directive 5 (Panic-Free Release Isolation)*: The state machine dynamics solver pipeline shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Verification latency ($`\lt 25\text{ ms}`$` for `$`10^4`$` state elements and transitions) and peak RSS memory (`$`\lt 100\text{ MB}`$) performance gates shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `StateMachine_Alpha`, `StateMachine_Beta`, `CompositeState_Alpha`, `CompositeState_Beta`, `State_Active_0`, `State_Active_1`, `State_Sub_0`, `State_Sub_1`, `State_Leaf_A1`, `State_Leaf_A2`, `State_Leaf_B1`, `State_Leaf_B2`, `ParallelState_Omega`, `Region_1`, `Region_2`, `Pseudostate_History_Shallow_1`, `Pseudostate_History_Deep_1`, `Transition_1`, `Transition_Default_1`, `Event_Suspend`, `Event_Resume`, `Event_Fault`, `Action_1`, `Port_1`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

#### 2. Formal Invariant

Let $`\mathcal{V}_{\text{AST}}`$ denote the universe of allocated AST nodes in contiguous bump arena storage.

  A discrete state machine with history support $`\mathcal{M}`$ is defined as a 7-tuple:

```math
  \mathcal{M} = \langle \mathcal{S}, \mathcal{R}, \mathcal{P}, \mathcal{T}, s_{\text{root}}, \sqsubset, \mathcal{H} \rangle
```

  where:

```math
  \begin{aligned}
  \mathcal{S} &= \mathcal{S}_{\text{atomic}} \cup \mathcal{S}_{\text{xor}} \cup \mathcal{S}_{\text{orth}} \quad (\text{finite set of occupational states}) \\
  \mathcal{R} &\subset \mathcal{V}_{\text{AST}} \quad (\text{finite set of orthogonal regions}) \\
  \mathcal{P} &= \mathcal{P}_{\text{init}} \cup \mathcal{P}_{\text{shallow}} \cup \mathcal{P}_{\text{deep}} \cup \mathcal{P}_{\text{other}} \quad (\text{finite set of pseudostates}) \\
  \mathcal{T} &\subset \mathcal{V}_{\text{AST}} \quad (\text{finite set of directed transitions}) \\
  s_{\text{root}} &\in \mathcal{S}_{\text{xor}} \cup \mathcal{S}_{\text{orth}} \quad (\text{unique root state container}) \\
  \sqsubset &\subset (\mathcal{S} \cup \mathcal{R} \cup \mathcal{P}) \times (\mathcal{S} \cup \mathcal{R}) \quad (\text{irreflexive parent-child containment relation}) \\
  \mathcal{H} &: (\mathcal{S}_{\text{xor}} \cup \mathcal{S}_{\text{orth}} \cup \mathcal{R}) \to 2^{\mathcal{S}} \quad (\text{history configuration register mapping})
  \end{aligned}
```

  History Pseudostate Partitioning:

```math
  \mathcal{P}_{\text{history}} = \mathcal{P}_{\text{shallow}} \cup \mathcal{P}_{\text{deep}}, \quad \mathcal{P}_{\text{shallow}} \cap \mathcal{P}_{\text{deep}} = \emptyset
```

  Each history pseudostate $`h \in \mathcal{P}_{\text{history}}`$ is formalized as a 7-tuple:

```math
  h = \langle \text{id}_h, \text{name}_h, \kappa_h, \text{parent}_h, T_{\text{default}}, \Delta_h, \text{span}_h \rangle
```

  where:

```math
  \begin{aligned}
  \text{id}_h &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
  \text{name}_h &\in \mathcal{S}_{\text{intern}} \quad (\text{interned scalar symbol identifier}) \\
  \kappa_h &\in \{ \text{Kind::ShallowHistory}, \text{Kind::DeepHistory} \} \quad (\text{history classification discriminant}) \\
  \text{parent}_h &\in \mathcal{S}_{\text{xor}} \cup \mathcal{S}_{\text{orth}} \cup \mathcal{R} \quad (\text{enclosing composite container handle}) \\
  T_{\text{default}} &\in \mathcal{T} \quad (\text{mandatory unique outgoing default transition}) \\
  \Delta_h &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
  \text{span}_h &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
  \end{aligned}
```

  1. Containment and Non-Root Placement Invariants:

```math
  \forall h \in \mathcal{P}_{\text{history}}, \quad \text{parent}_h \ne s_{\text{root}} \land \text{parent}_h \in \mathcal{S}_{\text{xor}} \cup \mathcal{S}_{\text{orth}} \cup \mathcal{R}
```

  2. Scope Uniqueness of History Pseudostates:

```math
  \begin{aligned}
  \forall p \in \mathcal{S}_{\text{xor}} \cup \mathcal{S}_{\text{orth}} \cup \mathcal{R}, &\quad |\{ h \in \mathcal{P}_{\text{shallow}} \mid \text{parent}_h = p \}| \le 1 \\
  \forall p \in \mathcal{S}_{\text{xor}} \cup \mathcal{S}_{\text{orth}} \cup \mathcal{R}, &\quad |\{ h \in \mathcal{P}_{\text{deep}} \mid \text{parent}_h = p \}| \le 1
  \end{aligned}
```

  3. Mandatory Default Transition Invariants:

```math
  \begin{aligned}
  \forall h \in \mathcal{P}_{\text{history}}, &\quad |\{ \tau \in \mathcal{T} \mid s_{\text{src}}(\tau) = h \}| = 1 \\
  \forall h \in \mathcal{P}_{\text{history}}, &\quad s_{\text{tgt}}(T_{\text{default}}(h)) \in \mathcal{C}_{\text{parent}_h} \\
  \forall h \in \mathcal{P}_{\text{history}}, &\quad e_{\text{trig}}(T_{\text{default}}(h)) = \epsilon \land g(T_{\text{default}}(h)) \equiv \text{true}
  \end{aligned}
```

  4. Non-Occupational & Action-Free Invariant:

```math
  \begin{aligned}
  \forall C \subseteq \mathcal{S}, &\quad C \cap \mathcal{P}_{\text{history}} = \emptyset \\
  \forall h \in \mathcal{P}_{\text{history}}, &\quad \text{entry}(h) = \emptyset \land \text{exit}(h) = \emptyset \land \text{do}(h) = \emptyset
  \end{aligned}
```

  5. History Configuration Capture upon Composite State Exit:
  Let $`C \subseteq \mathcal{S}`$` denote the active state configuration. When a transition `$`\tau = (s_{\text{src}}, s_{\text{tgt}})`$` executes such that container `$`S_{\text{comp}}`$` is exited (`$`S_{\text{comp}} \in C`$` and `$`S_{\text{comp}} \notin \text{ancestors}(s_{\text{tgt}}) \cup \{ s_{\text{tgt}} \}`$):

```math
  \mathcal{H}(S_{\text{comp}}) \leftarrow C \cap \text{descendants}(S_{\text{comp}})
```

  History Invalidation / Reset Invariant:

```math
  (C \cap \text{descendants}(S_{\text{comp}}) \cap \mathcal{S}_{\text{final}} \ne \emptyset) \lor \text{Executed}(\text{Action::ResetHistory}(S_{\text{comp}})) \implies \mathcal{H}(S_{\text{comp}}) \leftarrow \emptyset
```

  6. Recursive Initial State Resolution Operator:
  Let $`\text{ResolveInitial}(s)`$ define the deterministic completion of uninitialized hierarchy paths:

```math
  \text{ResolveInitial}(s) = \begin{cases}
  \emptyset, & \text{if } s \in \mathcal{S}_{\text{atomic}} \\
  \{ s_0 \} \cup \text{ResolveInitial}(s_0), & \text{if } s \in \mathcal{S}_{\text{xor}} \land s_0 = \text{InitialChild}(s) \\
  \bigcup_{R_i \in \mathcal{R}(s)} (\{ s_{0,i} \} \cup \text{ResolveInitial}(s_{0,i})), & \text{if } s \in \mathcal{S}_{\text{orth}} \land s_{0,i} = \text{InitialChild}(R_i)
  \end{cases}
```

  7. Shallow History Restoration Rule:
  Let transition $`\tau`$` target Shallow History pseudostate `$`h \in \mathcal{P}_{\text{shallow}}`$` with `$`S_{\text{comp}} = \text{parent}_h`$:

```math
  C_{\text{restore}}(h) = \begin{cases}
  \{ s_{\text{def}} \} \cup \text{ResolveInitial}(s_{\text{def}}), & \text{if } \mathcal{H}(S_{\text{comp}}) = \emptyset \text{ where } s_{\text{def}} = s_{\text{tgt}}(T_{\text{default}}(h)) \\
  \{ s^* \} \cup \text{ResolveInitial}(s^*), & \text{if } \mathcal{H}(S_{\text{comp}}) \ne \emptyset \text{ where } s^* \in \mathcal{H}(S_{\text{comp}}) \cap \mathcal{C}_{S_{\text{comp}}}
  \end{cases}
```

  8. Deep History Restoration Rule:
  Let transition $`\tau`$` target Deep History pseudostate `$`h \in \mathcal{P}_{\text{deep}}`$` with `$`S_{\text{comp}} = \text{parent}_h`$:

```math
  C_{\text{restore}}(h) = \begin{cases}
  \{ s_{\text{def}} \} \cup \text{ResolveInitial}(s_{\text{def}}), & \text{if } \mathcal{H}(S_{\text{comp}}) = \emptyset \text{ where } s_{\text{def}} = s_{\text{tgt}}(T_{\text{default}}(h)) \\
  \mathcal{H}(S_{\text{comp}}), & \text{if } \mathcal{H}(S_{\text{comp}}) \ne \emptyset
  \end{cases}
```

  9. Restored Active Configuration Equivalence:
  The global active configuration following history entry transition $`\tau`$ is defined as:

```math
  C_{\text{next}} = (C \setminus \text{descendants}(\text{LCA}(s_{\text{src}}(\tau), S_{\text{comp}}))) \cup \{ S_{\text{comp}} \} \cup (\text{ancestors}(S_{\text{comp}}) \cap \mathcal{S}) \cup C_{\text{restore}}(h)
```

  10. Deterministic Diagnostic Trigger Rules (REQ-0191):

```math
  \begin{aligned}
  \exists h \in \mathcal{P}_{\text{history}} : \text{parent}_h = s_{\text{root}} &\implies \text{Diagnostic}(h, \text{DiagnosticCode::E0400}, \text{HistoryPseudostateAtRoot}) \in \mathcal{D}_{\text{sink}} \\
  \exists h \in \mathcal{P}_{\text{history}} : |\{ \tau \in \mathcal{T} \mid s_{\text{src}}(\tau) = h \}| = 0 &\implies \text{Diagnostic}(h, \text{DiagnosticCode::E0400}, \text{HistoryPseudostateWithoutDefaultTransition}) \in \mathcal{D}_{\text{sink}} \\
  \exists h \in \mathcal{P}_{\text{history}} : |\{ \tau \in \mathcal{T} \mid s_{\text{src}}(\tau) = h \}| \gt 1 &\implies \text{Diagnostic}(h, \text{DiagnosticCode::E0400}, \text{MultipleHistoryDefaultTransitions}) \in \mathcal{D}_{\text{sink}} \\
  \exists h \in \mathcal{P}_{\text{history}} : s_{\text{tgt}}(T_{\text{default}}(h)) \notin \mathcal{C}_{\text{parent}_h} &\implies \text{Diagnostic}(T_{\text{default}}(h), \text{DiagnosticCode::E0400}, \text{InvalidHistoryDefaultTarget}) \in \mathcal{D}_{\text{sink}} \\
  \exists h \in \mathcal{P}_{\text{history}} : (e_{\text{trig}}(T_{\text{default}}(h)) \ne \epsilon \lor g(T_{\text{default}}(h)) \not\equiv \text{true}) &\implies \text{Diagnostic}(T_{\text{default}}(h), \text{DiagnosticCode::E0400}, \text{ConditionalHistoryDefaultTransition}) \in \mathcal{D}_{\text{sink}} \\
  \exists p, h_1, h_2 \in \mathcal{P}_{\text{history}} : h_1 \ne h_2 \land \text{parent}_{h_1} = \text{parent}_{h_2} = p \land \kappa_{h_1} = \kappa_{h_2} &\implies \text{Diagnostic}(h_2, \text{DiagnosticCode::E0400}, \text{DuplicateHistoryPseudostateKind}) \in \mathcal{D}_{\text{sink}} \\
  \exists h \in \mathcal{P}_{\text{history}} : (\text{entry}(h) \ne \emptyset \lor \text{exit}(h) \ne \emptyset \lor \text{do}(h) \ne \emptyset) &\implies \text{Diagnostic}(h, \text{DiagnosticCode::E0400}, \text{HistoryPseudostateWithActions}) \in \mathcal{D}_{\text{sink}} \\
  |\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
  \end{aligned}
```

  11. Deterministic RFC 4122 UUIDv5 Anchor Invariant (Directive 1):

```math
  \begin{aligned}
  \forall h \in \mathcal{P}_{\text{history}}, &\quad \Delta_h = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(h)) \\
  \forall \tau \in \mathcal{T}_{\text{default}}, &\quad \Delta_\tau = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(\tau))
  \end{aligned}
```

#### 3. Computational Complexity & Algorithmic Bounds

Static history pseudostate validation, default transition auditing, scope verification, and dynamic configuration capture and restoration algorithms reside strictly in **Complexity Class P** (Deterministic Polynomial Time).

  **Mathematical Delineation from Algorithmic Bound NP-5**:
  In concurrent discrete state machines containing orthogonal regions, dynamic reachability analysis, deadlock freedom, and livelock detection is PSPACE-complete (or NP-complete under bounded depth unrolling $`k \le k_{\max}`$), as formalized under Algorithmic Bound NP-5 (REQ-0124) via SAT-based Bounded Model Checking (BMC). This computational explosion arises because concurrent state spaces expand as the Cartesian product of regional sub-states:

```math
  |\text{GlobalStates}| = \prod_{i=1}^m |\text{States}(R_i)|
```

  In contrast, REQ-0126 governs the static well-formedness verification of history pseudostates and the deterministic execution semantics of configuration recording and restoration. Under static compilation, no dynamic reachability exploration or state-space unrolling is performed; the compiler operates directly on the containment tree $`(\mathcal{S} \cup \mathcal{R} \cup \mathcal{P}, \sqsubset)`$` and transition graph `$`(\mathcal{S} \cup \mathcal{P}, \mathcal{T})`$`, executing in deterministic linear time `$`O(V + E)`$`. During runtime execution, history configuration capture and restoration follow fixed hierarchical tree paths bounded by the maximum hierarchy depth `$`h \le 32`$`, executing in `$`O(h) = O(1)`$ bounded steps per transition traversal.

  **Asymptotic Complexity Analysis**:
  Let $`V = |\mathcal{S} \cup \mathcal{R} \cup \mathcal{P}|`$` denote the total number of state and pseudostate AST nodes, `$`E = |\mathcal{T}|`$` denote the total number of transitions, and `$`h`$` denote the maximum containment hierarchy depth (`$`h \le 32 \ll V`$ in valid MBSE models).
  1. *History Pseudostate Node Allocation & Symbol Interning*:
     Allocating history pseudostate records in contiguous bump arena storage and interning symbol strings requires $`O(1)`$ amortized operations per node, totaling:

```math
     T_{\text{alloc}}(|\mathcal{P}_{\text{history}}|) \in O(|\mathcal{P}_{\text{history}}|) \le O(V)
```

  2. *Containment Scope & Placement Validation*:
     For each history pseudostate $`h \in \mathcal{P}_{\text{history}}`$`, checking parent container validity (`$`\text{parent}_h \ne s_{\text{root}}`$` and `$`\text{parent}_h \in \mathcal{S}_{\text{xor}} \cup \mathcal{S}_{\text{orth}} \cup \mathcal{R}`$`) takes `$`O(1)`$ pointer inspections:

```math
     T_{\text{scope}}(|\mathcal{P}_{\text{history}}|) \in O(|\mathcal{P}_{\text{history}}|) \le O(V)
```

  3. *Scope Uniqueness Verification*:
     Checking that no container declares duplicate history pseudostates of the identical kind requires tracking at most two history node handles per composite state:

```math
     T_{\text{unique}}(V) \in O(V)
```

  4. *Default Transition Existence & Target Verification*:
     For each history pseudostate $`h`$`, verifying that exactly one outgoing default transition exists (`$`|\text{Outgoing}(h)| = 1`$`), that its target is an immediate child (`$`s_{\text{tgt}} \in \mathcal{C}_{\text{parent}_h}`$`), and that its trigger is empty (`$`e_{\text{trig}} = \epsilon`$`) and guard is tautological (`$`g \equiv \text{true}`$`) takes `$`O(1)`$ operations:

```math
     T_{\text{default}}(|\mathcal{P}_{\text{history}}|) \in O(|\mathcal{P}_{\text{history}}|) \le O(E)
```

  5. *Runtime History Recording upon Exit*:
     When composite state $`S_{\text{comp}}`$` is exited, copying the active sub-configuration `$`C \cap \text{descendants}(S_{\text{comp}})`$` into the history register `$`\mathcal{H}(S_{\text{comp}})`$` copies at most `$`h`$` state handles in non-orthogonal trees, or at most `$`m \cdot h`$` handles in orthogonal states with `$`m`$ regions:

```math
     T_{\text{record}}(h, m) \in O(m \cdot h) = O(1)
```

  6. *Runtime Shallow History Restoration*:
     Looking up direct child $`s^* \in \mathcal{H}(S_{\text{comp}}) \cap \mathcal{C}_{S_{\text{comp}}}`$` takes `$`O(1)`$` set intersection operations. Recursively resolving initial states down to active leaves takes at most `$`h`$ steps:

```math
     T_{\text{shallow}}(h) \in O(h) = O(1)
```

  7. *Runtime Deep History Restoration*:
     Restoring the complete active sub-configuration tree $`\mathcal{H}(S_{\text{comp}})`$` writes at most `$`m \cdot h`$` state handles directly into the active configuration set `$`C_{\text{next}}`$ without evaluating initial transitions:

```math
     T_{\text{deep}}(h, m) \in O(m \cdot h) = O(1)
```

  8. *Aggregate Compile-Time Verification Time Complexity*:
     Combining all static validation phases, total compile-time execution time is strictly linear:

```math
     T_{\text{total}}(V, E) \in O(V + E)
```

     The algorithm operates without backtracking, SAT solving, or exponential state-space unrolling, guaranteeing deterministic total-function termination.
  9. *Parallel Work-Stealing Scaling (Directive 2)*:
     When verifying $`P`$` independent state machines or decoupled packages across `$`N_{\text{max\_workers}}`$ threads on a bounded work-stealing thread pool:

```math
     T_{\text{parallel}}(V, E, N_{\text{max\_workers}}) \in O\left( \frac{V + E}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

  10. *Space Complexity & Arena Memory Bounds*:
      History pseudostates, default transition descriptors, and configuration registers reside in contiguous bump arena storage, requiring $`O(V + E)`$` bytes. Hierarchy traversal stack depth is strictly bounded by `$`h \le 32`$` (`$`O(1)`$` memory). The diagnostic error sink buffer is strictly bounded by `$`O(C_{\text{max\_errors}}) = O(1)`$ capacity.

#### 4. Verification & Conformance Criteria

Automated test suites shall deterministically verify compliance against synthetic abstract MBSE models (`Package_0`, `Package_1`, `StateMachine_Alpha`, `StateMachine_Beta`, `CompositeState_Alpha`, `CompositeState_Beta`, `State_Active_0`, `State_Active_1`, `State_Sub_0`, `State_Sub_1`, `State_Leaf_A1`, `State_Leaf_A2`, `State_Leaf_B1`, `State_Leaf_B2`, `ParallelState_Omega`, `Region_1`, `Region_2`, `Pseudostate_History_Shallow_1`, `Pseudostate_History_Deep_1`, `Transition_1`, `Transition_Default_1`, `Event_Suspend`, `Event_Resume`, `Event_Fault`, `Action_1`, `Port_1`, `Flow_A`, `param_x : Real`) across the following 18 verification gates:

  1. **Canonical Shallow History Restoration Gate**: Ingest synthetic model `Package_0` declaring `CompositeState_Alpha` containing atomic sub-states `State_Sub_0`, `State_Sub_1`, and shallow history pseudostate `Pseudostate_History_Shallow_1`. Activate `State_Sub_1`, execute an exit transition triggered by `Event_Suspend`, and re-enter `CompositeState_Alpha` via `Pseudostate_History_Shallow_1` on `Event_Resume`. Activate leaf state `State_Leaf_A2`, evacuate the hierarchy on `Event_Suspend`, and re-enter via `Pseudostate_History_Deep_1` on `Event_Resume`.
