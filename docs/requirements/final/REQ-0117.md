### REQ-0117: Allen's Interval Algebra Temporal Consistency & ORD-Horn SMT Solver (NP-1)

- **Normative Statement**: The spatio-temporal dynamics solver, occurrence lifecycle verification engine, and formal temporal constraint pipeline of Subsystem 6 shall enforce temporal consistency over occurrence lifecycles, action executions, and discrete state occupancies by restricting static qualitative constraint propagation to the ORD-Horn tractable subclass $\mathcal{H}_{\text{ORD}}$ guaranteeing $O(N^3)$ polynomial-time path consistency, while compiling general non-ORD-Horn temporal constraint networks to Quantifier-Free Rational Difference Logic (QF_RDL) formulas solved via an integrated SMT difference logic solver under an explicit deterministic step budget $\kappa_{\text{temporal}}$.

  Specifically, the temporal dynamics solver, ORD-Horn classifier, and difference logic SMT engine shall strictly enforce the following structural, algebraic, and algorithmic invariants:
  1. **Temporal Constraint Network Representation & Occurrence Lifecycles**:
     - The dynamics solver shall formalize qualitative and quantitative temporal constraints over occurrence lifecycles, action executions, and state occupancies as a directed temporal constraint network multigraph $\mathcal{G}_{\text{temp}} = (\mathcal{O}, \mathcal{C}_{\text{temp}})$.
     - Vertex set $\mathcal{O}$ shall comprise all temporal occurrence entities allocated in contiguous bump arena storage, where each occurrence $o \in \mathcal{O}$ possesses an interval lifecycle $I(o) = [t_{\text{start}}(o), t_{\text{end}}(o)]$ over the continuous linear timeline $(\mathbb{R}, \le)$.
     - Edge set $\mathcal{C}_{\text{temp}}$ shall comprise all directed pairwise temporal constraints $C_{ij} = \langle o_i, o_j, R(o_i, o_j) \rangle$, where $R(o_i, o_j) \subseteq \mathcal{B}_{13}$ denotes a disjunction over Allen's 13 primitive atomic interval relations $\mathcal{B}_{13} = \{ \mathbf{b}, \mathbf{bi}, \mathbf{m}, \mathbf{mi}, \mathbf{o}, \mathbf{oi}, \mathbf{s}, \mathbf{si}, \mathbf{d}, \mathbf{di}, \mathbf{f}, \mathbf{fi}, \mathbf{eq} \}$.
     - Each relation $R(o_i, o_j)$ shall be encoded as an immutable 13-bit relation bitmask $\mathbf{m}_{R(i, j)} \in [0, 8191]$ allocated in contiguous arena storage, where each bit corresponds to one basic relation in $\mathcal{B}_{13}$.
     - Directional converse symmetry shall be strictly maintained: $R(o_j, o_i) \equiv (R(o_i, o_j))^\smile$, computed via bitwise transpositions of inverse relation pairs ($\mathbf{b} \leftrightarrow \mathbf{bi}$, $\mathbf{m} \leftrightarrow \mathbf{mi}$, $\mathbf{o} \leftrightarrow \mathbf{oi}$, $\mathbf{s} \leftrightarrow \mathbf{si}$, $\mathbf{d} \leftrightarrow \mathbf{di}$, $\mathbf{f} \leftrightarrow \mathbf{fi}$, $\mathbf{eq} \leftrightarrow \mathbf{eq}$).
  2. **ORD-Horn Tractable Subclass Classification ($\mathcal{H}_{\text{ORD}}$)**:
     - The temporal solver shall embed a static, compile-time bitset lookup table representing the 868 tractable relations of the maximal ORD-Horn subclass $\mathcal{H}_{\text{ORD}} \subset 2^{\mathcal{B}_{13}}$ established by Nebel & Bürckert (1995).
     - For every asserted temporal constraint $R(o_i, o_j)$, the solver shall evaluate membership $R(o_i, o_j) \in \mathcal{H}_{\text{ORD}}$ in $O(1)$ time via bitmask table lookup.
     - If all constraints in a connected temporal network component belong to $\mathcal{H}_{\text{ORD}}$ ($\forall C_{ij} \in \mathcal{C}_{\text{temp}}, R(o_i, o_j) \in \mathcal{H}_{\text{ORD}}$), the component shall be classified as an ORD-Horn tractable network and routed to the deterministic polynomial-time path consistency engine.
     - If one or more constraints in a connected temporal network component do not belong to $\mathcal{H}_{\text{ORD}}$ ($\exists C_{ij} \in \mathcal{C}_{\text{temp}}, R(o_i, o_j) \notin \mathcal{H}_{\text{ORD}}$), the component shall be classified as a general temporal constraint network crossing the NP-1 frontier and routed to the QF_RDL difference logic SMT compiler.
  3. **Polynomial-Time Path Consistency Solver for $\mathcal{H}_{\text{ORD}}$**:
     - For ORD-Horn tractable networks, the solver shall execute path consistency propagation over all occurrence triples $(o_i, o_j, o_k)$:
       $$R(o_i, o_k) \leftarrow R(o_i, o_k) \cap (R(o_i, o_j) \circ R(o_j, o_k))$$
       where $\circ$ denotes relational composition evaluated via Allen's $13 \times 13$ composition table and $\cap$ denotes bitwise relation intersection.
     - Path consistency propagation shall execute using a deterministic worklist queue until reaching a stable fixed point or discovering an empty relation.
     - Because path consistency is sound and complete for consistency within the ORD-Horn subclass $\mathcal{H}_{\text{ORD}}$, achieving a non-empty fixed point statically certifies global temporal consistency and tightens all pairwise interval relationships without backtracking.
     - If any pair $(o_i, o_j)$ derives the empty relation ($R(o_i, o_j) = \emptyset$, bitmask $0\text{x}0000$), a qualitative temporal contradiction is proven. The solver shall reject the compilation unit deterministically with diagnostic error code `E0400` (`TemporalConsistencyContradiction`), reporting the minimal conflicting occurrence cycle and exact source span locations.
  4. **General Temporal Network Lowering to Difference Logic (QF_RDL)**:
     - For general temporal networks containing non-ORD-Horn relations, the compiler shall lower the qualitative interval constraint network into a quantifier-free difference logic formula $\Phi_{\text{temporal}} = \Phi_{\text{bool}} \land \Phi_{\text{diff}}$ over interval endpoint variables $\{ t_{i, s}, t_{i, e} \}$.
     - For each interval occurrence $o_i \in \mathcal{O}$, the compiler shall generate the intrinsic well-formedness difference constraint:
       $$t_{i, s} - t_{i, e} \le -\epsilon_{\text{dur}}$$
       for durative occurrences with positive duration guard $\epsilon_{\text{dur}} \gt 0$, or $t_{i, s} - t_{i, e} \le 0 \land t_{i, e} - t_{i, s} \le 0$ for instantaneous point events.
     - For each basic relation $r \in \mathcal{B}_{13}$, the compiler shall emit its canonical conjunction of endpoint difference constraints of the form $u - v \le c$.
     - For each non-ORD-Horn disjunctive relation $R(o_i, o_j) = \{ r_1, \dots, r_k \}$, the compiler shall introduce boolean selector literals $b_{i, j, r}$ such that:
       $$\bigvee_{r \in R(o_i, o_j)} b_{i, j, r} \quad \land \quad \bigwedge_{r \in R(o_i, o_j)} \left( b_{i, j, r} \implies \bigwedge_{(u, v, c) \in \text{Diff}(r)} (u - v \le c) \right)$$
  5. **DPLL(T) SMT Difference Logic Solver with Step Budget $\kappa_{\text{temporal}}$ (NP-1 Frontier)**:
     - In accordance with Algorithmic Bound NP-1, deciding consistency of general Allen interval networks is NP-complete. To guarantee bounded compile-time execution and prevent exponential solver stagnation, the compiler shall solve $\Phi_{\text{temporal}}$ using an integrated DPLL(T) difference logic solver governed by an explicit deterministic step budget $\kappa_{\text{temporal}}$ (defaulting to $\kappa_{\text{temporal}} = 10^5$ operations).
     - Each DPLL decision step, unit propagation pass, conflict analysis iteration, and theory-solver negative cycle detection step shall increment a deterministic monotonic step counter $N_{\text{step}}$.
     - The theory solver for $T_{\text{RDL}}$ shall evaluate difference constraint conjunctions by incremental negative cycle detection on the difference constraint graph.
     - If the difference graph contains a negative cycle, the theory solver shall synthesize a minimal conflict clause consisting of the negation of the selector literals forming the cycle, driving CDCL backjumping.
     - If the solver establishes satisfiability ($\Phi_{\text{temporal}} \equiv \text{SAT}$) within $N_{\text{step}} \le \kappa_{\text{temporal}}$, the temporal network is certified consistent, and the solver synthesizes concrete interval bounds and minimal tightened relations.
     - If the solver establishes unsatisfiability ($\Phi_{\text{temporal}} \equiv \text{UNSAT}$) within $N_{\text{step}} \le \kappa_{\text{temporal}}$, compilation shall fail deterministically with diagnostic error code `E0400` (`TemporalUnsatisfiableNetwork`), isolating the minimal unsatisfiable core and highlighting the conflicting occurrence declarations.
     - If the step counter exceeds the budget ($N_{\text{step}} \gt \kappa_{\text{temporal}}$) without reaching a decisive SAT or UNSAT termination, compilation shall fail deterministically with diagnostic error code `E0406` (`TemporalSolverStepLimitExceeded`), reporting the non-ORD-Horn subnetwork, active decision depth, and step limit cutoff.
  6. **Executive Architectural Directives Compliance**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every occurrence lifecycle node, temporal constraint record, difference logic literal, and conflict clause artifact shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical DEAP namespace OID and node fully qualified topological path ($\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel ORD-Horn classification, independent network component partitioning, path consistency propagation, and decoupled SMT difference logic solving across separate packages or occurrence clusters shall execute exclusively on a bounded work-stealing thread pool with worker bound $N_{\text{max\_workers}}$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: Occurrence identifiers, temporal relation names, SMT variable symbols, and qualifier labels shall be interned into the deduplicated global symbol interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The temporal dynamics solver shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When temporal semantic contradictions (`E0400`) or solver timeouts (`E0406`) occur, diagnostics shall accumulate in the error sink buffer $\mathcal{D}_{\text{sink}}$, substitute typed error sentinels ($\bot_{\text{interval}}$, $\bot_{\text{net}}$), and continue validating subsequent occurrence and constraint declarations. If accumulated diagnostics reach $C_{\text{max\_errors}}$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully in accordance with REQ-0013 and REQ-0016.
     - *Directive 5 (Panic-Free Release Isolation)*: The temporal consistency and SMT difference logic solver pipeline shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Verification latency ($\lt 25\text{ ms}$ for benchmark models of $10^3$ ORD-Horn occurrences) and peak RSS memory ($\lt 100\text{ MB}$) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Occurrence_Alpha`, `Occurrence_Beta`, `Occurrence_Gamma`, `Interval_1`, `Interval_2`, `Interval_3`, `TemporalNetwork_Alpha`, `TemporalNetwork_Beta`, `Port_1`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $\mathcal{V}_{\text{AST}}$ denote the universe of allocated AST nodes in contiguous bump arena storage.

  Let $\mathcal{G}_{\text{temp}} = (\mathcal{O}, \mathcal{C}_{\text{temp}})$ denote an abstract temporal constraint network multigraph.

  Each interval occurrence entity $o \in \mathcal{O}$ is formalized as an 8-tuple:

  $$
  o = \langle \text{id}_o, \text{name}_o, t_{\text{start}}(o), t_{\text{end}}(o), \kappa_o, \Delta_o, \text{provenance}_o, \text{span}_o \rangle
  $$

  where:

  $$
  \begin{aligned}
  \text{id}_o &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
  \text{name}_o &\in \mathcal{S}_{\text{intern}} \quad (\text{interned occurrence identifier}) \\
  t_{\text{start}}(o), t_{\text{end}}(o) &\in \mathbb{R} \cup \mathcal{E}_{\text{expr}} \quad (\text{interval start and end endpoints}) \\
  \kappa_o &\in \{ \text{Kind::Durative}, \text{Kind::Instantaneous} \} \quad (\text{occurrence lifecycle kind}) \\
  \Delta_o &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
  \text{provenance}_o &\in \mathcal{V}_{\text{AST}} \quad (\text{owning structural block or state handle}) \\
  \text{span}_o &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
  \end{aligned}
  $$

  Each pairwise temporal constraint $C_{ij} \in \mathcal{C}_{\text{temp}}$ between occurrences $o_i, o_j \in \mathcal{O}$ is formalized as a 5-tuple:

  $$
  C_{ij} = \langle \text{id}_{C_{ij}}, o_i, o_j, R(o_i, o_j), \Delta_{C_{ij}} \rangle
  $$

  where $R(o_i, o_j) \subseteq \mathcal{B}_{13}$ is represented as a 13-bit relation mask:

  $$
  \mathbf{m}_{R(i, j)} = \sum_{k=0}^{12} b_k \cdot 2^k \in [0, 8191], \quad b_k \in \{0, 1\}
  $$

  Allen's 13 Primitive Atomic Relations ($\mathcal{B}_{13}$):

  $$
  \mathcal{B}_{13} = \{ \mathbf{b}, \mathbf{bi}, \mathbf{m}, \mathbf{mi}, \mathbf{o}, \mathbf{oi}, \mathbf{s}, \mathbf{si}, \mathbf{d}, \mathbf{di}, \mathbf{f}, \mathbf{fi}, \mathbf{eq} \}
  $$

  ORD-Horn Tractable Subclass Definition ($\mathcal{H}_{\text{ORD}}$):

  $$
  \mathcal{H}_{\text{ORD}} \subset 2^{\mathcal{B}_{13}}, \quad |\mathcal{H}_{\text{ORD}}| = 868
  $$

  ORD-Horn Membership Invariant:

  $$
  \text{IsOrdHorn}(R(o_i, o_j)) \iff \mathbf{m}_{R(i, j)} \in \mathcal{T}_{\text{ORD\_Horn}}
  $$

  where $\mathcal{T}_{\text{ORD\_Horn}}$ is a precomputed lookup bitset over $\{0, \dots, 8191\}$.

  Path Consistency Invariant for ORD-Horn Networks:

  $$
  \forall i, j, k \in \{1, \dots, |\mathcal{O}|\}, \quad R(o_i, o_k) \leftarrow R(o_i, o_k) \cap (R(o_i, o_j) \circ R(o_j, o_k))
  $$

  Soundness and Completeness of Path Consistency on $\mathcal{H}_{\text{ORD}}$:

  $$
  \mathcal{C}_{\text{temp}} \subseteq \mathcal{H}_{\text{ORD}} \implies \left( \forall i, j, \; R(o_i, o_j) \ne \emptyset \iff \text{Satisfiable}(\mathcal{G}_{\text{temp}}) \right)
  $$

  Contradiction Invariant for Path Consistency:

  $$
  \exists i, j \in \{1, \dots, |\mathcal{O}|\} : R(o_i, o_j) = \emptyset \implies \text{Diagnostic}(\langle o_i, o_j \rangle, \text{DiagnosticCode::E0400}, \text{TemporalConsistencyContradiction}) \in \mathcal{D}_{\text{sink}}
  $$

  Quantifier-Free Rational Difference Logic (QF_RDL) Lowering:

  $$
  \Phi_{\text{temporal}} = \Phi_{\text{wellformed}} \land \Phi_{\text{clauses}} \land \Phi_{\text{diff}}
  $$

  where:

  $$
  \begin{aligned}
  \Phi_{\text{wellformed}} &= \bigwedge_{o_i \in \mathcal{O}_{\text{durative}}} (t_{i, s} - t_{i, e} \le -\epsilon_{\text{dur}}) \;\land\; \bigwedge_{o_k \in \mathcal{O}_{\text{point}}} (t_{k, s} - t_{k, e} \le 0 \;\land\; t_{k, e} - t_{k, s} \le 0) \\
  \Phi_{\text{clauses}} &= \bigwedge_{R(o_i, o_j) \notin \mathcal{H}_{\text{ORD}}} \left( \bigvee_{r \in R(o_i, o_j)} b_{i, j, r} \right) \\
  \Phi_{\text{diff}} &= \bigwedge_{R(o_i, o_j) \notin \mathcal{H}_{\text{ORD}}} \bigwedge_{r \in R(o_i, o_j)} \left( b_{i, j, r} \implies \bigwedge_{(u, v, c) \in \text{Diff}(r)} (u - v \le c) \right)
  \end{aligned}
  $$

  DPLL(T) SMT Step Bound Invariant:

  $$
  N_{\text{step}} = \text{Steps}(\text{DPLL\_T}(\Phi_{\text{temporal}})) \le \kappa_{\text{temporal}}
  $$

  Deterministic Diagnostic Emission Invariant (REQ-0191):

  $$
  \begin{aligned}
  \exists i, j : R(o_i, o_j) = \emptyset &\implies \text{Diagnostic}(\langle o_i, o_j \rangle, \text{DiagnosticCode::E0400}, \text{TemporalConsistencyContradiction}) \in \mathcal{D}_{\text{sink}} \\
  \Phi_{\text{temporal}} \equiv \text{UNSAT} &\implies \text{Diagnostic}(\text{UnsatCore}(\Phi_{\text{temporal}}), \text{DiagnosticCode::E0400}, \text{TemporalUnsatisfiableNetwork}) \in \mathcal{D}_{\text{sink}} \\

- **Computational Complexity & Algorithmic Bounds**: Qualitative temporal constraint consistency checking over occurrence lifecycles resides in **Complexity Class NP-complete** for general networks (Algorithmic Bound NP-1, Vilain & Kautz, 1986), and in **Complexity Class P** (Deterministic Polynomial Time) when restricted to the ORD-Horn tractable subclass $\mathcal{H}_{\text{ORD}}$ (Nebel & Bürckert, 1995).

  For an abstract MBSE model comprising $N = |\mathcal{O}|$ occurrence lifecycles and $M = |\mathcal{C}_{\text{temp}}| \le N(N - 1) / 2$ temporal constraints:
  1. *ORD-Horn Classification & Bitmask Table Lookup*:
     For each of the $M$ asserted temporal constraints, checking membership in $\mathcal{H}_{\text{ORD}}$ executes via $O(1)$ bitmask indexing into a precomputed 8192-bit table.
     For $M$ constraints:
     $$T_{\text{class}}(M) \in O(M) \subseteq O(N^2)$$
  2. *ORD-Horn Path Consistency Solver Complexity*:
     For networks where $\mathcal{C}_{\text{temp}} \subseteq \mathcal{H}_{\text{ORD}}$, the path consistency algorithm maintains an active queue of constraint pairs.
     There are at most $N(N - 1) / 2$ distinct pairs. Each pairwise relation $R(o_i, o_j)$ can be tightened at most 13 times as candidate atomic relations are pruned.
     Whenever an edge $(o_i, o_j)$ is tightened, the algorithm inspects $N - 2$ triangles $(o_i, o_j, o_k)$.
     Each triangle update computes relation composition and intersection in $O(1)$ bitwise operations.
     Therefore, the maximum number of triangle relaxations is bounded by:
     $$T_{\text{ORD\_Horn}}(N) \le 13 \cdot N \cdot \frac{N(N - 1)}{2} \in O(N^3)$$
     The algorithm operates without backtracking, branching, or floating-point iterations, guaranteeing deterministic polynomial convergence in $O(N^3)$ time.
  3. *General Non-ORD-Horn Lowering to Difference Logic (QF_RDL)*:
     Translating $K \le M$ non-ORD-Horn constraints produces at most $13 K$ boolean selector variables and $O(K)$ difference logic inequalities.
     Constructing the formula $\Phi_{\text{temporal}}$ executes in deterministic linear time:
     $$T_{\text{lower}}(K) \in O(K) \subseteq O(N^2)$$
  4. *DPLL(T) SMT Difference Logic Solving under Step Budget $\kappa_{\text{temporal}}$*:
     While general Allen interval networks are NP-complete with unconstrained worst-case complexity $O(2^M \cdot (V_{\text{diff}} + E_{\text{diff}}))$, the compiler enforces an explicit step budget $\kappa_{\text{temporal}}$.
     The difference logic theory solver maintains a difference constraint graph with $V_{\text{diff}} = 2N$ endpoint vertices and $E_{\text{diff}} \le 4M$ edges, checking for negative cycles in $O(E_{\text{diff}})$ time per incremental assertion.
     Under the deterministic cutoff $\kappa_{\text{temporal}}$, the total execution cost of the DPLL(T) solver is strictly bounded by:
     $$T_{\text{SMT}}(\kappa_{\text{temporal}}, N) \in O(\kappa_{\text{temporal}} \cdot (V_{\text{diff}} + E_{\text{diff}})) = O(\kappa_{\text{temporal}} \cdot N^2)$$
     If the step limit is reached, execution aborts deterministically in $O(1)$ steps with diagnostic `E0406`, completely precluding exponential compiler hang.
  5. *Aggregate Worst-Case Time Complexity*:
     For pure ORD-Horn networks:
     $$T_{\text{total}}(N) \in O(N^3)$$
     For general networks crossing NP-1:
     $$T_{\text{total}}(N, \kappa_{\text{temporal}}) \in O(N^3 + \kappa_{\text{temporal}} \cdot N^2)$$
     guaranteeing deterministic, predictable compile-time execution.
  6. *Parallel Work-Stealing Scaling (Directive 2)*:
     When evaluating $P$ independent occurrence networks or packages across $N_{\text{max\_workers}}$ threads on a bounded work-stealing thread pool:
     $$T_{\text{parallel}}(N, N_{\text{max\_workers}}) \in O\left( \frac{N^3 + \kappa_{\text{temporal}} \cdot N^2}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)$$
  7. *Space Complexity & Arena Memory Bounds*:
     Allocations for network vertices, constraint edges, 13-bit relation bitmasks, difference logic formulas, and SMT solver trail state are maintained in contiguous bump arena storage, requiring $O(N^2)$ bytes. Interned identifier tokens require $O(N)$ bytes in the global symbol pool. The diagnostic error sink buffer is strictly bounded by $O(C_{\text{max\_errors}}) = O(1)$ capacity.
