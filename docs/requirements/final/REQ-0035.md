### REQ-0035: Deterministic Node Handle Addressing & Reference Safety

- **Normative Statement**: The core compiler metamodel, node arena storage, and abstract syntax tree (AST) graph engine shall address, reference, interconnect, and traverse all AST nodes exclusively via deterministic typed integer handles (`NodeHandle<T>`) rather than unmanaged virtual memory pointers. Raw memory pointers (`*const T`, `*mut T`), dynamic heap references, and unaligned memory offsets are strictly prohibited across all inter-node relations, graph edges, lexical scope symbol tables, parent-child hierarchies, and cross-pass compiler communication channels. Every node handle shall be encoded as a compact 64-bit unsigned integer scalar value structured into three disjoint bitfields: a 32-bit arena slot index, a 16-bit slot generation counter, and a 16-bit node type discriminator tag.

  The node handle addressing architecture shall enforce the following normative guarantees:
  1. Generational Reference Safety: Every slot within an arena segment shall maintain an incarnation generation counter that monotonically increments upon slot reallocation, mutation, or recycling (such as during AST graph rewriting or tombstone pruning). Dereferencing a node handle within an arena shall perform a constant-time tripartite validation verifying that the slot index is strictly within allocated arena bounds, that the slot generation counter strictly equals the handle generation counter, and that the slot type tag strictly matches the handle type discriminator.
  2. Dangling Reference Elimination: Any handle referencing a slot whose generation counter has been incremented, or whose slot has been recycled or deallocated, shall immediately evaluate to an invalid stale reference ($`\bot`$). Dereferencing stale, out-of-bounds, or type-mismatched handles shall return a structured error result rather than triggering segmentation faults, invalid memory accesses, or system panics.
  3. Total-Function Non-Panicking Execution: In accordance with Architectural Directive 5 and REQ-0011, the node handle dereferencing engine shall strictly enforce a deterministic, non-panicking execution contract. If a dereference operation encounters a stale handle, out-of-bounds index, or type tag mismatch, the compiler shall halt invalid operations, emit structured diagnostic error code `E0200` per REQ-0191, and propagate the error through structured diagnostic channels.
  4. Platform-Agnostic Determinism and Bitwise Reproducibility: Node handle assignment shall be a deterministic function of topological ingestion order and lexical declaration sequences. Handles shall remain invariant under platform word size, operating system, and address space layout randomization (ASLR), ensuring bitwise reproducible compilation artifacts (REQ-0003) and deterministic Merkle tree hashing (REQ-0010, REQ-0133).
  5. Cross-Process and Storage Serializability: Because handles are pure 64-bit integer values without virtual memory dependencies, AST graphs and slices shall be serializable to CBOR and JSON interchange formats (REQ-0044, REQ-0050) without pointer rebasing, translation tables, or deserialization pointer swizzling.
  6. Thread Isolation and Work-Stealing Traversal: In accordance with Architectural Directive 2 and REQ-0012, node handles shall implement scalar copy-by-value semantics, permitting safe cross-thread distribution across the bounded work-stealing thread pool without reference count synchronization, atomic locking, or data races during immutable graph traversals (REQ-0045).
  7. Reserved Sentinel Representation: The handle space shall reserve explicit sentinel bit patterns, where handle value $`0\text{x}FFFF\_FFFF\_0000\_0000`$ represents the canonical typed null handle (`NodeHandle::NULL`), denoting absent optional links and unbound terminal nodes.
  8. Memory Allocation Invariant: In accordance with Architectural Directive 3 and REQ-0036, string literals and identifier names referenced by AST nodes shall be addressed via interned scalar `SymbolId` tokens within the global deduplicated symbol interner pool, which constitutes the sole permitted exception to zero-copy memory management. All node allocations shall reside in contiguous arena storage per REQ-0009 and REQ-0034.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `Action_X`, `param_x : Real`), strictly prohibiting hardcoded domain concepts and mock data.

- **Formal Invariant**: Let $`\mathbb{U}_k = \{ x \in \mathbb{N} \mid 0 \le x \lt 2^k \}`$ denote the set of unsigned integers representable in $`k`$ bits. A typed node handle $`H \in \mathbb{U}_{64}`$ is formally defined as a 3-tuple:

$$
H = \langle \text{Index}, \text{Generation}, \text{TypeTag} \rangle \in \mathbb{U}_{32} \times \mathbb{U}_{16} \times \mathbb{U}_{16}
$$

The bit-packing projection $`\pi_{\text{pack}} : \mathbb{U}_{32} \times \mathbb{U}_{16} \times \mathbb{U}_{16} \longrightarrow \mathbb{U}_{64}`$ and its corresponding projection decoders are defined as:

$$
\begin{aligned}
\pi_{\text{pack}}(\text{Index}, \text{Generation}, \text{TypeTag}) &= (\text{Index} \ll 32) \;\lor\; (\text{Generation} \ll 16) \;\lor\; \text{TypeTag} \\
\text{Index}(H) &= (H \gg 32) \;\mathbin{\&}\; (2^{32} - 1) \\
\text{Generation}(H) &= (H \gg 16) \;\mathbin{\&}\; (2^{16} - 1) \\
\text{TypeTag}(H) &= H \;\mathbin{\&}\; (2^{16} - 1)
\end{aligned}
$$

Handle Compactness Invariant: The storage footprint of handle $`H`$ is strictly bounded:

$$
\text{sizeof}(H) \le S_{\text{handle}} = 8 \text{ bytes (64 bits)}
$$

Let arena $`\mathcal{A}`$ represent a contiguous node arena segment comprising capacity $`C_{\text{arena}} \in \mathbb{N}`$ slots, denoted $`\mathcal{A}.\text{slots}[0 \dots C_{\text{arena}} - 1]`$. Each slot $`i`$ is structured as:

$$
\mathcal{A}.\text{slots}[i] = \langle \text{node}, \text{gen}, \text{tag}, \text{allocated} \rangle
$$

where $`\text{gen} \in \mathbb{U}_{16}`$, $`\text{tag} \in \mathbb{U}_{16}`$, and $`\text{allocated} \in \{ \text{true}, \text{false} \}`$.

The validity predicate $`\text{Valid}(H, \mathcal{A})`$ governing handle dereferencing is defined as:

$$
\begin{aligned}
\text{Valid}(H, \mathcal{A}) \iff &\; \text{Index}(H) \lt C_{\text{arena}} \;\wedge \\
&\; \mathcal{A}.\text{slots}[\text{Index}(H)].\text{allocated} = \text{true} \;\wedge \\
&\; \mathcal{A}.\text{slots}[\text{Index}(H)].\text{gen} = \text{Generation}(H) \;\wedge \\
&\; \mathcal{A}.\text{slots}[\text{Index}(H)].\text{tag} = \text{TypeTag}(H)
\end{aligned}
$$

Generational Reference Safety Invariant: The dereferencing function $`\text{Deref} : \mathbb{U}_{64} \times \text{Arena} \longrightarrow \mathcal{N} \cup \{ \bot \}`$ evaluates:

$$
\text{Deref}(H, \mathcal{A}) = \begin{cases}
\& \mathcal{A}.\text{slots}[\text{Index}(H)].\text{node}, & \text{if } \text{Valid}(H, \mathcal{A}) = \text{true} \\
\bot, & \text{otherwise (stale, out-of-bounds, or type-mismatched reference)}
\end{cases}
$$

Monotonic Generation Increment Invariant: When an arena slot $`i`$ is recycled or reallocated at time step $`t + 1`$ following eviction of an AST node at time step $`t`$:

$$
\mathcal{A}.\text{slots}[i].\text{gen}_{t+1} = (\mathcal{A}.\text{slots}[i].\text{gen}_t + 1) \pmod{2^{16}}
$$

For any handle $`H_t`$ created at time step $`t`$ referencing slot $`i`$ with $`\text{Generation}(H_t) = \mathcal{A}.\text{slots}[i].\text{gen}_t`$, the generational update guarantees immediate invalidation:

$$
\text{Generation}(H_t) \ne \mathcal{A}.\text{slots}[i].\text{gen}_{t+1} \implies \text{Deref}(H_t, \mathcal{A}_{t+1}) = \bot
$$

Zero Dangling Pointers Invariant: Across all arena allocations and compiler transformation phases:

$$
\text{RawPointers}(\text{NodeArena}) = 0 \quad \wedge \quad \text{DanglingPointers}(\text{NodeArena}) = 0
$$

Reserved Canonical Sentinel Invariant: The null handle $`H_{\text{null}}`$ satisfies:

$$
H_{\text{null}} = \pi_{\text{pack}}(2^{32} - 1, 0, 0) \implies \text{Valid}(H_{\text{null}}, \mathcal{A}) = \text{false} \quad \wedge \quad \text{Deref}(H_{\text{null}}, \mathcal{A}) = \bot
$$

- **Computational Complexity & Algorithmic Bounds**: Node handle operations execute strictly within Complexity Class $`\mathbf{P}`$:
  - Handle Packing and Construction: $`O(1)`$ worst-case constant time, requiring exactly two bitwise shifts and two bitwise OR operations.
  - Bitfield Projection Decoding: $`O(1)`$ worst-case constant time, executing via a single shift and bitwise masking operation for each component.
  - Handle Dereferencing: $`O(1)`$ worst-case constant time, executing exactly one direct array indexing operation, one numerical bounds check, and two scalar integer equality comparisons ($`\text{gen}`$ and $`\text{tag}`$ verification).
  - Generational Invalidation: $`O(1)`$ worst-case constant time, performing a single scalar integer increment upon slot reclamation or node replacement.
  - Graph Traversal Complexity: For an AST graph comprising $`V`$ nodes and $`E`$ handle-addressed edges, sequential and parallel topological traversals execute in deterministic $`O(V + E)`$ linear time, with zero pointer chasing and optimal spatial cache locality across contiguous arena slots.
  - Space Footprint: $`O(1)`$ constant memory overhead per handle ($`8`$ bytes), eliminating per-node heap allocator headers and achieving linear $`O(V)`$ total metamodel storage.

- **Verification & Conformance Criteria**: Conformance shall be verified deterministically through the following automated test suites:
  1. Generational Invalidation Suite: The test harness shall allocate node `Classifier_Alpha` into slot index $`k`$, yielding handle $`H_1 = \langle k, g, \text{Tag}_{\text{Classifier}} \rangle`$. The harness shall mutate or recycle slot $`k`$ by allocating node `Classifier_Beta`, asserting that the slot generation advances to $`g + 1`$. The harness shall verify that calling $`\text{Deref}(H_1, \mathcal{A})`$ deterministically returns $`\bot`$ and produces diagnostic error code `E0200`, whereas dereferencing new handle $`H_2 = \langle k, g + 1, \text{Tag}_{\text{Classifier}} \rangle`$ succeeds in $`O(1)`$ time.
  2. Type Tag Discriminator Suite: The harness shall create a handle with type tag $`\text{Tag}_{\text{Port}}`$ referencing a slot occupied by `Package_0` with type tag $`\text{Tag}_{\text{Package}}`$. The harness shall assert that dereferencing the handle fails validation, returns $`\bot`$, and raises diagnostic error code `E0200` without system panic.
  3. Bounds Check and Sentinel Verification: The harness shall attempt dereferencing $`H_{\text{null}}`$ and out-of-bounds handle $`H_{\text{oob}} = \langle C_{\text{arena}} + 100, 0, 0 \rangle`$. The harness shall assert that both operations evaluate to $`\bot`$ and emit diagnostic error code `E0200`.
  4. Cross-Platform Serialization Parity: The test suite shall serialize an AST graph consisting of synthetic entities `Package_0`, `Classifier_Alpha`, and `Port_1` into CBOR and JSON streams, deserialize them in independent clean processes across Linux, macOS, and Windows environments, and assert 100% bitwise parity of all handle values and resolved graph topologies.
  5. Performance and Memory Gate: In accordance with Directive 5, REQ-0011, and REQ-0196, benchmarks shall execute exclusively in compiled Release mode (`--release`) under isolated benchmark harnesses. The benchmark harness shall assert a dereferencing throughput exceeding $`10^8`$ operations per second (latency $`\lt 10\text{ ns}`$ per dereference) and total resident set size (RSS) memory consumption strictly below 100 MB for an AST graph with $`10^6`$ nodes.
