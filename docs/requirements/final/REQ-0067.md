### REQ-0067: KerML Occurrences: OccurrenceDefinition & OccurrenceUsage Semantics

- **Normative Statement**: The Core Metamodel, Node Arena & AST Graph Engine and KerML metamodel lowering engine shall formalize all spatio-temporal dynamic entities, physical phenomena, and lifecycles as instances of `OccurrenceDefinition` and `OccurrenceUsage` elements. In the KerML taxonomic foundation, `OccurrenceDefinition` shall specialize `Class` (which transitively specializes `Classifier`, `Type`, and `Namespace`), representing an identity-bearing class of four-dimensional spatio-temporal individuals that exist across physical space and time. `OccurrenceUsage` shall specialize both `Feature` and `Occurrence`, representing an occurrence feature or usage evaluated within the context of an enclosing occurrence or classifier.

  The compiler shall bind every `OccurrenceUsage` to one or more declared `OccurrenceDefinition` classifiers via formal `FeatureTyping` relationships ($`\tau`$). Attempting to type an `OccurrenceUsage` with a non-occurrence classifier definition (such as an identity-free `DataType` or pure structural primitive) shall be strictly prohibited at compile time, deterministically emitting diagnostic error code `E0200` in accordance with the standardized diagnostic taxonomy of REQ-0191.

  The spatio-temporal engine shall map each occurrence individual $`o`$ to a four-dimensional world-line manifold $`\mathcal{W}(o) \subseteq \mathbb{R}^3 \times \mathbb{R}`$, wherein the projection of $`\mathcal{W}(o)`$ onto the temporal coordinate axis yields a bounded temporal interval $`\text{temporal\_extent}(o) = [t_{\text{start}}(o), t_{\text{end}}(o)] \subset \mathbb{R}`$, subject to the strict temporal ordering constraint $`t_{\text{start}}(o) \le t_{\text{end}}(o)`$. Any occurrence declaration specifying an inverted static temporal interval where $`t_{\text{start}} \gt t_{\text{end}}`$ shall be rejected deterministically at compile time with diagnostic error code `E0200`. Occurrences with degenerate zero-duration intervals ($`t_{\text{start}} = t_{\text{end}}`$, $`\text{dur} = 0`$) shall be admitted as valid instantaneous snapshot or event occurrences.

  Every `OccurrenceUsage` shall specify an explicit or defaulted multiplicity interval $`\mu(u) = [m_{\min}, m_{\max}]`$ governing instance realization cardinality within the evaluation fiber. The lowering engine shall enforce interval well-formedness $`0 \le m_{\min} \le m_{\max}`$. Multiplicity intervals violating well-formedness ($`m_{\min} \gt m_{\max}`$) shall be rejected at compile time with diagnostic error code `E0200`.

  The compiler shall formalize composite occurrence structures via the sub-occurrence relation ($`o_{\text{sub}} \subseteq_{\text{occ}} o_{\text{super}}`$). The lowering engine shall enforce the Spatio-Temporal World-Line Containment Axiom: the four-dimensional manifold of any sub-occurrence must be contained within the manifold of its enclosing occurrence ($`\mathcal{W}(o_{\text{sub}}) \subseteq \mathcal{W}(o_{\text{super}})`$), which implies strict temporal interval containment $`[t_{\text{start}}(o_{\text{sub}}), t_{\text{end}}(o_{\text{sub}})] \subseteq [t_{\text{start}}(o_{\text{super}}), t_{\text{end}}(o_{\text{super}})]`$. Sub-occurrences whose declared static temporal intervals exceed the temporal extent of their enclosing parent occurrence shall be rejected with diagnostic error code `E0200`.

  The sub-occurrence containment graph must be strictly acyclic. Static cyclic containment chains ($`o_1 \subseteq_{\text{occ}} o_2 \subseteq_{\text{occ}} \dots \subseteq_{\text{occ}} o_1`$) shall be detected via topological cycle detection algorithms and rejected with diagnostic error code `E0203`.

  Subsetting (`:>`) and redefinition (`:>>`) of occurrence usages shall conform to REQ-0061 and REQ-0062: subsetting usages must specialize or preserve the occurrence type ($`\tau(u_{\text{sub}}) \le \tau(u_{\text{sup}})`$), narrow multiplicity bounds ($`\mu(u_{\text{sub}}).m_{\max} \le \mu(u_{\text{sup}}).m_{\max}`$), and preserve temporal containment. Any violation of these constraints shall emit diagnostic error code `E0200`.

  All occurrence definitions and usages shall be stored in contiguous bump arena storage in accordance with REQ-0009 and REQ-0034, addressed via stable 32-bit arena node handles per REQ-0035. Every lowered occurrence AST node must receive a deterministic RFC 4122 UUIDv5 identifier computed by namespace-hashing the node fully qualified topological path with the canonical compiler namespace OID in accordance with Architectural Directive 1 and REQ-0010. Scalar symbol identifiers for occurrence names, namespace segments, and type references shall be interned into the global symbol interner pool per REQ-0036 as the sole permitted exception to zero-copy memory management in accordance with Architectural Directive 3.

  In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, the lowering engine shall implement synchronization token error recovery on declaration and delimiter boundaries (e.g., `;`, `}`, `end`). Upon detecting an invalid occurrence declaration, invalid temporal interval (`E0200`), non-occurrence type binding (`E0200`), or cyclic containment (`E0203`), the engine shall record structured diagnostics into the diagnostic sink, bind an error sentinel $`\bot_{\text{occ}}`$ or $`\bot_{\text{type}}`$, and continue verifying subsequent declarations. If accumulated diagnostics reach the sink capacity limit $`C_{\text{max\_errors}}`$, the compiler shall emit terminal diagnostic `E0199` and halt gracefully.

  Parallel lowering and occurrence validation across independent packages shall be scheduled on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with Architectural Directive 2 and REQ-0012. In accordance with Architectural Directive 5, REQ-0011, and REQ-0196, the occurrence lowering engine shall enforce a deterministic, non-panicking execution contract with total-function termination across all inputs; performance latency ($`\lt 25\text{ ms}`$ for $`10^4`$ occurrence declarations) and peak memory RSS ($`\lt 100\text{ MB}`$ RSS) performance gates shall be verified exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests. All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `OccurrenceDef_Alpha`, `OccurrenceDef_Beta`, `OccurrenceUsage_1`, `OccurrenceUsage_2`, `Port_1`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts and mock data.

- **Formal Invariant**: Let $`\mathcal{V}_{\text{AST}}`$ denote the universe of allocated AST nodes. The metamodel partitions occurrence elements into occurrence definitions $`\mathcal{O}_{\text{def}} \subset \mathcal{V}_{\text{AST}}`$ and occurrence usages $`\mathcal{O}_{\text{use}} \subset \mathcal{V}_{\text{AST}}`$:

$$
\mathcal{O}_{\text{all}} = \mathcal{O}_{\text{def}} \cup \mathcal{O}_{\text{use}}, \quad \mathcal{O}_{\text{def}} \cap \mathcal{O}_{\text{use}} = \emptyset
$$

Each occurrence definition $`D \in \mathcal{O}_{\text{def}}`$ is formalized as a 7-tuple:

$$
D = \langle \text{id}_D, \text{name}_D, \mathcal{S}_D, \mathcal{F}_D, \mathcal{T}_D, \Delta_D, \text{span}_D \rangle
$$

where:

$$
\begin{aligned}
\text{id}_D &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
\text{name}_D &\in \mathcal{S}_{\text{intern}} \quad (\text{interned symbol identifier}) \\
\mathcal{S}_D &\subseteq \mathcal{O}_{\text{def}} \quad (\text{direct supertypes / generalizations}) \\
\mathcal{F}_D &\subseteq \mathcal{V}_{\text{feat}} \quad (\text{owned features, including sub-occurrences } \mathcal{O}_{\text{use}} \cap \mathcal{F}_D) \\
\mathcal{T}_D &= [t_{\text{start}}(D), t_{\text{end}}(D)] \subset \mathbb{R} \cup \{ -\infty, +\infty \} \quad (\text{declared static temporal extent}) \\
\Delta_D &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_D &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
\end{aligned}
$$

Each occurrence usage $`U \in \mathcal{O}_{\text{use}}`$ is formalized as an 8-tuple:

$$
U = \langle \text{id}_U, \text{name}_U, \text{owner}_U, \tau(U), \mu(U), \mathcal{T}_U, \Delta_U, \text{span}_U \rangle
$$

where:

$$
\begin{aligned}
\text{id}_U &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
\text{name}_U &\in \mathcal{S}_{\text{intern}} \quad (\text{interned symbol identifier}) \\
\text{owner}_U &\in \mathcal{O}_{\text{def}} \cup \mathcal{O}_{\text{use}} \quad (\text{featuring occurrence context}) \\
\tau(U) &\subseteq \mathcal{O}_{\text{def}} \setminus \{ \emptyset \} \quad (\text{occurrence definition types bound via FeatureTyping}) \\
\mu(U) &= [m_{\min}(U), m_{\max}(U)] \subseteq \mathbb{N}_0 \times (\mathbb{N}_0 \cup \{ \infty \}) \quad (\text{multiplicity interval}) \\
\mathcal{T}_U &= [t_{\text{start}}(U), t_{\text{end}}(U)] \subset \mathbb{R} \cup \{ -\infty, +\infty \} \quad (\text{declared static temporal extent}) \\
\Delta_U &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_U &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
\end{aligned}
$$

Let $`\llbracket \mathcal{O} \rrbracket`$ denote the semantic universe of occurrence individuals. Each occurrence individual $`o \in \llbracket \mathcal{O} \rrbracket`$ is mapped to a four-dimensional spatio-temporal world-line manifold $`\mathcal{W}(o)`$:

$$
\mathcal{W}(o) \subseteq \mathbb{R}^3 \times \mathbb{R}
$$

The temporal projection function $`\pi_{\text{time}} : \mathcal{P}(\mathbb{R}^3 \times \mathbb{R}) \to \mathcal{P}(\mathbb{R})`$ determines the temporal extent:

$$
\pi_{\text{time}}(\mathcal{W}(o)) = \{ t \in \mathbb{R} \mid \exists \mathbf{x} \in \mathbb{R}^3 : (\mathbf{x}, t) \in \mathcal{W}(o) \} = [t_{\text{start}}(o), t_{\text{end}}(o)] \subset \mathbb{R}
$$

Temporal Interval Well-Formedness Invariant: Every temporal interval must satisfy monotonic non-decreasing boundary ordering:

$$
\forall o \in \mathcal{O}_{\text{all}}, \quad t_{\text{start}}(o) \le t_{\text{end}}(o)
$$

Temporal Duration Invariant: The temporal duration $`\text{dur}(o)`$ is non-negative, with equality holding for instantaneous event snapshots:

$$
\text{dur}(o) = t_{\text{end}}(o) - t_{\text{start}}(o) \ge 0, \quad (\text{dur}(o) = 0 \iff t_{\text{start}}(o) = t_{\text{end}}(o))
$$

Sub-Occurrence Spatio-Temporal Containment Invariant: Let $`\mathcal{R}_{\text{sub\_occ}} \subset \mathcal{O}_{\text{all}} \times \mathcal{O}_{\text{all}}`$ denote the direct sub-occurrence containment relation, where $`(o_1, o_2) \in \mathcal{R}_{\text{sub\_occ}} \iff o_1 \subseteq_{\text{occ}} o_2`$. Four-dimensional manifold containment implies temporal interval containment:

$$
\forall (o_1, o_2) \in \mathcal{R}_{\text{sub\_occ}}, \quad \mathcal{W}(o_1) \subseteq \mathcal{W}(o_2) \implies [t_{\text{start}}(o_1), t_{\text{end}}(o_1)] \subseteq [t_{\text{start}}(o_2), t_{\text{end}}(o_2)]
$$

which decomposes into the scalar bounding inequalities:

$$
\forall (o_1, o_2) \in \mathcal{R}_{\text{sub\_occ}}, \quad t_{\text{start}}(o_2) \le t_{\text{start}}(o_1) \le t_{\text{end}}(o_1) \le t_{\text{end}}(o_2)
$$

Sub-Occurrence Acyclicity Invariant: The transitive closure $`\mathcal{R}_{\text{sub\_occ}}^+`$ of the containment relation must be irreflexive:

$$
\forall o \in \mathcal{O}_{\text{all}}, \quad (o, o) \notin \mathcal{R}_{\text{sub\_occ}}^+
$$

Occurrence Usage Typing Invariant: Every occurrence usage must be typed strictly by valid occurrence definitions:

$$
\forall U \in \mathcal{O}_{\text{use}}, \quad \forall T \in \tau(U), \quad T \in \mathcal{O}_{\text{def}} \wedge T \ne \bot_{\text{type}}
$$

Multiplicity Interval Well-Formedness Invariant: The multiplicity interval of every occurrence usage must form a valid non-empty range:

$$
\forall U \in \mathcal{O}_{\text{use}}, \quad 0 \le m_{\min}(U) \le m_{\max}(U) \wedge (m_{\max}(U) \ge 1 \vee m_{\max}(U) = 0)
$$

Deterministic RFC 4122 UUIDv5 Anchor Invariant (Architectural Directive 1): Every occurrence definition and occurrence usage AST node binds a deterministic UUIDv5 identifier:

$$
\begin{aligned}
\forall D \in \mathcal{O}_{\text{def}}, \quad \Delta_D &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(D)) \\
\forall U \in \mathcal{O}_{\text{use}}, \quad \Delta_U &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(U))
\end{aligned}
$$

Diagnostic Code Trigger Invariants: Violations of occurrence classifier typing, temporal interval ordering, temporal containment, acyclicity, or multiplicity bounds deterministically trigger diagnostic error codes per REQ-0191:

$$
\begin{aligned}
\exists U \in \mathcal{O}_{\text{use}}, \exists T \in \tau(U) : T \notin \mathcal{O}_{\text{def}} &\implies \text{Diagnostic}(U, \text{DiagnosticCode::E0200}, \text{InvalidOccurrenceClassifierType}) \in \mathcal{D}_{\text{sink}} \\
\exists o \in \mathcal{O}_{\text{all}} : t_{\text{start}}(o) \gt t_{\text{end}}(o) &\implies \text{Diagnostic}(o, \text{DiagnosticCode::E0200}, \text{InvalidTemporalIntervalBounds}) \in \mathcal{D}_{\text{sink}} \\
\exists (o_1, o_2) \in \mathcal{R}_{\text{sub\_occ}} : (t_{\text{start}}(o_1) \lt t_{\text{start}}(o_2) \vee t_{\text{end}}(o_1) \gt t_{\text{end}}(o_2)) &\implies \text{Diagnostic}(o_1, \text{DiagnosticCode::E0200}, \text{OccurrenceTemporalContainmentViolation}) \in \mathcal{D}_{\text{sink}} \\
\exists o \in \mathcal{O}_{\text{all}} : (o, o) \in \mathcal{R}_{\text{sub\_occ}}^+ &\implies \text{Diagnostic}(o, \text{DiagnosticCode::E0203}, \text{CircularOccurrenceContainment}) \in \mathcal{D}_{\text{sink}} \\
\exists U \in \mathcal{O}_{\text{use}} : m_{\min}(U) \gt m_{\max}(U) &\implies \text{Diagnostic}(U, \text{DiagnosticCode::E0200}, \text{InvalidOccurrenceMultiplicityBounds}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

Diagnostic Taxonomy Containment Invariant: Emitted diagnostics strictly belong to the Metamodel and Typing family and Ingestion error limit family:

$$
\forall d \in \mathcal{D}_{\text{occurrence}}, \quad \text{code}(d) \in \{ \text{DiagnosticCode::E0200}, \text{DiagnosticCode::E0203}, \text{DiagnosticCode::E0199} \} \subset \mathcal{E}_{\text{type}} \cup \mathcal{E}_{\text{ingest}}
$$

- **Computational Complexity & Algorithmic Bounds**: Lowering and static semantic verification of `OccurrenceDefinition` and `OccurrenceUsage` elements execute strictly within Complexity Class $`\mathbf{P}`$.

  **Relation to Algorithmic Bound NP-1**: While general temporal consistency across unconstrained networks of qualitative Allen interval relations is NP-complete (governed by NP-1 in REQ-0117 via ORD-Horn and SMT solvers), static occurrence lowering and hierarchical containment checking in REQ-0067 operates strictly over concrete scalar interval bounds and structural containment trees/DAGs. Under this restriction, occurrence verification reduces to direct interval arithmetic and topological traversal, executing in deterministic polynomial time without backtracking.

  **Asymptotic Verification Complexity**: For a model containing $`V = |\mathcal{O}_{\text{all}}|`$ occurrence nodes and $`E = |\mathcal{R}_{\text{sub\_occ}}|`$ containment edges:
  1. *Occurrence Allocation & Interning*: Allocating $`V`$ occurrence nodes in contiguous arena storage and interning symbol strings requires amortized $`O(1)`$ time per node, totaling $`O(V)`$ time.
  2. *Temporal Interval Bounds Validation*: Verifying $`t_{\text{start}}(o) \le t_{\text{end}}(o)`$ executes in strictly $`O(1)`$ scalar comparisons per node, totaling $`O(V)`$ time across the model.
  3. *Temporal Interval Containment Verification*: For each containment edge $`(o_1, o_2) \in \mathcal{R}_{\text{sub\_occ}}`$, evaluating $`t_{\text{start}}(o_2) \le t_{\text{start}}(o_1)`$ and $`t_{\text{end}}(o_1) \le t_{\text{end}}(o_2)`$ requires strictly $`O(1)`$ scalar comparisons, totaling $`O(E)`$ time.
  4. *Acyclicity Verification (Tarjan's SCC / DFS)*: Detecting circular sub-occurrence containment cycles over the directed containment graph $`(\mathcal{O}_{\text{all}}, \mathcal{R}_{\text{sub\_occ}})`$ executes in deterministic $`O(V + E)`$ time and $`O(V)`$ auxiliary stack space.
  5. *Occurrence Classifier Type Conformance*: Checking $`\tau(U) \subseteq \mathcal{O}_{\text{def}}`$ requires testing classifier discriminant tags in deterministic $`O(1)`$ time per usage, totaling $`O(V)`$ time.
  6. *Multiplicity Validation*: Validating $`0 \le m_{\min}(U) \le m_{\max}(U)`$ executes in $`O(1)`$ integer comparisons per usage, totaling $`O(V)`$ time.

  Total sequential verification time across all occurrence elements is strictly linear in the size of the occurrence graph:

$$
T_{\text{validate}}(V, E) \in O(V + E)
$$

  **Parallel Work-Stealing Scaling (Architectural Directive 2)**: When occurrence lowering and containment verification across independent package scopes is scheduled on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$:

$$
T_{\text{parallel}}(V, E, N_{\text{max\_workers}}) \in O\left( \frac{V + E}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  **Space Complexity & Memory Bounds**: Auxiliary working memory is strictly bounded by $`O(V + E)`$ for contiguous arena storage and adjacency representations. Traversal recursion depth is bounded by hierarchy depth $`h \le 32`$ ($`O(1)`$ stack memory). The diagnostic error sink is bounded by $`O(C_{\text{max\_errors}}) = O(1)`$ allocated records.
