### REQ-0105: Switched & Piecewise Conservative Flow Networks & Linear Complementarity Solvers (NP-6)

- **Normative Statement**: The physical metrology and abstract flow conservation engine of Subsystem 5 shall partition conservative flow conservation networks into continuous linear subgraphs solved via sparse LU factorization in $`O(V^3)`$` and hybrid switched piecewise junctions formulated as a Linear Complementarity Problem (LCP) / Mixed Complementarity Problem (MCP) solved via Lemke's complementary pivot algorithm with a finite iteration cutoff `$`\kappa_{\text{pivot}}`$.

  Specifically, the metrology analysis engine, topological partitioner, and complementarity solver shall strictly enforce the following structural, algebraic, and algorithmic invariants:
  1. **Network Topological Partitioning**:
     - The flow solver shall decompose the global abstract conservative flow network multigraph $`\mathcal{G}_{\text{flow}} = (\mathcal{V}_{\text{junc}}, \mathcal{E}_{\text{flow}})`$` into two disjoint edge sets: continuous linear branches `$`\mathcal{E}_{\text{lin}}`$` and hybrid switched piecewise branches `$`\mathcal{E}_{\text{switch}}`$`, such that `$`\mathcal{E}_{\text{flow}} = \mathcal{E}_{\text{lin}} \cup \mathcal{E}_{\text{switch}}`$` and `$`\mathcal{E}_{\text{lin}} \cap \mathcal{E}_{\text{switch}} = \emptyset`$.
     - Junction nodes $`\mathcal{V}_{\text{junc}}`$` shall be partitioned into continuous junction nodes `$`\mathcal{V}_{\text{lin}}`$` incident exclusively to linear branches and boundary/switched junction nodes `$`\mathcal{V}_{\text{switch}}`$ incident to at least one switched branch.
     - Disconnected network subgraphs shall be identified and solved independently as decoupled subsystems.
  2. **Continuous Linear Subgraph Formulation & Sparse LU Factorization**:
     - For the continuous linear subsystem, the compiler shall construct the generalized nodal conductance matrix $`\mathbf{K} \in \mathbb{R}^{n \times n}`$` from branch generalized conductances `$`\mathbf{G} = \operatorname{diag}(g_1, \dots, g_{|\mathcal{E}_{\text{lin}}|})`$` and the continuous incidence submatrix `$`\mathbf{A}_{\text{lin}} \in \{-1, 0, +1\}^{n \times |\mathcal{E}_{\text{lin}}|}`$`, satisfying `$`\mathbf{K} = \mathbf{A}_{\text{lin}} \mathbf{G} \mathbf{A}_{\text{lin}}^T`$.
     - The solver shall designate a reference ground junction node $`J_{\text{ref}}`$` with fixed potential `$`e_{\text{ref}} = 0`$` to eliminate rigid-body potential indeterminacy, producing the reduced non-singular conductance matrix `$`\mathbf{K}_{\text{red}} \in \mathbb{R}^{(n-1) \times (n-1)}`$.
     - If $`\text{rank}(\mathbf{K}_{\text{red}}) \lt n - 1`$, indicating a singular conductance matrix, floating network component, or ill-conditioned topological subnetwork, the compiler shall deterministically reject the model at compile time with diagnostic error code `E0301` (`SingularConductanceMatrix`).
     - Continuous linear nodal potential vectors $`\mathbf{e}`$` shall be computed by solving `$`\mathbf{K}_{\text{red}} \mathbf{e} = \mathbf{f}_{\text{ext}}`$` via sparse LU factorization with Markowitz threshold pivoting in `$`O(V^3)`$` worst-case dense time (`$`O(V^{1.5})`$ for planar sparse topologies).
  3. **Hybrid Switched Piecewise Junction Formulation as LCP / MCP**:
     - Each switched branch $`k \in \{1, \dots, m\}`$` in `$`\mathcal{E}_{\text{switch}}`$` (where `$`m = |\mathcal{E}_{\text{switch}}|`$) shall model piecewise linear or ideal switching behaviors (including ideal switches, unidirectional flow valves, threshold limiters, and diodes) governed by two complementary non-negative variables:
       * Primal switch activation / through flow variable $`z_k \ge 0`$.
       * Complementary across potential drop / slack variable $`w_k \ge 0`$.
     - The solver shall eliminate the internal linear node potentials $`\mathbf{e}`$` via Schur complement reduction, condensing the aggregate hybrid network into a canonical Linear Complementarity Problem `$`\operatorname{LCP}(\mathbf{M}, \mathbf{q})`$:

```math
\mathbf{w} - \mathbf{M} \mathbf{z} = \mathbf{q}, \quad \mathbf{w} \ge \mathbf{0}, \quad \mathbf{z} \ge \mathbf{0}, \quad \mathbf{w}^T \mathbf{z} = 0
```

       where $`\mathbf{M} = \mathbf{A}_{\text{switch}}^T \mathbf{K}_{\text{red}}^{-1} \mathbf{A}_{\text{switch}} \in \mathbb{R}^{m \times m}`$` is the complementarity interaction matrix and `$`\mathbf{q} = \mathbf{A}_{\text{switch}}^T \mathbf{K}_{\text{red}}^{-1} \mathbf{f}_{\text{ext}} + \mathbf{q}_0 \in \mathbb{R}^m`$ is the affine offset vector.
     - The complementarity condition $`\mathbf{w}^T \mathbf{z} = 0`$` enforces pairwise orthogonality: `$`\forall k \in \{1, \dots, m\}, w_k \cdot z_k = 0`$`, guaranteeing that each switched junction operates strictly in either an active conducting state (`$`w_k = 0, z_k \ge 0`$`) or an inactive blocking state (`$`z_k = 0, w_k \ge 0`$).
  4. **Lemke Complementary Pivot Solver & Tractable Bound NP-6**:
     - In accordance with Algorithmic Bound NP-6, solving general Linear Complementarity Problems is NP-complete. To guarantee polynomial compile-time tractability and eliminate exponential state enumeration ($`2^m`$` possible switch combinations), the compiler shall solve `$`\operatorname{LCP}(\mathbf{M}, \mathbf{q})`$` using Lemke's complementary pivot algorithm augmented with an artificial covering variable `$`z_0 \ge 0`$` and covering vector `$`\mathbf{d}_{\text{aux}} = \mathbf{1} = [1, \dots, 1]^T`$:

```math
\mathbf{w} - \mathbf{M} \mathbf{z} - \mathbf{d}_{\text{aux}} z_0 = \mathbf{q}, \quad \mathbf{w} \ge \mathbf{0}, \quad \mathbf{z} \ge \mathbf{0}, \quad z_0 \ge 0, \quad \mathbf{w}^T \mathbf{z} = 0
```

     - The Lemke pivot loop shall execute a sequence of complementary basis exchange pivots maintaining non-negativity and complementarity.
     - The engine shall enforce a strict, user-configurable iteration cutoff bound $`N_{\text{pivot}} \le \kappa_{\text{pivot}}`$` (defaulting to `$`\kappa_{\text{pivot}} = 4m^2`$).
     - If the artificial variable $`z_0`$` leaves the basis (`$`z_0 = 0`$`), the algorithm terminates successfully, returning the unique or valid complementary basic feasible solution `$`(\mathbf{w}^*, \mathbf{z}^*)`$` in bounded polynomial time `$`O(\kappa_{\text{pivot}} \cdot m^2)`$.
     - If the iteration count exceeds $`\kappa_{\text{pivot}}`$` without driving `$`z_0`$` to zero (`$`N_{\text{pivot}} \gt \kappa_{\text{pivot}}`$), compilation shall fail deterministically with diagnostic error code `E0399` (`LcpPivotLimitExceeded`).
     - If Lemke's algorithm encounters secondary ray termination (an unbounded ray with $`z_0 \gt 0`$), indicating an inconsistent or non-complementary switched network topology without a feasible operational mode, compilation shall fail deterministically with diagnostic error code `E0399` (`UnresolvableComplementarity`).
  5. **Physical Dimensional Homogeneity in $`\mathbb{Q}^7`$**:
     - Across and through variables coupled via continuous and switched branches must preserve exact dimensional homogeneity within the 7D rational metrology space $`\mathbb{Q}^7`$.
     - All across variables $`w_k`$` and potential differences `$`\Delta e_e`$` must share an identical across dimension vector `$`\mathbf{d}_{\text{across}} \in \mathbb{Q}^7`$.
     - All through variables $`z_k`$` and flow rates `$`f_e`$` must share an identical through dimension vector `$`\mathbf{d}_{\text{through}} \in \mathbb{Q}^7`$.
     - Any dimensional mismatch detected across switched junctions shall be deterministically rejected with diagnostic error code `E0300` (`DimensionalMismatch`).
  6. **Architectural Directives Compliance**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every continuous junction node, switched junction handle, conductance matrix entry, and complementarity constraint record shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the compiler namespace OID and canonical fully qualified path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))`$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel topological partitioning, independent continuous linear subgraph LU factorization, Schur complement reduction, and Lemke complementarity solving across independent network components or packages shall execute on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: Junction identifiers, branch names, switch state labels, and variable tokens shall be interned into the deduplicated global string interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The metrology engine shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When semantic violations occur (`E0300`, `E0301`, `E0399`), diagnostics shall accumulate in the error sink buffer $`\mathcal{D}_{\text{sink}}`$`, substitute typed error sentinels (`$`\bot_{\text{flow}}`$`, `$`\bot_{\text{lcp}}`$`), and continue parsing subsequent network declarations. If accumulated diagnostics reach `$`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully.
     - *Directive 5 (Panic-Free Release Isolation)*: The linear and complementarity solver pipeline shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Verification latency ($`\lt 25\text{ ms}`$`) and peak RSS memory (`$`\lt 100\text{ MB}`$` for `$`10^4`$ branches and junctions) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Junction_Alpha`, `Junction_Beta`, `SwitchedJunction_1`, `SwitchedJunction_2`, `FlowBranch_1`, `FlowBranch_2`, `Port_1`, `Port_2`, `Network_Alpha`, `param_x : Real`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $`\mathcal{V}_{\text{AST}}`$ denote the universe of allocated AST nodes in contiguous arena storage.

  Let $`\mathcal{G}_{\text{flow}} = (\mathcal{V}_{\text{junc}}, \mathcal{E}_{\text{flow}})`$` be an abstract flow conservation network multigraph. The edge set `$`\mathcal{E}_{\text{flow}}`$` is partitioned into continuous linear branches `$`\mathcal{E}_{\text{lin}}`$` and hybrid switched branches `$`\mathcal{E}_{\text{switch}}`$:

```math
  \mathcal{E}_{\text{flow}} = \mathcal{E}_{\text{lin}} \cup \mathcal{E}_{\text{switch}}, \quad \mathcal{E}_{\text{lin}} \cap \mathcal{E}_{\text{switch}} = \emptyset
```

  Each continuous junction node $`J \in \mathcal{V}_{\text{junc}}`$ is formalized as a 5-tuple:

```math
  J = \langle \text{id}_J, \text{name}_J, \text{Incident}(J), \Delta_J, \text{span}_J \rangle
```

  where:

```math
  \begin{aligned}
  \text{id}_J &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
  \text{name}_J &\in \mathcal{S}_{\text{intern}} \quad (\text{interned junction identifier}) \\
  \text{Incident}(J) &\subseteq \mathcal{E}_{\text{flow}} \quad (\text{incident continuous and switched branches}) \\
  \Delta_J &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
  \text{span}_J &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
  \end{aligned}
```

  Each continuous linear branch $`e \in \mathcal{E}_{\text{lin}}`$ is formalized as a 7-tuple:

```math
  e = \langle \text{id}_e, u_e, v_e, g_e, f_e, \Delta e_e, \Delta_e \rangle
```

  where $`u_e, v_e \in \mathcal{V}_{\text{junc}}`$`, `$`g_e \in \mathbb{R}^+`$` is the generalized branch conductance, `$`f_e`$` is the through flow, `$`\Delta e_e = e_{u_e} - e_{v_e}`$` is the across potential drop, and `$`f_e = g_e \cdot \Delta e_e`$.

  Each hybrid switched branch $`s \in \mathcal{E}_{\text{switch}}`$ is formalized as a 7-tuple:

```math
  s = \langle \text{id}_s, u_s, v_s, z_s, w_s, q_{0, s}, \Delta_s \rangle
```

  where $`u_s, v_s \in \mathcal{V}_{\text{junc}}`$`, `$`z_s \ge 0`$` is the primal switch flow variable, `$`w_s \ge 0`$` is the complementary across drop variable, and `$`q_{0, s} \in \mathbb{R}`$ is the switch threshold offset.

  Let $`n = |\mathcal{V}_{\text{junc}}|`$` and `$`m = |\mathcal{E}_{\text{switch}}|`$`. Let `$`\mathbf{A}_{\text{lin}} \in \{-1, 0, +1\}^{n \times |\mathcal{E}_{\text{lin}}|}`$` and `$`\mathbf{A}_{\text{switch}} \in \{-1, 0, +1\}^{n \times m}`$ denote the continuous and switched incidence submatrices respectively:

```math
  A_{\text{lin}, i, e} = \begin{cases} +1, & \text{if branch } e \text{ enters junction } J_i \\ -1, & \text{if branch } e \text{ leaves junction } J_i \\ 0, & \text{otherwise} \end{cases}
```

```math
  A_{\text{switch}, i, s} = \begin{cases} +1, & \text{if switched branch } s \text{ enters junction } J_i \\ -1, & \text{if switched branch } s \text{ leaves junction } J_i \\ 0, & \text{otherwise} \end{cases}
```

  Continuous Linear Subgraph Invariant: The generalized conductance matrix $`\mathbf{K} \in \mathbb{R}^{n \times n}`$` and reduced conductance matrix `$`\mathbf{K}_{\text{red}} \in \mathbb{R}^{(n-1) \times (n-1)}`$` with grounded reference potential `$`e_{\text{ref}} = 0`$ satisfy:

```math
  \mathbf{K} = \mathbf{A}_{\text{lin}} \mathbf{G} \mathbf{A}_{\text{lin}}^T, \quad \mathbf{K}_{\text{red}} \mathbf{e} = \mathbf{f}_{\text{ext}}
```

```math
  \text{rank}(\mathbf{K}_{\text{red}}) = n - 1 \iff \det(\mathbf{K}_{\text{red}}) \ne 0
```

```math
  \mathbf{P} \mathbf{K}_{\text{red}} \mathbf{Q} = \mathbf{L} \mathbf{U}
```

  where $`\mathbf{P}, \mathbf{Q}`$` are permutation matrices, `$`\mathbf{L}`$` is unit lower triangular, and `$`\mathbf{U}`$ is upper triangular.

  Hybrid Switched Complementarity Invariant (LCP / MCP): The coupled network satisfies the augmented system:

```math
  \begin{bmatrix}
  \mathbf{K}_{\text{red}} & -\mathbf{A}_{\text{switch}} \\
  \mathbf{A}_{\text{switch}}^T & \mathbf{0}
  \end{bmatrix}
  \begin{bmatrix}
  \mathbf{e} \\
  \mathbf{z}
  \end{bmatrix}
  =
  \begin{bmatrix}
  \mathbf{f}_{\text{ext}} \\
  -\mathbf{w} + \mathbf{q}_0
  \end{bmatrix}
```

  Schur complement reduction yields the standard Linear Complementarity Problem $`\operatorname{LCP}(\mathbf{M}, \mathbf{q})`$:

```math
  \begin{aligned}
  \mathbf{M} &= \mathbf{A}_{\text{switch}}^T \mathbf{K}_{\text{red}}^{-1} \mathbf{A}_{\text{switch}} \in \mathbb{R}^{m \times m} \\
  \mathbf{q} &= \mathbf{A}_{\text{switch}}^T \mathbf{K}_{\text{red}}^{-1} \mathbf{f}_{\text{ext}} + \mathbf{q}_0 \in \mathbb{R}^m
  \end{aligned}
```

  The state vectors $`\mathbf{w}, \mathbf{z} \in \mathbb{R}^m`$ satisfy the complementarity conditions:

```math
  \begin{aligned}
  \mathbf{w} - \mathbf{M} \mathbf{z} &= \mathbf{q} \\
  \mathbf{w} \ge \mathbf{0}, \quad \mathbf{z} &\ge \mathbf{0} \\
  \mathbf{w}^T \mathbf{z} = \sum_{k=1}^m w_k z_k &= 0 \iff \forall k \in \{1, \dots, m\}, \quad w_k \cdot z_k = 0
  \end{aligned}
```

  Lemke Complementary Pivot Formulation: Augmented tableau with artificial variable $`z_0 \in \mathbb{R}`$` and covering vector `$`\mathbf{d}_{\text{aux}} = [1, \dots, 1]^T`$:

```math
  \mathbf{w} - \mathbf{M} \mathbf{z} - \mathbf{d}_{\text{aux}} z_0 = \mathbf{q}, \quad \mathbf{w} \ge \mathbf{0}, \quad \mathbf{z} \ge \mathbf{0}, \quad z_0 \ge 0, \quad \mathbf{w}^T \mathbf{z} = 0
```

  Iteration cutoff bound:

```math
  N_{\text{pivot}} \le \kappa_{\text{pivot}}
```

  Complementary solution termination condition:

```math
  z_0 = 0 \implies (\mathbf{w}^*, \mathbf{z}^*) \text{ satisfies } \operatorname{LCP}(\mathbf{M}, \mathbf{q})
```

  Dimensional Homogeneity Invariants in $`\mathbb{Q}^7`$:

```math
  \begin{aligned}
  \forall e \in \mathcal{E}_{\text{lin}}, &\quad \mathbf{d}(f_e) \equiv \mathbf{d}_{\text{through}} \;\land\; \mathbf{d}(\Delta e_e) \equiv \mathbf{d}_{\text{across}} \\
  \forall s \in \mathcal{E}_{\text{switch}}, &\quad \mathbf{d}(z_s) \equiv \mathbf{d}_{\text{through}} \;\land\; \mathbf{d}(w_s) \equiv \mathbf{d}_{\text{across}} \\
  \mathbf{d}_{\text{through}} + \mathbf{d}_{\text{across}} &\equiv (1, 2, -3, 0, 0, 0, 0) \quad (\text{Abstract Power Invariant: } [M]^1 [L]^2 [T]^{-3})
  \end{aligned}
```

  Deterministic Diagnostic Emission Invariant (REQ-0191):

```math
  \begin{aligned}
  \text{rank}(\mathbf{K}_{\text{red}}) \lt n - 1 &\implies \text{Diagnostic}(\mathcal{G}_{\text{lin}}, \text{DiagnosticCode::E0301}, \text{SingularConductanceMatrix}) \in \mathcal{D}_{\text{sink}} \\
  \exists s \in \mathcal{E}_{\text{switch}} : (\mathbf{d}(w_s) \ne \mathbf{d}_{\text{across}} \lor \mathbf{d}(z_s) \ne \mathbf{d}_{\text{through}}) &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0300}, \text{DimensionalMismatch}) \in \mathcal{D}_{\text{sink}} \\
  N_{\text{pivot}} \gt \kappa_{\text{pivot}} &\implies \text{Diagnostic}(\mathcal{G}_{\text{switch}}, \text{DiagnosticCode::E0399}, \text{LcpPivotLimitExceeded}) \in \mathcal{D}_{\text{sink}} \\
  \text{RayTermination}(z_0 \gt 0) &\implies \text{Diagnostic}(\mathcal{G}_{\text{switch}}, \text{DiagnosticCode::E0399}, \text{UnresolvableComplementarity}) \in \mathcal{D}_{\text{sink}} \\
  |\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
  \end{aligned}
```

  Deterministic RFC 4122 UUIDv5 Anchor Invariant (Directive 1):

```math
  \begin{aligned}
  \forall J \in \mathcal{V}_{\text{junc}}, &\quad \Delta_J = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(J)) \\
  \forall e \in \mathcal{E}_{\text{flow}}, &\quad \Delta_e = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(e))
  \end{aligned}
```

- **Computational Complexity & Algorithmic Bounds**: Hybrid switched piecewise conservative flow network solving resides in Complexity Class **NP-complete** for the general complementarity formulation (NP-6), with continuous subgraphs solved in Complexity Class $`\mathbf{P}`$.

  For an abstract MBSE network containing $`V = |\mathcal{V}_{\text{junc}}|`$` junction nodes, `$`E_{\text{lin}} = |\mathcal{E}_{\text{lin}}|`$` continuous linear branches, and `$`m = |\mathcal{E}_{\text{switch}}|`$ hybrid switched branches:
  1. *Graph Partitioning & Subsystem Isolation*:
     Partitioning the network multigraph into continuous and switched subgraphs via breadth-first search (BFS) executes in deterministic linear time:

```math
T_{\text{partition}}(V, E_{\text{lin}}, m) \in O(V + E_{\text{lin}} + m)
```

  2. *Generalized Conductance Matrix Assembly*:
     Constructing the sparse continuous conductance matrix $`\mathbf{K} = \mathbf{A}_{\text{lin}} \mathbf{G} \mathbf{A}_{\text{lin}}^T`$` inspects each continuous linear branch once, executing in `$`O(V + E_{\text{lin}})`$ time and space.
  3. *Sparse LU Factorization (Continuous Subsystem)*:
     Computing the sparse LU decomposition $`\mathbf{P} \mathbf{K}_{\text{red}} \mathbf{Q} = \mathbf{L} \mathbf{U}`$` with Markowitz threshold pivoting executes in `$`O(V^3)`$ worst-case dense time:

```math
T_{\text{sparse\_LU}}(V) \in O(V^3)
```

     For planar and sparse physical connection topologies with bounded junction degree ($`d_{\max} \ll V`$`), sparse factorization complexity simplifies to `$`O(V^{1.5})`$.
  4. *Schur Complement Reduction*:
     Forming the complementarity interaction matrix $`\mathbf{M} = \mathbf{A}_{\text{switch}}^T \mathbf{K}_{\text{red}}^{-1} \mathbf{A}_{\text{switch}}`$` requires solving `$`m`$` linear triangular systems using pre-factored `$`\mathbf{L} \mathbf{U}`$` matrices, followed by matrix multiplication with `$`\mathbf{A}_{\text{switch}}^T`$. This executes in:

```math
T_{\text{Schur}}(V, m) \in O(m \cdot V^2 + m^2 \cdot V)
```

  5. *Lemke Complementary Pivot Solver (NP-6 Tractable Bound)*:
     In unconstrained formulations, solving general Linear Complementarity Problems is NP-complete, requiring $`O(2^m)`$ combinatorial state evaluations in the worst case.
     Under the Lemke complementary pivot algorithm with finite iteration cutoff $`\kappa_{\text{pivot}}`$`, each pivot exchange updates the `$`m \times (2m + 2)`$` tableau via Gauss-Jordan elimination in `$`O(m^2)`$ scalar arithmetic operations.
     The total execution time of the complementarity solver is strictly bounded by:

```math
T_{\text{Lemke}}(m, \kappa_{\text{pivot}}) \in O(\kappa_{\text{pivot}} \cdot m^2)
```

     Enforcing $`\kappa_{\text{pivot}} \le 4m^2`$` guarantees that the worst-case pivot complexity is strictly bounded by `$`O(m^4)`$ polynomial operations.
  6. *Aggregate Algorithmic Complexity*:
     Combining continuous LU factorization, Schur reduction, and bounded Lemke pivoting:

```math
  T_{\text{total}}(V, E_{\text{lin}}, m, \kappa_{\text{pivot}}) \in O(V^3 + m \cdot V^2 + \kappa_{\text{pivot}} \cdot m^2)
```

     For typical engineering models where switched elements are sparse relative to continuous junctions ($`m \ll V`$`), total compilation latency is dominated by sparse continuous factorization `$`O(V^3)`$` (or `$`O(V^{1.5})`$ for planar sparse graphs).
  7. *Parallel Work-Stealing Scaling (Directive 2)*:
     When evaluating $`M`$` independent network components or packages across `$`N_{\text{max\_workers}}`$ threads on a bounded work-stealing thread pool:

```math
  T_{\text{parallel}}(V, E_{\text{lin}}, m, \kappa_{\text{pivot}}, N_{\text{max\_workers}}) \in O\left( \frac{V^3 + m \cdot V^2 + \kappa_{\text{pivot}} \cdot m^2}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

  8. *Space Complexity & Memory Bounds*:
     Contiguous arena allocations for junction nodes, linear branches, sparse matrices, and complementarity tableaus are strictly bounded by $`O(V^2 + m^2)`$` bytes in the dense worst case, and `$`O(V + E_{\text{lin}} + m^2)`$` for sparse linear networks. Deduplicated string interner memory is bounded by `$`O(V + E_{\text{flow}})`$` unique symbol identifiers. Diagnostic sink memory is bounded by `$`O(C_{\text{max\_errors}}) = O(1)`$.
