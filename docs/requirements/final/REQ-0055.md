### REQ-0055: KerML Namespace, Membership, OwningMembership & Qualified Naming

- **Normative Statement**: The Core Metamodel, OMG SysML v2 / KerML Metamodel Lowering & Grammar subsystem shall model lexical scopes, naming environments, and containment hierarchies as formal `Namespace` scopes composed of typed `Membership` relationships. Memberships shall partition into owning memberships (`OwningMembership`) governing lifecycle containment and non-owning reference memberships (`Membership`), enforcing lexical uniqueness within local scopes and deterministic hierarchical qualified name resolution across the abstract syntax tree (AST) graph.

  1. Namespace Scope Representation: A `Namespace` shall provide a formal naming context for its member elements. Namespaces shall be organized hierarchically, where an enclosing namespace may contain nested child namespaces, classifiers, or structural features. A designated root namespace (`Package_Root`) shall serve as the top-level scope anchor with null parent ($\text{parent} = \bot$). Every namespace shall maintain an internal symbol table mapping interned member name tokens to bound semantic elements.

  2. Membership & OwningMembership Partitioning: A `Membership` relationship shall bind an enclosing `Namespace` to a member `Element`. The metamodel shall partition all memberships into two mutually exclusive sets:
     - `OwningMembership`: An owning membership shall establish authoritative composite ownership and lifecycle containment over its target member element. The compiler shall enforce the single-ownership invariant: every owned element in the semantic model shall be the member element of exactly one `OwningMembership` ($\forall e \in \mathcal{E}_{\text{owned}}, |\{ m \in \mathcal{M}_{\text{own}} \mid e_m = e \}| = 1$). No element shall possess multiple owning memberships, multiple owning namespaces, or conflicting parent containment links. The deletion, relocation, or lifecycle termination of an owning namespace shall cascade deterministically to all elements owned through its owning memberships.
     - Non-Owning Reference `Membership`: A non-owning membership shall establish a visible reference binding between a namespace and an element owned elsewhere (including elements imported via package imports, namespace aliases, or feature re-exports). An element may participate as the target of arbitrarily many non-owning reference memberships across distinct namespaces without altering its singular owning membership or lifecycle parent.

  3. Lexical Uniqueness & Collision Invariant: Within any given `Namespace`, all named memberships must satisfy lexical uniqueness. For all memberships $m_1, m_2$ within namespace $N$, if both memberships declare identical, non-null interned member names ($\sigma_{m_1} = \sigma_{m_2} \ne \bot$), both memberships must resolve to the identical semantic element ($e_{m_1} = e_{m_2}$). If two memberships within the same namespace declare identical member names that bind to distinct semantic elements ($e_{m_1} \ne e_{m_2}$), the compiler shall reject the declaration as an illegal duplicate membership collision, emitting structured diagnostic error code `E0200` per REQ-0191.

  4. Ownership Graph Strict Acyclicity: The ownership relation induced by owning memberships forms a directed ownership graph $\mathcal{O} \subset \mathcal{N} \times \mathcal{E}$. The compiler shall mandate that the transitive closure $\mathcal{O}^+$ is strictly irreflexive ($\forall e \in \mathcal{E}, (e, e) \notin \mathcal{O}^+$). No namespace or element shall directly or indirectly contain itself as an owned child. Any detected circular ownership cycle shall be rejected at compile time with structured diagnostic error code `E0203` per REQ-0191.

  5. Deterministic Qualified Naming Recurrence: Every named element in the model hierarchy shall possess a deterministic qualified name (`QualifiedName`), defined inductively as the sequence of interned symbol names of its enclosing ancestor namespaces concatenated with its own member name:
     - For a root-level element or top-level namespace with no owner ($\text{owner}(e) = \bot$), its qualified name sequence shall consist solely of its own interned name: $[\text{name}(e)]$.
     - For any element owned by an enclosing namespace ($\text{owner}(e) \ne \bot$), its qualified name sequence shall be the sequence concatenation of the qualified name sequence of its owner and its own interned name: $\text{QN}(\text{owner}(e)) \mathbin{\Vert} [\text{name}(e)]$.
     - The canonical string representation of a qualified name shall serialize each segment separated by the standard double-colon delimiter (`::`), e.g., `Package_0::Classifier_Alpha::Port_1`.
     - Elements without a declared name (anonymous elements) shall not possess a qualified name; references to anonymous elements must be resolved via structural or containment navigation rather than qualified path lookup.

  6. Qualified Path Resolution: The compiler shall support resolution of both absolute and relative qualified paths:
     - Absolute Qualified Paths: Paths prefixed with leading double-colons (`::Package_0::Classifier_Alpha`) shall initiate resolution strictly at the root namespace.
     - Relative Qualified Paths: Paths without leading double-colons (`Classifier_Alpha::Port_1`) shall resolve their leading segment within the active local scope via standard lexical lookup, and each subsequent segment via direct member lookup in the preceding namespace.
     - If any segment of a qualified path cannot be resolved within the targeted namespace, the compiler shall emit structured diagnostic error code `E0200` per REQ-0191.

  7. Architectural Directives Integration:
     - Directive 1 (Deterministic UUIDv5 Anchors): Every `Namespace`, `Membership`, and owned `Element` entity shall receive an immutable, deterministic RFC 4122 UUIDv5 identifier generated by hashing the fixed compiler namespace OID with its canonical fully qualified path string ($\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(e))$) per REQ-0010. Time-based UUIDs (such as UUIDv7) are strictly prohibited.
     - Directive 2 (Bounded Work-Stealing Parallelism): Parallel namespace indexing, membership table construction, and qualified name generation across independent compilation units shall be scheduled on a bounded work-stealing thread pool with worker bound $N_{\text{max\_workers}}$ in accordance with REQ-0012.
     - Directive 3 (String Interner Memory Allocation Exception): Scalar member names, namespace identifiers, and path segment tokens shall be interned into the global symbol interner pool as scalar `SymbolId` tokens during the initial lexical pass, representing the sole permitted exception to zero-copy memory management in accordance with REQ-0036.
     - Directive 4 (Synchronization Token Error Recovery): The namespace lowering engine shall implement synchronization token error recovery. Upon detecting duplicate membership names (`E0200`), multiple ownership violations (`E0200`), circular ownership cycles (`E0203`), or unresolved qualified path segments (`E0200`), the engine shall record the diagnostic with source byte spans and line/column coordinates, bind an error sentinel node handle $\bot_{\text{node}}$, and continue processing subsequent AST declarations in accordance with REQ-0013 and REQ-0016. If accumulated errors reach $C_{\text{max\_errors}}$, the compiler shall emit terminal diagnostic `E0199` and halt gracefully.
     - Directive 5 (Panic-Free Release Isolation): The compiler library shall strictly enforce a deterministic, non-panicking execution contract with total-function behavior across all inputs. Performance gates (execution latency strictly under 25 ms, peak memory RSS strictly under 100 MB for $10^5$ memberships/lookups) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196.
     - Pure MBSE Formalism: All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Package_1`, `Package_Root`, `Classifier_Alpha`, `Classifier_Beta`, `Port_1`, `Port_2`, `Flow_A`, `param_x : Real`, `Element_0`, `Element_1`), strictly prohibiting hardcoded domain concepts and mock data.

- **Formal Invariant**: Let $\mathcal{E}$ denote the universe of semantic elements, $\mathcal{N} \subseteq \mathcal{E}$ denote the subset of namespace elements, and $\mathcal{S}_{\text{intern}}$ denote the universe of interned scalar symbol tokens. Let $\mathcal{M}$ denote the universe of membership relationships.

A namespace $N \in \mathcal{N}$ defines a finite partial map from interned symbol handles to member elements:

$$
\mu_N : \mathcal{S}_{\text{intern}} \rightharpoonup \mathcal{E}
$$

Each namespace entity $N \in \mathcal{N}$ is formalized as a 7-tuple:

$$
N = \langle \text{id}_N, \sigma_N, \mathcal{M}_N, \mathcal{M}^{\text{own}}_N, \text{parent}_N, \Delta_N, \text{span}_N \rangle
$$

where:

$$
\begin{aligned}
\text{id}_N &\in \mathbb{N}_{32} \quad (\text{contiguous arena namespace handle}) \\
\sigma_N &\in \mathcal{S}_{\text{intern}} \cup \{ \bot \} \quad (\text{interned namespace identifier token}) \\
\mathcal{M}_N &\subseteq \mathcal{M} \quad (\text{finite set of hosted namespace memberships}) \\
\mathcal{M}^{\text{own}}_N &\subseteq \mathcal{M}_N \cap \mathcal{M}_{\text{own}} \quad (\text{subset of hosted owning memberships}) \\
\text{parent}_N &\in \mathcal{N} \cup \{ \bot \} \quad (\text{enclosing lexical parent namespace}) \\
\Delta_N &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_N &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical coordinate span})
\end{aligned}
$$

Each membership entity $m \in \mathcal{M}$ is formalized as an 8-tuple:

$$
m = \langle \text{id}_m, N_m, e_m, \sigma_m, v_m, \beta_{\text{own}}, \Delta_m, \text{span}_m \rangle
$$

where:

$$
\begin{aligned}
\text{id}_m &\in \mathbb{N}_{32} \quad (\text{contiguous arena membership handle}) \\
N_m &\in \mathcal{N} \quad (\text{enclosing namespace hosting the membership}) \\
e_m &\in \mathcal{E} \quad (\text{bound member semantic element}) \\
\sigma_m &\in \mathcal{S}_{\text{intern}} \cup \{ \bot \} \quad (\text{optional interned member name}) \\
v_m &\in \{ \text{Public}, \text{Private}, \text{Protected} \} \quad (\text{membership visibility kind}) \\
\beta_{\text{own}} &\in \mathbb{B} \quad (\text{lifecycle ownership boolean flag}) \\
\Delta_m &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_m &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical coordinate span})
\end{aligned}
$$

The universe of memberships $\mathcal{M}$ partitions into owning memberships $\mathcal{M}_{\text{own}}$ and non-owning reference memberships $\mathcal{M}_{\text{ref}}$:

$$
\mathcal{M} = \mathcal{M}_{\text{own}} \cup \mathcal{M}_{\text{ref}}, \quad \mathcal{M}_{\text{own}} \cap \mathcal{M}_{\text{ref}} = \emptyset
$$

where:

$$
\begin{aligned}
\mathcal{M}_{\text{own}} &= \{ m \in \mathcal{M} \mid \beta_{\text{own}}(m) = \text{true} \} \\
\mathcal{M}_{\text{ref}} &= \{ m \in \mathcal{M} \mid \beta_{\text{own}}(m) = \text{false} \}
\end{aligned}
$$

Local Member Resolution Function: For any namespace $N \in \mathcal{N}$ and interned symbol $\sigma \in \mathcal{S}_{\text{intern}}$, local lookup evaluates to:

$$
\mu_N(\sigma) = \begin{cases}
e_m, & \text{if } \exists m \in \mathcal{M}_N : \sigma_m = \sigma \\
\bot, & \text{otherwise}
\end{cases}
$$

Owning Membership Single-Ownership Bijection Invariant: Let $\mathcal{E}_{\text{owned}} \subseteq \mathcal{E}$ denote the set of elements owned by any namespace:

$$
\forall e \in \mathcal{E}_{\text{owned}}, \quad |\{ m \in \mathcal{M}_{\text{own}} \mid e_m = e \}| = 1
$$

The unique owner projection function $\text{owner} : \mathcal{E} \to \mathcal{N} \cup \{ \bot \}$ is given by:

$$
\text{owner}(e) = \begin{cases}
N_m, & \text{if } \exists ! m \in \mathcal{M}_{\text{own}} : e_m = e \\
\bot, & \text{otherwise}
\end{cases}
$$

Ownership Graph Strict Acyclicity Invariant: The direct ownership relation $\mathcal{O} \subset \mathcal{N} \times \mathcal{E}$ is defined by:

$$
\mathcal{O} = \{ (N_m, e_m) \mid m \in \mathcal{M}_{\text{own}} \} \subset \mathcal{N} \times \mathcal{E}
$$

Its irreflexive transitive closure $\mathcal{O}^+$ forbids self-containment:

$$
\forall e \in \mathcal{E}, \quad (e, e) \notin \mathcal{O}^+
$$

Lexical Uniqueness Invariant: Within any namespace $N \in \mathcal{N}$, memberships with identical non-null names must bind to the identical semantic element:

$$
\forall N \in \mathcal{N}, \; \forall m_1, m_2 \in \mathcal{M}_N, \quad (\sigma_{m_1} = \sigma_{m_2} \ne \bot) \implies e_{m_1} = e_{m_2}
$$

Deterministic Qualified Name Recurrence: Let $\text{Sequence}\langle \mathcal{S}_{\text{intern}} \rangle$ denote the set of finite sequences of interned symbol identifiers. The qualified name function $\text{QN} : \mathcal{E} \to \text{Sequence}\langle \mathcal{S}_{\text{intern}} \rangle \cup \{ \bot \}$ satisfies:

$$
\begin{aligned}
\text{QN}(e) &= \begin{cases}
\bot, & \text{if } \text{name}(e) = \bot \\
[\text{name}(e)], & \text{if } \text{name}(e) \ne \bot \;\wedge\; \text{owner}(e) = \bot \\
\text{QN}(\text{owner}(e)) \mathbin{\Vert} [\text{name}(e)], & \text{if } \text{name}(e) \ne \bot \;\wedge\; \text{owner}(e) \ne \bot
\end{cases}
\end{aligned}
$$

Canonical Serialized Qualified Path String: For an element $e$ with $\text{QN}(e) = \langle \sigma_1, \sigma_2, \dots, \sigma_k \rangle$, the canonical path string $\text{FQN}(e) \in \Sigma^*$ is:

$$
\text{FQN}(e) = \text{StringOf}(\sigma_1) \mathbin{\Vert} \text{"::"} \mathbin{\Vert} \text{StringOf}(\sigma_2) \mathbin{\Vert} \dots \mathbin{\Vert} \text{"::"} \mathbin{\Vert} \text{StringOf}(\sigma_k)
$$

Deterministic RFC 4122 UUIDv5 Topological Anchor Invariant: Every semantic element and membership entity possesses a deterministic UUIDv5 identifier:

$$
\begin{aligned}
\Delta_e &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(e)) \\
\Delta_m &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(N_m) \mathbin{\Vert} \text{"::membership::"} \mathbin{\Vert} \text{StringOf}(\sigma_m))
\end{aligned}
$$

Diagnostic Code Trigger Invariants: Failures during namespace, membership, or qualified name processing deterministically record structured diagnostics into the compiler diagnostic sink per REQ-0191:

$$
\begin{aligned}
\exists m_1, m_2 \in \mathcal{M}_N : (\sigma_{m_1} = \sigma_{m_2} \ne \bot) \wedge e_{m_1} \ne e_{m_2} &\implies \text{Diagnostic}(m_2, \text{DiagnosticCode::E0200}, \text{DuplicateMembershipNameCollision}) \in \mathcal{D}_{\text{sink}} \\
\exists e \in \mathcal{E} : |\{ m \in \mathcal{M}_{\text{own}} \mid e_m = e \}| \gt 1 &\implies \text{Diagnostic}(e, \text{DiagnosticCode::E0200}, \text{MultipleOwningMembershipViolation}) \in \mathcal{D}_{\text{sink}} \\
\exists e \in \mathcal{E} : (e, e) \in \mathcal{O}^+ &\implies \text{Diagnostic}(e, \text{DiagnosticCode::E0203}, \text{CircularNamespaceOwnershipCycle}) \in \mathcal{D}_{\text{sink}} \\
\text{ResolveQualifiedPath}(\pi, N) = \bot &\implies \text{Diagnostic}(\pi, \text{DiagnosticCode::E0200}, \text{UnresolvedQualifiedPathSegment}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

Diagnostic Taxonomy Containment Invariant: All diagnostics emitted by the namespace lowering engine belong strictly to the Subsystem 4 metamodel lowering and Subsystem 3 typing taxonomy:

$$
\forall D \in \mathcal{D}_{\text{namespace}}, \quad \text{code}(D) \in \{ \text{DiagnosticCode::E0200}, \text{DiagnosticCode::E0203}, \text{DiagnosticCode::E0199} \} \subset \mathcal{E}_{\text{type}}
$$

- **Computational Complexity & Algorithmic Bounds**: The namespace indexing, membership containment validation, lexical uniqueness enforcement, and qualified name resolution algorithms execute strictly within Complexity Class $\mathbf{P}$. Algorithmic bounds across operations are established as follows:

  1. Symbol Interning & Membership Construction: Interning a scalar symbol token of byte length $L$ into the global symbol interner pool executes in $O(L)$ deterministic time, returning a 32-bit scalar `SymbolId`. Inserting each membership $m$ into the open-addressing member hash table of namespace $N_m$ executes in amortized $O(1)$ time. For a model with $M = |\mathcal{M}|$ memberships across $|\mathcal{N}|$ namespaces, total membership construction executes in $O(M \cdot \bar{L})$ time, where $\bar{L} \le 64$ is the average identifier length.

  2. Local Member Symbol Lookup: Resolving a member element $\mu_N(\sigma)$ within a local namespace via its interned `SymbolId` requires a single hash table query, executing in amortized constant time $O(1)$ with zero string comparisons:

$$
T_{\text{lookup}}(\sigma) \in O(1)
$$

  3. Ownership Acyclicity Verification: Validating that the ownership graph $\mathcal{O} = (\mathcal{E}, \mathcal{M}_{\text{own}})$ contains no directed cycles is executed via depth-first cycle detection or Tarjan's strongly connected components algorithm. Because the single-ownership invariant bounds the in-degree of every owned element to at most 1 ($|\text{in-degree}(e)| \le 1$), the ownership graph is a forest of directed trees. Cycle detection visits each element node and owning membership edge at most once, executing in deterministic linear time:

$$
T_{\text{acyclic}}(|\mathcal{E}|, |\mathcal{M}_{\text{own}}|) \in O(|\mathcal{E}| + |\mathcal{M}_{\text{own}}|) \subseteq O(|\mathcal{E}|)
$$

  4. Qualified Name Construction: Computing the qualified name sequence $\text{QN}(e)$ ascends the ownership chain from element $e$ to the root namespace. For a hierarchy with maximum nesting depth bounded by $D_{\max} \le 16$, the recurrence traverses at most $D_{\max}$ ancestor hops, taking strictly bounded constant time:

$$
T_{\text{QN}}(e) \le D_{\max} \cdot O(1) = 16 \cdot O(1) \in O(1)
$$

  Serializing $\text{QN}(e)$ to canonical string $\text{FQN}(e)$ copies $d \le D_{\max}$ interned string segments, requiring $O(d \cdot \bar{L}) \subseteq O(1)$ time.

  5. Qualified Path Resolution: Resolving a qualified path $\pi = \langle p_1, p_2, \dots, p_k \rangle$ of length $k \le K_{\max} \le 16$ begins with resolving the leading segment $p_1$ in $O(1)$ time, followed by $k - 1$ sequential member lookups in the respective child namespaces. Each child lookup takes amortized $O(1)$ time. Thus, total qualified path resolution executes in strictly bounded constant time:

$$
T_{\text{resolve}}(\pi) \le K_{\max} \cdot O(1) = 16 \cdot O(1) \in O(1)
$$

  6. Overall Model Namespace Processing: For an entire AST model comprising $V = |\mathcal{E}|$ elements, $M = |\mathcal{M}|$ memberships, and $N_{\text{ref}}$ qualified path references, total sequential compilation time across all namespace passes is strictly linear:

$$
T_{\text{total}}(V, M, N_{\text{ref}}) \in O(V + M + N_{\text{ref}})
$$

  7. Parallel Work-Stealing Scheduling: When namespace indexing and qualified name computation across independent package compilation units are scheduled on $N_{\text{max\_workers}}$ threads in the bounded work-stealing pool:

$$
T_{\text{parallel}}(|\mathcal{E}|, |\mathcal{M}|) \in O\left( \frac{|\mathcal{E}| + |\mathcal{M}|}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  8. Space Complexity & Memory Bounds: Auxiliary working memory for namespace indexing is bounded by $O(|\mathcal{E}| + |\mathcal{M}|)$ contiguous arena storage. Call stack depth during recursive qualified name generation is strictly bounded by $O(D_{\max}) \le 16$ stack frames ($O(1)$ auxiliary stack space). The diagnostic sink is bounded by $O(C_{\text{max\_errors}}) = O(1)$ preallocated records.
