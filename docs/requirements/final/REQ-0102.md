### REQ-0102: Multiplicative Dimensional Exponent Addition & Subtraction ($`A \cdot B, A / B`$)

#### 1. Normative Statement

The metrology engine, semantic type checker, and AST lowering pipeline of Subsystem 5 shall compute, propagate, and validate the physical quantity dimension vectors of all multiplicative expressions ($`A \cdot B`$`), division expressions (`$`A / B`$`), and unary reciprocal expressions (`$`1 / B`$` or `$`B^{-1}`$`) by exact vector addition, vector subtraction, and vector negation in the seven-dimensional rational vector space `$`\mathbb{Q}^7`$ over the International System of Quantities (ISQ) base dimensions. The metrology engine shall simultaneously compute and propagate exact rational unit conversion scale factors, manage unit composition and dimensional cancellation, and enforce metrological consistency constraints across all expression AST nodes.

  Specifically, the metrology engine, type checker, and lowering pipeline shall strictly enforce the following structural, algebraic, and semantic invariants:
  1. **Seven-Dimensional Rational Vector Space Representation ($`\mathbb{Q}^7`$)**:
     - The metrology engine shall represent every physical quantity dimension as a rational 7-vector $`\mathbf{d} = (d_M, d_L, d_T, d_I, d_\Theta, d_N, d_J) \in \mathbb{Q}^7`$` over the ordered basis of 7 ISQ base dimensions: Mass (`$`M`$`), Length (`$`L`$`), Time (`$`T`$`), Electric Current (`$`I`$`), Thermodynamic Temperature (`$`\Theta`$`), Amount of Substance (`$`N`$`), and Luminous Intensity (`$`J`$).
     - Each coordinate $`d_i = \frac{p_i}{q_i}`$` shall be stored and evaluated as an irreducible rational fraction (`$`p_i \in \mathbb{Z}, q_i \in \mathbb{Z}^+, \gcd(|p_i|, q_i) = 1`$) to support both integer exponents and fractional/rational dimensional exponents (e.g., from square root and fractional power operations per REQ-0104).
     - Dimensionless Identity: The zero vector $`\mathbf{0} = (0, 0, 0, 0, 0, 0, 0) \in \mathbb{Q}^7`$ shall represent the dimensionless identity quantity space, corresponding to pure scalar counts, numeric constants, ratios, and plane/solid angles.
  2. **Multiplication Operator Semantics ($`A \cdot B`$)**:
     - For any binary multiplication expression $`E = A \cdot B`$` with operand sub-expressions `$`A`$` and `$`B`$` having inferred dimension vectors `$`\mathbf{d}_A, \mathbf{d}_B \in \mathbb{Q}^7`$:
       * The resultant dimension vector $`\mathbf{d}_{A \cdot B}`$` shall be computed by vector addition in `$`\mathbb{Q}^7`$:

```math
\mathbf{d}_{A \cdot B} = \mathbf{d}_A + \mathbf{d}_B = (d_{A, 1} + d_{B, 1}, \dots, d_{A, 7} + d_{B, 7})
```

       * The resultant exact rational scale factor $`c_{A \cdot B} \in \mathbb{Q}^+`$ relative to the coherent base unit system shall be computed by rational multiplication:

```math
c_{A \cdot B} = c_A \cdot c_B
```

       * If either operand is dimensionless ($`\mathbf{d} = \mathbf{0}`$`), the resultant dimension equals the dimension of the other operand (`$`\mathbf{0} + \mathbf{d} = \mathbf{d}`$`), acting as the additive identity in `$`\mathbb{Q}^7`$.
  3. **Division & Reciprocal Operator Semantics ($`A / B`$`, `$`1 / B`$)**:
     - For any binary division expression $`E = A / B`$` with operand sub-expressions `$`A`$` and `$`B`$` having inferred dimension vectors `$`\mathbf{d}_A, \mathbf{d}_B \in \mathbb{Q}^7`$:
       * The resultant dimension vector $`\mathbf{d}_{A / B}`$` shall be computed by vector subtraction in `$`\mathbb{Q}^7`$:

```math
\mathbf{d}_{A / B} = \mathbf{d}_A - \mathbf{d}_B = (d_{A, 1} - d_{B, 1}, \dots, d_{A, 7} - d_{B, 7})
```

       * The resultant exact rational scale factor $`c_{A / B} \in \mathbb{Q}^+`$ relative to the coherent base unit system shall be computed by rational division:

```math
c_{A / B} = c_A / c_B
```

       * For unary inversion or reciprocal expressions $`E = 1 / B`$:

```math
\mathbf{d}_{1 / B} = -\mathbf{d}_B = (-d_{B, 1}, \dots, -d_{B, 7}), \quad c_{1 / B} = 1 / c_B
```

       * Exact Dimensional Cancellation: When operands possess identical dimension vectors ($`\mathbf{d}_A \equiv \mathbf{d}_B`$`), the division yields the dimensionless identity vector `$`\mathbf{d}_{A / B} = \mathbf{0}`$`. The resultant scale factor `$`c_{A / B} = c_A / c_B`$` establishes the exact dimensionless conversion ratio (e.g., dividing a length in kilometres by a length in metres yields dimensionless scalar factor `$`1000`$).
  4. **Metrological Validity & Affine Scale Protection**:
     - Ratio Scales vs Affine Scales: Physical units defined on affine scales with non-zero additive offsets $`o \ne 0`$` (such as degree Celsius with `$`o = 273.15`$, or degree Fahrenheit) cannot participate directly in multiplication or division without thermodynamic inconsistency.
     - The type checker shall inspect the unit scale classification of operands. If an operand in a multiplication or division expression is typed with an affine unit where $`o \ne 0`$, the compiler shall reject the expression at compile time with diagnostic error code `E0300` (`AffineUnitInMultiplicativeExpression`) unless the value has been explicitly converted to an absolute thermodynamic ratio-scale unit (such as Kelvin) or declared as an affine difference quantity.
  5. **Compile-Time Division-by-Zero Detection**:
     - If the divisor expression $`B`$` in `$`A / B`$` evaluates at compile time to a known constant zero scalar or zero quantity (`$`v_B = 0`$), the compiler shall emit diagnostic error code `E0300` (`CompileTimeDivisionByZero`) and attach an error sentinel node $`\bot_{\text{dim}}`$.
  6. **Exact Rational Arithmetic & Exponent Bound Enforcement**:
     - All vector additions and subtractions across the 7 rational coordinates shall be performed using exact rational arithmetic (least common multiple of denominators, followed by integer arithmetic and greatest common divisor reduction $`\gcd`$).
     - The use of IEEE 754 floating-point operations in dimensional coordinate calculations, unit scale factor calculations, and prefix scalings is strictly prohibited.
     - Coordinate Exponent Bounds: The numerator $`p_i`$` and denominator `$`q_i`$` of every rational exponent `$`d_i = \frac{p_i}{q_i}`$` shall be bounded by `$`[-2^{15}, 2^{15}-1]`$` and `$`[1, 2^{15}-1]`$ respectively. Any rational exponent calculation that overflows the integer bounds shall be detected and rejected at compile time with diagnostic error code `E0300` (`DimensionalExponentOverflow`).
  7. **Architectural Directives Compliance**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every multiplicative and division expression AST node, synthesized anonymous derived unit node, and compound quantity type node shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the compiler namespace OID and canonical fully qualified expression path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(e))`$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Dimensional inference and type checking of multiplicative expressions across independent compilation units, packages, or equations shall execute on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: Synthesized unit symbols (e.g., compound unit symbol strings such as `m*s^-1` or `kg*m*s^-2`), identifier tokens, and operator symbol strings shall be interned into the global deduplicated symbol interner pool per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The type checker and metrology engine shall implement synchronization token error recovery on statement delimiters (`;`) and expression block boundaries (`}`). When semantic violations occur (`E0300`, `E0301`), diagnostics shall accumulate in error sink buffer $`\mathcal{D}_{\text{sink}}`$`, substitute typed error sentinel `$`\bot_{\text{dim}}`$` (with `$`\mathbf{d}(\bot_{\text{dim}}) = \bot`$`), and continue checking subsequent expressions. If accumulated diagnostics reach `$`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully.
     - *Directive 5 (Panic-Free Release Isolation)*: The multiplicative dimensional inference engine shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Performance latency ($`\lt 25\text{ ms}`$`) and peak memory RSS (`$`\lt 100\text{ MB}`$` for `$`10^5`$ multiplicative expressions) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Quantity_Alpha`, `Quantity_Beta`, `Unit_Alpha`, `Unit_Beta`, `param_x : Real`, `param_y : Real`, `Expr_Alpha`, `Expr_Beta`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

#### 2. Formal Invariant

Let $`\mathcal{V}_{\text{AST}}`$ denote the universe of allocated AST nodes in contiguous bump arena storage.

  The physical quantity dimension space is formalized as a 7-dimensional vector space over the field of rational numbers $`\mathbb{Q}`$:

```math
\mathcal{D}_{\mathbb{Q}} = (\mathbb{Q}^7, +, -, \cdot, \mathbf{0})
```

  where any dimension vector $`\mathbf{d} \in \mathbb{Q}^7`$ is defined as a rational 7-tuple:

```math
\mathbf{d} = (d_M, d_L, d_T, d_I, d_\Theta, d_N, d_J) \in \mathbb{Q}^7
```

  corresponding to the formal ISQ base quantity power product:

```math
\mathbf{d} \iff [M]^{d_M} [L]^{d_L} [T]^{d_T} [I]^{d_I} [\Theta]^{d_\Theta} [N]^{d_N} [J]^{d_J}
```

  Each coordinate $`d_i`$` for `$`i \in \{ M, L, T, I, \Theta, N, J \}`$ is formalized as an irreducible rational fraction:

```math
d_i = \frac{p_i}{q_i}, \quad p_i \in \mathbb{Z}, \; q_i \in \mathbb{Z}^+, \; \gcd(|p_i|, q_i) = 1
```

  The canonical elementary basis $`\mathcal{B} = \{ \mathbf{e}_M, \mathbf{e}_L, \mathbf{e}_T, \mathbf{e}_I, \mathbf{e}_\Theta, \mathbf{e}_N, \mathbf{e}_J \}`$` spans `$`\mathbb{Q}^7`$:

```math
\begin{aligned}
\mathbf{e}_M &= (1, 0, 0, 0, 0, 0, 0) \quad (\text{Mass } [M]) \\
\mathbf{e}_L &= (0, 1, 0, 0, 0, 0, 0) \quad (\text{Length } [L]) \\
\mathbf{e}_T &= (0, 0, 1, 0, 0, 0, 0) \quad (\text{Time } [T]) \\
\mathbf{e}_I &= (0, 0, 0, 1, 0, 0, 0) \quad (\text{Electric Current } [I]) \\
\mathbf{e}_\Theta &= (0, 0, 0, 0, 1, 0, 0) \quad (\text{Thermodynamic Temperature } [\Theta]) \\
\mathbf{e}_N &= (0, 0, 0, 0, 0, 1, 0) \quad (\text{Amount of Substance } [N]) \\
\mathbf{e}_J &= (0, 0, 0, 0, 0, 0, 1) \quad (\text{Luminous Intensity } [J])
\end{aligned}
```

  The dimensionless identity vector $`\mathbf{0}`$ satisfies:

```math
\mathbf{0} = (0, 0, 0, 0, 0, 0, 0)
```

  For each quantity expression AST node $`e \in \mathcal{V}_{\text{AST}}`$`, let `$`\tau(e) = \langle \mathbf{d}(e), c(e), o(e) \rangle`$ represent its metrological signature, where:
  - $`\mathbf{d}(e) \in \mathbb{Q}^7`$ is the dimension vector,
  - $`c(e) \in \mathbb{Q}^+`$ is the exact rational conversion scale factor relative to coherent SI base units,
  - $`o(e) \in \mathbb{Q}`$` is the exact rational additive offset (`$`o(e) = 0`$ for ratio scale quantities).

  Binary Multiplication AST Invariant: For binary multiplication node $`E_{\text{mul}} = \langle \text{Mul}, A, B \rangle \in \mathcal{V}_{\text{AST}}`$:

```math
\begin{aligned}
\mathbf{d}(E_{\text{mul}}) &= \mathbf{d}(A) + \mathbf{d}(B) \\
&= \left( d_M(A) + d_M(B), \; d_L(A) + d_L(B), \; \dots, \; d_J(A) + d_J(B) \right) \\
c(E_{\text{mul}}) &= c(A) \cdot c(B) \\
o(E_{\text{mul}}) &= 0
\end{aligned}
```

  Binary Division AST Invariant: For binary division node $`E_{\text{div}} = \langle \text{Div}, A, B \rangle \in \mathcal{V}_{\text{AST}}`$:

```math
\begin{aligned}
\mathbf{d}(E_{\text{div}}) &= \mathbf{d}(A) - \mathbf{d}(B) \\
&= \left( d_M(A) - d_M(B), \; d_L(A) - d_L(B), \; \dots, \; d_J(A) - d_J(B) \right) \\
c(E_{\text{div}}) &= \frac{c(A)}{c(B)} \\
o(E_{\text{div}}) &= 0
\end{aligned}
```

  Unary Multiplicative Inversion AST Invariant: For unary reciprocal node $`E_{\text{inv}} = \langle \text{Inv}, B \rangle \in \mathcal{V}_{\text{AST}}`$:

```math
\begin{aligned}
\mathbf{d}(E_{\text{inv}}) &= -\mathbf{d}(B) = \left( -d_M(B), \; -d_L(B), \; \dots, \; -d_J(B) \right) \\
c(E_{\text{inv}}) &= \frac{1}{c(B)} \\
o(E_{\text{inv}}) &= 0
\end{aligned}
```

  Rational Coordinate Arithmetic & Irreducible Reduction: For each coordinate $`i \in \{1, \dots, 7\}`$` with operands `$`d_i(A) = \frac{p_{A, i}}{q_{A, i}}`$` and `$`d_i(B) = \frac{p_{B, i}}{q_{B, i}}`$:

```math
\begin{aligned}
d_i(A \cdot B) &= \frac{p_{A, i} \cdot q_{B, i} + p_{B, i} \cdot q_{A, i}}{q_{A, i} \cdot q_{B, i}} = \frac{p_{\text{sum}, i} / g_{\text{sum}, i}}{q_{\text{prod}, i} / g_{\text{sum}, i}} \\
\text{where } g_{\text{sum}, i} &= \gcd\left(|p_{A, i} \cdot q_{B, i} + p_{B, i} \cdot q_{A, i}|, \; q_{A, i} \cdot q_{B, i}\right) \\
d_i(A / B) &= \frac{p_{A, i} \cdot q_{B, i} - p_{B, i} \cdot q_{A, i}}{q_{A, i} \cdot q_{B, i}} = \frac{p_{\text{diff}, i} / g_{\text{diff}, i}}{q_{\text{prod}, i} / g_{\text{diff}, i}} \\
\text{where } g_{\text{diff}, i} &= \gcd\left(|p_{A, i} \cdot q_{B, i} - p_{B, i} \cdot q_{A, i}|, \; q_{A, i} \cdot q_{B, i}\right)
\end{aligned}
```

  Dimensional Cancellation to Dimensionless Identity Invariant:

```math
\mathbf{d}(A) = \mathbf{d}(B) \implies \mathbf{d}(A / B) = \mathbf{d}(A) - \mathbf{d}(B) = \mathbf{0}
```

  Multiplication and Division Identity Invariants:

```math
\begin{aligned}
\mathbf{d}(A) + \mathbf{0} &= \mathbf{d}(A) \\
\mathbf{d}(A) - \mathbf{0} &= \mathbf{d}(A) \\
\mathbf{0} - \mathbf{d}(A) &= -\mathbf{d}(A)
\end{aligned}
```

  Affine Unit Rejection Predicate:

```math
\Phi_{\text{ratio\_valid}}(e) \iff (o(e) = 0)
```

  Deterministic RFC 4122 UUIDv5 Anchor Invariant (Architectural Directive 1):

```math
\forall e \in \mathcal{V}_{\text{AST}}, \quad \Delta_e = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(e))
```

  Diagnostic Trigger Rules: Violations of metrological validity, affine scale restrictions, division by zero, or coordinate bounds deterministically emit structured diagnostics in accordance with REQ-0191:

```math
\begin{aligned}
(o(A) \ne 0 \vee o(B) \ne 0) \wedge (e = A \cdot B \vee e = A / B) &\implies \text{Diagnostic}(e, \text{DiagnosticCode::E0300}, \text{AffineUnitInMultiplicativeExpression}) \in \mathcal{D}_{\text{sink}} \\
\text{is\_const\_zero}(B) \wedge e = A / B &\implies \text{Diagnostic}(e, \text{DiagnosticCode::E0300}, \text{CompileTimeDivisionByZero}) \in \mathcal{D}_{\text{sink}} \\
\exists i \in \{1, \dots, 7\} : (|p_i| \gt 32767 \vee q_i \gt 32767) &\implies \text{Diagnostic}(e, \text{DiagnosticCode::E0300}, \text{DimensionalExponentOverflow}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
```

#### 3. Computational Complexity & Algorithmic Bounds

Multiplicative and division dimensional exponent calculation, scale factor derivation, and affine scale validation execute strictly within Complexity Class $`\mathbf{P}`$.

  The operational complexity bounds are formalized as follows:
  1. *Per-Node Vector Addition & Subtraction in $`\mathbb{Q}^7`$*:
     For each multiplicative or division AST node, evaluating $`\mathbf{d}_A \pm \mathbf{d}_B`$` performs exactly 7 rational coordinate arithmetic operations. Each coordinate operation requires 2 integer multiplications, 1 integer addition or subtraction, 1 denominator multiplication, and 1 Euclidean algorithm greatest common divisor (`$`\gcd`$`) reduction. For 32-bit bounded integers, the Euclidean `$`\gcd`$` algorithm terminates in at most `$`2 \log_2(32767) \le 30`$` iterations, executing in deterministic `$`O(1)`$ time and requiring zero dynamic memory allocation:

```math
T_{\text{coord\_eval}} \in O(1), \quad T_{\text{node}} = 7 \cdot T_{\text{coord\_eval}} \in O(1)
```

  2. *Scale Factor Computation*:
     Multiplying or dividing two irreducible rational scale factors $`c_A, c_B \in \mathbb{Q}^+`$` requires 2 integer multiplications and 1 Euclidean `$`\gcd`$` reduction, executing in deterministic `$`O(1)`$` time and `$`O(1)`$ auxiliary space.
  3. *Expression AST Bottom-Up Inference Traversal*:
     For an expression syntax tree $`e`$` comprising `$`|e|`$` AST nodes, dimensional inference traverses the tree in post-order. Because each node performs at most `$`O(1)`$` vector operations and `$`O(1)`$ scale factor operations, dimensional inference for the complete tree requires strictly linear time:

```math
T_{\text{tree}}(|e|) \in O(|e|)
```

  4. *Aggregate Project Compilation Complexity*:
     For a complete compilation unit or multi-package project containing $`M`$` expression trees with total multiplicative AST nodes `$`K = \sum_{j=1}^M |e_j|`$:

```math
T_{\text{total}}(K) \in O(K)
```

  5. *Parallel Work-Stealing Scaling (Architectural Directive 2)*:
     When dimensional inference across independent compilation units, packages, or equations is scheduled onto a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$:

```math
T_{\text{parallel}}(K, N_{\text{max\_workers}}) \in O\left( \frac{K}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

  6. *Space Complexity & Memory Bounds*:
     Contiguous arena storage allocates exactly 1 fixed-size AST descriptor node per expression, bounded by $`O(K)`$` bytes. Each rational 7-vector occupies `$`7 \times 8 = 56`$` bytes (two 32-bit integers per coordinate). The traversal call stack depth is bounded by the maximum expression nesting depth `$`d_{\max} \le 64 = O(1)`$` frames. The diagnostic error sink buffer is strictly bounded by `$`O(C_{\text{max\_errors}}) = O(1)`$.
