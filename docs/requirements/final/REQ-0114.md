### REQ-0114: Spatio-Temporal Occurrence Lifecycles & Temporal Interval Bounds $[t_{\text{start}}, t_{\text{end}}]$

- **Normative Statement**: The spatio-temporal dynamics solver, occurrence analysis engine, and discrete state machine verification pipeline of Subsystem 6 shall assign explicit temporal interval bounds $[t_{\text{start}}, t_{\text{end}}]$ to all occurrence lifecycles, action executions, and state occupancies across the compiled system model, strictly enforcing temporal non-negativity, endpoint ordering, and duration consistency.

  Specifically, the dynamics solver and AST semantic validation engine shall enforce the following architectural, algebraic, and lifecycle invariants:
  1. **Temporal Interval Model & Lifetime Representation**:
     - The dynamics solver shall formalize the temporal lifecycle of every occurrence individual, action execution (performance), and discrete state occupancy as a closed, semi-open, or degenerate point temporal interval $I = [t_{\text{start}}, t_{\text{end}}] \subset \mathbb{R} \cup \{-\infty, +\infty\}$ over the continuous real time coordinate axis $(\mathbb{R}, \le)$ referenced to a defined system epoch $t_{\text{epoch}} = 0$.
     - Each interval $I$ shall be defined by a lower time bound $t_{\text{start}} \in \mathbb{R} \cup \{-\infty\}$ and an upper time bound $t_{\text{end}} \in \mathbb{R} \cup \{+\infty\}$.
     - The dynamics solver shall strictly enforce the Fundamental Temporal Interval Well-Formedness Invariant: $t_{\text{start}} \le t_{\text{end}}$.
     - Any occurrence declaration, action execution, or state occupancy specifying an inverted temporal interval where $t_{\text{start}} \gt t_{\text{end}}$ shall be deterministically rejected at compile time with diagnostic error code `E0400` (`TemporalIntervalInverted`).
     - The solver shall enforce coordinate non-negativity relative to the system epoch ($t_{\text{start}} \ge 0$) for all executable operational lifecycles. Any temporal declaration specifying a negative epoch time coordinate ($t_{\text{start}} \lt 0$) without explicit relative offset qualification shall be rejected with diagnostic error code `E0400` (`NegativeEpochTime`).
  2. **Dichotomy of Temporal Lifecycles: Discrete Events vs. Durative Occurrences**:
     - The dynamics solver shall partition all temporal occurrences into two mutually disjoint behavioral classes:
       * **Discrete Event Occurrences** (instantaneous snapshots, point triggers, state transitions, clock events):
         Every discrete event occurrence must satisfy the Zero-Duration Invariant: $t_{\text{start}} = t_{\text{end}}$, yielding an exact Lebesgue measure of zero ($\lambda_t(I) = 0$, $\text{duration}(I) = 0$). Any discrete event declared with disparate endpoints ($t_{\text{start}} \ne t_{\text{end}}$) shall be deterministically rejected with diagnostic error code `E0400` (`DiscreteEventNonZeroDuration`).
       * **Durative Occurrences** (continuous state occupancies, action performances, physical activities, time slices):
         Every durative occurrence must satisfy the Strict Positive Duration Invariant: $t_{\text{start}} \lt t_{\text{end}}$, yielding a strictly positive temporal duration ($\text{duration}(I) = t_{\text{end}} - t_{\text{start}} \gt 0$, $\lambda_t(I) \gt 0$). Any durative continuous state occupancy or action execution declared with degenerate endpoints ($t_{\text{start}} = t_{\text{end}}$, zero duration) or inverted endpoints ($t_{\text{start}} \gt t_{\text{end}}$) shall be deterministically rejected with diagnostic error code `E0400` (`NonPositiveContinuousDuration`).
  3. **Duration Consistency & Parametric Bounds Enforcement**:
     - The duration function of an interval $I = [t_{\text{start}}, t_{\text{end}}]$ shall be defined as $\text{duration}(I) = t_{\text{end}} - t_{\text{start}}$.
     - When an occurrence explicitly declares a nominal duration scalar $\delta_{\text{nom}} \in \mathbb{R}^+$ alongside interval endpoints $[t_{\text{start}}, t_{\text{end}}]$, the dynamics solver shall verify algebraic consistency:
       $$| (t_{\text{end}} - t_{\text{start}}) - \delta_{\text{nom}} | \le \epsilon_{\text{tol}}$$
       where $\epsilon_{\text{tol}} = 10^{-9}$ for floating-point evaluations, and exact rational identity ($t_{\text{end}} - t_{\text{start}} \equiv \delta_{\text{nom}}$) for rational time coordinates. Any inconsistency where $| (t_{\text{end}} - t_{\text{start}}) - \delta_{\text{nom}} | \gt \epsilon_{\text{tol}}$ shall be rejected with diagnostic error code `E0400` (`DurationBoundsInconsistency`).
     - When an occurrence declares parametric duration bounds $[\delta_{\min}, \delta_{\max}]$ where $0 \le \delta_{\min} \le \delta_{\max}$, the solver shall statically prove or assert that the interval duration satisfies:
       $$\delta_{\min} \le t_{\text{end}} - t_{\text{start}} \le \delta_{\max}$$
       Any occurrence violating declared duration envelope bounds ($t_{\text{end}} - t_{\text{start}} \lt \delta_{\min}$ or $t_{\text{end}} - t_{\text{start}} \gt \delta_{\max}$) shall trigger diagnostic error code `E0400` (`DurationEnvelopeBreach`).
     - Declaring a negative duration ($\delta \lt 0$) or an inverted duration envelope ($\delta_{\min} \gt \delta_{\max}$) shall be deterministically rejected with diagnostic error code `E0400` (`NegativeDuration`).
  4. **Hierarchical Spatio-Temporal Containment Axiom (Sub-Occurrences)**:
     - For composite occurrence structures where $o_{\text{sub}}$ is a declared sub-occurrence of $o_{\text{super}}$ ($o_{\text{sub}} \subseteq_{\text{occ}} o_{\text{super}}$) or an action sub-step within an enclosing action execution, the dynamics solver shall strictly enforce the Temporal Containment Invariant:
       $$[t_{\text{start}}(o_{\text{sub}}), t_{\text{end}}(o_{\text{sub}})] \subseteq [t_{\text{start}}(o_{\text{super}}), t_{\text{end}}(o_{\text{super}})]$$
       $$\iff t_{\text{start}}(o_{\text{super}}) \le t_{\text{start}}(o_{\text{sub}}) \le t_{\text{end}}(o_{\text{sub}}) \le t_{\text{end}}(o_{\text{super}})$$
     - Any sub-occurrence whose temporal interval starts before its parent's start time ($t_{\text{start}}(o_{\text{sub}}) \lt t_{\text{start}}(o_{\text{super}})$) or extends beyond its parent's end time ($t_{\text{end}}(o_{\text{sub}}) \gt t_{\text{end}}(o_{\text{super}})$) shall be rejected with diagnostic error code `E0400` (`TemporalContainmentBreach`).
  5. **State Occupancy Sequences & Transition Continuity**:
     - For discrete state machine lifecycles within an orthogonal region, state occupancies must form contiguous sequential chains.
     - For consecutive state occupancies $S_i$ and $S_{i+1}$ linked by an instantaneous transition $\tau$:
       $$t_{\text{end}}(S_i) = t(\tau) = t_{\text{start}}(S_{i+1})$$
       enforcing Allen's `meets` relation without unaccounted temporal gaps or dead time.
     - In non-orthogonal, mutually exclusive state configurations, overlapping occupancies ($S_i \cap S_j \ne \emptyset$ where $t_{\text{start}}(S_j) \lt t_{\text{end}}(S_i)$) shall be rejected with diagnostic error code `E0400` (`StateOccupancyOverlap`).
  6. **The 5 Executive Architectural Directives Compliance**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every occurrence lifecycle node, action execution interval record, state occupancy instance, and temporal constraint assertion shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical compiler namespace OID and the node fully qualified topological path ($\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel interval bound assignment, duration consistency verification, and hierarchical containment validation across independent packages, occurrence trees, or statecharts shall execute exclusively on a bounded work-stealing thread pool with worker bound $N_{\text{max\_workers}}$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: Occurrence identifiers, lifecycle labels, state names, action symbols, and temporal parameter tokens shall be interned into the deduplicated global symbol interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The dynamics solver shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When semantic temporal violations occur (`E0400`), diagnostics shall accumulate in the error sink buffer $\mathcal{D}_{\text{sink}}$, substitute typed error sentinels ($\bot_{\text{interval}}$, $\bot_{\text{occ}}$), and continue validating subsequent occurrence declarations. If accumulated diagnostics reach $C_{\text{max\_errors}}$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully.
     - *Directive 5 (Panic-Free Release Isolation)*: The dynamics solver pipeline shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Verification latency ($\lt 25\text{ ms}$ for $10^4$ occurrence lifecycles) and peak RSS memory ($\lt 100\text{ MB}$) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Occurrence_Alpha`, `Occurrence_Beta`, `Action_1`, `Action_2`, `State_1`, `State_2`, `Event_1`, `Event_2`, `Lifecycle_0`, `Port_1`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $\mathcal{V}_{\text{AST}}$ denote the universe of allocated AST nodes in contiguous bump arena storage.

  The set of occurrence lifecycles $\mathcal{O}_{\text{life}} \subset \mathcal{V}_{\text{AST}}$ is partitioned into discrete event occurrences $\mathcal{O}_{\text{event}}$ and durative occurrences $\mathcal{O}_{\text{durative}}$:

  $$
  \mathcal{O}_{\text{life}} = \mathcal{O}_{\text{event}} \cup \mathcal{O}_{\text{durative}}, \quad \mathcal{O}_{\text{event}} \cap \mathcal{O}_{\text{durative}} = \emptyset
  $$

  where durative occurrences comprise action executions $\mathcal{O}_{\text{action}}$ and state occupancies $\mathcal{O}_{\text{state}}$:

  $$
  \mathcal{O}_{\text{durative}} = \mathcal{O}_{\text{action}} \cup \mathcal{O}_{\text{state}}
  $$

  Each occurrence lifecycle entity $o \in \mathcal{O}_{\text{life}}$ is formalized as an 8-tuple:

  $$
  o = \langle \text{id}_o, \text{name}_o, \kappa_o, I(o), \delta(o), \text{parent}_o, \Delta_o, \text{span}_o \rangle
  $$

  where:

  $$
  \begin{aligned}
  \text{id}_o &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
  \text{name}_o &\in \mathcal{S}_{\text{intern}} \quad (\text{interned scalar symbol identifier}) \\
  \kappa_o &\in \{ \text{Kind::Event}, \text{Kind::Action}, \text{Kind::State} \} \quad (\text{occurrence lifecycle kind}) \\
  I(o) &= [t_{\text{start}}(o), t_{\text{end}}(o)] \subset \mathbb{R} \cup \{ -\infty, +\infty \} \quad (\text{temporal interval bounds}) \\
  \delta(o) &= \langle \delta_{\text{nom}}, \delta_{\min}, \delta_{\max} \rangle \in \mathbb{R}_{\ge 0} \times \mathbb{R}_{\ge 0} \times (\mathbb{R}_{\ge 0} \cup \{ +\infty \}) \quad (\text{declared duration parameters}) \\
  \text{parent}_o &\in \mathcal{O}_{\text{life}} \cup \{ \bot \} \quad (\text{enclosing parent occurrence handle or root}) \\
  \Delta_o &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
  \text{span}_o &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
  \end{aligned}
  $$

  Fundamental Interval Well-Formedness & Non-Negativity Invariants:

  $$
  \begin{aligned}
  \forall o \in \mathcal{O}_{\text{life}}, &\quad t_{\text{start}}(o) \le t_{\text{end}}(o) \\
  \forall o \in \mathcal{O}_{\text{life}}, &\quad \text{duration}(I(o)) = t_{\text{end}}(o) - t_{\text{start}}(o) \ge 0 \\
  \forall o \in \mathcal{O}_{\text{life}}, &\quad t_{\text{start}}(o) \ge t_{\text{epoch}} = 0
  \end{aligned}
  $$

  Discrete vs. Durative Classification Invariants:

  $$
  \begin{aligned}
  o \in \mathcal{O}_{\text{event}} &\iff (\kappa_o = \text{Kind::Event}) \implies (t_{\text{start}}(o) = t_{\text{end}}(o) \;\land\; \text{duration}(I(o)) = 0) \\
  o \in \mathcal{O}_{\text{durative}} &\iff (\kappa_o \in \{ \text{Kind::Action}, \text{Kind::State} \}) \implies (t_{\text{start}}(o) \lt t_{\text{end}}(o) \;\land\; \text{duration}(I(o)) \gt 0)
  \end{aligned}
  $$

  Duration Parameter Consistency Invariants:

  $$
  \begin{aligned}
  \delta_{\min}(o) &\le \delta_{\text{nom}}(o) \le \delta_{\max}(o) \\
  \delta_{\min}(o) &\le t_{\text{end}}(o) - t_{\text{start}}(o) \le \delta_{\max}(o) \\
  | (t_{\text{end}}(o) - t_{\text{start}}(o)) - \delta_{\text{nom}}(o) | &\le \epsilon_{\text{tol}}
  \end{aligned}
  $$

  Hierarchical Temporal Containment Invariant (Sub-Occurrences):

  $$
  \forall o_{\text{sub}}, o_{\text{super}} \in \mathcal{O}_{\text{life}}, \quad o_{\text{sub}} \subseteq_{\text{occ}} o_{\text{super}} \implies I(o_{\text{sub}}) \subseteq I(o_{\text{super}})
  $$

  $$
  \iff (t_{\text{start}}(o_{\text{super}}) \le t_{\text{start}}(o_{\text{sub}})) \;\land\; (t_{\text{end}}(o_{\text{sub}}) \le t_{\text{end}}(o_{\text{super}}))
  $$

  State Transition Continuity & Mutual Exclusion Invariants:

  $$
  \begin{aligned}
  S_i \xrightarrow{\tau} S_{i+1} &\implies t_{\text{end}}(S_i) = t(\tau) = t_{\text{start}}(S_{i+1}) \\
  \forall S_i, S_j \in \text{Region}(R), \quad S_i \ne S_j &\implies I(S_i) \cap I(S_j) \subseteq \{ t_{\text{boundary}} \}
  \end{aligned}
  $$

  Deterministic Diagnostic Emission Invariant (REQ-0191):

  $$
  \begin{aligned}
  t_{\text{start}}(o) \gt t_{\text{end}}(o) &\implies \text{Diagnostic}(o, \text{DiagnosticCode::E0400}, \text{TemporalIntervalInverted}) \in \mathcal{D}_{\text{sink}} \\
  o \in \mathcal{O}_{\text{event}} \land t_{\text{start}}(o) \ne t_{\text{end}}(o) &\implies \text{Diagnostic}(o, \text{DiagnosticCode::E0400}, \text{DiscreteEventNonZeroDuration}) \in \mathcal{D}_{\text{sink}} \\
  o \in \mathcal{O}_{\text{durative}} \land t_{\text{start}}(o) \ge t_{\text{end}}(o) &\implies \text{Diagnostic}(o, \text{DiagnosticCode::E0400}, \text{NonPositiveContinuousDuration}) \in \mathcal{D}_{\text{sink}} \\
  \delta_{\text{nom}}(o) \lt 0 \lor \delta_{\min}(o) \gt \delta_{\max}(o) &\implies \text{Diagnostic}(o, \text{DiagnosticCode::E0400}, \text{NegativeDuration}) \in \mathcal{D}_{\text{sink}} \\
  | (t_{\text{end}}(o) - t_{\text{start}}(o)) - \delta_{\text{nom}}(o) | \gt \epsilon_{\text{tol}} &\implies \text{Diagnostic}(o, \text{DiagnosticCode::E0400}, \text{DurationBoundsInconsistency}) \in \mathcal{D}_{\text{sink}} \\
  (t_{\text{end}}(o) - t_{\text{start}}(o) \lt \delta_{\min}(o)) \lor (t_{\text{end}}(o) - t_{\text{start}}(o) \gt \delta_{\max}(o)) &\implies \text{Diagnostic}(o, \text{DiagnosticCode::E0400}, \text{DurationEnvelopeBreach}) \in \mathcal{D}_{\text{sink}} \\
  o_{\text{sub}} \subseteq_{\text{occ}} o_{\text{super}} \land (t_{\text{start}}(o_{\text{sub}}) \lt t_{\text{start}}(o_{\text{super}}) \lor t_{\text{end}}(o_{\text{sub}}) \gt t_{\text{end}}(o_{\text{super}})) &\implies \text{Diagnostic}(o_{\text{sub}}, \text{DiagnosticCode::E0400}, \text{TemporalContainmentBreach}) \in \mathcal{D}_{\text{sink}} \\
  S_i, S_j \in \text{Region}(R) \land S_i \ne S_j \land t_{\text{start}}(S_j) \lt t_{\text{end}}(S_i) &\implies \text{Diagnostic}(S_j, \text{DiagnosticCode::E0400}, \text{StateOccupancyOverlap}) \in \mathcal{D}_{\text{sink}} \\
  |\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
  \end{aligned}
  $$

  Deterministic RFC 4122 UUIDv5 Anchor Invariant (Directive 1):

  $$
  \forall o \in \mathcal{O}_{\text{life}}, \quad \Delta_o = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(o))
  $$

- **Computational Complexity & Algorithmic Bounds**: Spatio-temporal occurrence lifecycle interval bound checking, duration consistency verification, and hierarchical containment validation reside in **Complexity Class P** (Deterministic Polynomial Time).

  For an abstract MBSE system model comprising $N = |\mathcal{O}_{\text{life}}|$ occurrence lifecycles, action executions, and state occupancies, organized in a containment forest with $M \le N - 1$ containment edges:
  1. *Interval Bound Assignment & Ordering Validation*:
     For each occurrence lifecycle node $o \in \mathcal{O}_{\text{life}}$, the dynamics solver retrieves the lower bound $t_{\text{start}}$ and upper bound $t_{\text{end}}$, verifies the scalar ordering $t_{\text{start}} \le t_{\text{end}}$, verifies coordinate non-negativity $t_{\text{start}} \ge 0$, and computes duration $\Delta t = t_{\text{end}} - t_{\text{start}}$ in $O(1)$ scalar arithmetic steps.
     For $N$ occurrence lifecycles:
     $$T_{\text{bounds}}(N) \in O(N)$$
  2. *Discrete vs. Durative Classification Verification*:
     Checking whether an event has $\Delta t = 0$ or whether a durative occurrence satisfies $\Delta t \gt 0$ requires an $O(1)$ comparison per node.
     For $N$ occurrence lifecycles:
     $$T_{\text{class}}(N) \in O(N)$$
  3. *Duration Parameter Consistency & Envelope Validation*:
     Comparing computed duration against explicit nominal duration $| \Delta t - \delta_{\text{nom}} | \le \epsilon_{\text{tol}}$ and parametric envelope $\delta_{\min} \le \Delta t \le \delta_{\max}$ executes in $O(1)$ time per occurrence.
     For $N$ occurrence lifecycles:
     $$T_{\text{duration}}(N) \in O(N)$$
  4. *Hierarchical Temporal Containment Verification*:
     Traversing the containment forest $(\mathcal{O}_{\text{life}}, \mathcal{E}_{\text{contain}})$ to verify $t_{\text{start}}(o_{\text{super}}) \le t_{\text{start}}(o_{\text{sub}})$ and $t_{\text{end}}(o_{\text{sub}}) \le t_{\text{end}}(o_{\text{super}})$ inspects each containment edge exactly once.
     With $M = |\mathcal{E}_{\text{contain}}| \le N - 1$ edges, verification takes:
     $$T_{\text{containment}}(N, M) \in O(N + M) = O(N)$$
  5. *State Transition Continuity & Mutual Exclusion Checking*:
     For an orthogonal statechart region containing $K$ sequential state occupancies, checking adjacent transition boundaries $t_{\text{end}}(S_i) = t_{\text{start}}(S_{i+1})$ and pairwise non-overlap executes in $O(K)$ time.
     Summed over all regions in the model, this step takes $O(N)$ operations.
  6. *Aggregate Worst-Case Time Complexity*:
     Combining all evaluation passes, the total execution time is strictly linear in the number of occurrence lifecycles:
     $$T_{\text{total}}(N, M) \in O(N + M) = O(N)$$
     The algorithm operates without backtracking, combinatorial search, or iterative numerical convergence loops, guaranteeing deterministic linear execution time.
  7. *Parallel Work-Stealing Scaling (Directive 2)*:
     When evaluating $P$ independent packages or decoupled occurrence trees across $N_{\text{max\_workers}}$ threads on a bounded work-stealing thread pool:
     $$T_{\text{parallel}}(N, N_{\text{max\_workers}}) \in O\left( \frac{N}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)$$
  8. *Space Complexity & Arena Memory Bounds*:
     Allocations for occurrence lifecycles, interval records, and duration descriptors are maintained in contiguous bump arena storage, requiring $O(N)$ bytes. Interned identifier tokens require $O(N)$ space in the symbol pool. The diagnostic error sink buffer is strictly bounded by $O(C_{\text{max\_errors}}) = O(1)$ capacity.
