### REQ-0120: Hierarchical State Machine (Statechart) Containment & Orthogonal Regions

- **Normative Statement**: The spatio-temporal dynamics and discrete state machine solver of Subsystem 6 shall model, validate, and verify hierarchical statecharts supporting nested composite states, parent-child state containment trees, orthogonal parallel regions, and active state configurations.

  Specifically, the statechart compiler, containment solver, and configuration validator shall enforce the following architectural, structural, and semantic invariants:
  1. **Hierarchical Statechart Containment Tree & Acyclicity**:
     - The statechart compiler shall formalize the state space of every discrete state machine as a rooted directed tree $`(S, \sqsubseteq)`$ over the universe of allocated state AST nodes $`\mathcal{S}_{\text{all}} \subset \mathcal{V}_{\text{AST}}`$.
     - Every state entity $`s \in \mathcal{S}_{\text{all}}`$ except the unique root state machine container $`s_{\text{root}}`$ shall have exactly one immediate parent container ($`\text{parent}_s \in \mathcal{S}_{\text{all}}`$). Multiple parent ownership or ambiguous containment shall be deterministically rejected at compile time with diagnostic error code `E0400` (`MultipleParentOwnership`).
     - The parent-child containment relation $`\sqsubset`$ shall be strictly irreflexive and acyclic: $`(s, s) \notin \sqsubset^+`$. Any cyclic containment chain ($`s_1 \sqsubset s_2 \sqsubset \dots \sqsubset s_1`$) shall be detected via topological cycle detection algorithms and rejected at compile time with diagnostic error code `E0400` (`CircularStateContainment`).
     - All sibling states and regions residing within the same composite state or region scope must possess unique interned symbol identifiers; duplicate state identifiers within an identical lexical scope shall be deterministically rejected with diagnostic error code `E0400` (`DuplicateStateNameInRegion`).
  2. **Taxonomic Partitioning of Statechart Entities**:
     - Statechart nodes shall be partitioned into mutually disjoint structural categories:
       * **Atomic Leaf States** ($`\mathcal{S}_{\text{atomic}}`$): Primitive states having zero child states and zero orthogonal regions ($`|\mathcal{C}_s| = 0`$, $`|\mathcal{R}_s| = 0`$).
       * **Exclusive Composite States (OR-States)** ($`\mathcal{S}_{\text{xor}}`$): Composite states containing one or more child states ($`|\mathcal{C}_s| \ge 1`$) where at most one sub-state may be active simultaneously.
       * **Orthogonal Composite States (AND-States / Parallel States)** ($`\mathcal{S}_{\text{orth}}`$): Composite states containing $`m \ge 2`$ orthogonal parallel regions ($`|\mathcal{R}_s| = m \ge 2`$) executing concurrently.
       * **Orthogonal Regions** ($`\mathcal{R}`$): Independent concurrent sub-state spaces owned by an enclosing orthogonal composite state.
       * **Pseudo-States** ($`\mathcal{P}`$): Non-occupational control nodes (initial, fork, join, choice, junction, shallow history, deep history).
  3. **Orthogonal Parallel Region Well-Formedness & Disjointness**:
     - Every orthogonal composite state $`S_{\text{orth}} \in \mathcal{S}_{\text{orth}}`$ must contain at least two orthogonal regions ($`m = |\mathcal{R}(S_{\text{orth}})| \ge 2`$). Any parallel state declared with fewer than two regions ($`m \lt 2`$) shall be classified as degenerate and deterministically rejected with diagnostic error code `E0400` (`DegenerateOrthogonalRegions`).
     - The orthogonal regions of $`S_{\text{orth}}`$ shall partition its descendant state space into mutually disjoint subsets:

$$
       \forall R_i, R_j \in \mathcal{R}(S_{\text{orth}}), \quad i \ne j \implies \text{States}(R_i) \cap \text{States}(R_j) = \emptyset
$$

     - Each orthogonal region $`R_i`$ shall constitute an independent statechart container possessing its own initial state, internal sub-states, and transition topology.
  4. **Active State Configuration Semantics**:
     - An active state configuration $`C \subseteq \mathcal{S}`$ represents the maximal consistent set of simultaneously active states during discrete state machine execution.
     - **Root Invariant**: The root state machine container must be active in every valid configuration ($`s_{\text{root}} \in C`$).
     - **Ancestor Closure Invariant**: If a state $`s`$ is active in configuration $`C`$, all its ancestor states must be active in $`C`$:

$$
       \forall s \in C, \quad \text{ancestors}(s) \cap \mathcal{S} \subseteq C
$$

       Any candidate configuration violating ancestor closure shall be rejected with diagnostic error code `E0400` (`AncestorClosureViolation`).
     - **Exclusive Composite Singularity Invariant**: For every active exclusive composite state $`S_{\text{xor}} \in C \cap \mathcal{S}_{\text{xor}}`$, exactly one immediate child state must be active simultaneously:

$$
       |C \cap \mathcal{C}_{S_{\text{xor}}}| = 1
$$

       Any configuration activating zero child states or multiple child states within an active exclusive composite state shall be rejected with diagnostic error code `E0400` (`InvalidCompositeActiveCount`).
     - **Orthogonal Concurrency & Region Leaf Invariant**: For every active orthogonal composite state $`S_{\text{orth}} \in C \cap \mathcal{S}_{\text{orth}}`$, every constituent region $`R_i \in \mathcal{R}(S_{\text{orth}})`$ must be active, must contain exactly one active immediate child state ($`|C \cap \mathcal{C}_{R_i}| = 1`$), and must contain exactly one active leaf state:

$$
       \forall R_i \in \mathcal{R}(S_{\text{orth}}), \quad |C \cap \text{Leaves}(R_i)| = 1
$$

       Any configuration exhibiting a leaf count underflow ($`|C \cap \text{Leaves}(R_i)| = 0`$) or overflow ($`|C \cap \text{Leaves}(R_i)| \gt 1`$) within an active orthogonal region shall be rejected with diagnostic error code `E0400` (`OrthogonalRegionLeafCountMismatch`).
     - **Active Leaf Determination**: The entire active configuration $`C`$ shall be uniquely determined by its set of active leaf states $`\text{Leaves}(C) = \{ s \in C \mid \mathcal{C}_s \cap C = \emptyset \}`$ through ancestor closure:

$$
       C = \bigcup_{l \in \text{Leaves}(C)} (\{ l \} \cup (\text{ancestors}(l) \cap \mathcal{S}))
$$

     - **Mutual Exclusion of Sibling Leaves**: For any two distinct active leaf states $`l_1, l_2 \in \text{Leaves}(C)`$ ($`l_1 \ne l_2`$), their Lowest Common Ancestor $`\text{LCA}(l_1, l_2)`$ must be an orthogonal composite state ($`\text{LCA}(l_1, l_2) \in \mathcal{S}_{\text{orth}}`$). Two active leaf states having an exclusive composite state as their LCA shall be rejected with diagnostic error code `E0400` (`ConflictingActiveLeaves`).
  5. **Orthogonal Boundary Synchronization & Compound Transitions**:
     - Direct state transitions crossing distinct orthogonal regions ($`s_{\text{src}} \in \text{States}(R_i) \to s_{\text{tgt}} \in \text{States}(R_j)`$ with $`i \ne j`$) without traversing enclosing orthogonal composite boundaries or utilizing explicit synchronization pseudo-states shall be strictly prohibited and deterministically rejected with diagnostic error code `E0400` (`UnsynchronizedCrossRegionTransition`).
     - Compound transitions entering an orthogonal composite state and activating multiple regions simultaneously must enter via an explicit `fork` pseudo-state construct.
     - Compound transitions exiting multiple orthogonal regions simultaneously and converging into an external target state must synchronize via an explicit `join` pseudo-state construct.
     - For any transition $`\tau = (s_{\text{src}}, s_{\text{tgt}})`$, the execution scope shall be defined as the Lowest Common Ancestor $`\text{LCA}(s_{\text{src}}, s_{\text{tgt}})`$. Transition firing shall exit all active states that are descendants of the LCA along the source path and enter all states along the target path down to the target active leaf states.
  6. **Compliance with the 5 Architectural Directives**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every state machine, composite state, orthogonal region, pseudo-state, and active configuration AST node shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical DEAP namespace OID and the node fully qualified topological path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))`$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel statechart containment validation, configuration consistency checks, and LCA evaluations across independent packages or state machines shall execute exclusively on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: State names, region labels, trigger event symbols, and fully qualified path segments shall be interned into the deduplicated global symbol interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The statechart solver shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When semantic violations occur (`E0400`), diagnostics shall accumulate in the error sink buffer $`\mathcal{D}_{\text{sink}}`$, substitute typed error sentinels ($`\bot_{\text{state}}`$, $`\bot_{\text{config}}`$), and continue validating subsequent state declarations. If accumulated diagnostics reach capacity $`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully in accordance with REQ-0013 and REQ-0016.
     - *Directive 5 (Panic-Free Release Isolation)*: The state machine solver pipeline shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Verification latency ($`\lt 25\text{ ms}`$ for $`10^4`$ state elements) and peak RSS memory ($`\lt 100\text{ MB}`$) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `StateMachine_Alpha`, `StateMachine_Beta`, `State_Alpha`, `State_Beta`, `State_Gamma`, `CompositeState_1`, `CompositeState_2`, `ParallelState_Omega`, `Region_1`, `Region_2`, `Region_3`, `LeafState_A1`, `LeafState_A2`, `LeafState_B1`, `LeafState_B2`, `Transition_1`, `Port_1`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $`\mathcal{V}_{\text{AST}}`$ denote the universe of allocated AST nodes in contiguous bump arena storage.

  The set of state machine elements $`\mathcal{S}_{\text{all}} \subset \mathcal{V}_{\text{AST}}`$ is partitioned into states $`\mathcal{S}`$, orthogonal regions $`\mathcal{R}`$, and pseudo-states $`\mathcal{P}`$:

$$
  \mathcal{S}_{\text{all}} = \mathcal{S} \cup \mathcal{R} \cup \mathcal{P}, \quad \mathcal{S} \cap \mathcal{R} = \emptyset, \quad \mathcal{S} \cap \mathcal{P} = \emptyset, \quad \mathcal{R} \cap \mathcal{P} = \emptyset
$$

  The state set $`\mathcal{S}`$ is partitioned into atomic leaf states $`\mathcal{S}_{\text{atomic}}`$, exclusive composite states $`\mathcal{S}_{\text{xor}}`$, and orthogonal composite states $`\mathcal{S}_{\text{orth}}`$:

$$
  \mathcal{S} = \mathcal{S}_{\text{atomic}} \cup \mathcal{S}_{\text{xor}} \cup \mathcal{S}_{\text{orth}}
$$

  Each state entity $`s \in \mathcal{S}_{\text{all}}`$ is formalized as a 9-tuple:

$$
  s = \langle \text{id}_s, \text{name}_s, \kappa_s, \text{parent}_s, \mathcal{C}_s, \mathcal{R}_s, \Delta_s, \text{span}_s, \text{is\_initial}_s \rangle
$$

  where:

$$
  \begin{aligned}
  \text{id}_s &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
  \text{name}_s &\in \mathcal{S}_{\text{intern}} \quad (\text{interned scalar symbol identifier}) \\
  \kappa_s &\in \{ \text{Kind::Atomic}, \text{Kind::Composite}, \text{Kind::Orthogonal}, \text{Kind::Region}, \text{Kind::Pseudo} \} \\
  \text{parent}_s &\in \mathcal{S}_{\text{all}} \cup \{ \bot \} \quad (\text{unique enclosing container handle or root sentinel}) \\
  \mathcal{C}_s &\subseteq \mathcal{S}_{\text{all}} \quad (\text{finite ordered set of direct child elements}) \\
  \mathcal{R}_s &\subseteq \mathcal{R} \quad (\text{ordered sequence of orthogonal regions when } \kappa_s = \text{Kind::Orthogonal}) \\
  \Delta_s &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
  \text{span}_s &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance}) \\
  \text{is\_initial}_s &\in \{ \text{true}, \text{false} \} \quad (\text{initial default state discriminant})
  \end{aligned}
$$

  Hierarchical Containment Tree & Acyclicity Invariants:

$$
  \begin{aligned}
  s_1 \sqsubset s_2 &\iff s_1 \in \mathcal{C}_{s_2} \lor (\text{parent}_{s_1} = s_2) \\
  \forall s \in \mathcal{S}_{\text{all}}, &\quad (s, s) \notin \sqsubset^+ \\
  \forall s \in \mathcal{S}_{\text{all}} \setminus \{ s_{\text{root}} \}, &\quad \exists ! p \in \mathcal{S}_{\text{all}} : \text{parent}_s = p
  \end{aligned}
$$

  Ancestor, Descendant, and Leaf Sets:

$$
  \begin{aligned}
  \text{ancestors}(s) &= \{ a \in \mathcal{S}_{\text{all}} \mid s \sqsubset^+ a \} \\
  \text{descendants}(s) &= \{ d \in \mathcal{S}_{\text{all}} \mid d \sqsubset^+ s \} \\
  \text{Leaves}(x) &= \{ s \in \text{descendants}(x) \cap \mathcal{S}_{\text{atomic}} \}
  \end{aligned}
$$

  Orthogonal Region Well-Formedness & Disjointness Invariants:

$$
  \begin{aligned}
  \forall S_{\text{orth}} \in \mathcal{S}_{\text{orth}}, &\quad |\mathcal{R}(S_{\text{orth}})| = m \ge 2 \\
  \forall S_{\text{orth}} \in \mathcal{S}_{\text{orth}}, &\quad \bigcup_{i=1}^m \text{States}(R_i) = \text{descendants}(S_{\text{orth}}) \cap \mathcal{S} \\
  \forall R_i, R_j \in \mathcal{R}(S_{\text{orth}}), &\quad i \ne j \implies \text{States}(R_i) \cap \text{States}(R_j) = \emptyset
  \end{aligned}
$$

  Active State Configuration Invariants:

$$
  \begin{aligned}
  s_{\text{root}} &\in C \\
  \forall s \in C, &\quad \text{ancestors}(s) \cap \mathcal{S} \subseteq C \\
  \forall s \in C \cap \mathcal{S}_{\text{xor}}, &\quad |C \cap \mathcal{C}_s| = 1 \\
  \forall S_{\text{orth}} \in C \cap \mathcal{S}_{\text{orth}}, &\quad \forall R_i \in \mathcal{R}(S_{\text{orth}}), \quad |C \cap \mathcal{C}_{R_i}| = 1 \\
  \forall S_{\text{orth}} \in C \cap \mathcal{S}_{\text{orth}}, &\quad \forall R_i \in \mathcal{R}(S_{\text{orth}}), \quad |C \cap \text{Leaves}(R_i)| = 1
  \end{aligned}
$$

  Active Leaf States & Configuration Equivalence:

$$
  \text{Leaves}(C) = \{ s \in C \mid \mathcal{C}_s \cap C = \emptyset \}
$$

$$
  C = \bigcup_{l \in \text{Leaves}(C)} (\{ l \} \cup (\text{ancestors}(l) \cap \mathcal{S}))
$$

  Mutual Exclusion of Distinct Active Leaves:

$$
  \forall l_1, l_2 \in \text{Leaves}(C), \quad l_1 \ne l_2 \implies \text{LCA}(l_1, l_2) \in \mathcal{S}_{\text{orth}}
$$

  where Lowest Common Ancestor $`\text{LCA}(u, v)`$ is defined as:

$$
  \text{LCA}(u, v) = \arg\max_{a \in \text{ancestors}(u) \cap \text{ancestors}(v)} \text{depth}(a)
$$

  Orthogonal Boundary Cross-Region Transition Invariant:

$$
  \begin{aligned}
  \forall (s_{\text{src}}, s_{\text{tgt}}) \in \mathcal{E}_{\text{trans}}, \quad &(\exists S_{\text{orth}} \in \mathcal{S}_{\text{orth}}, R_i, R_j \in \mathcal{R}(S_{\text{orth}}) : i \ne j \land s_{\text{src}} \in \text{States}(R_i) \land s_{\text{tgt}} \in \text{States}(R_j)) \\
  &\implies \text{Diagnostic}(s_{\text{src}}, \text{DiagnosticCode::E0400}, \text{UnsynchronizedCrossRegionTransition}) \in \mathcal{D}_{\text{sink}}
  \end{aligned}
$$

  Deterministic Diagnostic Emission Invariant (REQ-0191):

$$
  \begin{aligned}
  \exists s \in \mathcal{S}_{\text{all}} : (s, s) \in \sqsubset^+ &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0400}, \text{CircularStateContainment}) \in \mathcal{D}_{\text{sink}} \\
  \exists s \in \mathcal{S}_{\text{all}} \setminus \{ s_{\text{root}} \} : |\text{parents}(s)| \ne 1 &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0400}, \text{MultipleParentOwnership}) \in \mathcal{D}_{\text{sink}} \\
  \exists S \in \mathcal{S}_{\text{orth}} : |\mathcal{R}(S)| \lt 2 &\implies \text{Diagnostic}(S, \text{DiagnosticCode::E0400}, \text{DegenerateOrthogonalRegions}) \in \mathcal{D}_{\text{sink}} \\
  \exists s \in C : \exists a \in \text{ancestors}(s) \cap \mathcal{S}, a \notin C &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0400}, \text{AncestorClosureViolation}) \in \mathcal{D}_{\text{sink}} \\
  \exists s \in C \cap \mathcal{S}_{\text{xor}} : |C \cap \mathcal{C}_s| \ne 1 &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0400}, \text{InvalidCompositeActiveCount}) \in \mathcal{D}_{\text{sink}} \\
  \exists S \in C \cap \mathcal{S}_{\text{orth}}, \exists R_i \in \mathcal{R}(S) : |C \cap \text{Leaves}(R_i)| \ne 1 &\implies \text{Diagnostic}(S, \text{DiagnosticCode::E0400}, \text{OrthogonalRegionLeafCountMismatch}) \in \mathcal{D}_{\text{sink}} \\
  \exists l_1, l_2 \in \text{Leaves}(C) : l_1 \ne l_2 \land \text{LCA}(l_1, l_2) \in \mathcal{S}_{\text{xor}} &\implies \text{Diagnostic}(l_1, \text{DiagnosticCode::E0400}, \text{ConflictingActiveLeaves}) \in \mathcal{D}_{\text{sink}} \\
  \exists s_1, s_2 \in \mathcal{C}_p : s_1 \ne s_2 \land \text{name}(s_1) = \text{name}(s_2) &\implies \text{Diagnostic}(s_1, \text{DiagnosticCode::E0400}, \text{DuplicateStateNameInRegion}) \in \mathcal{D}_{\text{sink}} \\
  |\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
  \end{aligned}
$$

  Deterministic RFC 4122 UUIDv5 Anchor Invariant (Directive 1):

$$
  \forall s \in \mathcal{S}_{\text{all}}, \quad \Delta_s = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(s))
$$

- **Computational Complexity & Algorithmic Bounds**: Hierarchical statechart containment validation, parent-child tree construction, active state configuration verification, and Lowest Common Ancestor (LCA) queries reside in **Complexity Class P** (Deterministic Polynomial Time).

  **Mathematical Delineation from Algorithmic Bound NP-5**:
  In dynamic state machine verification, reachability analysis, deadlock detection, and livelock verification over orthogonal concurrent regions is PSPACE-complete (or NP-complete under bounded depth unrolling $`k \le k_{\max}`$), as formalized under Algorithmic Bound NP-5 (REQ-0124) via SAT-based Bounded Model Checking (BMC). This computational explosion arises because the concurrent state space grows exponentially as the Cartesian product of the active state sets:

$$
  |\text{GlobalStates}| = \prod_{i=1}^m |\text{States}(R_i)|
$$

  In contrast, REQ-0120 governs the static structural validation of the statechart containment hierarchy, tree acyclicity, single-parent ownership, candidate active configuration well-formedness, and LCA transition scope computation. Under static compilation, no dynamic reachability exploration or state-space unrolling is performed; all algorithms operate directly on the static containment graph $`(\mathcal{S}_{\text{all}}, \sqsubset)`$ and execute in deterministic linear time.

  **Asymptotic Complexity Analysis**:
  For an abstract MBSE system model comprising $`V = |\mathcal{S}_{\text{all}}|`$ state entities (atomic states, composite states, orthogonal regions, pseudo-states), $`E = V - 1`$ hierarchical containment edges, and $`|\mathcal{E}_{\text{trans}}|`$ state transitions:
  1. *State Node Allocation & Symbol Interning*:
     Allocating $`V`$ state nodes in contiguous bump arena storage and interning symbol strings requires $`O(1)`$ amortized operations per node, totaling:

$$
     T_{\text{alloc}}(V) \in O(V)
$$

  2. *Containment Tree Construction & Parent Resolution*:
     Linking parent-child pointers and partitioning children into regional arrays visits each node and containment edge exactly once:

$$
     T_{\text{tree}}(V, E) \in O(V + E) = O(V)
$$

  3. *Acyclicity Verification via Tarjan's SCC / DFS*:
     Verifying that the containment relation $`\sqsubset`$ contains zero cycles executes a depth-first search in deterministic:

$$
     T_{\text{acyclic}}(V, E) \in O(V + E) = O(V)
$$

     utilizing $`O(V)`$ auxiliary stack space.
  4. *Orthogonal Region Validation*:
     Checking that every orthogonal composite state has $`m \ge 2`$ regions and that regions define mutually disjoint sub-state sets evaluates in:

$$
     T_{\text{region}}(V) \in O(V)
$$

  5. *Active Configuration Verification*:
     Given a candidate active configuration $`C \subseteq \mathcal{S}`$ of size $`|C| \le V`$:
     - Checking the root state $`s_{\text{root}} \in C`$ takes $`O(1)`$ time.
     - Verifying ancestor closure $`\text{ancestors}(s) \subseteq C`$ checks each node's parent in $`O(1)`$ time, totaling $`O(|C|)`$ operations.
     - Verifying exclusive composite singularity $`|C \cap \mathcal{C}_s| = 1`$ checks child counts in $`O(|C|)`$ operations.
     - Verifying orthogonal region leaf counts $`|C \cap \text{Leaves}(R_i)| = 1`$ checks active leaf counts in $`O(|C|)`$ operations.
     Total configuration verification time evaluates in:

$$
     T_{\text{config}}(|C|) \in O(|C|) \le O(V)
$$

  6. *Lowest Common Ancestor (LCA) Evaluation*:
     In well-formed MBSE statecharts with maximum hierarchy tree depth bounded by $`h \le 32`$, computing the LCA of two states via depth-equalization pointer climbing takes $`O(h) = O(1)`$ bounded steps. Alternatively, Euler tour preprocessing in $`O(V)`$ time enables strictly $`O(1)`$ LCA queries.
  7. *Transition Cross-Region Invariant Check*:
     For each transition edge $`(s_{\text{src}}, s_{\text{tgt}}) \in \mathcal{E}_{\text{trans}}`$, verifying that source and target do not cross orthogonal regions without fork/join checks LCA and region membership in $`O(h) = O(1)`$ time:

$$
     T_{\text{trans}}(|\mathcal{E}_{\text{trans}}|) \in O(|\mathcal{E}_{\text{trans}}|)
$$

  8. *Aggregate Worst-Case Time Complexity*:
     Combining all evaluation passes, the total execution time is strictly linear in the size of the statechart graph:

$$
     T_{\text{total}}(V, |\mathcal{E}_{\text{trans}}|) \in O(V + |\mathcal{E}_{\text{trans}}|)
$$

     The algorithm operates without backtracking, combinatorial search, or iterative loops, guaranteeing deterministic linear execution.
  9. *Parallel Work-Stealing Scaling (Directive 2)*:
     When evaluating $`P`$ independent state machines or decoupled packages across $`N_{\text{max\_workers}}`$ threads on a bounded work-stealing thread pool:

$$
     T_{\text{parallel}}(V, |\mathcal{E}_{\text{trans}}|, N_{\text{max\_workers}}) \in O\left( \frac{V + |\mathcal{E}_{\text{trans}}|}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  10. *Space Complexity & Arena Memory Bounds*:
      Allocations for state nodes, region structures, and configuration records are maintained in contiguous bump arena storage, requiring $`O(V + |\mathcal{E}_{\text{trans}}|)`$ bytes. Traversal recursion depth is strictly bounded by tree depth $`h \le 32`$ ($`O(1)`$ stack memory). Interned symbol tokens require $`O(V)`$ space in the symbol pool. The diagnostic error sink buffer is strictly bounded by $`O(C_{\text{max\_errors}}) = O(1)`$ capacity.
