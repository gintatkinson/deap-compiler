### REQ-0056: KerML Import Declaration Semantics (Public, Private, All, Filtered)

- **Normative Statement**: The KerML Metamodel Lowering & Grammar subsystem shall evaluate and resolve namespace import declarations (`import`) as deterministic relational projections over exported membership sets across compilation units. The scoping and import evaluation engine shall enforce the following normative rules:
  1. Visibility Parameterization & Two-Point Lattice:
     Every import declaration shall parameterize its target visibility over a two-point bounded visibility lattice $`\mathcal{V} = \{ \text{Private} \le \text{Public} \}`$` where `$`\text{Private} \lt \text{Public}`$:
     - Private Import (`private import` or default unqualified `import` in private scope): Imported memberships shall be bound strictly into the internal namespace scope of the importing target namespace $`N_{\text{tgt}}`$`. Private imported memberships shall NOT become part of the public interface of `$`N_{\text{tgt}}`$` and shall be strictly inaccessible to foreign namespaces importing `$`N_{\text{tgt}}`$.
     - Public Import (`public import`): Imported memberships shall be re-exported by joining the public exported interface of $`N_{\text{tgt}}`$`. Any foreign namespace that subsequently imports `$`N_{\text{tgt}}`$ shall transitively inherit visibility to these re-exported memberships, subject to the importing namespace's own import visibility rules.
  2. Import Selection Semantics & Kinds:
     The compiler shall support four canonical import declaration variants:
     - Single-Element Import (`import Package_0::Classifier_Alpha;`): Projects a single named membership identified by a qualified path. The engine shall verify that the designated member exists within $`N_{\text{src}}`$ and possesses `Public` visibility. Any attempt to import a private, protected, or non-existent member shall be rejected with diagnostic error code `E0200` per REQ-0191.
     - Namespace Wildcard Import (`import Package_0::*;`): Evaluates a non-recursive wildcard projection importing all directly declared public memberships of source namespace $`N_{\text{src}}`$` into target namespace `$`N_{\text{tgt}}`$`. Private memberships of `$`N_{\text{src}}`$ shall be strictly excluded from the imported membership set.
     - Recursive Wildcard Import (`import Package_0::**;`): Evaluates a recursive wildcard projection computing the reflexive-transitive closure of $`N_{\text{src}}`$` over its public subnamespace containment hierarchy (`$`\text{SubNamespaces}^*(N_{\text{src}})`$`). All public memberships across `$`N_{\text{src}}`$` and all its transitively nested child namespaces shall be projected into `$`N_{\text{tgt}}`$. The traversal shall maintain a cycle-detection visited set to prevent infinite loops over cyclic package structures.
     - Predicate-Filtered Member Import & Aliasing (`import Package_0::[filter];` or `import Package_0::Classifier_Alpha as Classifier_Beta;`): Projects memberships that satisfy a boolean filter predicate $`\phi : \mathcal{M} \to \mathbb{B}`$` (such as classifier kind or property discrimination) or binds an explicit member alias identifier `$`\sigma_{\text{alias}} \in \mathcal{S}_{\text{sym}}`$` within `$`N_{\text{tgt}}`$, mapping the source member to the target alias while preserving AST node identity.
  3. Deterministic Shadow Precedence:
     The symbol resolution engine shall enforce strict shadow precedence within any target namespace $`N_{\text{tgt}}`$:
     - Locally declared (owned) memberships within $`N_{\text{tgt}}`$ shall strictly shadow imported memberships sharing an identical unqualified identifier or alias.
     - Unqualified symbol resolution for symbol $`\sigma`$` within `$`N_{\text{tgt}}`$` shall first query locally declared memberships `$`\mathcal{M}_{\text{owned}}(N_{\text{tgt}})`$. If a local match is found, it shall bind immediately.
     - If and only if no local declaration matches $`\sigma`$`, the resolver shall query the imported membership set `$`\mathcal{M}_{\text{imported}}(N_{\text{tgt}})`$.
     - Shadowing does not mutate or erase the imported declaration; the shadowed imported entity shall remain fully accessible via its absolute or relative fully qualified path (e.g., `::Package_0::Classifier_Alpha`).
  4. Ambiguous Import Detection & Collision Resolution:
     When an unqualified symbol lookup $`\sigma`$ matches multiple distinct imported memberships originating from different imported namespaces (or distinct paths) in the absence of a shadowing local declaration:
     - The scoping engine shall strictly reject the ambiguous reference at compile time, emitting structured diagnostic error code `E0200` (`AmbiguousImportConflict`) in accordance with REQ-0191.
     - The diagnostic record shall identify all conflicting import declarations, source file locations, and member declaration coordinates to guide user disambiguation.
     - Disambiguation requires either qualifying the reference or declaring an explicit local alias or shadowing element.
  5. Monotonic Fixed-Point Evaluation & Cyclic Re-export Termination:
     In the presence of mutual or transitive public imports (e.g., $`N_A`$` publicly imports `$`N_B`$`, and `$`N_B`$` publicly imports `$`N_A`$):
     - The scoping engine shall compute imported membership sets using a monotonic fixed-point iteration over the finite membership power lattice.
     - Because the universe of declared model elements in any compilation unit is finite, fixed-point iteration is guaranteed to terminate deterministically.
     - If circular import cycles violate structural layering invariants, the engine shall emit structured diagnostic error code `E0203` (`CircularImportCycle`) while continuing compilation via error recovery.
  6. Architectural Directives & Repository Standards Enforcement:
     - Directive 1 (Deterministic UUIDv5 Anchors): In accordance with REQ-0010, every import declaration relation node and imported membership proxy entity must receive an immutable, deterministic RFC 4122 UUIDv5 identifier generated by hashing the fixed compiler namespace OID with its canonical fully qualified path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(u))`$). Time-based UUIDs are strictly prohibited.
     - Directive 2 (Bounded Work-Stealing Parallelism): In accordance with REQ-0012, parallel import evaluation and membership projection across independent package boundaries and compilation units shall be dispatched strictly onto a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$.
     - Directive 3 (Interner Memory Allocation Exception): In accordance with REQ-0036, copying string bytes from source files into the global deduplicated symbol interner pool for scalar `SymbolId` tokens (package names, member identifiers, alias labels) during lexical ingestion is the sole permitted exception to the zero-copy arena allocation invariant.
     - Directive 4 (Synchronization Token Error Recovery): In accordance with REQ-0013 and REQ-0016, upon detecting an invalid import (such as an unresolvable source namespace, inaccessible private member import, or ambiguous symbol collision), the engine shall record the diagnostic into preallocated sink $`\mathcal{D}_{\text{sink}}`$`, bind a typed error sentinel handle `$`\bot_{\text{node}}`$`, and continue evaluating subsequent import declarations and AST nodes without aborting on first fault. If accumulated diagnostics reach capacity `$`C_{\text{max\_errors}}`$, the compiler shall emit terminal diagnostic `E0199` and halt gracefully.
     - Directive 5 (Panic-Free Release Isolation): In accordance with REQ-0011 and REQ-0196, the import evaluation engine must enforce a total, deterministic, non-panicking execution contract across all inputs. Performance gates (< 25 ms execution latency, < 100 MB peak RSS for $`10^5`$ imported symbols) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests.
     - Pure Schema-Driven Formalisms: All illustrative examples, test cases, and diagnostic templates shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Package_1`, `Package_2`, `Package_Root`, `Classifier_Alpha`, `Classifier_Beta`, `Classifier_Gamma`, `param_x : Real`, `Feature_A`) with zero domain contamination and zero concrete mock data.

- **Formal Invariant**: Let $`\mathcal{N} \subset \mathbb{N}_{32}`$` denote the universe of arena node handles representing namespace entities. Each namespace `$`N \in \mathcal{N}`$ is formalized as a 5-tuple:

```math
N = \langle \text{id}_N, \text{name}_N, \mathcal{M}_{\text{owned}}(N), \mathcal{I}(N), \Delta_N \rangle
```

where:

```math
\begin{aligned}
\text{id}_N &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
\text{name}_N &\in \mathcal{S}_{\text{sym}} \quad (\text{interned scalar identifier token}) \\
\mathcal{M}_{\text{owned}}(N) &\subset \mathcal{M} \quad (\text{finite set of locally declared memberships}) \\
\mathcal{I}(N) &\subset \mathcal{I}_{\text{decl}} \quad (\text{ordered sequence of import declarations}) \\
\Delta_N &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 anchor})
\end{aligned}
```

Each membership $`m \in \mathcal{M}`$ is formalized as a 5-tuple:

```math
m = \langle \text{id}_m, \sigma_m, v_m, h_m, \text{span}_m \rangle
```

where $`\sigma_m \in \mathcal{S}_{\text{sym}}`$` is the member name or local alias, `$`v_m \in \mathcal{V} = \{ \text{Private}, \text{Public} \}`$` is the visibility discriminant, `$`h_m \in \mathcal{H}_{\text{node}}`$` is the target AST element handle, and `$`\text{span}_m`$ is the lexical coordinate span.

The two-point visibility lattice $`(\mathcal{V}, \le_{\mathcal{V}})`$ is totally ordered:

```math
\text{Private} \le_{\mathcal{V}} \text{Public}, \quad \text{Private} \lt_{\mathcal{V}} \text{Public}
```

An import declaration $`I \in \mathcal{I}(N_{\text{tgt}})`$` within target namespace `$`N_{\text{tgt}}`$ is formalized as:

```math
I = \langle N_{\text{src}}, V_I, \kappa_I, \phi_I, \alpha_I, \Delta_I \rangle
```

where:

```math
\begin{aligned}
N_{\text{src}} &\in \mathcal{N} \cup \{ \bot \} \quad (\text{source namespace being imported}) \\
V_I &\in \mathcal{V} \quad (\text{import visibility attribute}) \\
\kappa_I &\in \{ \text{Single}, \text{Wildcard}, \text{RecursiveWildcard} \} \quad (\text{import kind discriminant}) \\
\phi_I &: \mathcal{M} \to \mathbb{B} \quad (\text{filter predicate over memberships}) \\
\alpha_I &: \mathcal{S}_{\text{sym}} \to \mathcal{S}_{\text{sym}} \quad (\text{optional alias renaming mapping}) \\
\Delta_I &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 anchor})
\end{aligned}
```

The set of exported (publicly visible) memberships of a namespace $`N`$ is defined as:

```math
\mathcal{M}_{\text{exp}}(N) = \{ m \in \text{memberships}(N) \mid m.v_m = \text{Public} \}
```

The induced imported membership set $`\mathcal{M}_{\text{imp}}(I)`$` for an import declaration `$`I`$ satisfies:

```math
\mathcal{M}_{\text{imp}}(I) = \begin{cases}
\{ \text{Project}(m, V_I, \alpha_I) \mid m \in \mathcal{M}_{\text{exp}}(N_{\text{src}}) \;\wedge\; \phi_I(m) \}, & \text{if } \kappa_I \in \{ \text{Single}, \text{Wildcard} \} \\
\{ \text{Project}(m, V_I, \alpha_I) \mid m \in \mathcal{M}_{\text{rec}}(N_{\text{src}}) \;\wedge\; \phi_I(m) \}, & \text{if } \kappa_I = \text{RecursiveWildcard}
\end{cases}
```

where the projection operator $`\text{Project}(m, V_I, \alpha_I)`$` assigns visibility `$`V_I`$ and applies alias renaming:

```math
\text{Project}(m, V_I, \alpha_I) = \langle \text{id}_{\text{new}}, \alpha_I(m.\sigma_m), V_I, m.h_m, m.\text{span}_m \rangle
```

Recursive Wildcard Transitive Closure: Let $`\text{ChildNamespaces}(N)`$` denote the set of public subnamespaces contained in `$`N`$:

```math
\text{ChildNamespaces}(N) = \{ N' \in \mathcal{N} \mid \exists m \in \mathcal{M}_{\text{exp}}(N) : m.h_m = \text{Handle}(N') \}
```

The reflexive-transitive closure $`\text{SubNamespaces}^*(N)`$ is defined inductively:

```math
\text{SubNamespaces}^*(N) = \{ N \} \cup \bigcup_{N' \in \text{ChildNamespaces}(N)} \text{SubNamespaces}^*(N')
```

The recursive wildcard membership set aggregates all exported memberships across this closure:

```math
\mathcal{M}_{\text{rec}}(N) = \bigcup_{N' \in \text{SubNamespaces}^*(N)} \mathcal{M}_{\text{exp}}(N')
```

Visibility Re-export Invariant: The aggregate imported membership set for target namespace $`N_{\text{tgt}}`$ is:

```math
\mathcal{M}_{\text{imported}}(N_{\text{tgt}}) = \bigcup_{I \in \mathcal{I}(N_{\text{tgt}})} \mathcal{M}_{\text{imp}}(I)
```

The total membership set of namespace $`N`$ is:

```math
\text{memberships}(N) = \mathcal{M}_{\text{owned}}(N) \cup \mathcal{M}_{\text{imported}}(N)
```

The public interface of namespace $`N`$ consists strictly of public owned memberships and public re-exported imported memberships:

```math
\mathcal{M}_{\text{public}}(N) = \{ m \in \mathcal{M}_{\text{owned}}(N) \mid m.v_m = \text{Public} \} \cup \{ m \in \mathcal{M}_{\text{imported}}(N) \mid m.v_m = \text{Public} \}
```

Memberships imported with $`V_I = \text{Private}`$ are strictly excluded from the public interface:

```math
\forall m \in \mathcal{M}_{\text{imported}}(N), \quad m.v_m = \text{Private} \implies m \notin \mathcal{M}_{\text{public}}(N)
```

Deterministic Shadow Precedence Invariant: For any queried symbol identifier $`s \in \mathcal{S}_{\text{sym}}`$` within namespace `$`N`$:

```math
\text{Find}(s, N) = \begin{cases}
m.h_m, & \text{if } \exists m \in \mathcal{M}_{\text{owned}}(N) : m.\sigma_m = s \\
m.h_m, & \text{if } (\forall m \in \mathcal{M}_{\text{owned}}(N), m.\sigma_m \ne s) \;\wedge\; \exists ! m \in \mathcal{M}_{\text{imported}}(N) : m.\sigma_m = s \\
\bot, & \text{otherwise}
\end{cases}
```

Diagnostic Code Binding Invariants: Ambiguities, unresolvable import paths, inaccessible private member imports, and cycle violations trigger structured diagnostics in accordance with REQ-0191:

```math
\begin{aligned}
(\forall m \in \mathcal{M}_{\text{owned}}(N), m.\sigma_m \ne s) \;\wedge\; |\{ m \in \mathcal{M}_{\text{imported}}(N) \mid m.\sigma_m = s \}| \gt 1 \\
\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0200}, \text{AmbiguousImportConflict}) \in \mathcal{D}_{\text{sink}} \\
N_{\text{src}} = \bot \;\vee\; \neg\text{NamespaceExists}(N_{\text{src}}) \\
\implies \text{Diagnostic}(I, \text{DiagnosticCode::E0200}, \text{UnresolvedNamespaceImport}) \in \mathcal{D}_{\text{sink}} \\
\exists m \in \text{DeclaredIn}(N_{\text{src}}) : \phi_I(m) \;\wedge\; m.v_m = \text{Private} \\
\implies \text{Diagnostic}(m, \text{DiagnosticCode::E0200}, \text{InaccessibleImportMember}) \in \mathcal{D}_{\text{sink}} \\
\exists C \in \text{TarjanSCC}(G_{\text{import}}) : |C| \gt 1 \;\wedge\; \text{IsDisallowedCycle}(C) \\
\implies \text{Diagnostic}(C, \text{DiagnosticCode::E0203}, \text{CircularImportCycle}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} \\
\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
```

Monotonic Fixed-Point Convergence Invariant: Let $`K = |\mathcal{N}|`$` denote the finite number of namespaces in the compilation unit, and let `$`\mathcal{M}_{\text{univ}}`$` denote the finite universe of declared memberships (`$`|\mathcal{M}_{\text{univ}}| = M`$`). The global state is a vector of public membership sets `$`\vec{\mathcal{M}} = \langle \mathcal{M}_{\text{public}}(N_1), \dots, \mathcal{M}_{\text{public}}(N_K) \rangle \in (\mathcal{P}(\mathcal{M}_{\text{univ}}))^K`$`. The re-export transformer function `$`T : (\mathcal{P}(\mathcal{M}_{\text{univ}}))^K \to (\mathcal{P}(\mathcal{M}_{\text{univ}}))^K`$` is monotone on the complete lattice `$`((\mathcal{P}(\mathcal{M}_{\text{univ}}))^K, \sqsubseteq)`$:

```math
\vec{\mathcal{M}}_1 \sqsubseteq \vec{\mathcal{M}}_2 \implies T(\vec{\mathcal{M}}_1) \sqsubseteq T(\vec{\mathcal{M}}_2)
```

where $`\vec{\mathcal{M}}_1 \sqsubseteq \vec{\mathcal{M}}_2 \iff \forall i \in \{1, \dots, K\}, \vec{\mathcal{M}}_1[i] \subseteq \vec{\mathcal{M}}_2[i]`$`. By the Knaster-Tarski theorem, starting from base owned public memberships `$`\vec{\mathcal{M}}^{(0)}[i] = \{ m \in \mathcal{M}_{\text{owned}}(N_i) \mid m.v_m = \text{Public} \}`$`, the sequence `$`\vec{\mathcal{M}}^{(k+1)} = T(\vec{\mathcal{M}}^{(k)})`$` converges to the unique least fixed point `$`\vec{\mathcal{M}}^*`$` in at most `$`K \cdot M`$ iterations:

```math
\vec{\mathcal{M}}^* = \bigcup_{k=0}^{K \cdot M} T^k(\vec{\mathcal{M}}^{(0)})
```

Deterministic RFC 4122 UUIDv5 Anchor Invariant: Every import declaration relation node $`I`$` and projected membership proxy `$`m`$ receives an immutable UUIDv5 identifier derived from the compiler namespace OID and canonical fully qualified path:

```math
\forall I \in \mathcal{I}_{\text{decl}}, \quad \Delta_I = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(I))
```

- **Computational Complexity & Algorithmic Bounds**: Namespace import evaluation and membership projection execute strictly within Complexity Class $`\mathbf{P}`$. The algorithmic bounds across operations are formalized as follows:
  1. Single-Element & Filtered Import Complexity: For a single-element import, resolving the target symbol in $`N_{\text{src}}`$`'s public membership hash index requires `$`O(1)`$` amortized time. Inserting the projected membership into `$`N_{\text{tgt}}`$`'s imported symbol table requires `$`O(1)`$` amortized time. For a predicate-filtered import over `$`M_{\text{src}} = |\mathcal{M}_{\text{exp}}(N_{\text{src}})|`$` memberships with `$`O(1)`$` predicate evaluation, total processing time is `$`O(M_{\text{src}})`$.
  2. Namespace Wildcard Import Complexity: Evaluating `import Package_0::*;` traverses all $`M_{\text{src}}`$` exported memberships of `$`N_{\text{src}}`$` and registers them in `$`N_{\text{tgt}}`$`'s imported symbol table, executing in deterministic linear time `$`O(M_{\text{src}})`$.
  3. Recursive Wildcard Import Complexity: Evaluating `import Package_0::**;` traverses the subnamespace containment subtree rooted at $`N_{\text{src}}`$` containing `$`K_{\text{sub}}`$` descendant namespaces and `$`M_{\text{sub}}`$ total exported memberships. Using a visited-set depth-first or breadth-first search, each subnamespace and membership is processed at most once, bounding execution time to:

```math
T_{\text{rec}}(K_{\text{sub}}, M_{\text{sub}}) \in O(K_{\text{sub}} + M_{\text{sub}})
```

  4. Total Compilation Unit Import Resolution Complexity: For a compilation unit comprising $`N = |\mathcal{N}|`$` namespaces, `$`I_{\text{total}} = |\mathcal{I}_{\text{decl}}|`$` import declarations, and `$`M_{\text{univ}}`$ total declared memberships:
     - In an acyclic import dependency graph, topologically sorted evaluation resolves all imported membership sets in linear time:

```math
T_{\text{acyclic}}(N, I_{\text{total}}, M_{\text{univ}}) \in O(N + I_{\text{total}} + M_{\text{univ}})
```

     - In the presence of cyclic public re-exports, the monotonic fixed-point iteration converges in at most $`d`$` rounds, where `$`d \le N`$` is the import graph diameter, with each round executing in `$`O(I_{\text{total}} + M_{\text{univ}})`$ time:

```math
T_{\text{fixedpoint}}(N, I_{\text{total}}, M_{\text{univ}}) \in O(d \cdot (I_{\text{total}} + M_{\text{univ}})) \subseteq O(N \cdot (I_{\text{total}} + M_{\text{univ}}))
```

  5. Unqualified Identifier Lookup Complexity: Following import resolution and imported table construction, querying an unqualified identifier $`s`$` within `$`N_{\text{tgt}}`$` performs at most two hash map queries (one in `$`\mathcal{M}_{\text{owned}}(N_{\text{tgt}})`$` and one in `$`\mathcal{M}_{\text{imported}}(N_{\text{tgt}})`$), executing in deterministic amortized constant time:

```math
T_{\text{lookup}}(s) \in O(1)
```

  6. Parallel Scheduling Complexity: When independent compilation units and disjoint namespace clusters are evaluated across the bounded work-stealing thread pool with $`N_{\text{max\_workers}}`$ workers:

```math
T_{\text{parallel}} \in O\left( \frac{N + I_{\text{total}} + M_{\text{univ}}}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

  7. Space Complexity: Auxiliary working memory is strictly bounded by $`O(M_{\text{univ}})`$` for the imported membership hash tables and `$`O(K_{\text{sub}})`$` for the recursive wildcard traversal stack (`$`K_{\text{sub}} \le 16`$`), while diagnostic records are bounded by preallocated sink capacity `$`O(C_{\text{max\_errors}}) = O(1)`$, guaranteeing zero unbounded heap allocations beyond contiguous bump arena storage.

- **Verification & Conformance Criteria**: Automated test suites shall deterministically verify compliance against synthetic MBSE models (e.g., `Package_0`, `Package_1`, `Package_2`, `Package_Root`, `Classifier_Alpha`, `Classifier_Beta`, `Classifier_Gamma`, `param_x : Real`, `Feature_A`) across the following verification gates:
  1. Public vs. Private Import Visibility Gate:
     - Construct a model where `Package_0` declares and exports public classifier `Classifier_Alpha`.
     - In `Package_1`, declare private import `private import Package_0::Classifier_Alpha;`.
     - In `Package_2`, declare public import `public import Package_1::*;`.
     - Assert that `Classifier_Alpha` resolves successfully for unqualified references inside `Package_1`.
     - Assert that `Classifier_Alpha` is NOT exported by `Package_1`, and unqualified lookup of `Classifier_Alpha` inside `Package_2` fails, emitting structured diagnostic error code `E0200` (`UnresolvedSymbolReference`).
     - Invert `Package_1` import declaration to `public import Package_0::Classifier_Alpha;`.
     - Re-compile and assert that `Classifier_Alpha` is re-exported by `Package_1` and successfully resolves in `Package_2` with zero diagnostics.
  2. Local Declaration Shadow Precedence Gate:
     - Construct a model where `Package_0` declares and exports `Classifier_Alpha` containing feature `param_x : Real`.
     - In `Package_1`, declare wildcard import `import Package_0::*;` and simultaneously declare local classifier `Classifier_Alpha` containing feature `param_x : Integer`.
     - Assert that unqualified resolution of `Classifier_Alpha` in `Package_1` resolves deterministically to the local declaration handle (`Integer`).
     - Assert that fully qualified lookup `::Package_0::Classifier_Alpha` in `Package_1` resolves to the imported external declaration handle (`Real`).
     - Assert that zero ambiguous import errors are emitted.
  3. Wildcard Member Import Gate (`::*`):
     - In `Package_0`, declare public classifiers `Classifier_Alpha`, `Classifier_Beta`, and private classifier `Classifier_Gamma`.
     - In `Package_1`, declare wildcard import `import Package_0::*;`.
     - Assert that `Classifier_Alpha` and `Classifier_Beta` are resolvable unqualified within `Package_1`.
     - Assert that `Classifier_Gamma` is strictly excluded from `Package_1`'s imported membership set and cannot be resolved unqualified, emitting diagnostic error code `E0200`.
  4. Recursive Wildcard Import Gate (`::**`):
     - Construct a 3-level nested package hierarchy: `Package_0` contains `Package_0::SubPackage_1`, which in turn contains `Package_0::SubPackage_1::SubPackage_2`.
     - Declare public classifiers `Classifier_Alpha`, `Classifier_Beta`, and `Classifier_Gamma` in `Package_0`, `SubPackage_1`, and `SubPackage_2` respectively.
     - In `Package_Target`, declare recursive wildcard import `import Package_0::**;`.
     - Assert that all 3 classifiers across all three hierarchical levels resolve unqualified in `Package_Target`.
     - Assert that the recursive traversal visits each nested package exactly once without redundant evaluations or infinite loops.
  5. Ambiguous Import Conflict Gate:
     - Construct two independent packages `Package_0` and `Package_1`, each declaring and exporting an identical symbol name `Classifier_Alpha`.
     - In `Package_Target`, declare both `import Package_0::*;` and `import Package_1::*;`.
     - Attempt unqualified reference to `Classifier_Alpha` in `Package_Target`.
     - Assert deterministic rejection emitting diagnostic error code `E0200` (`AmbiguousImportConflict`).
     - Assert that the emitted diagnostic record lists both candidate declaration locations (`Package_0::Classifier_Alpha` and `Package_1::Classifier_Alpha`) with exact byte spans.
     - Assert that synchronization token error recovery binds error sentinel handle $`\bot_{\text{node}}`$ and continues compilation of subsequent statements.
  6. Inaccessible Private Member Import Gate:
     - In `Package_0`, declare private member `Classifier_Internal`.
     - In `Package_Target`, attempt explicit single import `import Package_0::Classifier_Internal;`.
     - Assert deterministic compile-time rejection emitting diagnostic error code `E0200` (`InaccessibleImportMember`) with exact source byte span.
  7. Cyclic Public Import Fixed-Point Gate:
     - Construct mutual public re-export imports: `Package_A` declares `public import Package_B::*;` and `Package_B` declares `public import Package_A::*;`.
     - Assert that monotonic fixed-point iteration terminates deterministically within finite iterations with zero stack overflows.
     - If circular import cycles are restricted by architectural policy, assert deterministic emission of diagnostic error code `E0203` (`CircularImportCycle`).
  8. Error Accumulation & Sink Capacity Gate (Architectural Directive 4):
     - Ingest an AST model containing $`C_{\text{max\_errors}} + 1`$ invalid import declarations.
     - Assert that diagnostics are accumulated with exact source spans up to $`C_{\text{max\_errors}}`$.
     - Assert graceful termination with diagnostic error code `E0199` upon sink saturation.
  9. Deterministic UUIDv5 Anchor Gate (Architectural Directive 1):
     - Assert that 100% of import declaration relation nodes and imported membership proxy entities possess valid RFC 4122 UUIDv5 identifiers derived from `OID_DEAP` and their canonical fully qualified path per REQ-0010.
  10. Release Mode Latency & Memory Budget Gate (Architectural Directive 5):
     - In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196, benchmark import evaluation across an AST model comprising $`10^5`$ imported symbol references across 500 packages.
     - Assert zero panics, total-function execution, execution latency strictly under 25 ms, and peak RSS memory strictly under 100 MB.
  11. Bitwise Determinism & Zero Diff Churn Gate:
     - Re-run import evaluation 10 consecutive times on identical AST inputs.
     - Assert that symbol tables, node handles, diagnostics, and UUIDv5 assignments are 100% bitwise identical with zero diff churn.
