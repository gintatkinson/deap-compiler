## 1. Normative Statement

The ICD engine of Subsystem 8 SHALL evaluate static timing and propagate Worst-Case Execution Times (WCET) across interconnect latency paths using analyzer `WCET_Engine_0`.

The pipeline MUST enforce:
1. **Path Modeling**: Chains `Chain_0` model as paths $\pi = \langle v_1, e_1, \dots, e_{k-1}, v_k \rangle$ (`LatencyPath_Alpha`) over $G_{\text{comm}} = (V, E)$. Origin $v_1$ (`Node_0`) models $t_{\text{acquire}}$ and $t_{\text{compute}}$; egress $v_k$ (`Node_1`) models $t_{\text{compute}}$ and $t_{\text{actuate}}$; hops $e_j$ (`InterconnectHop_1`) model $t_{\text{transport}}$. Missing nodes (`Node_k`) emit `E0200`.
2. **Transport Decomposition**: Hop latency $t_{\text{transport}}(e) = t_{\text{serial}}(e) + t_{\text{prop}}(e) + t_{\text{queue}}(e)$ aggregates serialization, propagation, and scheduling delays.
3. **Cumulative WCET & DAG Critical Path**: Cumulative latency $t_{\text{end\_to\_end}}(\pi)$ sums node WCETs and hop delays; critical paths in DAGs evaluate via topological dynamic programming.
4. **Deadline & Jitter Gate**: Chains with $t_{\text{critical}} \gt T_{\text{deadline}}$, jitter $J \gt J_{\text{max}}$, or unbuffered cycles emit `E0213`, bind sentinel $\bot_{\text{latency}}$, and halt.
5. **Directives**: UUIDv5 anchors (Directive 1); work-stealing ceiling $N_{\text{max\_workers}}$ (Directive 2); symbol interning (Directive 3); delimiter recovery halting at $C_{\text{max\_errors}}$ with `E0199` (Directive 4); release performance isolation (Directive 5). Placeholders (`Package_0`, `LatencyPath_Alpha`, `WCET_Engine_0`, `InterconnectHop_1`, `Node_0`, `Node_1`, `Node_k`, `Chain_0`, `Chain_Alpha`, `param_x : Real`) used.

## 2. Formal Invariant

Let $G_{\text{comm}} = (V, E)$ be the communication DAG. The WCET propagation, DAG critical path recurrence, and diagnostic triggers satisfy:

```math
\begin{aligned}
t_{\text{transport}}(e)&=t_{\text{serial}}(e)+t_{\text{prop}}(e)+t_{\text{queue}}(e) \\
t_{\text{end\_to\_end}}(\pi)&=t_{\text{acquire}}(v_1)+\sum_{i=1}^k t_{\text{compute}}(v_i)+\sum_{j=1}^{k-1} t_{\text{transport}}(e_j)+t_{\text{actuate}}(v_k) \\
\text{dist}(u)&=\begin{cases}t_{\text{acquire}}(u)+t_{\text{compute}}(u),&u\in V_{\text{in}}\land\text{InEdges}(u)=\emptyset \\ t_{\text{compute}}(u)+\max_{e=(w,u)\in\text{InEdges}(u)}(\text{dist}(w)+t_{\text{transport}}(e)),&\text{otherwise}\end{cases} \\
t_{\text{critical}}(\mathcal{K})&=\max_{v\in V_{\text{out}}(\mathcal{K})}(\text{dist}(v)+t_{\text{actuate}}(v)) \\
\forall\mathcal{K}\in\mathcal{K}_{\text{chains}},&\quad t_{\text{critical}}(\mathcal{K})\le T_{\text{deadline}}(\mathcal{K})\land(t_{\text{critical}}^{\max}(\mathcal{K})-t_{\text{critical}}^{\min}(\mathcal{K}))\le J_{\text{max}}(\mathcal{K}) \\
(t_{\text{critical}}(\mathcal{K})\gt T_{\text{deadline}}(\mathcal{K})&\lor J(\mathcal{K})\gt J_{\text{max}}(\mathcal{K})\lor\text{HasCycle}(G_{\mathcal{K}}))\implies\text{Diagnostic}(\mathcal{K},\text{E0213})\in\mathcal{D}_{\text{sink}}\land\mathcal{K}\gets\bot_{\text{latency}} \\
(u\notin V\lor e\notin E)&\implies\text{Diagnostic}(e,\text{E0200})\in\mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}},\quad\Delta_x=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(x))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $\pi, G_{\text{comm}}$ | Latency path and communication multigraph $(V, E)$ |
| $t_{\text{compute}}, t_{\text{transport}}$ | Node WCET and hop transport latency in $\mathbb{N}_0$ |
| $t_{\text{acquire}}, t_{\text{actuate}}$ | Sensor acquisition and actuator egress latencies |
| $t_{\text{critical}}, T_{\text{deadline}}, J$ | Critical latency, deadline bound, and response jitter |
| $\bot_{\text{latency}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}$ | Sentinel, diagnostic sink, and capacity limit |
| $\Delta_x, \text{OID}_{\text{DEAP}}$ | UUIDv5 anchor and canonical namespace OID |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(|V| + |E|)$ DAG longest-path traversal over $G = (V, E)$. Parallel work-stealing pool scales as $O((|V| + |E|)/N_{\text{max\_workers}} + \log N_{\text{max\_workers}})$. Space: $O(|V| + |E|)$.
- **Tractable Subclass & Frontier:** N/A (Deterministic P). DAG dynamic programming avoids NP-hard general longest path, NP-2 packing (REQ-0147), and NP-8 solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: End-to-End Latency Propagation
- **Given:** Path `LatencyPath_Alpha` through `Node_0` ($150\,\mu\text{s}$), hop `InterconnectHop_1` ($200\,\mu\text{s}$), and `Node_1` ($200\,\mu\text{s}$).
- **When:** Lowering chain through `WCET_Engine_0`.
- **Then:** Confirms $t_{\text{end\_to\_end}} = 550\,\mu\text{s} \le 600\,\mu\text{s}$ and passes.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Exact Deadline Boundary Conformance
- **Given:** Path `LatencyPath_Alpha` with $t_{\text{end\_to\_end}} = T_{\text{deadline}} = 500\,\mu\text{s}$.
- **When:** Evaluating timing contract satisfaction.
- **Then:** Confirms $t_{\text{end\_to\_end}} \le T_{\text{deadline}}$ holds and passes.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Latency Deadline Violation Rejection
- **Given:** Chain `Chain_Alpha` with latency $550\,\mu\text{s}$ exceeding deadline $500\,\mu\text{s}$.
- **When:** Verifying response chain deadlines.
- **Then:** Fails closed, emits `E0213`, and binds sentinel $\bot_{\text{latency}}$.
- **Diagnostic:** `E0213` (LatencyDeadlineViolation).

### AC-04: Unresolved Endpoint & Error Recovery
- **Given:** Path referencing missing `Node_k` and unbuffered cycles, separated by `;`.
- **When:** Delimiter error recovery processes faults.
- **Then:** Emits `E0200` and `E0213`, and halts at $C_{\text{max\_errors}}$ with `E0199`.
- **Diagnostic:** `E0200`, `E0213`, `E0199`.

### AC-05: UUIDv5 Anchors & Performance Isolation
- **Given:** Graph with $10^4$ timing elements across $N_{\text{max\_workers}}$ threads.
- **When:** Benchmarking in Release mode (`--release`).
- **Then:** Anchors match bitwise; latency $< 25\text{ ms}$, RSS $< 100\text{ MB}$.
- **Diagnostic:** Diagnostic sink remains empty.
