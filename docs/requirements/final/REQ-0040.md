### REQ-0040: Two-Pass Symbol Hoisting & Lexical Scope Table Construction

- **Normative Statement**: The core AST engine shall execute a deterministic two-pass symbol resolution pipeline that decouples symbol declaration ordering from referencing ordering across all compilation units. Pass 1 (Symbol Hoisting) shall traverse the ingested abstract syntax tree (AST) and hoist all top-level and nested definition nodes--including packages, classifier definitions, port definitions, item definitions, connection definitions, interface definitions, action definitions, state definitions, constraint definitions, and calculation definitions--into a hierarchical lexical symbol table $`\Gamma`$. During Pass 1, the engine shall construct a tree of lexical scopes rooted at the global compilation namespace, register every declared identifier as an interned scalar `SymbolId` token in the global symbol interner pool, bind the symbol to its 32-bit arena node handle in contiguous node arena storage, and assign a deterministic RFC 4122 UUIDv5 identifier derived from the compiler namespace OID and the fully qualified topological symbol path. Pass 1 must strictly enforce lexical scope declaration uniqueness: declaring duplicate symbols with identical identifiers within the same lexical scope and visibility domain shall be prohibited and shall deterministically record structured diagnostic error code `E0200` without halting traversal.

  Pass 2 (Reference Resolution) shall traverse the AST and resolve all symbol references, cross-references, feature typings, connection endpoint paths, port references, inheritance and specialization declarations (`:>`, `:>>`), item flow payload types, and constraint variable identifiers against the hierarchical lexical symbol table $`\Gamma`$. The reference resolver must evaluate lexical scope lookups by searching inward from the local lexical scope outward through enclosing ancestor scopes up to the root global namespace, or directly via fully qualified namespace paths using double-colon path delimiters (`::`). Pass 2 shall resolve forward references and mutually recursive definitions across sibling packages and nested classifiers with complete invariance to source code text ordering or file ingestion sequence.

  If a referenced symbol cannot be resolved in any accessible lexical or qualified scope, Pass 2 shall deterministically record structured diagnostic error code `E0200`, bind a typed error sentinel $`\bot_{\text{sym}}`$ to the unresolved reference node, and proceed with resolving remaining references in accordance with total-function synchronization token recovery rules. If a reference binds ambiguously to multiple visible symbols in the same scope, Pass 2 shall deterministically record structured diagnostic error code `E0200`. Parallel hoisting and resolution across independent compilation units shall be scheduled strictly onto a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$. In accordance with Architectural Directive 3, interning string bytes into scalar `SymbolId` tokens during the lexical pass represents the sole permitted exception to zero-copy memory management. In accordance with Architectural Directive 5, the two-pass symbol engine shall maintain a deterministic, panic-free execution contract with total-function termination across all inputs, evaluating performance gates (execution latency strictly under 25 ms and peak RSS memory strictly under 100 MB) exclusively in compiled Release mode (`--release`). All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Port_1`, `Port_2`, `Usage_1`, `Flow_A`, `param_x : Real`) with zero domain contamination.

- **Formal Invariant**: Let $`\mathcal{A} = (\mathcal{V}_{\text{AST}}, \mathcal{E}_{\text{AST}})`$` denote the ingested abstract syntax graph partitioned into definition nodes `$`\mathcal{V}_{\text{defs}} \subseteq \mathcal{V}_{\text{AST}}`$` and reference nodes `$`\mathcal{V}_{\text{refs}} \subseteq \mathcal{V}_{\text{AST}}`$`, where `$`\mathcal{V}_{\text{defs}} \cap \mathcal{V}_{\text{refs}} = \emptyset`$.

  Let $`\mathcal{T}_{\text{scope}} = (\mathcal{S}, \prec, \sigma_0)`$` denote the hierarchical tree of lexical scopes, where `$`\mathcal{S}`$` is the finite set of lexical scopes, `$`\prec \;\subset \mathcal{S} \times \mathcal{S}`$` is the strict immediate parent relation, and `$`\sigma_0 \in \mathcal{S}`$` is the unique root scope (`$`\forall s \in \mathcal{S} \setminus \{ \sigma_0 \}, \exists! p \in \mathcal{S} : s \prec p`$).

  Each scope $`s \in \mathcal{S}`$` owns a local symbol dictionary `$`\mu_s : \mathcal{S}_{\text{intern}} \to \mathcal{V}_{\text{defs}} \cup \{ \bot \}`$`, where `$`\mathcal{S}_{\text{intern}}`$ is the universe of deduplicated scalar `SymbolId` interned strings.

  Pass 1 (Symbol Hoisting): The hoisting transformation $`\text{Pass}_1 : \mathcal{A} \to \Gamma`$` constructs the hierarchical symbol environment `$`\Gamma = \langle \mathcal{T}_{\text{scope}}, \mu_{\text{global}} \rangle`$:

```math
\Gamma = \text{Pass}_1(\mathcal{A}) = \bigcup_{n \in \mathcal{V}_{\text{defs}}} \{ \text{FQN}(n) \mapsto \text{Handle}(n) \}
```

  where $`\text{FQN} : \mathcal{V}_{\text{defs}} \to \mathcal{S}_{\text{FQN}}`$` maps an AST definition node to its canonical fully qualified path string, and `$`\text{Handle} : \mathcal{V}_{\text{AST}} \to \mathbb{N}_{32}`$ returns its 32-bit contiguous arena index.

  Lexical Scope Uniqueness Invariant: Within any lexical scope $`s \in \mathcal{S}`$, no two distinct definition nodes shall share the same local identifier:

```math
\forall n_1, n_2 \in \mathcal{V}_{\text{defs}}, \quad (\text{Scope}(n_1) = \text{Scope}(n_2) \wedge \text{Name}(n_1) = \text{Name}(n_2)) \implies n_1 = n_2
```

  Pass 2 (Reference Resolution): The resolution transformation $`\text{Pass}_2 : \mathcal{A} \times \Gamma \to \mathcal{A}_{\text{resolved}}`$` evaluates the binding function `$`\rho : \mathcal{V}_{\text{refs}} \times \mathcal{S} \times \Gamma \to \mathcal{V}_{\text{defs}} \cup \{ \bot_{\text{sym}} \}`$:

```math
\mathcal{A}_{\text{resolved}} = \text{Pass}_2(\mathcal{A}, \Gamma) \iff \forall r \in \mathcal{V}_{\text{refs}}, \quad \text{BindTarget}(r, \rho(r, \text{Scope}(r), \Gamma))
```

  The hierarchical lexical lookup function $`\rho(r, s, \Gamma)`$ evaluates recursively:

```math
\rho(r, s, \Gamma) = \begin{cases}
\mu_s(\text{Name}(r)), & \text{if } \mu_s(\text{Name}(r)) \ne \bot \\
\rho(r, p, \Gamma), & \text{if } \mu_s(\text{Name}(r)) = \bot \wedge (s \prec p) \\
\mu_{\text{global}}(\text{FQN}(r)), & \text{if } s = \sigma_0 \wedge \text{IsQualified}(r) \wedge \mu_{\text{global}}(\text{FQN}(r)) \ne \bot \\
\bot_{\text{sym}}, & \text{otherwise}
\end{cases}
```

  Mutual Recursion & Forward Reference Order Invariance: Let $`\text{SourcePosition} : \mathcal{V}_{\text{AST}} \to \mathbb{N}_0`$` map nodes to sequential byte offsets in the source compilation stream. For any reference `$`r \in \mathcal{V}_{\text{refs}}`$` whose target definition `$`d \in \mathcal{V}_{\text{defs}}`$` satisfies `$`\text{FQN}(d) = \text{TargetIdentifier}(r)`$:

```math
\forall r \in \mathcal{V}_{\text{refs}}, \quad \text{SourcePosition}(r) \lt \text{SourcePosition}(d) \implies \rho(r, \text{Scope}(r), \Gamma) = d
```

```math
\forall r_1, r_2 \in \mathcal{V}_{\text{refs}}, \quad (d_1 = \text{Target}(r_1) \wedge d_2 = \text{Target}(r_2) \wedge r_1 \in \text{Body}(d_2) \wedge r_2 \in \text{Body}(d_1)) \implies (\rho(r_1) = d_1 \wedge \rho(r_2) = d_2)
```

  Declaration Order Permutation Invariance: Let $`\pi : \mathcal{V}_{\text{AST}} \to \mathcal{V}_{\text{AST}}`$` be an arbitrary bijection permuting the declaration order of sibling nodes in `$`\mathcal{A}`$. The two-pass symbol pipeline yields identical symbol tables and resolved AST graphs:

```math
\begin{aligned}
\text{Pass}_1(\pi(\mathcal{A})) &\equiv \text{Pass}_1(\mathcal{A}) = \Gamma \\
\text{Pass}_2(\pi(\mathcal{A}), \Gamma) &\equiv \text{Pass}_2(\mathcal{A}, \Gamma) = \mathcal{A}_{\text{resolved}}
\end{aligned}
```

  Deterministic UUIDv5 & Arena Handle Invariant: Every hoisted definition node $`n \in \mathcal{V}_{\text{defs}}`$ receives a deterministic RFC 4122 UUIDv5 identifier and a stable 32-bit arena node handle:

```math
\begin{aligned}
\forall n \in \mathcal{V}_{\text{defs}}, \quad \text{UUID}(n) &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n)) \\
\forall n \in \mathcal{V}_{\text{AST}}, \quad \text{Handle}(n) &= \langle \text{ArenaId}, \text{Offset}_n \rangle \in \mathbb{N}_{32} \times \mathbb{N}_{32}
\end{aligned}
```

  Diagnostic Code Binding Invariant: Duplicate symbol declarations in Pass 1 and unresolvable or ambiguous references in Pass 2 deterministically record structured diagnostic records categorized under the Metamodel and Typing family ($`\mathcal{E}_{\text{type}}`$) with error code `E0200`:

```math
\begin{aligned}
\exists n_1 \ne n_2 : (\text{Scope}(n_1) = \text{Scope}(n_2) \wedge \text{Name}(n_1) = \text{Name}(n_2)) &\implies \text{Diagnostic}(n_2, \text{DiagnosticCode::E0200}, \text{DuplicateSymbolDeclaration}) \in \mathcal{D}_{\text{sink}} \\
\exists r \in \mathcal{V}_{\text{refs}} : \rho(r, \text{Scope}(r), \Gamma) = \bot_{\text{sym}} &\implies \text{Diagnostic}(r, \text{DiagnosticCode::E0200}, \text{UnresolvedSymbolReference}) \in \mathcal{D}_{\text{sink}} \\
\exists r \in \mathcal{V}_{\text{refs}} : |\text{Candidates}(r, \Gamma)| \gt 1 &\implies \text{Diagnostic}(r, \text{DiagnosticCode::E0200}, \text{AmbiguousSymbolReference}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
```

  Diagnostic Taxonomy Containment Invariant: All diagnostics emitted by the two-pass symbol engine strictly satisfy the Metamodel and Typing taxonomy range of REQ-0191:

```math
\forall d \in \mathcal{D}_{\text{symbol\_engine}}, \quad \text{code}(d) = \text{DiagnosticCode::E0200} \in \mathcal{E}_{\text{type}} \quad (\text{where } 200 \le \text{code} \le 299)
```

- **Computational Complexity & Algorithmic Bounds**: Two-pass symbol hoisting and reference resolution operates strictly within Complexity Class $`\mathbf{P}`$. The algorithmic performance bounds across pipeline phases and memory layouts are formalized as follows:

  1. Pass 1 Symbol Hoisting Bounds: For an AST comprising $`N = |\mathcal{V}_{\text{AST}}|`$` nodes and `$`N_{\text{defs}} = |\mathcal{V}_{\text{defs}}| \le N`$ definition nodes, Pass 1 traverses each AST node exactly once. Interning the identifier string into a scalar `SymbolId` token executes in amortized $`O(1)`$ time per symbol. Registering the `SymbolId` into the local scope hash table executes in amortized $`O(1)`$` time with open-addressing robin-hood hashing maintaining load factor `$`\alpha \le 0.70`$. Total time for Pass 1 is:

```math
T_{\text{Pass1}}(N) = \sum_{n \in \mathcal{V}_{\text{defs}}} O(1) + \sum_{n \in \mathcal{V}_{\text{AST}} \setminus \mathcal{V}_{\text{defs}}} O(1) = O(N)
```

  2. Pass 2 Reference Resolution Bounds: For $`N_{\text{refs}} = |\mathcal{V}_{\text{refs}}| \le N`$` reference nodes, each reference lookup traverses at most the maximum lexical nesting depth `$`D_{\text{depth}} \le 64`$`. At each scope level, hash table probe execution requires `$`O(1)`$ time. Fully qualified path lookups `p1::p2::...::pk` evaluate at most $`k \le 16`$` segment index hops, requiring `$`O(k) = O(1)`$` constant time. Thus, each reference lookup is strictly bounded by `$`O(D_{\text{depth}}) = O(1)`$, yielding total Pass 2 resolution time:

```math
T_{\text{Pass2}}(N) = \sum_{r \in \mathcal{V}_{\text{refs}}} O(D_{\text{depth}}) = O(N)
```

  3. Aggregate Sequential Execution Bound: Combining Pass 1 and Pass 2 yields total end-to-end resolution time:

```math
T_{\text{total}}(N) = T_{\text{Pass1}}(N) + T_{\text{Pass2}}(N) = O(N) + O(N) = O(N)
```

  4. Bounded Work-Stealing Parallel Bounds: For multi-file compilation units comprising $`K`$` independent packages processed concurrently over a bounded worker pool with `$`N_{\text{max\_workers}}`$ threads:

```math
T_{\text{parallel}}(N, K) \in O\left(\frac{N}{N_{\text{max\_workers}}} + K \log N_{\text{max\_workers}}\right)
```

  5. Space Complexity: The hierarchical scope table $`\Gamma`$` allocates exactly one scope descriptor per namespace/classifier node and one dictionary slot per hoisted definition, consuming `$`O(N)`$` arena storage. Auxiliary call stack depth during AST traversal is bounded by maximum tree depth `$`D_{\text{depth}} \le 64 = O(1)`$`. The diagnostic sink buffer is preallocated to bounded capacity `$`C_{\text{max\_errors}} = O(1)`$`, guaranteeing that auxiliary heap memory remains strictly `$`O(N)`$ overall.

- **Verification & Conformance Criteria**: Automated test suites shall deterministically verify compliance against synthetic abstract MBSE models (e.g., `Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Classifier_Gamma`, `Port_1`, `Port_2`, `Usage_1`, `Flow_A`, `param_x : Real`) across the following verification gates:

  1. Mutual Recursion & Forward Reference Gate: Construct two packages `Package_0` and `Package_1` where `Classifier_Alpha` in `Package_0` contains a feature typed by `Package_1::Classifier_Beta`, and `Classifier_Beta` in `Package_1` contains a feature typed by `Package_0::Classifier_Alpha`, with `Package_0` declared prior to `Package_1` in the source buffer. Assert that Pass 1 and Pass 2 resolve both cross-references to exact 32-bit arena node handles with zero diagnostics emitted.
  2. Declaration Order Invariance (Zero Diff Churn) Gate: Generate an AST containing 500 definitions and 1,000 cross-references. Construct 10 distinct permutations $`\pi_1, \dots, \pi_{10}`$ by shuffling definition declarations across files and source positions. Assert that the resulting symbol table digests and resolved AST graphs are bitwise identical across all 10 permutations with 0-byte diff churn.
  3. Duplicate Symbol Declaration Diagnostic Gate: Ingest an AST declaring two classifier definitions with identical interned name `Classifier_Alpha` within the same package `Package_0`. Assert deterministic emission of diagnostic error code `E0200` (`DuplicateSymbolDeclaration`) capturing the exact source code byte span and line/column coordinate of the second declaration, retaining the first definition handle in $`\Gamma`$, and continuing Pass 1 without panicking.
  4. Unresolved Symbol Reference Diagnostic Gate: Ingest an AST containing a feature usage referencing non-existent classifier `Classifier_Missing`. Assert deterministic emission of diagnostic error code `E0200` (`UnresolvedSymbolReference`) with exact source provenance, binding of typed sentinel $`\bot_{\text{sym}}`$, and successful completion of Pass 2.
  5. Lexical Shadowing & Fully Qualified Scope Gate: Declare attribute `param_x : Real` in enclosing package `Package_0` and declare local variable `param_x : Real` within an inner action block. Verify that unqualified reference `param_x` inside the action resolves to the local variable handle, while explicit qualified reference `Package_0::param_x` resolves to the package-level attribute handle.
  6. Ambiguous Symbol Reference Diagnostic Gate: Ingest an AST with conflicting imported symbols in a common scope; assert deterministic emission of diagnostic error code `E0200` (`AmbiguousSymbolReference`) detailing all conflicting symbol candidates.
  7. Synchronization Token Error Recovery Gate: Ingest an AST containing 20 syntax and reference errors distributed across multiple packages. Assert that the engine accumulates all 20 diagnostic records with exact byte spans and completes both passes without early abort. Inject more than $`C_{\text{max\_errors}}`$ errors and assert that the compiler emits diagnostic code `E0199` and gracefully halts analysis.
  8. Deterministic RFC 4122 UUIDv5 Anchor Gate: Verify that 100% of hoisted symbols in $`\Gamma`$ possess deterministic UUIDv5 identifiers computed from fixed namespace OID and canonical fully qualified paths per Directive 1 and REQ-0010.
  9. Bounded Work-Stealing Parallel Execution Gate: Execute two-pass resolution across $`10^4`$` synthetic definitions distributed across 50 compilation units using a bounded work-stealing thread pool (`$`N_{\text{max\_workers}} = 8`$); assert zero data races, thread-isolated arena chunk allocation, and bitwise deterministic output matching single-threaded baseline.
  10. String Interner Memory Allocation Exception Gate: Verify that string bytes are copied exclusively into the global symbol interner pool to allocate scalar `SymbolId` tokens per Directive 3 and REQ-0036, and that zero additional string copies occur during scope construction or reference resolution.
  11. Panic-Free Execution Contract & Release Mode Budget Gate: In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per Directive 5 and REQ-0196, benchmark two-pass resolution on an AST of $`10^5`$ nodes; assert total execution latency strictly under 25 ms, peak RSS memory strictly under 100 MB, and zero panics across pathologically cyclic and malformed inputs.
