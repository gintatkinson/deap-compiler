### REQ-0036: Concurrent String Interning & Scalar Symbol Deduplication Architecture

- **Normative Statement**: The core compiler platform, lexical analysis front-end, and abstract syntax tree (AST) engine shall intern all identifier strings, type names, keyword tokens, docstrings, and qualified path segments across all compilation units into a thread-safe, high-throughput concurrent string interner pool, mapping each distinct string occurrence to a compact 32-bit scalar symbol handle ($`\text{sizeof}(\sigma) \le 4\text{ bytes}`$`) supporting `$`O(1)`$` constant-time scalar equality comparisons. Slicing and copying string bytes from read-only memory-mapped source file buffers into this global deduplicated symbol interner pool during the initial lexical scanning pass shall constitute the sole permitted architectural exception to the zero-copy invariant, as mandated by Architectural Directive 3 and REQ-0009. All subsequent AST nodes, intermediate representations, symbol tables, lexical scope environments, and graph structures shall strictly store, reference, and pass 32-bit scalar symbol handles (`$`\text{SymbolId}`$`) rather than heap-allocated string objects or dynamic string clones. The string interner engine shall provide a bijective bidirectional mapping: forward interning (`$`\text{intern}(s) \to \sigma`$`) mapping any arbitrary UTF-8 byte slice to its unique scalar symbol identifier, and reverse resolution (`$`\text{resolve}(\sigma) \to \&\text{str}`$`) returning a borrowed immutable byte slice from the interner pool's contiguous backing storage without dynamic string allocation. Concurrent access across multiple worker threads shall be supported via a thread-safe, non-blocking or partitioned sharded synchronization architecture integrated with the compiler's bounded work-stealing thread pool (`$`N_{\text{max\_workers}}`$`), as mandated by Architectural Directive 2 and REQ-0012, guaranteeing data-race freedom with zero deadlocks and bounded lock contention. The symbol interner pool shall enforce a maximum scalar capacity bound of `$`S_{\text{max\_count}} = 2^{32} - 2`$` unique symbols and an individual string byte length limit of `$`L_{\text{max\_str}} = 65536\text{ bytes}`$`. In accordance with Architectural Directive 5, the interning interface must operate as a total function: invalid UTF-8 byte sequences, string slices exceeding `$`L_{\text{max\_str}}`$, or pool capacity exhaustion shall deterministically log structured diagnostic error code `E0200` per REQ-0191 and yield a typed sentinel handle $`\bot_{\text{sym}} = 2^{32}-1`$ without unhandled panics or stack unwinding. The compiler shall operate strictly on abstract MBSE formalisms using synthetic placeholders (e.g., `Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`) with zero domain contamination.

- **Formal Invariant**: Let $`\Sigma = \{0, 1, \dots, 255\}`$` denote the byte alphabet, and let `$`\mathcal{S} \subset \Sigma^*`$` represent the set of all well-formed UTF-8 encoded character strings bounded by maximum byte length `$`L_{\text{max\_str}} \in \mathbb{N}`$:

```math
\mathcal{S} = \{ s \in \Sigma^* \mid \text{ValidUTF8}(s) \;\wedge\; |s| \le L_{\text{max\_str}} \}
```

Let $`\text{SymbolId}`$` denote the set of 32-bit unsigned scalar symbol handles bounded by maximum capacity `$`S_{\text{max\_count}} = 2^{32} - 2`$`, with reserved sentinel handle `$`\bot_{\text{sym}} = 2^{32} - 1`$:

```math
\text{SymbolId} = \{ \sigma \in \mathbb{N}_0 \mid 0 \le \sigma \lt 2^{32} - 1 \}
```

Handle Memory Footprint Bound Invariant:

```math
\forall \sigma \in \text{SymbolId} \cup \{ \bot_{\text{sym}} \}, \quad \text{sizeof}(\sigma) \le S_{\max} = 4\text{ bytes}
```

The global concurrent string interner pool is formalized as a stateful bi-directional dictionary:

```math
\mathcal{I} = (\mathcal{M}_{\text{fwd}}, \mathcal{M}_{\text{rev}}, \mathcal{B}_{\text{pool}})
```

where $`\mathcal{M}_{\text{fwd}} : \mathcal{S} \to \text{SymbolId}`$` is the forward intern lookup mapping, `$`\mathcal{M}_{\text{rev}} : \text{SymbolId} \to \mathcal{S}`$` is the reverse resolution mapping, and `$`\mathcal{B}_{\text{pool}}`$ is the contiguous append-only byte storage buffer backing all interned string payloads.

Forward Interning Operator:
The interning operator $`\text{intern} : \mathcal{I} \times \Sigma^* \to (\mathcal{I} \times (\text{SymbolId} \cup \{ \bot_{\text{sym}} \}))`$ is formalized as:

```math
\text{intern}(\mathcal{I}, s) = 
\begin{cases}
(\mathcal{I}, \mathcal{M}_{\text{fwd}}(s)), & \text{if } s \in \text{dom}(\mathcal{M}_{\text{fwd}}) \\
(\mathcal{I}', \sigma_{\text{new}}), & \text{if } s \in \mathcal{S} \setminus \text{dom}(\mathcal{M}_{\text{fwd}}) \;\wedge\; |\text{dom}(\mathcal{M}_{\text{fwd}})| \lt S_{\text{max\_count}} \\
(\mathcal{I}, \bot_{\text{sym}}), & \text{otherwise}
\end{cases}
```

where $`\mathcal{I}'`$ denotes the updated interner pool state satisfying:

```math
\begin{aligned}
\sigma_{\text{new}} &= |\text{dom}(\mathcal{M}_{\text{fwd}})| \\
\mathcal{M}_{\text{fwd}}' &= \mathcal{M}_{\text{fwd}} \cup \{ (s, \sigma_{\text{new}}) \} \\
\mathcal{M}_{\text{rev}}' &= \mathcal{M}_{\text{rev}} \cup \{ (\sigma_{\text{new}}, s) \}
\end{aligned}
```

Reverse Resolution Operator:
The reverse resolution operator $`\text{resolve} : \mathcal{I} \times \text{SymbolId} \to \mathcal{S} \cup \{ \bot_{\text{sym}} \}`$ satisfies:

```math
\text{resolve}(\mathcal{I}, \sigma) = 
\begin{cases}
\mathcal{M}_{\text{rev}}(\sigma), & \text{if } \sigma \in \text{dom}(\mathcal{M}_{\text{rev}}) \\
\bot_{\text{sym}}, & \text{otherwise}
\end{cases}
```

Bijective Round-Trip Invariant:
For all registered strings in the symbol interner pool, forward interning and reverse resolution form an exact identity:

```math
\forall s \in \text{dom}(\mathcal{M}_{\text{fwd}}), \quad \text{resolve}(\mathcal{I}, \text{intern}(\mathcal{I}, s)) = s
```

```math
\forall \sigma \in \text{dom}(\mathcal{M}_{\text{rev}}), \quad \text{intern}(\mathcal{I}, \text{resolve}(\mathcal{I}, \sigma)) = \sigma
```

Scalar Integer Equality Invariant:
Equivalence between any two interned strings reduces strictly to primitive 32-bit scalar integer equality, eliminating all string character scan iterations during AST traversal, type checking, and symbol resolution:

```math
\forall s_1, s_2 \in \text{dom}(\mathcal{M}_{\text{fwd}}), \quad s_1 = s_2 \iff \text{intern}(\mathcal{I}, s_1) = \text{intern}(\mathcal{I}, s_2)
```

Deduplication and Idempotence Invariant:
Every unique string payload is stored exactly once in the backing memory buffer, guaranteeing zero redundant duplicate string allocations:

```math
\forall s \in \text{dom}(\mathcal{M}_{\text{fwd}}), \quad |\{ \sigma \in \text{dom}(\mathcal{M}_{\text{rev}}) \mid \mathcal{M}_{\text{rev}}(\sigma) = s \}| = 1
```

Architectural Directive 3 Buffer Allocation Boundary Invariant:
Let $`\mathcal{B}_{\text{file}}`$` denote a contiguous read-only memory-mapped source file buffer. Let `$`\text{HeapAllocs}(\mathcal{P})`$` denote the set of individual dynamic heap allocations performed across the compilation pipeline `$`\mathcal{P}`$`, and let `$`\text{Storage}(\text{StringInternerPool})`$` denote the memory allocations backing `$`\mathcal{I}`$`. Copying string bytes from `$`\mathcal{B}_{\text{file}}`$` into `$`\mathcal{B}_{\text{pool}}`$ during the initial lexical pass represents the sole permitted exception to zero-copy memory management:

```math
\text{HeapAllocs}(\text{ParsePass}(\mathcal{B}_{\text{file}})) \subseteq \text{Storage}(\text{StringInternerPool})
```

All remaining AST nodes, graph edges, token slices, and compiler data structures reside within contiguous bump arena storage $`\mathcal{A}_{\text{arena}}`$` (per REQ-0009 and REQ-0034) or borrow immutable byte slices directly from `$`\mathcal{B}_{\text{file}}`$:

```math
\text{HeapAllocs}(\text{ParsePass}(\mathcal{B}_{\text{file}})) \setminus \text{Storage}(\text{StringInternerPool}) = \emptyset
```

Concurrency Invariant under Bounded Work-Stealing:
Let $`\mathcal{T}_{\text{workers}} = \{ t_1, t_2, \dots, t_K \}`$` be the set of concurrent worker threads scheduled by the bounded work-stealing thread pool, where `$`K \le N_{\text{max\_workers}}`$` (per REQ-0012). For any two threads `$`t_a, t_b`$` concurrently interning an identical string `$`s`$:

```math
\forall t_a, t_b \in \mathcal{T}_{\text{workers}}, \quad \text{intern}_{t_a}(\mathcal{I}, s) = \text{intern}_{t_b}(\mathcal{I}, s)
```

and the concurrent interner maintains strict data-race freedom:

```math
\text{DataRaces}(\mathcal{I}) = 0
```

Diagnostic Code Binding Invariant:
Violations of UTF-8 encoding well-formedness, string token byte length boundaries, or symbol pool capacity deterministically trigger structured diagnostics in accordance with REQ-0191:

```math
\begin{aligned}
\neg\text{ValidUTF8}(s) &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0200}, \text{InvalidUTF8Encoding}) \in \mathcal{D} \;\wedge\; \text{intern}(\mathcal{I}, s) = \bot_{\text{sym}} \\
|s| \gt L_{\text{max\_str}} &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0200}, \text{SymbolLengthExceeded}) \in \mathcal{D} \;\wedge\; \text{intern}(\mathcal{I}, s) = \bot_{\text{sym}} \\
|\text{dom}(\mathcal{M}_{\text{fwd}})| \ge S_{\text{max\_count}} &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0200}, \text{InternerCapacityExhausted}) \in \mathcal{D} \;\wedge\; \text{intern}(\mathcal{I}, s) = \bot_{\text{sym}}
\end{aligned}
```

Diagnostic Taxonomy Containment Invariant:
All emitted diagnostic records strictly reside within the Metamodel and Typing error family:

```math
\forall D \in \mathcal{D}_{\text{interner}}, \quad \text{code}(D) \in \{ \text{DiagnosticCode::E0200} \} \subset \mathcal{E}_{\text{type}}
```

Parameter Definitions:
- $`\sigma`$`: Compact 32-bit unsigned scalar symbol handle (`$`\text{SymbolId}`$).
- $`S_{\max}`$`: Maximum handle memory footprint bound (`$`4\text{ bytes}`$, or 32-bit unsigned integer).
- $`S_{\text{max\_count}}`$`: Maximum allowable distinct interned symbols (`$`2^{32} - 2`$).
- $`L_{\text{max\_str}}`$`: Maximum byte length for an individual string token (`$`65536\text{ bytes}`$).
- $`\bot_{\text{sym}}`$`: Typed sentinel error symbol handle (`$`2^{32} - 1`$).
- $`\mathcal{B}_{\text{pool}}`$: Contiguous backing byte buffer allocated for interned strings.
- $`N_{\text{max\_workers}}`$: Upper bound on worker threads in the work-stealing pool.

- **Computational Complexity & Algorithmic Bounds**: String interning and scalar deduplication operations execute strictly within Complexity Class $`\mathbf{P}`$`. For an input token sequence containing `$`N_{\text{tokens}}`$` string occurrences with total byte volume `$`M = \sum_{i=1}^{N_{\text{tokens}}} |s_i|`$` and `$`N_{\text{unique}}`$` unique string values (`$`N_{\text{unique}} \le N_{\text{tokens}}`$), algorithmic execution adheres to the following exact bounds:
1. Initial String Interning (First Insertion): Computing a 64-bit non-cryptographic hash over string $`s_i`$` takes `$`O(|s_i|)`$` operations. Shard selection and hash table bucket probing take `$`O(1)`$` expected amortized operations. Appending `$`|s_i|`$` bytes into contiguous buffer `$`\mathcal{B}_{\text{pool}}`$` and inserting the new `$`(\sigma, s_i)`$` pair take `$`O(|s_i|)`$ amortized time.
2. Subsequent Interning Queries: Hashing takes $`O(|s_i|)`$` time. Table lookup in the open-addressing or Robin Hood hash table executes in `$`O(1)`$` expected comparisons with fast 64-bit integer hash equality checks and byte verification, yielding `$`O(|s_i|)`$ time overall.
3. Reverse Symbol Resolution: Querying $`\text{resolve}(\mathcal{I}, \sigma)`$` executes in strict `$`O(1)`$` worst-case constant time, performing a direct array index dereference using scalar offset `$`\sigma`$` into `$`\mathcal{M}_{\text{rev}}`$` to return an immutable borrowed byte slice into `$`\mathcal{B}_{\text{pool}}`$ with zero heap allocations.
4. Scalar Equality Comparison: Evaluating $`\sigma_1 == \sigma_2`$` between any two interned symbols executes in strict `$`O(1)`$ worst-case constant time via a single machine instruction (32-bit CPU register comparison), completely bypassing string dereferencing and character iteration loops.

Total sequential time complexity across all $`N_{\text{tokens}}`$ string tokens during the lexical and parsing passes is strictly linear in input byte volume:

```math
T(N_{\text{tokens}}, M) \in O\left( \sum_{i=1}^{N_{\text{tokens}}} |s_i| \right) = O(M)
```

Parallel Interning Throughput: When $`K`$` files or token batches are processed concurrently across `$`N_{\text{max\_workers}}`$` threads scheduled on the bounded work-stealing thread pool, the concurrent interner partitions its internal hash map across `$`P`$` disjoint shards (`$`P \ge 2 \cdot N_{\text{max\_workers}}`$`). Lock contention across distinct shards is bounded by `$`O(1)`$ amortized overhead, yielding parallel wall-clock runtime:

```math
T_{\text{parallel}}(N_{\text{tokens}}, M) \in O\left( \left\lceil \frac{N_{\text{tokens}}}{N_{\text{max\_workers}}} \right\rceil \cdot \bar{L} \right)
```

where $`\bar{L} = M / N_{\text{tokens}}`$ is the average token byte length.

Space Complexity & Memory Footprint Bounds:
Auxiliary memory consumption is strictly bounded by $`O(U + N_{\text{unique}})`$` space, where `$`U = \sum_{u \in \text{dom}(\mathcal{M}_{\text{fwd}})} |u|`$` is the aggregate byte size of all unique interned string payloads and `$`N_{\text{unique}}`$` is the number of distinct symbol handles. Redundant string storage across the AST is reduced from `$`O(N_{\text{tokens}} \cdot \bar{L})`$` to `$`O(U + 4 \cdot N_{\text{tokens}})`$`. In typical MBSE abstract syntax models with token repetition factors `$`\rho = N_{\text{tokens}} / N_{\text{unique}} \ge 5`$, replacing 24-byte pointer/length/capacity string descriptors with compact 4-byte scalar `SymbolId` handles reduces total AST node memory footprint by greater than 60%.

- **Verification & Conformance Criteria**: Automated test suites shall deterministically verify compliance against synthetic MBSE compilation units using abstract placeholders (e.g., `Package_0`, `Classifier_Alpha`, `Classifier_Beta`, `Port_0`, `Port_1`, `Flow_A`, `Flow_B`, `param_x : Real`). Conformance shall be validated through the following deterministic test gates:
1. Deduplication and Scalar Equality Gate: Intern a corpus of $`10^5`$ AST tokens with high identifier redundancy (e.g., 500 unique synthetic MBSE symbols such as `Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x` repeated 200 times). Assert that identical string tokens map to the exact same 32-bit `SymbolId` scalar value. Assert via compiler profiling that 100% of identifier comparisons during type checking, lexical scope lookup, AST slicing, and symbol resolution execute as primitive 32-bit integer comparisons with zero character-by-character string comparisons.
2. Zero-Copy Invariant & Heap Allocation Boundary Gate (Architectural Directive 3): Instrument the compiler memory allocator during front-end lexical scanning and parsing passes (`ParsePass`). Assert that 100% of individual dynamic heap allocations performed during parsing originate strictly within the global symbol interner pool (`Storage(StringInternerPool)`). Assert that all other AST nodes, tokens, and structural collections reside in contiguous bump arenas (REQ-0009, REQ-0034) or borrow slices from read-only memory-mapped source buffers with zero intermediate heap string copies.
3. Bidirectional Resolution & Inversion Fidelity Gate: For all $`N_{\text{unique}}`$` interned symbols, assert that calling `$`\text{resolve}(\text{intern}(s))`$` reconstructs the exact original UTF-8 string slice byte-for-byte. Assert that calling `$`\text{intern}(\text{resolve}(\sigma))`$` returns the identical scalar handle `$`\sigma`$.
4. Concurrent Multi-Threaded Interning Gate (Architectural Directive 2): Execute concurrent symbol interning across $`N_{\text{max\_workers}}`$` threads scheduled on a bounded work-stealing thread pool. Concurrently intern overlapping sets of `$`5 \times 10^4`$` synthetic identifiers from multiple threads. Assert zero data races, zero deadlocks, and that handles assigned to identical strings across distinct threads are identical (`$`\sigma_a = \sigma_b`$).
5. Memory Footprint Reduction Gate: Measure total memory consumption of an AST graph containing $`2 \times 10^5`$ nodes with string identifiers represented as 4-byte `SymbolId` handles against a baseline model representing identifiers as dynamic heap strings. Assert that the scalar symbol deduplication architecture achieves an AST memory footprint reduction exceeding 60%.
6. Total Function & Diagnostic Error Handling Gate (Architectural Directive 5): Submit pathological inputs to the interner:
   - Malformed byte slices containing invalid UTF-8 sequences (e.g., unexpected continuation bytes `0x80`, overlong encodings `0xC0 0xAF`); assert deterministic emission of diagnostic error code `E0200` (`InvalidUTF8Encoding`) and return of sentinel handle $`\bot_{\text{sym}}`$.
   - Oversized string slices exceeding $`L_{\text{max\_str}} = 65536\text{ bytes}`$; assert deterministic emission of diagnostic error code `E0200` (`SymbolLengthExceeded`) and return of sentinel $`\bot_{\text{sym}}`$.
   - Interner pool capacity saturation: simulate pool capacity reaching $`S_{\text{max\_count}}`$; assert deterministic emission of diagnostic error code `E0200` (`InternerCapacityExhausted`) and return of sentinel $`\bot_{\text{sym}}`$.
   Assert zero unhandled panics or stack unwinding exceptions across all fault injection paths.
7. Property-Based Fuzzing Gate: Execute $`10^5`$ random byte sequences and mutations through the interner interface; assert total-function termination, zero memory leaks, and zero undefined behavior.
8. Release Mode Latency & Throughput Benchmark Gate (Architectural Directive 5): In compiled Release mode (`--release`), benchmark the concurrent string interner under dedicated benchmark harnesses isolated from CI logic tests. Assert that single-thread interning throughput exceeds $`5 \times 10^6\text{ tokens/s}`$`, multi-threaded throughput across `$`N_{\text{max\_workers}}`$` threads exceeds `$`2 \times 10^7\text{ tokens/s}`$`, and reverse resolution latency is under `$`20\text{ ns}`$ per operation.
9. Bitwise Determinism Gate: Assert that interning an identical ordered sequence of AST tokens across separate compiler runs produces bitwise identical `SymbolId` assignments and deterministic symbol tables with zero diff churn.
