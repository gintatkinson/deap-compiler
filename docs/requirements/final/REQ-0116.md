### REQ-0116: Temporal Relation Composition Table & Path Consistency Constraint Propagation

- **Normative Statement**: The spatio-temporal dynamics solver and discrete state machine verification pipeline of Subsystem 6 shall implement an axiomatic constraint propagation engine based on Allen's $`13 \times 13`$ temporal interval relation composition table to deduce implied qualitative temporal relations across indirect interval pairs, compute the path-consistent transitive closure over temporal constraint networks, and detect latent temporal conflicts at compile time.

  Specifically, the temporal dynamics solver, relation composition engine, and path consistency propagator shall strictly enforce the following structural, algebraic, and diagnostic requirements:
  1. **Temporal Constraint Network (TCN) Model & Matrix Representation**:
     - The dynamics solver shall model the temporal relationships among occurrence lifecycles, action executions, and discrete state occupancies as a directed Temporal Constraint Network (TCN) $`\mathcal{G}_{\text{TCN}} = (\mathcal{V}_I, \mathcal{E}_C)`$, where $`\mathcal{V}_I = \{ X_1, X_2, \dots, X_N \}`$ is the set of $`N`$ temporal interval vertices and $`\mathcal{E}_C`$ is the set of directed binary constraint edges.
     - The network constraints shall be represented as a dense $`N \times N`$ relation matrix $`\mathbf{M} \in (2^{\mathcal{B}_{13}})^{N \times N}`$ allocated in contiguous bump arena storage, where each entry $`\mathbf{M}[i, j] = R(X_i, X_j) \subseteq \mathcal{B}_{13}`$ denotes the set of allowable qualitative relations holding between interval $`X_i`$ and interval $`X_j`$.
     - Each matrix cell $`\mathbf{M}[i, j]`$ shall be encoded as an immutable 13-bit integer bitmask $`\mathbf{m}_{ij} \in [0, 8191]`$ corresponding to the power set of Allen's 13 basic relations $`\mathcal{B}_{13} = \{ \mathbf{b}, \mathbf{bi}, \mathbf{m}, \mathbf{mi}, \mathbf{o}, \mathbf{oi}, \mathbf{s}, \mathbf{si}, \mathbf{d}, \mathbf{di}, \mathbf{f}, \mathbf{fi}, \mathbf{eq} \}`$.
     - The relation matrix shall be initialized according to the following canonical baseline rules:
       * Reflexive Identity: For all $`i \in \{1, \dots, N\}`$, $`\mathbf{M}[i, i] \leftarrow \{ \mathbf{eq} \}`$ (bitmask $`0\text{x}1000`$).
       * Declared Constraints: For each asserted binary constraint $`C(X_i, X_j) = R_{\text{asserted}}`$, $`\mathbf{M}[i, j] \leftarrow R_{\text{asserted}}`$ and $`\mathbf{M}[j, i] \leftarrow (R_{\text{asserted}})^\smile`$, where $`(-)^\smile`$ denotes the relational converse involution.
       * Unconstrained Pairs: For all undeclared pairs with $`i \ne j`$, $`\mathbf{M}[i, j] \leftarrow \mathcal{B}_{13}`$ (the universal relation mask $`\mathbf{U} = 0\text{x}1\text{FFF}`$).
  2. **Allen's $`13 \times 13`$ Composition Table Architecture**:
     - The solver shall maintain a static, immutable, compile-time composition lookup table $`\mathbf{T}_{\text{comp}}: \mathcal{B}_{13} \times \mathcal{B}_{13} \to 2^{\mathcal{B}_{13}}`$ containing the exact compositions of all $`13 \times 13 = 169`$ pairs of atomic basic relations.
     - For any two basic relations $`r_1, r_2 \in \mathcal{B}_{13}`$, $`\mathbf{T}_{\text{comp}}[r_1][r_2]`$ shall return the 13-bit bitmask encoding all basic relations $`r_3 \in \mathcal{B}_{13}`$ that can hold between intervals $`X`$ and $`Z`$ given that $`X \, r_1 \, Y`$ and $`Y \, r_2 \, Z`$ hold for some interval $`Y`$.
     - For general disjunctive qualitative relations $`R_1, R_2 \subseteq \mathcal{B}_{13}`$, the composition operator $`\circ`$ shall be computed as the relational union over atomic compositions:

$$
R_1 \circ R_2 = \bigcup_{r_1 \in R_1} \bigcup_{r_2 \in R_2} \mathbf{T}_{\text{comp}}[r_1][r_2]
$$

       implemented in hardware bitwise operations by iterating over the active bits of $`R_1`$ and $`R_2`$ and accumulating bitwise OR operations.
     - The composition table and operator shall strictly satisfy the following algebraic laws:
       * Right and Left Identity: For all $`R \subseteq \mathcal{B}_{13}`$, $`R \circ \{ \mathbf{eq} \} \equiv R`$ and $`\{ \mathbf{eq} \} \circ R \equiv R`$.
       * Annihilation by Empty Relation: For all $`R \subseteq \mathcal{B}_{13}`$, $`R \circ \emptyset \equiv \emptyset`$ and $`\emptyset \circ R \equiv \emptyset`$.
       * Converse Transposition Duality: For all $`R_1, R_2 \subseteq \mathcal{B}_{13}`$, $`(R_1 \circ R_2)^\smile \equiv R_2^\smile \circ R_1^\smile`$.
       * Associativity: For all $`R_1, R_2, R_3 \subseteq \mathcal{B}_{13}`$, $`(R_1 \circ R_2) \circ R_3 \equiv R_1 \circ (R_2 \circ R_3)`$.
  3. **Path Consistency (3-Consistency) Propagation Algorithm**:
     - The dynamics solver shall implement a queue-driven path consistency constraint propagation algorithm (Mackworth's PC-2 / Allen's path consistency algorithm) to compute the transitive closure of qualitative temporal constraints across all triples of intervals $`(X_i, X_k, X_j)`$.
     - A worklist FIFO queue $`Q`$ shall maintain directed node pairs $`(i, j)`$ whose relation constraint $`\mathbf{M}[i, j]`$ has been restricted.
     - The queue $`Q`$ shall be initialized with all directed pairs $`(i, j)`$ with $`i \ne j`$ whose initial relation $`\mathbf{M}[i, j]`$ is strictly more restrictive than the universal relation $`\mathbf{U}`$ ($`\mathbf{M}[i, j] \ne \mathbf{U}`$).
     - While $`Q`$ is non-empty, the algorithm shall dequeue a pair $`(i, j)`$ and inspect all third vertices $`k \in \{1, \dots, N\} \setminus \{i, j\}`$:
       * Triangle $`(k, i, j)`$: Refine relation $`\mathbf{M}[k, j] \leftarrow \mathbf{M}[k, j] \cap (\mathbf{M}[k, i] \circ \mathbf{M}[i, j])`$.
       * Triangle $`(i, j, k)`$: Refine relation $`\mathbf{M}[i, k] \leftarrow \mathbf{M}[i, k] \cap (\mathbf{M}[i, j] \circ \mathbf{M}[j, k])`$.
     - Whenever a relation $`\mathbf{M}[u, v]`$ is strictly narrowed to a proper subset ($`\mathbf{M}_{\text{new}}[u, v] \subset \mathbf{M}_{\text{old}}[u, v]`$):
       * The symmetric converse cell shall be updated synchronously: $`\mathbf{M}[v, u] \leftarrow (\mathbf{M}[u, v])^\smile`$.
       * The modified pair $`(u, v)`$ shall be enqueued onto $`Q`$ if not already present.
  4. **Fixed-Point Convergence & Monotonic Pruning Invariants**:
     - The propagation loop shall execute until $`Q`$ becomes empty, establishing a stable fixed point where no further relation pruning can occur across any triangle in the network:

$$
\forall i, j, k \in \{1, \dots, N\}, \quad \mathbf{M}[i, j] \subseteq \mathbf{M}[i, k] \circ \mathbf{M}[k, j]
$$

     - The solver shall guarantee monotonic non-increasing refinement: For every pair $`(i, j)`$ and every step $`t`$, $`\mathbf{M}^{(t+1)}[i, j] \subseteq \mathbf{M}^{(t)}[i, j]`$.
     - Because each entry $`\mathbf{M}[i, j]`$ contains at most 13 basic relations, any cell can be pruned at most 13 times, guaranteeing deterministic finite termination in at most $`13 \cdot N(N - 1)`$ queue insertions.
  5. **Latent Conflict Detection, Diagnostic Reporting & Typed Sentinels**:
     - If at any step of path consistency propagation a relation intersection evaluates to the empty set ($`\mathbf{M}[i, j] \cap (\mathbf{M}[i, k] \circ \mathbf{M}[k, j]) = \emptyset`$), the solver shall detect a latent temporal conflict.
     - The compiler shall deterministically reject the inconsistent model with diagnostic error code `E0400` (`PathConsistencyViolation`), reporting:
       * The exact conflicting triad $`\langle X_i, X_k, X_j \rangle`$ and their fully qualified topological paths.
       * The direct constraint $`\mathbf{M}[i, j]`$ versus the indirect implied relation $`\mathbf{M}[i, k] \circ \mathbf{M}[k, j]`$.
       * The source code spans and file provenance of the participating occurrence lifecycles and temporal assertions.
     - Upon detecting a contradiction, the solver shall substitute a typed error sentinel $`\bot_{\text{tcn}}`$ for the invalid network component to suppress downstream cascading diagnostics across dependent subsystems.
  6. **Compliance with the 5 Executive Architectural Directives**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every temporal interval vertex, asserted constraint edge, deduced relation cell, and TCN graph container shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical DEAP namespace OID and node fully qualified topological path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))`$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel path consistency propagation across independent packages, decoupled occurrence trees, or disjoint temporal network components shall execute exclusively on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: Occurrence identifiers, interval names, qualitative relation mnemonic tokens (`before`, `meets`, `overlaps`, etc.), and diagnostic tags shall be interned into the deduplicated global symbol interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The dynamics solver shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When semantic temporal violations occur (`E0400`), diagnostics shall accumulate in the error sink buffer $`\mathcal{D}_{\text{sink}}`$, substitute typed error sentinels ($`\bot_{\text{tcn}}`$, $`\bot_{\text{rel}}`$), and continue validating subsequent temporal networks. If accumulated diagnostics reach $`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully in accordance with REQ-0013 and REQ-0016.
     - *Directive 5 (Panic-Free Release Isolation)*: The temporal path consistency engine shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Verification latency ($`\lt 25\text{ ms}`$ for networks of $`10^2`$ intervals) and peak RSS memory ($`\lt 100\text{ MB}`$) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.

- **Computational Complexity & Algorithmic Bounds**: Qualitative temporal relation composition and path consistency constraint propagation execute strictly within **Complexity Class P** (Deterministic Polynomial Time).

  For an abstract MBSE temporal model containing $`N = |\mathcal{V}_I|`$ temporal interval occurrences and $`M = |\mathcal{E}_C|`$ declared qualitative relation assertions:
  1. *Relation Matrix Allocation & Initialization*:
     Allocating and initializing the dense $`N \times N`$ relation bitmask matrix $`\mathbf{M}`$, setting the diagonal to $`\{ \mathbf{eq} \}`$ and off-diagonal cells to the universal mask $`\mathbf{U}`$, requires inspecting $`N^2`$ cells:

$$
T_{\text{init}}(N) \in O(N^2)
$$

  2. *Constraint Ingestion & Converse Symmetry Normalization*:
     Writing $`M`$ asserted qualitative constraints into $`\mathbf{M}`$ and computing relational converses $`(R_{\text{asserted}})^\smile`$ executes in linear time:

$$
T_{\text{ingest}}(M) \in O(M)
$$

  3. *Atomic & Disjunctive Relation Composition*:
     Retrieving an atomic composition $`\mathbf{T}_{\text{comp}}[r_1][r_2]`$ requires exactly one array indexing operation ($`O(1)`$ steps). For arbitrary disjunctive relations $`R_1, R_2 \subseteq \mathcal{B}_{13}`$, each containing at most 13 basic relations, evaluating $`\mathbf{m}_{R_1 \circ R_2}`$ requires at most $`13 \times 13 = 169`$ table lookups and bitwise OR instructions:

$$
T_{\text{comp\_eval}} \le 169 \cdot O(1) \in O(1)
$$

  4. *Worklist Queue Upper Bound & Refinement Chaining*:
     The queue $`Q`$ holds directed interval pairs $`(i, j)`$ with $`i \ne j`$.
     Because the relation set at any cell $`\mathbf{M}[i, j]`$ is monotonically pruned and contains at most 13 elements, cell $`\mathbf{M}[i, j]`$ can be modified at most 13 times.
     The total number of pair enqueue operations over the entire execution of the algorithm is strictly bounded by:

$$
|Q_{\text{total}}| \le 13 \cdot N(N - 1) \in O(N^2)
$$

  5. *Triad Inspection & Propagation Work per Dequeue*:
     Each time a pair $`(i, j)`$ is popped from $`Q`$, the algorithm iterates over $`N - 2`$ third vertices $`k`$.
     For each vertex $`k`$, two triad compositions and intersections are evaluated:
     $`\mathbf{M}[k, j] \cap (\mathbf{M}[k, i] \circ \mathbf{M}[i, j])`$ and $`\mathbf{M}[i, k] \cap (\mathbf{M}[i, j] \circ \mathbf{M}[j, k])`$.
     Each check executes in $`O(1)`$ constant time.
     Hence, the work per dequeued pair is strictly bounded by:

$$
T_{\text{step}}(N) \le 2(N - 2) \cdot O(1) \in O(N)
$$

  6. *Aggregate Worst-Case Time Complexity*:
     Multiplying the maximum number of queue iterations by the work per iteration yields the overall worst-case time complexity:

$$
T_{\text{total}}(N, M) \le O(N^2 + M) + 13 \cdot N(N - 1) \cdot 2(N - 2) \cdot O(1) \in O(N^3)
$$

     Path consistency constraint propagation terminates deterministically in cubic polynomial time $`O(N^3)`$ without backtracking, search, or exponential branching.
  7. *Frontier NP-1 Subclass Relationship (REQ-0117)*:
     While deciding general temporal satisfiability in Allen's full interval algebra is NP-complete (NP-1, REQ-0117), path consistency is a polynomial-time 3-consistency filtering procedure ($`O(N^3)`$). For tractable algebraic fragments such as the ORD-Horn subclass ($`\mathcal{H}_{\text{ORD}}`$), path consistency is a sound and complete decision procedure. For general non-Horn networks, path consistency serves as an incomplete, polynomial-time static conflict filter that guarantees zero false positives when an empty relation is detected.
  8. *Parallel Work-Stealing Scaling (Architectural Directive 2)*:
     When executing path consistency propagation across $`K`$ independent compilation packages or decoupled occurrence scopes over $`N_{\text{max\_workers}}`$ threads on a bounded work-stealing thread pool:

$$
T_{\text{parallel}}(N, K, N_{\text{max\_workers}}) \in O\left( \frac{K \cdot N^3}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  9. *Space Complexity & Arena Memory Bounds*:
     The dense $`N \times N`$ relation matrix requires $`N^2 \times 2`$ bytes ($`2 N^2`$ bytes) using 16-bit integer containers in contiguous bump arena storage, scaling as $`O(N^2)`$ space. The worklist queue requires at most $`N(N - 1)`$ entries ($`O(N^2)`$ space). Deduplicated string interner memory is bounded by $`O(N)`$ unique symbol identifiers. The diagnostic error sink buffer is strictly bounded by $`O(C_{\text{max\_errors}}) = O(1)`$ capacity.
