### REQ-0016: Synchronization Token Recovery on Table Delimiter Boundaries

- **Normative Statement**: The CommonMark table parser within the Universal Schema Ingestion Engine shall implement a formal Synchronization Token Error Recovery architecture on table delimiter boundaries. In accordance with Architectural Directive 4, when the parser encounters unexpected formatting, unescaped pipe characters, invalid token layouts, malformed scalar literals, or cell delimiter mismatches within any cell $`C_{i, j}`$ of row $`R_i`$, the parser must record a localized diagnostic and resynchronize at the next designated synchronization token boundary without abandoning subsequent cells, rows, or tables in the compilation unit. The synchronization token set for tabular schemas shall consist of column delimiter pipes (`|`, $`\text{SYM}_{\text{PIPE}}`$), record line break delimiters ($`\text{SYM}_{\text{LF}}`$), and the end-of-file token ($`t_{\text{EOF}}`$). Upon detecting a cell fault, the parser shall construct a structured diagnostic record binding diagnostic error code `E0102` (table row delimiter synchronization failure) per REQ-0191, containing the exact 1-indexed line and column coordinates, the byte offset span $`[p_{\text{start}}, p_{\text{end}}]`$, the offending token slice, and the expected schema item. The parser shall advance the stream pointer monotonically forward to the nearest synchronization token, discard the corrupted token sequence, insert a typed sentinel error node $`\bot_{\text{cell}}`$ into the active row representation, preserve all preceding valid cells $`C_{i, 1}, \dots, C_{i, j-1}`$, and resume parsing at cell $`C_{i, j+1}`$ if synchronized on a column pipe, or advance to the next row $`R_{i+1}`$ if synchronized on a record line break. The parser must execute under a total, deterministic, non-panicking execution contract with zero unhandled panics or unwinding exceptions across all malformed inputs. The parser must enforce strictly monotonic forward stream progress, advancing the token stream pointer on every recovery cycle to eliminate livelocks and infinite recovery loops. The parser shall implement cascading error suppression by suppressing secondary diagnostic emissions occurring within a bounded token proximity window $`\delta \le 3`$ following a synchronization event when attributable to delimiter realignment ambiguity. The diagnostic sink shall enforce a bounded capacity limit $`C_{\text{max\_errors}}`$ per compilation unit, gracefully terminating the table parse pass and emitting diagnostic `E0199` when the threshold is reached to prevent denial of service from degenerate inputs.

- **Formal Invariant**: Let $`B = \langle b_0, b_1, \dots, b_{N-1} \rangle`$ denote the ordered sequence of input source bytes of length $`N = |B|`$, terminated by an explicit end-of-file sentinel $`b_N = t_{\text{EOF}}`$. Let $`T = \langle R_1, R_2, \dots, R_M \rangle`$ represent the tabular schema AST comprising $`M`$ rows, where each row $`R_i = \langle C_{i, 1}, C_{i, 2}, \dots, C_{i, K_i} \rangle`$ consists of $`K_i`$ cell entities. Let $`\mathcal{T}_{\text{cell}} = \{ \text{SYM}_{\text{PIPE}} \}`$ denote the cell delimiter set and $`\mathcal{T}_{\text{record}} = \{ \text{SYM}_{\text{LF}}, \text{SYM}_{\text{CRLF}} \}`$ denote the record line delimiter set. The table synchronization token set $`\mathcal{T}_{\text{sync}}`$ is defined as:

$$
\mathcal{T}_{\text{sync}} = \mathcal{T}_{\text{cell}} \cup \mathcal{T}_{\text{record}} \cup \{ t_{\text{EOF}} \}
$$

When a syntax or structural fault is detected during the lexical evaluation or semantic extraction of cell $`C_{i, j}`$ at byte offset $`p \in \{0, \dots, N-1\}`$, the delimiter scanning operator identifies the target synchronization point $`m`$:

$$
m = \text{ScanUntil}(\mathcal{T}_{\text{sync}}, p) = \min \{ k \in \{p, \dots, N\} \mid b_k \in \mathcal{T}_{\text{sync}} \}
$$

The parser state transition function $`\tau : \mathcal{S}_{\text{parser}} \times \mathcal{T}_{\text{sync}} \longrightarrow \mathcal{S}_{\text{parser}}`$ governs parser resynchronization:

$$
\text{State}_{t+1} = 
\begin{cases}
\text{State}_{\text{ParseCell}}(R_i, j+1), & \text{if } b_m \in \mathcal{T}_{\text{cell}} \\
\text{State}_{\text{ParseRow}}(R_{i+1}, 1), & \text{if } b_m \in \mathcal{T}_{\text{record}} \\
\text{State}_{\text{Halt}}, & \text{if } b_m = t_{\text{EOF}}
\end{cases}
$$

The Monotonic Forward Stream Progress Invariant mandates that the parser stream pointer strictly increases on every recovery transition:

$$
\forall t \in \mathbb{N}, \quad \text{ByteOffset}_{t+1} \gt \text{ByteOffset}_t
$$

where the updated stream pointer satisfies:

$$
\text{ByteOffset}_{t+1} = 
\begin{cases}
m + 1, & \text{if } b_m \in \mathcal{T}_{\text{cell}} \cup \mathcal{T}_{\text{record}} \\
N, & \text{if } b_m = t_{\text{EOF}}
\end{cases}
$$

Strict monotonicity guarantees bounded termination without livelock over any input stream:

$$
\forall \sigma \in \text{ParseExecutions}(B), \quad \text{Steps}(\sigma) \le N + 1
$$

Cell Preservation and Sentinel Substitution Invariant: Preceding valid cells $`C_{i, 1}, \dots, C_{i, j-1}`$ are retained in the synthesized row entity, and the faulted column is marked with a typed error sentinel $`\bot_{\text{cell}}`$:

$$
R_i = \langle C_{i, 1}, \dots, C_{i, j-1}, \bot_{\text{cell}}, C_{i, j+1}, \dots, C_{i, K_i} \rangle
$$

Row Extraction Independence Invariant: For any two distinct rows $`R_i, R_k \in T`$ with $`i \neq k`$, parsing failure in $`R_i`$ does not impede structural extraction of valid row $`R_k`$:

$$
\text{Fault}(R_i) \implies \text{Extracted}(R_k) \quad \forall k \neq i \text{ such that } \neg \text{Fault}(R_k)
$$

Cascading Error Suppression Invariant: Let $`\tau_{\text{sync\_last}} \in \mathbb{N}`$ denote the byte offset of the most recent delimiter synchronization event. For any subsequent syntax error detected at byte index $`q \gt \tau_{\text{sync\_last}}`$, cascading suppression evaluates:

$$
\text{EmitDecision}(q, \tau_{\text{sync\_last}}) = 
\begin{cases}
\text{Suppress}, & \text{if } q - \tau_{\text{sync\_last}} \le \delta \\
\text{Record}, & \text{if } q - \tau_{\text{sync\_last}} \gt \delta
\end{cases}
$$

where $`\delta \in \mathbb{N}`$ satisfies $`\delta \le 3`$.

Let $`\mathcal{D}_t`$ denote the set of accumulated diagnostics at step $`t`$. For a detected error at byte span $`[p, m]`$, diagnostic sink accumulation satisfies:

$$
\mathcal{D}_{t+1} = 
\begin{cases}
\mathcal{D}_t \cup \{ \text{Diagnostic}(R_i, C_j, \text{DiagnosticCode::E0102}, [p, m]) \}, & \text{if } \text{EmitDecision}(p, \tau_{\text{sync\_last}}) = \text{Record} \;\wedge\; |\mathcal{D}_t| \lt C_{\text{max\_errors}} \\
\mathcal{D}_t, & \text{otherwise}
\end{cases}
$$

Bounded Sink Capacity Invariant:

$$
|\mathcal{D}| \le C_{\text{max\_errors}}
$$

Diagnostic Taxonomy Containment Invariant: Every generated tabular delimiter diagnostic adheres to the partitioned taxonomy defined in REQ-0191:

$$
\forall D \in \mathcal{D}, \quad \text{Code}(D) = \text{DiagnosticCode::E0102} \;\vee\; (|\mathcal{D}| = C_{\text{max\_errors}} \implies \exists D_{\text{term}} \in \mathcal{D} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199})
$$

- **Computational Complexity & Algorithmic Bounds**: The table delimiter synchronization recovery engine executes within Complexity Class $`\mathbf{P}`$. Because forward scanning is strictly monotonic ($`\text{ByteOffset}_{t+1} \gt \text{ByteOffset}_t`$), every byte $`b_k \in B`$ in the input stream of length $`N = |B|`$ is inspected at most a constant number of times ($`O(1)`$) by the delimiter recovery scanner without backtracking. Delimiter scanning and error recovery across the entire tabular input document execute in deterministic $`O(N)`$ linear time in the worst case. Row array reallocation and sentinel insertion operate in $`O(K_{\text{max}})`$ time per row, where $`K_{\text{max}}`$ is the bounded maximum column arity ($`K_{\text{max}} \le 64`$), yielding $`O(M \cdot K_{\text{max}}) = O(N)`$ time across all $`M`$ rows. Cascading error suppression lookups execute in $`O(1)`$ constant time per error event via scalar distance subtraction. Total parser execution time is strictly bounded by $`O(N)`$. Auxiliary space complexity is strictly bounded by $`O(K_{\text{max}} + C_{\text{max\_errors}})`$, where $`K_{\text{max}}`$ accounts for the active row construction buffer and $`C_{\text{max\_errors}}`$ accounts for the preallocated diagnostic sink, ensuring $`O(1)`$ auxiliary heap memory overhead relative to input stream length $`N`$.

- **Verification & Conformance Criteria**: Automated parser test suites shall verify compliance against synthetic CommonMark tables containing abstract MBSE schema entities (e.g., `Package_0`, `Component_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`). The primary verification scenario shall ingest a synthetic 5-row CommonMark table containing deliberate syntax corruption in rows 2 and 4 (such as an unescaped pipe within a string literal in row 2 and an unclosed composite token in row 4). Conformance verification shall assert that: (1) valid rows 1, 3, and 5 are completely and accurately lowered into synthesized AST entities, (2) corrupted rows 2 and 4 retain valid preceding and succeeding cells while substituting $`\bot_{\text{cell}}`$ for the malformed columns, and (3) exactly two structured diagnostic entries are recorded in the diagnostic sink $`\mathcal{D}`$, each explicitly bound to diagnostic code `E0102` with precise line, column, and byte span mappings. Secondary test fixtures shall verify cascading error suppression by asserting that consecutive delimiter faults within distance $`\delta \le 3`$ emit exactly one primary diagnostic. Pathological fixtures exceeding $`C_{\text{max\_errors}}`$ faults must halt parsing at the capacity limit and emit diagnostic code `E0199`. Ingestion of empty cells or malformed cell tokens must execute without throwing panics or aborting compilation. Determinism is verified by executing the recovery test harness across multiple OS platforms and compiler threads, asserting 100% bitwise identical diagnostic output and zero diff churn.
