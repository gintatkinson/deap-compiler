### REQ-0008: Sovereign Single Source of Truth (SSOT) Multi-File AST Model

- **Normative Statement**: The compiler platform shall establish and maintain the unified, multi-file SysML v2 / KerML Abstract Syntax Tree (AST) synthesized from modular schemas in the `schema/` directory as the sovereign, authoritative Single Source of Truth (SSOT) for all architectural definitions, classifiers, ports, interconnects, behavioral lifecycles, and formal mathematical constraints across the entire compilation lifecycle. All downstream representations and target artifacts--including Epics, Features, Interface Control Documents (ICDs), simulation models, and target source code--shall function strictly as deterministic, pure mathematical projections of this authoritative central AST. The compiler must prohibit downstream artifacts from acting as independent sources of truth or introducing unauthorized architectural mutations. Every entity within the central AST model shall be deterministically anchored by an RFC 4122 UUIDv5 identifier computed from a fixed namespace OID and the entity's fully qualified topological path. When downstream artifacts are parsed or evaluated during compilation or synchronization passes, automated bidirectional reconciliation gates shall compare on-disk artifacts against the authoritative AST projections; any detected structural discrepancy or uncoordinated modification shall trigger the reconciliation rule wherein the central AST model unconditionally governs. If an irreconcilable structural divergence or non-conforming downstream modification is detected without corresponding upstream schema evolution, the compiler shall halt execution and emit diagnostic error code `E0100` detailing the offending artifact path, diverging node identifier, expected AST projection digest, and observed downstream content.

- **Formal Invariant**: Let $\mathcal{S} = \{ s_{1}, s_{2}, \dots, s_{M} \}$ be the set of modular schema input units located within `schema/`. Let $\mathcal{A}_{\text{SSOT}} = (V, E, \mu)$ denote the resolved sovereign root AST multigraph synthesized from $\mathcal{S}$, where $V$ represents the set of metamodel AST node handles, $E$ denotes directed syntactic and semantic relationship edges, and $\mu : V \to \mathcal{T}$ maps nodes to their metamodel definitions.

For every node $v \in V$, let $\text{path}(v) = \langle p_{1}, p_{2}, \dots, p_{d} \rangle$ denote its fully qualified topological path within the hierarchical namespace, and let $\text{NS}_{\text{DEAP}}$ be the fixed RFC 4122 namespace UUID. Each node possesses an immutable, deterministic topological anchor:

$$
\text{Anchor}(v) = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{path}(v))
$$

Let $\mathcal{D}_{\text{downstream}} = \{ D_{1}, D_{2}, \dots, D_{K} \}$ denote the set of downstream specification artifacts, documentation projections, and generated target code representations. For each downstream artifact category $k \in \{1, \dots, K\}$, there exists a deterministic, pure projection mapping function $\psi_{k}$:

$$
\psi_{k} : \mathcal{A}_{\text{SSOT}} \longrightarrow \mathcal{B}^*
$$

where $\mathcal{B}^* = \{0, 1\}^*$ represents the emitted artifact byte stream. The generated downstream artifact $D_{k}$ satisfies the Canonical Projection Contract:

$$
D_{k} = \psi_{k}(\mathcal{A}_{\text{SSOT}})
$$

Let $D_{k}^{\text{disk}} \in \mathcal{B}^*$ denote the observed on-disk artifact state. The compiler enforces the Anti-Drift Invariant:

$$
\text{Drift}(D_{k}) \iff D_{k}^{\text{disk}} \neq \psi_{k}(\mathcal{A}_{\text{SSOT}})
$$

Let $\text{Reconcile} : (\mathcal{B}^*, \mathcal{A}_{\text{SSOT}}) \longrightarrow \{\text{Valid}, \text{Conflict}\}$ denote the bidirectional reconciliation gate. In any reconciliation or reverse-synchronization evaluation, the central AST model $\mathcal{A}_{\text{SSOT}}$ is strictly and unconditionally authoritative:

$$
\forall D_{k} \in \mathcal{D}_{\text{downstream}}, \quad \text{Reconcile}(D_{k}^{\text{disk}}, \mathcal{A}_{\text{SSOT}}) = \begin{cases} \text{Valid}, & \text{if } D_{k}^{\text{disk}} = \psi_{k}(\mathcal{A}_{\text{SSOT}}) \\ \text{Conflict}, & \text{if } D_{k}^{\text{disk}} \neq \psi_{k}(\mathcal{A}_{\text{SSOT}}) \end{cases}
$$

Let $\mathcal{F}_{\text{arch}} : \mathcal{B}^* \to \mathcal{P}(V)$ be the semantic extraction operator recovering MBSE structural entities from an artifact byte stream. The Downstream Non-Invention Invariant mandates that no downstream artifact can instantiate architectural entities absent from $\mathcal{A}_{\text{SSOT}}$:

$$
\begin{aligned}
\forall D_{k}^{\text{disk}}, \quad \mathcal{F}_{\text{arch}}(D_{k}^{\text{disk}}) &\subseteq V(\mathcal{A}_{\text{SSOT}}) \\
\mathcal{F}_{\text{arch}}(D_{k}^{\text{disk}}) \setminus V(\mathcal{A}_{\text{SSOT}}) &= \emptyset
\end{aligned}
$$

Let $\mathcal{H} : \mathcal{B}^* \to \{0, 1\}^{256}$ denote the cryptographic SHA-256 hash digest function. The Merkle root digest $\mathcal{M}(\mathcal{A}_{\text{SSOT}})$ of the sovereign AST completely and deterministically determines the cryptographic digests of all projected downstream artifacts:

$$
\mathcal{M}(\mathcal{A}_{\text{SSOT}}^{(1)}) = \mathcal{M}(\mathcal{A}_{\text{SSOT}}^{(2)}) \implies \forall k \in \{1, \dots, K\}, \quad \mathcal{H}(\psi_{k}(\mathcal{A}_{\text{SSOT}}^{(1)})) = \mathcal{H}(\psi_{k}(\mathcal{A}_{\text{SSOT}}^{(2)}))
$$

- **Computational Complexity & Algorithmic Bounds**: The SSOT multi-file AST resolution and projection pipeline operates strictly within Complexity Class $\mathbf{P}$. The construction of the unified AST $\mathcal{A}_{\text{SSOT}} = (V, E)$ across $M$ modular schema units containing $N$ total tokens executes in deterministic linear time $O(N)$ with graph linking bounded by $O(|V| + |E|)$. Each downstream projection $\psi_{k}$ traverses the relevant AST subgraph and serializes output byte streams in $O(|V_{k}| + |E_{k}|)$ time, where $V_{k} \subseteq V$ and $E_{k} \subseteq E$. Total generation time across all $K$ downstream projections is bounded by $O(K \cdot (|V| + |E|))$. Cryptographic SHA-256 digest computation and drift verification against on-disk artifacts execute in linear time $O(B)$ where $B = \sum_{k=1}^K |D_{k}^{\text{disk}}|$ denotes the total artifact byte length. Auxiliary memory consumption is strictly bounded by $O(N)$ for contiguous AST storage, symbol interner pools, and projection buffers.

- **Verification & Conformance Criteria**: Automated conformance verification shall assert 100% bidirectional parity between all emitted downstream artifacts and the authoritative central AST model across synthetic multi-file test packages (e.g., `Package_0` containing interdependent structural classifiers `Classifier_Alpha` and `Classifier_Beta` with ports `Port_1` and directional flow `Flow_A`). Conformance testing shall verify that:
1. Synthesizing downstream artifacts from $\mathcal{A}_{\text{SSOT}}$ produces bitwise identical content upon repeated executions, satisfying $\text{Diff}(D_{k}, \psi_{k}(\mathcal{A}_{\text{SSOT}})) = \emptyset$.
2. Mutating any upstream schema unit automatically propagates changes across all affected downstream projections via $\psi_{k}$, updating corresponding SHA-256 digests without manual downstream intervention.
3. Injecting synthetic out-of-band structural modifications into any downstream artifact (such as adding an unmapped classifier `Classifier_Gamma` or altering a port direction in an emitted file) is flagged immediately by the reconciliation gate as an invalid drift state.
4. When an uncoordinated downstream structural mutation or drift conflict occurs, the compiler halts execution and emits diagnostic error code `E0100` reporting the absolute or relative artifact path, offending line and column numbers, the invalid symbol name, and the expected AST projection hash.
