### REQ-0124: Discrete State Machine Reachability, Deadlock & Livelock in Orthogonal Regions (NP-5)

#### 1. Normative Statement

The state machine compiler, spatio-temporal dynamics solver, and formal verification engine of Subsystem 6 shall verify state reachability, deadlock freedom, and livelock absence across $`K`$` concurrent orthogonal regions (`$`K \ge 2`$`) by unrolling composite transition relations into propositional Satisfiability (SAT) formulas via Bounded Model Checking (BMC) under a configurable depth cutoff `$`k \le k_{\text{max}}`$` and deterministic solver step budget `$`\kappa_{\text{steps}}`$, mitigating the PSPACE-complete combinatorial state explosion cataloged under Algorithmic Bound NP-5.

  Specifically, the discrete state machine solver, BMC unrolling compiler, and SAT verification engine shall strictly enforce the following structural, algebraic, and algorithmic invariants:
  1. **Orthogonal Region Concurrency & Global State Space Formalization**:
     - The state machine compiler shall represent concurrent orthogonal composite states $`\mathcal{S}_{\text{orth}}`$` comprising `$`K \ge 2`$` orthogonal regions `$`\{ R_1, R_2, \dots, R_K \}`$` allocated in contiguous bump arena storage, where each region `$`R_i`$` defines a local state space `$`S_i`$.
     - The global concurrent state space shall be formalized as the Cartesian product $`\mathcal{C}_{\text{global}} = \prod_{i=1}^K S_i`$` of size `$`|\mathcal{C}_{\text{global}}| = \prod_{i=1}^K |S_i|`$.
     - The compiler shall enforce the invariant that every valid global active configuration $`s \in \mathcal{C}_{\text{global}}`$` contains exactly one active leaf state per active orthogonal region (`$`|C \cap \text{Leaves}(R_i)| = 1`$).
     - The initial configuration $`s_0 \in \mathcal{C}_{\text{global}}`$` shall comprise the initial default state of each constituent region: `$`s_0 = \langle q_{\text{init}, 1}, q_{\text{init}, 2}, \dots, q_{\text{init}, K} \rangle`$.
  2. **Bounded Model Checking (BMC) Architecture & SAT Unrolling**:
     - To mitigate the PSPACE-completeness of unbounded reachability and deadlock verification in orthogonal statecharts, the verification engine shall compile safety properties into a propositional SAT formula $`\Phi_k`$` unrolled over discrete execution steps `$`t \in \{0, \dots, k\}`$` up to a bounded horizon `$`k \le k_{\text{max}}`$.
     - The unrolling depth limit $`k_{\text{max}}`$` shall be configurable via compilation flags with a deterministic system default of `$`k_{\text{max}} = 50`$.
     - The unrolled formula $`\Phi_k`$` shall be composed of three mandatory conjuncts: the initial configuration predicate `$`I(s_0)`$`, the conjunction of `$`k`$` step transition relations `$`\bigwedge_{t=0}^{k-1} T(s_t, s_{t+1})`$`, and the violation predicate asserting the refutation of the safety invariant at horizon step `$`k`$` (or along any intermediate step `$`t \le k`$`): `$`\neg \text{Safe}(s_k)`$.
  3. **Propositional SAT Encoding & State Occupancy Invariants**:
     - For each discrete time step $`t \in \{0, \dots, k\}`$`, region `$`R_i \in \mathcal{R}`$`, and local state `$`q \in S_i`$`, the compiler shall instantiate a boolean state occupancy variable `$`x_{i, q}^{(t)}`$` denoting whether region `$`R_i`$` resides in state `$`q`$` at step `$`t`$.
     - The compiler shall enforce an exact-one (one-hot) state occupancy constraint for each region at each step $`t`$`: at least one state in `$`S_i`$` is active (`$`\bigvee_{q \in S_i} x_{i, q}^{(t)}`$`) and no two distinct states in `$`S_i`$` are simultaneously active (`$`\bigwedge_{q \ne q' \in S_i} (\neg x_{i, q}^{(t)} \lor \neg x_{i, q'}^{(t)})`$).
     - The initial configuration predicate $`I(s_0)`$` shall strictly assert `$`x_{i, q_{\text{init}, i}}^{(0)} \equiv \text{true}`$` and `$`x_{i, q}^{(0)} \equiv \text{false}`$` for all non-initial states `$`q \in S_i \setminus \{ q_{\text{init}, i} \}`$` across all regions `$`R_i`$.
  4. **Composite Transition Relation Encoding ($`T(s_t, s_{t+1})`$)**:
     - The composite transition relation $`T(s_t, s_{t+1})`$ shall encode asynchronous regional micro-steps, synchronized multi-region compound transitions (fork and join pseudo-states), and terminal stuttering loops.
     - For each local transition $`\tau = \langle q_{\text{src}}, q_{\text{tgt}}, g_\tau, a_\tau \rangle`$` within region `$`R_i`$`, the encoding shall assert that `$`\tau`$` is enabled at step `$`t`$` if and only if source state `$`q_{\text{src}}`$` is active (`$`x_{i, q_{\text{src}}}^{(t)} = 1`$`) and guard condition `$`g_\tau^{(t)}`$ holds.
     - When transition $`\tau`$` fires, region `$`R_i`$` transitions to target state (`$`x_{i, q_{\text{tgt}}}^{(t+1)} = 1`$`); if no transition fires within region `$`R_i`$` during an interleaving step, region `$`R_i`$` stutters by preserving its previous state configuration (`$`\mathbf{x}_i^{(t+1)} = \mathbf{x}_i^{(t)}`$).
     - For compound fork transitions entering multiple orthogonal regions, all target states across the constituent regions must be activated simultaneously; for compound join transitions synchronizing from multiple orthogonal regions, all source states across the participating regions must be active simultaneously for the join transition to fire.
  5. **Deadlock Freedom Verification**:
     - A global state configuration $`s_t \in \mathcal{C}_{\text{global}}`$` shall be classified as a deadlock state if and only if `$`s_t`$` is not an explicitly designated terminal configuration (`$`\neg \text{IsTerminal}(s_t)`$`) and no outgoing composite transition is enabled (`$`\neg \exists s_{t+1}, \, T(s_t, s_{t+1})`$).
     - Deadlock freedom verification shall be encoded via the property $`\text{DeadlockFree}(s_t) \equiv \text{IsTerminal}(s_t) \lor \bigvee_{\tau \in \mathcal{T}} \text{Enabled}(\tau, s_t)`$.
     - If the BMC formula $`\Phi_k`$` is satisfiable for a deadlock violation predicate `$`\neg \text{DeadlockFree}(s_k)`$, the compiler shall deterministically reject the compilation unit with diagnostic error code `E0400` (`OrthogonalStateDeadlockDetected`), synthesizing the complete counterexample execution trace from $`s_0`$` to `$`s_k`$ with exact source span annotations.
  6. **Livelock & Non-Progress Cycle Verification**:
     - A livelock condition shall be defined as an execution sequence forming a periodic loop $`s_0 \to \dots \to s_l \to \dots \to s_k = s_l`$` (`$`0 \le l \lt k`$`) such that all transitions along the cycle `$`j \in \{l, \dots, k-1\}`$` execute without satisfying an asserted system progress predicate `$`\text{Progress}(s_j, s_{j+1})`$.
     - The BMC livelock violation formula shall assert the existence of a loop back-edge $`(s_k = s_l)`$ where no progress predicate is satisfied:
       $`\neg \text{Safe}_{\text{livelock}}(s_0, \dots, s_k) \equiv \bigvee_{l=0}^{k-1} \left( (s_k = s_l) \land \bigwedge_{j=l}^{k-1} \neg \text{Progress}(s_j, s_{j+1}) \right)`$.
     - If satisfiable, the compiler shall deterministically reject the compilation unit with diagnostic error code `E0400` (`OrthogonalStateLivelockDetected`), emitting the cyclic trace and highlighting the non-progress loop.
  7. **Dead State Reachability Analysis**:
     - The verification engine shall evaluate the reachability of each declared leaf state $`q \in S_i`$.
     - A state $`q`$` is bounded-unreachable if for all depths `$`k \in [1, k_{\text{max}}]`$`, the formula `$`\Phi_{\text{reach}, k}(q) = I(s_0) \land \left( \bigwedge_{t=0}^{k-1} T(s_t, s_{t+1}) \right) \land x_{i, q}^{(k)}`$ is UNSAT.
     - If state $`q`$` is additionally proven unreachable via inductive invariant strengthening or reachability diameter completion, the compiler shall flag `$`q`$ as a dead state with diagnostic error code `E0400` (`UnreachableOrthogonalState`).
  8. **Algorithmic Bound NP-5 Mitigation & Deterministic Solver Budgets**:
     - In accordance with Algorithmic Bound NP-5, deciding bounded reachability, deadlock, and livelock via BMC is NP-complete. The compiler shall execute propositional SAT solving via a deterministic Conflict-Driven Clause Learning (CDCL) solver governed by an explicit step budget $`\kappa_{\text{steps}}`$` (defaulting to `$`\kappa_{\text{steps}} = 2 \times 10^5`$ solver operations).
     - Each variable decision, two-watched-literal propagation step, conflict clause deduction, and backjump step shall increment a monotonic step counter $`N_{\text{step}}`$.
     - If the solver exceeds $`\kappa_{\text{steps}}`$ without reaching a decisive SAT or UNSAT termination, compilation shall fail deterministically with diagnostic error code `E0406` (`StateVerificationStepLimitExceeded`), reporting the unrolling depth, decision count, and active orthogonal region names.
  9. **Executive Architectural Directives Compliance**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every orthogonal region, state entity, transition, SAT variable descriptor, and witness trace record shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical DEAP namespace OID and node fully qualified topological path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))`$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel SAT formula construction, BMC unrolling across independent state machine models or orthogonal composite state clusters, and independent reachability queries shall execute exclusively on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: State names, region identifiers, event tokens, and SAT variable name strings shall be interned into the deduplicated global symbol interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The state machine solver shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When verification errors (`E0400`, `E0406`) occur, diagnostics shall accumulate in the error sink buffer $`\mathcal{D}_{\text{sink}}`$`, substitute typed error sentinels (`$`\bot_{\text{state}}`$`, `$`\bot_{\text{trace}}`$`), and continue validating subsequent state machine definitions. If accumulated diagnostics reach capacity `$`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully in accordance with REQ-0013 and REQ-0016.
     - *Directive 5 (Panic-Free Release Isolation)*: The state machine BMC pipeline shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Verification latency ($`\lt 25\text{ ms}`$` for benchmark models with up to 4 orthogonal regions and `$`k = 20`$`) and peak RSS memory (`$`\lt 100\text{ MB}`$) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `StateMachine_Alpha`, `StateMachine_Beta`, `Region_1`, `Region_2`, `Region_K`, `State_Alpha`, `State_Beta`, `State_Gamma`, `State_Delta`, `Transition_1`, `Transition_2`, `Port_1`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

#### 2. Formal Invariant

Let $`\mathcal{V}_{\text{AST}}`$ denote the universe of allocated AST nodes in contiguous bump arena storage.

  An orthogonal discrete state machine $`M`$ is formalized as a 6-tuple:

```math
  M = \langle \mathcal{S}_{\text{orth}}, \mathcal{R}, \mathcal{S}_{\text{local}}, \mathcal{T}, s_0, \mathcal{S}_{\text{term}} \rangle
```

  where:

```math
  \begin{aligned}
  \mathcal{S}_{\text{orth}} &\subset \mathcal{V}_{\text{AST}} \quad (\text{finite set of orthogonal composite states}) \\
  \mathcal{R} &= \{ R_1, R_2, \dots, R_K \} \quad (K \ge 2 \text{ concurrent orthogonal regions}) \\
  \mathcal{S}_{\text{local}} &= \bigcup_{i=1}^K S_i \quad (\text{partitioned local leaf states}, \, \forall i \ne j, \, S_i \cap S_j = \emptyset) \\
  \mathcal{T} &= \bigcup_{i=1}^K \mathcal{T}_i \cup \mathcal{T}_{\text{sync}} \quad (\text{regional and synchronizing transitions}) \\
  s_0 &= \langle q_{\text{init}, 1}, q_{\text{init}, 2}, \dots, q_{\text{init}, K} \rangle \in \prod_{i=1}^K S_i \quad (\text{unique initial global configuration}) \\
  \mathcal{S}_{\text{term}} &\subseteq \prod_{i=1}^K S_i \quad (\text{designated valid terminal configurations})
  \end{aligned}
```

  The global active configuration space $`\mathcal{C}_{\text{global}}`$ is the Cartesian product:

```math
  \mathcal{C}_{\text{global}} = \prod_{i=1}^K S_i, \quad |\mathcal{C}_{\text{global}}| = \prod_{i=1}^K |S_i|
```

  For BMC unrolling depth $`k \in [1, k_{\text{max}}]`$`, the state configuration at step `$`t \in \{0, \dots, k\}`$ is encoded as a boolean vector:

```math
  \mathbf{x}^{(t)} = \left( x_{1, q_1}^{(t)}, \dots, x_{K, q_m}^{(t)} \right) \in \{0, 1\}^{N_{\text{states}}}, \quad N_{\text{states}} = \sum_{i=1}^K |S_i|
```

  Region Exact-One (One-Hot) Occupancy Invariant:

```math
  \text{Occupancy}(\mathbf{x}^{(t)}) \equiv \bigwedge_{i=1}^K \left( \left( \bigvee_{q \in S_i} x_{i, q}^{(t)} \right) \land \bigwedge_{q, q' \in S_i, \, q \ne q'} \left( \neg x_{i, q}^{(t)} \lor \neg x_{i, q'}^{(t)} \right) \right)
```

  Initial Configuration Predicate:

```math
  I(\mathbf{x}^{(0)}) \equiv \text{Occupancy}(\mathbf{x}^{(0)}) \land \bigwedge_{i=1}^K \left( x_{i, q_{\text{init}, i}}^{(0)} \land \bigwedge_{q \in S_i \setminus \{ q_{\text{init}, i} \}} \neg x_{i, q}^{(0)} \right)
```

  Composite Step Transition Relation $`T(\mathbf{x}^{(t)}, \mathbf{x}^{(t+1)})`$:

```math
  \begin{aligned}
  T(\mathbf{x}^{(t)}, \mathbf{x}^{(t+1)}) &\equiv \text{Occupancy}(\mathbf{x}^{(t)}) \land \text{Occupancy}(\mathbf{x}^{(t+1)}) \\
  &\quad \land \left( T_{\text{interleave}}(\mathbf{x}^{(t)}, \mathbf{x}^{(t+1)}) \lor T_{\text{sync}}(\mathbf{x}^{(t)}, \mathbf{x}^{(t+1)}) \lor T_{\text{stutter}}(\mathbf{x}^{(t)}, \mathbf{x}^{(t+1)}) \right)
  \end{aligned}
```

  where:

```math
  \begin{aligned}
  T_{\text{interleave}}(\mathbf{x}^{(t)}, \mathbf{x}^{(t+1)}) &\equiv \bigvee_{i=1}^K \left( \bigvee_{\tau \in \mathcal{T}_i} \left( x_{i, \text{src}(\tau)}^{(t)} \land g_\tau^{(t)} \land x_{i, \text{tgt}(\tau)}^{(t+1)} \right) \land \bigwedge_{j \ne i} \left( \mathbf{x}_j^{(t+1)} = \mathbf{x}_j^{(t)} \right) \right) \\
  T_{\text{sync}}(\mathbf{x}^{(t)}, \mathbf{x}^{(t+1)}) &\equiv \bigvee_{\tau \in \mathcal{T}_{\text{sync}}} \left( \bigwedge_{i \in \text{Reg}(\text{src}(\tau))} x_{i, \text{src}_i(\tau)}^{(t)} \land g_\tau^{(t)} \land \bigwedge_{j \in \text{Reg}(\text{tgt}(\tau))} x_{j, \text{tgt}_j(\tau)}^{(t+1)} \right) \\
  T_{\text{stutter}}(\mathbf{x}^{(t)}, \mathbf{x}^{(t+1)}) &\equiv \text{IsTerminal}(\mathbf{x}^{(t)}) \land \left( \mathbf{x}^{(t+1)} = \mathbf{x}^{(t)} \right)
  \end{aligned}
```

  Safety Invariants & Violation Conditions:

```math
  \text{Safe}(\mathbf{x}^{(t)}) \equiv \text{DeadlockFree}(\mathbf{x}^{(t)}) \land \text{LivelockFree}(\mathbf{x}^{(0)}, \dots, \mathbf{x}^{(t)})
```

  Deadlock Invariant:

```math
  \text{DeadlockFree}(\mathbf{x}^{(t)}) \equiv \text{IsTerminal}(\mathbf{x}^{(t)}) \lor \exists \mathbf{x}^{(t+1)}, \, T(\mathbf{x}^{(t)}, \mathbf{x}^{(t+1)})
```

  Livelock Invariant:

```math
  \text{LivelockCycle}(\mathbf{x}^{(0)}, \dots, \mathbf{x}^{(k)}) \equiv \bigvee_{l=0}^{k-1} \left( (\mathbf{x}^{(k)} = \mathbf{x}^{(l)}) \land \bigwedge_{j=l}^{k-1} \neg \text{Progress}(\mathbf{x}^{(j)}, \mathbf{x}^{(j+1)}) \right)
```

  Bounded Model Checking Propositional Formula Unrolled to Depth $`k`$:

```math
  \Phi_k = I(\mathbf{x}^{(0)}) \land \left( \bigwedge_{t=0}^{k-1} T(\mathbf{x}^{(t)}, \mathbf{x}^{(t+1)}) \right) \land \neg \text{Safe}(\mathbf{x}^{(k)})
```

  Counterexample Witness Extraction:

```math
  \Phi_k \equiv \text{SAT} \implies \exists \mathbf{w} \in \{0, 1\}^{(k+1) \cdot N_{\text{states}}}, \quad \mathbf{w} \models \Phi_k \land \text{Trace}(\mathbf{w}) = \langle s_0, s_1, \dots, s_k \rangle
```

  Deterministic Diagnostic Invariants:

```math
  \begin{aligned}
  \Phi_k^{\text{deadlock}} \equiv \text{SAT} &\implies \text{Diagnostic}(\text{Trace}(\mathbf{w}), \text{DiagnosticCode::E0400}, \text{OrthogonalStateDeadlockDetected}) \in \mathcal{D}_{\text{sink}} \\
  \Phi_k^{\text{livelock}} \equiv \text{SAT} &\implies \text{Diagnostic}(\text{Trace}(\mathbf{w}), \text{DiagnosticCode::E0400}, \text{OrthogonalStateLivelockDetected}) \in \mathcal{D}_{\text{sink}} \\
  \exists q \in \mathcal{S}_{\text{local}} : \text{IsDeadState}(q) &\implies \text{Diagnostic}(q, \text{DiagnosticCode::E0400}, \text{UnreachableOrthogonalState}) \in \mathcal{D}_{\text{sink}} \\
  N_{\text{step}} \gt \kappa_{\text{steps}} &\implies \text{Diagnostic}(\mathcal{S}_{\text{orth}}, \text{DiagnosticCode::E0406}, \text{StateVerificationStepLimitExceeded}) \in \mathcal{D}_{\text{sink}} \\
  |\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
  \end{aligned}
```

  Deterministic RFC 4122 UUIDv5 Anchor Invariant (Directive 1):

```math
  \forall n \in \mathcal{S}_{\text{orth}} \cup \mathcal{R} \cup \mathcal{S}_{\text{local}} \cup \mathcal{T} \cup \mathcal{W}_{\text{trace}}, \quad \Delta_n = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))
```

#### 3. Computational Complexity & Algorithmic Bounds

Unbounded discrete state machine reachability, deadlock detection, and livelock verification across $`K`$` concurrent orthogonal regions resides in **Complexity Class PSPACE-complete** (Algorithmic Bound NP-5, Drusinsky & Harel, 1994). When restricted to Bounded Model Checking (BMC) unrolled to depth `$`k \le k_{\text{max}}`$, the problem resides in **Complexity Class NP-complete** (Biere et al., 1999).

  For an abstract MBSE statechart comprising $`K \ge 2`$` orthogonal regions, `$`N = \sum_{i=1}^K |S_i|`$` total local states, `$`M = |\mathcal{T}|`$` transitions, and unrolling depth `$`k \le k_{\text{max}}`$:
  1. *Cartesian State Space Dimension*:
     The unconstrained reachable state space grows exponentially as:

```math
|\mathcal{C}_{\text{global}}| = \prod_{i=1}^K |S_i| \in O\left( \left( \frac{N}{K} \right)^K \right)
```

     Direct state graph traversal requires exponential space $`O(N^K)`$, establishing PSPACE-completeness.
  2. *BMC Formula Propositional Encoding*:
     Unrolling the state machine to depth $`k`$ instantiates:

```math
V_{\text{SAT}} = (k + 1) \cdot N \text{ boolean variables}
```

     The number of propositional clauses generated for region occupancy, transition activation, frame axioms, and safety assertions is bounded by:

```math
C_{\text{SAT}} \in O(k \cdot (N^2 + M))
```

     Constructing the formula $`\Phi_k`$ executes in deterministic linear time:

```math
T_{\text{encode}}(k, N, M) \in O(k \cdot (N^2 + M))
```

  3. *SAT Solving under Monotonic Step Budget $`\kappa_{\text{steps}}`$*:
     While general propositional SAT solving is NP-complete with unconstrained worst-case runtime $`O(2^{(k+1) \cdot N})`$`, the compiler enforces a deterministic step budget `$`\kappa_{\text{steps}} = 2 \times 10^5`$ operations.
     Each decision step and two-watched-literal propagation step traverses clauses in $`O(1)`$ amortized time.
     Under the deterministic cutoff $`\kappa_{\text{steps}}`$, solver execution is strictly bounded by:

```math
T_{\text{SAT}}(k, N, M, \kappa_{\text{steps}}) \in O(\kappa_{\text{steps}} \cdot C_{\text{SAT}}) = O(\kappa_{\text{steps}} \cdot k \cdot (N^2 + M))
```

     If $`N_{\text{step}} \gt \kappa_{\text{steps}}`$`, execution aborts deterministically in `$`O(1)`$ operations with diagnostic `E0406`, completely preventing exponential compiler hang.
  4. *Dead State Reachability Bounding*:
     Evaluating bounded reachability for all $`N`$` local states across depth `$`k \le k_{\text{max}}`$` invokes at most `$`N`$ bounded SAT queries, bounded by:

```math
T_{\text{reach}}(N, k, \kappa_{\text{steps}}) \in O(N \cdot \kappa_{\text{steps}} \cdot k \cdot (N^2 + M))
```

  5. *Aggregate Time Complexity*:
     The total worst-case execution time for bounded reachability, deadlock, and livelock verification is:

```math
T_{\text{total}}(k, N, M, \kappa_{\text{steps}}) \in O(k \cdot (N^2 + M) + \kappa_{\text{steps}} \cdot k \cdot (N^2 + M))
```

     guaranteeing predictable, non-divergent compile-time execution.
  6. *Parallel Work-Stealing Scaling (Directive 2)*:
     When verifying $`P`$` independent orthogonal state machines across `$`N_{\text{max\_workers}}`$ threads on a bounded work-stealing thread pool:

```math
T_{\text{parallel}} \in O\left( \frac{T_{\text{total}}}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

  7. *Space Complexity & Arena Memory Bounds*:
     Allocations for unrolled boolean variables, propositional clauses, CDCL assignment trails, and two-watched-literal indexes are maintained in contiguous bump arena storage, requiring $`O(k \cdot (N^2 + M))`$` bytes. Interned symbol strings require `$`O(N + M)`$` bytes in the global symbol pool. The diagnostic error sink buffer is strictly bounded by `$`O(C_{\text{max\_errors}}) = O(1)`$ capacity.

  5. **Unreachable Dead State Detection Gate (`E0400`)**: Ingest a synthetic model containing an unlinked disconnected state `State_Delta` in `Region_1`.   8. **Synchronized Compound Transition (Fork-Join) Gate**: Ingest a synthetic model with an orthogonal composite state entered via an explicit `fork` pseudo-state into 3 regions and exited via an explicit `join` pseudo-state. Verify that the transition relation asserts simultaneous multi-region entry and synchronized multi-region exit without state divergence.
  9. **Asymmetric Orthogonal Region Scaling Gate**: Ingest a synthetic model with 4 orthogonal regions of sizes 2, 3, 4, and 5 states ($`2 \times 3 \times 4 \times 5 = 120`$` global configurations).
