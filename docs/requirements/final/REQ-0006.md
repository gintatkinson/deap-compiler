### REQ-0006: Incremental Compilation Dependency Tracking & AST Cache Invalidation

- **Normative Statement**: The compiler platform shall maintain fine-grained dependency tracking across all modular compilation units within an explicit compilation unit dependency directed acyclic graph (DAG). The incremental compilation subsystem must compute cryptographic content digests for each input compilation unit upon ingestion. When one or more input schema compilation units are modified, added, or removed, the compiler shall identify the mutated seed set and compute the exact forward reachability closure (transitive dependent set) across the dependency DAG. The compiler must invalidate and recompute strictly the AST subgraphs, symbol tables, and lowering artifacts belonging to this transitively affected closure. All unaffected compilation units outside the transitive invalidation set shall be reused directly from the compiler AST cache without disk re-reads, re-lexing, or re-parsing. The synthesized AST resulting from incremental recomputation shall be bitwise and structurally identical to the AST produced by an exhaustive clean compilation from scratch. If an unresolvable dependency cycle, invalidation fault, or corrupted cache record is encountered during graph traversal, the compiler shall reject the invalid state, invalidate the affected cache partition, and emit diagnostic error code `E0100` with the affected compilation unit identifier, dependency edge coordinates, and source byte spans.

- **Formal Invariant**: Let $`G = (V, E)`$` be the compilation unit dependency directed acyclic graph, where each vertex `$`v \in V`$` represents a distinct compilation unit and each directed edge `$`(u, v) \in E`$` denotes that compilation unit `$`v`$` directly depends on compilation unit `$`u`$`. Let `$`\mathcal{H} : \text{Unit} \to \{0, 1\}^{256}`$` be a deterministic cryptographic hashing function. For an incremental compilation cycle with modified compilation units `$`M \subseteq V`$, the mutated seed set satisfies:

```math
M = \{ u \in V \mid \mathcal{H}(u) \neq \mathcal{H}_{\text{cached}}(u) \}
```

The transitive invalidation closure $`\text{Invalidated}(M) \subseteq V`$ is defined as the forward reachability set:

```math
\text{Invalidated}(M) = \{ v \in V \mid \exists u \in M, \; u \to^* v \}
```

where $`u \to^* v`$` represents a reflexive-transitive directed path from `$`u`$` to `$`v`$` in `$`G`$.

For every unimpacted compilation unit $`w \in V \setminus \text{Invalidated}(M)`$, the parsing time and cache retrieval time satisfy:

```math
\forall w \in V \setminus \text{Invalidated}(M), \quad T_{\text{parse}}(w) = 0 \quad \land \quad T_{\text{compile}}(w) \in O(1)
```

Cache Semantic Equivalence Invariant: let $`\mathcal{A}_{\text{inc}}`$` denote the AST resulting from incremental execution and `$`\mathcal{A}_{\text{full}}`$ denote the AST synthesized from an exhaustive non-incremental compilation of the entire source suite. The incremental compilation pipeline satisfies total semantic and structural equivalence:

```math
\mathcal{A}_{\text{inc}} \equiv \mathcal{A}_{\text{full}}
```

where for every unit $`x \in V`$:

```math
\begin{aligned}
\forall w \in V \setminus \text{Invalidated}(M), \quad \text{AST}_{\text{cached}}(w) &\equiv \text{AST}_{\text{full}}(w) \\
\forall v \in \text{Invalidated}(M), \quad \text{AST}_{\text{recomputed}}(v) &\equiv \text{AST}_{\text{full}}(v)
\end{aligned}
```

Let $`\text{Digest}(\mathcal{A})`$ denote the root Merkle digest of the entire system AST. The incremental compilation pipeline guarantees zero diff churn:

```math
\text{Digest}(\mathcal{A}_{\text{inc}}) = \text{Digest}(\mathcal{A}_{\text{full}})
```

- **Computational Complexity & Algorithmic Bounds**: The incremental dependency tracking and invalidation pipeline executes within Complexity Class $`\mathbf{P}`$`. Transitive dependency reachability closure over DAG `$`G = (V, E)`$` executes in deterministic linear time `$`O(|V| + |E|)`$` via breadth-first search or topological order traversal. Cache lookup and reuse for unimpacted units execute in `$`O(1)`$` amortized time per unit via hash-indexed lookups. Recomputation of the invalidated AST subgraphs scales strictly as `$`O(N_{\text{inv}})`$` time, where `$`N_{\text{inv}} = \sum_{v \in \text{Invalidated}(M)} |\text{Tokens}(v)| \le N`$`, where `$`N`$` is the total token count of the full schema suite. Peak auxiliary memory for the dependency graph and cache directory structures is bounded by `$`O(|V| + |E|)`$.

- **Verification & Conformance Criteria**: Automated verification harnesses shall evaluate incremental compilation behavior across synthetic multi-unit schema suites (e.g., `Package_0` containing interdependent units `CompilationUnit_Alpha`, `CompilationUnit_Beta`, and `CompilationUnit_Gamma`). The test framework shall inject isolated content mutations into leaf and intermediate units and verify that:
  1. Exactly the units in $`\text{Invalidated}(M)`$ undergo re-lexing, re-parsing, and re-lowering, validated by monitoring compilation phase execution counters.
  2. All units in $`V \setminus \text{Invalidated}(M)`$ are loaded directly from the AST cache without disk re-reads.
  3. The resulting AST $`\mathcal{A}_{\text{inc}}`$` matches the clean-compilation AST `$`\mathcal{A}_{\text{full}}`$ with a 0-byte diff across all serialized nodes and Merkle tree roots.
  If an invalidation cycle is detected or if an invalidated node cannot be reconciled against its upstream cached dependencies, the compiler shall halt execution and emit diagnostic error code `E0100` with the topological coordinates and identifier of the faulted node.
