### REQ-0044: Lossless AST Serialization & Deserialization (JSON & CBOR Formats)

- **Normative Statement**: The core compiler Abstract Syntax Tree (AST) engine within the Core Metamodel, Node Arena & AST Graph Engine shall provide high-performance, deterministic, lossless bidirectional serialization and deserialization of the compiled model AST to and from minified JavaScript Object Notation (JSON, conforming to RFC 8259) and binary Concise Binary Object Representation (CBOR, conforming to RFC 8949) formats. The serialization and deserialization codecs must preserve all AST structural entities, including packages, part definitions, port definitions, item definitions, connection definitions, action definitions, constraint definitions, calculation definitions, state definitions, metadata annotations, expressions, attributes, and cross-node relational edges.

  The serialization and deserialization engine shall adhere strictly to the following normative guarantees:
  1. Complete Structural and Semantic Preservation: The serialization codecs shall losslessly serialize and deserialize every AST entity and graph edge, preserving node kinds, metamodel typing relations, parent-child containment hierarchies, directed cross-tree references, multiplicity intervals $[l, u]$ with $u \in \mathbb{N}_0 \cup \{ \infty \}$, port directions (`in`, `out`, `inout`) and conjugation markers per REQ-0038, attribute value literals, constraint expressions, and exact source code provenance coordinates $\langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle$ per REQ-0002.
  2. Deterministic UUIDv5 Node Anchors: In accordance with Architectural Directive 1 and REQ-0010, every serialized AST node must store a deterministic RFC 4122 UUIDv5 identifier derived from the fixed compiler namespace OID ($\text{OID}_{\text{DEAP}}$) and the canonical fully qualified topological path of the node (e.g., `Package_0::PartDef_Alpha`). Time-based UUIDs (such as UUIDv1 or UUIDv7) are strictly prohibited.
  3. Contiguous Node Arena Lowering: The deserialization engine shall reconstruct AST nodes directly into contiguous typed bump arena storage in accordance with REQ-0009 and REQ-0034. AST inter-node relationships, parent links, and child lists must be addressed exclusively via deterministic 64-bit typed integer node handles (`NodeHandle` / `NodeIndex`) in accordance with REQ-0035, eliminating raw virtual memory pointer indirection and deserialization pointer-swizzling tables.
  4. Deduplicated String Interner Symbol Table: The serialized payload must store string literals, identifier names, docstrings, and qualified path segments within a centralized, deduplicated string symbol table segment ($\mathcal{T}_{\text{sym}}$). Individual AST nodes must store 32-bit unsigned scalar symbol handles (`SymbolId`) referencing this table. Copying string bytes from the serialized payload into the global symbol interner pool during deserialization shall constitute the sole permitted architectural exception to the zero-copy memory management invariant, in strict accordance with Architectural Directive 3 and REQ-0036.
  5. Minified Canonical JSON Codec: The JSON serializer shall emit valid UTF-8 text conforming strictly to RFC 8259 without extraneous whitespace, indentation, or trailing delimiters. Object keys must be serialized in a deterministic, canonical schema order. Floating-point numerical values must be encoded without precision loss in accordance with IEEE 754-2008 specifications. String literals must escape control characters in strict accordance with RFC 8259.
  6. Compact Binary CBOR Codec: The CBOR serializer shall emit compact binary streams conforming strictly to RFC 8949 using deterministic canonical encoding rules. The CBOR format shall utilize major type 0 and major type 1 variable-length integer encoding to represent arena slot indices and generation counters with minimal byte overhead, major type 2 byte-strings for raw 16-byte RFC 4122 UUID binary payloads and cryptographic hash values, major type 3 text-strings for deduplicated symbol table records, and major type 4 and major type 5 definite-length arrays and maps for AST node collections and structural properties.
  7. Binary Compaction Efficiency Bound: The serialized binary CBOR representation must achieve a strict byte compaction threshold relative to the minified canonical JSON representation, satisfying $|\text{CBOR}(\mathcal{A})| \le 0.40 \cdot |\text{JSON}(\mathcal{A})|$ across all valid compiled MBSE models, guaranteeing at least a 60% reduction in serialized artifact byte size.
  8. Structural Round-Trip Isomorphism & Bitwise Idempotency: The deserialization $\mathcal{D}_{\mathcal{F}}$ of a serialized model $\mathcal{S}_{\mathcal{F}}(\mathcal{A})$ must be strictly isomorphic to the original compiled AST $\mathcal{A}$ ($\mathcal{D}_{\mathcal{F}}(\mathcal{S}_{\mathcal{F}}(\mathcal{A})) \cong \mathcal{A}$). Serializing a deserialized AST must produce a bit-for-bit identical byte stream ($\mathcal{S}_{\mathcal{F}}(\mathcal{D}_{\mathcal{F}}(\mathcal{S}_{\mathcal{F}}(\mathcal{A}))) = \mathcal{S}_{\mathcal{F}}(\mathcal{A})$), guaranteeing zero diff churn across iterative compiler invocations in accordance with REQ-0003.
  9. Bounded Work-Stealing Concurrency: Parallel serialization and deserialization across independent compilation units, module partitions, or context-bounded AST slices (REQ-0049, REQ-0050) shall be executed strictly over the compiler's bounded work-stealing thread pool with worker bound $N_{\text{max\_workers}}$ in accordance with Architectural Directive 2 and REQ-0012. Manual or unbounded thread spawning is strictly banned.
  10. Synchronization Token Error Recovery & Diagnostic Binding: In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, the deserialization engine shall implement synchronization token error recovery on record and delimiter boundaries. If a corrupted byte sequence, truncated buffer, schema version incompatibility, or unresolvable node handle index is encountered, the deserializer shall record a structured diagnostic record binding diagnostic error code `E0200` per REQ-0191 with exact byte offset and offending token context, resynchronize on the next entity boundary, and accumulate diagnostics rather than aborting immediately. If accumulated diagnostics reach the configured sink limit $C_{\text{max\_errors}}$, the compiler shall emit diagnostic error code `E0199` and terminate gracefully.
  11. Deterministic Non-Panicking Contract & Release Performance Bounds: In accordance with Architectural Directive 5, REQ-0011, and REQ-0196, the serialization and deserialization engines shall enforce a deterministic, non-panicking execution contract with total-function termination across all inputs. In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests, the engine shall deserialize a $100,000$-node model from CBOR in under $15\text{ ms}$, with total serialization latency under $25\text{ ms}$ and peak RSS memory under $100\text{ MB}$.
  12. Zero Domain Contamination: All diagnostic records, test suites, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Classifier_Alpha`, `PartDef_0`, `PortDef_1`, `Flow_A`, `param_x : Real`), with zero hardcoded domain concepts and zero mock data.

- **Formal Invariant**: Let $\mathcal{A} = (\mathcal{V}_{\text{AST}}, \mathcal{E}_{\text{AST}}, \mathcal{T}_{\text{sym}}, \Phi_{\text{meta}})$ denote a compiled abstract syntax tree model, where:

$$
\begin{aligned}
\mathcal{V}_{\text{AST}} &= \{ n_0, n_1, \dots, n_{N-1} \} \quad (N = |\mathcal{V}_{\text{AST}}| \in \mathbb{N}_0) \\
\mathcal{E}_{\text{AST}} &\subseteq \mathcal{V}_{\text{AST}} \times \mathcal{V}_{\text{AST}} \times \mathcal{K}_{\text{edge}} \\
\mathcal{T}_{\text{sym}} &= \langle s_0, s_1, \dots, s_{M-1} \rangle \quad (s_i \in \Sigma_{\text{UTF8}}^*, \, M = |\mathcal{T}_{\text{sym}}| \in \mathbb{N}_0) \\
\Phi_{\text{meta}} &= \langle \text{schema\_version}, \text{format\_kind}, \text{root\_uuid}, \text{entity\_count} \rangle
\end{aligned}
$$

Each node $n \in \mathcal{V}_{\text{AST}}$ is formalized as a 9-tuple:

$$
n = \langle \text{id}, \text{uuid}, \text{kind}, \text{span}, \text{name}, \text{parent}, \text{children}, \text{attrs}, \text{flags} \rangle
$$

where:
- $\text{id} \in \mathbb{U}_{64}$ is the 64-bit generational arena node handle $\text{NodeHandle}$,
- $\text{uuid} \in \Sigma_{\text{byte}}^{16}$ is the 128-bit RFC 4122 UUIDv5 identifier:

$$
\text{uuid}(n) = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))
$$

- $\text{kind} \in \mathcal{K}_{\text{node}}$ is the metamodel classifier discriminator tag,
- $\text{span} = \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \in \mathbb{U}_{32} \times \mathbb{U}_{32} \times \mathbb{U}_{32} \times \mathbb{U}_{32} \times \mathbb{U}_{32}$ is the exact source provenance coordinate span,
- $\text{name} \in \mathbb{U}_{32}$ is the scalar symbol handle $\text{SymbolId} \in \{0, \dots, M-1\}$,
- $\text{parent} \in \mathbb{U}_{64} \cup \{ \bot_{\text{handle}} \}$ is the handle of the enclosing parent node,
- $\text{children} \in \text{Seq}(\mathbb{U}_{64})$ is the ordered sequence of child node handles,
- $\text{attrs} \in \text{Map}(\mathbb{U}_{32}, \mathcal{V}_{\text{attr}})$ is the dictionary of attribute key-value pairs,
- $\text{flags} \in \mathbb{U}_{32}$ is the bitfield containing boolean configuration markers (including port conjugation flag $c \in \{0, 1\}$).

Let $\mathcal{F} \in \{ \text{JSON}, \text{CBOR} \}$ denote the target serialization format. The serialization operators $\mathcal{S}_{\mathcal{F}}$ and deserialization operators $\mathcal{D}_{\mathcal{F}}$ are formalized as:

$$
\begin{aligned}
\mathcal{S}_{\text{JSON}} &: \mathcal{A}_{\text{model}} \longrightarrow \Sigma_{\text{UTF8}}^* \\
\mathcal{S}_{\text{CBOR}} &: \mathcal{A}_{\text{model}} \longrightarrow \Sigma_{\text{byte}}^* \\
\mathcal{D}_{\text{JSON}} &: \Sigma_{\text{UTF8}}^* \longrightarrow \mathcal{A}_{\text{model}} \cup \mathcal{E}_{\text{diag}} \\
\mathcal{D}_{\text{CBOR}} &: \Sigma_{\text{byte}}^* \longrightarrow \mathcal{A}_{\text{model}} \cup \mathcal{E}_{\text{diag}}
\end{aligned}
$$

Round-Trip Structural Isomorphism Invariant:
For every valid compiled AST $\mathcal{A}$ and format $\mathcal{F} \in \{ \text{JSON}, \text{CBOR} \}$:

$$
\mathcal{D}_{\mathcal{F}}(\mathcal{S}_{\mathcal{F}}(\mathcal{A})) \cong \mathcal{A}
$$

Structural isomorphism $\mathcal{A}' \cong \mathcal{A}$ holds if and only if there exists a bijective mapping $f : \mathcal{V}_{\text{AST}} \to \mathcal{V}_{\text{AST}}'$ such that for all $n \in \mathcal{V}_{\text{AST}}$ and $n' = f(n)$:

$$
\begin{aligned}
\text{uuid}(n') &= \text{uuid}(n) \\
\text{kind}(n') &= \text{kind}(n) \\
\text{span}(n') &= \text{span}(n) \\
\text{Resolve}(\mathcal{I}, \text{name}(n')) &= \text{Resolve}(\mathcal{I}, \text{name}(n)) \\
\text{flags}(n') &= \text{flags}(n) \\
\text{parent}(n') &= \begin{cases} \bot_{\text{handle}}, & \text{if } \text{parent}(n) = \bot_{\text{handle}} \\ f(\text{parent}(n)), & \text{otherwise} \end{cases} \\
|\text{children}(n')| &= |\text{children}(n)| \\
\forall i \in \{0, \dots, |\text{children}(n)| - 1\}, \quad \text{children}(n')[i] &= f(\text{children}(n)[i]) \\
\text{attrs}(n') &= \text{attrs}(n)
\end{aligned}
$$

Element-Wise Preservation Invariant:
Every individual node slot $n \in \mathcal{V}_{\text{AST}}$ satisfies value dereference equivalence under round-trip serialization and deserialization:

$$
\forall n \in \mathcal{V}_{\text{AST}}, \quad \text{Deref}(\mathcal{D}_{\mathcal{F}}(\mathcal{S}_{\mathcal{F}}(n))) \equiv n
$$

Bitwise Serialization Idempotency Invariant:
Serializing a deserialized AST reproduces the exact original serialization byte stream:

$$
\begin{aligned}
\mathcal{S}_{\text{JSON}}(\mathcal{D}_{\text{JSON}}(\mathcal{S}_{\text{JSON}}(\mathcal{A}))) &= \mathcal{S}_{\text{JSON}}(\mathcal{A}) \\
\mathcal{S}_{\text{CBOR}}(\mathcal{D}_{\text{CBOR}}(\mathcal{S}_{\text{CBOR}}(\mathcal{A}))) &= \mathcal{S}_{\text{CBOR}}(\mathcal{A})
\end{aligned}
$$

Binary Compaction Efficiency Invariant:
The byte size of the serialized CBOR payload is strictly bounded by 40% of the byte size of the minified JSON payload for any compiled model satisfying $|\mathcal{V}_{\text{AST}}| \ge 100$:

$$
|\mathcal{S}_{\text{CBOR}}(\mathcal{A})| \le 0.40 \cdot |\mathcal{S}_{\text{JSON}}(\mathcal{A})|
$$

Centralized Symbol Deduplication Invariant:
The symbol table $\mathcal{T}_{\text{sym}}$ embedded in the serialized payload contains strictly unique string records:

$$
\forall i, j \in \{0, \dots, |\mathcal{T}_{\text{sym}}| - 1\}, \quad i \ne j \implies \mathcal{T}_{\text{sym}}[i] \ne \mathcal{T}_{\text{sym}}[j]
$$

and all node symbol references strictly index into $\mathcal{T}_{\text{sym}}$:

$$
\forall n \in \mathcal{V}_{\text{AST}}, \quad 0 \le \text{name}(n) \lt |\mathcal{T}_{\text{sym}}|
$$

Diagnostic Code Trigger Invariant:
Malformed serialization headers, truncated payload streams, schema version mismatches, or corrupted node handle indices deterministically trigger structured diagnostics with diagnostic error code `E0200` per REQ-0191:

$$
\begin{aligned}
\text{InvalidHeader}(\mathcal{B}) &\implies \text{Diagnostic}(p_{\text{byte}}, \text{DiagnosticCode::E0200}, \text{InvalidAstHeaderMagic}) \in \mathcal{D}_{\text{sink}} \\
\text{TruncatedStream}(\mathcal{B}) &\implies \text{Diagnostic}(p_{\text{byte}}, \text{DiagnosticCode::E0200}, \text{TruncatedAstPayloadStream}) \in \mathcal{D}_{\text{sink}} \\
\text{UnsupportedVersion}(v) &\implies \text{Diagnostic}(p_{\text{byte}}, \text{DiagnosticCode::E0200}, \text{AstSchemaVersionIncompatible}) \in \mathcal{D}_{\text{sink}} \\
\text{UnresolvedHandle}(h) &\implies \text{Diagnostic}(p_{\text{byte}}, \text{DiagnosticCode::E0200}, \text{DeserializationHandleUnresolved}) \in \mathcal{D}_{\text{sink}} \\
\neg(\mathcal{D}_{\mathcal{F}}(\mathcal{S}_{\mathcal{F}}(\mathcal{A})) \cong \mathcal{A}) &\implies \text{Diagnostic}(p_{\text{byte}}, \text{DiagnosticCode::E0200}, \text{AstRoundTripMismatch}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

Diagnostic Taxonomy Containment Invariant:
All diagnostics emitted by the serialization and deserialization engine reside strictly within the Subsystem 3 metamodel and typing family or the global error termination sentinel:

$$
\forall d \in \mathcal{D}_{\text{ast\_codec}}, \quad \text{code}(d) \in \{ \text{DiagnosticCode::E0200}, \text{DiagnosticCode::E0199} \} \subset \mathcal{E}_{\text{type}} \cup \mathcal{E}_{\text{ingest}}
$$

- **Computational Complexity & Algorithmic Bounds**: The AST serialization and deserialization engine executes strictly within Complexity Class $\mathbf{P}$. The computational complexity and resource bounds across data structures and operations are formalized as follows:
  1. Serialization Time Complexity: Serializing a compiled AST model $\mathcal{A}$ containing $N = |\mathcal{V}_{\text{AST}}|$ nodes, $E = |\mathcal{E}_{\text{AST}}|$ relational edges, and $M = |\mathcal{T}_{\text{sym}}|$ interned string symbols traverses the contiguous arena buffers in a single sequential pass. Because each node slot is laid out contiguously with 64-bit alignment and integer handles are directly encoded without pointer indirection, the total serialization time is strictly linear:

$$
T_{\text{serialize}}(\mathcal{A}) \in O(N + E + M) = O(N)
$$

  2. Deserialization Time Complexity: Deserializing a payload buffer $\mathcal{B}$ of size $|\mathcal{B}|$ bytes operates in a single linear scan. The CBOR binary decoder evaluates major types and variable-length integer headers in $O(1)$ constant time per token. Reconstructing node slots into pre-allocated contiguous bump arena storage requires $O(1)$ amortized allocation time per node. Inserting deduplicated string symbols into the global symbol interner pool takes $O(1)$ amortized time per symbol. Total deserialization time is strictly linear in the input byte size:

$$
T_{\text{deserialize}}(\mathcal{B}) \in O(|\mathcal{B}|) = O(N)
$$

  3. High-Throughput Empirical Bound: In compiled Release mode (`--release`), the CBOR deserialization engine shall reconstruct a model containing $N = 100,000$ AST nodes in under $15\text{ ms}$ on standard reference hardware:

$$
T_{\text{deser}}(10^5\text{ nodes}) \le 15\text{ ms}
$$

  4. Parallel Throughput under Bounded Work-Stealing: When serializing or deserializing $K$ independent compilation units or AST slices across $N_{\text{max\_workers}}$ threads in the bounded work-stealing thread pool (Directive 2, REQ-0012), wall-clock execution time is bounded by:

$$
T_{\text{parallel}}(N, K) \in O\left( \frac{N}{N_{\text{max\_workers}}} + \max_{1 \le j \le K} N_j + \log N_{\text{max\_workers}} \right)
$$

  5. Space Complexity: The serialization engine requires $O(N)$ linear space for the output byte buffer. The deserialization engine constructs the AST directly into the contiguous typed bump arena without per-node heap allocations, consuming $O(N \cdot S_{\text{slot}})$ arena memory where $S_{\text{slot}} = \text{sizeof}(\text{NodeSlot})$. Auxiliary stack depth for hierarchical traversal during deserialization is bounded by $D_{\text{max}} \le 64$, requiring $O(D_{\text{max}}) = O(1)$ auxiliary stack space.

- **Verification & Conformance Criteria**: Conformance shall be verified deterministically through automated test suites and profiling harnesses operating on synthetic models containing abstract MBSE entities (`Package_0`, `Classifier_Alpha`, `PartDef_0`, `PortDef_1`, `Flow_A`, `param_x : Real`). Conformance validation shall enforce the following test gates:
  1. Structural Round-Trip Isomorphism Gate (JSON & CBOR): Construct a synthetic AST model $\mathcal{A}$ containing $10^4$ nodes. Serialize $\mathcal{A}$ to minified JSON and binary CBOR formats, deserialize each back into independent node arenas $\mathcal{A}_{\text{JSON}}'$ and $\mathcal{A}_{\text{CBOR}}'$, and assert that $\mathcal{A}_{\text{JSON}}' \cong \mathcal{A}$ and $\mathcal{A}_{\text{CBOR}}' \cong \mathcal{A}$ with 100% attribute, span, handle, and UUID equality across all nodes.
  2. Element-Wise Value Dereference Equality Gate: For every node $n \in \mathcal{V}_{\text{AST}}$, assert that $\text{Deref}(\mathcal{D}(\mathcal{S}(n))) \equiv n$ holds identically across both JSON and CBOR codecs.
  3. Bit-for-Bit Serialization Idempotency Gate: Perform three successive serialize-deserialize-serialize cycles ($\mathcal{S} \to \mathcal{D} \to \mathcal{S} \to \mathcal{D} \to \mathcal{S}$) on synthetic models. Assert bitwise identical byte streams ($\mathcal{S}_1 == \mathcal{S}_2 == \mathcal{S}_3$) for both JSON and CBOR formats, verifying zero diff churn across runs in accordance with REQ-0003.
  4. Binary Compaction Efficiency Gate: Benchmark serialized payload byte sizes across synthetic AST models scaling from $N = 10^2$ to $N = 10^5$ nodes. Assert that $|\text{CBOR}(\mathcal{A})| \le 0.40 \cdot |\text{JSON}(\mathcal{A})|$ holds across 100% of benchmark configurations.
  5. Centralized String Deduplication Gate: Ingest an AST model containing 1,000 nodes referencing 50 distinct identifier strings. Assert that the serialized string symbol table $\mathcal{T}_{\text{sym}}$ contains exactly 50 entries, verifying that individual node slots store compact 32-bit scalar symbol handles (`SymbolId`) rather than inline duplicated string literals.
  6. Deterministic UUIDv5 Anchor Gate: Verify that 100% of node UUIDs in deserialized AST artifacts match deterministic RFC 4122 UUIDv5 hashes derived from the compiler namespace OID and canonical fully qualified paths per Directive 1 and REQ-0010.
  7. Deserialization Error Recovery and Diagnostic Gate: Inject deliberate corruptions into serialized byte streams (corrupted magic header, truncated payload at byte offset $k$, invalid UTF-8 byte sequence in symbol table, out-of-bounds node index handle, unsupported schema version `99.0.0`). Assert that the engine emits structured diagnostic records with diagnostic error code `E0200` per REQ-0191, capturing exact byte offsets without crashing. Inject errors exceeding $C_{\text{max\_errors}}$ and assert graceful termination with diagnostic code `E0199` per Directive 4.
  8. Total-Function Panic-Free Execution Gate (Directive 5): Execute property-based fuzz testing over $10^5$ randomized, truncated, and malformed bitstreams. Assert total-function termination with structured diagnostic reporting and zero panics across all iterations.
  9. Release Mode Latency and Memory Budget Gate (Directive 5 & REQ-0196): In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests, deserialize a $100,000$-node model from CBOR in strictly under $15\text{ ms}$, assert total serialization latency under $25\text{ ms}$, and assert peak memory RSS strictly under $100\text{ MB}$.
  10. Bounded Work-Stealing Parallelism Gate: Execute concurrent serialization and deserialization across $K = 16$ compilation units on a thread pool bounded by $N_{\text{max\_workers}} = 4$ worker threads. Assert data-race freedom, isolated arena allocations, and bit-for-bit identical outputs.
  11. Abstract MBSE Placeholder Compliance Gate: Assert that 100% of test entities, diagnostics, and documentation employ synthetic abstract placeholders (`Package_0`, `Classifier_Alpha`, `PartDef_0`, `PortDef_1`, `Flow_A`, `param_x : Real`), with zero hardcoded domain concepts and zero mock data.
