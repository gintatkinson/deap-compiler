### REQ-0032: Deterministic Qualified-Name Symbol Sorting for Canonical Model Emission

- **Normative Statement**: The textual emitter and model serialization engine within the Universal Schema Ingestion Engine shall sort all packages, classifiers, ports, attributes, connections, constraints, behaviors, and model declarations strictly by canonical fully qualified name prior to textual emission (including canonical SysML v2 textual emission to `schema/model.sysml` per REQ-0031, intermediate AST serialization per REQ-0044, interface control document synthesis per REQ-0145, and code generation manifest serialization per REQ-0178). Symbol sorting shall be applied recursively and deterministically across all structural and behavioral element classes: root packages, compilation units, child packages, classifiers (part definitions, port definitions, item definitions, connection definitions, interface definitions, calculation definitions, constraint definitions, requirement definitions, action definitions, state definitions), feature usages (ports, attributes, parameters, internal parts, item flows), and state machine elements (regions, states, transitions, actions). The canonical fully qualified name ($`\mathcal{N}_{\text{topological}}(d)`$) shall be constructed by recursively concatenating enclosing ancestor namespace identifiers separated by canonical scope delimiters (`::`), rooted at the top-level compilation unit or root package (e.g., `Package_0::Classifier_Alpha::Port_1`). All identifier segments shall be sanitized ASCII representations adhering to REQ-0019. Symbol sorting shall evaluate qualified names according to standard lexicographical ASCII byte ordering ($`\prec_{\text{lex}}`$), establishing a strict total order over all declarations within each scope and across the entire AST. If two declarations within the same scope share an identical fully qualified name and identical metaclass, the engine shall report a duplicate symbol definition collision and deterministically emit diagnostic error code `E0102` in accordance with the diagnostic taxonomy of REQ-0191. In accordance with Architectural Directive 4 (Synchronization Token Error Recovery), if duplicate symbol definitions or invalid symbol tokens are detected, the emitter shall record the structured diagnostic `E0102`, substitute a typed sentinel error element $`\bot_{\text{sym}}`$`, and continue sorting and serializing remaining declarations without aborting the emission pass prematurely. If accumulated diagnostic records reach the capacity limit `$`C_{\text{max\_errors}}`$, the emitter shall emit diagnostic code `E0199` and terminate gracefully. In accordance with Architectural Directive 1 (REQ-0010), when generating deterministic UUID identifiers, Merkle tree digests, or specification anchors from sorted symbol rosters, the engine shall hash canonical fully qualified names using RFC 4122 UUIDv5 seeded by the fixed compiler namespace OID. In accordance with Architectural Directive 2 (REQ-0012), parallel symbol sorting passes across independent packages or compilation units shall execute strictly within a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$, guaranteeing concurrency schedule independence such that emitted text artifacts remain bit-for-bit identical regardless of thread scheduling order or worker count. In accordance with Architectural Directive 3 (REQ-0036), interning qualified name tokens into the global symbol interner pool during sorting key generation and symbol resolution is the sole permitted exception to the zero-copy invariant. In accordance with Architectural Directive 5 (REQ-0011, REQ-0196), symbol sorting and emission shall enforce a total, non-panicking execution contract with deterministic error propagation across all inputs. Performance latency (< 25 ms) and RSS memory overhead (< 100 MB) shall be evaluated exclusively in compiled Release mode (`--release`) under isolated benchmark harnesses. The emission engine shall guarantee the Zero Diff Churn Invariant: repeated emission passes over unchanged AST representations shall produce bit-for-bit identical, byte-level output files, eliminating non-deterministic diff churn across repeated compilations and version control commits. All illustrative examples, test models, and diagnostic messages shall strictly use synthetic abstract MBSE placeholders (e.g., `Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Port_1`, `Port_2`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts and mock data.

- **Formal Invariant**: Let $`\mathcal{A} = (\mathcal{D}, \mathcal{E}_{\text{contain}})`$` denote an Abstract Syntax Tree (AST) representation, where `$`\mathcal{D} = \{ d_1, d_2, \dots, d_M \}`$` is the set of `$`M`$` declarations and `$`\mathcal{E}_{\text{contain}}`$` defines the structural containment forest. Each declaration `$`d \in \mathcal{D}`$ is formalized as a 5-tuple:

```math
d = \langle \text{id}, \text{parent}, \tau, \sigma, \text{span} \rangle
```

where the constituent domains and attributes are defined as:

```math
\begin{aligned}
\text{id} &\in \mathcal{S}_{\text{sym}} \quad (\text{sanitized interned symbol identifier}) \\
\text{parent} &\in \mathcal{D} \cup \{ \bot \} \quad (\text{immediate enclosing parent declaration}) \\
\tau &\in \mathcal{T}_{\text{kind}} \quad (\text{metamodel element kind or classifier metaclass}) \\
\sigma &\in \Sigma^* \quad (\text{canonical fully qualified topological name}) \\
\text{span} &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
\end{aligned}
```

The canonical fully qualified topological name function $`\text{QName} : \mathcal{D} \to \Sigma^*`$ is defined recursively over the parent containment hierarchy:

```math
\text{QName}(d) = 
\begin{cases}
\text{id}(d), & \text{if } \text{parent}(d) = \bot \\
\text{QName}(\text{parent}(d)) \mathbin{\Vert} \text{"::"} \mathbin{\Vert} \text{id}(d), & \text{if } \text{parent}(d) \ne \bot
\end{cases}
```

Let $`\Sigma^*`$` denote the ASCII byte alphabet. Let `$`s_1, s_2 \in \Sigma^*`$` be two strings of lengths `$`|s_1| = m`$` and `$`|s_2| = n`$`, represented by byte sequences `$`s_1 = \langle b_{1, 0}, b_{1, 1}, \dots, b_{1, m-1} \rangle`$` and `$`s_2 = \langle b_{2, 0}, b_{2, 1}, \dots, b_{2, n-1} \rangle`$` where `$`b_{k, j} \in [0, 255]`$`. The lexicographical ASCII byte precedence relation `$`\prec_{\text{lex}}`$ is defined as:

```math
s_1 \prec_{\text{lex}} s_2 \iff \exists i \ge 0 \text{ s.t. } (i \le \min(m, n)) \wedge (\forall j \lt i, \; b_{1, j} = b_{2, j}) \wedge \big((i \lt m \wedge i \lt n \implies b_{1, i} \lt b_{2, i}) \wedge (i = m \implies m \lt n)\big)
```

The canonical declaration ordering relation $`\prec_{\text{sym}}`$` over `$`\mathcal{D} \times \mathcal{D}`$` evaluates qualified names with a deterministic secondary tie-breaker over the static metaclass ordinal `$`\text{KindOrdinal} : \mathcal{T}_{\text{kind}} \to \mathbb{N}`$:

```math
d_1 \prec_{\text{sym}} d_2 \iff (\text{QName}(d_1) \prec_{\text{lex}} \text{QName}(d_2)) \vee \big(\text{QName}(d_1) = \text{QName}(d_2) \wedge \text{KindOrdinal}(\tau(d_1)) \lt \text{KindOrdinal}(\tau(d_2))\big)
```

On any collision-free AST $`\mathcal{A}_{\text{valid}}`$`, the ordering relation `$`\prec_{\text{sym}}`$ satisfies the axioms of a strict total order:

1. Irreflexivity:

```math
\forall d \in \mathcal{D}, \quad \neg (d \prec_{\text{sym}} d)
```

2. Asymmetry:

```math
\forall d_1, d_2 \in \mathcal{D}, \quad (d_1 \prec_{\text{sym}} d_2) \implies \neg (d_2 \prec_{\text{sym}} d_1)
```

3. Transitivity:

```math
\forall d_1, d_2, d_3 \in \mathcal{D}, \quad (d_1 \prec_{\text{sym}} d_2) \wedge (d_2 \prec_{\text{sym}} d_3) \implies (d_1 \prec_{\text{sym}} d_3)
```

4. Totality:

```math
\forall d_1 \ne d_2 \in \mathcal{D}, \quad (d_1 \prec_{\text{sym}} d_2) \oplus (d_2 \prec_{\text{sym}} d_1)
```

Hierarchical Canonical Scope Ordering Invariant: For any enclosing parent container $`p \in \mathcal{D} \cup \{ \bot \}`$`, let `$`\text{Children}(p) = \{ c \in \mathcal{D} \mid \text{parent}(c) = p \}`$` denote the set of declarations directly owned by `$`p`$`, with cardinality `$`k = |\text{Children}(p)|`$`. The canonical serialized child sequence `$`\text{Children}_{\text{sorted}}(p) = \langle c_{\pi(1)}, c_{\pi(2)}, \dots, c_{\pi(k)} \rangle`$ satisfies:

```math
\forall i \in \{1, \dots, k - 1\}, \quad c_{\pi(i)} \prec_{\text{sym}} c_{\pi(i+1)}
```

Zero Diff Churn & Bitwise Determinism Invariant: Let $`\mathcal{E} : \mathcal{A} \to \{0, 1\}^*`$` denote the total canonical model emission function mapping an AST to a serialized byte stream. Let `$`\Pi(\mathcal{A})`$` denote the set of all isomorphic AST representations generated under arbitrary declaration insertion permutations, differing hash table iteration orders, or worker thread completion sequences. For any two AST representations `$`\mathcal{A}_1, \mathcal{A}_2 \in \Pi(\mathcal{A})`$:

```math
\forall \mathcal{A}_1, \mathcal{A}_2 \in \Pi(\mathcal{A}), \quad \mathcal{E}(\mathcal{A}_1) = \mathcal{E}(\mathcal{A}_2)
```

Expressed cryptographically via the SHA-256 hash function:

```math
\forall \mathcal{A}_1, \mathcal{A}_2 \in \Pi(\mathcal{A}), \quad \text{SHA256}(\mathcal{E}(\mathcal{A}_1)) = \text{SHA256}(\mathcal{E}(\mathcal{A}_2))
```

and evaluated as zero diff churn against existing disk artifacts:

```math
\text{Diff}(\mathcal{E}(\mathcal{A}_1), \mathcal{E}(\mathcal{A}_2)) = \emptyset
```

Concurrency Schedule Independence Invariant (Architectural Directive 2): Let $`\sigma_1, \sigma_2`$` represent distinct non-deterministic thread execution schedules across `$`W \le N_{\text{max\_workers}}`$ worker threads in the bounded work-stealing pool. Canonical emission satisfies:

```math
\forall \sigma_1, \sigma_2, \quad \mathcal{E}(\mathcal{A}; \sigma_1) = \mathcal{E}(\mathcal{A}; \sigma_2)
```

Diagnostic Code Binding Invariant: Symbol collisions and determinism failures trigger structured diagnostics in accordance with REQ-0191:

```math
\begin{aligned}
\exists d_a \ne d_b \text{ s.t. } \text{QName}(d_a) = \text{QName}(d_b) \wedge \tau(d_a) = \tau(d_b) &\implies \text{Diagnostic}(d_b, \text{DiagnosticCode::E0102}, \text{DuplicateSymbolDeclaration}) \in \mathcal{D}_{\text{diag}} \\
\text{SHA256}(\mathcal{E}(\mathcal{A}_1)) \ne \text{SHA256}(\mathcal{E}(\mathcal{A}_2)) &\implies \text{Diagnostic}(\text{span}_{\text{root}}, \text{DiagnosticCode::E0100}, \text{BitwiseDeterminismViolation}) \in \mathcal{D}_{\text{diag}} \\
|\mathcal{D}_{\text{diag}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{diag}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
```

Diagnostic Taxonomy Containment Invariant: All emitted diagnostic codes strictly reside within the Subsystem 2 ingestion and lexer taxonomy established in REQ-0191:

```math
\forall D \in \mathcal{D}_{\text{sort\_diag}}, \quad \text{code}(D) \in \{ \text{DiagnosticCode::E0100}, \text{DiagnosticCode::E0102}, \text{DiagnosticCode::E0199} \} \subset \mathcal{E}_{\text{ingest}}
```

- **Computational Complexity & Algorithmic Bounds**: Deterministic qualified-name symbol sorting and canonical model emission execute within Complexity Class $`\mathbf{P}`$`. Let `$`M = |\mathcal{D}|`$` denote the total number of declarations across the entire AST, and let `$`L \le L_{\text{max\_path}} = 1024`$` denote the maximum length of a fully qualified name string. Constructing or referencing interned qualified names executes in `$`O(L)`$` time per declaration, requiring `$`O(L \cdot M) = O(M)`$` operations in total via the global symbol interner pool (Architectural Directive 3). When declarations are partitioned into `$`K`$` discrete parent scopes where scope `$`j`$` contains `$`m_j`$` child declarations (`$`\sum_{j=1}^K m_j = M`$`), sorting each scope using deterministic comparison sort requires `$`O(L \cdot m_j \log m_j)`$` operations. Across all `$`K`$ scopes, aggregate sorting execution time satisfies:

```math
T(M) = \sum_{j=1}^{K} O(L \cdot m_j \log m_j) \le O(L \cdot M \log M)
```

Because the maximum topological path length $`L`$` is bounded by a fixed constant (`$`L \le 1024`$` bytes), overall sequential sorting runtime is strictly bounded by `$`O(M \log M)`$` deterministic time. When sorting across `$`K`$` independent package subtrees in parallel across `$`N_{\text{max\_workers}}`$ threads under a bounded work-stealing pool (Architectural Directive 2), parallel wall-clock execution time is bounded by:

```math
T_{\text{parallel}} = O\left(\frac{L \cdot M \log M}{N_{\text{max\_workers}}} + L \cdot M_{\text{root}} \log M_{\text{root}}\right)
```

where $`M_{\text{root}}`$` is the declaration count at the root scope. Canonical textual emission and in-memory cryptographic hashing over `$`N`$` serialized output bytes execute in `$`O(N)`$` linear time. Auxiliary space complexity is strictly bounded by `$`O(M)`$` for node handles and index permutation vectors in contiguous arena buffers, with zero redundant string cloning. The diagnostic sink capacity is bounded by `$`O(C_{\text{max\_errors}}) = O(1)`$` records, preserving strict `$`O(M)`$ auxiliary memory overhead with zero unbounded heap allocations.

- **Verification & Conformance Criteria**: Automated test suites shall verify deterministic qualified-name symbol sorting and zero diff churn against synthetic MBSE models using abstract placeholders (e.g., `Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Port_1`, `Port_2`, `Flow_A`, `param_x : Real`). Conformance shall be validated through the following deterministic test gates:
  1. Permutation Invariance & Zero Diff Churn Gate: Ingest an AST comprising 1,000 declarations across packages, classifiers, ports, and attributes. Generate 50 distinct randomized orderings of the declaration inputs. Execute canonical qualified-name sorting and textual emission across all 50 permutations. Compute SHA-256 cryptographic digests on all emitted output files. Assert 100% bitwise identity: $`\text{SHA256}(\mathbf{b}_i) = \text{SHA256}(\mathbf{b}_j)`$` for all `$`i, j \in \{1, \dots, 50\}`$`, and assert zero git diff churn (`$`\text{Diff} = \emptyset`$).
  2. Hierarchical Scope Ordering Gate: Ingest an AST with nested packages and classifiers (e.g., `Package_B::Classifier_1`, `Package_A::Subsystem_1::Classifier_Alpha`, `Package_A::Classifier_Beta`). Assert that the emitted canonical text orders top-level packages alphabetically (`Package_A` before `Package_B`), and within `Package_A`, orders member declarations alphabetically by qualified name (`Package_A::Classifier_Beta` before `Package_A::Subsystem_1`).
  3. Lexicographical ASCII Byte Order Gate: Assert exact ASCII byte ordering for alphanumeric and symbol strings (`"Attribute_1"`, `"Attribute_10"`, `"Attribute_2"`, `"Attribute_Alpha"`, `"Attribute_alpha"`, `"Attribute_beta"`). Confirm that uppercase letters precede lowercase letters per standard ASCII ($`0x41 \lt 0x61`$`), and numbers follow ASCII code points (`$`0x31 \lt 0x32`$), verifying that no locale-dependent collation or natural numeric sorting alters canonical order.
  4. Sibling Feature Sorting Gate: Ingest classifiers containing mixtures of ports, attributes, and constraints declared in random order. Assert that ports are sorted alphabetically, attributes are sorted alphabetically, and constraints are sorted alphabetically, producing bitwise-identical classifier bodies across compilations.
  5. Duplicate Symbol Declaration Diagnostic Gate: Ingest an input model containing two declarations with identical fully qualified names within the same package scope (e.g., two distinct classifiers named `Classifier_Alpha` in `Package_0`). Assert that the emitter detects the symbol collision, logs structured diagnostic error code `E0102` (`DuplicateSymbolDeclaration`) with exact line, column, and byte coordinates, substitutes sentinel $`\bot_{\text{sym}}`$, and continues processing remaining symbols.
  6. Multithreading Schedule Independence Gate (Directive 2): Execute sorting and emission across 20 independent package subtrees under varying thread worker counts ($`N_{\text{workers}} \in \{1, 2, 4, 8, 16\}`$) and randomized thread execution yields. Assert that emitted textual artifacts are 100% bitwise identical across all concurrency configurations.
  7. Synchronization Token Error Recovery Gate (Directive 4): Ingest an input containing 10 corrupted or duplicate symbol rows interspersed with 100 valid declarations. Assert that exactly 10 structured diagnostic records binding `E0102` are accumulated, all valid declarations are sorted and emitted canonically, and if errors exceed $`C_{\text{max\_errors}}`$, diagnostic `E0199` is emitted with clean termination.
  8. Deterministic UUIDv5 Anchor Invariant Gate (Directive 1): Assert that UUID anchors generated for sorted symbols derive deterministically from their canonical fully qualified names via RFC 4122 UUIDv5 hashing, remaining invariant across repeated runs, platforms, and directory roots.
  9. Total Non-Panicking Contract Gate (Directive 5): Execute property fuzz testing over degenerate and malformed AST structures (empty trees, 10,000 identical names, deeply nested 128-level packages, cyclic containment graphs). Assert total-function termination with zero panics or unhandled exceptions.
  10. Release Mode Latency & Memory Assurance Gate (Directive 5): Benchmark sorting and emission of $`10^5`$ AST declarations in compiled Release mode (`--release`). Assert execution latency strictly under 25 ms, peak RSS memory consumption under 50 MB (within the 100 MB budget), and zero memory leakage.
