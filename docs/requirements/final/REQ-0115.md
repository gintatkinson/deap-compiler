### REQ-0115: Allen's 13 Qualitative Interval Relations Axiomatic Algebraic Solver

- **Normative Statement**: The spatio-temporal dynamics and discrete state machine solver of Subsystem 6 shall implement an axiomatic algebraic constraint solver for Allen's 13 qualitative temporal interval relations (`before`, `after`, `meets`, `met-by`, `overlaps`, `overlapped-by`, `starts`, `started-by`, `during`, `contains`, `finishes`, `finished-by`, `equals`). The solver shall formalize qualitative temporal relations over occurrence lifecycles, action executions, and state occupancies as compact 13-bit relation algebras, verify endpoint ordering invariants for concrete and parametric temporal intervals, evaluate pairwise relation compositions and converse inversions, and lower qualitative interval relations into systems of linear difference constraints.

  Specifically, the temporal dynamics solver, interval constraint engine, and axiomatic solver pipeline shall strictly enforce the following structural, algebraic, and diagnostic invariants:
  1. **Temporal Interval Definition & Well-Formedness Invariants**:
     - Each temporal interval $`X = [x_s, x_e]`$` shall model a convex, continuous temporal duration on the linear timeline `$`\mathbb{T} = \mathbb{R}`$` bounded by start endpoint `$`x_s`$` and end endpoint `$`x_e`$.
     - The solver shall mandate non-degeneracy with strict positive duration for continuous occurrences, action executions, and state occupancies: $`x_s \lt x_e \iff \text{duration}(X) = x_e - x_s \gt 0`$.
     - Any temporal interval exhibiting an inverted endpoint ordering ($`x_s \gt x_e`$) shall be deterministically rejected at compile time with diagnostic error code `E0400` (`InvertedTemporalInterval`).
     - Degenerate instantaneous event occurrences ($`x_s = x_e`$) shall be formalized as zero-duration limits, handled distinctly from non-degenerate intervals, and prohibited from receiving non-point qualitative relations.
  2. **The 13 Jointly Exhaustive and Mutually Exclusive (JEPD) Qualitative Relations**:
     - The solver shall formalize the 13 primitive atomic qualitative interval relations $`\mathcal{B}_{13} = \{ \mathbf{b}, \mathbf{bi}, \mathbf{m}, \mathbf{mi}, \mathbf{o}, \mathbf{oi}, \mathbf{s}, \mathbf{si}, \mathbf{d}, \mathbf{di}, \mathbf{f}, \mathbf{fi}, \mathbf{eq} \}`$, comprising 6 mutually inverse relation pairs and 1 self-inverse relation:
       * `before` ($`\mathbf{b}`$) and `after` ($`\mathbf{bi}`$`): `$`X \mathbf{b} Y \iff x_e \lt y_s`$`, `$`X \mathbf{bi} Y \iff y_e \lt x_s`$.
       * `meets` ($`\mathbf{m}`$) and `met-by` ($`\mathbf{mi}`$`): `$`X \mathbf{m} Y \iff x_e = y_s`$`, `$`X \mathbf{mi} Y \iff y_e = x_s`$.
       * `overlaps` ($`\mathbf{o}`$) and `overlapped-by` ($`\mathbf{oi}`$`): `$`X \mathbf{o} Y \iff x_s \lt y_s \land y_s \lt x_e \land x_e \lt y_e`$`, `$`X \mathbf{oi} Y \iff y_s \lt x_s \land x_s \lt y_e \land y_e \lt x_e`$.
       * `starts` ($`\mathbf{s}`$) and `started-by` ($`\mathbf{si}`$`): `$`X \mathbf{s} Y \iff x_s = y_s \land x_e \lt y_e`$`, `$`X \mathbf{si} Y \iff x_s = y_s \land y_e \lt x_e`$.
       * `during` ($`\mathbf{d}`$) and `contains` ($`\mathbf{di}`$`): `$`X \mathbf{d} Y \iff y_s \lt x_s \land x_e \lt y_e`$`, `$`X \mathbf{di} Y \iff x_s \lt y_s \land y_e \lt x_e`$.
       * `finishes` ($`\mathbf{f}`$) and `finished-by` ($`\mathbf{fi}`$`): `$`X \mathbf{f} Y \iff y_s \lt x_s \land x_e = y_e`$`, `$`X \mathbf{fi} Y \iff x_s \lt y_s \land x_e = y_e`$.
       * `equals` ($`\mathbf{eq}`$`): `$`X \mathbf{eq} Y \iff x_s = y_s \land x_e = y_e`$.
     - For every pair of well-formed, non-degenerate temporal intervals $`X`$` and `$`Y`$`, exactly one basic relation `$`r \in \mathcal{B}_{13}`$ shall hold, guaranteeing mutual exclusivity and joint exhaustiveness.
  3. **Relation Algebra & 13-Bit Vector Encoding**:
     - The set of all qualitative relations shall be modeled as the power set $`2^{\mathcal{B}_{13}}`$` containing `$`2^{13} = 8192`$` possible relations, representing disjunctions of basic relations (`$`X \, R \, Y \iff \bigvee_{r \in R} X \, r \, Y`$).
     - The solver shall encode each qualitative relation $`R \subseteq \mathcal{B}_{13}`$` as an immutable 13-bit integer bitmask `$`\mathbf{m}_R \in [0, 8191]`$ allocated in contiguous arena storage.
     - The solver shall implement the fundamental algebraic operations:
       * Inversion / Converse ($`R^\smile`$`): Computes the converse relation by bitwise transposition of inverse pairs (`$`\mathbf{b} \leftrightarrow \mathbf{bi}`$`, `$`\mathbf{m} \leftrightarrow \mathbf{mi}`$`, `$`\mathbf{o} \leftrightarrow \mathbf{oi}`$`, `$`\mathbf{s} \leftrightarrow \mathbf{si}`$`, `$`\mathbf{d} \leftrightarrow \mathbf{di}`$`, `$`\mathbf{f} \leftrightarrow \mathbf{fi}`$`, `$`\mathbf{eq} \leftrightarrow \mathbf{eq}`$`), satisfying `$`(R^\smile)^\smile = R`$.
       * Conjunction / Intersection ($`R_1 \cap R_2`$`): Computes the bitwise conjunction (`$`\mathbf{m}_{R_1} \operatorname{AND} \mathbf{m}_{R_2}`$`). If the result is the empty relation `$`\emptyset`$` (`$`0\text{x}0000`$), a temporal contradiction is detected.
       * Disjunction / Union ($`R_1 \cup R_2`$`): Computes the bitwise disjunction (`$`\mathbf{m}_{R_1} \operatorname{OR} \mathbf{m}_{R_2}`$).
       * Complement ($`\overline{R}`$`): Computes the set difference `$`\mathcal{B}_{13} \setminus R`$` via bitwise negation with the universal mask `$`\mathbf{U} = 0\text{x}1\text{FFF}`$.
  4. **Reflexive, Symmetric, and Consistency Properties**:
     - For every temporal interval $`X`$`, the self-relation `$`R(X, X)`$` must be identically equal to the singleton `$`\{ \mathbf{eq} \}`$` (`$`0\text{x}1000`$`). Any constraint asserted on `$`(X, X)`$` that excludes `$`\mathbf{eq}`$ shall be deterministically rejected at compile time with diagnostic error code `E0400` (`TemporalRelationContradiction`).
     - For any interval pair $`(X, Y)`$`, the asserted relations must satisfy relational converse symmetry: `$`R(Y, X) \equiv (R(X, Y))^\smile`$`. Asserting contradictory directional constraints on `$`(X, Y)`$` such that `$`R(X, Y) \cap (R(Y, X))^\smile = \emptyset`$ shall trigger diagnostic error code `E0400` (`TemporalRelationContradiction`).
  5. **Concrete and Parametric Endpoint Evaluation**:
     - When interval endpoints are statically declared constants or compile-time evaluable expressions, the solver shall evaluate the 4 pairwise endpoint relations ($`(x_s \sim y_s)`$`, `$`(x_s \sim y_e)`$`, `$`(x_e \sim y_s)`$`, `$`(x_e \sim y_e)`$` with `$`\sim \;\in \{ \lt, =, \gt \}`$`) and classify the pair into its unique atomic relation `$`r_{\text{eval}} \in \mathcal{B}_{13}`$.
     - If an asserted relation constraint $`R_{\text{asserted}}(X, Y)`$` does not contain `$`r_{\text{eval}}`$` (`$`r_{\text{eval}} \notin R_{\text{asserted}}`$`, i.e., `$`\mathbf{m}_{r_{\text{eval}}} \operatorname{AND} \mathbf{m}_{R_{\text{asserted}}} = 0`$), the compiler shall emit diagnostic error code `E0400` (`TemporalRelationContradiction`).
  6. **Lowering to Difference Constraints (Simple Temporal Problem Translation)**:
     - For downstream SMT verification (REQ-0188) and simulation solving (REQ-0179), the solver shall lower basic qualitative relations into conjunctive systems of endpoint difference constraints of the form $`u - v \le c`$` (`$`u, v \in \{ x_s, x_e, y_s, y_e \}`$`, `$`c \in \mathbb{R}`$).
     - Strict inequalities $`u \lt v`$` shall be encoded with a strictly positive temporal guard offset `$`\epsilon_{\text{dur}} \gt 0`$` as `$`u - v \le -\epsilon_{\text{dur}}`$.
     - Equalities $`u = v`$` shall be encoded as two opposing inequalities: `$`u - v \le 0 \land v - u \le 0`$.
  7. **Architectural Directives Compliance**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every temporal interval AST node, occurrence lifecycle, and qualitative relation constraint node shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical DEAP namespace OID and node fully qualified topological path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))`$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel interval validation, pairwise axiomatic constraint evaluation, and temporal network consistency checking across independent packages or occurrence scopes shall execute on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: Interval identifiers, occurrence names, relation symbol tokens (`before`, `meets`, `overlaps`, etc.), and qualifier labels shall be interned into the deduplicated global symbol interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The temporal dynamics solver shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When semantic violations occur (`E0400`), diagnostics shall accumulate in the error sink buffer $`\mathcal{D}_{\text{sink}}`$`, substitute typed error sentinels (`$`\bot_{\text{interval}}`$`, `$`\bot_{\text{rel}}`$`), and continue auditing subsequent temporal assertions. If accumulated diagnostics reach `$`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully in accordance with REQ-0013 and REQ-0016.
     - *Directive 5 (Panic-Free Release Isolation)*: The temporal axiomatic solver pipeline shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Verification latency ($`\lt 25\text{ ms}`$`) and peak RSS memory (`$`\lt 100\text{ MB}`$` for `$`10^5`$ interval relations) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Occurrence_1`, `Occurrence_2`, `Occurrence_3`, `Interval_Alpha`, `Interval_Beta`, `Interval_Gamma`, `Port_1`, `Port_2`, `param_x : Real`, `TemporalNetwork_Alpha`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $`\mathcal{V}_{\text{AST}}`$ denote the universe of allocated AST nodes in contiguous arena storage.
  Let $`\mathbb{T} = \mathbb{R}`$ denote the linear continuous temporal domain.

```math
X = \langle \text{id}_X, \text{name}_X, x_s, x_e, \Delta_X, \text{kind}_X, \text{provenance}_X, \text{span}_X \rangle
```

  where:

```math
\begin{aligned}
```

```math
\begin{aligned}
\text{kind}(X) = \text{ContinuousInterval} &\implies x_s \lt x_e \land \text{duration}(X) = x_e - x_s \gt 0 \\
\text{kind}(X) = \text{InstantaneousPoint} &\implies x_s = x_e \land \text{duration}(X) = 0 \\
x_s \gt x_e &\implies \text{Diagnostic}(X, \text{DiagnosticCode::E0400}, \text{InvertedTemporalInterval}) \in \mathcal{D}_{\text{sink}}
```

```math
\mathcal{B}_{13} = \{ \mathbf{b}, \mathbf{bi}, \mathbf{m}, \mathbf{mi}, \mathbf{o}, \mathbf{oi}, \mathbf{s}, \mathbf{si}, \mathbf{d}, \mathbf{di}, \mathbf{f}, \mathbf{fi}, \mathbf{eq} \}
```

  The 13 endpoint ordering definitions:

```math
\begin{aligned}
X \text{ before } Y &\iff x_e \lt y_s \\
X \text{ after } Y &\iff y_e \lt x_s \\
X \text{ meets } Y &\iff x_e = y_s \\
X \text{ met-by } Y &\iff y_e = x_s \\
X \text{ overlaps } Y &\iff x_s \lt y_s \land y_s \lt x_e \land x_e \lt y_e \\
X \text{ overlapped-by } Y &\iff y_s \lt x_s \land x_s \lt y_e \land y_e \lt x_e \\
X \text{ starts } Y &\iff x_s = y_s \land x_e \lt y_e \\
X \text{ started-by } Y &\iff x_s = y_s \land y_e \lt x_e \\
X \text{ during } Y &\iff y_s \lt x_s \land x_e \lt y_e \\
X \text{ contains } Y &\iff x_s \lt y_s \land y_e \lt x_e \\
X \text{ finishes } Y &\iff y_s \lt x_s \land x_e = y_e \\
X \text{ finished-by } Y &\iff x_s \lt y_s \land x_e = y_e \\
X \text{ equals } Y &\iff x_s = y_s \land x_e = y_e
\end{aligned}
```

  Mutual Exclusivity and Exhaustiveness:
  For every pair of non-degenerate continuous intervals $`X, Y \in \mathcal{I}`$:

```math
\left( \sum_{r \in \mathcal{B}_{13}} \mathbf{1}_{X \, r \, Y} \right) = 1
```

  where $`\mathbf{1}_{X \, r \, Y} = 1`$` if relation `$`r`$` holds between `$`X`$` and `$`Y`$`, and `$`0`$ otherwise.

  Qualitative Relation Bitmask Encoding:
  Each relation $`R \subseteq \mathcal{B}_{13}`$` is mapped to an integer bitmask `$`\mathbf{m}_R \in \{0, \dots, 2^{13}-1\}`$:

```math
\mathbf{m}_R = \sum_{k=0}^{12} b_k \cdot 2^k, \quad b_k \in \{0, 1\}
```

  with bit positions assigned to basic relations:

```math
\begin{aligned}
b_0 &\leftrightarrow \mathbf{b} \quad (0\text{x}0001) &\quad b_1 &\leftrightarrow \mathbf{bi} \quad (0\text{x}0002) \\
b_2 &\leftrightarrow \mathbf{m} \quad (0\text{x}0004) &\quad b_3 &\leftrightarrow \mathbf{mi} \quad (0\text{x}0008) \\
b_4 &\leftrightarrow \mathbf{o} \quad (0\text{x}0010) &\quad b_5 &\leftrightarrow \mathbf{oi} \quad (0\text{x}0020) \\
b_6 &\leftrightarrow \mathbf{s} \quad (0\text{x}0040) &\quad b_7 &\leftrightarrow \mathbf{si} \quad (0\text{x}0080) \\
b_8 &\leftrightarrow \mathbf{d} \quad (0\text{x}0100) &\quad b_9 &\leftrightarrow \mathbf{di} \quad (0\text{x}0200) \\
b_{10} &\leftrightarrow \mathbf{f} \quad (0\text{x}0400) &\quad b_{11} &\leftrightarrow \mathbf{fi} \quad (0\text{x}0800) \\
b_{12} &\leftrightarrow \mathbf{eq} \quad (0\text{x}1000)
\end{aligned}
```

  Algebraic Operators on Bitmasks:

```math
\begin{aligned}
\mathbf{m}_{R_1 \cap R_2} &= \mathbf{m}_{R_1} \operatorname{AND} \mathbf{m}_{R_2} \\
\mathbf{m}_{R_1 \cup R_2} &= \mathbf{m}_{R_1} \operatorname{OR} \mathbf{m}_{R_2} \\
\mathbf{m}_{\overline{R}} &= (\operatorname{NOT} \mathbf{m}_R) \operatorname{AND} 0\text{x}1\text{FFF} \\
\mathbf{m}_{\emptyset} &= 0\text{x}0000, \quad \mathbf{m}_{\mathbf{U}} = 0\text{x}1\text{FFF}
\end{aligned}
```

  Converse Involution Operator ($`(-)^\smile`$):

```math
\begin{aligned}
(\mathbf{b})^\smile &= \mathbf{bi}, \quad (\mathbf{bi})^\smile = \mathbf{b} \\
(\mathbf{m})^\smile &= \mathbf{mi}, \quad (\mathbf{mi})^\smile = \mathbf{m} \\

(\mathbf{eq})^\smile &= \mathbf{eq}
\end{aligned}
```

  satisfying involution and homomorphism:

```math
\forall R \subseteq \mathcal{B}_{13}, \quad (R^\smile)^\smile = R \quad \text{and} \quad (R_1 \cap R_2)^\smile = R_1^\smile \cap R_2^\smile
```

- **Computational Complexity & Algorithmic Bounds**: Axiomatic qualitative interval relation solving, bitmask algebraic operations, concrete relation classification, and difference logic translation execute strictly within Complexity Class $`\mathbf{P}`$.

  For an abstract MBSE temporal model comprising $`N = |\mathcal{I}|`$` temporal intervals and `$`M = |\mathcal{C}_{\text{temp}}|`$ asserted qualitative relation constraints:
  1. *Endpoint Ordering & Concrete Relation Classification*:
     Evaluating the 4 pairwise endpoint ordering relations between two known intervals $`[x_s, x_e]`$` and `$`[y_s, y_e]`$` requires at most 4 scalar comparisons, executing in deterministic `$`O(1)`$ constant time:

```math
T_{\text{classify}} \in O(1)
```

  2. *Bitmask Algebraic Operations*:
     Computing intersection, union, complement, converse involution, or identity checking on 13-bit relation masks requires at most 2 bitwise CPU instructions (AND, OR, XOR, SHIFT), executing in deterministic $`O(1)`$ constant time:

```math
T_{\text{algebra}} \in O(1)
```

  3. *Pairwise Relation Validation & Symmetry Normalization*:
     Auditing $`M`$` asserted qualitative constraints against declared intervals, computing relational converses `$`(R(Y, X))^\smile`$, and verifying non-empty intersections across bidirectional assertions executes in deterministic linear time:

```math
T_{\text{validate}}(M) \in O(M)
```

  4. *Difference Constraint Lowering*:
     Lowering $`M`$ atomic qualitative constraints into systems of endpoint difference inequalities generates at most 4 linear inequalities per relation, requiring total allocation and translation time bounded by:

```math
T_{\text{lower}}(M) \in O(M)
```

  5. *Full Pairwise Constraint Matrix Construction*:
     When synthesizing a complete $`N \times N`$` qualitative relation table across all pairs of intervals in an occurrence scope, populating the upper triangular matrix requires `$`\frac{N(N-1)}{2}`$ entries, executing in:

```math
T_{\text{matrix}}(N) \in O(N^2)
```

  6. *Aggregate Sequential Complexity*:
     The overall execution time of the axiomatic solver for validating and lowering $`M`$` constraints over `$`N`$ intervals is strictly bounded by:

```math
T_{\text{total}}(N, M) \in O(N + M)
```

     (or $`O(N^2)`$ when all pairwise relations are explicitly constructed).
  7. *Parallel Work-Stealing Scaling (Architectural Directive 2)*:
     When validating temporal intervals and evaluating qualitative relation constraints across $`K`$` independent packages or occurrence scopes over `$`N_{\text{max\_workers}}`$ threads on a bounded work-stealing thread pool:

```math
T_{\text{parallel}}(N, M, N_{\text{max\_workers}}) \in O\left( \frac{N + M}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

  8. *Space Complexity & Memory Bounds*:
