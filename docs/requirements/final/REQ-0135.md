## 1. Normative Statement

The safety compiler SHALL compute the minimal hitting set of constraints covering all declared hazards, ingesting hazards $\mathcal{H}$ and constraints $\mathcal{C}$ from the AST arena as an abstract hypergraph.

The pipeline MUST enforce five rules:
1. **Coverage**: Each hazard $``H_i \in \mathcal{H}``$ (`Hazard_Alpha`) SHALL define non-empty cut-set $``\mathbf{C}_{\text{mitig}}(H_i) \subseteq \mathcal{C}``$ (`Constraint_0`). If $``\mathbf{C}_{\text{mitig}}(H_i) = \emptyset``$, the compiler SHALL emit diagnostic `E0400`.
2. **Greedy Engine**: Solver `CutSetSolver_0` SHALL compute $``C_{\text{greedy}}``$ in polynomial time via ratio maximization with lexicographical tie-breaking.
3. **Exact Minimization**: Exact search for $C^*$ SHALL enforce $``N_{\text{step}} \le \kappa_{\text{cut}}``$, aborting with diagnostic `E0413` if exceeded.
4. **Traceability**: Traceability to Unsafe Control Actions $``\mathcal{U}_{\text{UCA}}``$ (`UCA_1`) SHALL verify constraints eliminate causal cut-sets.
5. **Directives**: Elements bind UUIDv5 anchors (Directive 1); work-stealing pool uses $``N_{\text{max\_workers}}``$ threads (Directive 2); symbols are interned (Directive 3); delimiter recovery halts at $``C_{\text{max\_errors}}``$ with `E0199` (Directive 4); release performance is isolated (Directive 5).

## 2. Formal Invariant

Let $``\mathcal{H}_{\text{hyper}} = (\mathcal{C}, \mathcal{H})``$ denote the hazard hypergraph. Every valid hitting set $C \subseteq \mathcal{C}$ satisfies:

```math
\begin{aligned}
\forall H_i \in \mathcal{H}, \quad C \cap \mathbf{C}_{\text{mitig}}(H_i) \ne \emptyset \\
C^* = \arg\min_{C \subseteq \mathcal{C}} \left\{ \sum_{c \in C} w(c) \;\middle|\; \forall H_i \in \mathcal{H}, \, C \cap \mathbf{C}_{\text{mitig}}(H_i) \ne \emptyset \right\} \\
|C_{\text{greedy}}| \le (1 + \ln |\mathcal{H}|) \cdot |C^*| \\
N_{\text{step}}(\text{CutSetSolver}_0) \le \kappa_{\text{cut}} \\
\mathbf{C}_{\text{mitig}}(H_i) = \emptyset \implies \text{Diagnostic}(H_i, \text{E0400}) \in \mathcal{D}_{\text{sink}} \\
N_{\text{step}} \gt \kappa_{\text{cut}} \implies \text{Diagnostic}(\mathcal{H}, \text{E0413}) \in \mathcal{D}_{\text{sink}} \\
\forall x \in \mathcal{H} \cup \mathcal{C} \cup \mathcal{U}_{\text{UCA}}, \quad \Delta_x = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \text{FQN}(x))
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** $\mathbf{NP}\text{-hard}$ (Decision: $\mathbf{NP}\text{-complete}$, Karp 1972).
- **Asymptotic Bound:** Greedy approximation operates in $O(m \cdot n)$ for $m = |\mathcal{H}|$ hazards and $n = |\mathcal{C}|$ constraints. Branch-and-bound is bounded to $``O(\kappa_{\text{cut}} \cdot (m + n))``$ by step threshold $``\kappa_{\text{cut}}``$.
- **Tractable Subclass & Frontier:** Frontier **NP-4** (STPA Minimal Hazard Cut-Sets & Unsafe Control Action Minimization). Tractability is achieved via $(1 + \ln m)$-greedy approximation, absorption reductions, and bounded branch-and-bound under threshold $``\kappa_{\text{cut}}``$.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Greedy Cut-Set Minimization
- **Given:** Model `Package_0` with hazards `Hazard_Alpha`, `Hazard_Beta` and candidate constraints.
- **When:** `CutSetSolver_0` executes greedy minimization.
- **Then:** Hitting set $``C_{\text{greedy}}``$ covers all hazards within $(1 + \ln |\mathcal{H}|)$ bound.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Step Limit Enforcement
- **Given:** Exact cut-set model with threshold $``\kappa_{\text{cut}}``$.
- **When:** Counter $``N_{\text{step}} \gt \kappa_{\text{cut}}``$.
- **Then:** Search aborts with diagnostic `E0413`.
- **Diagnostic:** `E0413` on step limit exceeded.

### AC-03: Unmitigated Hazard Rejection
- **Given:** Model `Package_0` declaring `Hazard_Alpha` with empty mitigation set.
- **When:** Completeness validation executes.
- **Then:** Lowering halts with diagnostic `E0400`.
- **Diagnostic:** `E0400` on unmitigated hazard.

### AC-04: Delimiter Error Recovery
- **Given:** Malformed hazard declarations separated by delimiters (`;`, `}`).
- **When:** Validator encounters syntax or semantic faults.
- **Then:** Errors accumulate in $``\mathcal{D}_{\text{sink}}``$, resuming at delimiters until halting at capacity.
- **Diagnostic:** `E0199` on buffer capacity reached.

### AC-05: Bitwise Deterministic Solution
- **Given:** Model `Package_0` with symmetric candidate constraints.
- **When:** `CutSetSolver_0` resolves ties via lexicographical name order.
- **Then:** Solutions and UUIDv5 anchors match bit-for-bit across runs.
- **Diagnostic:** Diagnostic sink remains empty.
