### REQ-0063: KerML Conjugation Relationship (`~`) Lowering & Port Inversion

- **Normative Statement**: The Universal Schema Ingestion and Metamodel Lowering Engine shall implement the OMG Systems Modeling Language (SysML v2) and Kernel Modeling Language (KerML) Conjugation Relationship (`~`) and port inversion transformation. The lowering engine shall formalize port and interface conjugation as an algebraic involution over the closed directional algebra $\mathcal{D} = \{ \text{In}, \text{Out}, \text{InOut}, \text{None} \}$, inverting flow and signal orientations while strictly preserving internal structural typing, payload schemas, parametric invariant constraints, and multiplicity intervals within the bounded subtyping meet-semilattice in accordance with Algorithmic Bound NP-3.

  Specifically, the lowering engine shall satisfy the following normative provisions:
  1. Directional Involution Semantics: The lowering engine shall evaluate the conjugation operator ${\sim}$ as a strict algebraic involution over the direction domain $\mathcal{D}$. Applying conjugation to an input direction (`In`) shall yield output (`Out`); applying conjugation to an output direction (`Out`) shall yield input (`In`); applying conjugation to a bidirectional direction (`InOut`) shall yield `InOut` (self-dual fixed point); and applying conjugation to a non-directed feature (`None`) shall yield `None`. For every direction $d \in \mathcal{D}$, the involution identity ${\sim}({\sim}d) \equiv d$ shall hold unconditionally.
  2. Port and Interface Type Conjugation: The lowering engine shall support conjugation applied to port definitions (`port def`), interface definitions (`interface def`), and contextual port usages (`port`). For any port or interface definition $P$, its conjugated counterpart $\widetilde{P} = {\sim}P$ shall possess an identical set of features where each feature $f' \in \text{features}(\widetilde{P})$ corresponds bijectively to an original feature $f \in \text{features}(P)$ such that:
     - Name preservation: $\text{name}(f') = \text{name}(f)$,
     - Payload and structural typing invariance: $\tau(f') = \tau(f)$,
     - Multiplicity interval invariance: $\mu(f') = \mu(f)$,
     - Invariant contract preservation: all behavioral contracts, operational constraints, and parametric assertions $\psi \in \Psi(P)$ are preserved symmetrically on $\widetilde{P}$,
     - Directional inversion: $\text{dir}(f') = {\sim}\text{dir}(f)$.
  3. Recursive Hierarchical Port Conjugation: When a port or interface definition $P$ contains nested child ports or nested interface usages $p_{\text{child}} \in \text{features}(P)$, the lowering engine shall apply conjugation recursively: the nested port interaction direction shall invert ($\text{dir}(\widetilde{p_{\text{child}}}) = {\sim}\text{dir}(p_{\text{child}})$), and its internal feature set shall be recursively conjugated ($\text{features}(\widetilde{p_{\text{child}}}) = {\sim}\text{features}(p_{\text{child}})$).
  4. Subtyping Semi-Lattice and Multiple Inheritance (Algorithmic Bound NP-3): The subtyping relation over port and interface classifiers $(\mathcal{T}_{\text{port}}, \le)$ shall form a bounded monotonic meet-semilattice. Conjugation shall act as an order-preserving lattice automorphism: for any two port classifiers $P_1, P_2 \in \mathcal{T}_{\text{port}}$, $P_1 \le P_2 \iff {\sim}P_1 \le {\sim}P_2$, and ${\sim}(P_1 \wedge P_2) \equiv {\sim}P_1 \wedge {\sim}P_2$. When a classifier derives from multiple supertypes where one or more supertypes are conjugated (e.g., `port def Classifier_Gamma :> ~Classifier_Alpha, Classifier_Beta`), the lowering engine shall resolve the linearized precedence list deterministically via the C3 linearization algorithm without backtracking, executing in deterministic $O(V + E)$ polynomial time to eliminate exponential search and undecidable subtyping cycles.
  5. Involutive Simplification and Normalization: In abstract syntax graph construction, the lowering engine shall simplify consecutive conjugation operations algebraically: any even number of conjugations applied to a type or feature reference shall normalize directly to the unconjugated base classifier (${\sim}^{2k} P \equiv P$), and any odd number of conjugations shall normalize to the canonical single-conjugation form (${\sim}^{2k+1} P \equiv {\sim}P$).
  6. Feature Redefinition under Conjugation: When a feature usage in a specialized classifier redefines a feature inherited from a conjugated parent ($f_{\text{redef}} :>> f_{\text{base}}$), the lowering engine shall verify monotonic covariance: (a) the effective type must specialize the base feature type ($\tau(f_{\text{redef}}) \le \tau(f_{\text{base}})$), (b) the multiplicity must be narrowed ($[l_{\text{redef}}, u_{\text{redef}}] \subseteq [l_{\text{base}}, u_{\text{base}}]$), and (c) the direction must match the conjugated orientation ($\text{dir}(f_{\text{redef}}) = \text{dir}(f_{\text{base}})$).
  7. Target Classifier Validity Gate: The conjugation operator `~` shall apply exclusively to classifiers with interaction and flow semantics: port definitions, interface definitions, interaction definitions, and port usages. Applying the conjugation operator to non-conjugable classifier kinds (including primitive scalar types `Integer`, `Real`, `Boolean`, `String`, enumerated types, or allocation definitions) shall be strictly prohibited and shall deterministically emit structured diagnostic error code `E0200` per REQ-0191.
  8. Architectural Directives Compliance:
     - Directive 1 (Deterministic UUIDv5): Every lowered conjugated classifier definition node, conjugated port usage, and synthetic inverted feature node shall be assigned a deterministic RFC 4122 UUIDv5 identifier computed from the compiler namespace OID and canonical fully qualified symbol path including the conjugation prefix.
     - Directive 2 (Bounded Work-Stealing Parallelism): Lowering and type checking of conjugation relationships across independent packages shall be scheduled strictly on a bounded work-stealing thread pool with worker thread upper bound $N_{\text{max\_workers}}$ in accordance with REQ-0012.
     - Directive 3 (String Interner Memory Allocation Exception): All identifier strings, feature names, and symbol paths shall be interned into the global symbol interner pool during initial lexical lowering as the sole permitted exception to zero-copy arena management in accordance with REQ-0036.
     - Directive 4 (Synchronization Token Error Recovery): The lowering engine shall implement synchronization token error recovery in accordance with REQ-0013 and REQ-0016: upon detecting an invalid conjugation target or incompatible conjugated redefinition (`E0200`), directional invariant mismatch (`E0201`), or circular inheritance (`E0203`), the engine shall record the diagnostic into the preallocated diagnostic sink buffer $\mathcal{D}_{\text{sink}}$, substitute a typed error sentinel $\bot_{\text{type}}$, and resynchronize at the next definition or delimiter token. If accumulated diagnostics reach capacity limit $C_{\text{max\_errors}}$, diagnostic code `E0199` shall be emitted and compilation terminated gracefully.
     - Directive 5 (Panic-Free Release Execution and Benchmarking Isolation): Compiler library code shall strictly enforce a deterministic, non-panicking execution contract with total-function termination across all inputs. Performance latency (< 25 ms) and peak RSS memory (< 100 MB) shall be evaluated exclusively in compiled Release mode (`--release`).
     - Domain Purity: All diagnostic messages, test models, and examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Classifier_Alpha`, `Classifier_Beta`, `Classifier_Gamma`, `PortDef_0`, `PortDef_1`, `Port_1`, `Port_2`, `Feature_A`, `Feature_B`, `param_x : Real`).

- **Formal Invariant**: Let $\mathcal{D}$ denote the discrete closed directional domain:

$$
\mathcal{D} = \{ \text{In}, \text{Out}, \text{InOut}, \text{None} \}
$$

The direction inversion operator ${\sim} : \mathcal{D} \to \mathcal{D}$ is an algebraic involution defined by:

$$
{\sim}(d) = \begin{cases}
\text{Out}, & \text{if } d = \text{In} \\
\text{In}, & \text{if } d = \text{Out} \\
\text{InOut}, & \text{if } d = \text{InOut} \\
\text{None}, & \text{if } d = \text{None}
\end{cases}
$$

Involution and Power Properties: For every direction $d \in \mathcal{D}$ and integer $k \in \mathbb{N}_{0}$:

$$
\begin{aligned}
{\sim}({\sim}d) &\equiv d \\
{\sim}^{2k}(d) &\equiv d \\
{\sim}^{2k+1}(d) &\equiv {\sim}d
\end{aligned}
$$

Each port definition classifier $P \in \mathcal{P}_{\text{def}}$ is formalized as a 7-tuple:

$$
P = \langle \text{id}_{P}, \text{name}_{P}, \mathcal{F}_{P}, \mathcal{S}_{P}, \Psi_{P}, \mu_{P}, \Delta_{P} \rangle
$$

where:
- $\text{id}_{P} \in \mathbb{N}_{32}$ is the unique typed arena node handle,
- $\text{name}_{P} \in \mathcal{S}_{\text{intern}}$ is the interned scalar symbol identifier,
- $\mathcal{F}_{P} = \{ f_{1}, \dots, f_{m} \}$ is the set of owned and inherited feature handles,
- $\mathcal{S}_{P} \subseteq \mathcal{P}_{\text{def}}$ is the set of direct generalization supertypes,
- $\Psi_{P} = \{ \psi_{1}, \dots, \psi_{k} \}$ is the set of invariant contract constraints,
- $\mu_{P} = [l_{P}, u_{P}] \subseteq \mathbb{N}_{0} \times (\mathbb{N}_{0} \cup \{ \infty \})$ is the definition multiplicity interval with $0 \le l_{P} \le u_{P}$ and $u_{P} \ge 1$,
- $\Delta_{P} \in \Sigma^{*}$ is the deterministic RFC 4122 UUIDv5 identifier.

Each feature $f \in \mathcal{F}_{P}$ is formalized as a 6-tuple:

$$
f = \langle \text{id}_{f}, \text{name}_{f}, \tau(f), \text{dir}(f), \mu(f), \Delta_{f} \rangle
$$

where $\tau(f) \in \mathcal{T}$ is the feature classifier type, $\text{dir}(f) \in \mathcal{D}$ is the direction, and $\mu(f) = [l_{f}, u_{f}]$ is the feature multiplicity interval.

Conjugated Classifier Definition $\widetilde{P} = {\sim}P$: The lowering transformation maps $P$ to $\widetilde{P}$:

$$
\widetilde{P} = \langle \text{id}_{\widetilde{P}}, \text{name}_{\widetilde{P}}, \mathcal{F}_{\widetilde{P}}, \mathcal{S}_{\widetilde{P}}, \Psi_{\widetilde{P}}, \mu_{\widetilde{P}}, \Delta_{\widetilde{P}} \rangle
$$

satisfying the following invariants:

1. Feature Set Conjugation Bijection:

$$
\mathcal{F}_{\widetilde{P}} = \{ {\sim}f \mid f \in \mathcal{F}_{P} \}
$$

where each conjugated feature ${\sim}f$ is constructed as:

$$
{\sim}f = \langle \text{id}_{{\sim}f}, \text{name}_{f}, \tau(f), {\sim}\text{dir}(f), \mu(f), \Delta_{{\sim}f} \rangle
$$

2. Payload Typing, Multiplicity, and Constraint Preservation Invariant:

$$
\begin{aligned}
\forall f \in \mathcal{F}_{P}, \quad \tau({\sim}f) &\equiv \tau(f) \quad (\text{structural typing preservation}) \\
\forall f \in \mathcal{F}_{P}, \quad \mu({\sim}f) &\equiv \mu(f) \quad (\text{feature multiplicity preservation}) \\
\mu_{\widetilde{P}} &\equiv \mu_{P} \quad (\text{classifier multiplicity preservation}) \\
\Psi_{\widetilde{P}} &\equiv \Psi_{P} \quad (\text{invariant constraint preservation})
\end{aligned}
$$

3. Classifier Involution Identity:

$$
{\sim}({\sim}P) \equiv P \quad \wedge \quad \forall f \in \mathcal{F}_{P}, \, {\sim}({\sim}f) \equiv f
$$

4. Recursive Nested Port Conjugation: For any child port usage $p_{\text{child}} \in \mathcal{F}_{P}$ where $\tau(p_{\text{child}}) \in \mathcal{P}_{\text{def}}$:

$$
\begin{aligned}
\text{dir}({\sim}p_{\text{child}}) &= {\sim}\text{dir}(p_{\text{child}}) \\
\tau({\sim}p_{\text{child}}) &= {\sim}\tau(p_{\text{child}}) \\
\mathcal{F}_{\tau({\sim}p_{\text{child}})} &= \{ {\sim}f_{\text{nested}} \mid f_{\text{nested}} \in \mathcal{F}_{\tau(p_{\text{child}})} \}
\end{aligned}
$$

5. Subtyping Meet-Semilattice and C3 Linearization Invariant (Algorithmic Bound NP-3): Let $(\mathcal{T}_{\text{port}}, \le)$ denote the subtyping poset of port and interface classifiers:

$$
\begin{aligned}
\forall P \in \mathcal{T}_{\text{port}}, &\quad P \le P \quad (\text{reflexivity}) \\
\forall P_{1}, P_{2}, P_{3} \in \mathcal{T}_{\text{port}}, &\quad (P_{1} \le P_{2} \wedge P_{2} \le P_{3}) \implies P_{1} \le P_{3} \quad (\text{transitivity}) \\
\forall P_{1}, P_{2} \in \mathcal{T}_{\text{port}}, &\quad (P_{1} \le P_{2} \wedge P_{2} \le P_{1}) \implies P_{1} = P_{2} \quad (\text{antisymmetry})
\end{aligned}
$$

Conjugation acts as a lattice automorphism over $(\mathcal{T}_{\text{port}}, \le)$:

$$
\forall P_{1}, P_{2} \in \mathcal{T}_{\text{port}}, \quad P_{1} \le P_{2} \iff {\sim}P_{1} \le {\sim}P_{2}
$$

Meet-Semilattice Preservation: For any $P_{1}, P_{2} \in \mathcal{T}_{\text{port}}$, the greatest lower bound (meet) $P_{1} \wedge P_{2} = \inf \{ P_{1}, P_{2} \}$ exists uniquely, satisfying:

$$
{\sim}(P_{1} \wedge P_{2}) \equiv {\sim}P_{1} \wedge {\sim}P_{2}
$$

Monotonic C3 Linearization: For a classifier $C$ declaring direct supertypes $\mathcal{S}_{C} = \langle S_{1}, S_{2}, \dots, S_{n} \rangle$ where each $S_{i} \in \mathcal{T}_{\text{port}}$ is either unconjugated ($P_{i}$) or conjugated (${\sim}P_{i}$):

$$
\text{C3}(C) = [C] \mathbin{\Vert} \text{merge}(\text{C3}(S_{1}), \text{C3}(S_{2}), \dots, \text{C3}(S_{n}), [S_{1}, S_{2}, \dots, S_{n}])
$$

where $\mathbin{\Vert}$ denotes sequence concatenation and $\text{merge}$ extracts candidates preserving local precedence order without cyclic dependencies.

6. Peer Port Compatibility via Conjugation Duality: Two port usages $p_{1}$ and $p_{2}$ bound in a peer-to-peer assembly connection $C = (p_{1}, p_{2})$ are directionally compatible if and only if:

$$
\text{CompatiblePeer}(p_{1}, p_{2}) \iff \forall f \in \mathcal{F}_{\tau(p_{1})}, \quad \exists f' \in \mathcal{F}_{\tau(p_{2})} : (\text{name}(f') = \text{name}(f) \wedge \tau(f') \le \tau(f) \wedge \text{dir}(f') = {\sim}\text{dir}(f))
$$

which holds whenever $\tau(p_{2}) \le {\sim}\tau(p_{1})$.

7. Diagnostic Code Trigger Invariant: Compiler diagnostic emission is bound strictly to the taxonomy of REQ-0191:

$$
\begin{aligned}
\text{kind}(T) \notin \{ \text{PortDef}, \text{InterfaceDef}, \text{PortUsage} \} \wedge \text{is\_conjugated}(T) &\implies \text{Diagnostic}(T, \text{DiagnosticCode::E0200}, \text{InvalidConjugationTarget}) \in \mathcal{D}_{\text{sink}} \\
\neg(\tau(f_{\text{redef}}) \le \tau(f_{\text{base}})) \vee \neg([l_{\text{redef}}, u_{\text{redef}}] \subseteq [l_{\text{base}}, u_{\text{base}}]) &\implies \text{Diagnostic}(f_{\text{redef}}, \text{DiagnosticCode::E0200}, \text{IncompatibleConjugatedRedefinition}) \in \mathcal{D}_{\text{sink}} \\
\text{HasInheritanceCycle}(G_{\text{inherit}}) &\implies \text{Diagnostic}(G_{\text{inherit}}, \text{DiagnosticCode::E0203}, \text{CircularConjugationInheritance}) \in \mathcal{D}_{\text{sink}} \\
\kappa_{\text{conn}}(C) = \text{Assembly} \wedge \neg \text{CompatiblePeer}(p_{1}, p_{2}) &\implies \text{Diagnostic}(C, \text{DiagnosticCode::E0201}, \text{ConjugatedDirectionMismatch}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

8. Deterministic RFC 4122 UUIDv5 Identification Invariant:

$$
\begin{aligned}
\Delta_{\widetilde{P}} &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(P) \mathbin{\Vert} \text{"::\textasciitilde{}"}) \\
\Delta_{{\sim}f} &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(P) \mathbin{\Vert} \text{"::\textasciitilde{}::"} \mathbin{\Vert} \text{name}(f))
\end{aligned}
$$

- **Computational Complexity & Algorithmic Bounds**: Conjugation lowering and port inversion execute within Complexity Class $\mathbf{P}$. The computational characteristics and bounds are formalized as follows:
  1. Frontier NP-3 Complexity Context: Subtyping lattice consistency and feature redefinition across multiple inheritance hierarchies is NP-complete for arbitrary, unconstrained partially ordered sets (posets), as poset subtyping allows reduction from 3-SAT through non-monotonic subtyping graphs. In the sovereign compiler, the subtyping space is restricted to a monotonic bounded meet-semilattice $(\mathcal{T}_{\text{port}}, \le, \wedge)$ with unambiguous C3 linearization. This restriction eliminates exponential backtracking search, ensuring all subtyping checks and feature redefinition verifications execute in deterministic polynomial time.
  2. Direction Inversion Operator (${\sim}d$): Evaluates a 4-entry lookup table over a 2-bit discriminant representation in strictly $O(1)$ constant time with zero heap allocations.
  3. Involutive Normalization: Evaluates even/odd parity of stacked conjugation tokens via a single bitwise XOR operation ($\text{is\_conjugated} \leftarrow \text{is\_conjugated} \oplus 1$) in $O(1)$ time.
  4. Feature Set Inversion: For a port classifier $P$ containing $M = |\mathcal{F}_{P}|$ features, copying node handles and inverting feature direction tags executes in strictly deterministic $O(M)$ linear time.
  5. C3 Linearization with Conjugated Supertypes: For a multiple inheritance subgraph containing $V$ transitive ancestor classifiers and $E$ specialization edges, computing the C3 linearized resolution order executes in $O(V + E)$ time using deterministic list-merging.
  6. Peer Port Compatibility Verification: Verifying directional duality for two connected ports with $M$ features executes in $O(M)$ time using interned symbol table lookups.
  7. Aggregate Model Complexity: For an entire AST model with $N$ classifiers, $F$ total features, and $E$ specialization edges:

$$
T(N, F, E) = O(N + F + E)
$$

  8. Bounded Work-Stealing Parallelism: Parallel lowering across independent compilation units scheduled onto a bounded work-stealing thread pool with $N_{\text{max\_workers}}$ workers executes within:

$$
T_{\text{parallel}}(N, F, E) = O\left(\frac{N + F + E}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}}\right)
$$

  9. Space Complexity: Auxiliary memory overhead is strictly $O(1)$ beyond contiguous bump arena storage for AST nodes ($O(N + F)$) and the preallocated diagnostic sink buffer ($O(C_{\text{max\_errors}}) = O(1)$), ensuring zero heap reallocation during the lowering pass.
