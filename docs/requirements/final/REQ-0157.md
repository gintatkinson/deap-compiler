## 1. Normative Statement

The ICD engine of Subsystem 8 SHALL calculate framing overheads and serialization penalties for all signal flows.

Synthesis MUST enforce:
1. **Profiles**: Profiles (`ProtocolFrame_Alpha`) declare framing ($``L_{\text{preamble}}, L_{\text{header}}, L_{\text{trailer}}, L_{\text{crc}}, L_{\text{ifg}}``$), bounds ($``L_{\text{payload\_min}}, L_{\text{mtu}}``$), alignment ($``\text{Align}_{\text{frame}} \in \{1, 8, 16, 32, 64\}``$), stuffing ($``\Sigma_{\text{stuffing}}``$), and rate ($``R_{\text{bus}} \gt 0``$). Faulty rates ($``R_{\text{bus}} \le 0``$) or alignments emit `E0212`. Missing profiles emit `E0200`.
2. **Padding**: Flow `Flow_0` (`Payload_1`, payload $L$) computes $``L_{\text{fixed}}``$, minimum padding $``\Delta_{\text{min\_pad}}``$, and alignment padding $``\Delta_{\text{align\_pad}}``$ enforcing $``\text{Align}_{\text{frame}}``$ divisibility.
3. **Stuffing**: Run-length threshold $``k_{\text{stuff}} \ge 2``$ calculates penalty $``\Delta_{\text{stuffing}} = \lfloor (L_{\text{stuffed}} - 1) / (k_{\text{stuff}} - 1) \rfloor``$; unstuffed profiles yield $``\Delta_{\text{stuffing}} = 0``$.
4. **Metrics**: Computes efficiency $``\eta_{\text{framing}} = L / L_{\text{frame}}``$, penalty $``\Pi_{\text{penalty}} = (1 / \eta_{\text{framing}}) - 1``$ (`HeaderPenalty_0`), duration $``\tau_{\text{occupancy}}``$, and duty cycle $``\rho_{\text{occupancy}}``$. Low efficiency ($``\eta_{\text{framing}} \lt \eta_{\text{min}}``$) emits `E0212`.
5. **Directives**: Overflow $``L \gt L_{\text{mtu}}``$ without fragmentation emits `E0212`, binding $``\bot_{\text{framing}}``$. UUIDv5 anchors (Directive 1); work-stealing ceiling $``N_{\text{max\_workers}}``$ (Directive 2); symbol interning (Directive 3); recovery on `;` and `|` halting at $``C_{\text{max\_errors}}``$ with `E0199` (Directive 4); Release budget ($< 25\text{ ms}$ for $10^4$ flows, $< 100\text{ MB}$) (Directive 5). Placeholders (`Package_0`, `ProtocolFrame_Alpha`, `HeaderPenalty_0`, `Payload_1`, `Flow_0`, `Channel_0`, `param_x : Real`) used.

## 2. Formal Invariant

The framing tuple, padding expansion, bit-stuffing penalty, and wire duration satisfy:

```math
\begin{aligned}
L_{\text{fixed}}(\Pi)&=L_{\text{preamble}}+L_{\text{header}}+L_{\text{trailer}}+L_{\text{crc}}+L_{\text{ifg}} \\
\Delta_{\text{min\_pad}}(L,\Pi)&=\max(0,L_{\text{payload\_min}}-L) \\
\Delta_{\text{align\_pad}}(L,\Pi)&=(\text{Align}_{\text{frame}}-((L_{\text{fixed}}(\Pi)+L+\Delta_{\text{min\_pad}}(L,\Pi))\bmod\text{Align}_{\text{frame}}))\bmod\text{Align}_{\text{frame}} \\
\Delta_{\text{stuffing}}(L,\Pi)&=\begin{cases}\lfloor(L_{\text{header}}+L+\Delta_{\text{padding}}(L,\Pi)+L_{\text{crc}}-1)/(k_{\text{stuff}}-1)\rfloor,&\text{if }\Sigma_{\text{stuffing}}=\text{BitStuffing}(k_{\text{stuff}})\\0,&\text{if }\Sigma_{\text{stuffing}}=\text{None}\end{cases} \\
L_{\text{frame}}(L,\Pi)&=L_{\text{fixed}}(\Pi)+L+\Delta_{\text{min\_pad}}(L,\Pi)+\Delta_{\text{align\_pad}}(L,\Pi)+\Delta_{\text{stuffing}}(L,\Pi) \\
\eta_{\text{framing}}(L,\Pi)&=L/L_{\text{frame}}(L,\Pi),\quad\Pi_{\text{penalty}}(L,\Pi)=(1/\eta_{\text{framing}}(L,\Pi))-1 \\
\tau_{\text{occupancy}}(L,\Pi)&=L_{\text{frame}}(L,\Pi)/R_{\text{bus}},\quad\rho_{\text{occupancy}}(\sigma)=\tau_{\text{occupancy}}(L_{\text{payload}}(\sigma),\Pi_\sigma)/T_{\text{period}}(\sigma) \\
(L\gt L_{\text{mtu}}\land\neg\Pi_{\text{fragment}})\lor R_{\text{bus}}\le 0&\lor\text{Align}_{\text{frame}}\notin\{1,8,16,32,64\}\lor\eta_{\text{framing}}\lt\eta_{\text{min}}\implies\text{Diagnostic}(\text{E0212})\in\mathcal{D}_{\text{sink}} \\
\Pi_\sigma\notin\mathcal{P}_{\text{transport}}\implies\text{Diagnostic}(\sigma,\text{E0200})&\in\mathcal{D}_{\text{sink}},\quad|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}}
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``\Pi, \mathcal{P}_{\text{transport}}``$ | Transport protocol profile tuple and universe |
| $``L_{\text{fixed}}, L_{\text{frame}}``$ | Fixed protocol overhead and total frame bit length |
| $``\Delta_{\text{min\_pad}}, \Delta_{\text{align\_pad}}, \Delta_{\text{stuffing}}``$ | Minimum padding, alignment padding, and bit-stuffing penalty |
| $``\eta_{\text{framing}}, \Pi_{\text{penalty}}``$ | Dimensionless framing efficiency and penalty ratio |
| $``\tau_{\text{occupancy}}, \rho_{\text{occupancy}}``$ | Transmission occupancy duration and periodic duty cycle |
| $``\bot_{\text{framing}}, \mathcal{D}_{\text{sink}}, \Delta_x``$ | Error sentinel, diagnostic sink, and UUIDv5 anchor |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$ (Deterministic Polynomial Time).
- **Asymptotic Bound:** $O(|F|)$ framing calculation ($O(1)$ per frame). Work-stealing achieves $``O(|F| / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Arena is $O(|F|)$.
- **Tractable Subclass & Frontier:** N/A (Deterministic P). Linear evaluation bypasses NP-2 channel packing (REQ-0147) and NP-8 SMT solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Overhead & Efficiency
- **Given:** Flow `Flow_0` (`Payload_1`, $L = 64$) with profile `ProtocolFrame_Alpha` ($``L_{\text{fixed}} = 88``$, $``R_{\text{bus}} = 10^6``$).
- **When:** Computing wire framing and serialization metrics.
- **Then:** Computes $``L_{\text{frame}} = 152``$, $``\eta_{\text{framing}} \approx 0.4211``$, $``\tau_{\text{occupancy}} = 152\ \mu\text{s}``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Alignment Padding & Bit-Stuffing
- **Given:** Flow with $L = 40$, $``L_{\text{payload\_min}} = 128``$, $\text{Align} = 32$, and $``\Sigma_{\text{stuffing}} = \text{BitStuffing}(5)``$.
- **When:** Synthesizing padding and stuffing expansions.
- **Then:** Yields $``\Delta_{\text{min\_pad}} = 88``$ and $``\Delta_{\text{stuffing}} = 49``$.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: MTU Overflow Rejection
- **Given:** Flow `Flow_0` with $L = 1024$, $``L_{\text{mtu}} = 512``$, and $``\Pi_{\text{fragment}} = \text{false}``$.
- **When:** Validating MTU and framing limits.
- **Then:** Fails closed, emits `E0212`, and binds $``\bot_{\text{framing}}``$.
- **Diagnostic:** `E0212` (FramingMTUExceeded).

### AC-04: Profile Resolution & Delimiter Recovery
- **Given:** Flow `Flow_0` referencing undeclared `Profile_Alpha`, separated by `;`.
- **When:** Recovering across delimiter boundaries.
- **Then:** Emits `E0200`, resynchronizes, and halts at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0200`, `E0199`.

### AC-05: UUIDv5 Anchors & Performance
- **Given:** $10^4$ flows across $``N_{\text{max\_workers}}``$ threads.
- **When:** Benchmarking in Release mode (`--release`).
- **Then:** Emits identical UUIDv5 anchors across 100 runs; latency $< 25\text{ ms}$, RSS $< 100\text{ MB}$.
- **Diagnostic:** Diagnostic sink remains empty.
