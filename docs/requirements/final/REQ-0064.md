### REQ-0064: KerML Disjoining, Differencing, Intersecting & Unioning Type Algebra

- **Normative Statement**: The Universal Schema Ingestion, KerML Metamodel Lowering Engine, and Semantic Type Checker shall implement a complete set-theoretic Boolean type algebra over classifier denotations within the KerML and SysML v2 type systems. The lowering engine shall formalize type operations over the semantic universe of instances $`\mathcal{U}`$, providing set-theoretic type operators (`unioning`, `intersecting`, `differencing`, `disjoining`) to construct compound classifiers and enforce compile-time disjointness constraints within the subtyping meet-semilattice $`(\mathcal{T}, \le, \wedge)`$ in accordance with Algorithmic Bound NP-3.

  The lowering engine and semantic type checker shall strictly enforce the following normative provisions:
  1. **Set-Theoretic Type Algebraic Operators**:
     - **Type Unioning (`unioning`, $`\cup`$`)**: For any set of classifiers `$`\{ T_{1}, \dots, T_{k} \}`$`, the union type `$`\bigcup_{i=1}^k T_{i}`$` shall denote the set-theoretic union of their instance value sets (`$`\llbracket \bigcup_{i=1}^k T_{i} \rrbracket = \bigcup_{i=1}^k \llbracket T_{i} \rrbracket`$`). Every constituent type shall specialize the union type (`$`T_{i} \le \bigcup_{j} T_{j}`$`). Furthermore, if a type `$`S`$` is a supertype of every constituent type (`$`\forall i, T_{i} \le S`$`), then the union type shall specialize `$`S`$` (`$`(\bigcup_{i=1}^k T_{i}) \le S`$).
     - **Type Intersecting (`intersecting`, $`\cap`$`)**: For any set of classifiers `$`\{ T_{1}, \dots, T_{k} \}`$`, the intersection type `$`\bigcap_{i=1}^k T_{i}`$` shall denote the set-theoretic intersection of their instance value sets (`$`\llbracket \bigcap_{i=1}^k T_{i} \rrbracket = \bigcap_{i=1}^k \llbracket T_{i} \rrbracket`$`). The intersection type shall specialize every constituent type (`$`\bigcap_{j} T_{j} \le T_{i}`$`). Furthermore, if a type `$`S`$` specializes every constituent type (`$`\forall i, S \le T_{i}`$`), then `$`S`$` shall specialize the intersection type (`$`S \le \bigcap_{i=1}^k T_{i}`$), establishing the unique greatest lower bound (meet) in the semilattice.
     - **Type Differencing (`differencing`, $`\setminus`$`)**: For classifiers `$`T_{1}`$` and `$`T_{2}`$`, the differencing type `$`T_{1} \setminus T_{2}`$` shall denote the relative complement of `$`T_{2}`$` with respect to `$`T_{1}`$` (`$`\llbracket T_{1} \setminus T_{2} \rrbracket = \llbracket T_{1} \rrbracket \setminus \llbracket T_{2} \rrbracket`$`). The differencing type shall specialize the base type (`$`T_{1} \setminus T_{2} \le T_{1}`$`). If `$`T_{1} \le T_{2}`$`, the difference shall evaluate to the bottom type `$`\bot_{\text{type}}`$`. If `$`T_{1} \perp T_{2}`$`, the difference shall simplify to `$`T_{1}`$.
     - **Type Disjoining (`disjoining`, $`\perp`$`)**: A disjoining relationship between classifiers `$`T_{1}`$` and `$`T_{2}`$` (`$`T_{1} \perp T_{2}`$`) shall assert that their semantic extensions are mutually disjoint (`$`\llbracket T_{1} \rrbracket \cap \llbracket T_{2} \rrbracket = \emptyset`$`). Equivalently, their intersection shall evaluate to the uninhabited bottom type (`$`T_{1} \cap T_{2} \equiv \bot_{\text{type}}`$).
  2. **Compile-Time Disjointness Enforcement**:
     - When a classifier $`C`$` declares or inherits multiple specialization paths such that `$`C \le T_{1}`$` and `$`C \le T_{2}`$` where `$`T_{1} \perp T_{2}`$`, the type checker shall detect an uninhabited type contradiction (`$`\llbracket C \rrbracket \subseteq \llbracket T_{1} \cap T_{2} \rrbracket = \emptyset`$`). Unless `$`C`$` is explicitly defined as the bottom type `$`\bot_{\text{type}}`$, the declaration shall be strictly rejected at compile time with diagnostic error code `E0200` (`DisjointTypeInheritanceConflict`).
     - If an expression, feature slot, or instance variable $`x`$` statically typed with `$`T_{1}`$` is asserted, bound, or cast to `$`T_{2}`$` where `$`T_{1} \perp T_{2}`$`, the compiler shall reject the assertion in `$`O(1)`$ lattice lookup and emit diagnostic error code `E0200` (`DisjointTypeInstanceViolation`).
     - Disjointness shall propagate monotonically downward through specialization: if $`T_{1} \perp T_{2}`$`, then for all `$`S_{1} \le T_{1}`$` and `$`S_{2} \le T_{2}`$`, the condition `$`S_{1} \perp S_{2}`$ shall hold unconditionally.
  3. **Subtyping Consistency and Normalization**:
     - Subtyping shall be sound and complete with respect to denotational containment: for all $`T_{1}, T_{2} \in \mathcal{T}`$`, `$`T_{1} \le T_{2} \iff \llbracket T_{1} \rrbracket \subseteq \llbracket T_{2} \rrbracket \iff \llbracket T_{1} \setminus T_{2} \rrbracket = \emptyset \iff T_{1} \cap T_{2} = T_{1} \iff T_{1} \cup T_{2} = T_{2}`$.
     - The type engine shall canonicalize compound type expressions into canonical normal forms (such as Disjunctive Normal Form over atomic base types) utilizing the standard Boolean algebra axioms: idempotence, commutativity, associativity, distributivity, absorption, and De Morgan laws.
  4. **Feature Projection across Compound Types**:
     - *Intersection Types*: An intersection type $`T_{1} \cap T_{2}`$` shall inherit the union of all features owned or inherited by `$`T_{1}`$` and `$`T_{2}`$. If features with identical interned names appear in both types, their signatures must be mutually compatible and specialize to their meet type; conflicting non-unifiable feature signatures shall trigger diagnostic error code `E0200` (`ConflictingIntersectionFeatures`).
     - *Union Types*: A union type $`T_{1} \cup T_{2}`$` shall expose only the intersection of features common to all constituent types. The projected type of a common feature shall be the union of the feature types across the variants (`$`\tau(f_{T_{1}}) \cup \tau(f_{T_{2}})`$). Accessing a variant-specific feature without prior type narrowing or pattern-matching guard shall trigger diagnostic error code `E0200` (`UnionVariantFeatureAccessViolation`).
  5. **Acyclicity and Dependency Verification**:
     - Circular type definitions or recursive algebraic equations without base-case stratification (e.g., $`T_{1} = T_{2} \setminus T_{1}`$) shall be detected via strongly connected component analysis and rejected with diagnostic error code `E0203` (`CircularTypeAlgebraDependency`).
  6. **NP-3 Tractable Subclass Formulation**:
     - In arbitrary partially ordered sets (posets), general subtyping satisfiability and compound type simplification is NP-complete (NP-3). To guarantee polynomial tractability, the compiler shall restrict classifier posets to a finite monotonic meet-semilattice and encode type denotations via compact bitset representations over atomic base classifiers. Under this formulation, compound type operations evaluate in deterministic $`O(|\text{Types}|)`$` polynomial time and disjointness queries evaluate in `$`O(1)`$ constant time.
  7. **Total-Function Error Recovery & Architectural Directives**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every lowered compound type classifier node (union, intersection, differencing) and disjoining relationship AST node shall be assigned a deterministic RFC 4122 UUIDv5 identifier generated by namespace-hashing the canonical normalized expression string with the compiler namespace OID per REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel lowering and validation of independent type algebra expressions across decoupled packages shall be scheduled strictly on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ per REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: Scalar classifier names, operator tokens, and qualified symbol paths shall be interned into the global symbol interner pool per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The lowering engine shall implement synchronization token error recovery per REQ-0013 and REQ-0016: upon detecting a disjointness conflict (`E0200`), uninhabited contradiction (`E0200`), or cyclic definition (`E0203`), the engine shall record the diagnostic into preallocated sink $`\mathcal{D}_{\text{sink}}`$`, substitute typed error sentinel `$`\bot_{\text{type}}`$`, and resynchronize at the next delimiter token. If accumulated diagnostics reach capacity limit `$`C_{\text{max\_errors}}`$, diagnostic code `E0199` shall be emitted and compilation halted gracefully.
     - *Directive 5 (Panic-Free Release Isolation)*: The compiler shall strictly enforce a deterministic, non-panicking execution contract with total-function termination across all inputs. Performance latency ($`\lt 25\text{ ms}`$`) and peak memory RSS (`$`\lt 100\text{ MB}`$` for `$`10^5`$ type algebra operations) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196.
     - *Domain Purity*: All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Classifier_Alpha`, `Classifier_Beta`, `Classifier_Gamma`, `Classifier_Delta`, `Type_Union`, `Type_Inter`, `Type_Diff`, `param_x : Real`).

- **Formal Invariant**: Let $`\mathcal{U}`$` denote the semantic universe of instances. Let `$`\mathcal{T}`$` denote the finite set of lowered type classifiers within the contiguous arena storage, bounded by top type `$`\top_{\text{type}}`$` and bottom type `$`\bot_{\text{type}}`$`. The denotation function `$`\llbracket \cdot \rrbracket : \mathcal{T} \to \mathcal{P}(\mathcal{U})`$ maps each type to its instance value set.

  The set-theoretic type algebraic operators evaluate over the instance universe as follows:

```math
\begin{aligned}
\llbracket T_{1} \cup T_{2} \rrbracket &= \llbracket T_{1} \rrbracket \cup \llbracket T_{2} \rrbracket \quad (\text{unioning}) \\
\llbracket T_{1} \cap T_{2} \rrbracket &= \llbracket T_{1} \rrbracket \cap \llbracket T_{2} \rrbracket \quad (\text{intersecting}) \\
\llbracket T_{1} \setminus T_{2} \rrbracket &= \llbracket T_{1} \rrbracket \setminus \llbracket T_{2} \rrbracket = \{ x \in \llbracket T_{1} \rrbracket \mid x \notin \llbracket T_{2} \rrbracket \} \quad (\text{differencing}) \\
T_{1} \perp T_{2} &\iff \llbracket T_{1} \rrbracket \cap \llbracket T_{2} \rrbracket = \emptyset \quad (\text{disjoining})
\end{aligned}
```

  Subtyping consistency with value-set inclusion:

```math
T_{1} \le T_{2} \iff \llbracket T_{1} \rrbracket \subseteq \llbracket T_{2} \rrbracket \iff \llbracket T_{1} \setminus T_{2} \rrbracket = \emptyset \iff T_{1} \cap T_{2} = T_{1} \iff T_{1} \cup T_{2} = T_{2}
```

  Bounded Meet-Semilattice Invariants:

```math
\begin{aligned}
\forall T \in \mathcal{T}, &\quad \bot_{\text{type}} \le T \le \top_{\text{type}} \\
\forall T_{1}, T_{2} \in \mathcal{T}, &\quad T_{1} \cap T_{2} = \inf \{ T_{1}, T_{2} \} \\
\forall T_{1}, T_{2} \in \mathcal{T}, &\quad T_{1} \cup T_{2} = \sup \{ T_{1}, T_{2} \}
\end{aligned}
```

  Boolean Algebra Axiomatic Identities on $`(\mathcal{T}, \le, \wedge)`$:

```math
\begin{aligned}
T \cup T &= T, \quad T \cap T = T \quad (\text{idempotence}) \\
T_{1} \cup T_{2} &= T_{2} \cup T_{1}, \quad T_{1} \cap T_{2} = T_{2} \cap T_{1} \quad (\text{commutativity}) \\
(T_{1} \cup T_{2}) \cup T_{3} &= T_{1} \cup (T_{2} \cup T_{3}), \quad (T_{1} \cap T_{2}) \cap T_{3} = T_{1} \cap (T_{2} \cap T_{3}) \quad (\text{associativity}) \\
T_{1} \cap (T_{2} \cup T_{3}) &= (T_{1} \cap T_{2}) \cup (T_{1} \cap T_{3}) \quad (\text{distributivity of } \cap \text{ over } \cup) \\
T_{1} \cup (T_{2} \cap T_{3}) &= (T_{1} \cup T_{2}) \cap (T_{1} \cup T_{3}) \quad (\text{distributivity of } \cup \text{ over } \cap) \\
T_{1} \cap (T_{1} \cup T_{2}) &= T_{1}, \quad T_{1} \cup (T_{1} \cap T_{2}) = T_{1} \quad (\text{absorption}) \\
T \cap \bot_{\text{type}} &= \bot_{\text{type}}, \quad T \cup \bot_{\text{type}} = T \quad (\text{bottom identity}) \\
T \cap \top_{\text{type}} &= T, \quad T \cup \top_{\text{type}} = \top_{\text{type}} \quad (\text{top identity}) \\
T \setminus T &= \bot_{\text{type}}, \quad T \setminus \bot_{\text{type}} = T, \quad T \setminus \top_{\text{type}} = \bot_{\text{type}} \quad (\text{relative complement})
\end{aligned}
```

  Disjointness Invariant and Downward Specialization Propagation:

```math
\forall T_{1}, T_{2}, S_{1}, S_{2} \in \mathcal{T}, \quad (T_{1} \perp T_{2} \;\wedge\; S_{1} \le T_{1} \;\wedge\; S_{2} \le T_{2}) \implies S_{1} \perp S_{2}
```

  Inhabitation and Non-Vacuity Invariant:

```math
\forall C \in \mathcal{C} \setminus \{ \bot_{\text{type}} \}, \quad \llbracket C \rrbracket \ne \emptyset
```

  Consequently, no non-bottom classifier may specialize mutually disjoint types:

```math
\forall C \in \mathcal{C} \setminus \{ \bot_{\text{type}} \}, \quad \forall T_{1}, T_{2} \in \mathcal{T}, \quad (C \le T_{1} \;\wedge\; C \le T_{2}) \implies \neg(T_{1} \perp T_{2})
```

  Characteristic Bit-Vector Isomorphism (NP-3 Tractable Model): Let $`\mathcal{A} = \{ A_{1}, A_{2}, \dots, A_{K} \}`$` denote the set of irreducible atomic classifiers spanning the poset, where `$`K = |\mathcal{A}| \le |\mathcal{T}|`$`. Each type `$`T \in \mathcal{T}`$` is represented by a characteristic bit-vector `$`\mathbf{b}(T) \in \{0, 1\}^K`$` such that `$`\mathbf{b}(T)[k] = 1 \iff A_{k} \le T`$:

```math
\begin{aligned}
\mathbf{b}(T_{1} \cup T_{2}) &= \mathbf{b}(T_{1}) \vee \mathbf{b}(T_{2}) \\
\mathbf{b}(T_{1} \cap T_{2}) &= \mathbf{b}(T_{1}) \wedge \mathbf{b}(T_{2}) \\
\mathbf{b}(T_{1} \setminus T_{2}) &= \mathbf{b}(T_{1}) \wedge \neg \mathbf{b}(T_{2}) \\
T_{1} \le T_{2} &\iff (\mathbf{b}(T_{1}) \wedge \neg \mathbf{b}(T_{2})) = \mathbf{0} \\
T_{1} \perp T_{2} &\iff (\mathbf{b}(T_{1}) \wedge \mathbf{b}(T_{2})) = \mathbf{0}
\end{aligned}
```

  AST Node Formalization: Each compound type node $`T_{\text{alg}} \in \mathcal{V}_{\text{AST}}`$ is formalized as a 6-tuple:


  where:

```math
\begin{aligned}
```

- **Computational Complexity & Algorithmic Bounds**: Compound type algebra lowering, normalization, and disjointness verification execute strictly within Complexity Class $`\mathbf{P}`$.

  **Algorithmic Bound NP-3 Formulation**: In unrestricted partially ordered sets (posets) with multiple inheritance and arbitrary type complements, subtyping satisfiability and compound type simplification is NP-complete (NP-3). The DEAP compiler eliminates exponential backtracking and non-termination by enforcing a finite monotonic meet-semilattice $`(\mathcal{T}, \le, \wedge)`$` with C3 superclass linearization and encoding classifier extensions as compact characteristic bit-vectors `$`\mathbf{b}(T)`$ over atomic base classifiers.

  **Asymptotic Verification Bounds**:
  1. *Pairwise Disjointness Check*: Evaluates in strictly $`O(1)`$` constant time via bitset intersection check `$`(\mathbf{b}(T_{1}) \ \& \ \mathbf{b}(T_{2})) == \mathbf{0}`$` or direct lookup in a precomputed upper-triangular disjointness matrix `$`\mathbf{M}_{\text{disjoint}} \in \{0, 1\}^{|\mathcal{T}| \times |\mathcal{T}|}`$.
  2. *Compound Type Algebraic Operations*: For an expression with $`M`$` operators over `$`|\text{Types}|`$` classifiers, each operation performs word-level bitwise manipulation across `$`W = \lceil |\text{Types}| / 64 \rceil`$` machine words. For typical models where `$`|\text{Types}| \le 4096`$`, `$`W \le 64 = O(1)`$` machine words, evaluating each operation in `$`O(1)`$` amortized time. Over the finite classifier poset, compound type operations evaluate in deterministic `$`O(|\text{Types}|)`$ time.
  3. *Cycle Detection & Topological Sorting*: Cycle detection on the type dependency graph $`G = (V, E)`$` executes via Tarjan's strongly connected components algorithm in deterministic `$`O(V + E)`$ time.
  4. *Total Sequential Verification Complexity*: For an abstract model containing $`V = |\mathcal{T}|`$` classifier nodes, `$`E`$` specialization edges, and `$`M`$ type algebra expressions:

```math
T_{\text{validate}}(V, E, M) \in O(V + E + M \cdot \lceil V / 64 \rceil) \subseteq O(V + E)
```

  **Parallel Work-Stealing Scaling (Architectural Directive 2)**: When type algebra verification across decoupled packages is scheduled on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$:

```math
T_{\text{parallel}}(V, E, M, N_{\text{max\_workers}}) \in O\left( \frac{V + E + M}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

  **Space Complexity & Memory Bounds**: Compact bitset representations require $`O(V \cdot \lceil V / 64 \rceil)`$` bits, and contiguous arena memory for AST nodes requires `$`O(V + M)`$` storage. The diagnostic sink buffer is bounded by `$`O(C_{\text{max\_errors}}) = O(1)`$` preallocated memory. Total space complexity is strictly `$`O(V + E + M)`$ with zero dynamic heap reallocations.
