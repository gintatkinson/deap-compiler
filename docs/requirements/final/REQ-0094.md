### REQ-0094: KerML Standard Library: `ControlFunctions` Package (Decision, Merge, Fork, Join)

- **Normative Statement**: The behavioral compiler and metamodel lowering engine of Subsystem 4 shall bootstrap the normative KerML `ControlFunctions` standard library package (`KerML::ControlFunctions`) into the root symbol table, formalizing Petri net execution token-passing semantics and discrete control node primitives (`Decision`, `Merge`, `Fork`, `Join`) for behavioral action control graphs.

  The lowering engine shall bootstrap the package hierarchy, register authoritative control node classifiers, and statically verify and enforce the following structural, topological, typing, and behavioral invariants for every control graph and control function instantiation:
  1. **Standard Library Bootstrap & Classifier Hierarchy**: The compiler shall register package `ControlFunctions` within the immutable standard library root namespace. The package shall define base control classifiers specializing KerML `Feature` and `Step`, and corresponding behavioral function classifiers specializing KerML `Behavior` and `Function`:
     - `ControlNode`: Abstract base classifier for discrete control routing nodes specializing KerML `Feature`.
     - `ForkNode` and function `Fork`: Concurrent token replication node specializing `ControlNode` and KerML `Behavior`.
     - `JoinNode` and function `Join`: Concurrent token synchronization node specializing `ControlNode` and KerML `Behavior`.
     - `DecisionNode` and function `Decision`: Guarded conditional token routing node specializing `ControlNode` and KerML `Behavior`.
     - `MergeNode` and function `Merge`: Alternative token pass-through node specializing `ControlNode` and KerML `Behavior`.
     Every bootstrapped control classifier and primitive function shall be permanently interned in the root lexical symbol table during compiler initialization.
  2. **Control Node Topology & Degree Invariants**: Every control node instantiated within an action control graph $G_{\text{ctrl}} = (V_{\text{ctrl}} \cup V_{\text{step}}, E_{\text{ctrl}})$ shall strictly adhere to exact input and output control edge degree constraints:
     - *Fork Node*: Exactly 1 incoming control edge ($\text{deg}_{\text{in}} = 1$) and two or more outgoing concurrent control edges ($\text{deg}_{\text{out}} \ge 2$).
     - *Join Node*: Two or more incoming concurrent control edges ($\text{deg}_{\text{in}} \ge 2$) and exactly 1 outgoing control edge ($\text{deg}_{\text{out}} = 1$).
     - *Decision Node*: Exactly 1 incoming control edge ($\text{deg}_{\text{in}} = 1$) and two or more outgoing alternative control edges ($\text{deg}_{\text{out}} \ge 2$), each associated with a guard expression.
     - *Merge Node*: Two or more incoming alternative control edges ($\text{deg}_{\text{in}} \ge 2$) and exactly 1 outgoing control edge ($\text{deg}_{\text{out}} = 1$).
     Any control node violating these degree constraints or exhibiting dangling control edges shall be deterministically rejected at compile time with structured diagnostic error code `E0200` (`MalformedControlTopology`) per REQ-0191.
  3. **Petri Net Token Passing & Multiset Execution Semantics**: Control flows shall execute according to formal discrete Petri net token multiset semantics over marking $M : E_{\text{ctrl}} \to \mathbb{N}_0$:
     - *Fork Semantics*: Arrival of a single control token on the incoming edge ($\bullet t$) consumes the incoming token and produces $k \ge 2$ independent, concurrent control tokens distributed simultaneously across all outgoing edges ($\{ t_1, t_2, \dots, t_k \}$).
     - *Join Semantics*: A Join node requires the simultaneous presence of incoming tokens across all $k \ge 2$ incoming control edges ($\{ t_1, t_2, \dots, t_k \}$) before firing. Firing consumes exactly one token from each incoming edge and releases a single synchronized token ($t_\bullet$) onto the outgoing control edge.
     - *Decision Semantics*: Arrival of a single control token on the incoming edge ($\bullet t$) evaluates all outgoing guard predicates against the active system evaluation state $\sigma \in \Sigma$. The token is routed exclusively along the unique outgoing branch $e_i$ whose guard evaluates to true ($g_i(\sigma) = \text{true}$).
     - *Merge Semantics*: Arrival of an incoming control token on any single incoming edge ($t_j$) immediately consumes the token and passes a single token ($t_\bullet$) through to the outgoing control edge without waiting for tokens on other incoming edges.
  4. **Decision Guard Disjointness & Exhaustiveness**: For every Decision node with outgoing branches $e_1, \dots, e_k$ and associated guard predicates $g_1, \dots, g_k$:
     - *Pairwise Guard Disjointness*: The guard predicates must be statically pairwise disjoint across all valid valuation states: $\forall i \ne j, \forall \sigma \in \Sigma, \; \neg(g_i(\sigma) \wedge g_j(\sigma))$. If any pair of guards can be simultaneously satisfied, the compiler shall emit structured diagnostic error code `E0200` (`AmbiguousDecisionBranch`).
     - *Guard Exhaustiveness*: The disjunction of all guard predicates must be tautologically complete ($\bigvee_{i=1}^k g_i(\sigma) \equiv \text{true}$), or the Decision node must provide an explicit fallback `else` branch.
     - *Boolean Expression Typing*: Each guard expression $g_i$ must statically evaluate to a scalar `Boolean` type ($\tau(g_i) \equiv \text{Boolean}$). Guard expressions evaluating to non-boolean types shall be rejected with structured diagnostic error code `E0202` (`InvalidGuardType`).
  5. **Join Deadlock Freedom & Fork Ancestry Invariant**: To guarantee that a Join node never suffers permanent token starvation or deadlock, the compiler shall enforce static Join deadlock freedom:
     - *Common Fork Ancestor*: For every Join node $u_{\text{join}}$ with $k \ge 2$ incoming branches, there must exist a common ancestor Fork node $w_{\text{fork}}$ such that each of the $k$ incoming branches to $u_{\text{join}}$ can be traced backward along directed control paths to distinct outgoing branches of $w_{\text{fork}}$.
     - *Deadlock from Mutually Exclusive Decision Branches*: If any two incoming branches to a Join node originate from distinct alternative branches of an intervening Decision node without a mediating Fork, or if guards along paths from the ancestor Fork to the Join are mutually exclusive, a token cannot simultaneously arrive on all incoming branches of the Join. The compiler shall detect this static starvation condition and reject the control graph with structured diagnostic error code `E0200` (`JoinDeadlockStarvation`).
  6. **Instant Control Cycle Elimination**: Directed paths composed exclusively of control nodes (`Fork`, `Join`, `Decision`, `Merge`) that form a closed cycle without intervening action step executions or event triggers shall be detected via topological cycle analysis and rejected with structured diagnostic error code `E0203` (`InstantControlCycle`).
  7. **Total-Function Error Recovery & Sentinel Binding (Architectural Directive 4)**: In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, the engine shall implement synchronization token error recovery on statement and control node delimiters. Upon detecting any structural or typing defect (`E0200`, `E0202`, or `E0203`), the engine shall record a structured diagnostic record into the preallocated diagnostic sink buffer $\mathcal{D}_{\text{sink}}$, bind an error sentinel node $\bot_{\text{ctrl}}$ to malformed control elements, sever cyclic back-edges in an overlay graph $\mathcal{E}_{\text{overlay}}$, and resume parsing subsequent action steps and control nodes. If accumulated diagnostics reach the preallocated capacity limit $C_{\text{max\_errors}}$, the compiler shall emit terminal diagnostic `E0199` and halt gracefully.
  8. **Architectural Directives Compliance**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every bootstrapped control function, lowered control node, control edge, and guard expression AST node shall receive an immutable deterministic RFC 4122 UUIDv5 identifier hashed from the canonical compiler namespace OID and the fully qualified symbol path ($\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(u))$) per REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel lowering, validation, and reachability verification of independent control graphs across separate compilation units shall execute strictly on a bounded work-stealing thread pool with worker bound $N_{\text{max\_workers}}$ per REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: Scalar identifiers, control node labels, function names, and guard tokens shall be interned into the global deduplicated symbol interner pool per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 5 (Panic-Free Release Isolation)*: Production compiler library code shall enforce a deterministic, non-panicking execution contract with total-function termination across all valid and malformed inputs. Execution latency (strictly below 25 ms) and peak memory RSS (strictly below 100 MB for $10^5$ control nodes) performance gates shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `ControlFunctions`, `ActionDef_Alpha`, `ActionDef_Beta`, `Node_Fork`, `Node_Join`, `Node_Decision`, `Node_Merge`, `Step_Alpha`, `Step_Beta`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $\mathcal{T}_{\text{metamodel}}$ denote the KerML classifier specialization poset ordered by subtyping relation $\le_{\text{sub}}$. The taxonomic specialization of bootstrapped control entities satisfies:

$$
\begin{aligned}
\text{ControlNode} &\le_{\text{sub}} \text{Feature} \le_{\text{sub}} \text{Type} \\
\text{ForkNode} &\le_{\text{sub}} \text{ControlNode} \\
\text{JoinNode} &\le_{\text{sub}} \text{ControlNode} \\
\text{DecisionNode} &\le_{\text{sub}} \text{ControlNode} \\
\text{MergeNode} &\le_{\text{sub}} \text{ControlNode} \\
\text{Fork} &\le_{\text{sub}} \text{Function} \le_{\text{sub}} \text{Behavior} \\
\text{Join} &\le_{\text{sub}} \text{Function} \le_{\text{sub}} \text{Behavior} \\
\text{Decision} &\le_{\text{sub}} \text{Function} \le_{\text{sub}} \text{Behavior} \\
\text{Merge} &\le_{\text{sub}} \text{Function} \le_{\text{sub}} \text{Behavior}
\end{aligned}
$$

An action control graph $G_{\text{ctrl}}$ is formalized as a directed multigraph:

$$
G_{\text{ctrl}} = (V, E_{\text{ctrl}})
$$

where the vertex set $V$ is partitioned into action steps and control routing nodes:

$$
V = V_{\text{step}} \cup V_{\text{ctrl}}
$$

$$
V_{\text{ctrl}} = V_{\text{fork}} \cup V_{\text{join}} \cup V_{\text{decision}} \cup V_{\text{merge}}
$$

For each node $u \in V$, the incoming and outgoing control edge sets are defined as:

$$
\text{InEdges}(u) = \{ (v, u) \in E_{\text{ctrl}} \}, \quad \text{OutEdges}(u) = \{ (u, w) \in E_{\text{ctrl}} \}
$$

Control Node In-Degree and Out-Degree Cardinality Invariants:

$$
\begin{aligned}
\forall u \in V_{\text{fork}}, &\quad |\text{InEdges}(u)| = 1 \;\wedge\; |\text{OutEdges}(u)| \ge 2 \\
\forall u \in V_{\text{join}}, &\quad |\text{InEdges}(u)| \ge 2 \;\wedge\; |\text{OutEdges}(u)| = 1 \\
\forall u \in V_{\text{decision}}, &\quad |\text{InEdges}(u)| = 1 \;\wedge\; |\text{OutEdges}(u)| \ge 2 \\
\forall u \in V_{\text{merge}}, &\quad |\text{InEdges}(u)| \ge 2 \;\wedge\; |\text{OutEdges}(u)| = 1
\end{aligned}
$$

Let $M : E_{\text{ctrl}} \to \mathbb{N}_0$ denote a Petri net execution token marking over control edges. The transition firing semantics for the four control primitives are formalized as:

$$
\begin{aligned}
\text{Fork}(u) &: \bullet t \to \{ t_1, t_2, \dots, t_k \} \\
&\quad M(e_{\text{in}}) \ge 1 \implies M'(e_{\text{in}}) = M(e_{\text{in}}) - 1 \;\wedge\; \left( \forall e \in \text{OutEdges}(u), \; M'(e) = M(e) + 1 \right) \\
\text{Join}(u) &: \{ t_1, t_2, \dots, t_k \} \to t_\bullet \\
&\quad \left( \forall e \in \text{InEdges}(u), \; M(e) \ge 1 \right) \implies \left( \forall e \in \text{InEdges}(u), \; M'(e) = M(e) - 1 \right) \;\wedge\; M'(e_{\text{out}}) = M(e_{\text{out}}) + 1 \\
\text{Decision}(u) &: \bullet t \to t_i \quad (\text{where } g_i(\sigma) = \text{true}) \\
&\quad (M(e_{\text{in}}) \ge 1 \;\wedge\; g_i(\sigma) = \text{true}) \implies M'(e_{\text{in}}) = M(e_{\text{in}}) - 1 \;\wedge\; M'(e_i) = M(e_i) + 1 \;\wedge\; \left( \forall j \ne i, \; M'(e_j) = M(e_j) \right) \\
\text{Merge}(u) &: t_j \to t_\bullet \\
&\quad (\exists e_j \in \text{InEdges}(u) : M(e_j) \ge 1) \implies M'(e_j) = M(e_j) - 1 \;\wedge\; M'(e_{\text{out}}) = M(e_{\text{out}}) + 1
\end{aligned}
$$

Decision Guard Disjointness, Exhaustiveness, and Typing Invariants:

$$
\forall u \in V_{\text{decision}}, \quad \forall e_i, e_j \in \text{OutEdges}(u), \; i \ne j \implies \left( \forall \sigma \in \Sigma, \; \neg(g_{e_i}(\sigma) \wedge g_{e_j}(\sigma)) \right)
$$

$$
\forall u \in V_{\text{decision}}, \quad \forall \sigma \in \Sigma, \quad \bigvee_{e \in \text{OutEdges}(u)} g_e(\sigma) \equiv \text{true}
$$

$$
\forall u \in V_{\text{decision}}, \quad \forall e \in \text{OutEdges}(u), \quad \tau(g_e) \equiv \text{Boolean}
$$

Join Deadlock Freedom & Common Fork Ancestor Invariant: For every Join node $u \in V_{\text{join}}$ with incoming edges $\text{InEdges}(u) = \{ e_1, \dots, e_k \}$ with $k \ge 2$, there exists a common ancestor Fork node $w \in V_{\text{fork}}$ such that each incoming branch derives from a distinct outgoing edge of $w$:

$$
\begin{aligned}
\forall u \in V_{\text{join}}, \quad \exists w \in V_{\text{fork}} \quad &\text{such that} \quad \forall i \in \{ 1, \dots, k \}, \; \exists \text{ directed path } \pi_i : w \rightsquigarrow u \text{ entering via } e_i \\
&\text{where } \forall i \ne j, \quad \text{FirstEdge}(\pi_i) \ne \text{FirstEdge}(\pi_j)
\end{aligned}
$$

Furthermore, let $\text{Guards}(\pi_i)$ denote the set of guard predicates encountered along path $\pi_i$. The joint path condition across all synchronized branches must be satisfiable:

$$
\forall u \in V_{\text{join}}, \quad \text{SAT}\left( \bigwedge_{i=1}^k \bigwedge_{g \in \text{Guards}(\pi_i)} g \right) \equiv \text{true}
$$

Static Join Deadlock Detection from Mutually Exclusive Decision Branches:

$$
\left( \exists e_i, e_j \in \text{InEdges}(u), \; i \ne j, \; \exists d \in V_{\text{decision}} : d \rightsquigarrow e_i \;\wedge\; d \rightsquigarrow e_j \;\wedge\; \text{FirstEdge}(d \rightsquigarrow e_i) \ne \text{FirstEdge}(d \rightsquigarrow e_j) \right) \implies \text{JoinDeadlock}(u)
$$

Instant Control Node Cycle Elimination Invariant: Let $G_{\text{node}} = (V_{\text{ctrl}}, E_{\text{ctrl}} \cap (V_{\text{ctrl}} \times V_{\text{ctrl}}))$ denote the direct control node subgraph. $G_{\text{node}}$ must be strictly acyclic:

$$
\forall u \in V_{\text{ctrl}}, \quad (u, u) \notin E_{\text{node}}^+
$$

Deterministic RFC 4122 UUIDv5 Topological Anchor (Architectural Directive 1):

$$
\forall u \in V_{\text{ctrl}} \cup E_{\text{ctrl}} \cup \mathcal{G}_{\text{expr}}, \quad \Delta(u) = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(u))
$$

Compiler Diagnostic Code Trigger Invariant (REQ-0191):

$$
\begin{aligned}
(|\text{InEdges}(u)| \ne 1 \;\vee\; |\text{OutEdges}(u)| \lt 2) \quad \text{for } u \in V_{\text{fork}} &\implies \text{Diagnostic}(u, \text{DiagnosticCode::E0200}, \text{MalformedControlTopology}) \in \mathcal{D}_{\text{sink}} \\
(|\text{InEdges}(u)| \lt 2 \;\vee\; |\text{OutEdges}(u)| \ne 1) \quad \text{for } u \in V_{\text{join}} &\implies \text{Diagnostic}(u, \text{DiagnosticCode::E0200}, \text{MalformedControlTopology}) \in \mathcal{D}_{\text{sink}} \\
(|\text{InEdges}(u)| \ne 1 \;\vee\; |\text{OutEdges}(u)| \lt 2) \quad \text{for } u \in V_{\text{decision}} &\implies \text{Diagnostic}(u, \text{DiagnosticCode::E0200}, \text{MalformedControlTopology}) \in \mathcal{D}_{\text{sink}} \\
(|\text{InEdges}(u)| \lt 2 \;\vee\; |\text{OutEdges}(u)| \ne 1) \quad \text{for } u \in V_{\text{merge}} &\implies \text{Diagnostic}(u, \text{DiagnosticCode::E0200}, \text{MalformedControlTopology}) \in \mathcal{D}_{\text{sink}} \\
\exists e_i, e_j \in \text{OutEdges}(u), i \ne j : \text{SAT}(g_{e_i} \wedge g_{e_j}) &\implies \text{Diagnostic}(u, \text{DiagnosticCode::E0200}, \text{AmbiguousDecisionBranch}) \in \mathcal{D}_{\text{sink}} \\
\text{JoinDeadlock}(u) &\implies \text{Diagnostic}(u, \text{DiagnosticCode::E0200}, \text{JoinDeadlockStarvation}) \in \mathcal{D}_{\text{sink}} \\
\tau(g_e) \not\equiv \text{Boolean} &\implies \text{Diagnostic}(e, \text{DiagnosticCode::E0202}, \text{InvalidGuardType}) \in \mathcal{D}_{\text{sink}} \\
\exists u \in V_{\text{ctrl}} : (u, u) \in E_{\text{node}}^+ &\implies \text{Diagnostic}(u, \text{DiagnosticCode::E0203}, \text{InstantControlCycle}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

Sanitized Analysis Overlay Graph Invariant (Architectural Directive 4):

$$
E_{\text{ctrl}, \text{overlay}} = E_{\text{ctrl}} \setminus \{ (u, v) \in E_{\text{ctrl}} \mid (u, v) \in E_{\text{ctrl}}^+ \;\wedge\; (v, u) \in E_{\text{ctrl}}^+ \}
$$

$$
\text{IsAcyclic}((V_{\text{ctrl}}, E_{\text{ctrl}, \text{overlay}})) \equiv \text{true}
$$

- **Computational Complexity & Algorithmic Bounds**: Static analysis, topology verification, Join deadlock freedom verification, and simulation evaluation of the KerML `ControlFunctions` primitives execute strictly within Complexity Class $\mathbf{P}$.

  **Algorithmic Bound Formulation & NP-Completeness Decoupling**: While general Petri net reachability is EXPSPACE-complete and concurrent orthogonal state reachability is PSPACE-complete (as cataloged in NP-5 under REQ-0124), discrete acyclic action control graphs with structured Fork-Join pairs and guarded Decision-Merge blocks avoid combinatorial state space explosion. Static semantic checks, degree verification, dominator analysis, and topological sorting are bounded to deterministic low-degree polynomial time.

  **Asymptotic Verification Complexity**: For an action control graph containing $V = |V_{\text{step}}| + |V_{\text{ctrl}}|$ nodes, $E = |E_{\text{ctrl}}|$ control edges, and $G = |\mathcal{G}_{\text{expr}}|$ guard expressions:
  1. *Bootstrapped Library Symbol Registration*: Bootstrapping the `ControlFunctions` package and interning scalar symbol tokens during compiler initialization requires $O(1)$ constant time.
  2. *Control Node Degree and Topology Verification*: Accumulating incoming and outgoing degree counts across all $u \in V_{\text{ctrl}}$ and verifying degree bounds executes in $O(|V_{\text{ctrl}}| + |E_{\text{ctrl}}|)$ deterministic linear time.
  3. *Decision Guard Disjointness & Typing Validation*: For each Decision node with $k$ outgoing branches, verifying that $\tau(g_i) \equiv \text{Boolean}$ takes $O(k)$ time. Evaluating pairwise disjointness across $k(k-1)/2$ pairs of linear arithmetic guards executes in $O(k^2)$ time via syntactic disjointness rules. Since $\sum k \le E$, total guard validation executes in $O(E)$ time.
  4. *Join Deadlock Freedom & Common Fork Ancestry*: Verifying that each Join node possesses a valid common ancestor Fork node and that incoming branches do not originate from mutually exclusive Decision branches executes via backwards reachability bitsets or dominator tree analysis in $O(V + E)$ time.
  5. *Instant Control Cycle Elimination*: Cycle detection over the direct control node subgraph $G_{\text{node}} = (V_{\text{ctrl}}, E_{\text{node}})$ via Tarjan's strongly connected components algorithm or Kahn's in-degree reduction algorithm visits each control node at most twice and traverses each control edge exactly once:

$$
T_{\text{cycle}}(V_{\text{ctrl}}, E_{\text{node}}) = \sum_{u \in V_{\text{ctrl}}} \left( O(1) + \sum_{v \in \text{Succ}(u)} O(1) \right) \in O(V_{\text{ctrl}} + E_{\text{node}}) \subseteq O(V + E)
$$

  6. *Discrete Petri Net Token Step Simulation*: Evaluating a single token dispatch or control node transition (`Fork`, `Join`, `Decision`, `Merge`) during execution simulation executes in deterministic amortized $O(1)$ time per transition step.
  7. *Total Sequential Verification Complexity*: Total compilation time across all verification phases is strictly linear in the size of the control flow graph:

$$
T_{\text{total}}(V, E, G) \in O(V + E + G) \subseteq O(V + E)
$$

  8. *Parallel Work-Stealing Scaling (Architectural Directive 2)*: When $M$ independent control graphs $\{ G_1, G_2, \dots, G_M \}$ across disjoint packages are verified concurrently on a bounded work-stealing thread pool with worker bound $N_{\text{max\_workers}}$:

$$
T_{\text{parallel}} \in O\left( \frac{\sum_{i=1}^M (V_i + E_i)}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  9. *Space Complexity & Memory Bounds*: Auxiliary memory is bounded by $O(V + E)$ for adjacency lists, node degree tables indexed directly by 32-bit arena offsets, and the topological evaluation queue. The diagnostic sink buffer is bounded by $O(C_{\text{max\_errors}}) = O(1)$ allocated memory, guaranteeing that auxiliary memory remains strictly $O(V + E)$ with zero unbounded heap reallocations.
