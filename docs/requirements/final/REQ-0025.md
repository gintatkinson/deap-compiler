### REQ-0025: Tabular Schema Ingestion for Topological Connections & Interconnects

- **Normative Statement**: The ingestion engine within the Universal Schema Ingestion Engine shall parse CommonMark tabular schemas specifying topological connections and interconnects between ports into `IngestedConnection` intermediate Abstract Syntax Tree (AST) entities. For each data row in a connection definition table, the parser must extract the unique connection identifier, the fully qualified source port endpoint path ($`P_{\text{src}}`$`), the fully qualified target port endpoint path (`$`P_{\text{tgt}}`$`), the interconnect communication protocol or interaction kind, and any optional physical or temporal parameters including latency upper bounds (`$`\tau_{\text{lat}}`$`) and explicit delay model flags (`$`\delta`$). Header column keys shall be dynamically normalized into canonical connection metamodel attributes in an order-independent manner. All connection and endpoint identifiers must be sanitized in accordance with the lexical rules defined in REQ-0019. The ingestion engine shall enforce endpoint path well-formedness: both source and target port paths must comprise at least two path segments separated by canonical namespace delimiters (`::`), decomposing into an owning parent component hierarchy path and a terminal port identifier. The parser shall validate topological interconnect graph invariants: every connection establishes a directed edge $`E = (P_{\text{src}}, P_{\text{tgt}})`$` within the topological interconnect graph; direct self-loops (`$`P_{\text{src}} = P_{\text{tgt}}`$) lacking an explicit delay model or buffering queue specification are strictly invalid and shall deterministically trigger diagnostic error code `E0104`. If an endpoint path fails structural well-formedness (such as fewer than two segments, empty segment tokens, or invalid identifier characters), the parser shall emit diagnostic error code `E0104`. If a row specifies a negative latency bound ($`\tau_{\text{lat}} \lt 0`$), the parser shall emit diagnostic error code `E0104`. If duplicate connection identifiers are declared within the same scope, the parser shall emit diagnostic error code `E0104`. Missing mandatory endpoint columns (`source` or `target`) shall trigger diagnostic error code `E0104`. All successfully parsed `IngestedConnection` entities shall be allocated sequentially into contiguous typed bump arena storage in accordance with REQ-0009 and REQ-0034, yielding deterministic node handles with stable relative offsets. In accordance with Architectural Directive 3 and REQ-0036, copying string bytes from the input table buffer into the global symbol interner pool for scalar symbol tokens (connection identifiers, endpoint segments, protocol handles) during this initial ingestion pass is the sole permitted exception to the zero-copy invariant. In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, the ingestion engine shall implement synchronization token error recovery on row delimiter boundaries ($`\text{SYM}_{\text{LF}}`$`), logging structured diagnostics, substituting a typed sentinel error node `$`\bot_{\text{conn}}`$`, and resuming ingestion at the next row boundary rather than aborting compilation. If accumulated diagnostics reach the sink capacity limit `$`C_{\text{max\_errors}}`$, the parser must emit diagnostic error code `E0199` and terminate table processing gracefully. In accordance with Architectural Directive 2 and REQ-0012, multi-table or multi-file parallel ingestion passes shall be scheduled strictly onto a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$. In accordance with Architectural Directive 5, the parser must execute as a total function with zero unhandled panics or unwinding exceptions across all malformed inputs. The engine shall operate strictly on abstract MBSE formalisms using synthetic placeholders (e.g., `Package_0`, `Component_Alpha`, `Component_Beta`, `Part_0`, `Part_1`, `Port_Src`, `Port_Tgt`, `Conn_0`, `Protocol_A`, `param_x : Real`) with zero domain contamination.

- **Formal Invariant**: Let $`\mathcal{T}_{\text{conn}} = (\mathbf{H}, \mathbf{R})`$` denote a tabular schema specifying topological connections, where `$`\mathbf{H} = \langle H_0, H_1, \dots, H_{C-1} \rangle`$` represents the sequence of `$`C`$` normalized column headers (`$`1 \le C \le C_{\text{max\_cols}} = 32`$`) and `$`\mathbf{R} = \langle R_1, R_2, \dots, R_M \rangle`$` represents the ordered sequence of `$`M`$` table rows. Each row `$`R_i = \langle c_{i, 0}, c_{i, 1}, \dots, c_{i, C-1} \rangle`$ specifies a topological interconnect entity.

Let $`\vec{\beta} : \{0, \dots, C-1\} \to \mathcal{K}_{\text{conn}} \cup \{ \bot \}`$ denote the column-to-attribute binding vector mapping table column indices to canonical connection attributes:

```math
\mathcal{K}_{\text{conn}} = \{ \text{id}, \text{source}, \text{target}, \text{protocol}, \text{latency}, \text{delay\_flag} \}
```

Let $`\mathcal{C} = \{ C_1, C_2, \dots, C_M \}`$ denote the collection of lowered `IngestedConnection` intermediate entities. Each connection entity $`C_i \in \mathcal{C}`$ is formalized as a 7-tuple:

```math
C_i = \langle \text{id}_i, P_{\text{src}, i}, P_{\text{tgt}, i}, \pi_i, \tau_{\text{lat}, i}, \delta_i, \text{span}_i \rangle
```

where:
- $`\text{id}_i \in \mathcal{S}_{\text{sym}}`$ is the interned scalar symbol handle representing the unique connection identifier,
- $`P_{\text{src}, i} \in \mathcal{P}_{\text{path}}`$ is the fully qualified source port endpoint path,
- $`P_{\text{tgt}, i} \in \mathcal{P}_{\text{path}}`$ is the fully qualified target port endpoint path,
- $`\pi_i \in \Pi_{\text{proto}} \cup \{ \bot \}`$ is the communication protocol or interaction kind handle,
- $`\tau_{\text{lat}, i} \in \mathbb{R}_{\ge 0} \cup \{ \infty, \bot \}`$ is the optional upper latency bound,
- $`\delta_i \in \mathbb{B}`$` is the boolean explicit delay model flag (`$`\text{has\_delay}`$),
- $`\text{span}_i = \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle`$ is the exact source code provenance coordinate.

Endpoint Path Representation & Decomposition:
Let an endpoint path $`P \in \mathcal{P}_{\text{path}}`$` be an ordered sequence of non-empty identifier tokens over alphabet `$`\Sigma^*`$:

```math
P = \langle s_1, s_2, \dots, s_k \rangle, \quad s_j \in \Sigma^+, \quad k \in \mathbb{N}
```

The path segmentation operator $`\text{SplitSegments} : \Sigma^* \to \mathcal{P}_{\text{path}}`$` decomposes raw endpoint string `$`s`$ by delimiter token `"::"`:

```math
\text{Segments}(P) = |\text{SplitSegments}(P)| = k
```

Endpoint Path Well-Formedness Invariant:
Every valid connection endpoint path must contain at least two segments, decomposing into an owner part hierarchy path and a terminal port identifier:

```math
\forall P \in \{ P_{\text{src}}, P_{\text{tgt}} \}, \quad \text{Segments}(P) \ge 2 \;\wedge\; (\forall j \in \{1, \dots, k\}, \; \text{ValidIdentifier}(s_j))
```

where structural path decomposition satisfies:

```math
P = \text{OwnerPath}(P) \mathbin{\Vert} \text{"::"} \mathbin{\Vert} \text{PortIdentifier}(P)
```

with:

```math
\begin{aligned}
\text{OwnerPath}(P) &= \langle s_1, \dots, s_{k-1} \rangle \\
\text{PortIdentifier}(P) &= s_k
\end{aligned}
```

Topological Multigraph Invariant:
Let $`G_{\text{topo}} = (\mathcal{V}_{\text{port}}, \mathcal{E}_{\text{conn}})`$` denote the topological interconnect directed multigraph, where vertices `$`\mathcal{V}_{\text{port}}`$` correspond to structural port instances and directed edges `$`\mathcal{E}_{\text{conn}}`$ correspond to connection instances:

```math
E_i = (P_{\text{src}, i}, P_{\text{tgt}, i}) \in \mathcal{E}_{\text{conn}}
```

Self-Loop Delay Model Invariant:
A connection establishing a self-loop ($`P_{\text{src}} = P_{\text{tgt}}`$`) is permitted if and only if an explicit delay model or buffering queue is declared (`$`\delta = \text{true}`$):

```math
\forall C \in \mathcal{C}, \quad (P_{\text{src}} = P_{\text{tgt}}) \implies (\delta = \text{true})
```

Equivalently, instantaneous self-loops lacking explicit delay models are strictly forbidden:

```math
(P_{\text{src}} = P_{\text{tgt}} \;\wedge\; \delta = \text{false}) \implies \bot_{\text{conn}}
```

Latency Bound Invariant:
When an explicit latency bound is specified, it must be strictly non-negative:

```math
\tau_{\text{lat}} \ne \bot \implies \tau_{\text{lat}} \ge 0
```

Scoped Connection Identifier Uniqueness Invariant:
Within any enclosing structural scope $`\mathcal{K}_{\text{scope}}`$, connection identifiers must be pairwise distinct:

```math
\forall C_a, C_b \in \mathcal{C}, \quad (\text{scope}(C_a) = \text{scope}(C_b) \;\wedge\; C_a.\text{id} = C_b.\text{id}) \implies C_a = C_b
```

Row-to-Entity Ingestion Mapping:
The connection row ingestion operator $`\Phi_{\text{conn}} : \text{Row} \to \text{IngestedConnection} \cup \{ \bot_{\text{conn}} \}`$` evaluates row `$`R_i`$:

```math
\Phi_{\text{conn}}(R_i) = 
\begin{cases}
C_i, & \text{if } \text{ValidConnectionRow}(R_i) \\
\bot_{\text{conn}}, & \text{if } \neg\text{ValidConnectionRow}(R_i)
\end{cases}
```

Diagnostic Code Binding Invariant:
Violations of connection syntax, endpoint path well-formedness, topological invariants, or identifier uniqueness deterministically trigger structured diagnostic records in accordance with REQ-0191:

```math
\begin{aligned}
\text{Segments}(P_{\text{src}, i}) \lt 2 \;\vee\; \text{Segments}(P_{\text{tgt}, i}) \lt 2 &\implies \text{Diagnostic}(R_i, C_{\text{endp}}, \text{DiagnosticCode::E0104}, \text{MalformedEndpointPath}) \in \mathcal{D} \\
P_{\text{src}, i} = P_{\text{tgt}, i} \;\wedge\; \delta_i = \text{false} &\implies \text{Diagnostic}(R_i, C_{\text{tgt}}, \text{DiagnosticCode::E0104}, \text{ForbiddenZeroDelaySelfLoop}) \in \mathcal{D} \\
\tau_{\text{lat}, i} \lt 0 &\implies \text{Diagnostic}(R_i, C_{\text{lat}}, \text{DiagnosticCode::E0104}, \text{NegativeLatencyBound}) \in \mathcal{D} \\
\exists k \ne i : C_k.\text{id} = C_i.\text{id} \wedge \text{scope}(C_k) = \text{scope}(C_i) &\implies \text{Diagnostic}(R_i, C_{\text{id}}, \text{DiagnosticCode::E0104}, \text{DuplicateConnectionId}) \in \mathcal{D} \\
\text{Cell}(R_i, C_{\text{src}}) = \varepsilon \;\vee\; \text{Cell}(R_i, C_{\text{tgt}}) = \varepsilon &\implies \text{Diagnostic}(R_i, 0, \text{DiagnosticCode::E0104}, \text{MissingMandatoryEndpoint}) \in \mathcal{D} \\
|\mathcal{D}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
```

Diagnostic Taxonomy Containment Invariant:
All emitted diagnostic records strictly reside within the ingestion error family:

```math
\forall D \in \mathcal{D}_{\text{conn\_table}}, \quad \text{code}(D) \in \{ \text{DiagnosticCode::E0102}, \text{DiagnosticCode::E0104}, \text{DiagnosticCode::E0199} \} \subset \mathcal{E}_{\text{ingest}}
```

- **Computational Complexity & Algorithmic Bounds**: Tabular schema ingestion for topological connections and interconnects executes strictly within Complexity Class $`\mathbf{P}`$`. For an input document of total byte length `$`N`$` containing `$`R`$` table rows and `$`C`$` columns subject to the upper bound `$`C \le C_{\text{max\_cols}} = 32`$, the ingestion engine executes through the following bounded algorithmic phases:
1. Lexical Scanning & Delimiter Extraction: The event-driven CommonMark table scanner scans the byte stream sequentially without backtracking, advancing monotonically in $`O(N)`$ operations.
2. Header Normalization & Column Binding: The column-to-attribute binding vector $`\vec{\beta}`$` is computed once per table in `$`O(C) = O(1)`$ constant time.
3. Row Cell Tokenization: For each row $`R_i`$`, extracting cell string slices takes `$`O(C) = O(1)`$ operations.
4. Endpoint Path Splitting: For each endpoint string of byte length $`L_P \le 256`$, delimiter splitting by `"::"` and segment count verification execute in $`O(L_P) = O(1)`$ deterministic time.
5. Identifier Sanitization & Interning: Sanitizing connection identifiers and interning string tokens into the global symbol interner pool takes $`O(L_{\text{id}}) = O(1)`$ amortized time per token.
6. Self-Loop and Delay Validation: Comparing source and destination endpoint symbol tuples $`(P_{\text{src}}, P_{\text{tgt}})`$` and inspecting the boolean delay flag `$`\delta`$` executes in `$`O(1)`$ constant time.
7. Latency Envelope Validation: Parsing and verifying numeric non-negativity ($`\tau_{\text{lat}} \ge 0`$`) executes in `$`O(1)`$ scalar operations.
8. Scoped Identifier Uniqueness Verification: Checking connection identifier uniqueness against an interned 64-bit SymbolId hash set within the active scope executes in $`O(1)`$ expected amortized time per row.
9. Contiguous Arena Allocation: Writing the synthesized `IngestedConnection` 7-tuple into contiguous bump arena storage requires a single pointer bump operation, executing in strict $`O(1)`$ constant time.
10. Graph Edge Insertion: Inserting connection edge $`E = (P_{\text{src}}, P_{\text{tgt}})`$` into the topological multigraph adjacency structure executes in `$`O(1)`$ amortized time.

Total sequential execution time across all $`R`$ connection rows is strictly linear:

```math
T(R, N) \in O(N) = O(R \cdot C) = O(R)
```

Topological multigraph construction over $`R`$` connections with `$`|V| \le 2R`$` port vertices and `$`|E| = R`$` connection edges executes in deterministic `$`O(|V| + |E|) = O(R)`$ linear time.
When processing $`K`$` distinct connection tables across `$`N_{\text{max\_workers}}`$` threads in a bounded work-stealing thread pool, parallel wall-clock runtime is bounded by `$`O(\lceil K / N_{\text{max\_workers}} \rceil \cdot R_{\text{max}})`$.
Auxiliary space complexity is strictly bounded by $`O(R)`$` for contiguous bump arena entity storage and `$`O(1)`$` stack frame allocation per row. The diagnostic sink capacity is bounded by `$`O(C_{\text{max\_errors}}) = O(1)`$` heap records, ensuring zero unbounded heap memory growth relative to input table size `$`R`$.

- **Verification & Conformance Criteria**: Automated test suites shall deterministically verify compliance against synthetic CommonMark schema tables specifying generic MBSE topological interconnects using abstract placeholders (e.g., `Package_0`, `Component_Alpha`, `Component_Beta`, `Part_0`, `Part_1`, `Port_Src`, `Port_Tgt`, `Conn_0`, `Conn_1`, `Protocol_A`, `Protocol_B`, `param_x : Real`). Conformance shall be validated through the following deterministic test gates:
1. Canonical Connection Table Ingestion Gate: Ingest a valid 50-row connection definition table declaring connections (`Conn_0` through `Conn_49`) between structural ports across component part instances (e.g., `Part_Alpha::Port_Out` to `Part_Beta::Port_In`, `Part_0::Port_A` to `Part_1::Port_B`) with diverse protocols (`Protocol_Async`, `Protocol_Sync`), valid positive latency bounds (`10.5 ms`, `2.0 ms`), and explicit delay annotations; assert that 100% of rows lower into synthesized `IngestedConnection` AST entities with correct endpoint decomposition, stable bump arena node handle offsets, and zero diagnostics.
2. Endpoint Path Segmentation & Well-Formedness Gate: Ingest connection rows containing malformed endpoint paths, such as single-segment identifiers without owner prefixes (`Port_Out`), empty segments (`Part_Alpha::::Port_In` or `::Port_In`), or illegal identifier characters (`Part@Alpha::Port#1`); assert deterministic emission of diagnostic error code `E0104` (`MalformedEndpointPath`), substitution of typed sentinel $`\bot_{\text{conn}}`$, and successful continuation to subsequent table rows.
3. Self-Loop Detection Gate: Ingest a connection table row declaring identical source and destination endpoint paths (`Part_Alpha::Port_0` to `Part_Alpha::Port_0`) with no delay model (`delay = false` or omitted); assert deterministic emission of diagnostic error code `E0104` (`ForbiddenZeroDelaySelfLoop`). Ingest a second row declaring identical endpoints but specifying an explicit delay model (`delay = true`); assert that the connection lowers successfully into an `IngestedConnection` entity with zero diagnostics.
4. Latency Bound Non-Negativity Gate: Ingest a connection row specifying a negative latency bound (e.g., `-12.5 ms`); assert deterministic emission of diagnostic error code `E0104` (`NegativeLatencyBound`), substitution of $`\bot_{\text{conn}}`$, and continued parsing.
5. Scoped Identifier Uniqueness Gate: Ingest two distinct rows declaring identical connection identifiers within the same component/subsystem scope; assert deterministic emission of diagnostic error code `E0104` (`DuplicateConnectionId`) for the colliding row.
6. Missing Mandatory Endpoint Column Gate: Ingest a connection table where mandatory columns (`source` or `target`) are omitted or left blank; assert deterministic emission of diagnostic error code `E0104` (`MissingMandatoryEndpoint`).
7. Synchronization Token Error Recovery Gate (Directive 4): Ingest a synthetic 10-row connection table where rows 3 and 7 contain deliberate syntax faults (a single-segment endpoint path and an unbuffered zero-delay self-loop); assert that rows 1, 2, 4, 5, 6, 8, 9, 10 are completely extracted into valid `IngestedConnection` entities, rows 3 and 7 record typed sentinels $`\bot_{\text{conn}}`$, exactly two `E0104` diagnostic records are accumulated in the sink, and the parser resynchronizes cleanly on line break delimiter tokens ($`\text{SYM}_{\text{LF}}`$`). Ingest a pathological table exceeding `$`C_{\text{max\_errors}}`$ faults; assert that parsing halts gracefully with diagnostic code `E0199`.
8. Total Function & Panic-Free Execution Gate (Directive 5): Fuzz testing with $`10^4`$ pathological tabular inputs (including truncated rows, unclosed pipe delimiters, null bytes, high-entropy unicode noise, and deeply nested paths) shall verify total-function termination with zero panics or unwinding exceptions across all execution paths.
9. Release Mode Latency Gate (Directive 5): Connection ingestion throughput and latency shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests, asserting throughput exceeding $`10^5`$ rows/s, execution latency under 25 ms for standard compilation units, and peak RSS memory under 20 MB.
10. Bitwise Determinism Gate: Assert that compiling identical connection schema tables across multiple runs and distinct thread counts yields 100% bitwise identical AST entities and topological multigraph representations with zero diff churn.
