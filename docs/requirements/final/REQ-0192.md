## 1. Normative Statement

Subsystem 11 SHALL execute reverse synchronization via `ProseGate_Alpha` and `Reconciler_0`.

Pipeline MUST enforce:
1. **Tri-State Classification**: Ingesting $``D_{\text{doc}}``$ against arena $\mathcal{A}$, `ProseGate_Alpha` SHALL classify entities $``E_{\text{doc}} \in \mathcal{E}_{\text{doc}}``$ into `ExactMatch(n)`, `Renamed(n)`, or `NewProseEntity`.
2. **Exact Match Preservation**: Matching anchor ID and name for $n \in \mathcal{A}$ SHALL trigger `PreserveExisting(n)`, retaining node and sub-tree without mutation.
3. **Identifier Rename Validation**: Matching anchor ID with modified name triggers syntax and scope checks. Syntax faults MUST emit `E0300`, binding $``\bot_{\text{reconcile}}``$. Scope collisions MUST emit `E0502`. Valid renames SHALL update identifiers in-place.
4. **Prohibition of Entity Injection**: Entities lacking anchor IDs in $\mathcal{A}$ SHALL be classified as `NewProseEntity` and rejected with `E0502`, enforcing $``|\mathcal{A}_{\text{post}}| \le |\mathcal{A}_{\text{pre}}|``$ and $``\mathcal{A}_{\text{post}} \setminus \mathcal{A}_{\text{pre}} = \emptyset``$.
5. **Prose Protection**: `Reconciler_0` SHALL partition $``D_{\text{doc}}``$ into schema blocks $``\mathcal{B}_{\text{schema}}``$ and prose blocks $``\mathcal{B}_{\text{prose}}``$. Unmapped blocks $``B \in \mathcal{B}_{\text{prose}}``$ SHALL remain byte-for-byte intact ($``\text{SHA256}(\mathcal{R}_{\text{doc}}(B)) \equiv \text{SHA256}(B)``$).
6. **Directives**: UUIDv5 anchors (Directive 1); work-stealing $``N_{\text{max\_workers}}``$ (Directive 2); symbol interning (Directive 3); delimiter recovery halting at $``C_{\text{max\_errors}}``$ with `E0199` (Directive 4); Release budget ($< 25\text{ ms}$, $< 100\text{ MB}$) (Directive 5). Placeholders (`Package_0`, `Classifier_Alpha`, `ProseGate_Alpha`, `Reconciler_0`, `ProseEntity_1`, `Entity_0`, `param_x : Real`) used.

## 2. Formal Invariant

Tri-state document entity reconciliation, AST non-injection, and prose preservation satisfy:

```math
\begin{aligned}
\text{Classify}(E_{\text{doc}},\mathcal{A})&=\begin{cases}
\text{ExactMatch}(n),&\text{if }\exists n\in\mathcal{A}:\text{id}(E_{\text{doc}})=\text{id}(n)\land\text{name}(E_{\text{doc}})=\text{name}(n) \\
\text{Renamed}(n),&\text{if }\exists n\in\mathcal{A}:\text{id}(E_{\text{doc}})=\text{id}(n)\land\text{name}(E_{\text{doc}})\ne\text{name}(n) \\
\text{NewProseEntity},&\text{if }\neg\exists n\in\mathcal{A}:\text{id}(E_{\text{doc}})=\text{id}(n)
\end{cases} \\
\alpha(c)&=\begin{cases}
\text{PreserveExisting}(n),&\text{if }c=\text{ExactMatch}(n) \\
\text{UpdateIdentifier}(n,\text{name}(E_{\text{doc}})),&\text{if }c=\text{Renamed}(n)\land\Phi_{\text{valid}}(E_{\text{doc}},n) \\
\text{RejectUnauthorizedEntity}(\text{E0502}),&\text{if }c=\text{NewProseEntity}
\end{cases} \\
\mathcal{A}_{\text{post}}\setminus\mathcal{A}_{\text{pre}}&=\emptyset\land|\mathcal{A}_{\text{post}}|\le|\mathcal{A}_{\text{pre}}|,\quad\forall B\in\mathcal{B}_{\text{prose}},\;\text{SHA256}(\mathcal{R}_{\text{doc}}(B))\equiv\text{SHA256}(B) \\
\neg\Phi_{\text{valid}}(E_{\text{doc}},n)&\implies\text{Diagnostic}(E_{\text{doc}},\text{E0300})\in\mathcal{D}_{\text{sink}}\land E_{\text{doc}}\gets\bot_{\text{reconcile}} \\
c=\text{NewProseEntity}&\implies\text{Diagnostic}(E_{\text{doc}},\text{E0502})\in\mathcal{D}_{\text{sink}}\land E_{\text{doc}}\gets\bot_{\text{reconcile}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}} \\
\Delta_{\text{reconcile}}(E_{\text{doc}})&=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(E_{\text{doc}})\mathbin{\Vert}\text{"::ProseGate::Entity"})
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$.
- **Asymptotic Bound:** Reconciliation takes $``O(\vert E_{\text{doc}} \vert + \vert N_{\text{AST}} \vert)``$ time and $``O(N_{\text{bytes}} + \vert E_{\text{doc}} \vert + \vert N_{\text{AST}} \vert)``$ space. Work-stealing scales as $``O(N_{\text{total}} / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Bypasses NP-1 (REQ-0117), NP-2 (REQ-0147), and NP-8 (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: ExactMatch Classification and Invariant Preservation
- **Given:** Entity `Entity_0` in $\mathcal{A}$ and document `Doc_0` with matching ID and name.
- **When:** `ProseGate_Alpha` evaluates reconciliation.
- **Then:** Classifies as `ExactMatch`, preserving node without mutation.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Renamed Entity Validation and Identifier Mutation
- **Given:** Entity `Entity_0` renamed to `Classifier_Beta` in document `Doc_0`.
- **When:** `Reconciler_0` validates syntax and scope.
- **Then:** Classifies as `Renamed`, updating identifier in-place.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Unauthorized Prose Entity Detection and Rejection
- **Given:** Document `Doc_0` declaring ungrounded `ProseEntity_1` without anchor ID in $\mathcal{A}$.
- **When:** `ProseGate_Alpha` evaluates classification.
- **Then:** Rejects entity as `NewProseEntity`, halting injection, emitting `E0502`.
- **Diagnostic:** `E0502`.

### AC-04: Malformed Rename Identifier and Delimiter Recovery
- **Given:** Malformed rename followed by delimiter `###` and valid `Entity_0`.
- **When:** `Reconciler_0` scans tokens.
- **Then:** Emits `E0300`, binds $``\bot_{\text{reconcile}}``$, recovers on `###`, parses `Entity_0`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.

### AC-05: User Prose Block Preservation and Release Performance Budget
- **Given:** Schema entities and prose blocks $``\mathcal{B}_{\text{prose}}``$ across $10^4$ nodes on $``N_{\text{max\_workers}}``$ threads.
- **When:** Benchmarking in Release mode (`--release`).
- **Then:** Preserves prose byte-for-byte ($\text{SHA256}$ match); latency $< 25\text{ ms}$, RSS $< 100\text{ MB}$.
- **Diagnostic:** Diagnostic sink remains empty.
