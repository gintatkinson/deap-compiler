## 1. Normative Statement

The Universal Schema Ingestion Engine shall provide a native XML Schema Definition (W3C XSD) and Architecture Description Language (ADL) parser that ingests structural schemas and component topologies into intermediate schema IR without external toolchains. The parser must execute via a deterministic, single-pass event-driven pushdown automaton without regular expressions, enforcing the Zero Regex XML Processing Invariant across all input streams.

The lowering transformation shall map XML constructs into schema IR:
1. Complex Types and Components: `xs:complexType` definitions and `adl:component` prototypes lower to `IngestedPart` entities within an `IngestedPackage` namespace, establishing hierarchical scoping (e.g., `Package_0::Component_Alpha`).
2. Attributes and Elements: `xs:element` and `xs:attribute` declarations lower to `IngestedAttr` properties with multiplicity $``\langle \text{minOccurs}, \text{maxOccurs} \rangle \in \mathbb{N}_0 \times (\mathbb{N}_0 \cup \{\infty\})``$, mapping `unbounded` to $`\infty`$. Declarations with $`\text{minOccurs} \gt \text{maxOccurs}`$ are invalid and emit `E0103`.
3. Ports: `adl:port` definitions lower to `IngestedPort` entities with explicit directions: provided ports (P-Ports) map to `Out`, required ports (R-Ports) map to `In`, and bidirectional ports map to `InOut`. Missing or invalid directions emit `E0102`.
4. Connectors: `adl:connector` links lower to `IngestedConnection` entities binding source endpoint $``P_{\text{src}}``$ and target endpoint $``P_{\text{tgt}}``$. Unresolved endpoints or directional mismatches (connecting `In` to `Out` in reverse flow) emit `E0102`.

Lowered AST nodes are allocated in contiguous bump arena storage (REQ-0009, REQ-0034) with deterministic RFC 4122 UUIDv5 identifiers (Directive 1, REQ-0010). Interning string bytes into the symbol pool is the sole permitted zero-copy exception (Directive 3, REQ-0036). On syntax faults, the parser executes Synchronization Token Error Recovery on delimiters (`>`, `/>`, tag boundaries), logging diagnostics (`E0100`, `E0102`, `E0103`), substituting sentinels ($``\bot_{\text{part}}``$, $``\bot_{\text{port}}``$, $``\bot_{\text{conn}}``$), and resuming parsing (Directive 4, REQ-0013, REQ-0016). Saturated error sinks emit `E0199` and halt gracefully. Multi-file units are ingested on a bounded work-stealing pool ($``N_{\text{max\_workers}}``$, Directive 2, REQ-0012). The parser enforces a deterministic non-panicking contract evaluated in Release mode (Directive 5, REQ-0011, REQ-0196). Models strictly employ abstract MBSE placeholders (`Package_0`, `Component_Alpha`, `Component_Beta`, `Port_1`, `Port_2`, `Conn_0`, `Flow_A`, `param_x : Real`).

## 2. Formal Invariant

Let $``\mathcal{X}_{\text{xml}}``$ denote an ingested XML document tree:

```math
\mathcal{X}_{\text{xml}} = \langle \mathcal{N}_{\text{ns}}, \mathcal{T}_{\text{types}}, \mathcal{C}_{\text{comps}}, \mathcal{K}_{\text{conns}} \rangle
```

The schema lowering transformation $``\mathcal{T}_{\text{xml}} : \mathcal{X}_{\text{xml}} \longrightarrow \mathcal{A}_{\text{IR}}``$ maps XML declarations to schema IR entities:

```math
\begin{aligned}
\text{xs:complexType } T &\longmapsto \text{IngestedPart}(T, \text{attrs}: \mathcal{F}_{\text{attrs}}(T)) \\
\text{xs:element } e &\longmapsto \text{IngestedAttr}(e, \text{type}: \tau(e), \text{mult}: \mu(e)) \\
\text{adl:component } C &\longmapsto \text{IngestedPart}(C, \text{ports}: \mathcal{F}_{\text{ports}}(C)) \\
\text{adl:port } p &\longmapsto \text{IngestedPort}(p, \text{dir}: \text{Direction}(p)) \\
\text{adl:connector } c &\longmapsto \text{IngestedConnection}(c.\text{src}, c.\text{tgt})
\end{aligned}
```

Port directionality mapping satisfies:

```math
\text{Direction}(p) = \begin{cases}
\text{Out}, & \text{if } p \in \text{ProvidedPorts} \\
\text{In}, & \text{if } p \in \text{RequiredPorts} \\
\text{InOut}, & \text{if } p \in \text{BidirectionalPorts}
\end{cases}
```

Occurrence multiplicity $`\mu(e)`$ and connector compatibility satisfy:

```math
\begin{aligned}
\mu(e) = \langle \text{minOccurs}(e), \text{maxOccurs}(e) \rangle &\quad \wedge \quad \text{minOccurs}(e) \le \text{maxOccurs}(e) \\
\text{Compatible}(P_{\text{src}}, P_{\text{tgt}}) &\iff \text{Direction}(P_{\text{src}}) \in \{ \text{Out}, \text{InOut} \} \;\wedge\; \text{Direction}(P_{\text{tgt}}) \in \{ \text{In}, \text{InOut} \}
\end{aligned}
```

The Zero Regex XML Processing Invariant enforces deterministic pushdown transition $``\delta_{\text{pda}}``$:

```math
\delta_{\text{pda}} : Q \times (\Sigma \cup \{ \epsilon \}) \times \Gamma \longrightarrow \mathcal{P}(Q \times \Gamma^*)
```

Diagnostic code bindings per REQ-0191 satisfy:

```math
\begin{aligned}
\text{XMLMalformed}(\text{span}) &\implies \text{Diagnostic}(\text{span}, \text{DiagnosticCode::E0100}) \in \mathcal{D} \\
\text{minOccurs}(e) \gt \text{maxOccurs}(e) &\implies \text{Diagnostic}(\text{span}(e), \text{DiagnosticCode::E0103}) \in \mathcal{D} \\
\text{IsUnsupportedType}(T) &\implies \text{Diagnostic}(\text{span}(T), \text{DiagnosticCode::E0103}) \in \mathcal{D} \\
(\neg\text{Compatible}(P_{\text{src}}, P_{\text{tgt}}) \;\vee\; \text{UnresolvedEndpoint}(P)) &\implies \text{Diagnostic}(\text{span}(c), \text{DiagnosticCode::E0102}) \in \mathcal{D} \\
|\mathcal{D}| \ge C_{\text{max\_errors}} &\implies \text{Diagnostic}(\text{span}(\text{EOF}), \text{DiagnosticCode::E0199}) \in \mathcal{D}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The XSD and ADL XML ingestion engine executes in Complexity Class $`\mathbf{P}`$. Deterministic pushdown parsing scans $`N`$ bytes in $`O(N)`$ linear time without backtracking. Element hierarchy tracking maintains stack depth $`D \le 64 \ll N`$, requiring $`O(D) = O(1)`$ space. Lowering $`V`$ components/types, $`P`$ ports, and $`K`$ connectors requires $`O(V + P + K) \le O(N)`$ entity operations. Symbol interning and bump arena node allocation execute in $`O(1)`$ amortized and constant time respectively. Resolving endpoints across $`K`$ connections takes $`O(K)`$ time via scoped symbol tables. Parallel compilation across $`M`$ schemas on a bounded work-stealing pool ($``N_{\text{max\_workers}}``$) runs in $``O(\lceil M / N_{\text{max\_workers}} \rceil \cdot N_{\text{max}})``$ time. The engine executes strictly in polynomial time, bypassing combinatorial NP-complete frontiers (NP-1--NP-8).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Canonical Component and Complex Type Lowering
- **Given:** Valid XSD/ADL document declaring complex type `Type_Alpha` and component `Component_Alpha` with attributes `param_x : Real` and `param_y : Int32`.
- **When:** Lowering the XML AST into intermediate schema IR.
- **Then:** Emits `IngestedPart` entities containing `IngestedAttr` entries with exact scalar types in bump arena storage without diagnostics.
- **Diagnostic:** `E0100` on XML grammar failure.

### AC-02: Port Directionality Mapping for Provided, Required, and Bidirectional Ports
- **Given:** Component `Component_Alpha` declaring provided port `Port_1` (P-Port), required port `Port_2` (R-Port), and bidirectional port `Port_3`.
- **When:** Lowering port definitions into intermediate schema IR.
- **Then:** Maps `Port_1` to `Out`, `Port_2` to `In`, and `Port_3` to `InOut` within generated `IngestedPort` entities.
- **Diagnostic:** `E0102` on missing or invalid port direction specification.

### AC-03: Connector Topology Lowering and Directional Compatibility Gate
- **Given:** ADL connector `Conn_0` connecting `Component_Alpha::Port_1` (`Out`) to `Component_Beta::Port_2` (`In`), and invalid connector `Conn_1` connecting `Component_Beta::Port_2` (`In`) to `Component_Alpha::Port_1` (`Out`).
- **When:** Validating topological connections and port endpoint directions.
- **Then:** Lowers `Conn_0` into an `IngestedConnection` link; rejects `Conn_1` due to reversed flow, substitutes sentinel $``\bot_{\text{conn}}``$, and emits a structured diagnostic.
- **Diagnostic:** `E0102` on directional mismatch or unresolvable endpoint path.

### AC-04: Occurrence Bound Multiplicity and Validation
- **Given:** XSD elements with valid bounds (`minOccurs="0"`, `maxOccurs="1"`, and `minOccurs="1"`, `maxOccurs="unbounded"`), and an invalid element with `minOccurs="5"` and `maxOccurs="2"`.
- **When:** Parsing occurrence attributes and computing multiplicity interval $`\mu(e)`$.
- **Then:** Lowers valid elements with multiplicity $`\langle 0, 1 \rangle`$ and $`\langle 1, \infty \rangle`$; rejects invalid declaration with $`\text{minOccurs} \gt \text{maxOccurs}`$, logs a structured diagnostic, and substitutes sentinel $``\bot_{\text{attr}}``$.
- **Diagnostic:** `E0103` on inverted occurrence bounds ($`\text{minOccurs} \gt \text{maxOccurs}`$).

### AC-05: Pushdown Automaton Recovery on Malformed XML Delimiters
- **Given:** XML document with syntax errors between valid declarations `Component_Alpha` and `Component_Beta`, with error limit $``C_{\text{max\_errors}}``$.
- **When:** Executing single-pass pushdown parsing under Synchronization Token Error Recovery.
- **Then:** Recovers at sibling tag boundary (`>`), records structured diagnostics, substitutes sentinel $``\bot_{\text{part}}``$, extracts all subsequent valid components, and halts gracefully emitting `E0199` upon reaching $``C_{\text{max\_errors}}``$.
- **Diagnostic:** `E0100` on syntax recovery; `E0199` on diagnostic sink saturation.

### AC-06: Panic-Free Release Mode Latency and Bounded Memory Footprint
- **Given:** Malformed and truncated XML/ADL test schemas evaluated in compiled Release mode (`--release`).
- **When:** Ingesting schemas under dedicated benchmark harness isolation.
- **Then:** Terminates under a total-function contract with zero panics, execution latency under 25 ms, and peak memory RSS under 50 MB for documents up to 5 MB.
- **Diagnostic:** Structured diagnostics `E0100` through `E0199` with clean process exit.
