### REQ-0005: Standalone Self-Contained Execution & Environment Independence

- **Normative Statement**: The compiler platform shall execute as an autonomous, self-contained compiler binary that operates completely independently of host environment configuration, external service daemons, network connectivity, or implicit ambient filesystem state. The compiler must not require external language runtimes, dynamic linkers to non-standard host libraries, container engines, or persistent daemon processes during any compilation phase. The compiler shall isolate its execution from ambient host environment variables, user identity (UID/username), system locale, timezone, hostname, and global filesystem paths located outside the sovereign workspace root. All standard metamodels, core KerML/SysML v2 standard libraries, primitive scalar type definitions, and diagnostic templates required for bootstrapping must be bundled directly into the executable binary or resolved exclusively from workspace-relative paths. The compiler shall strictly prohibit network communication; compilation passes must never initiate outbound network sockets, listen on inbound sockets, execute remote procedure calls, or issue DNS queries. Any attempt to access external network sockets, read unwhitelisted environment variables, or access files outside the sovereign workspace boundary shall be rejected as an invariant violation, causing the compiler to halt execution and report diagnostic error code `E0100`.

- **Formal Invariant**: Let $`\mathcal{C}`$` denote the compiler evaluation function, and let `$`\mathcal{I}`$` denote the tuple of explicit input schemas, workspace configuration, and command-line arguments. Let `$`\mathbb{E}`$` denote the universe of host execution environments, where each environment `$`\mathcal{E} \in \mathbb{E}`$ is defined as the 4-tuple:

```math
\mathcal{E} = \langle \mathcal{V}_{\text{env}}, \mathcal{N}_{\text{net}}, \mathcal{F}_{\text{host}}, \mathcal{T}_{\text{host}} \rangle
```

representing host environment variables $`\mathcal{V}_{\text{env}}`$`, network socket capabilities `$`\mathcal{N}_{\text{net}}`$`, host non-workspace filesystem state `$`\mathcal{F}_{\text{host}}`$`, and host temporal/locale configuration `$`\mathcal{T}_{\text{host}}`$.

Environment Invariance: for any two host execution environments $`\mathcal{E}_1, \mathcal{E}_2 \in \mathbb{E}`$`, the compiled artifact output `$`\mathcal{C}(\mathcal{I}, \mathcal{E})`$ is invariant:

```math
\forall \mathcal{E}_1, \mathcal{E}_2 \in \mathbb{E}, \quad \mathcal{C}(\mathcal{I}, \mathcal{E}_1) \equiv \mathcal{C}(\mathcal{I}, \mathcal{E}_2)
```

Environment Variable Isolation Invariant: let $`\text{ReadEnv}(\mathcal{C})`$` denote the set of environment variables queried by `$`\mathcal{C}`$` during execution, and let `$`\mathcal{V}_{\text{whitelisted}}`$ denote the explicitly enumerated set of compiler-permitted configuration flags:

```math
\text{ReadEnv}(\mathcal{C}) \subseteq \mathcal{V}_{\text{whitelisted}}
```

Network Isolation Invariant: let $`\text{SocketsActive}(\mathcal{C})`$` denote the set of all transport-layer socket descriptors, network interfaces, and DNS resolutions opened or polled by `$`\mathcal{C}`$:

```math
\text{SocketsActive}(\mathcal{C}) = \emptyset
```

Host Filesystem Containment Invariant: let $`\text{PathsAccessed}(\mathcal{C})`$` denote all filesystem paths opened for read or write operations by `$`\mathcal{C}`$`, and let `$`\text{Workspace}(\mathcal{I})`$` denote the closure of workspace-relative paths under repository root `$`\mathcal{R}`$:

```math
\forall p \in \text{PathsAccessed}(\mathcal{C}), \quad p \in \text{Workspace}(\mathcal{I}) \cup \text{BinarySelf}(\mathcal{C})
```

Self-Contained Standard Metamodel Closure: let $`\mathcal{M}_{\text{bootstrap}}`$` represent the complete set of primitive metamodels, scalar types, and standard library definitions required for compilation, and let `$`\text{Embedded}(\mathcal{C})`$ represent symbols compiled directly into the binary:

```math
\mathcal{M}_{\text{bootstrap}} \subseteq \text{Embedded}(\mathcal{C}) \cup \text{Workspace}(\mathcal{I})
```

- **Computational Complexity & Algorithmic Bounds**: The compiler bootstrap and environment isolation verification execute within Complexity Class $`\mathbf{P}`$`. Startup environment inspection and whitelist filtering execute in `$`O(|\mathcal{V}_{\text{env}}|)`$` deterministic time, where `$`|\mathcal{V}_{\text{env}}|`$` is the number of ambient environment variables presented at process launch. Dynamic workspace path confinement checks execute in `$`O(1)`$` constant time amortized per path evaluation (or `$`O(|P|)`$` with respect to path string length `$`|P|`$`). Total auxiliary memory overhead for environment isolation verification is `$`O(1)`$, requiring zero dynamic heap growth outside the compiler's linear memory arena.

- **Verification & Conformance Criteria**: Conformance shall be deterministically validated by executing the compiler test suite inside a fully isolated, air-gapped container sandbox where network interfaces are unconfigured, ambient environment variables are purged ($`\mathcal{V}_{\text{env}} = \emptyset`$), and filesystem access outside the workspace is blocked via unmounted or restricted permissions. The test harness shall assert that compiling identical input schema units under this sanitized sandbox and under standard host environments produces bitwise-identical output digests with zero diff churn. Any unauthorized network socket operation, unwhitelisted environment access, or non-workspace filesystem escape shall immediately halt compilation and emit diagnostic error code `E0100` specifying the violating resource identifier and execution context.
