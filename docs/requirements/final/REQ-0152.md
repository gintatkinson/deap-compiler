### REQ-0152: SI Unit Verification in $`\mathbb{Q}^7`$ Rational Metric Space across Signal Flows

- **Normative Statement**: The Level 1C Interface Control Document (ICD) synthesis engine, signal flow validator, and interconnect contract verifier of Subsystem 8 shall verify that engineering units assigned to signals in the Master Signal Flow Dictionary strictly match the physical dimensional exponent vectors of connected interface ports in the formal $`\mathbb{Q}^7`$ rational metric space. The verification engine shall guarantee dimensional homogeneity across all inter-component and intra-subsystem flow pathways, preventing dimensional inconsistency across interconnected components and failing closed with diagnostic error code `E0301` upon any dimensional mismatch.

  Specifically, the ICD dimensional verification engine and signal flow contract validator shall strictly enforce the following structural, algebraic, and operational provisions across all compilation units:
  1. **Canonical $`\mathbb{Q}^7`$ Rational Metric Space Integration**:
     - The verification engine shall model all physical dimensions in accordance with Subsystem 5 (REQ-0098, REQ-0099, REQ-0100) as an exact 7-dimensional vector space $`(\mathbb{Q}^7, +, \cdot)`$ over the algebraic field of rational numbers $`\mathbb{Q}`$.
     - The 7 canonical basis vectors shall correspond bijectively to the International System of Units (SI) base dimensions in standardized ISO/IEC 80000 coordinate order:

$$
\mathbf{u} = [d_L, d_M, d_T, d_I, d_\Theta, d_N, d_J]^T \in \mathbb{Q}^7
$$

       representing Length ($`L`$, meter), Mass ($`M`$, kilogram), Time ($`T`$, second), Electric Current / Base Flow Quantity ($`I`$, ampere), Thermodynamic Temperature ($`\Theta`$, kelvin), Amount of Substance ($`N`$, mole), and Luminous Intensity ($`J`$, candela).
     - Each dimensional coordinate $`d_k = \frac{p_k}{q_k}`$ ($`k \in \{L, M, T, I, \Theta, N, J\}`$) shall be stored as an exact irreducible rational number with signed 64-bit integer numerator $`p_k \in \mathbb{Z}`$ and positive 64-bit integer denominator $`q_k \in \mathbb{Z}^+`$ satisfying $`\gcd(|p_k|, q_k) = 1`$.
     - The use of IEEE 754 floating-point representations (`f32`, `f64`) for dimensional exponent vectors is strictly prohibited to prevent rounding divergence and non-deterministic behavior.
     - Dimensionless signals, scalar numerical counts, boolean states, and ratio indicators shall be represented strictly by the zero vector $`\mathbf{0} = [0, 0, 0, 0, 0, 0, 0]^T \in \mathbb{Q}^7`$.
  2. **Signal Flow Dimensional Triad Homogeneity Invariant**:
     - For every signal flow record $`\sigma`$ cataloged in the Master Signal Flow Dictionary (REQ-0148) or directed item flow $`f`$ in the $`N^2`$ System Interface Matrix (REQ-0145, REQ-0146) connecting source port $`P_{\text{src}}`$ to target port $`P_{\text{tgt}}`$, the verification engine shall assert the strict equality of the dimensional triad in $`\mathbb{Q}^7`$:

$$
\text{dim}(\mathbf{u}_\sigma) = \text{dim}(P_{\text{src}}.\text{unit}) = \text{dim}(P_{\text{tgt}}.\text{unit}) \in \mathbb{Q}^7
$$

     - Triad Equivalence Rule: The declared physical dimension of the routed signal payload $`\mathbf{u}_\sigma`$ must equal the physical dimension of the transmitting source port $`P_{\text{src}}.\text{unit}`$, and must simultaneously equal the physical dimension of the receiving destination port $`P_{\text{tgt}}.\text{unit}`$.
     - Direct Port Commensurability Rule: The source port dimension and target port dimension must be strictly commensurable: $`\text{dim}(P_{\text{src}}.\text{unit}) = \text{dim}(P_{\text{tgt}}.\text{unit})`$.
  3. **Deterministic Failure Closed & Diagnostic Emission (`E0301`)**:
     - If any coordinate inequality exists across the triad:
       - If $`\text{dim}(P_{\text{src}}.\text{unit}) \ne \text{dim}(P_{\text{tgt}}.\text{unit})`$, the compiler shall fail closed and emit diagnostic error code `E0301` (`PortDimensionalMismatch`).
       - If $`\text{dim}(\mathbf{u}_\sigma) \ne \text{dim}(P_{\text{src}}.\text{unit})`$, the compiler shall fail closed and emit diagnostic error code `E0301` (`SignalSourceDimensionalMismatch`).
       - If $`\text{dim}(\mathbf{u}_\sigma) \ne \text{dim}(P_{\text{tgt}}.\text{unit})`$, the compiler shall fail closed and emit diagnostic error code `E0301` (`SignalTargetDimensionalMismatch`).
     - Every emitted diagnostic shall explicitly cite the fully qualified symbol identifier of signal $`\sigma`$, the source port identifier $`P_{\text{src}}`$, the target port identifier $`P_{\text{tgt}}`$, the respective dimensional exponent vectors in $`\mathbb{Q}^7`$, and the exact source file byte spans.
  4. **Engineering Unit Scale Multipliers & Prefix Verification**:
     - The verification engine shall delineate physical dimensional homogeneity from engineering unit scale factors (REQ-0095).
     - When two units share identical dimension vectors in $`\mathbb{Q}^7`$ but possess different scale factors or SI prefixes (such as millivolts versus volts, or kilometers versus meters), the compiler shall evaluate the scale conversion ratio $`s_{\text{ratio}} = \frac{s_{\text{src}}}{s_{\text{tgt}}} \in \mathbb{Q}`$.
     - If $`s_{\text{ratio}} \ne 1`$, the signal contract must declare an explicit linear unit conversion adapter ($`\text{scale\_adapter}(\sigma) \ne \bot`$), or the ICD code generation backend must synthesize a verified rational scaling multiplier into the serialization codec (REQ-0183, REQ-0184).
     - If an unmapped unit scale disparity exists without an explicit conversion adapter and implicit coercion is disabled, the compiler shall emit diagnostic error code `E0301` (`SignalUnitScaleMismatch`).
  5. **Compound Structured Payloads & Multi-Signal Busses**:
     - For composite signal payloads containing structured records or tuples ($`\tau_{\text{payload}} = \langle \text{field}_1, \dots, \text{field}_m \rangle`$), the engine shall recursively verify that every constituent field possessing physical semantics satisfies dimensional triad equality with its corresponding port contract field.
     - For multiplexed interconnect channels (REQ-0147) routing a bundle of multiple logical signals, every routed signal shall be individually and deterministically verified against its mapped source and target sub-port contracts.
  6. **Bidirectional & Conjugate Flow Pair Dimensional Verification**:
     - In bidirectional interconnect channels (REQ-0146) and opposing conjugate flow pairs ($`f \in M_{ij}`$ and $`f' \in M_{ji}`$), the dimensional triad verification shall be applied independently to both forward and reverse transmission pathways.
     - For complementary conjugate interfaces (e.g., effort and flow conjugate variable pairs per REQ-0107), the engine shall verify that conjugate variables satisfy the respective across and through dimensional contracts whose product yields power $`[L^2 M^1 T^{-3} I^0 \Theta^0 N^0 J^0]`$.
  7. **Contiguous Memory Bump Arena Storage & Node Handles**:
     - All signal flow dimension descriptors, port unit bindings, scale factor records, and verification outcome witnesses shall be allocated sequentially into contiguous typed bump arena storage in accordance with REQ-0009 and REQ-0034, referenced by stable 32-bit arena node handles in accordance with REQ-0035.

     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel extraction, dimensional verification, and scale factor checking of signal flows across independent compilation units, subsystems, and interface matrices shall execute strictly on a centralized, bounded work-stealing thread pool with worker upper bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.      - *Directive 3 (String Interner Memory Allocation Exception)*: Signal names, port identifiers, unit symbols (`m`, `kg`, `s`, `V`, `A`), and dimension names shall be interned into the deduplicated global symbol interner pool during lexical analysis in accordance with REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The verification engine shall implement synchronization token error recovery on statement delimiters (`;`) and table row delimiters (`|`) in accordance with REQ-0013 and REQ-0016. When dimensional mismatches (`E0301`) or invalid unit definitions (`E0300`) occur, the engine shall record structured diagnostics into the preallocated error sink buffer $`\mathcal{D}_{\text{sink}}`$, substitute typed error sentinels ($`\bot_{\text{dim}}`$), and continue validating subsequent signal declarations.
