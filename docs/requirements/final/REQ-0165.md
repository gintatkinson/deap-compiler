### REQ-0165: Feature Layer 1: Domain State, Data Models & Primitive Structural Typing

- **Normative Statement**: The downstream specification projection engine, feature synthesizer, and structural typing validator of Subsystem 9 shall extract, formalize, and project Feature Layer 1 (Domain State, Data Models & Primitive Structural Typing) specifications for every feature element defined in the system model. Layer 1 specifications shall exhaustively document all domain attributes, structural types, physical measurement units in the formal rational metric space $`\mathbb{Q}^7`$, operational range constraints, default values, and access control modifiers derived deterministically from AST part definitions (`part def`), item definitions (`item def`), port definitions (`port def`), and attribute usages. The compiler shall verify that zero untyped attributes, undefined classifiers, missing unit vectors, ungrounded placeholder tokens, or out-of-bounds default values exist within the projected Layer 1 specification, failing closed with diagnostic error code `E0500` (or `E0230` for missing or empty Layer 1 specifications per REQ-0164) upon any specification or typing violation.

  Specifically, the Feature Layer 1 projection engine and structural typing validator shall strictly enforce the following structural, algebraic, and operational provisions across all compilation units:
  1. **Feature Scope & Exhaustive Attribute Extraction**:
     - For every feature classifier $`F`$ cataloged in the feature dependency DAG (REQ-0160, REQ-0161), the compiler shall traverse the AST feature definition and exhaustively collect all constituent domain attributes, state variables, configuration parameters, and telemetry metrics into an ordered sequence $`\mathbf{A}_F = \text{Attributes}(F)`$.
     - Attributes shall be lowered from SysML v2 part definitions (`part def`, REQ-0071), item definitions (`item def`, REQ-0073), port usages (`port`, REQ-0072), attribute definitions (`attribute def`), and KerML core feature structures (REQ-0057, REQ-0060).
     - No declared domain attribute, state variable, or configuration parameter shall be omitted or elided from the synthesized Layer 1 projection.
  2. **Mandatory 6-Tuple Attribute Contract Schema**:
     - For every attribute $`a \in \mathbf{A}_F`$, Layer 1 shall formalize an explicit 6-tuple contract:

$$
a = \langle \text{Name}, \tau_{\text{type}}, u_{\text{unit}}, [v_{\min}, v_{\max}], v_{\text{default}}, \text{access} \rangle
$$

     - **Name ($`\text{Name} \in \mathcal{S}_{\text{intern}}`$)**: Fully resolved, interned attribute symbol identifier, unique within the scope of feature $`F`$.
     - **Structural Type ($`\tau_{\text{type}} \in \mathcal{V}_{\text{AST}}`$)**: Strongly typed classifier handle binding standard UML primitive types (`String`, `Integer`, `Real`, `Boolean`), fixed-width numeric types (`Int8`, `Int16`, `Int32`, `Int64`, `UInt8`, `UInt16`, `UInt32`, `UInt64`, `Float32`, `Float64`), enumeration classifiers with declared variant sets, fixed-size arrays/sequences, or structured composite record types (`DataType`, `Structure`).
     - **Physical Unit Vector ($`u_{\text{unit}} \in \mathbb{Q}^7`$)**: Rational dimensional vector over SI base dimensions $`[L, M, T, I, \Theta, N, J]^T`$ conforming to REQ-0098, REQ-0099, REQ-0100, and REQ-0152. Dimensionless attributes shall bind the null dimension vector $`\mathbf{0} \in \mathbb{Q}^7`$.
     - **Operational Range Envelope ($`[v_{\min}, v_{\max}]`$)**: Explicit numerical domain interval specifying admissible lower and upper bounds in accordance with REQ-0112 and REQ-0113. Closed, open, and semi-open intervals are supported; finite numerical bounds must satisfy $`v_{\min} \le v_{\max}`$.
     - **Default Value ($`v_{\text{default}}`$)**: Explicit, fully grounded literal or constant expression resolvable at compile time, satisfying domain membership $`v_{\text{default}} \in \text{Domain}(\tau_{\text{type}})`$ and operational interval containment $`v_{\min} \le v_{\text{default}} \le v_{\max}`$.
     - **Access Modifier ($`\text{access} \in \{ \text{ReadOnly}, \text{Configurable}, \text{OperationalWrite} \}`$)**: Explicit access modifier designating whether the attribute represents immutable sensor/telemetry state (`ReadOnly`), calibration/tuning parameter (`Configurable`), or active runtime state (`OperationalWrite`).
  3. **Zero Untyped Attribute Invariant (Completeness Gate)**:
     - Every attribute $`a \in \mathbf{A}_F`$ must bind a valid, resolved type classifier $`\tau_{\text{type}}(a) \ne \bot`$.
     - Untyped attributes, unresolved type identifiers, and ambiguous classifier bindings are strictly prohibited.
     - If an attribute lacks an explicit type annotation or references an unresolvable type symbol, the compiler shall fail closed and emit diagnostic error code `E0500` (`UntypedAttributeViolation`).
  4. **Physical Measurement Unit Verification in Rational Metric Space $`\mathbb{Q}^7`$**:
     - The verification engine shall evaluate the physical unit of every quantitative attribute against the formal 7-dimensional rational vector space $`\mathbb{Q}^7`$ (REQ-0098).
     - The declared measurement unit symbol (e.g., `m/s`, `kg`, `V`, `Pa`, `rad/s`) must correspond bijectively to the rational exponent tuple:

$$
\mathbf{u} = [d_L, d_M, d_T, d_I, d_\Theta, d_N, d_J]^T \in \mathbb{Q}^7
$$

     - If an attribute specifies an incompatible unit symbol, invalid rational exponent, or dimension mismatch relative to its declared quantity type (REQ-0095, REQ-0096, REQ-0097), the compiler shall fail closed and emit diagnostic error code `E0500` (`IncompatibleUnitDimensionViolation`).
  5. **Parametric Operational Envelopes & Boundary Validation**:
     - For every numerical attribute (integer or real), Layer 1 shall establish an explicit operational range $`[v_{\min}, v_{\max}]`$ (REQ-0112, REQ-0113).
     - The compiler shall verify that $`v_{\min} \le v_{\max}`$. If $`v_{\min} \gt v_{\max}`$, the compiler shall fail closed and emit diagnostic error code `E0500` (`MalformedOperationalEnvelopeViolation`).
     - Enumeration attributes must define an exhaustive, finite set of variant literals $`\text{Variants}(\tau_{\text{type}})`$.
     - String attributes shall declare a maximum length constraint $`L_{\max} \in \mathbb{N}^+`$.
  6. **Default Value Grounding & Domain Validity Gate**:
     - Every attribute must declare an explicit default value $`v_{\text{default}}`$.
     - Implicit uninitialized defaults, null sentinels ($`\bot`$), placeholder strings (`"TBD"`, `"TODO"`, `"UNKNOWN"`), and non-finite floating-point literals (`NaN`, $`+\infty`$, $`-\infty`$) are strictly prohibited.
     - The compiler shall verify at compile time that $`v_{\text{default}} \in \text{Domain}(\tau_{\text{type}})`$.
     - For numerical types with operational envelopes, the compiler shall assert:

$$
v_{\min} \le v_{\text{default}} \le v_{\max}
$$

     - If $`v_{\text{default}}`$ violates domain membership, boundary containment, or contains an ungrounded placeholder token, the compiler shall fail closed and emit diagnostic error code `E0500` (`DefaultValueDomainViolation`).
  7. **Access Control Modifier Enforcement**:
     - Every attribute must be assigned an access modifier from the closed enumeration $`\{ \text{ReadOnly}, \text{Configurable}, \text{OperationalWrite} \}`$.
     - Omission of the access modifier, ambiguous access specifiers, or ungrounded modifier strings shall trigger diagnostic error code `E0500` (`InvalidAccessModifierViolation`).
  8. **Deterministic Tabular Markdown Emission**:
     - Layer 1 projections shall emit canonical Markdown specification tables documenting each attribute in lexicographical order by interned symbol identifier (REQ-0032).
     - Table columns shall provide: `Attribute Name`, `Structural Type`, `Physical Unit`, `Operational Envelope`, `Default Value`, `Access`.
     - In accordance with Charter Invariant 3, Markdown table cells must never contain `$` math delimiters (using plain text, e.g., `[0.0, 100.0]`, `m/s`, `Real`, `Configurable`).
     - In accordance with Charter Invariant 4, emitted Markdown tables and text must use ASCII `--` or `-` exclusively, with zero Unicode em dashes.
  9. **Definition of Done Mandatory Layer 1 Completeness (REQ-0164)**:
     - Every feature specification must contain a non-empty Layer 1 domain model ($`|\mathbf{A}_F| \ge 1`$).
     - If a feature projection omits Layer 1 or produces an empty attribute roster without domain models, the compiler shall fail closed and emit diagnostic error code `E0230` (`Layer1DefinitionOfDoneViolation`).
  10. **Contiguous Bump Arena Storage & Node Handles**:
      - All Layer 1 feature descriptors, attribute records, operational envelope structures, and verification outcome witnesses shall be allocated sequentially into contiguous typed bump arena storage in accordance with REQ-0009 and REQ-0034, referenced by stable 32-bit arena node handles (REQ-0035).
  11. **Enforcement of the 5 Executive Architectural Directives**:
      - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every feature Layer 1 projection, constituent attribute record, operational envelope, and verification witness shall bind an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical DEAP namespace OID and the node fully qualified topological path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))`$) in accordance with REQ-0010 and REQ-0159. Time-based UUIDs are strictly banned.
      - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel extraction, domain validation, and table emission across independent features shall execute strictly on a centralized, bounded work-stealing thread pool with worker upper bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012. Unbounded manual thread spawning is strictly banned.
      - *Directive 3 (String Interner Memory Allocation Exception)*: Attribute names, type symbols, unit labels, variant identifiers, and modifier keywords shall be interned into the deduplicated global symbol interner pool during lexical analysis in accordance with REQ-0036 as the sole permitted exception to zero-copy memory management.
      - *Directive 4 (Synchronization Token Error Recovery)*: The Layer 1 extraction engine shall implement synchronization token error recovery on statement delimiters (`;`, `}`) and table row delimiters (`|`) in accordance with REQ-0013 and REQ-0016. When domain violations (`E0500`) or Definition of Done breaches (`E0230`) occur, the engine shall record structured diagnostics into the preallocated error sink buffer $`\mathcal{D}_{\text{sink}}`$, substitute typed error sentinels ($`\bot_{\text{attr}}`$), and continue validating subsequent attributes. If accumulated diagnostics reach capacity limit $`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully.
      - *Directive 5 (Panic-Free Release Paths & Benchmarking Isolation)*: The Feature Layer 1 projection engine shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Verification latency (strictly under 25 ms for $`N_A = 10^4`$ attributes) and peak RSS memory (strictly under 100 MB) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.
  12. **Pure Abstract MBSE Placeholder Mandate**:
      - All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Feature_0`, `Feature_1`, `Feature_Alpha`, `Feature_Beta`, `Part_0`, `Item_0`, `Port_0`, `attr_0`, `attr_alpha`, `attr_beta`, `param_x : Real`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

  Let $`\mathcal{F}_{\text{proj}} \subset \mathcal{V}_{\text{AST}}`$ denote the finite set of features projected by Subsystem 9.
  For each feature $`F \in \mathcal{F}_{\text{proj}}`$, its Layer 1 specification model $`\text{Layer}_1(F)`$ is formalized as a 5-tuple:

$$
  \text{Layer}_1(F) = \langle \text{id}_1, F, \mathbf{A}_F, \Delta_{\text{layer1}(F)}, \text{span}_1 \rangle
$$

  where:

$$
  \begin{aligned}
  \text{id}_1 &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
  F &\in \mathcal{F}_{\text{proj}} \quad (\text{owning feature classifier handle}) \\

  \Delta_{\text{layer1}(F)} &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 anchor}) \\

$$

  where:

$$
  \begin{aligned}

  \tau_{\text{type}}(a) &\in \mathcal{V}_{\text{AST}} \quad (\text{strongly typed classifier handle}) \\
  \mathbf{u}_{\text{unit}}(a) &\in \mathbb{Q}^7 \quad (\text{rational SI physical dimension vector}) \\
  v_{\min}(a), v_{\max}(a) &\in \mathbb{R} \cup \{-\infty, +\infty\} \quad (\text{operational envelope bounds}) \\
  v_{\text{default}}(a) &\in \mathcal{V}_{\text{AST}} \quad (\text{compile-time resolvable default value literal}) \\
  \text{access}(a) &\in \{ \text{ReadOnly}, \text{Configurable}, \text{OperationalWrite} \} \quad (\text{access modifier}) \\

  \end{aligned}

  The semantic domain $`\text{Domain}(\tau)`$ for any classifier $`\tau \in \mathcal{V}_{\text{AST}}`$ is defined inductively:

$$
  \begin{aligned}
  \text{Domain}(\tau_{\text{bool}}) &= \{ \text{false}, \text{true} \} \\
  \text{Domain}(\tau_{\text{int}}) &= \{ v \in \mathbb{Z} \mid I_{\min}(\tau_{\text{int}}) \le v \le I_{\max}(\tau_{\text{int}}) \} \\
  \text{Domain}(\tau_{\text{real}}) &= \{ v \in \mathbb{R} \mid \neg\text{isnan}(v) \wedge \neg\text{isinf}(v) \} \\
  \text{Domain}(\tau_{\text{string}}) &= \{ s \in \mathcal{S}_{\text{intern}} \mid \text{len}(s) \le L_{\max}(\tau_{\text{string}}) \} \\
  \text{Domain}(\tau_{\text{enum}}) &= \text{Variants}(\tau_{\text{enum}}) \subset \mathcal{S}_{\text{intern}} \\
  \text{Domain}(\tau_{\text{record}}) &= \left\{ \langle f_1 : v_1, \dots, f_m : v_m \rangle \;\middle|\; \forall i \in \{1, \dots, m\}, \, v_i \in \text{Domain}(\tau_i) \right\} \\
  \text{Domain}(\tau_{\text{array}}) &= \left\{ [v_1, \dots, v_N] \;\middle|\; \forall j \in \{1, \dots, N\}, \, v_j \in \text{Domain}(\tau_{\text{elem}}) \right\}
  \end{aligned}
$$

- **Computational Complexity & Algorithmic Bounds**: Feature Layer 1: Domain State, Data Models & Primitive Structural Typing resides strictly in **Complexity Class P** (Deterministic Polynomial Time), executing in strictly deterministic linear time $`O(|\mathbf{A}_F|)`$ for each feature $`F`$, and $`O(N_A)`$ across all features in a compilation unit, where $`N_A = \sum_{F \in \mathcal{F}_{\text{proj}}} |\mathbf{A}_F|`$ denotes the aggregate count of domain attributes.

  **Mathematical Delineation from the 8 NP Frontiers**:
  - *Delineation from NP-1 (REQ-0117)*: NP-1 addresses temporal interval consistency over occurrence lifecycles using Allen's 13 qualitative relations via ORD-Horn difference logic SMT solving in $`O(N^3)`$ polynomial time. In contrast, REQ-0165 performs static attribute schema projection, structural type checks, and domain envelope evaluations in deterministic linear time $`O(N_A)`$ without temporal reasoning or backtracking.
  - *Delineation from NP-2 (REQ-0147)*: NP-2 solves strongly NP-hard vector bin packing for structural allocation and interconnect channel multiplexing. In contrast, REQ-0165 projects already-typed domain attributes from AST definitions without combinatorial bin packing or multidimensional resource allocation.
  - *Delineation from NP-3 (REQ-0061--REQ-0063)*: NP-3 resolves subtyping lattices and multiple inheritance hierarchies via C3 linearization in $`O(V + E)`$ time. In contrast, REQ-0165 consumes resolved type handles and verifies scalar value containment against already-linearized classifier domains in $`O(1)`$ operations per attribute.
  - *Delineation from NP-4 (REQ-0135)*: NP-4 minimizes STPA hazard cut-sets and Unsafe Control Actions via NP-complete Minimal Hitting Set reductions. In contrast, REQ-0165 extracts domain state data models using direct single-pass AST node traversals.
  - *Delineation from NP-5 (REQ-0124)*: NP-5 solves discrete state machine reachability, deadlock, and livelock over orthogonal regions (PSPACE-complete / NP-complete BMC). In contrast, REQ-0165 operates strictly at the static structural data model layer (Layer 1), prior to and isolated from dynamic state machine verification (Layer 2, REQ-0166).
  - *Delineation from NP-6 (REQ-0105)*: NP-6 solves switched conservative flow networks via linear complementarity problems and Lemke pivoting (NP-complete). In contrast, REQ-0165 validates static attribute default values and SI dimension vectors without solving continuous flow balances or complementary inequalities.
  - *Delineation from NP-7 (REQ-0180)*: NP-7 performs register allocation and basic block scheduling in LUMI IR using Chaitin graph coloring (NP-complete). In contrast, REQ-0165 operates at the downstream specification projection boundary, formalizing requirements and data dictionaries.
  - *Delineation from NP-8 (REQ-0197)*: NP-8 proves the satisfiability of first-order invariant contracts via DPLL(T) SMT solvers. In contrast, REQ-0165 evaluates quantifier-free ground literal expressions against scalar bounds in $`O(1)`$ operations.

  **Asymptotic Complexity Analysis**:
  Let $`N_A = |\mathbf{A}_F|`$ denote the number of attributes in feature $`F`$.
  1. *AST Attribute Traversal & Lowering Phase*:
     - Traversing the AST feature node and extracting part, item, and attribute definitions requires a single pass over the contiguous bump arena node list of feature $`F`$.
     - Visiting $`N_A`$ attribute nodes requires exactly $`O(N_A)`$ operations:

$$
T_{\text{traverse}}(N_A) \in O(N_A), \quad S_{\text{traverse}}(N_A) \in O(N_A)
$$

  2. *Structural Type & Domain Membership Verification*:
     - Validating primitive scalar types (`Integer`, `Real`, `Boolean`, `String`) involves checking 64-bit integer words and IEEE 754 bit patterns in $`O(1)`$ CPU cycles.
     - Validating enumeration variants requires $`O(1)`$ membership test in the interned variant bitset or sorted slice.
     - Validating composite record types with $`m`$ fields requires $`m`$ independent field checks; with schema field bound $`m \le M_{\text{max\_fields}} \in O(1)`$, composite checks execute in $`O(1)`$ time:

$$
T_{\text{type\_check}}(a) \in O(1), \quad S_{\text{type\_check}}(a) \in O(1)
$$

  3. *Physical Measurement Unit Dimension Check in $`\mathbb{Q}^7`$*:
     - Comparing the 7 rational exponents of $`u_{\text{unit}}(a)`$ against the declared quantity system dimension tuple requires exactly 7 rational comparisons:

$$
T_{\text{unit\_check}}(a) \in O(1), \quad S_{\text{unit\_check}}(a) \in O(1)
$$

  4. *Operational Range Envelope Verification*:
     - Evaluating $`v_{\min} \le v_{\max}`$ and $`v_{\min} \le v_{\text{default}} \le v_{\max}`$ requires at most 3 scalar comparisons:

$$
T_{\text{envelope\_check}}(a) \in O(1), \quad S_{\text{envelope\_check}}(a) \in O(1)
$$

  5. *Deterministic Symbol Sorting & Table Emission*:
     - Sorting $`N_A`$ attributes lexicographically by interned symbol identifier requires comparison sort in $`O(N_A \log N_A)`$ or radix sort on 32-bit `SymbolId` tokens in strictly linear $`O(N_A)`$ time.
     - Emitting GFM Markdown table rows requires streaming $`O(N_A)`$ formatted rows directly to the artifact sink:

$$
T_{\text{emission}}(N_A) \in O(N_A), \quad S_{\text{emission}}(N_A) \in O(N_A)
$$

  6. *Aggregate Compilation Unit Complexity*:
     - Summing across all features in $`\mathcal{F}_{\text{proj}}`$, the total sequential execution time is strictly linear:

$$
T_{\text{total}}(N_A) = \sum_{F \in \mathcal{F}_{\text{proj}}} \sum_{a \in \mathbf{A}_F} \left( T_{\text{traverse}}(a) + T_{\text{type\_check}}(a) + T_{\text{unit\_check}}(a) + T_{\text{envelope\_check}}(a) \right) \in O(N_A)
$$

     - Total space complexity is strictly $`O(N_A)`$ in contiguous bump arena storage, requiring zero heap allocations outside the preallocated arena.
  7. *Parallel Work-Stealing Scaling (Directive 2)*:
