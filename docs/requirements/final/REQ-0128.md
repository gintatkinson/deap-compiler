### REQ-0128: 7-Tier Bipartite Traceability DAG Architecture

- **Normative Statement**: The safety compiler, traceability graph engine, and formal verification framework of Subsystem 7 shall construct, validate, index, and query a deterministic 7-tier bipartite directed acyclic graph (DAG) $`G_{\text{trace}} = (V_{\text{trace}}, E_{\text{trace}})`$ linking mission requirements, system requirements, architectural elements, interfaces, safety invariants, realization artifacts, and verification witnesses across the entire system specification.

  Specifically, the traceability compiler, tier validator, and query engine shall strictly enforce the following structural, topological, algebraic, and operational invariants:
  1. **Disjoint 7-Tier Vertex Partitioning**:
     - The compiler shall partition the vertex universe $`V_{\text{trace}}`$ into exactly seven mutually disjoint, non-empty tiers:
       - Tier 1 ($`T_1`$`): Mission Requirements & Operational Concepts (`$`\mathcal{R}_{\text{mission}}`$).
       - Tier 2 ($`T_2`$`): System Requirements & Functional Specifications (`$`\mathcal{R}_{\text{system}}`$).
       - Tier 3 ($`T_3`$`): Architectural Classifiers & Component Definitions (`$`\mathcal{C}_{\text{arch}}`$).
       - Tier 4 ($`T_4`$`): Ports, Interfaces & Directed Flow Endpoints (`$`\mathcal{P}_{\text{port}}`$).
       - Tier 5 ($`T_5`$`): Safety Invariants, Hazard Mitigations & Control Constraints (`$`\mathcal{I}_{\text{safety}}`$).
       - Tier 6 ($`T_6`$`): Realization Implementations, LUMI IR Blocks & Code Units (`$`\mathcal{M}_{\text{code}}`$).
       - Tier 7 ($`T_7`$`): Verification Witnesses, Test Cases & Proof Obligations (`$`\mathcal{W}_{\text{verify}}`$).
     - Every vertex $`v \in V_{\text{trace}}`$` shall be mapped to exactly one tier index `$`\tau_V(v) \in \{1, 2, 3, 4, 5, 6, 7\}`$.
     - Any declared node that cannot be unambiguously resolved to a single tier, or that is assigned to multiple conflicting tiers, shall be deterministically rejected at compile time with diagnostic error code `E0400` (`UnpartitionedTraceabilityNode` or `ConflictingTierAssignment`).
  2. **Strict Adjacent-Tier Bipartite Edge Relation**:
     - Every directed edge $`e = (u, v) \in E_{\text{trace}}`$` shall strictly connect a source node `$`u`$` in tier `$`T_i`$` to a target node `$`v`$` in tier `$`T_{i+1}`$` for some `$`i \in \{1, 2, 3, 4, 5, 6\}`$.
     - Traceability edges must satisfy:

```math
E_{\text{trace}} \subseteq \bigcup_{i=1}^6 (T_i \times T_{i+1})
```

     - Skip-tier edges where $`\tau_V(v) \gt \tau_V(u) + 1`$ (e.g., direct edges bypassing ports from system requirements to safety invariants) shall be prohibited.
     - Backward or inverted edges where $`\tau_V(v) \le \tau_V(u)`$` (e.g., edges from realization code back to architectural classifiers) shall be prohibited in `$`E_{\text{trace}}`$.
     - Intra-tier edges where $`\tau_V(u) = \tau_V(v)`$` (e.g., peer-to-peer requirement relationships within `$`T_2`$`) shall be modeled in local containment ASTs but are strictly excluded from the inter-tier bipartite edge set `$`E_{\text{trace}}`$.
     - Any edge violating the adjacent-tier invariant ($`\tau_V(v) \ne \tau_V(u) + 1`$) shall be deterministically rejected at compile time with diagnostic error code `E0400` (`InvalidTraceabilityEdgeTier`).
  3. **Inherent Structural Acyclicity Invariant**:
     - Because every directed edge $`(u, v) \in E_{\text{trace}}`$` strictly advances the tier index (`$`\tau_V(v) = \tau_V(u) + 1`$`), the graph `$`G_{\text{trace}}`$ shall be strictly acyclic by construction.
     - No directed cycle $`\langle u_0, u_1, \dots, u_k, u_0 \rangle`$` can exist within `$`G_{\text{trace}}`$.
     - If an illegal cyclic or self-referential edge is presented during model ingestion or AST transformation, the compiler shall detect it during edge validation and reject compilation with diagnostic error code `E0400` (`TraceabilityCycleDetected`).
  4. **Typed Semantic Traceability Edge Relations**:
     - Every edge $`e = (u, v) \in E_{\text{trace}}`$` shall bind a semantic relationship type `$`\tau_E(u, v)`$ corresponding to the adjacent tier pair:
       - $`(T_1, T_2)`$: `Refines` (system requirement $`v \in T_2`$` refines mission requirement `$`u \in T_1`$).
       - $`(T_2, T_3)`$: `Allocates` (system requirement $`u \in T_2`$` allocates to architectural classifier `$`v \in T_3`$).
       - $`(T_3, T_4)`$: `Exposes` (architectural classifier $`u \in T_3`$` exposes port or interface `$`v \in T_4`$).
       - $`(T_4, T_5)`$: `Guards` (port or interface $`u \in T_4`$` is constrained by safety invariant `$`v \in T_5`$).
       - $`(T_5, T_6)`$: `Enforces` (safety invariant $`u \in T_5`$` is enforced by realization code unit `$`v \in T_6`$).
       - $`(T_6, T_7)`$: `Witnesses` (realization code unit $`u \in T_6`$` is verified by witness or proof `$`v \in T_7`$).
     - Duplicate identical edges shall be deduplicated idempotently. Declaring conflicting relation semantics on identical node pairs shall trigger diagnostic error code `E0400` (`ConflictingTraceabilityEdge`).
  5. **Deterministic Bidirectional Traversal & Reachability Indexing**:
     - The compiler shall construct forward adjacency lists $`\text{Adj}^+(u)`$` and backward adjacency lists `$`\text{Adj}^-(v)`$ in contiguous memory to support bidirectional traversal.
     - Downward Reachability: For any node $`u \in T_i`$`, the forward reachable set `$`\text{Reach}^+(u) \subseteq \bigcup_{j=i+1}^7 T_j`$` shall be computed via deterministic breadth-first search (BFS) or depth-first search (DFS) along `$`E_{\text{trace}}`$.
     - Upward Reachability: For any node $`v \in T_j`$`, the backward reachable set `$`\text{Reach}^-(v) \subseteq \bigcup_{i=1}^{j-1} T_i`$` shall be computed via search along the transposed edge set `$`E_{\text{trace}}^{\top}`$.
     - A sequence $`\rho = \langle v_1, v_2, v_3, v_4, v_5, v_6, v_7 \rangle`$` is defined as a complete 7-tier verification thread if and only if `$`v_i \in T_i`$` for all `$`i \in \{1, \dots, 7\}`$` and `$`(v_i, v_{i+1}) \in E_{\text{trace}}`$` for all `$`i \in \{1, \dots, 6\}`$.
  6. **The 5 Executive Architectural Directives Compliance**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every vertex $`v \in V_{\text{trace}}`$` and edge `$`e = (u, v) \in E_{\text{trace}}`$` shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical DEAP namespace OID and node fully qualified topological path (`$`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(v))`$` for vertices, and `$`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(u) \,\|\, \text{"::"} \,\|\, \text{FQN}(v))`$ for edges) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel construction of bipartite tier adjacency lists and parallel reachability queries across independent packages or models shall execute strictly on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Memory Allocation Exception)*: Node identifiers, requirement labels, qualified names, and relationship type tokens shall be interned into the deduplicated global symbol interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The traceability compiler shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When semantic violations occur (`E0400`), diagnostics shall accumulate in the error sink buffer $`\mathcal{D}_{\text{sink}}`$`, substitute typed error sentinels (`$`\bot_{\text{node}}`$`, `$`\bot_{\text{edge}}`$`), and continue validating subsequent declarations. If accumulated diagnostics reach capacity `$`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully in accordance with REQ-0013 and REQ-0016.
     - *Directive 5 (Panic-Free Release Isolation)*: The traceability graph engine shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Verification latency ($`\lt 25\text{ ms}`$` for `$`10^4`$` nodes and `$`5 \times 10^4`$` edges) and peak RSS memory (`$`\lt 100\text{ MB}`$) performance gates shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Req_Mission_0`, `Req_Mission_1`, `Req_System_0`, `Req_System_1`, `Classifier_Alpha`, `Classifier_Beta`, `Port_1`, `Port_2`, `Invariant_0`, `Invariant_1`, `Module_Realization_0`, `Module_Realization_1`, `Witness_0`, `Witness_1`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $`\mathcal{V}_{\text{AST}}`$ denote the universe of allocated AST nodes in contiguous bump arena storage.

  A 7-tier bipartite traceability DAG $`G_{\text{trace}}`$ is formalized as an 8-tuple:

```math
  G_{\text{trace}} = \langle V_{\text{trace}}, E_{\text{trace}}, \mathcal{T}_{\text{tiers}}, \tau_V, \tau_E, \Delta_V, \Delta_E, \mathcal{D}_{\text{sink}} \rangle
```

  where:

```math
  \begin{aligned}
  V_{\text{trace}} &\subset \mathcal{V}_{\text{AST}} \quad (\text{finite set of traceability vertices}) \\
  E_{\text{trace}} &\subset V_{\text{trace}} \times V_{\text{trace}} \quad (\text{finite set of directed traceability edges}) \\
  \mathcal{T}_{\text{tiers}} &= \langle T_1, T_2, T_3, T_4, T_5, T_6, T_7 \rangle \quad (\text{ordered sequence of 7 discrete tiers}) \\
  \tau_V &: V_{\text{trace}} \to \{1, 2, 3, 4, 5, 6, 7\} \quad (\text{surjective vertex tier assignment function}) \\
  \tau_E &: E_{\text{trace}} \to \{ \text{Refines}, \text{Allocates}, \text{Exposes}, \text{Guards}, \text{Enforces}, \text{Witnesses} \} \quad (\text{edge semantic type}) \\
  \Delta_V &: V_{\text{trace}} \to \mathbb{U}_{128} \quad (\text{deterministic RFC 4122 UUIDv5 vertex identifier}) \\
  \Delta_E &: E_{\text{trace}} \to \mathbb{U}_{128} \quad (\text{deterministic RFC 4122 UUIDv5 edge identifier}) \\
  \mathcal{D}_{\text{sink}} &\subseteq \mathcal{D}_{\text{catalog}} \quad (\text{diagnostic error accumulation sink})
  \end{aligned}
```

  1. Tier Partitioning Invariant:

```math
  \begin{aligned}
  V_{\text{trace}} &= \biguplus_{i=1}^7 T_i = T_1 \cup T_2 \cup T_3 \cup T_4 \cup T_5 \cup T_6 \cup T_7 \\
  \forall i, j \in \{1, \dots, 7\}, &\quad i \ne j \implies T_i \cap T_j = \emptyset
  \end{aligned}
```

  where the constituent tier sets are defined as:

```math
  \begin{aligned}
  T_1 &= \mathcal{R}_{\text{mission}} = \{ u \in V_{\text{trace}} \mid \tau_V(u) = 1 \} \quad (\text{Mission Requirements}) \\
  T_2 &= \mathcal{R}_{\text{system}} = \{ u \in V_{\text{trace}} \mid \tau_V(u) = 2 \} \quad (\text{System Requirements}) \\
  T_3 &= \mathcal{C}_{\text{arch}} = \{ u \in V_{\text{trace}} \mid \tau_V(u) = 3 \} \quad (\text{Architectural Classifiers}) \\
  T_4 &= \mathcal{P}_{\text{port}} = \{ u \in V_{\text{trace}} \mid \tau_V(u) = 4 \} \quad (\text{Ports and Interfaces}) \\
  T_5 &= \mathcal{I}_{\text{safety}} = \{ u \in V_{\text{trace}} \mid \tau_V(u) = 5 \} \quad (\text{Safety Invariants and Hazards}) \\
  T_6 &= \mathcal{M}_{\text{code}} = \{ u \in V_{\text{trace}} \mid \tau_V(u) = 6 \} \quad (\text{Realization Code and Blocks}) \\
  T_7 &= \mathcal{W}_{\text{verify}} = \{ u \in V_{\text{trace}} \mid \tau_V(u) = 7 \} \quad (\text{Verification Witnesses})
  \end{aligned}
```

  2. Strict Adjacent-Tier Bipartite Edge Invariant:

```math
  E_{\text{trace}} \subseteq \bigcup_{i=1}^6 (T_i \times T_{i+1})
```

  Equivalently, every directed edge connects strictly from tier $`i`$` to tier `$`i+1`$:

```math
  \forall e = (u, v) \in E_{\text{trace}}, \quad \tau_V(v) = \tau_V(u) + 1
```

  3. Edge Semantic Typing Invariant:

```math
  \forall (u, v) \in E_{\text{trace}}, \quad \tau_E(u, v) = \begin{cases}
  \text{Refines} & \text{if } \tau_V(u) = 1 \land \tau_V(v) = 2 \\
  \text{Allocates} & \text{if } \tau_V(u) = 2 \land \tau_V(v) = 3 \\
  \text{Exposes} & \text{if } \tau_V(u) = 3 \land \tau_V(v) = 4 \\
  \text{Guards} & \text{if } \tau_V(u) = 4 \land \tau_V(v) = 5 \\
  \text{Enforces} & \text{if } \tau_V(u) = 5 \land \tau_V(v) = 6 \\
  \text{Witnesses} & \text{if } \tau_V(u) = 6 \land \tau_V(v) = 7
  \end{cases}
```

  4. Inherent Structural Acyclicity Invariant:
  Let $`\text{Path}(u, v)`$` denote a non-empty directed walk `$`\langle u_0, u_1, \dots, u_k \rangle`$` such that `$`u_0 = u`$`, `$`u_k = v`$`, `$`k \ge 1`$`, and `$`(u_{j-1}, u_j) \in E_{\text{trace}}`$` for all `$`j \in \{1, \dots, k\}`$.
  Because $`(u, v) \in E_{\text{trace}} \implies \tau_V(v) = \tau_V(u) + 1`$`, along any directed walk of length `$`k \ge 1`$:

```math
  \tau_V(u_k) = \tau_V(u_0) + k \gt \tau_V(u_0)
```

  Therefore:

```math
  \forall u \in V_{\text{trace}}, \quad \neg \exists \text{Path}(u, u)
```

  5. Reachability and Complete 7-Tier Verification Thread:
  Let the forward reachable set from vertex $`u \in V_{\text{trace}}`$ be defined as:

```math
  \text{Reach}^+(u) = \{ v \in V_{\text{trace}} \mid \exists \text{Path}(u, v) \}
```

  and the backward reachable set to vertex $`v \in V_{\text{trace}}`$ as:

```math
  \text{Reach}^-(v) = \{ u \in V_{\text{trace}} \mid \exists \text{Path}(u, v) \}
```

  A complete 7-tier verification thread $`\rho`$` is an element of `$`\prod_{i=1}^7 T_i`$:

```math
  \rho = \langle v_1, v_2, v_3, v_4, v_5, v_6, v_7 \rangle \quad \text{such that} \quad \bigwedge_{i=1}^6 (v_i, v_{i+1}) \in E_{\text{trace}}
```

  6. Deterministic RFC 4122 UUIDv5 Anchor Invariant (Directive 1):

```math
  \begin{aligned}
  \forall v \in V_{\text{trace}}, &\quad \Delta_V(v) = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(v)) \\
  \forall e = (u, v) \in E_{\text{trace}}, &\quad \Delta_E(e) = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(u) \,\|\, \text{"::"} \,\|\, \text{FQN}(v))
  \end{aligned}
```

  7. Deterministic Diagnostic Trigger Rules (REQ-0191):

```math
  \begin{aligned}
  \exists u \in \mathcal{V}_{\text{AST}} : u \notin \bigcup_{i=1}^7 T_i \lor (\exists i \ne j : u \in T_i \land u \in T_j) &\implies \text{Diagnostic}(u, \text{DiagnosticCode::E0400}, \text{UnpartitionedTraceabilityNode}) \in \mathcal{D}_{\text{sink}} \\
  \exists (u, v) \in E_{\text{trace}} : \tau_V(v) \ne \tau_V(u) + 1 &\implies \text{Diagnostic}((u, v), \text{DiagnosticCode::E0400}, \text{InvalidTraceabilityEdgeTier}) \in \mathcal{D}_{\text{sink}} \\
  \exists e_1, e_2 \in E_{\text{trace}} : e_1 \ne e_2 \land \text{src}(e_1) = \text{src}(e_2) \land \text{tgt}(e_1) = \text{tgt}(e_2) \land \tau_E(e_1) \ne \tau_E(e_2) &\implies \text{Diagnostic}(e_1, \text{DiagnosticCode::E0400}, \text{ConflictingTraceabilityEdge}) \in \mathcal{D}_{\text{sink}} \\
  \exists u \in V_{\text{trace}} : \exists \text{Path}(u, u) &\implies \text{Diagnostic}(u, \text{DiagnosticCode::E0400}, \text{TraceabilityCycleDetected}) \in \mathcal{D}_{\text{sink}} \\
  |\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
  \end{aligned}
```

- **Computational Complexity & Algorithmic Bounds**: Construction, adjacency indexation, tier-adjacency validation, and reachability traversal of the 7-tier bipartite traceability DAG reside strictly in **Complexity Class P** (Deterministic Polynomial Time).

  **Mathematical Delineation from Algorithmic Bound NP-4**:
  In safety verification, computing minimal hazard cut-sets or selecting a minimum cardinality set of safety invariants covering all Unsafe Control Actions (UCAs) corresponds to the Minimal Hitting Set / Set Cover problem, which is NP-complete as cataloged under Algorithmic Bound NP-4 (REQ-0135). In contrast, REQ-0128 establishes the structural 7-tier bipartite DAG substrate upon which safety relations are indexed. Checking node tier memberships, validating adjacent-tier edge constraints ($`\tau_V(v) = \tau_V(u) + 1`$`), and traversing transitive reachability paths do not require combinatorial search, SAT unrolling, or exponential backtracking. All graph construction and validation algorithms operate in deterministic linear time proportional to graph size `$`|V| + |E|`$.

  **Asymptotic Complexity Analysis**:
  Let $`V = |V_{\text{trace}}|`$` denote the total number of traceability vertices across all 7 tiers (`$`V = \sum_{i=1}^7 |T_i|`$`), and let `$`E = |E_{\text{trace}}|`$` denote the total number of declared traceability edges (`$`E = \sum_{i=1}^6 |E_i|`$` where `$`E_i = E_{\text{trace}} \cap (T_i \times T_{i+1})`$).
  1. *Node Tier Partition Verification*:
     Assigning each node $`u \in V_{\text{trace}}`$` to its tier and verifying that it belongs to exactly one tier takes `$`O(1)`$ operations per vertex using contiguous arena node handles. For all vertices:

```math
     T_{\text{nodes}}(V) \in O(V)
```

  2. *Adjacent-Tier Edge Invariant Validation*:
     For every edge $`e = (u, v) \in E_{\text{trace}}`$`, the compiler retrieves `$`\tau_V(u)`$` and `$`\tau_V(v)`$` in `$`O(1)`$` time and validates `$`\tau_V(v) = \tau_V(u) + 1`$`. Checking all `$`E`$ edges requires:

```math
     T_{\text{edges}}(E) \in O(E)
```

  3. *Acyclicity Verification*:
     Because the tier index is strictly monotonically increasing along every valid edge ($`\tau_V(v) = \tau_V(u) + 1`$`), edge validation intrinsically guarantees that no directed cycles exist. Topological ordering is directly defined by tier index, requiring `$`O(1)`$ additional operations per edge:

```math
     T_{\text{acyclic}}(E) \in O(E)
```

  4. *Edge Deduplication & Semantic Typing*:
     Inserting edges into contiguous adjacent-tier buckets using a deterministic hash set or radix-sorted edge vector requires $`O(1)`$ amortized operations per edge, ensuring duplicate elimination and semantic conflict detection:

```math
     T_{\text{dedup}}(E) \in O(E)
```

  5. *Forward and Backward Reachability Traversal (BFS / DFS)*:
     Computing the downstream reachable set $`\text{Reach}^+(u)`$` or upstream reachable set `$`\text{Reach}^-(v)`$ visits each reachable vertex and edge at most once:

```math
     T_{\text{reach}}(V, E) \in O(V + E)
```

     using $`O(V)`$ auxiliary bitset memory.
  6. *Complete 7-Tier Verification Thread Enumeration (Dynamic Programming)*:
     Counting or extracting valid end-to-end paths $`\langle v_1, \dots, v_7 \rangle`$` is performed tier-by-tier in forward topological order. For each tier `$`i \in \{1, \dots, 6\}`$`, path counts propagate along bipartite edges `$`E_i`$` via dynamic programming in `$`O(|E_i|)`$ operations. Across all 6 bipartite layers:

```math
     T_{\text{thread}}(V, E) \in O(V + E)
```

  7. *Aggregate Worst-Case Execution Time*:
     Summing all verification and indexing passes:

```math
     T_{\text{total}}(V, E) \in O(V + E)
```

     The algorithm is strictly linear in the size of the traceability graph, operating deterministically without backtracking or recursion stack overflow.
  8. *Parallel Work-Stealing Scaling (Directive 2)*:
     When constructing and validating independent compilation units or decoupled packages across $`N_{\text{max\_workers}}`$ threads on a bounded work-stealing thread pool:

```math
     T_{\text{parallel}}(V, E, N_{\text{max\_workers}}) \in O\left( \frac{V + E}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

  9. *Space Complexity & Arena Memory Bounds*:
     Vertices and edge records are stored in contiguous bump arena allocations, requiring $`O(V + E)`$` bytes. Traversal bitsets and dynamic programming tables require `$`O(V)`$` bits. The diagnostic error sink buffer is strictly bounded by `$`O(C_{\text{max\_errors}}) = O(1)`$ capacity.

  1. **Canonical 7-Tier Verification Thread Construction Gate**: Ingest synthetic model `Package_0` declaring a complete end-to-end traceability chain: mission requirement `Req_Mission_0` ($`T_1`$), system requirement `Req_System_0` ($`T_2`$), architectural classifier `Classifier_Alpha` ($`T_3`$), directed port `Port_1` ($`T_4`$), safety invariant `Invariant_0` ($`T_5`$), realization module `Module_Realization_0` ($`T_6`$), and verification witness `Witness_0` ($`T_7`$).   2. **Skip-Tier Forward Edge Rejection Gate (`E0400`)**: Declare a directed edge linking mission requirement `Req_Mission_0` ($`T_1`$) directly to architectural classifier `Classifier_Alpha` ($`T_3`$), skipping Tier 2.   3. **Multi-Skip Tier Edge Rejection Gate (`E0400`)**: Declare a directed edge linking system requirement `Req_System_0` ($`T_2`$) directly to verification witness `Witness_0` ($`T_7`$), skipping tiers 3 through 6.   4. **Backward Inverted Edge Rejection Gate (`E0400`)**: Declare a directed edge from architectural classifier `Classifier_Alpha` ($`T_3`$) to system requirement `Req_System_0` ($`T_2`$`) within `$`E_{\text{trace}}`$.   5. **Intra-Tier Edge Rejection Gate (`E0400`)**: Declare a directed edge within $`E_{\text{trace}}`$ between two system requirements `Req_System_0` ($`T_2`$) and `Req_System_1` ($`T_2`$). Verify deterministic compile-time rejection with diagnostic error code `E0400` (`InvalidTraceabilityEdgeTier`), enforcing that $`E_{\text{trace}}`$` exclusively admits inter-tier edges where `$`\tau_V(v) = \tau_V(u) + 1`$.
  6. **Self-Referential Edge Rejection Gate (`E0400`)**: Declare a reflexive edge $`(u, u)`$ on safety invariant `Invariant_0` ($`T_5`$). Verify deterministic compile-time rejection with diagnostic error code `E0400` (`InvalidTraceabilityEdgeTier` and `TraceabilityCycleDetected`).

Verify deterministic compile-time rejection with diagnostic error code `E0400` (`UnpartitionedTraceabilityNode`), identifying the node handle and source span.
