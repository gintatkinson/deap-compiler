### REQ-0022: Tabular Schema Ingestion for Directed Ports & Structural Interfaces

- **Normative Statement**: The Universal Schema Ingestion Engine shall parse CommonMark tabular schemas specifying directed ports and structural interfaces into intermediate `IngestedPort` Abstract Syntax Tree (AST) entities. The ingestion engine must extract port identifiers, owning parent component definitions, declared port directions (`in`, `out`, `inout`), interface payload data type handles, and conjugated interface markers (`~`). Header columns must be normalized dynamically into canonical port metamodel attributes in an order-independent manner. The parser shall validate that all port identifiers conform to sanitized alphanumeric symbol names and are unique within the scope of their parent component. The ingestion engine shall compute the effective port direction by evaluating an algebraic involution operator $\tau_{\text{conj}}$ over the declared direction when a conjugated interface marker is present. Conjugation must invert directional flow polarity (`in` maps to `out`, `out` maps to `in`, and `inout` maps to `inout`) while strictly preserving the underlying payload data type schema, multiplicity bounds, and contractual invariant constraints. In accordance with Architectural Directive 4 (Synchronization Token Error Recovery), if the parser encounters a malformed port row--such as an unrecognized direction literal, a missing mandatory attribute, a duplicate port identifier within the same parent owner, or an unescaped delimiter--the parser must construct a structured diagnostic record binding diagnostic error code `E0102` (table row delimiter or entity mapping failure) per REQ-0191, substitute a typed error sentinel $\bot_{\text{port}}$, and resynchronize at the next row line break delimiter ($\text{SYM}_{\text{LF}}$) or table boundary without aborting the compilation unit. If accumulated diagnostics reach the bounded sink capacity limit $C_{\text{max\_errors}}$, the parser must emit diagnostic error code `E0199` and terminate table processing gracefully. In accordance with Architectural Directive 5 (Deterministic Non-Panicking Execution Contract), the ingestion pipeline must execute as a total function with zero unhandled panics or unwinding exceptions across all malformed inputs. The engine shall operate strictly on abstract MBSE formalisms using synthetic placeholders (e.g., `Package_0`, `Part_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`) with zero domain-specific contamination.

- **Formal Invariant**: Let $T = \langle R_1, R_2, \dots, R_M \rangle$ denote a tabular port schema comprising $M$ rows, and let $\vec{\beta}$ denote the column-to-attribute binding vector mapping table column indices $j \in \{0, \dots, C-1\}$ to canonical port attributes $\mathcal{K}_{\text{port}} = \{ \text{id}, \text{owner}, \text{dir}, \text{payload}, \text{conj}, \text{mult} \}$.

The discrete port direction domain $\mathcal{D}$ is defined as:

$$
\mathcal{D} = \{ \text{In}, \text{Out}, \text{InOut} \}
$$

The direction parsing operator $\text{ParseDir} : \Sigma^* \to \mathcal{D} \cup \{ \bot \}$ maps normalized direction cell strings to the direction domain:

$$
\text{ParseDir}(s) = 
\begin{cases}
\text{In}, & \text{if } \eta(s) \in \{ \text{"in"}, \text{"input"}, \text{"in\_port"}, \text{"recv"} \} \\
\text{Out}, & \text{if } \eta(s) \in \{ \text{"out"}, \text{"output"}, \text{"out\_port"}, \text{"send"} \} \\
\text{InOut}, & \text{if } \eta(s) \in \{ \text{"inout"}, \text{"bidirectional"}, \text{"in\_out"}, \text{"duplex"} \} \\
\bot, & \text{otherwise}
\end{cases}
$$

The conjugation extraction operator $\chi : \Sigma^* \to \mathbb{B} \times \Sigma^*$ inspects a port symbol or explicit conjugation token for the tilde marker (`~`):

$$
\chi(s) = 
\begin{cases}
(\text{true}, s'), & \text{if } s = \text{"}\mathord{\sim}\text{"} \mathbin{\Vert} s' \;\vee\; s = s' \mathbin{\Vert} \text{"}\mathord{\sim}\text{"} \\
(\text{true}, s), & \text{if } \eta(s) \in \{ \text{"true"}, \text{"yes"}, \text{"1"}, \text{"conj"}, \text{"conjugated"} \} \\
(\text{false}, s), & \text{otherwise}
\end{cases}
$$

where $\mathbin{\Vert}$ denotes string concatenation.

The port conjugation involution operator $\tau_{\text{conj}} : \mathcal{D} \to \mathcal{D}$ is defined as:

$$
\tau_{\text{conj}}(d) = 
\begin{cases}
\text{Out}, & \text{if } d = \text{In} \\
\text{In}, & \text{if } d = \text{Out} \\
\text{InOut}, & \text{if } d = \text{InOut}
\end{cases}
$$

Involution Identity Invariant: For every direction $d \in \mathcal{D}$, applying conjugation twice yields the original direction:

$$
\forall d \in \mathcal{D}, \quad \tau_{\text{conj}}(\tau_{\text{conj}}(d)) \equiv d
$$

The effective direction resolution function $d_{\text{eff}} : \mathcal{D} \times \mathbb{B} \to \mathcal{D}$ computes the runtime flow orientation:

$$
d_{\text{eff}}(d_{\text{decl}}, c) = 
\begin{cases}
\tau_{\text{conj}}(d_{\text{decl}}), & \text{if } c = \text{true} \\
d_{\text{decl}}, & \text{if } c = \text{false}
\end{cases}
$$

Double Conjugation Invariant: For all declared directions $d_{\text{decl}} \in \mathcal{D}$ and conjugation flags $c \in \mathbb{B}$:

$$
d_{\text{eff}}(d_{\text{eff}}(d_{\text{decl}}, c), c) \equiv d_{\text{decl}}
$$

Each successfully lowered port entity is represented as a 7-tuple:

$$
\text{PortDef} = \langle \text{id}, \text{owner}, d_{\text{decl}}, d_{\text{eff}}, \tau_{\text{payload}}, c, \mu \rangle
$$

where $\text{id} \in \mathcal{S}_{\text{id}}$ is the sanitized port identifier, $\text{owner} \in \mathcal{H}_{\text{owner}}$ is the parent component handle, $d_{\text{decl}} \in \mathcal{D}$ is the declared direction, $d_{\text{eff}} \in \mathcal{D}$ is the resolved effective direction, $\tau_{\text{payload}} \in \mathcal{H}_{\text{type}}$ is the interface payload type handle, $c = \text{is\_conjugated} \in \mathbb{B}$ is the conjugation flag, and $\mu = \langle l, u \rangle \in \mathbb{N} \times (\mathbb{N} \cup \{ \infty \})$ denotes the multiplicity bounds ($0 \le l \le u$, $u \ge 1$).

Payload Typing and Contract Preservation Invariant: Conjugation shall not mutate the payload type handle, multiplicity bounds, or behavioral invariants of the port:

$$
\begin{aligned}
\text{PayloadHandle}(\tau_{\text{conj}}(P)) &\equiv \text{PayloadHandle}(P) \\
\text{MultiplicityBounds}(\tau_{\text{conj}}(P)) &\equiv \text{MultiplicityBounds}(P) \\
\text{InvariantConstraints}(\tau_{\text{conj}}(P)) &\equiv \text{InvariantConstraints}(P)
\end{aligned}
$$

Scoped Identifier Uniqueness Invariant: Within the scope of any owning parent component classifier $H \in \mathcal{H}_{\text{owner}}$, all port identifiers must be pairwise distinct:

$$
\forall P_a, P_b \in \mathcal{P}, \quad (P_a.\text{owner} = P_b.\text{owner} \;\wedge\; P_a.\text{id} = P_b.\text{id}) \implies P_a = P_b
$$

Row-to-Entity Ingestion Mapping: The row ingestion operator $\Phi_{\text{port}} : \text{Row} \to \text{PortDef} \cup \{ \bot_{\text{port}} \}$ maps table row $R_i$ into the AST model:

$$
\Phi_{\text{port}}(R_i) = 
\begin{cases}
\text{PortDef}_i, & \text{if } \text{ValidRow}(R_i) \\
\bot_{\text{port}}, & \text{if } \neg\text{ValidRow}(R_i)
\end{cases}
$$

Diagnostic Code Binding Invariant: Structural and lexical faults encountered during port row evaluation generate structured diagnostics bound to diagnostic error code `E0102` (or `E0199` upon sink saturation) in accordance with REQ-0191:

$$
\begin{aligned}
\text{ParseDir}(\text{Cell}(R_i, C_{\text{dir}})) = \bot &\implies \text{Diagnostic}(R_i, C_{\text{dir}}, \text{DiagnosticCode::E0102}, \text{InvalidDirection}) \in \mathcal{D} \\
\exists k \ne i \text{ s.t. } P_k.\text{owner} = P_i.\text{owner} \wedge P_k.\text{id} = P_i.\text{id} &\implies \text{Diagnostic}(R_i, C_{\text{id}}, \text{DiagnosticCode::E0102}, \text{DuplicatePortId}) \in \mathcal{D} \\
\text{UnresolvedClassifier}(\text{Cell}(R_i, C_{\text{owner}})) &\implies \text{Diagnostic}(R_i, C_{\text{owner}}, \text{DiagnosticCode::E0102}, \text{UnresolvedOwner}) \in \mathcal{D} \\
\text{Cell}(R_i, C_{\text{id}}) = \varepsilon &\implies \text{Diagnostic}(R_i, C_{\text{id}}, \text{DiagnosticCode::E0102}, \text{MissingPortId}) \in \mathcal{D} \\
|\mathcal{D}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

- **Computational Complexity & Algorithmic Bounds**: Tabular schema ingestion for directed ports and structural interfaces executes strictly within Complexity Class $\mathbf{P}$. For an input document of total byte size $N$ containing $R$ port table rows and $C$ columns ($1 \le C \le C_{\text{max\_cols}} = 32$), the table lexer and delimiter scanner advance monotonically forward through the input byte sequence without backtracking, requiring $O(N)$ operations. Header normalization and column binding vector computation $\vec{\beta}$ execute once per table in $O(C) = O(1)$ constant time. For each row $R_i$, cell string normalization and identifier sanitization operate in $O(|s|)$ time bounded by maximum cell length $L_{\text{max}} \le 256$, establishing an $O(1)$ bound per cell. Direction parsing $\text{ParseDir}(s)$ evaluates a static enum match in $O(1)$ constant time. Conjugation involution $\tau_{\text{conj}}$ evaluates a discrete lookup over three enum variants in deterministic $O(1)$ time with zero dynamic memory allocation. Scoped port uniqueness verification performs a hash lookup against an interned 64-bit SymbolId set, executing in $O(1)$ expected amortized time per row. Constructing and appending the `IngestedPort` entity to contiguous arena storage requires $O(1)$ constant time. Thus, total port table ingestion executes in deterministic linear time:

$$
T(R, N) \in O(N) = O(R \cdot C) = O(R)
$$

Auxiliary space complexity is strictly bounded by $O(C + C_{\text{max\_errors}})$, where $C \le 32$ accounts for the active column binding buffer and $C_{\text{max\_errors}}$ accounts for the preallocated diagnostic sink, ensuring $O(1)$ auxiliary heap memory overhead relative to input stream length $N$.

- **Verification & Conformance Criteria**: Automated test suites shall deterministically verify compliance against synthetic CommonMark schema tables containing generic MBSE placeholders (e.g., `Package_0`, `Part_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`). Verification shall be enforced through the following test gates: (1) Involution Axiom Gate: Assert that $\tau_{\text{conj}}(\text{In}) = \text{Out}$, $\tau_{\text{conj}}(\text{Out}) = \text{In}$, $\tau_{\text{conj}}(\text{InOut}) = \text{InOut}$, and that the double involution identity $\tau_{\text{conj}}(\tau_{\text{conj}}(d)) \equiv d$ holds for all $d \in \mathcal{D}$. (2) Tabular Port Ingestion Gate: Ingest a synthetic CommonMark table specifying multiple ports (`Port_0`, `Port_1`, `Port_2`, `Port_3`) across parent component definitions (`Part_Alpha`, `Part_Beta`) with varied direction tokens (`in`, `out`, `inout`), payload type references (`Payload_Type_A`, `Signal_Type_B`), and conjugation markers (`~Port_1`, explicit `true` column); assert that 100% of valid rows lower into synthesized `IngestedPort` AST entities with correct declared and effective directions. (3) Payload Typing & Contract Preservation Gate: Verify that conjugated ports invert flow orientation while preserving bitwise identical payload data type handles, multiplicity intervals $[l, u]$, and contractual invariant expressions. (4) Diagnostic Error Code Binding Gate: (a) Ingest a table row with an invalid direction literal (e.g., `"forward"` or `"invalid_dir"`); assert emission of diagnostic error code `E0102`, substitution of $\bot_{\text{port}}$, and successful continuation to subsequent rows. (b) Ingest two rows declaring identical port identifiers within the same parent owner component; assert emission of diagnostic error code `E0102` reporting the identifier collision. (c) Ingest a table omitting mandatory columns (`id` or `direction`); assert emission of diagnostic error code `E0102`. (d) Inject corrupted rows exceeding $C_{\text{max\_errors}}$; assert parsing terminates gracefully with diagnostic error code `E0199`. (5) Total Function & Panic-Free Execution Gate: Fuzz testing with $10^4$ pathological tabular inputs (including unclosed pipes, null bytes, truncated rows, and high-entropy unicode text) shall verify total-function termination with zero panics or unwinding exceptions. (6) Bitwise Determinism Gate: Assert that compiling identical port schema tables across independent compilation passes yields 100% bitwise identical AST entities with zero diff churn.
