### REQ-0046: Mutable AST Transformation & In-Place Rewrite Engine

- **Normative Statement**: The abstract syntax tree (AST) graph engine shall provide a deterministic, mutable transformation pass engine for AST lowering, syntactic desugaring, optimization rewrites, constant propagation, and semantic enrichments while strictly preserving graph topological integrity and typed reference safety. All AST rewrite passes shall perform node attribute modifications in-place within the contiguous node arena storage rather than allocating disjoint node copies, preserving immutable slot indices ($`\text{Index}(n, \mathcal{A}_{t+1}) = \text{Index}(n, \mathcal{A}_t)`$) and fixed virtual memory base offsets for unmodified and modified node slots. The mutation engine must update each arena slot's monotonic incarnation generation counter upon in-place modification or structural replacement, ensuring that any external node handle (`NodeHandle<T>`) referencing an obsolete generation evaluates deterministically to an invalid stale reference ($`\bot`$) and preventing ABA reference hazards across compiler passes.

  The mutable transformation and rewrite engine shall enforce the following normative guarantees:
  1. In-Place Slot Invariance: When an AST node is mutated during lowering, desugaring, or semantic attribution passes, its assigned arena slot index, node handle index component, and contiguous buffer address shall remain invariant. The rewrite engine shall forbid reallocating or moving existing active node slots within the arena, ensuring that intra-pass index bindings remain stable.
  2. Generational Monotonicity and ABA Prevention: Every arena slot shall maintain an unsigned 16-bit incarnation generation counter ($`g \in \mathbb{U}_{16}`$`). Whenever an AST node is modified in-place or replaced by a desugared equivalent, the mutation engine shall increment the slot generation counter modulo `$`2^{16}`$`. Any external handle `$`H = \langle i, g_{\text{old}}, \tau \rangle`$` possessing generation `$`g_{\text{old}} \ne g_{\text{new}}`$ shall immediately fail dereference validation, preventing stale handles from silently observing altered semantics.
  3. Topological Reference Integrity: Rewrite passes shall preserve topological graph closure. For every directed relationship or interconnect edge $`e = (u, v)`$` in the transformed AST graph `$`\mathcal{G}_{t+1}`$`, both source handle `$`u`$` and target handle `$`v`$` must reference valid, active node slots in the arena. If a rewrite replaces or elides a node, all incident edges must be topologically rewired or pruned within the same transformation pass, guaranteeing zero dangling edges (`$`\text{DanglingEdges}(\mathcal{G}_{t+1}) = \emptyset`$).
  4. Deterministic Topological UUIDv5 Preservation: In accordance with Architectural Directive 1 and REQ-0010, every AST node transformed in-place shall preserve its deterministic RFC 4122 UUIDv5 identifier, computed via namespace hashing from the compiler namespace UUID and canonical fully qualified path (e.g., `Package_0::Part_1`). If a rewrite transforms an anonymous child into a named element, the new UUIDv5 must be deterministically synthesized from its hierarchical path.
  5. Bounded Work-Stealing Parallelism: In accordance with Architectural Directive 2 and REQ-0012, parallel AST rewrite passes operating over disjoint compilation units or independent package subtrees shall be scheduled onto the bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$. Each worker thread shall operate on thread-isolated arena segments or thread-local rewrite buffers, ensuring zero data races and deterministic merge semantics without global locking contention.
  6. Scalar Symbol Interning Invariant: In accordance with Architectural Directive 3 and REQ-0036, all newly synthesized identifier names, desugared operator symbols, and attribute literals generated during rewrite passes shall be interned into the global deduplicated symbol interner pool as compact 32-bit scalar `SymbolId` tokens, preserving the zero-copy invariant.
  7. Synchronization Token Error Recovery: In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, if an AST rewrite pass encounters a semantic contradiction, ill-typed operand, or invalid edge target during transformation, the engine shall record structured diagnostics with source spans, synchronize on the nearest enclosing scope boundary or declaration delimiter, and proceed with subsequent independent node rewrites to accumulate comprehensive compiler diagnostics.
  8. Total-Function Non-Panicking Contract: In accordance with Architectural Directive 5, REQ-0011, and REQ-0196, the AST transformation engine shall operate strictly as a total function. Injected faults, stale handle dereferences, topological cycles, or arena capacity boundary violations shall never trigger unhandled panics or segmentation faults; the engine shall emit structured diagnostic error code `E0200` per REQ-0191 and safely propagate structured error results. Performance latency (< 25 ms for standard models) and peak memory RSS (< 100 MB for $`10^6`$ AST nodes) gates shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests.
  9. Clean-Room MBSE Placeholder Purity: All diagnostic messages, test models, and transformation rules shall strictly operate on abstract MBSE formalisms using synthetic placeholders (e.g., `Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `Action_X`, `param_x : Real`), strictly prohibiting hardcoded domain concepts and mock data.

- **Formal Invariant**: Let $`\mathcal{A}_t`$` denote the state of the contiguous node arena at discrete compiler pass step `$`t \in \mathbb{N}_0`$`, configured with uniform slot capacity `$`C \in \mathbb{N}`$` and slot byte size `$`S_{\text{slot}} = \text{sizeof}(\text{NodeSlot})`$`. Each arena slot `$`i \in \{0, 1, \dots, C - 1\}`$ is formalized as a 4-tuple:

```math
\mathcal{S}_t[i] = \langle \text{node}: \mathcal{N}_t(i), \, \text{gen}: g_t(i), \, \text{tag}: \tau_t(i), \, \text{allocated}: b_t(i) \rangle
```

where $`\mathcal{N}_t(i)`$` represents the stored AST node payload, `$`g_t(i) \in \mathbb{U}_{16}`$` is the slot incarnation generation counter, `$`\tau_t(i) \in \mathbb{U}_{16}`$` is the node type discriminator tag, and `$`b_t(i) \in \{0, 1\}`$ is the allocation status flag.

An AST rewrite pass is formalized as a deterministic state transition function:

```math
\mathcal{T}_{\text{rewrite}} : \mathcal{A}_t \times \mathcal{P}_{\text{rules}} \longrightarrow \mathcal{A}_{t+1} \times \mathcal{D}
```

where $`\mathcal{P}_{\text{rules}}`$` is the set of declarative transformation rules and `$`\mathcal{D}`$ is the set of accumulated compiler diagnostic records.

In-Place Slot Index and Physical Address Invariance:
For every node $`n`$` modified in-place by the rewrite transformation `$`\mathcal{T}_{\text{rewrite}}`$:

```math
\forall n \in \text{ModifiedNodes}(\mathcal{T}_{\text{rewrite}}), \quad \text{Index}(n, \mathcal{A}_{t+1}) = \text{Index}(n, \mathcal{A}_t)
```

The physical base virtual memory address of the modified node remains identical:

```math
\forall n \in \text{ModifiedNodes}(\mathcal{T}_{\text{rewrite}}), \quad \text{Address}(n, \mathcal{A}_{t+1}) = \text{Address}(n, \mathcal{A}_t) = \text{Base}(\mathcal{A}) + \text{Index}(n, \mathcal{A}_t) \cdot S_{\text{slot}}
```

Generational Mutation and Stale Reference Invalidation Invariant:
When node slot $`i`$` undergoes in-place mutation or structural replacement at transition `$`t \to t + 1`$:

```math
g_{t+1}(i) = (g_t(i) + 1) \pmod{2^{16}}
```

For any external typed handle $`H = \langle i, g_H, \tau \rangle \in \mathbb{U}_{32} \times \mathbb{U}_{16} \times \mathbb{U}_{16}`$` created prior to step `$`t+1`$` with generation `$`g_H = g_t(i)`$:

```math
g_H \ne g_{t+1}(i) \implies \text{Valid}(H, \mathcal{A}_{t+1}) = \text{false} \;\wedge\; \text{Deref}(H, \mathcal{A}_{t+1}) = \bot
```

Topological Graph Closure and Dangling Edge Elimination Invariant:
Let $`\mathcal{G}_{t+1} = (\mathcal{V}_{t+1}, \mathcal{E}_{t+1})`$` be the directed graph induced by arena `$`\mathcal{A}_{t+1}`$`, where `$`\mathcal{V}_{t+1} = \{ i \in \{0, \dots, C - 1\} \mid b_{t+1}(i) = 1 \}`$` and `$`\mathcal{E}_{t+1} \subseteq \mathcal{V}_{t+1} \times \mathcal{V}_{t+1}`$`. Every directed edge `$`e = (u, v)`$` in `$`\mathcal{E}_{t+1}`$ satisfies:

```math
\forall e = (u, v) \in \text{Edges}(\mathcal{A}_{t+1}), \quad u \in \text{Nodes}(\mathcal{A}_{t+1}) \;\wedge\; v \in \text{Nodes}(\mathcal{A}_{t+1})
```

guaranteeing zero dangling edges:

```math
\text{DanglingEdges}(\mathcal{G}_{t+1}) = \{ (u, v) \in \mathcal{E}_{t+1} \mid u \notin \mathcal{V}_{t+1} \;\vee\; v \notin \mathcal{V}_{t+1} \} = \emptyset
```

Semantic Equivalence Preservation under Desugaring:
Let $`\llbracket \mathcal{A} \rrbracket_{\text{sem}}`$ represent the denotational MBSE semantics of the AST model. For all semantics-preserving transformation passes:

```math
\llbracket \mathcal{A}_{t+1} \rrbracket_{\text{sem}} \equiv \llbracket \mathcal{A}_t \rrbracket_{\text{sem}}
```

Deterministic UUIDv5 Invariance (Directive 1):
For any node $`n`$` whose canonical fully qualified path `$`\mathcal{P}_{\text{topological}}(n)`$` is preserved across transformation `$`\mathcal{T}_{\text{rewrite}}`$:

```math
\mathcal{P}_{\text{topological}}(n, \mathcal{A}_{t+1}) = \mathcal{P}_{\text{topological}}(n, \mathcal{A}_t) \implies \text{UUIDv5}(n, \mathcal{A}_{t+1}) = \text{UUIDv5}(n, \mathcal{A}_t)
```

Diagnostic Code Binding and Taxonomy Containment Invariant:
Stale handle dereferences, dangling edge attempts, and capacity limit boundaries trigger structured diagnostics bound to diagnostic code `E0200` within error family $`\mathcal{E}_{\text{type}}`$ per REQ-0191:

```math
\begin{aligned}
\neg\text{Valid}(H, \mathcal{A}_{t+1}) &\implies \text{Diagnostic}(\text{span}(H), \text{DiagnosticCode::E0200}, \text{StaleHandleAccess}) \in \mathcal{D} \\
(u, v) \in \mathcal{E}_{\text{target}} \;\wedge\; v \notin \mathcal{V}_{t+1} &\implies \text{Diagnostic}(\text{span}(u), \text{DiagnosticCode::E0200}, \text{DanglingEdgeReference}) \in \mathcal{D} \\
\text{Offset}(\mathcal{A}) + S_{\text{slot}} \gt C \cdot S_{\text{slot}} &\implies \text{Diagnostic}(\text{span}(0), \text{DiagnosticCode::E0200}, \text{ArenaCapacityExceeded}) \in \mathcal{D}
\end{aligned}
```

```math
\forall d \in \mathcal{D}_{\text{rewrite}}, \quad \text{code}(d) = \text{DiagnosticCode::E0200} \in \mathcal{E}_{\text{type}}
```

Algorithmic Bounds Invariant:
Let $`V = |\mathcal{V}_t|`$` and `$`E = |\mathcal{E}_t|`$`. In-place node mutation latency `$`T_{\text{mutate}}(n)`$`, handle validation latency `$`T_{\text{deref}}(H)`$`, and full rewrite pass execution time `$`T_{\text{pass}}(V, E)`$ satisfy:

```math
\begin{aligned}
T_{\text{mutate}}(n) &\le c_{\text{mut}} \cdot 1 \\
T_{\text{deref}}(H) &\le c_{\text{deref}} \cdot 1 \\
T_{\text{pass}}(V, E) &\le c_1 \cdot V + c_2 \cdot E + c_0
\end{aligned}
```

where $`c_{\text{mut}}, c_{\text{deref}}, c_0, c_1, c_2 \in \mathbb{R}^+`$` are platform-specific execution constants independent of `$`V`$` and `$`E`$.

- **Computational Complexity & Algorithmic Bounds**: The mutable AST transformation and in-place rewrite engine executes strictly within Complexity Class $`\mathbf{P}`$. The operational complexity bounds are formalized as follows:
  - In-Place Single Node Mutation: Strict $`O(1)`$` worst-case constant time. Modifying slot fields in-place requires direct array base-plus-offset indexing (`$`\text{Base} + i \cdot S_{\text{slot}}`$`), bitwise field updates, and a single modular integer increment of the generation counter (`$`g \leftarrow (g + 1) \pmod{2^{16}}`$).
  - Generational Handle Validation: Strict $`O(1)`$` worst-case constant time. Validating handle `$`H`$` requires a single array index bounds check (`$`i \lt C`$`), a boolean allocation check, an integer equality check on generation counters (`$`g_t(i) == g_H`$`), and a type tag match (`$`\tau_t(i) == \tau_H`$).
  - Full AST Rewrite Pass: Strict $`O(V)`$` deterministic linear time for attribute-level passes, and `$`O(V + E)`$` linear time for structural rewrites, desugaring passes, and edge rewirings, where `$`V = |\text{Nodes}(\mathcal{A})|`$` and `$`E = |\text{Edges}(\mathcal{A})|`$. Each node and incident edge is visited a constant number of times during top-down or bottom-up AST traversals without unbounded backtracking.
  - Bounded Work-Stealing Parallelism (Directive 2): When $`K`$` independent subtrees or compilation units are processed concurrently across `$`N_{\text{max\_workers}}`$` worker threads in the bounded work-stealing pool, total parallel execution latency scales as `$`O(\lceil K / N_{\text{max\_workers}} \rceil \cdot (V_{\text{unit}} + E_{\text{unit}}))`$, with thread-isolated arena segments eliminating lock contention.
  - Auxiliary Space Complexity: $`O(1)`$` auxiliary memory for in-place attribute mutation, and `$`O(D_{\text{max}})`$` auxiliary stack/queue space for recursive or explicit worklist traversal over syntactic trees, where maximum AST hierarchy depth satisfies `$`D_{\text{max}} \le 64`$`. Full pass memory overhead is strictly linear in model size (`$`O(V)`$), requiring zero per-node dynamic heap allocator headers.

- **Verification & Conformance Criteria**: Conformance shall be verified deterministically through automated test suites operating on synthetic models using abstract MBSE placeholders (`Package_0`, `Classifier_Alpha`, `Classifier_Beta`, `Port_1`, `Port_2`, `Flow_A`, `Action_X`, `param_x : Real`). Conformance validation shall enforce the following test gates:
  1. In-Place Slot Index and Address Invariance Gate: Allocate node `Classifier_Alpha` in arena slot index $`k`$`. Execute an in-place semantic enrichment rewrite pass updating its attribute fields. Assert that `$`\text{Index}(\text{Classifier\_Alpha}, \mathcal{A}_{t+1}) == k`$ and that the physical virtual memory starting address of the slot remains identical with zero byte offset shift.
  2. Generational Monotonicity & Stale Dereference Gate: Before mutating slot $`k`$ containing `Classifier_Alpha`, capture handle $`H_1 = \langle k, g, \text{Tag}_{\text{Classifier}} \rangle`$`. Execute an in-place mutation or desugaring rewrite on slot `$`k`$`. Assert that the slot generation counter increments to `$`g + 1`$`. Assert that calling `$`\text{Deref}(H_1, \mathcal{A}_{t+1})`$` deterministically returns sentinel `$`\bot`$ and produces structured diagnostic error code `E0200` without system panic per Directive 5. Assert that dereferencing new handle $`H_2 = \langle k, g + 1, \text{Tag}_{\text{Classifier}} \rangle`$` succeeds in `$`O(1)`$ time.
  3. Desugaring Structural Integrity & Zero Dangling Edges Gate: Execute a desugaring pass that expands a composite interconnect declaration between `Port_1` and `Port_2` into primitive directed flow bindings. Assert that 100% of newly generated edges connect valid, active node slots in the arena, asserting $`\text{DanglingEdges}(\mathcal{G}_{t+1}) == 0`$. Inject an artificial out-of-bounds target handle into an edge update; assert that the engine detects the invalid handle, logs diagnostic error code `E0200`, and rejects the edge without crashing.
  4. Deterministic RFC 4122 UUIDv5 Anchor Gate (Directive 1): Verify that nodes modified in-place retain identical RFC 4122 UUIDv5 identifiers derived from the fixed compiler namespace OID and canonical qualified paths (e.g., `Package_0::Classifier_Alpha`) per REQ-0010.
  5. Scalar Symbol Interning Compliance Gate (Directive 3): Verify that all identifiers, synthetic names, and desugared operator symbols generated during rewrite passes are interned into the deduplicated symbol interner pool as compact 32-bit `SymbolId` scalar tokens per REQ-0036, asserting zero dynamic heap string allocations during the rewrite pass.
  6. Synchronization Token Error Recovery Gate (Directive 4): Inject a semantic error into a nested action node within `Classifier_Alpha`. Execute the rewrite pass; assert that the engine logs diagnostic error code `E0200`, resynchronizes on the next sibling element delimiter boundary, and successfully completes rewriting of sibling node `Classifier_Beta`.
  7. Bounded Work-Stealing Parallelism Gate (Directive 2): Execute concurrent rewrite passes across $`K`$` independent package hierarchies using `$`N_{\text{max\_workers}}`$ threads scheduled on the bounded work-stealing pool. Assert zero data races, thread-isolated arena execution, and 100% bitwise identical output graphs across repeated runs.
  8. Total-Function Non-Panicking Execution Gate (Directive 5): Subject the rewrite engine to pathological AST graphs containing cyclic references, malformed handles, and arena boundary limits. Assert that the engine operates as a total function, terminating deterministically, emitting structured diagnostic error code `E0200`, and causing zero system panics.
  9. Release Mode Performance & Memory Gate (Directive 5, REQ-0011, REQ-0196): In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests, execute a complete rewrite and desugaring pass across an AST graph with $`10^6`$ nodes. Assert that execution latency is strictly below 25 ms and peak resident set size (RSS) memory consumption is strictly below 100 MB.
  10. Bitwise Determinism & Zero Diff Churn Gate (REQ-0003): Assert 0-byte diff churn across repeated executions of the rewrite and desugaring engine on identical inputs.
