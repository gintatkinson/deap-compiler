# REQ-0046: Mutable AST Transformation & In-Place Rewrite Engine

## 1. Normative Statement

The abstract syntax tree (AST) engine shall provide a deterministic, mutable transformation pass engine for lowering, syntactic desugaring, optimization rewrites, constant propagation, and semantic enrichments while strictly preserving graph topological integrity and typed reference safety. All AST rewrite passes shall perform node attribute modifications in-place within contiguous node arena storage, preserving immutable slot indices ($`\text{Index}(n, \mathcal{A}_{t+1}) = \text{Index}(n, \mathcal{A}_t)`$) and fixed virtual memory base offsets without disjoint node reallocations.

The mutation engine must update each arena slot's monotonic incarnation generation counter ($`g \in \mathbb{U}_{16}`$) modulo $`2^{16}`$ upon in-place modification or replacement. Any external node handle referencing an obsolete generation shall evaluate deterministically to an invalid reference ($`\bot`$), preventing ABA hazards across compiler passes.

Rewrite passes shall preserve topological graph closure: every directed relationship edge $`e = (u, v)`$ in transformed AST graph $`\mathcal{A}_{t+1}`$ must connect valid, active node slots, guaranteeing zero dangling edges ($`\text{DanglingEdges}(\mathcal{A}_{t+1}) = \emptyset`$). Nodes mutated in-place retain deterministic RFC 4122 UUIDv5 identifiers hashed from compiler namespace $`\text{NS}_{\text{DEAP}}`$ and canonical topological paths (Architectural Directive 1). Disjoint package passes execute on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ over thread-isolated arena segments (Architectural Directive 2). Newly synthesized symbols are interned into the symbol pool as 32-bit scalar `SymbolId` tokens (sole zero-copy exception per Architectural Directive 3).

Encountering malformed constructs shall trigger synchronization token error recovery (Architectural Directive 4), emitting diagnostic code `E0200` per REQ-0191 and resuming at enclosing delimiters. The engine enforces a deterministic, non-panicking total-function contract, meeting performance gates (latency strictly under 25 ms and memory strictly under 100 MB RSS) in compiled Release mode (`--release`, Architectural Directive 5). All diagnostics, models, and transformations strictly utilize synthetic abstract MBSE placeholders (e.g., `Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`).

## 2. Formal Invariant

Let $`\mathcal{A}_t`$ denote the contiguous node arena at step $`t \in \mathbb{N}_0`$, with uniform slot capacity $`C \in \mathbb{N}`$ and slot byte size $`S_{\text{slot}}`$. Each arena slot is formalized as:

```math
\mathcal{S}_t[i] = \langle \mathcal{N}_t(i), g_t(i), \tau_t(i), b_t(i) \rangle
```

where $`\mathcal{N}_t(i)`$ is the node payload, $`g_t(i) \in \mathbb{U}_{16}`$ is the generation counter, $`\tau_t(i) \in \mathbb{U}_{16}`$ is the type tag, and $`b_t(i) \in \{0, 1\}`$ is the allocation flag.

An AST rewrite pass is a deterministic transformation:

```math
\mathcal{T}_{\text{rewrite}} : \mathcal{A}_t \times \mathcal{P}_{\text{rules}} \longrightarrow \mathcal{A}_{t+1} \times \mathcal{D}
```

In-Place Slot Index and Physical Address Invariance:

```math
\forall n \in \text{ModifiedNodes}(\mathcal{T}_{\text{rewrite}}), \quad \text{Index}(n, \mathcal{A}_{t+1}) = \text{Index}(n, \mathcal{A}_t) \;\wedge\; \text{Address}(n, \mathcal{A}_{t+1}) = \text{Address}(n, \mathcal{A}_t)
```

Generational Mutation and Stale Reference Invalidation Invariant:

```math
\begin{aligned}
g_{t+1}(i) &= (g_t(i) + 1) \pmod{2^{16}} \\
\forall H = \langle i, g_H, \tau \rangle, \quad g_H \ne g_{t+1}(i) &\implies \text{Valid}(H, \mathcal{A}_{t+1}) = \text{false} \;\wedge\; \text{Deref}(H, \mathcal{A}_{t+1}) = \bot
\end{aligned}
```

Topological Graph Closure and Zero Dangling Edges Invariant:

```math
\forall e = (u, v) \in \text{Edges}(\mathcal{A}_{t+1}), \quad u \in \text{Nodes}(\mathcal{A}_{t+1}) \;\wedge\; v \in \text{Nodes}(\mathcal{A}_{t+1}) \;\wedge\; \text{DanglingEdges}(\mathcal{A}_{t+1}) = \emptyset
```

Deterministic UUIDv5 and Diagnostic Code Invariants:

```math
\begin{aligned}
\mathcal{P}_{\text{path}}(n, \mathcal{A}_{t+1}) = \mathcal{P}_{\text{path}}(n, \mathcal{A}_t) &\implies \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \mathcal{P}_{\text{path}}(n, \mathcal{A}_{t+1})) = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \mathcal{P}_{\text{path}}(n, \mathcal{A}_t)) \\
\neg\text{Valid}(H, \mathcal{A}_{t+1}) &\implies \text{Diagnostic}(\text{span}(H), \text{E0200}) \in \mathcal{D}
\end{aligned}
```

## 3. Computational Complexity & Algorithmic Bounds

The mutable AST transformation and in-place rewrite engine operates strictly within Complexity Class $`\mathbf{P}`$.

1. In-Place Mutation: Strict $`O(1)`$ worst-case constant time via array base-plus-offset addressing ($`\text{Base} + i \cdot S_{\text{slot}}`$), bitwise update, and modular generation increment.
2. Handle Validation: Strict $`O(1)`$ worst-case constant time via bounds check ($`i \lt C`$), generation match ($`g_t(i) = g_H`$), and tag match ($`\tau_t(i) = \tau_H`$).
3. Full Rewrite Pass: Deterministic $`O(V)`$ linear time for attribute modifications and $`O(V + E)`$ linear time for structural rewrites, where $`V = |\text{Nodes}(\mathcal{A})|`$ and $`E = |\text{Edges}(\mathcal{A})|`$.
4. Parallel Bounds: Processing $`K`$ subtrees on $`N_{\text{max\_workers}}`$ threads scales as $`O(\lceil K / N_{\text{max\_workers}} \rceil \cdot (V_{\text{unit}} + E_{\text{unit}}))`$.
5. Space Complexity: Strict $`O(1)`$ auxiliary memory for in-place updates, recursion depth $`D_{\text{max}} \le 64 = O(1)`$, and $`O(V)`$ arena storage with zero dynamic heap allocations.

Local in-place AST rewrites execute deterministically without backtracking or state-space explosion, bypassing combinatorial NP-hard frontiers (e.g., NP-1, NP-3, NP-7) with guaranteed polynomial-time termination.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: In-Place Slot Index and Physical Address Invariance

- **Given:** Node `Classifier_Alpha` in arena slot $`k`$ with address $`\text{Base}(\mathcal{A}) + k \cdot S_{\text{slot}}`$.
- **When:** The engine applies an attribute modification or desugaring rewrite pass.
- **Then:** Slot index satisfies $`\text{Index}(\text{Classifier\_Alpha}, \mathcal{A}_{t+1}) = k`$, virtual memory address remains invariant, and zero reallocations occur.
- **Diagnostic:** `E0200` emitted on slot relocation or index divergence.

### AC-02: Generational Counter Monotonicity & Stale Dereference Invalidation

- **Given:** Node handle $`H_1 = \langle k, g, \tau \rangle`$ referencing slot $`k`$ with generation $`g`$.
- **When:** Slot $`k`$ undergoes in-place mutation or replacement at step $`t \to t+1`$.
- **Then:** Generation increments to $`(g + 1) \pmod{2^{16}}`$, dereferencing $`H_1`$ returns $`\bot`$, and new handle $`H_2 = \langle k, (g + 1) \pmod{2^{16}}, \tau \rangle`$ dereferences in $`O(1)`$ time.
- **Diagnostic:** `E0200` emitted on stale handle access.

### AC-03: Desugaring Structural Integrity & Zero Dangling Edges

- **Given:** An AST containing composite interconnect declarations between `Port_1` and `Port_2`.
- **When:** A desugaring pass lowers composite connectors into directed primitive flows.
- **Then:** 100% of emitted directed edges connect active, valid node slots in $`\mathcal{A}_{t+1}`$, satisfying $`\text{DanglingEdges}(\mathcal{A}_{t+1}) = \emptyset`$.
- **Diagnostic:** `E0200` emitted on dangling edge or invalid endpoint handle.

### AC-04: Deterministic RFC 4122 UUIDv5 Anchor Preservation

- **Given:** Structural node `Package_0::Classifier_Alpha` with canonical topological path $`p`$.
- **When:** The transformation engine executes an in-place rewrite pass.
- **Then:** The node's RFC 4122 UUIDv5 matches $`\text{UUIDv5}(\text{NS}_{\text{DEAP}}, p)`$ with version bits `0x50` and variant bits `0x80`, ensuring 0-byte diff churn.
- **Diagnostic:** `E0200` emitted on UUIDv5 computation failure or variant mismatch.

### AC-05: Synchronization Token Error Recovery & Non-Panicking Contract

- **Given:** An AST containing a malformed expression in `Classifier_Alpha` followed by valid sibling `Classifier_Beta`.
- **When:** The rewrite engine encounters the malformed construct during AST lowering.
- **Then:** The engine emits `E0200`, resynchronizes on the next sibling delimiter without panicking, and completes rewriting of `Classifier_Beta`.
- **Diagnostic:** `E0200` emitted on malformed syntax or semantic contradiction.

### AC-06: Bounded Work-Stealing Parallelism & Performance Budgets

- **Given:** An AST graph with $`10^5`$ nodes and $`K`$ package hierarchies processed across $`N_{\text{max\_workers}}`$ threads.
- **When:** Rewrite passes execute in compiled Release mode (`--release`) on the bounded work-stealing pool.
- **Then:** Execution latency is strictly under 25 ms, peak memory RSS is strictly under 100 MB, thread-isolated arena segments prevent data races, and symbols are interned as scalar `SymbolId` tokens.
- **Diagnostic:** `E0200` emitted on thread race condition, interner violation, or performance budget breach.
