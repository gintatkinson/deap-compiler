### REQ-0034: Contiguous Memory Lowering & Linear Allocation Complexity

- **Normative Statement**: The compiler core metamodel and intermediate representation lowering engine shall lower all ingested schema abstract syntax tree (AST) entities (including packages, part definitions, port definitions, action definitions, constraint definitions, item definitions, connection definitions, metadata annotations, expressions, and attributes) into contiguous memory representations within a dedicated, typed node arena. The lowering transformation must store AST nodes within uniform-sized, contiguous slot allocations (`sizeof(NodeSlot)` with 64-bit alignment, $`A_{\text{align}} = 8\text{ bytes}`$`), eliminating dynamic heap pointer indirection overhead, pointer-chasing latency, per-node heap allocator metadata headers, and memory fragmentation. The compiler shall provide strict `$`O(1)`$ constant-time random access to any node slot via typed integer index handles (`NodeHandle<T>` or `NodeIndex`) using base-plus-offset address arithmetic, guaranteeing a pointer indirection depth of zero within the node arena ($`\text{PointerIndirectionDepth}(\mathcal{A}_{\text{node}}) = 0`$`). Node insertion into pre-allocated arena chunks shall execute in `$`O(1)`$` amortized time, and full AST lowering shall execute in strict linear time `$`O(N)`$` proportional to total AST entity count `$`N`$`. Lowered node slots must exhibit spatial buffer locality within contiguous memory segments to maximize CPU cache line utilization (`$`L_{\text{cache}} = 64\text{ bytes}`$) and enable hardware stream prefetching during traversals, semantic analysis, and serialization passes. When an arena chunk reaches its configured capacity, the arena manager shall allocate a new contiguous chunk segment without relocating previously allocated nodes or invalidating existing node handles. Every lowered AST node must receive a deterministic RFC 4122 UUIDv5 identifier derived from the compiler namespace UUID and its canonical fully qualified topological path (e.g., `Package_0::PartDef_Alpha`), adhering to Architectural Directive 1 and REQ-0010. Multi-file compilation unit lowering shall execute concurrently over a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ using thread-isolated arena allocators, adhering to Architectural Directive 2 and REQ-0012. Scalar symbol identifiers shall reference deduplicated interned strings via scalar `SymbolId` tokens within the global symbol interner pool, which constitutes the sole permitted exception to zero-copy memory management in accordance with Architectural Directive 3 and REQ-0036. The lowering engine must enforce Architectural Directive 5, guaranteeing a total, deterministic, non-panicking execution contract with total-function termination across all inputs; if virtual memory allocation fails or an invalid slot boundary is detected, the engine shall record structured diagnostic record `E0200` per REQ-0191 without aborting or unwinding. Execution latency (< 25 ms) and peak memory RSS (< 100 MB for $`10^6`$ AST nodes) performance gates shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196. All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `PartDef_Alpha`, `PortDef_Beta`, `ActionDef_Gamma`, `ConstraintDef_Delta`, `param_x : Real`), strictly prohibiting hardcoded domain concepts and mock data.

- **Formal Invariant**: Let $`\mathcal{A}_{\text{node}}`$` denote a contiguous typed node arena buffer with base address `$`\text{Base}(\mathcal{A}_{\text{node}}) \in \mathbb{N}`$` and capacity `$`C \in \mathbb{N}`$` slots. Let `$`S_{\text{slot}} = \text{sizeof}(\text{NodeSlot})`$` denote the uniform byte size of each node slot, and let `$`A_{\text{align}} \in \{8, 16\}`$` denote the alignment constraint (`$`A_{\text{align}} = 8\text{ bytes}`$`). The virtual memory address of the node slot at index `$`i \in \{0, 1, \dots, N-1\}`$ satisfies:

```math
\text{Address}(\text{Node}_i) = \text{Base}(\mathcal{A}_{\text{node}}) + i \cdot S_{\text{slot}}
```

Adjacent node slots in the arena satisfy strict contiguous memory layout without intervening padding or header words:

```math
\text{Address}(\text{Node}_{i+1}) - \text{Address}(\text{Node}_i) = S_{\text{slot}} = \text{sizeof}(\text{NodeSlot})
```

64-Bit Memory Alignment Invariant: Every allocated node slot satisfies 64-bit alignment boundaries:

```math
\forall i \in \{0, 1, \dots, N-1\}, \quad \text{Address}(\text{Node}_i) \equiv 0 \pmod{A_{\text{align}}}
```

Zero Pointer Indirection Depth Invariant: Relationships between AST nodes in the lowered graph $`\mathcal{G}_{\text{AST}} = (\mathcal{V}_{\text{AST}}, \mathcal{E}_{\text{AST}})`$` are represented strictly by scalar integer index handles `$`h \in \mathbb{N}_0`$ rather than virtual memory pointers:

```math
\text{PointerIndirectionDepth}(\mathcal{A}_{\text{node}}) = 0
```

```math
\forall (u, v) \in \mathcal{E}_{\text{AST}}, \quad \text{TargetHandle}(u, v) \in \mathbb{N}_0 \times \mathbb{N}_0
```

Temporal Lowering and Constant-Time Access Invariants: For an ingested schema model comprising $`N = |\mathcal{V}_{\text{AST}}|`$` nodes, the total lowering time `$`T_{\text{lower}}(N)`$` and the random slot access time `$`T_{\text{access}}(i)`$ satisfy:

```math
\begin{aligned}
T_{\text{lower}}(N) &\le c_1 \cdot N + c_0, \quad \forall N \ge 1 \\
T_{\text{access}}(i) &\le c_2 \cdot 1, \quad \forall i \in \{0, 1, \dots, N-1\}
\end{aligned}
```

where $`c_0, c_1, c_2 \in \mathbb{R}^+`$` are fixed platform constants independent of `$`N`$.

Spatial Cache Locality Invariant: For CPU cache line size $`L_{\text{cache}} \in \{64, 128\}`$` bytes, a sequential traversal over `$`k`$` consecutive node slots (`$`k \ge 1`$`) incurs a cache line transfer count `$`\mathcal{M}_{\text{cache}}(k)`$ bounded by:

```math
\mathcal{M}_{\text{cache}}(k) \le \left\lceil \frac{k \cdot S_{\text{slot}}}{L_{\text{cache}}} \right\rceil + 1
```

yielding a cache hit reuse ratio $`\mathcal{R}_{\text{cache}}`$:

```math
\mathcal{R}_{\text{cache}} = \frac{k}{\mathcal{M}_{\text{cache}}(k)} \ge \min\left(1, \, \frac{L_{\text{cache}}}{S_{\text{slot}}}\right)
```

in contrast to heap-allocated pointer graphs where the worst-case cache line miss count is $`\mathcal{M}_{\text{heap}}(k) = \Omega(k)`$.

Monotonic Arena Progression Invariant: Let $`\text{ArenaOffset}_k`$` denote the monotonic byte offset after lowering `$`k`$ node slots. The allocator satisfies:

```math
\begin{aligned}
\text{ArenaOffset}_0 &= 0 \\
\text{ArenaOffset}_{k+1} &= \text{ArenaOffset}_k + S_{\text{slot}}, \quad \forall k \in \{0, 1, \dots, N-1\} \\
0 &\le \text{ArenaOffset}_k \le \text{ArenaOffset}_{k+1} \le C \cdot S_{\text{slot}}
\end{aligned}
```

Injective Schema Lowering Invariant: Let $`\mathcal{M}_{\text{ingest}}`$` denote the set of ingested schema entities. The lowering transformation `$`\mathcal{L} : \mathcal{M}_{\text{ingest}} \longrightarrow \mathcal{A}_{\text{node}}`$` maps each schema entity `$`e \in \mathcal{M}_{\text{ingest}}`$` injectively to an arena slot index `$`i \in \{0, \dots, N-1\}`$:

```math
\mathcal{L}(e) = \langle \text{Index}: i, \, \text{Kind}: \text{Family}(e), \, \text{UUID}: \text{UUIDv5}(\text{NS}_{\text{DEAP}}, \mathcal{N}_{\text{topological}}(e)) \rangle
```

```math
\forall e_1, e_2 \in \mathcal{M}_{\text{ingest}}, \quad e_1 \ne e_2 \implies \text{Index}(\mathcal{L}(e_1)) \ne \text{Index}(\mathcal{L}(e_2))
```

Diagnostic Code Binding Invariant: Capacity exhaustion, alignment violations, or out-of-bounds indexing trigger structured diagnostic records in accordance with REQ-0191:

```math
\begin{aligned}
\text{ArenaOffset}_k + S_{\text{slot}} \gt C \cdot S_{\text{slot}} &\implies \text{Diagnostic}(\text{span}(e), \text{DiagnosticCode::E0200}, \text{ArenaCapacityExceeded}) \in \mathcal{D} \\
\text{Address}(\text{Node}_i) \not\equiv 0 \pmod{A_{\text{align}}} &\implies \text{Diagnostic}(\text{span}(e), \text{DiagnosticCode::E0200}, \text{MemoryAlignmentViolation}) \in \mathcal{D} \\
i \ge N \;\vee\; i \lt 0 &\implies \text{Diagnostic}(\text{span}(e), \text{DiagnosticCode::E0200}, \text{NodeSlotIndexOutOfBounds}) \in \mathcal{D}
\end{aligned}
```

Diagnostic Taxonomy Containment Invariant: All emitted diagnostics strictly belong to the Subsystem 3 metamodel and typing family:

```math
\forall d \in \mathcal{D}_{\text{arena}}, \quad \text{code}(d) = \text{DiagnosticCode::E0200} \in \mathcal{E}_{\text{type}}
```

- **Computational Complexity & Algorithmic Bounds**: The contiguous memory lowering engine executes within Complexity Class $`\mathbf{P}`$`. Node slot insertion executes in `$`O(1)`$` amortized time (and strict `$`O(1)`$` worst-case time within an allocated arena chunk), requiring only an integer addition to advance the offset, an integer bounds check against capacity `$`C`$`, and a sequential memory write into the pre-allocated buffer. Lowering an entire AST model consisting of `$`N = |\mathcal{V}_{\text{AST}}|`$` nodes executes in deterministic `$`O(N)`$` linear time, traversing the ingested schema tree in a single pass without backtracking. Random node access executes in strict `$`O(1)`$` worst-case constant time via base-plus-offset address arithmetic `$`\text{Base} + i \cdot S_{\text{slot}}`$`, requiring zero pointer dereference hops or hash table lookups. Sequential iteration over all `$`N`$` nodes operates in deterministic `$`O(N)`$` linear time, with hardware prefetching minimizing CPU cache miss stall cycles. When lowering `$`K`$` independent compilation units concurrently across `$`N_{\text{max\_workers}}`$` threads in the bounded work-stealing thread pool, wall-clock lowering time is bounded by `$`O(\lceil K / N_{\text{max\_workers}} \rceil \cdot N_{\text{max\_unit}})`$`, where each worker thread allocates into an isolated arena chunk segment without lock contention. Auxiliary memory consumption is strictly bounded by `$`O(N)`$` linear space proportional to slot size `$`S_{\text{slot}}`$` and node count `$`N`$`, completely eliminating dynamic per-node heap allocator metadata headers, object reference counters, and pointer indirection arrays. Auxiliary call stack space for the lowering traversal is strictly bounded by `$`O(D_{\text{max}})`$`, where maximum syntactic tree nesting depth satisfies `$`D_{\text{max}} \le 64`$`, requiring `$`O(1)`$ auxiliary stack memory.

- **Verification & Conformance Criteria**: Conformance shall be verified deterministically through automated test suites and profiling harnesses operating on synthetic models containing abstract MBSE entities (`Package_0`, `PartDef_Alpha`, `PortDef_Beta`, `ActionDef_Gamma`, `ConstraintDef_Delta`, `param_x : Real`). Conformance validation shall enforce the following test gates:
  1. Contiguous Virtual Memory Layout Gate: Assert that for an allocated sequence of $`N`$` nodes (`$`N = 10^4`$`), the difference between starting virtual addresses of adjacent slots `$`\text{Address}(\text{Node}_{i+1}) - \text{Address}(\text{Node}_i)`$` strictly equals `$`\text{sizeof}(\text{NodeSlot})`$ across 100% of adjacent pairs.
  2. Zero Pointer Indirection Depth Gate: Assert that node structures store references to child, sibling, or target nodes exclusively as typed integer indices or handles (`NodeIndex` or `NodeHandle`) with $`\text{sizeof}(\text{Handle}) \le 8\text{ bytes}`$, verifying zero raw virtual memory pointers within node representations.
  3. Linear Lowering Throughput Scaling Gate: Benchmark lowering throughput across synthetic AST models scaling from $`N = 10^3`$` to `$`N = 10^6`$` nodes. Assert linear time scaling `$`T(N) \le c_1 \cdot N`$` with a linear regression coefficient of determination `$`R^2 \ge 0.99`$.
  4. Constant-Time Random Access Gate: Execute $`10^6`$` randomized index lookups across the contiguous arena; assert empirical access latency satisfies `$`T_{\text{access}}(i) \le c_2`$`, verifying `$`O(1)`$ constant-time performance without cache line thrashing.
  5. Cache Line Locality Profiling Gate: Profile hardware cache metrics during sequential AST traversal; assert that L1 data cache misses do not exceed $`\lceil (N \cdot S_{\text{slot}}) / L_{\text{cache}} \rceil + \epsilon`$`, demonstrating a cache-line reuse factor of at least `$`L_{\text{cache}} / S_{\text{slot}}`$.
  6. 64-Bit Memory Alignment Gate: Assert that 100% of node slot starting addresses satisfy $`\text{Address}(\text{Node}_i) \equiv 0 \pmod 8`$.
  7. Arena Capacity Exhaustion and Diagnostic Gate: Simulate arena capacity exhaustion and invalid index access ($`i \ge N`$); assert that the compiler records structured diagnostic record `E0200` with source span details and diagnostic taxonomy family $`\mathcal{E}_{\text{type}}`$, terminating gracefully without panicking per Directive 5.
  8. Deterministic UUIDv5 Anchor Gate: Verify that 100% of lowered AST nodes receive deterministic RFC 4122 UUIDv5 identifiers hashed from the namespace UUID and canonical qualified paths per Directive 1 and REQ-0010.
  9. Bounded Work-Stealing Parallelism Gate: Execute multi-threaded lowering across $`K`$` compilation units on a thread pool bounded by `$`N_{\text{max\_workers}}`$; assert zero race conditions, thread-isolated arena allocation, and identical AST output.
  10. Release Mode Latency and Memory Budget Gate: In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per Directive 5 and REQ-0196, assert total execution latency is under 25 ms for standard schemas and peak RSS memory is under 100 MB for $`10^6`$ AST nodes.
  11. Bitwise Parity & Zero Churn Gate: Assert 0-byte diff churn across repeated compilations of synthetic test suites.
