### REQ-0109: Generalized Kirchhoff Potential Law ($`\oint \text{Across} = 0`$) across Closed Loops

- **Normative Statement**: The physical metrology and abstract flow conservation network engine of Subsystem 5 shall synthesize generalized Kirchhoff Potential Law (KVL / loop potential conservation) constraint equations across all closed topological loops in conservative networks such that the algebraic sum of across variables (effort / potential differences) around any closed topological cycle sums identically to zero at every instant.

  Specifically, the metrology engine, network topology analyzer, and constraint synthesizer shall strictly enforce the following structural, algebraic, and topological invariants:
  1. **Network Topology & Across Variable Representation**:
     - The network constraint engine shall ingest abstract flow network definitions formalized as directed multigraphs $`\mathcal{G}_{\text{flow}} = (\mathcal{V}_{\text{junc}}, \mathcal{E}_{\text{flow}})`$, where $`\mathcal{V}_{\text{junc}}`$ is the set of junction nodes ($`|\mathcal{V}_{\text{junc}}| = N_V`$) and $`\mathcal{E}_{\text{flow}}`$ is the set of directed flow branches ($`|\mathcal{E}_{\text{flow}}| = N_E`$).
     - Each flow branch $`e = (u, v) \in \mathcal{E}_{\text{flow}}`$ shall couple a source junction node $`u \in \mathcal{V}_{\text{junc}}`$ to a target junction node $`v \in \mathcal{V}_{\text{junc}}`$, carrying an across variable $`\Delta e_e = e_u - e_v`$ representing the generalized effort or potential difference between junction $`u`$ and junction $`v`$ in reference direction $`u \to v`$.
     - The physical dimension of every across variable shall be modeled as an exact rational coordinate vector $`\mathbf{d}_{\text{across}}(e) \in \mathbb{Q}^7`$ over the seven base physical dimensions $`[M, L, T, I, \Theta, N, J]`$ in accordance with REQ-0098 and REQ-0100.
  2. **Spanning Forest Partitioning & Fundamental Cycle Basis Extraction**:
     - The network engine shall compute a spanning forest $`\mathcal{T} = (\mathcal{V}_{\text{junc}}, \mathcal{E}_{\text{tree}})`$ across the network graph, partitioning edges into tree branches $`\mathcal{E}_{\text{tree}}`$ and cotree chord branches $`\mathcal{E}_{\text{chord}} = \mathcal{E}_{\text{flow}} \setminus \mathcal{E}_{\text{tree}}`$.
     - For a network graph with $`|\mathcal{K}|`$ connected components, the spanning forest shall contain exactly $`|\mathcal{E}_{\text{tree}}| = N_V - |\mathcal{K}|`$ tree branches.
     - The number of fundamental cycles shall equal the cyclomatic number $`N_C = |\mathcal{E}_{\text{chord}}| = N_E - N_V + |\mathcal{K}|`$.
     - For each chord branch $`e_k = (u_k, v_k) \in \mathcal{E}_{\text{chord}}`$, the engine shall construct the unique fundamental cycle $`\mathcal{L}_k`$ formed by chord $`e_k`$ and the unique path in $`\mathcal{T}`$ connecting $`v_k`$ to $`u_k`$.
     - The set of fundamental cycles $`\mathcal{C} = \{ \mathcal{L}_1, \dots, \mathcal{L}_{N_C} \}`$ constitutes a minimal cycle basis spanning the cycle space $`\operatorname{Ker}(\mathbf{A})`$ of $`\mathcal{G}_{\text{flow}}`$.
  3. **Fundamental Cycle Matrix $`\mathbf{B}`$ Assembly**:
     - The network engine shall construct the fundamental cycle matrix $`\mathbf{B} \in \{-1, 0, +1\}^{N_C \times N_E}`$ according to cycle branch traversal orientations:

$$
B_{k, e} = \begin{cases} +1, & \text{if branch } e \text{ traverses cycle } \mathcal{L}_k \text{ in the forward reference direction} \\ -1, & \text{if branch } e \text{ traverses cycle } \mathcal{L}_k \text{ in the reverse reference direction} \\ 0, & \text{if branch } e \notin \text{Edges}(\mathcal{L}_k) \end{cases}
$$

     - Under canonical branch indexing partitioning tree branches $`\mathcal{E}_{\text{tree}}`$ and chord branches $`\mathcal{E}_{\text{chord}}`$, the fundamental cycle matrix shall partition as $`\mathbf{B} = [\mathbf{B}_T \mid \mathbf{I}_{N_C}]`$, where $`\mathbf{I}_{N_C}`$ is the identity matrix corresponding to chords and $`\mathbf{B}_T \in \{-1, 0, +1\}^{N_C \times (N_V - |\mathcal{K}|)}`$ maps fundamental tree paths.
  4. **Generalized Kirchhoff Potential Law Synthesis**:
     - Across every fundamental cycle $`\mathcal{L}_k \in \mathcal{C}`$, the network engine shall synthesize a loop potential conservation constraint requiring the algebraic sum of across variables along the cycle to equal zero identically:

$$
\sum_{e \in \text{Edges}(\mathcal{L}_k)} B_{k, e} \cdot \Delta e_e(t) = 0, \quad \forall t \ge 0 \iff \mathbf{B} \mathbf{\Delta e}(t) = \mathbf{0}
$$

       where $`\mathbf{\Delta e} = [\Delta e_1, \dots, \Delta e_{N_E}]^T`$.
     - The synthesized constraint AST nodes shall be emitted into contiguous arena storage as formal invariant assertions for compile-time validation, simulation solver initialization, and downstream solver code generation.
  5. **Arbitrary Closed Cycle Linear Combination Invariance**:
     - The fundamental cycle basis $`\mathcal{C}`$ spans the complete cycle space. For any arbitrary closed loop $`\mathcal{L}_{\text{arb}}`$ expressible as an integer linear combination of fundamental cycles $`\mathcal{L}_{\text{arb}} = \sum_{k=1}^{N_C} \alpha_k \mathcal{L}_k`$ ($`\alpha_k \in \mathbb{Z}`$), the engine shall verify that loop potential closure holds unconditionally:

$$
\oint_{\mathcal{L}_{\text{arb}}} \Delta e = \sum_{e \in \text{Edges}(\mathcal{L}_{\text{arb}})} \mu_e \cdot \Delta e_e = \sum_{k=1}^{N_C} \alpha_k \left( \sum_{e \in \text{Edges}(\mathcal{L}_k)} B_{k, e} \cdot \Delta e_e \right) = 0
$$

  6. **Potential Field Uniqueness & Datum Ground Junction**:
     - For each connected component $`K_m \in \mathcal{K}`$, the engine shall designate a unique reference datum junction node $`J_{\text{ref}, m} \in \mathcal{V}_{K_m}`$ with assigned reference potential $`e(J_{\text{ref}, m}) = 0`$.
     - The engine shall verify that satisfying $`\mathbf{B} \mathbf{\Delta e} = \mathbf{0}`$ is necessary and sufficient for the existence of a single-valued potential field $`\mathbf{e}_{\text{node}} \in \mathbb{R}^{N_V}`$ on network junctions such that $`\mathbf{\Delta e} = \mathbf{A}_{\text{red}}^T \mathbf{e}_{\text{node}}`$, where $`\mathbf{A}_{\text{red}}`$ is the reduced incidence matrix obtained by eliminating datum rows.
  7. **Tellegen Orthogonality & Abstract Power Conservation**:
     - The engine shall assert the fundamental topological orthogonality condition between the node-branch incidence matrix $`\mathbf{A} \in \{-1, 0, +1\}^{N_V \times N_E}`$ and the fundamental cycle matrix $`\mathbf{B} \in \{-1, 0, +1\}^{N_C \times N_E}`$:

$$
\mathbf{A} \mathbf{B}^T = \mathbf{0}_{N_V \times N_C} \quad \text{and} \quad \mathbf{B} \mathbf{A}^T = \mathbf{0}_{N_C \times N_V}
$$

     - For any admissible through variable flow vector $`\mathbf{f}`$ satisfying flow continuity ($`\mathbf{A} \mathbf{f} = \mathbf{0}`$) and across variable vector $`\mathbf{\Delta e}`$ satisfying loop closure ($`\mathbf{B} \mathbf{\Delta e} = \mathbf{0}`$), total abstract power shall satisfy conservation: $`\mathbf{f}^T \mathbf{\Delta e} = \sum_{e \in \mathcal{E}_{\text{flow}}} f_e \cdot \Delta e_e = 0`$.
  8. **Across Variable Dimensional Homogeneity**:
     - All across variables $`\Delta e_e`$ traversing branches of a fundamental cycle $`\mathcal{L}_k`$ must share an identical physical dimension vector in $`\mathbb{Q}^7`$:

$$
\forall e_1, e_2 \in \text{Edges}(\mathcal{L}_k), \quad \mathbf{d}_{\text{across}}(e_1) \equiv \mathbf{d}_{\text{across}}(e_2)
$$

     - Any dimensional mismatch detected across branches participating in a closed loop shall be deterministically rejected at compile time with diagnostic error code `E0300` (`DimensionalMismatch`).
  9. **Static Potential Balance Evaluation & Violation Diagnostics**:
     - For networks with statically declared or constant across variables, the engine shall evaluate cycle potential balance $`\mathbf{B} \mathbf{\Delta e}`$ at compile time.
     - Any closed fundamental cycle violating potential closure ($`\sum_{e} B_{k, e} \Delta e_e \ne 0`$) shall be deterministically rejected at compile time with diagnostic error code `E0301` (`KirchhoffConservationViolation`).
  10. **Architectural Directives Compliance**:
      - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every fundamental cycle AST node, loop constraint assertion node, and across variable reference handle shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the compiler namespace OID and canonical fully qualified path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))`$) in accordance with REQ-0010.
      - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel extraction of spanning forests, fundamental cycle tracing, and potential constraint synthesis across independent network subgraphs and packages shall execute concurrently on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
      - *Directive 3 (String Interner Memory Allocation Exception)*: Junction identifiers, branch names, across variable names, and loop identifiers shall be interned into the deduplicated global string interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
      - *Directive 4 (Synchronization Token Error Recovery)*: The parser and network validator shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When semantic violations occur (`E0300`, `E0301`), diagnostics shall accumulate in error sink buffer $`\mathcal{D}_{\text{sink}}`$, substitute typed error sentinels ($`\bot_{\text{dim}}`$, $`\bot_{\text{effort}}`$), and continue parsing. If accumulated diagnostics reach $`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully.
      - *Directive 5 (Panic-Free Release Isolation)*: The potential loop conservation engine shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Verification latency ($`\lt 25\text{ ms}`$) and peak RSS memory ($`\lt 100\text{ MB}`$ for $`10^4`$ branches) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Classifier_Alpha`, `Junction_Alpha`, `Junction_Beta`, `FlowBranch_1`, `FlowBranch_2`, `Port_1`, `Port_2`, `param_x : Real`, `Quantity_1`, `Network_Alpha`, `Loop_Alpha`, `Loop_Beta`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $`\mathcal{V}_{\text{AST}}`$ denote the universe of allocated AST nodes in contiguous bump arena storage.

  Let $`\mathcal{G}_{\text{flow}} = (\mathcal{V}_{\text{junc}}, \mathcal{E}_{\text{flow}})`$ be an abstract flow conservation network multigraph. Each junction node $`J \in \mathcal{V}_{\text{junc}}`$ is formalized as a 5-tuple:

$$
  J = \langle \text{id}_J, \text{name}_J, \text{Incident}(J), \Delta_J, \text{span}_J \rangle
$$

  where:

$$
  \begin{aligned}
  \text{id}_J &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
  \text{name}_J &\in \mathcal{S}_{\text{intern}} \quad (\text{interned junction name identifier}) \\
  \text{Incident}(J) &\subseteq \mathcal{E}_{\text{flow}} \quad (\text{set of incident directed flow branches}) \\
  \Delta_J &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
  \text{span}_J &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
  \end{aligned}
$$

  Each flow branch $`e \in \mathcal{E}_{\text{flow}}`$ is formalized as a 9-tuple:

$$
  e = \langle \text{id}_e, u_e, v_e, f_e, \Delta e_e, \mathbf{d}_{\text{through}}, \mathbf{d}_{\text{across}}, \Delta_e, \text{span}_e \rangle
$$

  where $`u_e, v_e \in \mathcal{V}_{\text{junc}}`$, $`f_e`$ is the through variable, $`\Delta e_e`$ is the across variable, and $`\mathbf{d}_{\text{through}}, \mathbf{d}_{\text{across}} \in \mathbb{Q}^7`$.

  Let $`\mathcal{K} = \{ K_1, \dots, K_{|\mathcal{K}|} \}`$ denote the set of connected components of $`\mathcal{G}_{\text{flow}}`$. Let $`N_V = |\mathcal{V}_{\text{junc}}|`$ and $`N_E = |\mathcal{E}_{\text{flow}}|`$.

  Let $`\mathcal{T} = (\mathcal{V}_{\text{junc}}, \mathcal{E}_{\text{tree}})`$ denote a spanning forest of $`\mathcal{G}_{\text{flow}}`$ containing $`|\mathcal{E}_{\text{tree}}| = N_V - |\mathcal{K}|`$ tree branches. The cotree chord set is defined by:

$$
  \mathcal{E}_{\text{chord}} = \mathcal{E}_{\text{flow}} \setminus \mathcal{E}_{\text{tree}}, \quad |\mathcal{E}_{\text{chord}}| = N_C = N_E - N_V + |\mathcal{K}|
$$

  For each chord branch $`e_k = (u_k, v_k) \in \mathcal{E}_{\text{chord}}`$, the induced fundamental cycle $`\mathcal{L}_k`$ is formalized as a 5-tuple:

$$
  \mathcal{L}_k = \langle \text{id}_k, e_k, \text{Path}_{\mathcal{T}}(v_k, u_k), \mathbf{b}_k, \Delta_k \rangle
$$

  where $`\text{Path}_{\mathcal{T}}(v_k, u_k)`$ is the unique directed path in spanning forest $`\mathcal{T}`$ connecting $`v_k`$ to $`u_k`$, and $`\mathbf{b}_k \in \{-1, 0, +1\}^{N_E}`$ is the cycle incidence row vector.

  The fundamental cycle matrix $`\mathbf{B} \in \{-1, 0, +1\}^{N_C \times N_E}`$ is defined by:

$$
  B_{k, e} = \begin{cases} +1, & \text{if branch } e \text{ traverses cycle } \mathcal{L}_k \text{ in forward reference direction} \\ -1, & \text{if branch } e \text{ traverses cycle } \mathcal{L}_k \text{ in reverse reference direction} \\ 0, & \text{if branch } e \notin \text{Edges}(\mathcal{L}_k) \end{cases}
$$

  Generalized Kirchhoff Potential Law (KVL / Potential Loop Conservation Invariant):

$$
  \forall \mathcal{L}_k \in \mathcal{C}, \quad \sum_{e \in \text{Edges}(\mathcal{L}_k)} B_{k, e} \cdot \Delta e_e(t) = 0, \quad \forall t \ge 0 \iff \mathbf{B} \mathbf{\Delta e}(t) = \mathbf{0}
$$

  Arbitrary Closed Cycle Linear Combination Invariant:

$$
  \forall \mathcal{L}_{\text{arb}} = \sum_{k=1}^{N_C} \alpha_k \mathcal{L}_k \quad (\alpha_k \in \mathbb{Z}), \quad \oint_{\mathcal{L}_{\text{arb}}} \Delta e = \sum_{k=1}^{N_C} \alpha_k (\mathbf{B} \mathbf{\Delta e})_k = 0
$$

  Single-Valued Potential Field & Reference Datum Invariant:

$$
  \begin{aligned}
  \forall K_m \in \mathcal{K}, \exists ! J_{\text{ref}, m} \in \mathcal{V}_{K_m} &: e(J_{\text{ref}, m}) = 0 \\
  \mathbf{\Delta e} &= \mathbf{A}_{\text{red}}^T \mathbf{e}_{\text{node}} \\
  \mathbf{B} \mathbf{\Delta e} = \mathbf{B} (\mathbf{A}_{\text{red}}^T \mathbf{e}_{\text{node}}) &= (\mathbf{B} \mathbf{A}_{\text{red}}^T) \mathbf{e}_{\text{node}} = \mathbf{0}
  \end{aligned}
$$

  Tellegen Orthogonality & Abstract Power Conservation Invariant:

$$
  \mathbf{A} \mathbf{B}^T = \mathbf{0}_{N_V \times N_C}, \quad \mathbf{B} \mathbf{A}^T = \mathbf{0}_{N_C \times N_V}
$$

$$
  \mathbf{f}^T \mathbf{\Delta e} = \sum_{e \in \mathcal{E}_{\text{flow}}} f_e \cdot \Delta e_e = 0
$$

  Dimensional Homogeneity across Loops Invariant:

$$
  \forall \mathcal{L}_k \in \mathcal{C}, \; \forall e_1, e_2 \in \text{Edges}(\mathcal{L}_k) \implies \mathbf{d}_{\text{across}}(e_1) = \mathbf{d}_{\text{across}}(e_2)
$$

  Deterministic RFC 4122 UUIDv5 Anchor Invariant (Architectural Directive 1):

$$
  \begin{aligned}
  \forall \mathcal{L} \in \mathcal{C}, &\quad \Delta_{\mathcal{L}} = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(\mathcal{L})) \\
  \forall e \in \mathcal{E}_{\text{flow}}, &\quad \Delta_e = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(e))
  \end{aligned}
$$

  Diagnostic Trigger Rules: In accordance with REQ-0191, dimensional and conservation violations deterministically emit structured diagnostic records:

$$
  \begin{aligned}
  \exists \mathcal{L}_k \in \mathcal{C}, (e_1, e_2) \in \text{Edges}(\mathcal{L}_k) : \mathbf{d}_{\text{across}}(e_1) \ne \mathbf{d}_{\text{across}}(e_2) &\implies \text{Diagnostic}(\mathcal{L}_k, \text{DiagnosticCode::E0300}, \text{DimensionalMismatch}) \in \mathcal{D}_{\text{sink}} \\
  \exists \mathcal{L}_k \in \mathcal{C} : \sum_{e \in \text{Edges}(\mathcal{L}_k)} B_{k, e} \cdot \Delta e_e \ne 0 &\implies \text{Diagnostic}(\mathcal{L}_k, \text{DiagnosticCode::E0301}, \text{KirchhoffConservationViolation}) \in \mathcal{D}_{\text{sink}} \\
  |\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
  \end{aligned}
$$

- **Computational Complexity & Algorithmic Bounds**: Fundamental cycle basis extraction, cycle matrix assembly, dimensional homogeneity validation, and generalized Kirchhoff potential law constraint synthesis execute strictly within Complexity Class $`\mathbf{P}`$.

  For an abstract flow conservation network graph $`\mathcal{G}_{\text{flow}}`$ with $`N_V = |\mathcal{V}_{\text{junc}}|`$ junction nodes, $`N_E = |\mathcal{E}_{\text{flow}}|`$ directed flow branches, and $`|\mathcal{K}|`$ connected components:
  1. *Spanning Forest Construction*:
     - Partitioning the network graph into a spanning forest $`\mathcal{T}`$ across all $`|\mathcal{K}|`$ connected components via depth-first search (DFS) or breadth-first search (BFS) inspects every junction node and flow branch exactly once.
     - This construction executes in deterministic linear time and space:

$$
T_{\text{forest}}(N_V, N_E) \in O(N_V + N_E)
$$

  2. *Fundamental Cycle Path Reconstruction*:
     - The number of chords is $`N_C = N_E - N_V + |\mathcal{K}| \le N_E`$.
     - For each chord branch $`e_k = (u_k, v_k) \in \mathcal{E}_{\text{chord}}`$, tracing the unique tree path connecting $`v_k`$ to $`u_k`$ in $`\mathcal{T}`$ traverses at most the diameter of the tree component, bounded by $`N_V`$.
     - Extracting the complete fundamental cycle basis $`\mathcal{C} = \{ \mathcal{L}_1, \dots, \mathcal{L}_{N_C} \}`$ executes in deterministic polynomial time:

$$
T_{\text{cycle\_basis}}(N_V, N_E) \in O(N_C \cdot N_V) \subseteq O(N_E \cdot N_V)
$$

  3. *Fundamental Cycle Matrix $`\mathbf{B}`$ Assembly*:
     - Allocating and populating the sparse cycle matrix $`\mathbf{B} \in \{-1, 0, +1\}^{N_C \times N_E}`$ writes non-zero traversal orientations along each cycle path. Each fundamental cycle contains at most $`N_V`$ edges.
     - Cycle matrix construction requires $`O(N_C \cdot N_V)`$ operations:

$$
T_{\text{matrix\_B}}(N_V, N_E) \in O(N_C \cdot N_V) \subseteq O(N_E \cdot N_V)
$$

  4. *Tellegen Orthogonality Verification*:
     - Evaluating the sparse matrix product $`\mathbf{A} \mathbf{B}^T`$ involves verifying that for each junction $`J_i`$ and fundamental cycle $`\mathcal{L}_k`$, the product row-column dot product is zero. Since each edge in $`\mathcal{L}_k`$ connects exactly two vertices, the sum telescopes to zero in $`O(N_C \cdot \bar{d}_{\text{loop}})`$ operations where $`\bar{d}_{\text{loop}} \le N_V`$.

$$
T_{\text{tellegen}}(N_V, N_E) \in O(N_C \cdot N_V)
$$

  5. *Dimensional Homogeneity & Static Conservation Verification*:
     - Verifying that all across variables in a cycle share identical dimension vectors in $`\mathbb{Q}^7`$ requires at most $`7 \cdot N_V`$ integer comparisons per fundamental cycle, executing in $`O(N_C \cdot N_V)`$ time.
     - Static evaluation of $`\mathbf{B} \mathbf{\Delta e}`$ for constant across variables performs sparse matrix-vector multiplication in $`O(N_C \cdot \bar{d}_{\text{loop}}) \subseteq O(N_C \cdot N_V)`$ operations.
  6. *Aggregate Algorithmic Complexity*:

$$
  T_{\text{total}}(N_V, N_E) \in O(N_V + N_E + N_C \cdot N_V) \subseteq O(N_V + N_E \cdot N_V) \subseteq O(N_E^2)
$$

     For sparse physical topologies (where node degrees are bounded by a small constant $`d_{\text{max}} \ll N_V`$ and average cycle length is bounded by a constant $`\bar{L} \ll N_V`$), total execution time simplifies to strictly linear time:

$$
  T_{\text{sparse}}(N_V, N_E) \in O(N_V + N_E)
$$

  7. *Parallel Work-Stealing Scaling (Architectural Directive 2)*:
     When evaluating $`M`$ independent network components or packages across $`N_{\text{max\_workers}}`$ threads on a bounded work-stealing thread pool:

$$
  T_{\text{parallel}}(N_V, N_E, N_{\text{max\_workers}}) \in O\left( \frac{N_V + N_E \cdot N_V}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  8. *Space Complexity & Memory Bounds*:
     Contiguous bump arena storage for junction nodes, flow branches, spanning forest records, fundamental cycles, cycle matrix entries, and synthesized constraint expressions is strictly bounded by $`O(N_V + N_E + N_C \cdot N_V)`$ bytes. Deduplicated string interner memory is bounded by the lengths of unique junction and variable names. Diagnostic buffer memory is strictly bounded by $`O(C_{\text{max\_errors}}) = O(1)`$.
