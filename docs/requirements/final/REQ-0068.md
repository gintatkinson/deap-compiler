### REQ-0068: KerML PortionKind, TimeSlice, Snapshot & EventOccurrence Semantics

#### 1. Normative Statement

The Core Metamodel, Node Arena & AST Graph Engine shall formalize occurrence decomposition operators, lowering `snapshot`, `time slice`, and `event occurrence` constructs into rigorous geometric intersections over 4-dimensional occurrence world-lines and world-volumes ($`\mathcal{W} \subseteq \mathbb{R}^3 \times \mathbb{R}`$`). In the KerML and SysML v2 metamodel lowering pipeline, an occurrence `$`O`$ instantiated from an `OccurrenceDefinition` or `OccurrenceUsage` shall define a spatio-temporal world-volume $`\mathcal{W}(O) \subseteq \mathbb{R}^3 \times \mathbb{R}`$` bounded by a closed temporal lifetime interval `$`\mathcal{T}(O) = [t_{\text{start}}(O), t_{\text{end}}(O)]`$` where `$`t_{\text{start}}(O) \le t_{\text{end}}(O)`$. The lowering engine shall support occurrence portioning via the `Portion` metaclass and `PortionKind` enumeration, partitioning occurrences across spatial and temporal dimensions into specialized portions: `Snapshot`, `TimeSlice`, and `EventOccurrence`.

  The lowering engine must enforce the following formal semantic rules and validation gates for each portion kind:
  1. **Snapshot Lowering Semantics**: A snapshot declaration `Snapshot(O, t_0)` shall project the state, structural features, and active values of occurrence $`O`$` at an exact temporal point `$`t_0 \in \mathbb{R}`$`. The snapshot must be lowered as a hyper-plane intersection `$`\text{Snapshot}(O, t_0) = \mathcal{W}(O) \cap \{ (\mathbf{x}, t) \in \mathbb{R}^3 \times \mathbb{R} \mid t = t_0 \}`$`. The temporal duration of a snapshot is identically zero (`$`\Delta t = 0`$`), possessing zero Lebesgue measure in the time dimension (`$`\lambda_t = 0`$`). The lowering engine shall statically verify that the snapshot instant `$`t_0`$` falls within the temporal lifetime of the parent occurrence: `$`t_{\text{start}}(O) \le t_0 \le t_{\text{end}}(O)`$`. Any snapshot declared at an instant strictly outside this lifetime (`$`t_0 \lt t_{\text{start}}(O)`$` or `$`t_0 \gt t_{\text{end}}(O)`$) shall be rejected at compile time, deterministically emitting diagnostic error code `E0200` in accordance with the standardized diagnostic taxonomy of REQ-0191.
  2. **TimeSlice Lowering Semantics**: A time slice declaration `TimeSlice(O, t_1, t_2)` shall project the continuous temporal behavior, state transitions, and feature dynamics of occurrence $`O`$` over a closed interval `$`[t_1, t_2]`$`. The time slice must be lowered as a 4D geometric slab intersection `$`\text{TimeSlice}(O, t_1, t_2) = \mathcal{W}(O) \cap \{ (\mathbf{x}, t) \in \mathbb{R}^3 \times \mathbb{R} \mid t_1 \le t \le t_2 \}`$. The lowering engine shall verify two non-negotiable invariants:
     - *Non-negative Duration Invariant*: The start time must not exceed the end time ($`t_1 \le t_2`$`), ensuring a non-negative Lebesgue duration (`$`\Delta t = t_2 - t_1 \ge 0`$`). An inverted time interval where `$`t_1 \gt t_2`$ shall be rejected at compile time with diagnostic error code `E0200`.
     - *Temporal Sub-Interval Inclusion Invariant*: The time slice interval must be wholly contained within the parent occurrence lifetime ($`[t_1, t_2] \subseteq [t_{\text{start}}(O), t_{\text{end}}(O)]`$`). Any boundary breach (`$`t_1 \lt t_{\text{start}}(O)`$` or `$`t_2 \gt t_{\text{end}}(O)`$) shall be rejected at compile time with diagnostic error code `E0200`.
  3. **EventOccurrence Lowering Semantics**: An event occurrence declaration `EventOccurrence(O, t_e, \Phi_{\text{trigger}})` shall formalize the realization of an instantaneous or discrete occurrence triggered upon the satisfaction of an event predicate $`\Phi_{\text{trigger}}`$` at instant `$`t_e \in \mathbb{R}`$`. The event occurrence must be lowered as a constrained point-in-time slice: `$`\text{EventOccurrence}(O, t_e, \Phi_{\text{trigger}}) = \{ (\mathbf{x}, t) \in \mathcal{W}(O) \mid t = t_e \wedge \Phi_{\text{trigger}}(\mathbf{x}, t_e) = \text{true} \}`$`. Like snapshots, instantaneous event occurrences enforce zero Lebesgue duration (`$`\Delta t = 0`$`, `$`\lambda_t = 0`$`) and require temporal lifetime inclusion (`$`t_e \in [t_{\text{start}}(O), t_{\text{end}}(O)]`$`). The trigger expression `$`\Phi_{\text{trigger}}`$` must be statically verified as a well-typed boolean constraint expression (`$`\tau(\Phi_{\text{trigger}}) = \text{Boolean}`$). Any non-boolean trigger expression or temporal boundary breach shall deterministically emit diagnostic error code `E0200`.
  4. **Portioning Transitivity and Disjointness**: The portioning relationship shall be transitive: if $`P_1`$` is a time slice of `$`P_2`$` and `$`P_2`$` is a time slice of `$`O`$`, then `$`P_1`$` is a valid time slice of `$`O`$` if and only if its temporal bounds satisfy nested interval containment (`$`\mathcal{T}(P_1) \subseteq \mathcal{T}(P_2) \subseteq \mathcal{T}(O)`$`). Two snapshots of the same occurrence taken at distinct points in time (`$`t_a \ne t_b`$`) shall be strictly disjoint in spacetime: `$`\text{Snapshot}(O, t_a) \cap \text{Snapshot}(O, t_b) = \emptyset`$.

  All lowered portion nodes, snapshots, time slices, and event occurrences shall be stored sequentially in contiguous typed bump arena storage in accordance with REQ-0009 and REQ-0034, addressed via stable 32-bit relative node handles per REQ-0035. In accordance with Architectural Directive 1 and REQ-0010, every portion node must receive a deterministic RFC 4122 UUIDv5 identifier computed by namespace-hashing the parent occurrence fully qualified path and the portion identifier with the canonical compiler namespace OID. In accordance with Architectural Directive 3 and REQ-0036, scalar symbol identifiers for portion names, trigger identifiers, and temporal parameter tokens shall be interned into the global symbol interner pool. In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, the lowering engine shall implement synchronization token error recovery: upon encountering an inverted interval, temporal boundary breach, or ill-typed trigger expression, the engine shall record a structured diagnostic record (`E0200`), substitute an error sentinel $`\bot_{\text{portion}}`$`, and continue verifying subsequent AST nodes without panicking. If accumulated diagnostics reach the sink capacity limit `$`C_{\text{max\_errors}}`$, the compiler shall emit terminal diagnostic `E0199` and halt gracefully. Multithreaded validation of portion graphs across independent packages shall execute on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$` in accordance with Architectural Directive 2 and REQ-0012. In accordance with Architectural Directive 5, REQ-0011, and REQ-0196, the lowering engine shall enforce a deterministic, non-panicking execution contract with total-function termination across all inputs, evaluating performance gates (< 25 ms latency, < 100 MB RSS for `$`10^5`$ portion nodes) exclusively in compiled Release mode (`--release`). All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Occurrence_Alpha`, `Occurrence_Beta`, `Portion_0`, `Snapshot_T0`, `Snapshot_T1`, `TimeSlice_Phase1`, `TimeSlice_Phase2`, `EventOccurrence_Ev1`, `param_x : Real`) with zero domain contamination.

#### 2. Formal Invariant

Let $`\mathcal{V}_{\text{AST}}`$` denote the universe of allocated AST nodes. The set of occurrence nodes `$`\mathcal{V}_{\text{occ}} \subset \mathcal{V}_{\text{AST}}`$` and portion nodes `$`\mathcal{V}_{\text{portion}} \subset \mathcal{V}_{\text{AST}}`$` are defined by metamodel discriminant kinds. Each portion node `$`P \in \mathcal{V}_{\text{portion}}`$ is formalized as an 8-tuple:

```math
P = \langle \text{id}_P, \text{name}_P, \text{parent}_P, \kappa_P, \mathcal{I}_P, \Phi_P, \Delta_P, \text{span}_P \rangle
```

where:

```math
\begin{aligned}
\text{id}_P &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
\text{name}_P &\in \mathcal{S}_{\text{intern}} \quad (\text{interned scalar symbol identifier}) \\
\text{parent}_P &\in \mathcal{V}_{\text{occ}} \cup \mathcal{V}_{\text{portion}} \quad (\text{parent occurrence or enclosing portion node handle}) \\
\kappa_P &\in \{ \text{PortionKind::Snapshot}, \text{PortionKind::TimeSlice}, \text{PortionKind::EventOccurrence} \} \quad (\text{portion kind discriminant}) \\
\mathcal{I}_P &\subseteq \mathbb{R} \quad (\text{associated temporal interval or discrete time coordinate}) \\
\Phi_P &\in \mathcal{E}_{\text{expr}} \cup \{ \top \} \quad (\text{event trigger predicate expression or default true}) \\
\Delta_P &\in \Sigma^* \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_P &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
\end{aligned}
```

Let $`O \in \mathcal{V}_{\text{occ}}`$` be an occurrence with 4-dimensional spatio-temporal world-volume `$`\mathcal{W}(O) \subseteq \mathbb{R}^3 \times \mathbb{R}`$`. The temporal lifetime projection `$`\mathcal{T}(O) \subset \mathbb{R}`$ is defined as:

```math
\mathcal{T}(O) = \{ t \in \mathbb{R} \mid \exists \mathbf{x} \in \mathbb{R}^3 : (\mathbf{x}, t) \in \mathcal{W}(O) \} = [t_{\text{start}}(O), t_{\text{end}}(O)]
```

subject to the lifetime well-formedness invariant $`t_{\text{start}}(O) \le t_{\text{end}}(O)`$.

The geometric lowering operators for snapshots, time slices, and event occurrences are formalized as follows:

```math
\begin{aligned}
\text{Snapshot}(O, t_0) &= \mathcal{W}(O) \cap \{ (\mathbf{x}, t) \in \mathbb{R}^3 \times \mathbb{R} \mid t = t_0 \} \\
\text{TimeSlice}(O, t_1, t_2) &= \mathcal{W}(O) \cap \{ (\mathbf{x}, t) \in \mathbb{R}^3 \times \mathbb{R} \mid t_1 \le t \le t_2 \} \\
\text{EventOccurrence}(O, t_e, \Phi_{\text{trigger}}) &= \{ (\mathbf{x}, t) \in \mathcal{W}(O) \mid t = t_e \wedge \Phi_{\text{trigger}}(\mathbf{x}, t_e) = \text{true} \}
\end{aligned}
```

Degeneracy and Temporal Lebesgue Measure Invariant: Snapshots and event occurrences have zero Lebesgue measure ($`\lambda_t`$`) in the temporal dimension (`$`\Delta t = 0`$), whereas time slices enforce non-negative Lebesgue duration:

```math
\begin{aligned}
\lambda_t(\pi_t(\text{Snapshot}(O, t_0))) &= 0 \\
\lambda_t(\pi_t(\text{EventOccurrence}(O, t_e, \Phi_{\text{trigger}}))) &= 0 \\
\lambda_t(\pi_t(\text{TimeSlice}(O, t_1, t_2))) &= t_2 - t_1 \ge 0
\end{aligned}
```

Temporal Validity and Containment Invariants:
1. Snapshot Validity:

```math
\Phi_{\text{snap\_valid}}(O, t_0) \iff t_{\text{start}}(O) \le t_0 \le t_{\text{end}}(O)
```

2. TimeSlice Validity:

```math
\Phi_{\text{slice\_valid}}(O, t_1, t_2) \iff (t_1 \le t_2) \wedge (t_{\text{start}}(O) \le t_1) \wedge (t_2 \le t_{\text{end}}(O))
```

3. EventOccurrence Validity:

```math
\Phi_{\text{event\_valid}}(O, t_e, \Phi_{\text{trigger}}) \iff (t_{\text{start}}(O) \le t_e \le t_{\text{end}}(O)) \wedge (\tau(\Phi_{\text{trigger}}) = \text{Boolean})
```

Snapshot Pairwise Disjointness Invariant: Two distinct snapshots of occurrence $`O`$` taken at different instants `$`t_a \ne t_b`$ have empty intersection:

```math
\forall t_a, t_b \in \mathcal{T}(O), \quad t_a \ne t_b \implies \text{Snapshot}(O, t_a) \cap \text{Snapshot}(O, t_b) = \emptyset
```

Portioning Transitivity Invariant: If portion $`P_{\text{sub}}`$` portions `$`P_{\text{sup}}`$`, and `$`P_{\text{sup}}`$` portions `$`O`$, then the 4D spatio-temporal extents satisfy monotonic set inclusion:

```math
P_{\text{sub}} \sqsubseteq_{\text{portion}} P_{\text{sup}} \sqsubseteq_{\text{portion}} O \implies \mathcal{W}(P_{\text{sub}}) \subseteq \mathcal{W}(P_{\text{sup}}) \subseteq \mathcal{W}(O)
```

Deterministic RFC 4122 UUIDv5 Topological Anchor (Architectural Directive 1): Each lowered portion node receives an immutable UUIDv5 identifier:

```math
\forall P \in \mathcal{V}_{\text{portion}}, \quad \Delta_P = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(\text{parent}_P) \mathbin{\Vert} \text{"::"} \mathbin{\Vert} \text{FQN}(P))
```

Diagnostic Code Trigger Invariant (REQ-0191): Violations of temporal lifetime inclusion, duration non-negativity, or trigger boolean typing deterministically trigger structured diagnostics:

```math
\begin{aligned}
(\kappa_P = \text{PortionKind::Snapshot} \wedge \neg \Phi_{\text{snap\_valid}}(O, t_0)) &\implies \text{Diagnostic}(P, \text{DiagnosticCode::E0200}, \text{SnapshotOutsideTemporalLifetime}) \in \mathcal{D}_{\text{sink}} \\
(\kappa_P = \text{PortionKind::TimeSlice} \wedge t_1 \gt t_2) &\implies \text{Diagnostic}(P, \text{DiagnosticCode::E0200}, \text{InvertedTimeSliceInterval}) \in \mathcal{D}_{\text{sink}} \\
(\kappa_P = \text{PortionKind::TimeSlice} \wedge \neg \Phi_{\text{slice\_valid}}(O, t_1, t_2)) &\implies \text{Diagnostic}(P, \text{DiagnosticCode::E0200}, \text{TimeSliceBoundaryBreach}) \in \mathcal{D}_{\text{sink}} \\
(\kappa_P = \text{PortionKind::EventOccurrence} \wedge \neg \Phi_{\text{event\_valid}}(O, t_e, \Phi_{\text{trigger}})) &\implies \text{Diagnostic}(P, \text{DiagnosticCode::E0200}, \text{InvalidEventOccurrence}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
```

Diagnostic Taxonomy Containment Invariant: All diagnostics emitted by the portion lowering engine strictly belong to the Metamodel and Typing family and Ingestion error limit family:

```math
\forall d \in \mathcal{D}_{\text{portion}}, \quad \text{code}(d) \in \{ \text{DiagnosticCode::E0200}, \text{DiagnosticCode::E0199} \} \subset \mathcal{E}_{\text{type}} \cup \mathcal{E}_{\text{ingest}}
```

#### 3. Computational Complexity & Algorithmic Bounds

Lowering and validating occurrence portioning operators, snapshots, time slices, and event occurrences executes strictly within Complexity Class $`\mathbf{P}`$. The algorithmic bounds across operations are formalized as follows:
  1. Portion Allocation & Handle Resolution: Allocating each portion node in contiguous typed bump arena storage and interning its scalar symbol name requires amortized $`O(1)`$` time and `$`O(1)`$ space.
  2. Snapshot Geometric Evaluation: Verifying temporal lifetime containment $`t_{\text{start}}(O) \le t_0 \le t_{\text{end}}(O)`$` requires strictly 2 scalar floating-point comparisons, executing in deterministic `$`O(1)`$ time.
  3. TimeSlice Interval Evaluation: Validating interval well-formedness ($`t_1 \le t_2`$`) and parent inclusion (`$`t_{\text{start}}(O) \le t_1 \wedge t_2 \le t_{\text{end}}(O)`$`) requires strictly 3 scalar floating-point comparisons, executing in deterministic `$`O(1)`$ time.
  4. EventOccurrence Trigger Typing: Validating that $`\tau(\Phi_{\text{trigger}}) = \text{Boolean}`$` evaluates the root type of the trigger predicate expression in `$`O(1)`$ time.
  5. Geometric Slicing Complexity: Projecting 4D world-volumes onto 1D temporal intervals executes via axis-aligned geometric bounding evaluations in strictly $`O(1)`$ time per portion node.
  6. Transitive Portion Hierarchy Verification: Checking nested containment across hierarchical portions is bounded by tree depth $`h \le 32 = O(1)`$`, executing in `$`O(1)`$ time.
  7. Aggregate Verification Bounds: For an AST containing $`N_{\text{occ}} = |\mathcal{V}_{\text{occ}}|`$` occurrence nodes and `$`N_{\text{portion}} = |\mathcal{V}_{\text{portion}}|`$ portion nodes:

```math
T(N_{\text{portion}}) = \sum_{P \in \mathcal{V}_{\text{portion}}} O(1) = O(N_{\text{portion}})
```

  8. Parallel Work-Stealing Scaling (Architectural Directive 2): When portion verification across independent compilation units is scheduled onto a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$:

```math
T_{\text{parallel}}(N_{\text{portion}}, N_{\text{max\_workers}}) \in O\left( \frac{N_{\text{portion}}}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

  9. Space Complexity: Auxiliary heap allocation is strictly bounded by $`O(1)`$` beyond contiguous bump arena storage for AST nodes and the diagnostic sink buffer `$`O(C_{\text{max\_errors}})`$, guaranteeing zero heap churn during the portion lowering pass.

#### 4. Verification & Conformance Criteria

Automated test suites shall deterministically verify compliance against synthetic abstract MBSE models containing abstract placeholders (`Package_0`, `Occurrence_Alpha`, `Occurrence_Beta`, `Portion_0`, `Snapshot_T0`, `Snapshot_T1`, `TimeSlice_Phase1`, `TimeSlice_Phase2`, `EventOccurrence_Ev1`, `param_x : Real`) across the following verification gates:
  1. **Canonical Snapshot Lowering Gate**: Ingest `Occurrence_Alpha` declaring lifetime interval $`[0.0, 100.0]`$; lower `Snapshot_T0` at $`t_0 = 25.0`$`; assert 100% resolution to contiguous arena node handle, temporal duration `$`\Delta t = 0`$`, Lebesgue measure `$`\lambda_t = 0`$, valid UUIDv5 anchor, and zero diagnostics.
  2. **Snapshot Lifetime Breach Gate (`E0200`)**: Declare `Occurrence_Alpha` with lifetime $`[0.0, 100.0]`$; attempt to lower `Snapshot_T1` at $`t_0 = 120.0`$` (`$`t_0 \gt t_{\text{end}}`$`) and at `$`t_0 = -5.0`$` (`$`t_0 \lt t_{\text{start}}`$); assert deterministic compile-time rejection with diagnostic error code `E0200` (`SnapshotOutsideTemporalLifetime`), substitution of error sentinel $`\bot_{\text{portion}}`$, and zero panics.
  3. **Canonical TimeSlice Lowering Gate**: Ingest `Occurrence_Alpha` declaring lifetime $`[0.0, 100.0]`$; lower `TimeSlice_Phase1` over interval $`[10.0, 40.0]`$`; assert valid interval containment `$`[10.0, 40.0] \subseteq [0.0, 100.0]`$`, Lebesgue duration `$`\Delta t = 30.0 \ge 0`$, and zero diagnostics.
  4. **Inverted TimeSlice Interval Rejection Gate (`E0200`)**: Attempt to lower `TimeSlice_Phase2` with inverted interval $`[50.0, 20.0]`$` (`$`t_1 \gt t_2`$); assert deterministic compile-time rejection with diagnostic error code `E0200` (`InvertedTimeSliceInterval`).
  5. **TimeSlice Lifetime Breach Gate (`E0200`)**: Declare `Occurrence_Alpha` with lifetime $`[0.0, 100.0]`$`; attempt to declare a time slice with interval `$`[-10.0, 50.0]`$` (`$`t_1 \lt t_{\text{start}}`$`) or `$`[50.0, 120.0]`$` (`$`t_2 \gt t_{\text{end}}`$); assert deterministic rejection with diagnostic error code `E0200` (`TimeSliceBoundaryBreach`).
  6. **Canonical EventOccurrence Lowering Gate**: Lower `EventOccurrence_Ev1` on `Occurrence_Alpha` at instant $`t_e = 15.0`$ with trigger predicate `param_x > 0.0` typed as `Boolean`; assert instantaneous degeneracy ($`\Delta t = 0`$), temporal inclusion, valid boolean typing, and zero diagnostics.
  7. **EventOccurrence Non-Boolean Trigger & Out-of-Bounds Gate (`E0200`)**: Attempt to lower an event occurrence with trigger expression `param_x + 1.0` (typed as `Real` rather than `Boolean`) or trigger instant $`t_e = 150.0`$; assert deterministic rejection with diagnostic error code `E0200` (`InvalidEventOccurrence`).
  8. **Hierarchical Portioning & Transitivity Gate**: Declare time slice $`P_1`$` over `$`[10.0, 50.0]`$ of `Occurrence_Alpha` ($`[0.0, 100.0]`$`), and sub-portion `$`P_2`$` as a time slice of `$`P_1`$` over `$`[20.0, 30.0]`$`; assert valid nested containment `$`\mathcal{W}(P_2) \subseteq \mathcal{W}(P_1) \subseteq \mathcal{W}(\text{Occurrence\_Alpha})`$`; attempt to declare sub-portion `$`P_3`$` over `$`[20.0, 60.0]`$; assert deterministic rejection with diagnostic code `E0200`.
  9. **Pairwise Snapshot Disjointness Gate**: Lower distinct snapshots `Snapshot_T0` ($`t_0 = 10.0`$) and `Snapshot_T1` ($`t_0 = 20.0`$) of `Occurrence_Alpha`; assert pairwise empty intersection: $`\mathcal{W}(\text{Snapshot\_T0}) \cap \mathcal{W}(\text{Snapshot\_T1}) = \emptyset`$.
  10. **Synchronization Token Recovery & Error Accumulation Gate (Architectural Directive 4)**: Ingest an AST unit containing 6 portion declarations with 3 intentional faults (one out-of-bounds snapshot, one inverted time slice, one ill-typed event trigger); verify that the lowering engine resynchronizes on delimiter boundaries, accumulates all 3 `E0200` diagnostics with precise source spans, binds error sentinel $`\bot_{\text{portion}}`$`, and successfully lowers the 3 valid portions without panicking; when injected faults exceed `$`C_{\text{max\_errors}}`$, assert graceful termination with terminal diagnostic `E0199`.
  11. **Deterministic UUIDv5 Topological Identity Gate (Architectural Directive 1)**: Verify that 100% of lowered portion nodes bind valid RFC 4122 UUIDv5 identifiers computed from compiler namespace OID and portion fully qualified paths, asserting bitwise identical UUIDs and 0-byte diff churn across repeated compilation runs.
  12. **Release Mode Latency & Memory Budget Gate (Architectural Directive 5)**: In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196, benchmark lowering and verification across an AST containing $`10^5`$ synthetic portion constructs (snapshots, time slices, event occurrences); assert total execution latency strictly under 25 ms and peak RSS memory strictly under 100 MB.
