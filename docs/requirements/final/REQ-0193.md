## 1. Normative Statement

Subsystem 11 SHALL parse and mutate CommonMark documents non-destructively via `MarkdownParser_Alpha` and `MutationEngine_0`.

Pipeline MUST enforce:
1. **Contiguous Partitioning**: `MarkdownParser_Alpha` SHALL partition document $``D_{\text{orig}}``$ into contiguous blocks $``\langle B_1, \dots, B_m \rangle``$ with spans $``[b_{\text{start}}(B_i), b_{\text{end}}(B_i))``$ covering $``[0, |D_{\text{orig}}|)``$ without gaps ($``b_{\text{start}}(B_1)=0, b_{\text{end}}(B_m)=|D_{\text{orig}}|, b_{\text{end}}(B_i)=b_{\text{start}}(B_{i+1})``$). Blocks partition into schema blocks $``\mathcal{B}_{\text{schema}}``$ and prose blocks $``\mathcal{B}_{\text{prose}}``$.
2. **Prose Preservation**: For all $``B_i \in \mathcal{B}_{\text{prose}}``$, prose, notes, and formatting SHALL remain byte-for-byte invariant ($``\text{SHA256}(B'_i) \equiv \text{SHA256}(B_i)``$).
3. **In-Place Mutation**: For $``B_i \in \mathcal{B}_{\text{schema}}``$, `MutationEngine_0` SHALL apply delta $``\Delta_{\text{AST}}``$ in place ($``\text{MutateNode}(B_i, \Delta_{\text{AST}})``$) updating schema entities. Spliced document $``D_{\text{updated}}``$ concatenates reconciled blocks in sequence.
4. **Memory-Mapped Diffing**: Engine SHALL inspect path $P$ via memory view $\mathcal{M}(P)$. If on-disk content matches $``D_{\text{updated}}``$, disk writes MUST be bypassed, preserving inode and $\text{mtime}(P, t+1) = \text{mtime}(P, t)$. Divergent files SHALL be written atomically.
5. **Directives**: UUIDv5 anchors via $``\text{OID}_{\text{DEAP}}``$ (Directive 1); work-stealing ceiling $``N_{\text{max\_workers}}``$ (Directive 2); symbol interning (Directive 3); recovery on `#`, `|`, fences, halting at $``C_{\text{max\_errors}}``$ with `E0199` (Directive 4); Release budget ($< 25\text{ ms}$ for $10^4$ blocks, $< 100\text{ MB}$) (Directive 5). Syntax faults emit `E0300`; unauthorized entities emit `E0500`, binding sentinel $``\bot_{\text{block}}``$. Synthetic placeholders (`Package_0`, `Classifier_Alpha`, `Block_0`, `Doc_0`, `param_x : Real`) used.

## 2. Formal Invariant

Parsing, non-destructive reconciliation, and memory-mapped mutation satisfy:

```math
\begin{aligned}
b_{\text{start}}(B_1)=0\land b_{\text{end}}(B_m)=|D_{\text{orig}}|&\land\forall i\in\{1,\dots,m-1\},\ b_{\text{end}}(B_i)=b_{\text{start}}(B_{i+1}) \\
\mathcal{B}_{\text{schema}}\cap\mathcal{B}_{\text{prose}}=\emptyset&\land\mathcal{B}_{\text{schema}}\cup\mathcal{B}_{\text{prose}}=\{B_1,\dots,B_m\} \\
B'_i&=\begin{cases}
\text{MutateNode}(B_i,\Delta_{\text{AST}}),&\text{if }B_i\in\mathcal{B}_{\text{schema}} \\
B_i,&\text{if }B_i\in\mathcal{B}_{\text{prose}}
\end{cases} \\
\forall B_i\in\mathcal{B}_{\text{prose}},\quad\text{raw}(B'_i)\equiv\text{raw}(B_i)&\land\text{SHA256}(B'_i)\equiv\text{SHA256}(B_i) \\
D_{\text{updated}}=\bigoplus_{i=1}^m\text{raw}(B'_i)&=\text{raw}(B'_1)\mathbin{\Vert}\dots\mathbin{\Vert}\text{raw}(B'_m) \\
\text{FileExists}(P)\land\text{FileSize}(P)=|D_{\text{updated}}|&\land\mathcal{M}(P)==D_{\text{updated}}\implies\text{ShouldWrite}(P,D_{\text{updated}})=\text{false} \\
\neg\text{ShouldWrite}(P,D_{\text{updated}})&\implies\text{inode}(P,t+1)=\text{inode}(P,t)\land\text{mtime}(P,t+1)=\text{mtime}(P,t) \\
\text{SyntaxCorrupted}(B_i)&\implies\text{Diagnostic}(B_i,\text{E0300})\in\mathcal{D}_{\text{sink}}\land B_i\gets\bot_{\text{block}} \\
\text{UnauthorizedEntity}(B_i)&\implies\text{Diagnostic}(B_i,\text{E0500})\in\mathcal{D}_{\text{sink}}\land B_i\gets\bot_{\text{block}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}} \\
\Delta(B_i)&=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(B_i)\mathbin{\Vert}\text{"::Block"})
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``D_{\text{orig}}, D_{\text{updated}}, B_i, B'_i``$ | Documents, blocks |
| $``[b_{\text{start}}, b_{\text{end}}), \mathcal{B}_{\text{schema}}, \mathcal{B}_{\text{prose}}``$ | Spans, partitions |
| $``\Delta_{\text{AST}}, \text{MutateNode}``$ | AST delta, mutation |
| $\mathcal{M}(P), \text{ShouldWrite}$ | Memory view, write predicate |
| $\text{inode}(P, t), \text{mtime}(P, t)$ | Inode, mtime |
| $``\bot_{\text{block}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Sentinel, sink, limit |
| $``\Delta(B_i), \text{OID}_{\text{DEAP}}, \text{FQN}``$ | UUIDv5, OID, FQN |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$.
- **Asymptotic Bound:** $``O(|D_{\text{orig}}|)``$ non-destructive parsing and mutation time for document size $``|D_{\text{orig}}|``$. Block partitioning and prose hashing take $``O(|D_{\text{orig}}|)``$. AST mutation takes $``O(|\mathcal{B}_{\text{schema}}| + |\Delta_{\text{AST}}|)``$. Work-stealing scales as $``O(|D_{\text{orig}}| / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Arena memory is $``O(|D_{\text{orig}}| + |\mathcal{B}|)``$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Bypasses NP-1 (REQ-0117), NP-2 (REQ-0147), and NP-8 (REQ-0197) via linear partitioning and in-place AST mutation.

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: Schema Block In-Place Mutation
- **Given:** Document `Doc_0` with `Block_0` containing `Classifier_Alpha`.
- **When:** `MutationEngine_0` applies delta $``\Delta_{\text{AST}}``$ renaming to `Classifier_Beta`.
- **Then:** Mutates attributes in place, preserving layout, partition, and UUIDv5 anchors.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Byte-for-Byte Prose Preservation
- **Given:** Document `Doc_0` with schema blocks and unmapped prose `Block_1`.
- **When:** `MutationEngine_0` reconciles AST updates.
- **Then:** 100% of prose blocks preserve byte slices and hashes ($``\text{SHA256}(B'_i) \equiv \text{SHA256}(B_i)``$).
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Memory-Mapped Diff Bypass
- **Given:** File at `Path_0` matching $``D_{\text{updated}}``$ byte-for-byte.
- **When:** `MarkdownParser_Alpha` evaluates $``\text{ShouldWrite}(P, D_{\text{updated}})``$.
- **Then:** Evaluates false, bypassing write while preserving inode and timestamp.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-04: Delimiter Syntax Error Recovery
- **Given:** Document `Doc_0` with malformed `|` followed by `## Block_1`.
- **When:** `MarkdownParser_Alpha` parses document streams.
- **Then:** Emits `E0300`, binds $``\bot_{\text{block}}``$, resynchronizes on `##`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.

### AC-05: Unauthorized Entity Rejection
- **Given:** Document `Doc_0` declaring ungrounded `Classifier_Beta` without AST anchor.
- **When:** Executing reconciliation across $``N_{\text{max\_workers}}``$ threads in Release mode (`--release`).
- **Then:** Emits `E0500`, binds $``\bot_{\text{block}}``$; valid runs take $< 25\text{ ms}$ ($10\text{ MB}$) with RSS $< 100\text{ MB}$.
- **Diagnostic:** `E0500`.
