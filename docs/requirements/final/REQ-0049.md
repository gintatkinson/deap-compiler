### REQ-0049: Context-Bounded AST Slicing (`query_slice`) for Token-Isolated Subagents

- **Normative Statement**: The core metamodel, node arena, and AST graph engine of the sovereign compiler shall provide a deterministic, depth-bounded semantic AST slicing facility (`query_slice`) to extract self-contained subgraphs surrounding a specified target element for focused reasoning, code generation, and micro-verification within context-isolated subagent environments. The slicing engine shall accept a target node handle $n_{\text{target}}$, an integer traversal depth bound $k \in \mathbb{N}^+$ ($1 \le k \le k_{\text{max}}$), and an optional boundary expansion policy. The slicing engine shall extract a connected topological neighborhood up to geodesic distance $k$ in the undirected multigraph projection of the AST and compute the complete transitive semantic closure over all referenced classifier definitions, port definitions, item definitions, connection definitions, attribute data types, and numerical constraint declarations.

  The context-bounded AST slicing engine shall enforce the following normative operational guarantees:
  1. Target Validation and Reference Safety: The engine must validate target node handle $n_{\text{target}}$ against the contiguous typed node arena in $O(1)$ constant time using generational validation in accordance with REQ-0035. If $n_{\text{target}}$ represents a stale handle, null sentinel, or out-of-bounds index, or if depth bound $k$ satisfies $k \le 0$ or $k \gt k_{\text{max}}$, the engine shall deterministically record structured diagnostic error code `E0200` per REQ-0191 and return an explicit error result without aborting compilation or panicking.
  2. Metric Neighborhood Traversal: Starting from $n_{\text{target}}$, the engine shall traverse the undirected projection of the AST graph using a bounded breadth-first search to identify all reachable AST nodes at unweighted shortest-path distance $\text{dist}(n_{\text{target}}, v) \le k$.
  3. Transitive Semantic Closure: To ensure standalone compilability, the engine shall compute the semantic closure of the metric neighborhood, transitively incorporating all type definitions, inherited base classifiers, structural interfaces, unit systems, and operational constraints referenced by any node in the neighborhood. Any referenced type or constraint symbol defined outside the metric neighborhood must be included in the slice boundary, guaranteeing zero unresolved symbol references ($\text{UnresolvedSymbols}(\mathcal{G}_{\text{slice}}) = \emptyset$).
  4. Boundary Port Reification and Stub Synthesis: For any topological connection or flow edge crossing the slice boundary between an included node and an excluded external node, the engine shall synthesize a typed boundary port stub that preserves declared port directionality (`in`, `out`, `inout`) per REQ-0038, payload typing per REQ-0039, and contract invariants without dragging in unrelated structural hierarchies.
  5. Context Isolation and Token Reduction Invariant: The serialized token volume of the extracted slice $|\text{Tokens}(\text{Slice}(n_{\text{target}}, k))|$ shall remain strictly bounded relative to the total serialized token volume of the complete model $|\text{Tokens}(\mathcal{A})|$: for localized subgraphs ($k \le 3$), the slice shall satisfy $|\text{Tokens}(\text{Slice}(n_{\text{target}}, k))| \le \alpha \cdot |\text{Tokens}(\mathcal{A})|$ where $\alpha \le 0.15$, guaranteeing high-fidelity context isolation without prompt bloat or irrelevant token overhead.
  6. Deterministic Identifier Preservation: In accordance with Architectural Directive 1 and REQ-0010, every AST node included in the slice must retain its deterministic RFC 4122 UUIDv5 identifier derived from the fixed compiler namespace UUID and its canonical fully qualified path (`Package_0::Classifier_Alpha`).
  7. Thread-Isolated Concurrent Queries: In accordance with Architectural Directive 2 and REQ-0012, parallel AST slicing requests across independent subagent workers shall be scheduled onto a bounded work-stealing thread pool with worker bound $N_{\text{max\_workers}}$, using thread-isolated visited bitsets and scratch traversal buffers without lock contention.
  8. Interned Symbol Preservation: In accordance with Architectural Directive 3 and REQ-0036, all symbol names, type identifiers, and qualified paths in the slice shall reference deduplicated interned strings via scalar `SymbolId` tokens within the global symbol interner pool, which constitutes the sole permitted exception to zero-copy memory management.
  9. Synchronization Token Error Recovery: In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, if an unresolvable type reference or malformed edge is detected during slice traversal, the engine shall record diagnostic error code `E0200`, resynchronize to the next edge, and continue traversal. If accumulated diagnostics reach capacity limit $C_{\text{max\_errors}}$, the compiler shall emit diagnostic error code `E0199` and terminate gracefully.
  10. Deterministic Non-Panicking Contract: In accordance with Architectural Directive 5, REQ-0011, and REQ-0196, the slicing engine shall enforce a deterministic, non-panicking execution contract with total-function termination across all inputs. Performance gates (latency strictly below 25 ms, memory strictly below 100 MB RSS) shall be evaluated exclusively in compiled Release mode (`--release`) under isolated benchmark harnesses. All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Classifier_Alpha`, `Classifier_Beta`, `Part_0`, `Port_1`, `Flow_A`, `param_x : Real`).

- **Formal Invariant**: Let the complete compiled AST model be formalized as a directed multigraph:

$$
\mathcal{G} = (\mathcal{V}, \mathcal{E}, \tau_V, \tau_E)
$$

The symmetric undirected projection $\mathcal{G}_{\text{sym}} = (\mathcal{V}, \mathcal{E}_{\text{sym}})$ is defined by symmetrizing all edges:

$$
\mathcal{E}_{\text{sym}} = \{ \{u, v\} \mid \exists \kappa \in \mathcal{K}_E : (u, v, \kappa) \in \mathcal{E} \;\lor\; (v, u, \kappa) \in \mathcal{E} \}
$$

The geodesic shortest-path distance metric $\text{dist}_{\mathcal{G}} : \mathcal{V} \times \mathcal{V} \to \mathbb{N}_0 \cup \{ \infty \}$ over $\mathcal{G}_{\text{sym}}$ is defined as:

$$
\text{dist}_{\mathcal{G}}(u, v) = \begin{cases}
0, & \text{if } u = v \\
\min \left\{ m \in \mathbb{N} \;\middle|\; \exists \langle w_0, w_1, \dots, w_m \rangle, \, w_0 = u, \, w_m = v, \, \{w_i, w_{i+1}\} \in \mathcal{E}_{\text{sym}} \right\}, & \text{if a path exists} \\
\infty, & \text{otherwise}
\end{cases}
$$

For target node $n_{\text{target}} \in \mathcal{V}$ and depth bound $k \in \mathbb{N}^+$, the metric topological neighborhood $\mathcal{B}_k(n_{\text{target}})$ is defined as:

$$
\mathcal{B}_k(n_{\text{target}}) = \{ v \in \mathcal{V} \mid \text{dist}_{\mathcal{G}}(n_{\text{target}}, v) \le k \}
$$

Let $\text{Ref}(v)$ denote the set of external type definitions, parent classifiers, and constraints directly referenced by node $v$:

$$
\text{Ref}(v) = \{ w \in \mathcal{V} \mid \exists (v, w, \kappa) \in \mathcal{E} : \kappa \in \{ \text{Typing}, \text{Subtyping}, \text{Constraint} \} \}
$$

The semantic closure operator $\text{Closure} : \mathcal{P}(\mathcal{V}) \to \mathcal{P}(\mathcal{V})$ is the least fixed point satisfying:

$$
\text{Closure}(S) = S \cup \bigcup_{v \in S} \text{Closure}(\text{Ref}(v))
$$

The sliced node set $\mathcal{V}_{\text{slice}}$ and edge set $\mathcal{E}_{\text{slice}}$ are formalized as:

$$
\begin{aligned}
\mathcal{V}_{\text{slice}} &= \text{Closure}(\mathcal{B}_k(n_{\text{target}})) = \mathcal{B}_k(n_{\text{target}}) \cup \text{RequiredTypes}(\mathcal{B}_k(n_{\text{target}})) \cup \text{RequiredConstraints}(\mathcal{B}_k(n_{\text{target}})) \\
\mathcal{E}_{\text{slice}} &= \{ (u, v, \kappa) \in \mathcal{E} \mid u \in \mathcal{V}_{\text{slice}} \;\wedge\; v \in \mathcal{V}_{\text{slice}} \}
\end{aligned}
$$

Semantic Closure Invariant (Zero Dangling Internal References):
Every semantic type or constraint dependency referenced by any node in the slice is completely contained within $\mathcal{V}_{\text{slice}}$:

$$
\forall v \in \mathcal{V}_{\text{slice}}, \quad \text{Ref}(v) \subseteq \mathcal{V}_{\text{slice}} \implies \text{UnresolvedSymbols}(\mathcal{G}_{\text{slice}}) = \emptyset
$$

Boundary Port Reification Invariant:
For every connection edge crossing the slice boundary, a typed boundary stub port $v_{\text{stub}}$ is synthesized:

$$
\forall (u, v, \kappa) \in \mathcal{E}, \quad (u \in \mathcal{V}_{\text{slice}} \;\wedge\; v \notin \mathcal{V}_{\text{slice}} \;\wedge\; \kappa = \text{Connection}) \implies \exists v_{\text{stub}} \in \mathcal{V}_{\text{slice}} : \tau_V(v_{\text{stub}}) = \tau_V(v)
$$

Token Reduction Invariant:
Let $\text{Tokens}(\cdot)$ denote the token volume of an AST graph under canonical serialization. For localized subgraphs with depth bound $k \le 3$, the token volume is bounded by ratio $\alpha$:

$$
|\text{Tokens}(\text{Slice}(n_{\text{target}}, k))| \le \alpha \cdot |\text{Tokens}(\mathcal{A})|, \quad \alpha \le 0.15
$$

Deterministic UUIDv5 and Handle Preservation Invariant:
Every node in the extracted slice preserves its immutable UUIDv5 identifier:

$$
\forall v \in \mathcal{V}_{\text{slice}}, \quad \text{UUID}(v) = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(v))
$$

Diagnostic Code Binding Invariant:
Invalid parameters, stale handles, unresolvable references, or diagnostic capacity overflow trigger structured diagnostic error codes in accordance with REQ-0191:

$$
\begin{aligned}
\neg\text{ValidHandle}(n_{\text{target}}, \mathcal{A}_{\text{node}}) &\implies \text{Diagnostic}(n_{\text{target}}, \text{DiagnosticCode::E0200}, \text{InvalidSliceTargetHandle}) \in \mathcal{D}_{\text{sink}} \\
(k \le 0 \;\lor\; k \gt k_{\text{max}}) &\implies \text{Diagnostic}(n_{\text{target}}, \text{DiagnosticCode::E0200}, \text{InvalidSliceDepthBound}) \in \mathcal{D}_{\text{sink}} \\
\exists w \in \text{Ref}(\mathcal{V}_{\text{slice}}) \text{ s.t. } w \notin \mathcal{V} &\implies \text{Diagnostic}(w, \text{DiagnosticCode::E0200}, \text{UnresolvableTypeReference}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

- **Computational Complexity & Algorithmic Bounds**: Context-bounded AST slice extraction executes strictly within Complexity Class $\mathbf{P}$. The algorithmic operations and asymptotic bounds are formalized as follows:
  1. Target Node Handle Dereferencing: Generational handle validation and bounds verification for $n_{\text{target}}$ executes in $O(1)$ constant time with zero heap allocations.
  2. Bounded Breadth-First Search Traversal: For a depth bound $k \le k_{\text{max}}$, the BFS traversal on the undirected multigraph projection visits only vertices within the ball $\mathcal{B}_k(n_{\text{target}})$. For visited subgraph size $V_k = |\mathcal{B}_k(n_{\text{target}})|$ and incident edge count $E_k$, traversal time is strictly bounded by:

$$
T_{\text{BFS}}(k) \in O(V_k + E_k)
$$

  3. Semantic Closure Computation: Transitive closure over referenced types and constraint definitions evaluates each referenced handle in $O(1)$ arena lookup time. For closure size $V_{\text{closure}} = |\mathcal{V}_{\text{slice}} \setminus \mathcal{B}_k(n_{\text{target}})|$ and average reference fan-out $\bar{d}_{\text{ref}}$, closure evaluation time satisfies:

$$
T_{\text{closure}} \in O(|V_{\text{closure}}| \cdot \bar{d}_{\text{ref}}) \subseteq O(|\mathcal{V}_{\text{slice}}|)
$$

  4. Total Slice Extraction Bound: Total execution time for `query_slice` is strictly linear in the size of the extracted slice:

$$
T_{\text{slice}} = T_{\text{BFS}} + T_{\text{closure}} \in O(|\mathcal{V}_{\text{slice}}| + |\mathcal{E}_{\text{slice}}|) \ll O(|\mathcal{V}| + |\mathcal{E}|)
$$

  5. Concurrent Slicing Throughput: When $M$ slicing queries are processed concurrently across $N_{\text{max\_workers}}$ threads in the bounded work-stealing thread pool:

$$
T_{\text{parallel}} \in O\left( \frac{\sum_{i=1}^M (|\mathcal{V}_{\text{slice}, i}| + |\mathcal{E}_{\text{slice}, i}|)}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  6. Auxiliary Space Complexity: Traversal scratch space requires $O(|\mathcal{V}_{\text{slice}}|)$ memory for the BFS queue and visited handle bitset. Output subgraph construction requires $O(|\mathcal{V}_{\text{slice}}| + |\mathcal{E}_{\text{slice}}|)$ contiguous slot allocations within a dedicated sub-arena segment, requiring zero dynamic pointer rebasing.

- **Verification & Conformance Criteria**: Automated test suites shall deterministically verify compliance against synthetic abstract MBSE models (e.g., `Package_0`, `Classifier_Alpha`, `Classifier_Beta`, `Part_0`, `Port_1`, `Flow_A`, `param_x : Real`) across the following verification gates:
  1. Depth-Bounded Traversal Gate: Ingest a hierarchical synthetic model with a 6-level containment tree (`Package_0` down to `Part_5`). Execute `query_slice` targeting a mid-level node with depth bounds $k = 1, 2, 3$. Assert that the extracted neighborhood contains strictly those nodes with $\text{dist}(n_{\text{target}}, v) \le k$, and that nodes at distance $d \gt k$ without direct semantic dependencies are strictly excluded.
  2. Semantic Closure & Standalone Compilability Gate: Target component `Classifier_Alpha` referencing custom value type `DataType_Sigma` and constraint `Constraint_Alpha` located outside the metric neighborhood. Assert that both `DataType_Sigma` and `Constraint_Alpha` are transitively included in the slice. Pass the extracted slice into an isolated compiler subagent; assert that the slice parses, type-checks, and validates with zero unresolved symbol diagnostics.
  3. Boundary Port Reification Gate: Sift an interconnected assembly where `Port_1` connects to external component port `Port_External`. Assert that the slicing engine synthesizes boundary stub `Port_Stub` preserving declared directionality (`in`, `out`, `inout`) and payload type handle, while excluding `Port_External`'s parent component hierarchy.
  4. Token Volume Reduction Gate: Benchmark serialization of an extracted slice ($k = 2$) against a synthetic model containing $10^4$ AST nodes. Assert that the serialized token count satisfies $|\text{Tokens}(G_{\text{slice}})| \le 0.15 \cdot |\text{Tokens}(\mathcal{A})|$, confirming token reduction and context isolation.
  5. Diagnostic Error Code Binding & Recovery Gate:
     - Invoke `query_slice` with an invalid node handle (stale generation or out-of-bounds index); assert deterministic emission of diagnostic error code `E0200` (`InvalidSliceTargetHandle`).
     - Invoke `query_slice` with invalid depth bound $k = 0$ or $k = 256 \gt k_{\text{max}}$; assert deterministic emission of diagnostic error code `E0200` (`InvalidSliceDepthBound`).
     - Inject an unresolvable type reference in an AST node; assert deterministic emission of diagnostic error code `E0200` (`UnresolvableTypeReference`).
     - Exceed diagnostic sink capacity $C_{\text{max\_errors}}$; assert graceful termination with diagnostic error code `E0199`.
  6. Deterministic UUIDv5 Anchor Gate: Verify that 100% of nodes in the extracted slice preserve their deterministic RFC 4122 UUIDv5 identifiers computed from namespace OID and canonical fully qualified paths per Directive 1 and REQ-0010.
  7. Bounded Work-Stealing Parallelism Gate: Execute 100 concurrent `query_slice` operations across a thread pool bounded by $N_{\text{max\_workers}}$ worker threads. Assert thread safety, zero data races, thread-isolated scratch memory, and 100% identical slice results.
  8. Release Mode Performance & Memory Gate: In compiled Release mode (`--release`) under isolated benchmark harnesses per Directive 5 and REQ-0196, assert that `query_slice` extraction latency is strictly below 25 ms and memory consumption is strictly below 100 MB RSS for an AST model containing $10^6$ nodes.
  9. Bitwise Determinism & Zero Diff Churn Gate: Assert 0-byte diff churn across repeated slice extractions from identical AST inputs.
