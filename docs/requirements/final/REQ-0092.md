### REQ-0092: Canonical Scalar Type Lowering & Precision Preservation

- **Normative Statement**: The KerML metamodel lowering engine and semantic type checker of Subsystem 4 shall formalize primitive scalar types from the KerML `ScalarValues` package (`Boolean`, `Integer`, `Real`, `String`) and their standard numeric subtypes (`Natural`, `Positive`) into canonical target machine representations, preserving semantic value precision, exact integer boundaries, and IEEE 754-2019 binary64 floating-point semantics.

  The lowering engine shall strictly enforce the following structural, semantic, and typing invariants during scalar type lowering and literal evaluation:
  1. **Canonical Target Machine Representations & Value Domains**:
     - `ScalarValues::Boolean` shall map to the canonical 1-bit boolean domain $`\mathbb{B} = \{ \text{false}, \text{true} \}`$, represented in target storage as an 8-bit unsigned byte with values `0x00` (`false`) and `0x01` (`true`).
     - `ScalarValues::Integer` shall map to the exact 64-bit two's complement signed integer domain $`\mathbb{Z}_{64} = [-2^{63}, 2^{63}-1]`$, spanning from $`-9{,}223{,}372{,}036{,}854{,}775{,}808`$ to $`+9{,}223{,}372{,}036{,}854{,}775{,}807`$ inclusive.
     - `ScalarValues::Natural` shall specialize `ScalarValues::Integer` and map to the non-negative integer domain $`\mathbb{N}_0 = [0, 2^{63}-1]`$.
     - `ScalarValues::Positive` shall specialize `ScalarValues::Natural` and map to the strictly positive integer domain $`\mathbb{Z}^+ = [1, 2^{63}-1]`$.
     - `ScalarValues::Real` shall map to the IEEE 754-2019 double-precision floating-point domain $`\mathbb{R}_{64}`$ (`binary64`), with 53 bits of significand precision (including the implicit leading bit), 11 bits of exponent, signed zeros ($`\pm 0.0`$), subnormal numbers, positive and negative infinities ($`\pm\infty`$), and quiet NaN representations.
     - `ScalarValues::String` shall map to an immutable, interned UTF-8 string token `SymbolId` registered within the global deduplicated symbol interner pool in accordance with REQ-0036.
  2. **Lexical Parsing & Literal Precision Preservation**:
     - *Boolean Literals*: The parser shall recognize exact literal tokens `true` and `false`. Any other lexical token in boolean context shall be rejected at compile time with diagnostic error code `E0200`.
     - *Integer Literals*: The parser shall ingest decimal, hexadecimal (`0x` / `0X`), binary (`0b` / `0B`), and octal (`0o` / `0O`) integer notations, permitting ASCII underscore (`_`) digit separators. The lowering engine shall compute the exact mathematical integer value and assert that it falls strictly within the interval $`[-2^{63}, 2^{63}-1]`$. Any integer literal whose value exceeds this interval shall be rejected at compile time with diagnostic error code `E0200` (`IntegerLiteralOverflow`).
     - *Real Literals*: The parser shall ingest decimal floating-point representations with optional fractional parts, scientific exponent notation (`e` / `E`), and optional underscore digit separators. Floating-point conversion to IEEE 754 `binary64` shall employ exact decimal-to-binary conversion using round-to-nearest-even (ties to even) semantics without intermediate rounding or double-rounding artifacts. Special literals for positive infinity (`Infinity`), negative infinity (`-Infinity`), and quiet not-a-number (`NaN`) shall lower directly to their IEEE 754 bitwise representations. Malformed floating-point literal syntax shall be rejected with diagnostic error code `E0200` (`InvalidRealLiteralSyntax`).
     - *String Literals*: The parser shall ingest double-quoted string literals containing valid UTF-8 sequences and standard escape characters (`\n`, `\t`, `\r`, `\"`, `\\`, and unicode code point escapes `\u{...}`). The lowering engine shall validate UTF-8 byte sequences, reject invalid byte encodings or malformed escape sequences with diagnostic error code `E0200` (`InvalidStringLiteralEncoding`), and register deduplicated string tokens into the global symbol interner pool.
  3. **Subtyping Lattice & Coercion Invariants**:
     - The primitive numeric subtyping partial order shall enforce the total order chain:

$$
\text{Positive} \le \text{Natural} \le \text{Integer} \le \text{Real}
$$

     - *Monotonic Widening Promotion*: Implicit subtype widening conversions along the numeric subtyping chain shall be permitted without explicit casting. When an expression of type $`\text{Positive}`$ is supplied where $`\text{Natural}`$, $`\text{Integer}`$, or $`\text{Real}`$ is required, or where $`\text{Natural}`$ or $`\text{Integer}`$ is supplied where $`\text{Real}`$ is required, the compiler shall insert a monotonic widening injection $`\iota`$.
     - *Integer-to-Real Precision Preservation*: For any integer $`n \in \mathbb{Z}_{64}`$ promoted to $`\mathbb{R}_{64}`$, the promotion shall be exact whenever $`|n| \le 2^{53} = 9{,}007{,}199{,}254{,}740{,}992`$. For integers $`|n| \gt 2^{53}`$, the promotion shall perform deterministic round-to-nearest-even projection according to IEEE 754-2019 without compiler panics.
     - *Prohibition of Implicit Narrowing*: Implicit demotion or narrowing conversions -- including `Real` to `Integer`, `Integer` to `Natural`, `Integer` to `Positive`, or `Natural` to `Positive` -- shall be strictly prohibited. Attempting to assign or pass a wider numeric type to a narrower parameter without an explicit conversion operator or bounds check shall be rejected at compile time with diagnostic error code `E0200` (`IncompatibleScalarCoercion`).
     - *Orthogonal Scalar Disjointness*: The scalar types `Boolean`, `String`, and the numeric hierarchy (`Real`, `Integer`, `Natural`, `Positive`) shall be mutually disjoint:

$$
\llbracket \text{Boolean} \rrbracket \cap \llbracket \text{Real} \rrbracket = \emptyset, \quad \llbracket \text{String} \rrbracket \cap \llbracket \text{Real} \rrbracket = \emptyset, \quad \llbracket \text{Boolean} \rrbracket \cap \llbracket \text{String} \rrbracket = \emptyset
$$

       Implicit coercion between `Boolean`, `String`, and numeric types shall be strictly forbidden, emitting diagnostic error code `E0200` (`IncompatibleScalarCoercion`).
  4. **Contiguous Bump Arena Storage & Handle Addressing**:
     - All lowered scalar type definitions, primitive type descriptor nodes, and scalar literal AST nodes shall be stored sequentially in contiguous bump arena storage in accordance with REQ-0009 and REQ-0034.
     - Every scalar node shall be referenced via a stable 32-bit arena node handle in accordance with REQ-0035, ensuring reference safety without pointer indirection.
  5. **Architectural Directives Compliance**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every lowered scalar type definition, primitive classifier descriptor, and literal expression AST node shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical compiler namespace OID and its fully qualified topological path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))`$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel lowering, expression parsing, literal evaluation, and subtyping checks of scalar attributes across independent packages shall execute exclusively on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: Copying string bytes from the source file buffer into the global symbol interner pool for scalar `String` literal tokens and `SymbolId` tokens during the initial lexical pass is the sole permitted exception to zero-copy memory management in accordance with REQ-0036.
     - *Directive 4 (Synchronization Token Error Recovery)*: The scalar parser and type checker shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). Upon encountering malformed scalar literals, integer range overflow, invalid UTF-8 encodings, or illegal scalar coercions (`E0200`), the engine shall record the diagnostic into the preallocated error sink buffer $`\mathcal{D}_{\text{sink}}`$, substitute typed error sentinels $`\bot_{\text{scalar}}`$, and resynchronize on the next declaration delimiter without aborting compilation. If accumulated diagnostics reach $`C_{\text{max\_errors}}`$, the compiler shall emit terminal diagnostic `E0199` and halt gracefully in accordance with REQ-0013 and REQ-0016.
     - *Directive 5 (Panic-Free Release Isolation)*: The scalar lowering and precision preservation engine shall enforce a deterministic, non-panicking execution contract with total-function error handling across all valid and invalid inputs. Performance latency ($`\lt 25\text{ ms}`$) and peak memory RSS ($`\lt 100\text{ MB}`$ for $`10^5`$ scalar operations) performance gates shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `PartDef_Alpha`, `param_x : Real`, `val_b : Boolean`, `val_i : Integer`, `val_r : Real`, `val_s : String`, `val_nat : Natural`, `val_pos : Positive`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $`\mathcal{V}_{\text{AST}}`$ denote the universe of allocated AST nodes in contiguous bump arena storage. Let $`\mathcal{T}_{\text{scalar}} \subset \mathcal{T}`$ denote the set of primitive scalar classifier types:

$$
\mathcal{T}_{\text{scalar}} = \{ \text{Boolean}, \text{Positive}, \text{Natural}, \text{Integer}, \text{Real}, \text{String} \} \subset \mathcal{T}
$$

  The primitive numeric subtyping lattice enforces the total order:

$$
\text{Positive} \le \text{Natural} \le \text{Integer} \le \text{Real}
$$

  The canonical target machine representations and value domains are defined by the denotational semantic mapping $`\llbracket \cdot \rrbracket`$:

$$
\begin{aligned}
\llbracket \text{ScalarValues::Boolean} \rrbracket &\longleftrightarrow \mathbb{B} = \{ \text{false}, \text{true} \} \\
\llbracket \text{ScalarValues::Positive} \rrbracket &\longleftrightarrow \mathbb{Z}^+ = [1, 2^{63}-1] \\
\llbracket \text{ScalarValues::Natural} \rrbracket &\longleftrightarrow \mathbb{N}_0 = [0, 2^{63}-1] \\
\llbracket \text{ScalarValues::Integer} \rrbracket &\longleftrightarrow \mathbb{Z}_{64} = [-2^{63}, 2^{63}-1] \\
\llbracket \text{ScalarValues::Real} \rrbracket &\longleftrightarrow \mathbb{R}_{64} \quad (\text{IEEE 754-2019 binary64}) \\
\llbracket \text{ScalarValues::String} \rrbracket &\longleftrightarrow \text{SymbolId} \quad (\text{Interned UTF-8})
\end{aligned}
$$

  Orthogonal Disjointness Invariant: The scalar families are mutually disjoint:

$$
\begin{aligned}
\llbracket \text{Boolean} \rrbracket \cap \llbracket \text{Real} \rrbracket &= \emptyset \\
\llbracket \text{String} \rrbracket \cap \llbracket \text{Real} \rrbracket &= \emptyset \\
\llbracket \text{Boolean} \rrbracket \cap \llbracket \text{String} \rrbracket &= \emptyset
\end{aligned}
$$

  Each lowered scalar literal expression node $`v \in \mathcal{V}_{\text{scalar}} \subset \mathcal{V}_{\text{AST}}`$ is formalized as a 5-tuple:

$$
v = \langle \text{id}_v, \tau_v, \text{val}_v, \Delta_v, \text{span}_v \rangle
$$

  where:

$$
\begin{aligned}
\text{id}_v &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
\tau_v &\in \mathcal{T}_{\text{scalar}} \quad (\text{authoritative scalar type classifier}) \\
\text{val}_v &\in \mathbb{B} \cup \mathbb{Z}_{64} \cup \mathbb{R}_{64} \cup \text{SymbolId} \quad (\text{canonical target representation}) \\
\Delta_v &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_v &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
\end{aligned}
$$

  Monotonic Widening Injection Invariant: For any subtyping relationship $`A \le B`$, there exists a unique monotonic widening injection $`\iota_{A \hookrightarrow B} : \llbracket A \rrbracket \hookrightarrow \llbracket B \rrbracket`$:

$$
\forall A, B \in \mathcal{T}_{\text{scalar}}, \quad A \le B \implies \exists ! \iota_{A \hookrightarrow B} : \llbracket A \rrbracket \hookrightarrow \llbracket B \rrbracket
$$

  Exact Integer-to-Real Promotion Invariant: Promoting an integer $`n \in \mathbb{Z}_{64}`$ to $`\mathbb{R}_{64}`$ is strictly lossless for magnitudes within the 53-bit significand capacity:

$$
\forall n \in \mathbb{Z}_{64}, \quad |n| \le 2^{53} \implies \text{float64}(n) = n
$$

  For integer magnitudes $`|n| \gt 2^{53}`$, the promotion satisfies IEEE 754-2019 round-to-nearest-even precision bounds:

$$
\forall n \in \mathbb{Z}_{64}, \quad |n| \gt 2^{53} \implies |\text{float64}(n) - n| \le \frac{1}{2} \text{ulp}(n)
$$

  Prohibition of Implicit Narrowing and Incompatible Coercion Invariant:

$$
\forall \tau_1, \tau_2 \in \mathcal{T}_{\text{scalar}}, \quad \tau_1 \not\le \tau_2 \implies \text{Coerce}(\tau_1, \tau_2) = \bot_{\text{scalar}}
$$

  Deterministic RFC 4122 UUIDv5 Anchor Invariant (Architectural Directive 1): Every lowered scalar type node and literal expression receives an immutable deterministic UUIDv5 identifier:

$$
\forall v \in \mathcal{V}_{\text{scalar}}, \quad \Delta_v = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(v))
$$

  Diagnostic Trigger Rules: In accordance with REQ-0191, scalar semantic violations deterministically emit structured diagnostic records:

$$
\begin{aligned}
\text{parsed\_int}(l) \notin [-2^{63}, 2^{63}-1] &\implies \text{Diagnostic}(l, \text{DiagnosticCode::E0200}, \text{IntegerLiteralOverflow}) \in \mathcal{D}_{\text{sink}} \\
\text{type}(e) \not\le \text{target\_type} &\implies \text{Diagnostic}(e, \text{DiagnosticCode::E0200}, \text{IncompatibleScalarCoercion}) \in \mathcal{D}_{\text{sink}} \\
\neg \text{valid\_utf8}(s) &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0200}, \text{InvalidStringLiteralEncoding}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

- **Computational Complexity & Algorithmic Bounds**: Lowering, parsing, subtyping verification, and coercion evaluation of primitive scalar types and literal expressions execute strictly within Complexity Class $`\mathbf{P}`$.

  1. *Algorithmic Bound NP-3 Integration*: In arbitrary partially ordered sets, subtyping satisfiability and multiple inheritance feature redefinition is NP-complete (NP-3). The KerML primitive scalar hierarchy is restricted to a finite total order chain $`\text{Positive} \le \text{Natural} \le \text{Integer} \le \text{Real}`$ of height 4, together with orthogonal singletons $`\text{Boolean}`$ and $`\text{String}`$. Consequently, subtyping queries ($`\tau_1 \le \tau_2`$) and least upper bound evaluations ($`\tau_1 \vee \tau_2`$) execute in deterministic $`O(1)`$ constant time via direct ordinal integer comparisons or a static $`6 \times 6`$ subtyping lookup matrix, completely eliminating search and backtracking.
  2. *Scalar Literal Parsing*:
     - Boolean literal parsing evaluates two static token variants in $`O(1)`$ time.
     - Integer literal parsing traverses at most 64 digit characters, evaluating mathematical value and range boundaries in $`O(1)`$ constant time.
     - Real literal parsing converts decimal strings into IEEE 754 `binary64` using exact round-to-nearest-even algorithms in bounded $`O(1)`$ time per literal.
     - String literal parsing validates UTF-8 byte sequences in $`O(L)`$ time, where $`L`$ is the byte length of the literal, and interns the deduplicated token in amortized $`O(1)`$ hash table lookup time in accordance with REQ-0036.
  3. *Aggregate Compilation Unit Complexity*: For an abstract MBSE model compilation unit containing $`N`$ scalar declarations, feature usages, and literal expressions:

$$
T_{\text{total}}(N) \in O(N)
$$

  4. *Parallel Work-Stealing Scaling (Architectural Directive 2)*: When $`N`$ scalar expressions distributed across independent packages are lowered concurrently on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$:

$$
T_{\text{parallel}}(N, N_{\text{max\_workers}}) \in O\left( \frac{N}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  5. *Space Complexity & Memory Bounds*: Contiguous bump arena storage for scalar AST nodes requires strictly $`O(N)`$ memory. String character bytes stored in the global deduplicated symbol interner pool require $`O(S)`$ auxiliary space, where $`S`$ is the total number of unique string bytes across all compilation units. The preallocated diagnostic error sink buffer is strictly bounded by $`O(C_{\text{max\_errors}}) = O(1)`$ memory.

- **Verification & Conformance Criteria**: Automated test suites shall deterministically verify compliance against synthetic abstract MBSE models (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `PartDef_Alpha`, `param_x : Real`, `val_b : Boolean`, `val_i : Integer`, `val_r : Real`, `val_s : String`, `val_nat : Natural`, `val_pos : Positive`) across the following verification gates:

  1. **Canonical Boolean Lowering Gate**: Declare `val_b : Boolean = true;` and `val_b2 : Boolean = false;` in `Package_0`. Assert that the lowered AST nodes map to $`\mathbb{B}`$, bind canonical byte representations `0x01` and `0x00`, allocate in contiguous bump arena storage, and emit zero diagnostics.
  2. **Canonical Integer Lowering & Boundary Gate**: Declare integer attributes with boundary values $`-9223372036854775808`$ ($`-2^{63}`$) and $`9223372036854775807`$ ($`2^{63}-1`$). Assert exact 64-bit two's complement preservation, zero bit distortion, and successful validation with zero diagnostics.
  3. **Integer Literal Overflow Detection Gate (`E0200`)**: Attempt to declare an integer literal exceeding 64-bit signed bounds: `val_i : Integer = 9223372036854775808;` or `val_i : Integer = -9223372036854775809;`. Assert deterministic compile-time rejection with diagnostic error code `E0200` (`IntegerLiteralOverflow`), substitution of error sentinel $`\bot_{\text{scalar}}`$, and zero panics.
  4. **Natural and Positive Subtyping Specialization Gate**: Declare `val_nat : Natural = 0;` and `val_pos : Positive = 1;`. Assert that `Natural` and `Positive` specialize `Integer`, verify valid non-negative and positive bounds, and assert zero diagnostics. Ingest `val_nat : Natural = -1;` and `val_pos : Positive = 0;` and assert compile-time rejection with diagnostic error code `E0200`.
  5. **Canonical Real Lowering & IEEE 754 Precision Preservation Gate**: Declare real attributes with standard decimal values, scientific exponents, subnormals, and boundary powers of two up to $`2^{53}`$. Assert exact IEEE 754 `binary64` representation, round-to-nearest-even semantics, exact preservation of $`|n| \le 2^{53}`$, and correct bit patterns for `Infinity`, `-Infinity`, and `NaN`.
  6. **Canonical String Lowering & UTF-8 Interning Gate (Architectural Directive 3)**: Ingest string literals containing multi-byte UTF-8 code points and escape sequences (`\n`, `\t`, `\"`, `\\`). Assert that string bytes are interned into the deduplicated global symbol interner pool per REQ-0036, returning identical 32-bit `SymbolId` tokens for identical literal contents, while non-string AST allocations remain strictly zero-copy.
  7. **Monotonic Numeric Subtyping Widening Gate**: Declare an attribute of type `Real` initialized with a `Positive` literal: `param_x : Real = 42;`. Assert that the lowering engine inserts a valid widening injection $`\iota`$, promotes the value to `42.0` in $`\mathbb{R}_{64}`$ without diagnostic emission, and confirms $`\text{Positive} \le \text{Natural} \le \text{Integer} \le \text{Real}`$.
  8. **Implicit Narrowing & Incompatible Coercion Rejection Gate (`E0200`)**: Attempt to pass an expression of type `Real` to a parameter expecting `Integer`: `param_y : Integer = 3.14159;`. Assert deterministic rejection at compile time with diagnostic error code `E0200` (`IncompatibleScalarCoercion`), binding error sentinel $`\bot_{\text{scalar}}`$, and preserving compiler stability.
  9. **Orthogonal Scalar Disjointness Enforcement Gate (`E0200`)**: Attempt cross-family assignments between disjoint scalar types: `val_b : Boolean = 1;`, `val_i : Integer = "100";`, or `val_s : String = false;`. Assert deterministic rejection for all cases with diagnostic error code `E0200` (`IncompatibleScalarCoercion`).
  10. **NP-3 Algorithmic Tractability Benchmark Gate**: Construct a synthetic benchmark model containing $`10^5`$ scalar attributes, subtyping assertions, and literal expressions across the subtyping chain $`\text{Positive} \le \text{Natural} \le \text{Integer} \le \text{Real}`$. Assert that subtyping checks complete in deterministic $`O(1)`$ time per query and $`O(N)`$ linear time overall, without backtracking or combinatorial explosion.
  11. **Synchronization Token Error Recovery Gate (Architectural Directive 4)**: Ingest a compilation unit containing 5 distinct malformed scalar declarations (integer overflow, invalid float syntax, invalid UTF-8 escape, implicit narrowing, and disjoint cross-family coercion) interspersed with valid code. Verify that the lowering engine resynchronizes on statement delimiters (`;`), records all 5 `E0200` diagnostics with precise source byte spans, and halts gracefully with terminal diagnostic `E0199` when the error count reaches $`C_{\text{max\_errors}}`$.
  12. **Deterministic RFC 4122 UUIDv5 Anchor Gate (Architectural Directive 1)**: Verify that 100% of lowered scalar type definitions, primitive descriptors, and literal AST nodes receive deterministic RFC 4122 UUIDv5 identifiers derived from the compiler namespace OID and fully qualified topological path, ensuring 0-byte diff churn across consecutive compilation runs.
  13. **Bounded Work-Stealing Parallelism Gate (Architectural Directive 2)**: Ingest a model with 50 packages containing $`10^5`$ scalar attributes lowered across $`N_{\text{max\_workers}}`$ threads in the bounded work-stealing pool; assert thread isolation, data-race freedom, and identical AST topology compared to single-threaded execution.
  14. **Release Mode Latency & Memory Budget Gate (Architectural Directive 5)**: In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196, assert that lowering and verifying $`10^5`$ synthetic scalar declarations executes in under 25 ms, peak RSS memory remains strictly under 100 MB, and consecutive compilation runs exhibit bitwise determinism with 0-byte diff churn.
