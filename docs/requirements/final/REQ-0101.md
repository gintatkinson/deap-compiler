### REQ-0101: Static Dimensional Homogeneity Validation for Additive Expressions ($A \\pm B$)

- **Normative Statement**: The semantic metrology validation engine and static type checker of Subsystem 5 shall enforce strict dimensional homogeneity on all additive expressions ($A + B$, $A - B$), comparative and relational expressions ($A == B$, $A \ne B$, $A \lt B$, $A \le B$, $A \gt B$, $A \ge B$), boundary and extremum expressions ($\min(A, B)$, $\max(A, B)$, $\text{clamp}(X, A, B)$), and branch-selected conditional expressions ($\text{if } C \text{ then } A \text{ else } B$) across all abstract syntax tree (AST) nodes. The type checker shall require all participating operand terms to possess identically equal dimensional exponent vectors in the 7-dimensional rational vector space $\mathbb{Q}^7$ over the International System of Quantities (ISQ) base dimensions.

  Specifically, the metrology type-checking pipeline shall strictly enforce the following structural, semantic, and algebraic invariants:
  1. **Seven-Dimensional Rational Vector Space ($\mathbb{Q}^7$) Representation**:
     - Physical dimensions shall be formalized as a 7-dimensional vector space over the field of rational numbers $\mathbb{Q}^7$, whose basis vectors correspond strictly to the seven SI/ISQ base quantities: Mass ($M$), Length ($L$), Time ($T$), Electric Current / Base Flow ($I$), Thermodynamic Temperature ($\Theta$), Amount of Substance ($N$), and Luminous Intensity ($J$).
     - Every physical dimension vector $\mathbf{d} \in \mathbb{Q}^7$ shall be represented as an exact rational 7-tuple $(\alpha, \beta, \gamma, \delta, \epsilon, \zeta, \eta)$ where each exponent coordinate is an irreducible fraction $\frac{p_i}{q_i}$ ($p_i \in \mathbb{Z}$, $q_i \in \mathbb{Z}^+$, $\gcd(|p_i|, q_i) = 1$).
     - The zero vector $\mathbf{0} = (0, 0, 0, 0, 0, 0, 0) \in \mathbb{Q}^7$ shall represent pure dimensionless scalar quantities.
     - Fractional rational exponents shall be natively supported to validate intermediate fractional dimensional quantities (such as specific speeds, fracture toughness, and diffusion coefficients) without loss of precision. Floating-point approximations in dimensional exponents are strictly prohibited.
  2. **Additive Expression Homogeneity Invariant ($A + B$, $A - B$)**:
     - For any binary additive operation $E = A + B$ or $E = A - B$, the type checker shall evaluate the inferred dimensional vectors $\mathbf{d}_A, \mathbf{d}_B \in \mathbb{Q}^7$ of the left and right operand expressions.
     - Dimensional Homogeneity Requirement: Operands $A$ and $B$ must possess identically equal dimensional vectors: $\mathbf{d}_A \equiv \mathbf{d}_B$.
     - Resulting Dimension: The resulting expression node $E$ shall inherit the exact dimensional vector of its operands: $\mathbf{d}_{A \pm B} = \mathbf{d}_A = \mathbf{d}_B$.
     - Unary Additive Operations: Unary plus ($+A$) and unary minus ($-A$) shall preserve operand dimensionality identically: $\mathbf{d}_{+A} = \mathbf{d}_{-A} = \mathbf{d}_A$.
  3. **Comparative and Relational Expression Homogeneity Invariant**:
     - For all relational equality and ordering comparison operators ($A == B$, $A \ne B$, $A \lt B$, $A \le B$, $A \gt B$, $A \ge B$), the type checker shall enforce strict dimensional homogeneity: $\mathbf{d}_A \equiv \mathbf{d}_B$.
     - Comparing physical quantities of mismatched dimensions (e.g., comparing length to time or energy to force) shall be deterministically rejected at compile time.
     - Resulting Typing: Relational comparison expressions evaluate to Boolean truth values and shall be assigned the dimensionless identity vector $\mathbf{d}_{A \sim B} = \mathbf{0} \in \mathbb{Q}^7$.
  4. **Conditional, Extremum, and Aggregation Expressions**:
     - Conditional Expressions ($\text{if } C \text{ then } A \text{ else } B$ or ternary $C \,?\, A : B$): The condition predicate $C$ must evaluate to Boolean (dimensionless $\mathbf{0}$), and the consequence branch $A$ and alternative branch $B$ must possess identically equal dimensional vectors ($\mathbf{d}_A \equiv \mathbf{d}_B$). The resulting expression dimension is $\mathbf{d}_A$.
     - Extremum Functions ($\min(A, B)$, $\max(A, B)$, $\text{clamp}(X, A, B)$): All quantity arguments must possess identically equal dimensional vectors: $\mathbf{d}_A \equiv \mathbf{d}_B$ (and $\mathbf{d}_X \equiv \mathbf{d}_A \equiv \mathbf{d}_B$ for clamp). The result dimension equals $\mathbf{d}_A$.
     - Finite Aggregated Sums ($\sum_{i \in I} X_i$): Every summand term $X_i$ across the iteration domain must possess a dimensional vector identically equal to the summation accumulator dimension.
  5. **Commensurability Verification and Exact Rational Unit Conversion**:
     - When operands $A$ and $B$ possess identical dimensional vectors ($\mathbf{d}_A \equiv \mathbf{d}_B$) but are specified with disparate measurement units $u_A \ne u_B$ (e.g., $u_A = \text{metre}$, $u_B = \text{millimetre}$), the compiler shall recognize the operands as commensurable.
     - The compiler shall automatically synthesize an explicit unit conversion scaling node for operand $B$, scaling its numerical value by the exact rational factor $k = \frac{c_B}{c_A} \in \mathbb{Q}^+$ where $c_A$ and $c_B$ are the exact rational conversion scale factors relative to the coherent SI base unit.
     - The resulting expression shall adopt the measurement unit of the left operand $u_A$ (canonical left-operand convention).
     - If $\mathbf{d}_A \not\equiv \mathbf{d}_B$, the operands are incommensurable, and automated unit conversion is mathematically impossible.
  6. **Affine Interval vs. Ratio Scale Additive Semantics**:
     - For physical quantities associated with affine interval scales possessing non-zero additive reference offsets ($o \ne 0$, such as degree Celsius where $o = 273.15\text{ K}$):
       * The addition of two absolute interval quantities ($T_1 + T_2$ where $o_1 \ne 0$ and $o_2 \ne 0$) is physically undefined and shall be rejected at compile time with diagnostic error code `E0300`.
       * The difference between two interval quantities ($T_1 - T_2$ where $o_1 = o_2$) produces a relative temperature difference quantity belonging to a ratio scale with zero offset ($o = 0$).
       * The addition or subtraction of an interval quantity and a ratio-scale relative difference ($T + \Delta T$ or $T - \Delta T$ where $o_T \ne 0$ and $o_{\Delta T} = 0$) produces an interval quantity with offset $o = o_T$.
  7. **Deterministic Diagnostic Error Reporting & Cascade Poisoning Suppression**:
     - Any additive, comparative, conditional, or extremum expression violating dimensional homogeneity ($\mathbf{d}_A \not\equiv \mathbf{d}_B$) shall be deterministically rejected at compile time with diagnostic error code `E0300` (`DimensionalHomogeneityViolation`) in accordance with REQ-0191.
     - The diagnostic record shall bind the primary source byte span of the operator and secondary spans of operands $A$ and $B$, including their inferred 7-dimensional rational exponent vectors and the non-zero difference vector $\Delta \mathbf{d} = \mathbf{d}_A - \mathbf{d}_B \in \mathbb{Q}^7$ highlighting the specific base dimensions where exponents mismatch.
     - The compiler shall assign the typed error dimension sentinel $\bot_{\text{dim}}$ to the invalid expression AST node. Outer expressions consuming an operand typed as $\bot_{\text{dim}}$ shall suppress cascade error emissions, avoiding redundant diagnostic noise.
  8. **Architectural Directives Compliance**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every lowered expression node, synthesized unit conversion node, and diagnostic record shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier hashed from the compiler namespace OID and the node fully qualified topological path ($\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(E))$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel AST traversal, expression type checking, and dimensional homogeneity validation across independent compilation units and package modules shall execute strictly on a bounded work-stealing thread pool with worker bound $N_{\text{max\_workers}}$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: Dimension names, unit symbols, and operator identifier tokens shall be interned into the deduplicated global string interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The metrology parser and semantic type checker shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When dimensional homogeneity violations occur (`E0300`), diagnostics shall accumulate into error sink buffer $\mathcal{D}_{\text{sink}}$, substitute typed error sentinel $\bot_{\text{dim}}$, and continue auditing subsequent expressions. If accumulated diagnostics reach $C_{\text{max\_errors}}$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully in accordance with REQ-0013 and REQ-0016.
     - *Directive 5 (Panic-Free Release Isolation)*: The dimensional analysis pipeline shall enforce a deterministic, non-panicking execution contract with total-function error handling. Performance latency ($\lt 25\text{ ms}$) and peak RSS memory ($\lt 100\text{ MB}$ for $10^5$ expression validations) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Quantity_Alpha`, `Quantity_Beta`, `param_x : Real`, `param_y : Real`, `Unit_Alpha`, `Unit_Beta`, `Dimension_Alpha`, `Dimension_Beta`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $\mathcal{V}_{\text{AST}}$ denote the universe of allocated AST nodes in contiguous bump arena storage, and let $\mathcal{E}_{\text{AST}} \subset \mathcal{V}_{\text{AST}}$ denote the subset of expression AST nodes.

  The 7-dimensional physical quantity dimension space is formalized as a rational vector space over the field $\mathbb{Q}$:

$$
\mathbb{Q}^7 = \{ \mathbf{d} = (\alpha, \beta, \gamma, \delta, \epsilon, \zeta, \eta) \mid \alpha, \beta, \gamma, \delta, \epsilon, \zeta, \eta \in \mathbb{Q} \}
$$

  where the ordered coordinate positions correspond to the canonical basis $\mathcal{B} = \{ [M], [L], [T], [I], [\Theta], [N], [J] \}$. Every rational exponent coordinate is represented as an irreducible fraction:

$$
\forall i \in \{1, \dots, 7\}, \quad \mathbf{d}[i] = \frac{p_i}{q_i}, \quad p_i \in \mathbb{Z}, \; q_i \in \mathbb{Z}^+, \; \gcd(|p_i|, q_i) = 1
$$

  The dimensional equivalence relation $\equiv$ over $\mathbb{Q}^7$ is defined as bitwise equality of rational coordinates:

$$
\mathbf{d}_A \equiv \mathbf{d}_B \iff \forall i \in \{1, \dots, 7\}, \quad \mathbf{d}_A[i] = \mathbf{d}_B[i]
$$

  Each expression AST node $E \in \mathcal{E}_{\text{AST}}$ is formalized as a 10-tuple:

$$
E = \langle \text{id}_E, \text{kind}_E, \text{op}_E, \text{left}_E, \text{right}_E, \mathbf{d}_E, u_E, o_E, \Delta_E, \text{span}_E \rangle
$$

  where:

$$
\begin{aligned}
\text{id}_E &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
\text{kind}_E &\in \{ \text{BinaryOp}, \text{UnaryOp}, \text{Conditional}, \text{Extremum}, \text{Literal}, \text{VariableRef}, \text{Conversion} \} \\
\text{op}_E &\in \{ +, -, ==, \ne, \lt, \le, \gt, \ge, \min, \max, \text{clamp}, \text{none} \} \\
\text{left}_E, \text{right}_E &\in \mathcal{E}_{\text{AST}} \cup \{ \bot_{\text{AST}} \} \quad (\text{child operand node handles}) \\
\mathbf{d}_E &\in \mathbb{Q}^7 \cup \{ \bot_{\text{dim}} \} \quad (\text{inferred physical dimension vector}) \\
u_E &\in \mathcal{U} \cup \{ \bot_{\text{unit}} \} \quad (\text{associated concrete measurement unit}) \\
o_E &\in \mathbb{Q} \quad (\text{additive reference offset for affine scales, } 0 \text{ for ratio scales}) \\
\Delta_E &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_E &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{lexical source provenance})
\end{aligned}
$$

  Additive Expression Homogeneity Invariant: For every binary additive expression node $E \in \mathcal{E}_{\text{AST}}$ where $\text{kind}_E = \text{BinaryOp}$ and $\text{op}_E \in \{ +, - \}$:

$$
\mathbf{d}_{\text{left}_E} \equiv \mathbf{d}_{\text{right}_E} \implies \mathbf{d}_E = \mathbf{d}_{\text{left}_E}
$$

  Comparative Expression Homogeneity Invariant: For every relational comparative expression node $E \in \mathcal{E}_{\text{AST}}$ where $\text{kind}_E = \text{BinaryOp}$ and $\text{op}_E \in \{ ==, \ne, \lt, \le, \gt, \ge \}$:

$$
\mathbf{d}_{\text{left}_E} \equiv \mathbf{d}_{\text{right}_E} \implies \mathbf{d}_E = \mathbf{0}
$$

  Conditional Expression Homogeneity Invariant: For every conditional expression node $E = \text{if } C \text{ then } A \text{ else } B$:

$$
(\mathbf{d}_C = \mathbf{0} \wedge \mathbf{d}_A \equiv \mathbf{d}_B) \implies \mathbf{d}_E = \mathbf{d}_A
$$

  Extremum Expression Homogeneity Invariant: For every extremum function expression node $E = \text{op}(A, B)$ where $\text{op} \in \{ \min, \max \}$:

$$
\mathbf{d}_A \equiv \mathbf{d}_B \implies \mathbf{d}_E = \mathbf{d}_A
$$

  Affine Interval Scale Offset Invariants: Let $o_A = o_{\text{left}_E}$ and $o_B = o_{\text{right}_E}$ be the additive reference offsets of the operands:

$$
\begin{aligned}
\text{op}_E = + &\implies (o_A = 0 \vee o_B = 0) \wedge o_E = o_A + o_B \\
\text{op}_E = - &\implies (o_A = o_B \implies o_E = 0) \wedge (o_B = 0 \implies o_E = o_A)
\end{aligned}
$$

  Commensurable Unit Conversion Synthesis Invariant: When $\mathbf{d}_A \equiv \mathbf{d}_B$ and $u_A \ne u_B$, the compiler synthesizes conversion factor $k \in \mathbb{Q}^+$:

$$
k = \frac{c_{u_B}}{c_{u_A}} \in \mathbb{Q}^+, \quad E_{\text{synth}} = A \pm (k \cdot B), \quad u_{E_{\text{synth}}} = u_A
$$

  where $c_{u_A}, c_{u_B} \in \mathbb{Q}^+$ are the exact rational conversion scale factors relative to the coherent SI base unit.

  Deterministic RFC 4122 UUIDv5 Anchor Invariant (Architectural Directive 1):

$$
\forall E \in \mathcal{E}_{\text{AST}}, \quad \Delta_E = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(E))
$$

  Diagnostic Trigger Rules: In accordance with REQ-0191, dimensional violations deterministically emit structured diagnostic records into error sink buffer $\mathcal{D}_{\text{sink}}$:

$$
\begin{aligned}
\exists E \in \mathcal{E}_{\text{AST}} : \text{op}_E \in \{ +, - \} \wedge \mathbf{d}_{\text{left}_E} \not\equiv \mathbf{d}_{\text{right}_E} &\implies \text{Diagnostic}(E, \text{DiagnosticCode::E0300}, \text{DimensionalHomogeneityViolation}) \in \mathcal{D}_{\text{sink}} \\
\exists E \in \mathcal{E}_{\text{AST}} : \text{op}_E \in \{ ==, \ne, \lt, \le, \gt, \ge \} \wedge \mathbf{d}_{\text{left}_E} \not\equiv \mathbf{d}_{\text{right}_E} &\implies \text{Diagnostic}(E, \text{DiagnosticCode::E0300}, \text{DimensionalComparisonMismatch}) \in \mathcal{D}_{\text{sink}} \\
\exists E \in \mathcal{E}_{\text{AST}} : \text{op}_E = + \wedge o_{\text{left}_E} \ne 0 \wedge o_{\text{right}_E} \ne 0 &\implies \text{Diagnostic}(E, \text{DiagnosticCode::E0300}, \text{AffineScaleAdditionViolation}) \in \mathcal{D}_{\text{sink}} \\
\exists E \in \mathcal{E}_{\text{AST}} : (\mathbf{d}_{\text{left}_E} = \bot_{\text{dim}} \vee \mathbf{d}_{\text{right}_E} = \bot_{\text{dim}}) &\implies \mathbf{d}_E = \bot_{\text{dim}} \quad (\text{cascade diagnostic suppressed}) \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

- **Computational Complexity & Algorithmic Bounds**: Static dimensional homogeneity validation, commensurability verification, and exact rational unit conversion synthesis execute strictly within Complexity Class $\mathbf{P}$.

  For an MBSE model containing $N_{\text{expr}}$ expression AST nodes across $M$ compilation packages:
  1. *Dimensional Equality Comparison Complexity*: Comparing two 7-dimensional rational exponent vectors $\mathbf{d}_A, \mathbf{d}_B \in \mathbb{Q}^7$ requires 7 scalar rational equality checks. For each coordinate $i \in \{1, \dots, 7\}$, the check evaluates $p_{A, i} \cdot q_{B, i} == p_{B, i} \cdot q_{A, i}$ using 64-bit or 128-bit integer arithmetic, executing in deterministic $O(1)$ time and requiring zero heap allocations:

$$
T_{\text{eq\_check}} \in O(1)
$$

  2. *Single-Expression Homogeneity Validation*: Inferring and checking dimensional homogeneity for a binary, comparative, or conditional expression node, including affine scale validation, requires evaluating child node dimensions and at most 7 coordinate comparisons, executing in deterministic $O(1)$ time:

$$
T_{\text{node\_check}} \in O(1)
$$

  3. *Unit Commensurability & Conversion Synthesis*: Calculating the exact rational conversion scale multiplier $k = \frac{c_B}{c_A} = \frac{p_B \cdot q_A}{q_B \cdot p_A}$ requires two integer multiplications and Euclidean algorithm greatest common divisor ($\gcd$) reduction. For 64-bit integer words, Euclidean reduction terminates in at most $2 \log_2(\min(|p|, q))$ steps, executing in deterministic $O(1)$ time:

$$
T_{\text{unit\_synth}} \in O(1)
$$

  4. *Complete AST Post-Order Traversal*: Evaluating dimensional homogeneity across all $N_{\text{expr}}$ expression nodes in an AST via bottom-up post-order traversal visits each node exactly once, executing in deterministic linear time:

$$
T_{\text{traversal}}(N_{\text{expr}}) \in O(N_{\text{expr}})
$$

  5. *Parallel Work-Stealing Scaling (Architectural Directive 2)*: When type checking is distributed across $N_{\text{max\_workers}}$ threads on a bounded work-stealing thread pool over $M$ independent packages or feature scopes:

$$
T_{\text{parallel}}(N_{\text{expr}}, N_{\text{max\_workers}}) \in O\left( \frac{N_{\text{expr}}}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  6. *Space Complexity & Memory Bounds*: Contiguous bump arena storage for all expression AST nodes is strictly bounded by $O(N_{\text{expr}})$ bytes. Deduplicated string interner memory is bounded by the number of unique dimension and unit symbols. The diagnostic error sink buffer is strictly bounded by $O(C_{\text{max\_errors}}) = O(1)$.
