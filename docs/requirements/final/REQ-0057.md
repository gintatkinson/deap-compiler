### REQ-0057: KerML Core Classifiers: Type, Classifier, DataType, Class, Structure

- **Normative Statement**: The semantic metamodel lowering engine and abstract syntax tree (AST) graph engine shall formalize the foundational classifier hierarchy into a bounded subtyping partially ordered set (poset) $`(\mathcal{K}, \le)`$ rooted at `Type`, partitioning all classifier definitions into identity-free structural value types (`DataType`) and extensional identity-bearing stateful entities (`Class`, `Structure`) under set-theoretic denotational semantics. The compiler shall enforce the canonical KerML taxonomic specialization chain: `Structure` specializes `Class`, `Class` specializes `Classifier`, `DataType` specializes `Classifier`, and `Classifier` specializes `Type`.

  The compiler shall enforce a strict disjointness invariant between value types and identity-bearing entities: the semantic denotation of `DataType` and the semantic denotation of `Class` (and by transitivity, `Structure`) shall have an empty intersection ($`\llbracket \text{DataType} \rrbracket \cap \llbracket \text{Class} \rrbracket = \emptyset`$). Any model element that attempts multiple inheritance spanning both `DataType` and `Class` (or `Structure`), or any feature declaration that attempts to introduce mutable state or lifecycle behaviors into a `DataType`, shall be rejected deterministically at compile time with structured diagnostic error code `E0200` in accordance with the standardized diagnostic taxonomy of REQ-0191.

  The compiler shall validate identity duality across all instantiated expressions and model entities:
  1. For instances $`a, b \in \llbracket \text{DataType} \rrbracket`$, equivalence shall be evaluated strictly via structural value congruence ($`a \equiv_{\text{val}} b`$), wherein equality is established if and only if all corresponding feature projections evaluate to equivalent values.
  2. For instances $`u, v \in \llbracket \text{Class} \rrbracket`$ (including `Structure`), equivalence shall be evaluated strictly via extensional object token identity ($`\text{id}(u) = \text{id}(v)`$), such that two distinct object instances remain non-identical even when all observed feature values and internal state projections are congruent.

  The subtyping relation $`(\mathcal{K}, \le)`$ shall satisfy reflexivity, transitivity, and antisymmetry. Generalization graphs containing circular inheritance cycles ($`C_{1} \le C_{2} \le \dots \le C_{k} \le C_{1}`$ with distinct nodes) shall be detected and rejected deterministically with diagnostic error code `E0203`. Unresolvable supertype references or dangling classifier bindings shall trigger diagnostic error code `E0200`.

  Every classifier definition node instantiated in the contiguous AST arena shall be bound to an immutable, bitwise deterministic RFC 4122 UUIDv5 identifier ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(C))`$) derived from a fixed namespace OID and its canonical fully qualified topological path in accordance with Architectural Directive 1 and REQ-0010. Multi-threaded ingestion and subtyping validation of classifier definitions across independent package scopes shall be scheduled on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with Architectural Directive 2 and REQ-0012. String bytes representing classifier names, type parameters, and feature symbols shall be copied into the global symbol interner pool during the initial lexical pass to yield scalar `SymbolId` tokens in accordance with Architectural Directive 3 and REQ-0036, constituting the sole permitted exception to zero-copy arena allocation.

  In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, the classifier parser and type checker shall implement synchronization token error recovery on declaration and delimiter boundaries (e.g., `;`, `}`, `end`), recording structured diagnostic records (`E0200`, `E0203`) into the diagnostic sink and continuing analysis of subsequent declarations rather than halting on the first fault. If accumulated errors reach the error sink bound $`C_{\text{max\_errors}}`$, the compiler shall emit terminal diagnostic `E0199` and gracefully terminate. In accordance with Architectural Directive 5, REQ-0011, and REQ-0196, the compiler shall enforce a total, non-panicking execution contract by binding a typed error sentinel $`\bot_{\text{classifier}}`$ to malformed classifier nodes; execution latency (< 25 ms for $`10^4`$ classifier declarations) and peak memory RSS (< 100 MB RSS) performance gates shall be verified exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests. All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Classifier_Alpha`, `Classifier_Beta`, `DataType_Delta`, `Class_Zeta`, `Structure_Omega`, `Part_0`, `Port_1`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts and mock data.

- **Formal Invariant**: Let $`\mathcal{K}`$ denote the finite set of classifier definition nodes allocated within the compiler AST arena. The core classifier taxonomic hierarchy is partitioned into five distinct discriminant kinds:

$$
\text{Kind} \in \{ \text{Type}, \text{Classifier}, \text{DataType}, \text{Class}, \text{Structure} \}
$$

Each classifier definition $`C \in \mathcal{K}`$ is formalized as an 8-tuple:

$$
C = \langle \text{id}_{C}, \text{name}_{C}, \text{kind}_{C}, \mathcal{S}_{C}, \mathcal{F}_{C}, \mathcal{M}_{C}, \Delta_{C}, \text{span}_{C} \rangle
$$

where:

$$
\begin{aligned}
\text{id}_{C} &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
\text{name}_{C} &\in \mathcal{S}_{\text{intern}} \quad (\text{interned symbol identifier}) \\
\text{kind}_{C} &\in \{ \text{Type}, \text{Classifier}, \text{DataType}, \text{Class}, \text{Structure} \} \quad (\text{discriminant classifier kind}) \\
\mathcal{S}_{C} &\subseteq \mathcal{K} \quad (\text{direct supertypes / declared generalizations}) \\
\mathcal{F}_{C} &\subseteq \mathcal{U}_{\text{feat}} \quad (\text{owned feature definitions and usages}) \\
\mathcal{M}_{C} &= [m_{\min}, m_{\max}] \subseteq \mathbb{N}_{0} \cup \{ \infty \} \quad (\text{classifier multiplicity envelope}) \\
\Delta_{C} &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_{C} &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
\end{aligned}
$$

Let $`\mathcal{U}_{\text{universe}}`$ denote the semantic universe of instances, partitioned into the domain of identity-free pure values $`\mathcal{V}_{\text{values}}`$ and the domain of extensional identity-bearing entities $`\mathcal{O}_{\text{entities}}`$:

$$
\mathcal{U}_{\text{universe}} = \mathcal{V}_{\text{values}} \cup \mathcal{O}_{\text{entities}}, \quad \mathcal{V}_{\text{values}} \cap \mathcal{O}_{\text{entities}} = \emptyset
$$

The semantic denotation function $`\llbracket \cdot \rrbracket : \mathcal{K} \to \mathcal{P}(\mathcal{U}_{\text{universe}})`$ maps each classifier to its set of valid instances.

Taxonomic Subtyping Invariant: The subtyping relation $`\le`$ over core classifiers denotes subset inclusion over instance denotations:

$$
C_{1} \le C_{2} \iff \llbracket C_{1} \rrbracket \subseteq \llbracket C_{2} \rrbracket
$$

The foundational taxonomic poset satisfies the following axiomatic specialization chains:

$$
\begin{aligned}
\llbracket \text{Structure} \rrbracket &\subseteq \llbracket \text{Class} \rrbracket \subseteq \llbracket \text{Classifier} \rrbracket \subseteq \llbracket \text{Type} \rrbracket \\
\llbracket \text{DataType} \rrbracket &\subseteq \llbracket \text{Classifier} \rrbracket \subseteq \llbracket \text{Type} \rrbracket
\end{aligned}
$$

Disjointness Invariant: Value types and identity-bearing entities are strictly disjoint:

$$
\begin{aligned}
\llbracket \text{DataType} \rrbracket \cap \llbracket \text{Class} \rrbracket &= \emptyset \\
\llbracket \text{DataType} \rrbracket \cap \llbracket \text{Structure} \rrbracket &= \emptyset
\end{aligned}
$$

Subtyping Poset Closure Invariant: The subtyping relation $`(\mathcal{K}, \le)`$ is the reflexive, transitive, and antisymmetric closure over declared direct generalizations $`\mathcal{S}_{C}`$:

$$
\begin{aligned}
\forall C \in \mathcal{K}, &\quad C \le C \quad (\text{reflexivity}) \\
\forall C_{1}, C_{2}, C_{3} \in \mathcal{K}, &\quad (C_{1} \le C_{2} \wedge C_{2} \le C_{3}) \implies C_{1} \le C_{3} \quad (\text{transitivity}) \\
\forall C_{1}, C_{2} \in \mathcal{K}, &\quad (C_{1} \le C_{2} \wedge C_{2} \le C_{1}) \implies C_{1} = C_{2} \quad (\text{antisymmetry})
\end{aligned}
$$

Generalization Graph Acyclicity: Let $`G_{\mathcal{K}} = (\mathcal{K}, \mathcal{E}_{\text{gen}})`$ be the directed generalization graph where $`(C_{a}, C_{b}) \in \mathcal{E}_{\text{gen}} \iff C_{b} \in \mathcal{S}_{C_{a}}`$. Acyclicity requires:

$$
\forall C \in \mathcal{K}, \quad (C, C) \notin \mathcal{E}_{\text{gen}}^+
$$

Identity Duality Invariants:
1. Structural Value Congruence: For instances $`a, b \in \llbracket \text{DataType} \rrbracket`$:

$$
a \equiv_{\text{val}} b \iff (\text{kind}(a) = \text{kind}(b)) \wedge \left( \forall f \in \mathcal{F}_{\tau(a)}, \pi_{f}(a) \equiv_{\text{val}} \pi_{f}(b) \right)
$$

where $`\pi_{f}`$ denotes the feature evaluation projection.

2. Extensional Object Identity: For instances $`u, v \in \llbracket \text{Class} \rrbracket \cup \llbracket \text{Structure} \rrbracket`$:

$$
u = v \iff \text{id}(u) = \text{id}(v) \in \mathcal{O}_{\text{id}}
$$

where $`\left( \forall f \in \mathcal{F}_{\tau(u)}, \pi_{f}(u) \equiv_{\text{val}} \pi_{f}(v) \right) \not\implies u = v`$.

DataType Feature Immutability Invariant: All features owned by a `DataType` must be immutable value projections:

$$
\forall C \in \mathcal{K}, \quad C \le \text{DataType} \implies \forall f \in \mathcal{F}_{C}, \left( \text{is\_read\_only}(f) \equiv \text{true} \;\wedge\; \text{is\_behavioral}(f) \equiv \text{false} \right)
$$

Deterministic UUIDv5 Anchor Invariant: Every classifier $`C \in \mathcal{K}`$ is deterministically hashed from the canonical fully qualified path:

$$
\Delta_{C} = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(C))
$$

Diagnostic Code Trigger Invariant: Compiler diagnostic emission is strictly governed by the following trigger rules:

$$
\begin{aligned}
\exists C \in \mathcal{K} : (C \le \text{DataType} \wedge C \le \text{Class}) &\implies \text{Diagnostic}(C, \text{DiagnosticCode::E0200}, \text{DisjointClassifierSpecializationViolation}) \in \mathcal{D}_{\text{sink}} \\
\exists C \in \mathcal{K} : (C, C) \in \mathcal{E}_{\text{gen}}^+ &\implies \text{Diagnostic}(C, \text{DiagnosticCode::E0203}, \text{CircularInheritanceCycle}) \in \mathcal{D}_{\text{sink}} \\
\exists C \in \mathcal{K}, \exists S \in \mathcal{S}_{C} : S \notin \mathcal{K} &\implies \text{Diagnostic}(C, \text{DiagnosticCode::E0200}, \text{UnresolvedSupertypeReference}) \in \mathcal{D}_{\text{sink}} \\
\exists C \in \mathcal{K}, \exists f \in \mathcal{F}_{C} : (C \le \text{DataType} \wedge \neg\text{is\_read\_only}(f)) &\implies \text{Diagnostic}(f, \text{DiagnosticCode::E0200}, \text{MutableFeatureInDataTypeViolation}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

Diagnostic Taxonomy Containment Invariant: All emitted diagnostic codes strictly belong to the Metamodel and Typing family:

$$
\forall D \in \mathcal{D}_{\text{classifier}}, \quad \text{code}(D) \in \{ \text{DiagnosticCode::E0200}, \text{DiagnosticCode::E0203}, \text{DiagnosticCode::E0199} \} \subset \mathcal{E}_{\text{type}}
$$

- **Computational Complexity & Algorithmic Bounds**: Classifier hierarchy construction, cycle detection, and subtyping queries execute strictly within Complexity Class $`\mathbf{P}`$. For a model containing $`V = |\mathcal{K}|`$ classifier definitions, $`E = |\mathcal{E}_{\text{gen}}|`$ generalization edges, and $`F = \sum_{C \in \mathcal{K}} |\mathcal{F}_{C}|`$ feature definitions:

  1. AST Arena Allocation & Interning: Allocating $`V`$ classifier nodes in contiguous arena storage requires $`O(V)`$ time with $`O(1)`$ amortized allocation per node. Interning $`V`$ symbol names into the global string pool requires $`O(\sum_{C \in \mathcal{K}} |\text{name}_{C}|)`$ byte hashing operations.
  2. Cycle Detection & Topological Sorting: Detecting circular inheritance cycles over directed graph $`G_{\mathcal{K}} = (\mathcal{K}, \mathcal{E}_{\text{gen}})`$ via Tarjan's Strongly Connected Components (SCC) algorithm or depth-first search graph coloring executes in deterministic $`O(V + E)`$ time and $`O(V)`$ auxiliary stack space.
  3. Single-Inheritance Subtyping Queries: For trees or forests where each classifier has at most one direct supertype ($`|\mathcal{S}_{C}| \le 1`$), precomputing depth-first traversal entry and exit timestamps ($`[l_{C}, r_{C}]`$) executes in $`O(V)`$ time; any subsequent subtyping query $`C_{1} \le C_{2}`$ executes in strictly $`O(1)`$ time via interval containment:

$$
C_{1} \le C_{2} \iff l_{C_{2}} \le l_{C_{1}} \wedge r_{C_{1}} \le r_{C_{2}}
$$

  4. Multiple-Inheritance DAG Subtyping & Transitive Closure: For general directed acyclic graphs (DAGs), on-demand subtyping reachability queries execute via breadth-first search (BFS) or depth-first search (DFS) in $`O(V + E)`$ time. When compiled into dense transitive closure reachability bitsets ($`\text{BitSet}[V][\lceil V/64 \rceil]`$), precomputation requires $`O(V \cdot (V + E))`$ time, after which any subtyping query $`C_{1} \le C_{2}`$ executes in strictly $`O(1)`$ time via bitwise test. This complies with NP-3 tractable meet-semilattice and C3 linearization bounds without backtracking.
  5. Disjointness & Feature Immutability Validation: Evaluating the disjointness invariant $`\neg (C \le \text{DataType} \wedge C \le \text{Class})`$ across all $`V`$ classifiers requires $`O(V)`$ queries ($`O(V)`$ total time using precomputed bitsets). Validating read-only feature immutability for all `DataType` classifiers requires $`O(F)`$ enum checks.
  6. Parallel Work-Stealing Scaling: Ingestion and validation of independent package sub-forests scheduled across $`N_{\text{max\_workers}}`$ threads in the bounded work-stealing pool achieves parallel runtime:

$$
T_{\text{parallel}} \in O\left( \frac{V + E + F}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  7. Space Complexity: Auxiliary working memory is strictly bounded by $`O(V + E)`$ for graph adjacency representations and $`O(V^2 / 64)`$ bits for transitive closure bitsets. Call stack recursion depth is strictly bounded by $`O(V)`$ (or $`O(1)`$ using explicit worklists). The diagnostic sink is bounded by $`O(C_{\text{max\_errors}}) = O(1)`$ allocated records.

- **Verification & Conformance Criteria**: Automated test suites shall verify compliance using synthetic CommonMark and SysML v2 model definitions containing abstract MBSE placeholders (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Classifier_Gamma`, `DataType_Delta`, `DataType_Epsilon`, `Class_Zeta`, `Class_Eta`, `Structure_Omega`, `Part_0`, `Port_1`, `Flow_A`, `param_x : Real`). Conformance shall be validated through the following deterministic test gates:

  1. Foundational Taxonomic Hierarchy Gate: Ingest the core KerML library declarations defining `Type`, `Classifier`, `DataType`, `Class`, and `Structure`. Assert that:
     - $`\text{Structure} \le \text{Class} \le \text{Classifier} \le \text{Type}`$ evaluates to `true`.
     - $`\text{DataType} \le \text{Classifier} \le \text{Type}`$ evaluates to `true`.
     - $`\text{Structure} \le \text{DataType}`$ and $`\text{Class} \le \text{DataType}`$ evaluate to `false`.
     - Zero diagnostic records are emitted.
  2. Identity Duality Value Congruence Gate: Ingest two synthetic value instances $`a, b \in \llbracket \text{DataType\_Delta} \rrbracket`$ possessing identical feature projection values (`param_x = 42.0`). Assert that value equivalence evaluates to $`a \equiv_{\text{val}} b`$. Mutate a temporary projection copy of $`b`$ (`param_x = 43.0`); assert $`a \not\equiv_{\text{val}} b`$.
  3. Identity Duality Extensional Entity Gate: Ingest two synthetic class instances $`u, v \in \llbracket \text{Class\_Zeta} \rrbracket`$ possessing identical feature projection values (`param_x = 42.0`) but distinct arena handles and object IDs ($`\text{id}(u) \neq \text{id}(v)`$). Assert that object identity evaluates to $`u \neq v`$ despite state value congruence.
  4. Single-Inheritance $`O(1)`$ Subtyping Performance Gate: Construct a linear synthetic inheritance hierarchy of depth 32 ($`\text{Class}_{32} \le \dots \le \text{Class}_{0}`$). Execute $`10^5`$ subtyping queries between arbitrary pairs $`(\text{Class}_{i}, \text{Class}_{j})`$; assert subtyping resolution in strictly $`O(1)`$ time per query via interval index comparisons.
  5. Multiple-Inheritance Diamond DAG Gate: Construct a diamond inheritance pattern where `Structure_Omega` specializes both `Class_Zeta` and `Classifier_Beta`, both of which specialize `Classifier_Alpha`. Assert that $`\text{Structure\_Omega} \le \text{Classifier\_Alpha}`$ evaluates to `true` with deterministic linear traversal without backtracking or duplicate edge visits.
  6. Disjoint Classifier Specialization Diagnostic Gate (`E0200`): Ingest a model containing an illegal hybrid classifier `Hybrid_Err` declared to specialize both `DataType_Delta` and `Class_Zeta` (`Hybrid_Err :> DataType_Delta, Class_Zeta`). Assert that the compiler detects the disjointness violation, emits structured diagnostic error code `E0200` (`DisjointClassifierSpecializationViolation`) with exact source byte spans, binds sentinel $`\bot_{\text{classifier}}`$, and halts downstream lowering without panicking.
  7. Circular Inheritance Cycle Diagnostic Gate (`E0203`): Ingest a model declaring a circular inheritance chain `Classifier_Alpha :> Classifier_Beta :> Classifier_Gamma :> Classifier_Alpha`. Assert deterministic cycle detection, emission of diagnostic error code `E0203` (`CircularInheritanceCycle`) listing the cycle path in the diagnostic message, and graceful recovery.
  8. DataType Immutability Violation Gate (`E0200`): Ingest a `DataType` declaration `DataType_Delta` containing a mutable feature or behavioral state action. Assert deterministic rejection with diagnostic code `E0200` (`MutableFeatureInDataTypeViolation`).
  9. Synchronization Token Error Recovery Gate (Architectural Directive 4): Ingest a malformed source file containing three syntax and typing errors across classifier declarations separated by semicolons and closing braces. Assert that the compiler recovers at each token boundary, accumulates all three diagnostics into $`\mathcal{D}_{\text{sink}}`$ without panicking, and when tested against an error cascade exceeding $`C_{\text{max\_errors}}`$, emits terminal code `E0199`.
  10. Deterministic UUIDv5 Anchor Gate (Architectural Directive 1): Ingest classifier declarations under `Package_0::SubPackage_1::Classifier_Alpha`. Assert that 100% of generated classifier nodes bind bitwise identical RFC 4122 UUIDv5 identifiers across independent compiler invocations, derived deterministically from the fixed DEAP OID and fully qualified symbol path.
  11. Bounded Work-Stealing Parallelism Gate (Architectural Directive 2): Ingest a synthetic model containing 50 packages with $`10^4`$ classifiers across $`N_{\text{max\_workers}}`$ threads; assert data-race freedom, zero race conditions, and identical AST topology compared to single-threaded execution.
  12. Release Mode Latency & Memory Budget Gate (Architectural Directive 5): In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196, ingest $`10^4`$ core classifier definitions and execute $`5 \times 10^4`$ subtyping queries; assert execution latency under 25 ms, peak memory RSS under 100 MB, zero panics, and 0-byte diff churn across consecutive compiler runs.
