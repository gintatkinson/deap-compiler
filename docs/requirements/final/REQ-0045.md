### REQ-0045: Immutable AST Graph Traversal Engine with Bounded Linear Complexity

- **Normative Statement**: The Core Metamodel, Node Arena & AST Graph Engine shall provide a deterministic, immutable graph traversal engine that systematically visits nodes and edges of the abstract syntax tree (AST) multigraph $`G = (\mathcal{V}_{\text{AST}}, \mathcal{E}_{\text{AST}})`$ in topological, depth-first (pre-order and post-order), or breadth-first (level-order) traversal disciplines with strictly bounded $`O(|V| + |E|)`$ linear time complexity. Traversal algorithms must operate strictly over shared immutable references (`&NodeArena`, `NodeHandle<T>`) without allocating temporary graph representations or mutating node payloads, headers, generational counters, or edge relations.

  The graph traversal engine shall enforce the following normative guarantees:
  1. Immutability & Zero Heap Mutation Contract: The traversal engine shall not alter any byte within the contiguous node arena storage. The bitwise state of every allocated node slot following traversal completion must be strictly identical to its state prior to traversal initiation ($`\text{Mutations}(\text{Traverse}(G, \text{Visitor})) = 0`$). Furthermore, traversal algorithms shall not allocate dynamic data structures, node collections, or adjacency tables on the general heap ($`\text{HeapAllocs}(\text{Traverse}) = 0`$); all tracking state (including visited bitsets, explicit traversal stacks, and queues) must be managed using pre-allocated workspace buffers or scratch arenas sized to the configured arena capacity $`C_{\text{arena}}`$.
  2. Traversal Ordering Disciplines:
     - Depth-First Search (DFS) Traversal: The engine shall support both pre-order visitation (invoking visitor hook $`\text{enter}(v, H)`$ upon node discovery before exploring outgoing edges) and post-order visitation (invoking visitor hook $`\text{leave}(v, H)`$ after all reachable descendants have been fully explored). DFS traversal must execute using an explicit pre-allocated stack buffer to guarantee immunity to host call-stack exhaustion, enforcing a configurable maximum recursion depth bound $`D_{\text{max\_depth}}`$.
     - Breadth-First Search (BFS) Traversal: The engine shall support level-order traversal across structural containment hierarchies and dependency layers using an explicit pre-allocated ring-buffer queue.
     - Topological Traversal: For directed acyclic subgraphs (DAGs, e.g., compilation dependency DAGs, classifier specialization hierarchies, and calculation expression graphs), the engine shall visit vertices such that every predecessor vertex is visited prior to its successors ($`u \prec v`$ for all directed dependency edges $`(u, v)`$).
     - Edge-Selective Filtering: The traversal engine shall permit callers to restrict traversals to specific edge classifications $`\kappa \in \mathcal{K}_{\text{edge}}`$ (such as structural containment, type specialization, connection binding, occurrence sequencing, or reference attribution) without materializing or cloning intermediate subgraphs.
  3. Cycle Resilience & Single-Visit Completeness: The AST multigraph may contain cyclical relationships (including bidirectional associations, mutual cross-package imports, and recursive composite types). The traversal engine shall guarantee termination without infinite loops by maintaining dense visited bitsets indexed directly by the 32-bit arena slot index ($`\text{Index}(H) \in [0, C_{\text{arena}} - 1]`$) or monotonic epoch generation markers. Every vertex reachable from the designated traversal root $`v_0`$ must be visited exactly once per traversal pass ($`\text{VisitedCount}(v) = 1`$), while unreachable vertices remain unvisited ($`\text{VisitedCount}(v) = 0`$).
  4. Visitor Control Flow Directives: The engine shall accept user-defined visitor callbacks returning deterministic control flow directives: `Continue` (proceed with outgoing edge traversal), `Prune` (skip outgoing edges of the current node while continuing frontier traversal), or `Halt` (terminate traversal immediately with early exit status).
  5. Panic-Free Total-Function Error Contract: In accordance with Architectural Directive 5 and REQ-0011, the traversal engine shall strictly enforce a deterministic, non-panicking execution contract. Dereferencing an invalid node handle (stale generation, out-of-bounds slot index, or node type tag mismatch per REQ-0035) or exceeding the maximum stack depth bound ($`D \gt D_{\text{max\_depth}}`$) shall immediately cease traversal on that branch, emit structured diagnostic error code `E0200` per REQ-0191, and return a structured diagnostic result rather than triggering runtime unwinding or system panics.
  6. Bounded Work-Stealing Parallelism: In accordance with Architectural Directive 2 and REQ-0012, read-only traversals across independent AST subgraphs, packages, or compilation units shall be scheduled onto the bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$. Because node handles are scalar values (REQ-0035) and AST node arenas are accessed strictly via shared immutable references, concurrent traversals shall execute without lock acquisition, mutex contention, or atomic reference counting overhead.
  7. Deterministic UUIDv5 Anchors & Interned Symbols: In accordance with Architectural Directive 1 and REQ-0010, every visited AST node must possess a deterministic RFC 4122 UUIDv5 identifier derived by hashing the compiler namespace UUID and its canonical fully qualified path. In accordance with Architectural Directive 3 and REQ-0036, symbol identifiers and string labels referenced by AST nodes shall be scalar `SymbolId` tokens within the global deduplicated symbol interner pool, which constitutes the sole permitted exception to zero-copy memory management. All node payloads reside in contiguous bump arena storage per REQ-0009 and REQ-0034.
  8. Synchronization Token Error Recovery: In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, when batch traversals evaluate multiple root entities, encountering an error on one entity shall invoke synchronization token error recovery: recording structured diagnostics, isolating the faulted entity, and proceeding to traverse subsequent independent entities up to diagnostic capacity $`C_{\text{max\_errors}}`$, emitting `E0199` upon capacity exhaustion.
  9. Abstract MBSE Placeholders: All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Classifier_Alpha`, `Classifier_Beta`, `Port_1`, `Flow_A`, `Action_X`, `param_x : Real`), strictly prohibiting hardcoded domain concepts and mock data.

- **Formal Invariant**: Let $`G = (\mathcal{V}_{\text{AST}}, \mathcal{E}_{\text{AST}})`$ represent the AST multigraph where $`\mathcal{V}_{\text{AST}} \subset \mathbb{U}_{64}`$ is the set of typed node handles stored in contiguous arena $`\mathcal{A}_{\text{node}}`$ with capacity $`C_{\text{arena}} \in \mathbb{N}`$, and $`\mathcal{E}_{\text{AST}} \subseteq \mathcal{V}_{\text{AST}} \times \mathcal{V}_{\text{AST}} \times \mathcal{K}_{\text{edge}}`$ denotes directed edges with classification $`\kappa \in \mathcal{K}_{\text{edge}} = \{ \text{Containment}, \text{Specialization}, \text{Connection}, \text{Sequencing}, \text{Reference} \}`$.

  For a designated root vertex handle $`v_0 \in \mathcal{V}_{\text{AST}}`$, let $`V_{\text{reach}}(v_0)`$ and $`E_{\text{reach}}(v_0)`$ denote the reachable vertex and edge subgraphs:

$$
V_{\text{reach}}(v_0) = \{ v \in \mathcal{V}_{\text{AST}} \mid v_0 \rightsquigarrow v \}
$$

$$
E_{\text{reach}}(v_0) = \{ (u, v, \kappa) \in \mathcal{E}_{\text{AST}} \mid u \in V_{\text{reach}}(v_0) \}
$$

  Bounded Linear Traversal Time Invariant: The execution time $`T_{\text{traversal}}(G, v_0)`$ is strictly bounded by the cardinality of reachable vertices and edges:

$$
T_{\text{traversal}}(G, v_0) \le c_1 \cdot (|V_{\text{reach}}(v_0)| + |E_{\text{reach}}(v_0)|) + c_0
$$

  where $`c_0, c_1 \in \mathbb{R}^+`$ are fixed platform constants independent of graph size.

  Immutability & Zero Heap Mutation Invariant: Let $`\sigma(v, t)`$ denote the bitwise binary representation of node slot $`v`$ in arena $`\mathcal{A}_{\text{node}}`$ at time step $`t`$. Let $`t_{\text{pre}}`$ and $`t_{\text{post}}`$ denote time steps immediately prior to and following traversal execution:

$$
\begin{aligned}
\forall v \in \mathcal{V}_{\text{AST}}, \quad \sigma(v, t_{\text{post}}) &\equiv \sigma(v, t_{\text{pre}}) \\
\text{Mutations}(\text{Traverse}(G, \text{Visitor})) &= 0 \\
\text{HeapAllocs}(\text{Traverse}(G, \text{Visitor})) &= 0
\end{aligned}
$$

  Visited Bitset Invariant: Let $`B \in \{0, 1\}^{C_{\text{arena}}}`$ denote the pre-allocated bitset workspace buffer indexed by arena slot indices:

$$
\begin{aligned}
\forall i \in \{0, \dots, C_{\text{arena}} - 1\}, \quad B[i]_{t_{\text{pre}}} &= 0 \\
\text{IsVisited}(H, B) &\iff B[\text{Index}(H)] = 1
\end{aligned}
$$

  When visiting handle $`H`$ during traversal, the bit transition satisfies:

$$
B[\text{Index}(H)]_{t+1} = 1
$$

  Visiting Completeness & Single-Visit Invariant: For any traversal completing without early abort:

$$
\begin{aligned}
\forall v \in V_{\text{reach}}(v_0), \quad \text{VisitedCount}(v) &= 1 \\
\forall v \in \mathcal{V}_{\text{AST}} \setminus V_{\text{reach}}(v_0), \quad \text{VisitedCount}(v) &= 0
\end{aligned}
$$

  Cycle Resilience & Termination Invariant: Let $`\mathcal{C} = \langle v_1, v_2, \dots, v_m, v_1 \rangle`$ denote a directed cycle in $`G`$ with $`(v_i, v_{i+1}, \kappa_i) \in \mathcal{E}_{\text{AST}}`$ and $`(v_m, v_1, \kappa_m) \in \mathcal{E}_{\text{AST}}`$. Because $`B[\text{Index}(v_1)] = 1`$ upon the initial visit to $`v_1`$, the back-edge $`(v_m, v_1, \kappa_m)`$ is skipped:

$$
\text{IsVisited}(v_1, B) = 1 \implies \text{TraverseEdge}(v_m, v_1) = \text{Skip}
$$

$$
\text{CycleIterations}(\mathcal{C}) \le m \quad \wedge \quad \text{Terminates}(\text{Traverse}(G, v_0)) \equiv \text{true}
$$

  Traversal Ordering Formal Invariants:
  1. Depth-First Pre-Order Sequence $`\sigma_{\text{pre}}`$: For every directed tree edge $`(u, v, \kappa) \in \mathcal{E}_{\text{tree}}`$ in the traversal spanning forest:

$$
\forall (u, v, \kappa) \in \mathcal{E}_{\text{tree}}, \quad \text{pos}(\sigma_{\text{pre}}, u) \lt \text{pos}(\sigma_{\text{pre}}, v)
$$

  2. Depth-First Post-Order Sequence $`\sigma_{\text{post}}`$: For every directed tree edge $`(u, v, \kappa) \in \mathcal{E}_{\text{tree}}`$ in the traversal spanning forest:

$$
\forall (u, v, \kappa) \in \mathcal{E}_{\text{tree}}, \quad \text{pos}(\sigma_{\text{post}}, u) \gt \text{pos}(\sigma_{\text{post}}, v)
$$

  3. Topological Order Sequence $`\sigma_{\text{topo}}`$: For any acyclic subgraph $`G_{\text{DAG}} = (\mathcal{V}_{\text{AST}}, \mathcal{E}_{\text{DAG}})`$:

$$
\forall (u, v, \kappa) \in \mathcal{E}_{\text{DAG}}, \quad \text{pos}(\sigma_{\text{topo}}, u) \lt \text{pos}(\sigma_{\text{topo}}, v)
$$

  4. Breadth-First Level-Order Sequence $`\sigma_{\text{BFS}}`$: For any two reachable vertices $`u, v \in V_{\text{reach}}(v_0)`$:

$$
\text{dist}_G(v_0, u) \lt \text{dist}_G(v_0, v) \implies \text{pos}(\sigma_{\text{BFS}}, u) \le \text{pos}(\sigma_{\text{BFS}}, v)
$$

  Stack Depth Bound & Overflow Protection: Let $`S_{\text{stack}}(t)`$ denote the auxiliary traversal stack at step $`t`$:

$$
|S_{\text{stack}}(t)| \le D_{\text{max\_depth}} \le |V_{\text{reach}}(v_0)|
$$

  Diagnostic Error Code Binding Invariant: Handle dereference violations or recursion depth overflows trigger structured diagnostic records in accordance with REQ-0191:

$$
\begin{aligned}
\neg\text{ValidHandle}(H, \mathcal{A}) &\implies \text{Diagnostic}(H, \text{DiagnosticCode::E0200}, \text{InvalidNodeHandleDereference}) \in \mathcal{D}_{\text{sink}} \\
|S_{\text{stack}}(t)| \gt D_{\text{max\_depth}} &\implies \text{Diagnostic}(H, \text{DiagnosticCode::E0200}, \text{TraversalRecursionDepthExceeded}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

$$
\forall d \in \mathcal{D}_{\text{traversal}}, \quad \text{code}(d) \in \{ \text{DiagnosticCode::E0200}, \text{DiagnosticCode::E0199} \} \subset \mathcal{E}_{\text{type}} \cup \mathcal{E}_{\text{ingest}}
$$

- **Computational Complexity & Algorithmic Bounds**: The immutable graph traversal engine executes strictly within Complexity Class $`\mathbf{P}`$. The algorithmic bounds across operations and data structures are formalized as follows:
  1. Time Complexity:
     - Traversal Time: For an AST multigraph containing $`V = |V_{\text{reach}}(v_0)|`$ reachable nodes and $`E = |E_{\text{reach}}(v_0)|`$ reachable edges, traversal executes in deterministic $`O(|V| + |E|)`$ linear time.
     - Bitset Operations: Bit query and update operations execute in strict $`O(1)`$ constant time via direct bitwise shifts and masks ($`B[i \gg 6] \mathbin{\&} (1 \ll (i \mathbin{\&} 63))`$ and $`B[i \gg 6] \mathbin{|} (1 \ll (i \mathbin{\&} 63))`$). Over the full traversal, total bitset operations are bounded by $`O(|V| + |E|)`$.
     - Node Dereferencing: Dereferencing a node handle within the contiguous node arena executes in strict $`O(1)`$ worst-case constant time via base-plus-offset address arithmetic in accordance with REQ-0034 and REQ-0035.
     - Edge Succession Iteration: For vertex $`u`$, iterating over its outgoing edges incurs $`O(\text{deg}^+(u))`$ time, yielding total edge exploration time $`\sum_{u \in V_{\text{reach}}} O(\text{deg}^+(u)) = O(|E|)`$.
     - Stack and Queue Operations: Explicit stack push/pop and queue enqueue/dequeue operations execute in $`O(1)`$ constant time per element, requiring at most $`O(|V|)`$ operations across the entire traversal pass.
  2. Parallel Traversal Bounds (Architectural Directive 2, REQ-0012):
     - When traversing $`M`$ disjoint AST subgraphs or packages concurrently across $`N_{\text{max\_workers}}`$ threads in the bounded work-stealing thread pool, wall-clock traversal time satisfies:

$$
T_{\text{parallel}}(V, E) \in O\left(\frac{|V| + |E|}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}}\right)
$$

     - Read-only shared access across worker threads guarantees zero lock acquisition and zero mutex contention.
  3. Space Complexity:
     - Visited Bitset Footprint: The bitset requires strictly $`\lceil C_{\text{arena}} / 8 \rceil`$ bytes of auxiliary memory, scaling as $`O(C_{\text{arena}})`$ bits. For an arena capacity of $`10^6`$ nodes, the bitset requires exactly $`125\text{ KB}`$ allocated once within pre-allocated scratch memory.
     - Traversal Frontier Stack and Queue: The explicit stack or queue stores at most $`D_{\text{max\_depth}}`$ node handles ($`8`$ bytes per handle). For $`D_{\text{max\_depth}} = 65536`$, auxiliary frontier memory is strictly bounded by $`512\text{ KB}`$.
     - Dynamic Heap Allocations: Traversal execution incurs exactly $`0`$ bytes of dynamic heap allocation ($`\text{HeapAllocs} = 0`$).
     - Arena Payload Mutation: Zero bytes of node payload or arena metadata are mutated during traversal.

- **Verification & Conformance Criteria**: Automated test suites shall deterministically verify compliance against synthetic abstract MBSE models (`Package_0`, `Classifier_Alpha`, `Classifier_Beta`, `Port_1`, `Flow_A`, `Action_X`, `param_x : Real`) across the following verification gates:
  1. Exact Linear Runtime Scaling Gate ($`10^5`$ to $`10^6`$ Nodes): Benchmark traversal execution across synthetic tree, DAG, and multigraph topologies scaling from $`10^3`$ to $`10^6`$ nodes and edges. Assert empirical linear time scaling $`T(V, E) \le c_1 \cdot (V + E) + c_0`$ with a linear regression coefficient of determination $`R^2 \ge 0.99`$.
  2. Immutability & Zero Heap Allocation Gate: Instrument the traversal engine with a memory allocator hook and SHA-256 digests of node arena memory segments before and after traversal. Assert zero dynamic heap allocations ($`\text{HeapAllocs} = 0`$) and identical pre/post arena memory digests across all traversal passes.
  3. Visiting Completeness & Reachability Gate: Ingest a model containing both reachable and unreachable subgraphs from root `Package_0`. Run DFS and BFS traversals, asserting that 100% of reachable vertices have $`\text{VisitedCount}(v) = 1`$ and all unreachable vertices have $`\text{VisitedCount}(v) = 0`$.
  4. Cyclic Graph Resilience & Infinite Loop Prevention Gate: Ingest synthetic models containing deliberate cyclical references (mutual cross-package associations `Classifier_Alpha -> Classifier_Beta -> Classifier_Alpha`, self-referencing ports `Port_1 -> Port_1`, and dense cycles). Assert that traversal terminates deterministically without infinite loop, visits each node in the cycle exactly once, and finishes within $`O(|V| + |E|)`$ steps.
  5. Traversal Order Conformance Gate: Verify ordering invariants across synthetic DAG structures:
     - Depth-First Pre-Order: Assert that every parent node strictly precedes its child nodes in the visitation log.
     - Depth-First Post-Order: Assert that child nodes strictly precede their parent nodes in the visitation log.
     - Breadth-First Level-Order: Assert that all vertices at depth $`d`$ strictly precede vertices at depth $`d + 1`$.
     - Topological Order: Assert that for all dependency edges $`(u, v)`$, node $`u`$ strictly precedes node $`v`$.
  6. Visitor Control Flow Directives Gate: Test visitor directive handling:
     - Assert that returning `Prune` halts exploration of the current node's descendants while continuing frontier traversal of sibling branches.
     - Assert that returning `Halt` terminates traversal immediately in $`O(1)`$ operations with early exit status.
  7. Edge-Selective Filtering Gate: Execute traversals filtering exclusively on `Containment` edges, and verify that `Reference` and `Connection` edges are omitted without allocating intermediate graph structures.
  8. Error Handling & Diagnostic Code Binding Gate: Inject an invalid node handle (stale generation counter or out-of-bounds slot index) into the traversal frontier, and construct a path exceeding $`D_{\text{max\_depth}}`$. Assert deterministic emission of diagnostic error code `E0200` (`InvalidNodeHandleDereference` and `TraversalRecursionDepthExceeded`) with exact source span details, terminating gracefully without system panic per Directive 5.
  9. Bounded Work-Stealing Parallelism & Thread Isolation Gate (Directive 2, REQ-0012): Execute concurrent read-only traversals across $`M = 32`$ disjoint subgraphs using $`N_{\text{max\_workers}} = 8`$ worker threads. Assert zero race conditions, thread-isolated workspace allocations, identical visitation logs to single-threaded executions, and zero lock contention.
  10. Release Mode Latency and Memory Budget Gate (Directive 5, REQ-0011, REQ-0196): In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests, benchmark traversal over an AST multigraph containing $`10^5`$ nodes and $`2 \times 10^5`$ edges. Assert execution latency is strictly below 25 ms and total peak resident set size (RSS) memory consumption is strictly below 100 MB.
  11. Bitwise Parity & Zero Churn Gate (REQ-0003): Assert bitwise identical visitation logs and 0-byte diff churn across repeated compilations of synthetic test suites.
