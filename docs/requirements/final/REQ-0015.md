### REQ-0015: Event-Driven CommonMark Table Lexer & Token Streaming

- **Normative Statement**: The ingestion engine shall parse CommonMark Markdown tables containing component declarations, interfaces, attributes, and constraints using an explicit deterministic pushdown automaton (DPDA) that emits an event stream of structural tokens. Lexing and tokenization must strictly prohibit regular expressions and catastrophic backtracking. Front-end table ingestion passes shall operate directly on contiguous UTF-8 byte streams, executing scalar byte-matching transitions to classify cell boundaries, row terminators, header delimiters, and escaped literal sequences. Token emissions must occur on-the-fly via a streaming event sink interface, delivering structured token events without materializing intermediate syntax trees or buffering unneeded file contents in memory. Every emitted token event shall capture exact source provenance, including 0-indexed byte offset intervals and 1-indexed line and column coordinates. The lexer shall enforce an explicit bounded frame stack with maximum nesting depth $`D \le 4`$, rejecting any deeper nesting or unclosed frames deterministically with diagnostic code `E0100` or `E0102`. Lexer execution shall follow a total, non-panicking execution contract with deterministic error emission upon encountering invalid byte encodings or structural anomalies.

- **Formal Invariant**: The CommonMark table lexer is formalized as a 7-tuple deterministic pushdown automaton:

```math
M_{\text{table}} = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)
```

where the constituent sets and parameters are defined as:

```math
\begin{aligned}
Q &= \{ q_{\text{scan}}, q_{\text{header}}, q_{\text{delimiter}}, q_{\text{row}}, q_{\text{cell}}, q_{\text{escape}}, q_{\text{halt}} \} \\
\Sigma &= \{ b \in \mathbb{N} \mid 0 \le b \le 255 \} \\
\Gamma &= \{ Z_0, \text{TableFrame}, \text{HeaderFrame}, \text{RowFrame}, \text{CellFrame} \} \\
q_0 &= q_{\text{scan}} \\
Z_0 &\in \Gamma \quad (\text{bottom-of-stack sentinel}) \\
F &= \{ q_{\text{halt}} \}
\end{aligned}
```

The deterministic transition function governs automaton state transitions:

```math
\delta : Q \times (\Sigma \cup \{ \epsilon \}) \times \Gamma \longrightarrow Q \times \Gamma^*
```

subject to the strict determinism condition:

```math
\forall q \in Q, \; \forall \gamma \in \Gamma, \quad \delta(q, \epsilon, \gamma) \neq \emptyset \implies \forall a \in \Sigma, \; \delta(q, a, \gamma) = \emptyset
```

and the singleton transition cardinality invariant:

```math
\forall (q, a, \gamma) \in Q \times (\Sigma \cup \{ \epsilon \}) \times \Gamma, \quad |\delta(q, a, \gamma)| \le 1
```

The token stream $`\mathcal{S}_{\text{events}} = \langle e_1, e_2, \dots, e_m \rangle`$ is an ordered sequence of event tuples emitted during execution:

```math
e_i = \langle \text{tag}, \text{span} \rangle \quad \text{or} \quad e_i = \langle \text{tag}(s), \text{span} \rangle
```

where event tags are drawn from the closed structural token alphabet:

```math
\text{tag} \in \{ \text{StartTable}, \text{StartHeader}, \text{EndHeader}, \text{StartRow}, \text{EndRow}, \text{StartCell}, \text{CellText}(s), \text{EndCell}, \text{EndTable} \}
```

and the token span $`\text{span}(e_i) = [b_{\text{start}}, b_{\text{end}}]`$ satisfies exact byte containment:

```math
0 \le b_{\text{start}} \le b_{\text{end}} \le N
```

over input byte sequence $`B = \langle b_0, b_1, \dots, b_{N-1} \rangle`$` of length `$`N = |B|`$.

Zero Backtracking & Zero Regex Invariant:

```math
\text{BacktrackCount}(M_{\text{table}}) = 0, \quad \text{RegexEvaluations}(M_{\text{table}}) = 0
```

Monotonic Forward Stream Progress Invariant: let $`\text{pos}_t \in \{0, \dots, N\}`$` denote the byte position of the lexer at discrete execution step `$`t`$`. For all evaluation steps `$`t`$, the byte position advances monotonically:

```math
\forall t, \quad \text{pos}_{t+1} \ge \text{pos}_t
```

with strictly positive advance $`\text{pos}_{t+1} = \text{pos}_t + 1`$` on consuming transitions `$`a \in \Sigma`$`. The number of consecutive `$`\epsilon`$-transitions is bounded by the maximum stack depth:

```math
k_{\epsilon} \le |\Gamma| \le D
```

Bounded Stack Depth Invariant: for any configuration reachable by $`M_{\text{table}}`$`, the depth of the pushdown stack `$`\text{stack}_t \in \Gamma^*`$ is bounded by:

```math
\forall t, \quad |\text{stack}_t| \le D \le 4
```

Token Stream Structural Balance Invariant: every opening structural tag in $`\mathcal{S}_{\text{events}}`$ possesses an identical count of corresponding closing tags:

```math
\begin{aligned}
\text{count}(\text{StartTable}, \mathcal{S}_{\text{events}}) &= \text{count}(\text{EndTable}, \mathcal{S}_{\text{events}}) \\
\text{count}(\text{StartHeader}, \mathcal{S}_{\text{events}}) &= \text{count}(\text{EndHeader}, \mathcal{S}_{\text{events}}) \\
\text{count}(\text{StartRow}, \mathcal{S}_{\text{events}}) &= \text{count}(\text{EndRow}, \mathcal{S}_{\text{events}}) \\
\text{count}(\text{StartCell}, \mathcal{S}_{\text{events}}) &= \text{count}(\text{EndCell}, \mathcal{S}_{\text{events}})
\end{aligned}
```

Diagnostic Code Containment Invariant: any structural violation or malformed tabular sequence encountered during automaton execution produces a structured diagnostic binding within the ingestion error code taxonomy defined in REQ-0191:

```math
\forall D_k \in \mathcal{D}, \quad \text{code}(D_k) \in \{ \text{E0100}, \text{E0102} \} \subset \mathcal{E}_{\text{ingest}}
```

- **Computational Complexity & Algorithmic Bounds**: The event-driven CommonMark table lexer executes within Complexity Class $`\mathbf{P}`$`. Because transition rules evaluate solely scalar byte matches without backtracking (`$`\text{BacktrackCount} = 0`$`) and regular expression evaluations are strictly prohibited (`$`\text{RegexEvaluations} = 0`$`), each input byte in `$`B`$` is processed in `$`O(1)`$` operations, guaranteeing strictly linear time complexity `$`O(N)`$` where `$`N = |B|`$`. Stack operations (`$`\text{push}`$`, `$`\text{pop}`$`) execute in `$`O(1)`$` time, and the pushdown stack depth is bounded by constant `$`D \le 4`$`, establishing an auxiliary memory bound of `$`O(D) = O(1)`$`. The streaming event emission architecture writes directly to the event sink, preserving a constant `$`O(1)`$` active memory overhead independent of file length `$`N`$.

- **Verification & Conformance Criteria**: Deterministic compliance shall be validated via automated integration and benchmark test suites. Execution of the table lexer across synthetic CommonMark schemas with $`10^5`$ table rows shall verify that streaming throughput exceeds 50 MB/s in compiled Release mode (`--release`), exhibiting zero quadratic performance degradation such that $`T(2N) / T(N) \le 2.05`$`. Static verification and profiler assertions shall verify that the automaton stack depth satisfies `$`|\text{stack}_t| \le 4`$` throughout parsing, with zero heap allocations per streaming event. Static codebase inspection shall assert that zero regular expression libraries or regex APIs are invoked across the lexer module, and that stream cursor position decreases are strictly absent (`$`\text{pos}_{t+1} \ge \text{pos}_t`$). Conformance tests with synthetic malformed table records (including unclosed rows, mismatched cell counts, illegal control characters, and truncated delimiter lines) shall assert that the parser emits structured diagnostic records binding error code `E0100` or `E0102` with exact byte span coordinates and non-panicking termination. Bitwise determinism shall be verified across repeated compiler passes on identical inputs, asserting 0-byte diff churn in the resulting token event stream $`\mathcal{S}_{\text{events}}`$.
