### REQ-0174: Downstream Projections: Bidirectional Realization Matrices, STPA Matrices & ICD Tables Synthesis

#### 1. Normative Statement

The downstream specification projection engine, traceability verification framework, and tabular artifact synthesizer of Subsystem 9 shall synthesize complete bidirectional realization matrices, structured System-Theoretic Process Analysis (STPA) safety matrices (incorporating Losses, Hazards, Unsafe Control Actions, Safety Constraints, and FMECA failure modes), and Level 1C Interface Control Document (ICD) tables linking Epics to Features, Features to User Stories, and User Stories to Use Cases, guaranteeing 100% bidirectional traceability between downstream specification artifacts and the sovereign abstract syntax tree (AST) source compilation model.

  Specifically, the downstream projection engine, matrix generator, and verification framework shall strictly enforce the following structural, algebraic, and operational provisions across all compilation units:
  1. **Bidirectional Realization Matrix Synthesis & Coverage Invariants**:
     - The projection engine shall construct a global incidence matrix $`\mathbf{R} \in \{0, 1\}^{|\mathcal{S}_{\text{specs}}| \times |\mathcal{V}_{\text{AST}}|}`$` mapping the finite set of downstream specification artifacts `$`\mathcal{S}_{\text{specs}}`$` to the finite universe of AST source nodes `$`\mathcal{V}_{\text{AST}}`$.
     - The engine shall enforce full coverage across both dimensions:
       - Forward Realization (Zero Orphan AST Nodes): Every compilation unit AST node $`v_j \in \mathcal{V}_{\text{AST}}`$` must be realized by at least one downstream specification artifact (`$`\sum_{i=1}^{|\mathcal{S}_{\text{specs}}|} R_{ij} \ge 1`$). Any unrealized or orphaned AST node shall constitute a fatal non-conformance.
       - Backward Grounding (Zero Ungrounded Specifications): Every downstream specification artifact $`s_i \in \mathcal{S}_{\text{specs}}`$` must realize at least one source AST node (`$`\sum_{j=1}^{|\mathcal{V}_{\text{AST}}|} R_{ij} \ge 1`$). Hallucinated, floating, or ungrounded specification artifacts lacking AST provenance shall be rejected.
  2. **Hierarchical Specification Projection Cascade**:
     - The projection engine shall synthesize intermediate realization incidence sub-matrices linking successive tiers of the downstream specification hierarchy:
       - Epic-to-Feature Incidence Matrix $`\mathbf{M}_{\text{EF}} \in \{0, 1\}^{|\mathcal{E}_{\text{epic}}| \times |\mathcal{F}_{\text{proj}}|}`$ linking high-level Epics (REQ-0161) to constituent 3-Layer Features (REQ-0164);
       - Feature-to-Story Incidence Matrix $`\mathbf{M}_{\text{FS}} \in \{0, 1\}^{|\mathcal{F}_{\text{proj}}| \times |\mathcal{S}_{\text{story}}|}`$ linking Features to Gherkin BDD User Stories (REQ-0169, REQ-0170, REQ-0171);
       - Story-to-UseCase Incidence Matrix $`\mathbf{M}_{\text{SU}} \in \{0, 1\}^{|\mathcal{S}_{\text{story}}| \times |\mathcal{U}_{\text{case}}|}`$ linking User Stories to operational Use Cases (REQ-0172, REQ-0173).
     - The engine shall enforce cascade completeness:
       - Every Epic must contain at least one Feature ($`\forall a, \sum_b M_{\text{EF}, ab} \ge 1`$);
       - Every Feature must belong to at least one Epic and specify at least one User Story ($`\forall b, \sum_a M_{\text{EF}, ab} \ge 1 \wedge \sum_c M_{\text{FS}, bc} \ge 1`$);
       - Every User Story must refine at least one Feature and trigger at least one Use Case ($`\forall c, \sum_b M_{\text{FS}, bc} \ge 1 \wedge \sum_d M_{\text{SU}, cd} \ge 1`$);
       - Every Use Case must execute at least one User Story ($`\forall d, \sum_c M_{\text{SU}, cd} \ge 1`$).
     - The transitive projection product $`\mathbf{M}_{\text{EU}} = \mathbf{M}_{\text{EF}} \cdot \mathbf{M}_{\text{FS}} \cdot \mathbf{M}_{\text{SU}}`$ must provide a non-zero realization path from every operational Use Case back to at least one root Epic.
  3. **Structured STPA Safety Matrix Synthesis**:
     - The projection engine shall extract and synthesize complete STPA safety matrices integrating System Losses ($`\mathcal{L}`$`), System Hazards (`$`\mathcal{H}`$`), Unsafe Control Actions (`$`\mathcal{U}`$`, REQ-0135, REQ-0136), Safety Constraints (`$`\mathcal{S}\mathcal{C}`$`, REQ-0137, REQ-0138), and FMECA Failure Modes (`$`\mathcal{F}\mathcal{M}`$, REQ-0139, REQ-0140).
     - The engine shall construct four typed safety relational incidence matrices:
       - Mitigation Matrix $`\mathbf{M}_{\text{Mitigates}} \in \{0, 1\}^{|\mathcal{S}\mathcal{C}| \times |\mathcal{H}|}`$;
       - Causal Loss Matrix $`\mathbf{M}_{\text{LeadsTo}} \in \{0, 1\}^{|\mathcal{H}| \times |\mathcal{L}|}`$;
       - Enforcement Matrix $`\mathbf{M}_{\text{Enforces}} \in \{0, 1\}^{|\mathcal{S}\mathcal{C}| \times |\mathcal{U}|}`$;
       - Failure Mode Exposure Matrix $`\mathbf{M}_{\text{Exposes}} \in \{0, 1\}^{|\mathcal{F}\mathcal{M}| \times |\mathcal{H}|}`$.
     - The engine shall enforce unbroken safety chain integrity:
       - Every Safety Constraint $`\text{SC}_k \in \mathcal{S}\mathcal{C}`$` must mitigate at least one Hazard `$`H \in \mathcal{H}`$` that leads to at least one Loss `$`L \in \mathcal{L}`$` (`$`\forall \text{SC}_k, \exists H \in \mathcal{H}, L \in \mathcal{L} : \text{Mitigates}(\text{SC}_k, H) \wedge \text{LeadsTo}(H, L)`$);
       - Every Hazard must lead to at least one Loss and be mitigated by at least one Safety Constraint;
       - Every Unsafe Control Action must be constrained by at least one Safety Constraint;
       - Every FMECA Failure Mode must map to at least one System Hazard.
     - Any orphan hazard, unlinked loss, unconstrained UCA, unmapped failure mode, or unmitigated safety constraint shall cause immediate compile-time rejection with diagnostic error code `E0500`.
  4. **Level 1C Interface Control Document (ICD) Table Synthesis**:
     - The projection engine shall synthesize Level 1C Interface Control Document tables adhering to Subsystem 8 standards:
       - Subsystem N^2 Interface Matrices ($`\mathbf{N} \in \{0, 1\}^{|\mathcal{C}_{\text{sub}}| \times |\mathcal{C}_{\text{sub}}|}`$) mapping directed flows between subsystem boundary ports per REQ-0145 and REQ-0146;
       - Master Signal Flow Dictionaries per REQ-0148 providing the canonical 10-column schema (Signal Name, Source Port, Destination Port, Payload Classifier, Q^7 Rational Metric Vector per REQ-0098 and REQ-0152, Update Rate in Hertz, Bandwidth Allocation in bits per second per REQ-0154, Failsafe Default State per REQ-0153, Latency Deadline per REQ-0158, and Realizing Feature/Use Case Anchor);
       - Port Definition Rosters (REQ-0149) and Connection Binding Rosters (REQ-0150).
     - Every interface port, flow, and channel in the ICD tables must be bidirectionally bound to its realizing Feature Layer 1/3 definition (REQ-0165, REQ-0167) and operational Use Case (REQ-0172).
     - Dangling ports, unrouted flows, or unbound interface endpoints shall be detected and rejected at compile time with diagnostic error code `E0500`.
  5. **Deterministic Markdown Table Presentation & Purity Standards**:
     - All synthesized realization matrices, STPA matrices, and ICD tables shall be projected as deterministic GitHub Flavored Markdown tables.
     - In strict accordance with Charter Invariant 3, Markdown table cells must never contain `$` math delimiters (using plain text, e.g., `M_EF in {0, 1}`, `Sum >= 1`, or Unicode symbols).
     - In strict accordance with Charter Invariant 4, emitted markdown tables and text must utilize ASCII `--` or `-` exclusively, with zero Unicode em dashes or en dashes.
     - Matrix rows and table entries shall be sorted lexicographically by interned symbol identifiers to ensure bitwise reproducibility and 0-byte diff churn across regenerations (REQ-0003).
  6. **Contiguous Bump Arena Memory Allocation**:
     - All synthesized realization matrices, STPA tables, ICD dictionaries, incidence bitvectors, and verification witnesses shall be allocated sequentially into contiguous typed bump arena storage in accordance with REQ-0009 and REQ-0034.
     - All matrix nodes and table entries shall be addressed via stable 32-bit arena node handles in accordance with REQ-0035, eliminating pointer-based heap allocations during projection passes.
  7. **Enforcement of the 5 Executive Architectural Directives**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every synthesized realization matrix document, STPA safety matrix, Level 1C ICD table, constituent row descriptor, and trace link witness shall bind an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical DEAP namespace OID and the node fully qualified topological path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(v) \mathbin{\Vert} \text{"::Matrix"}))`$ in accordance with REQ-0010 and REQ-0159. Time-based UUIDs are strictly banned.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel extraction of realization incidences, STPA graph traversal, ICD table generation, and coverage invariant verification across independent subsystems and feature packages shall execute strictly on a centralized, bounded work-stealing thread pool with worker thread upper bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012. Unbounded manual thread spawning is strictly banned.
     - *Directive 3 (String Interner Memory Allocation Exception)*: Signal names, port identifiers, classifier names, hazard descriptions, loss labels, UCA tags, and table column headers shall be interned into the deduplicated global symbol interner pool during synthesis in accordance with REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The downstream projection engine shall implement synchronization token error recovery on matrix row delimiters (`|`), markdown section boundaries (`###`), and YAML frontmatter fences (`---`) in accordance with REQ-0013 and REQ-0016. When realization gaps or matrix non-conformances (`E0500`) occur, the engine shall record structured diagnostics into the preallocated error sink buffer $`\mathcal{D}_{\text{sink}}`$`, substitute typed error sentinels (`$`\bot_{\text{realize}}`$`, `$`\bot_{\text{stpa}}`$`, `$`\bot_{\text{icd}}`$`), and continue validating subsequent rows and packages. If accumulated diagnostics reach capacity limit `$`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully.
     - *Directive 5 (Panic-Free Release Paths & Benchmarking Isolation)*: The matrix projection engine and coverage verification gates shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Synthesis latency (strictly under 25 ms for an architectural model containing $`10^4`$ AST nodes and specification entities) and peak RSS memory (strictly under 100 MB) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.
  8. **Pure Abstract MBSE Placeholder Mandate**:
     - All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Port_0`, `Port_1`, `Flow_A`, `Flow_B`, `Subsystem_0`, `Subsystem_1`, `Epic_0`, `Epic_1`, `Feature_0`, `Feature_1`, `Story_0`, `Story_1`, `UseCase_0`, `UseCase_1`, `Loss_0`, `Hazard_0`, `UCA_0`, `SafetyConstraint_0`, `FailureMode_0`, `param_x : Real`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

#### 2. Formal Invariant

Let $`\mathcal{V}_{\text{AST}}`$` denote the universe of allocated AST nodes in contiguous bump arena storage, and let `$`\mathcal{S}_{\text{specs}}`$` denote the finite set of downstream specification artifacts projected across Epics `$`\mathcal{E}_{\text{epic}}`$`, Features `$`\mathcal{F}_{\text{proj}}`$`, User Stories `$`\mathcal{S}_{\text{story}}`$`, and Use Cases `$`\mathcal{U}_{\text{case}}`$, such that:

```math
  \mathcal{S}_{\text{specs}} = \mathcal{E}_{\text{epic}} \cup \mathcal{F}_{\text{proj}} \cup \mathcal{S}_{\text{story}} \cup \mathcal{U}_{\text{case}}
```

  The global bidirectional realization mapping is formalized as an incidence matrix:

```math
  \mathbf{R} \in \{0, 1\}^{|\mathcal{S}_{\text{specs}}| \times |\mathcal{V}_{\text{AST}}|}, \quad R_{ij} = 1 \iff \text{Spec}_i \text{ realizes } \text{Node}_j
```

  1. Full Coverage & Zero-Orphan Invariants:
     - Forward Realization Completeness (Zero Orphan AST Nodes):

```math
  \forall j \in \{1, \dots, |\mathcal{V}_{\text{AST}}|\}, \quad \sum_{i=1}^{|\mathcal{S}_{\text{specs}}|} R_{ij} \ge 1
```

     - Backward Grounding Completeness (Zero Ungrounded Specifications):

```math
  \forall i \in \{1, \dots, |\mathcal{S}_{\text{specs}}|\}, \quad \sum_{j=1}^{|\mathcal{V}_{\text{AST}}|} R_{ij} \ge 1
```

  2. Hierarchical Specification Projection Cascade Invariants:
     - Intermediate projection incidence sub-matrices are defined as:

```math
  \begin{aligned}
  \mathbf{M}_{\text{EF}} &\in \{0, 1\}^{|\mathcal{E}_{\text{epic}}| \times |\mathcal{F}_{\text{proj}}|}, \quad M_{\text{EF}, ab} = 1 \iff E_a \text{ contains } F_b \\
  \mathbf{M}_{\text{FS}} &\in \{0, 1\}^{|\mathcal{F}_{\text{proj}}| \times |\mathcal{S}_{\text{story}}|}, \quad M_{\text{FS}, bc} = 1 \iff F_b \text{ specifies } S_c \\
  \mathbf{M}_{\text{SU}} &\in \{0, 1\}^{|\mathcal{S}_{\text{story}}| \times |\mathcal{U}_{\text{case}}|}, \quad M_{\text{SU}, cd} = 1 \iff S_c \text{ executes } U_d
  \end{aligned}
```

     - Tier-to-Tier Cascade Completeness Conditions:

```math
  \begin{aligned}
  \forall a \in \{1, \dots, |\mathcal{E}_{\text{epic}}|\}, \quad &\sum_{b=1}^{|\mathcal{F}_{\text{proj}}|} M_{\text{EF}, ab} \ge 1 \\
  \forall b \in \{1, \dots, |\mathcal{F}_{\text{proj}}|\}, \quad &\left( \sum_{a=1}^{|\mathcal{E}_{\text{epic}}|} M_{\text{EF}, ab} \ge 1 \right) \wedge \left( \sum_{c=1}^{|\mathcal{S}_{\text{story}}|} M_{\text{FS}, bc} \ge 1 \right) \\
  \forall c \in \{1, \dots, |\mathcal{S}_{\text{story}}|\}, \quad &\left( \sum_{b=1}^{|\mathcal{F}_{\text{proj}}|} M_{\text{FS}, bc} \ge 1 \right) \wedge \left( \sum_{d=1}^{|\mathcal{U}_{\text{case}}|} M_{\text{SU}, cd} \ge 1 \right) \\
  \forall d \in \{1, \dots, |\mathcal{U}_{\text{case}}|\}, \quad &\sum_{c=1}^{|\mathcal{S}_{\text{story}}|} M_{\text{SU}, cd} \ge 1
  \end{aligned}
```

     - Transitive End-to-End Epic-to-UseCase Reachability Matrix:

```math
  \mathbf{M}_{\text{EU}} = \mathbf{M}_{\text{EF}} \cdot \mathbf{M}_{\text{FS}} \cdot \mathbf{M}_{\text{SU}} \in \mathbb{N}^{|\mathcal{E}_{\text{epic}}| \times |\mathcal{U}_{\text{case}}|}, \quad \forall d \in \{1, \dots, |\mathcal{U}_{\text{case}}|\}, \quad \sum_{a=1}^{|\mathcal{E}_{\text{epic}}|} M_{\text{EU}, ad} \ge 1
```

  3. Structured STPA Safety Traceability Invariants:
     - Let $`\mathcal{L}`$` denote System Losses, `$`\mathcal{H}`$` System Hazards, `$`\mathcal{U}`$` Unsafe Control Actions, `$`\mathcal{S}\mathcal{C}`$` Safety Constraints, and `$`\mathcal{F}\mathcal{M}`$ FMECA Failure Modes.
     - STPA Relational Incidence Matrices:

```math
  \begin{aligned}
  \mathbf{M}_{\text{Mitigates}} &\in \{0, 1\}^{|\mathcal{S}\mathcal{C}| \times |\mathcal{H}|}, \quad M_{\text{Mitigates}, kh} = 1 \iff \text{SC}_k \text{ mitigates } H_h \\
  \mathbf{M}_{\text{LeadsTo}} &\in \{0, 1\}^{|\mathcal{H}| \times |\mathcal{L}|}, \quad M_{\text{LeadsTo}, h\ell} = 1 \iff H_h \text{ leads to } L_\ell \\
  \mathbf{M}_{\text{Enforces}} &\in \{0, 1\}^{|\mathcal{S}\mathcal{C}| \times |\mathcal{U}|}, \quad M_{\text{Enforces}, ku} = 1 \iff \text{SC}_k \text{ constrains } \text{UCA}_u \\
  \mathbf{M}_{\text{Exposes}} &\in \{0, 1\}^{|\mathcal{F}\mathcal{M}| \times |\mathcal{H}|}, \quad M_{\text{Exposes}, mh} = 1 \iff \text{FM}_m \text{ exposes } H_h
  \end{aligned}
```

     - Unbroken STPA Safety Chain Invariant:

```math
  \forall \text{SC}_k \in \mathcal{S}\mathcal{C}, \quad \exists H \in \mathcal{H}, \, L \in \mathcal{L} \quad \text{such that } \text{Mitigates}(\text{SC}_k, H) \wedge \text{LeadsTo}(H, L)
```

     - Hazard, UCA, and Failure Mode Completeness:

```math
  \begin{aligned}
  \forall H_h \in \mathcal{H}, \quad &\left( \sum_{k=1}^{|\mathcal{S}\mathcal{C}|} M_{\text{Mitigates}, kh} \ge 1 \right) \wedge \left( \sum_{\ell=1}^{|\mathcal{L}|} M_{\text{LeadsTo}, h\ell} \ge 1 \right) \\
  \forall U_u \in \mathcal{U}, \quad &\sum_{k=1}^{|\mathcal{S}\mathcal{C}|} M_{\text{Enforces}, ku} \ge 1 \\
  \forall \text{FM}_m \in \mathcal{F}\mathcal{M}, \quad &\sum_{h=1}^{|\mathcal{H}|} M_{\text{Exposes}, mh} \ge 1
  \end{aligned}
```

  4. Level 1C ICD Interface Table Invariant:
     - Let $`\mathcal{C}_{\text{sub}} \subset \mathcal{V}_{\text{AST}}`$` denote subsystem classifiers, `$`\mathcal{P}_{\text{ports}} \subset \mathcal{V}_{\text{AST}}`$` boundary ports, and `$`\mathcal{F}_{\text{flows}} \subset \mathcal{V}_{\text{AST}}`$ interface flow connections.


#### 3. Computational Complexity & Algorithmic Bounds

Downstream Projections: Bidirectional Realization Matrices, STPA Matrices & ICD Tables Synthesis resides strictly in **Complexity Class P** (Deterministic Polynomial Time), executing in strictly deterministic time bounded by $`O(|\mathcal{S}_{\text{specs}}| \cdot |\mathcal{V}_{\text{AST}}| + |\mathcal{C}_{\text{sub}}|^2 + |\mathcal{F}_{\text{flows}}|)`$` and strictly deterministic space bounded by `$`O(|\mathcal{S}_{\text{specs}}| \cdot |\mathcal{V}_{\text{AST}}|)`$ in contiguous bump arena storage.

  **Mathematical Delineation from the 8 NP Frontiers**:
  - *Delineation from NP-1 (REQ-0117)*: NP-1 resolves temporal consistency over occurrence lifecycles in Allen's Interval Algebra using ORD-Horn SMT difference logic in $`O(N^3)`$ polynomial time. In contrast, REQ-0174 performs static incidence matrix population and coverage indexing between specifications and AST nodes without temporal networks, interval constraints, or consistency propagation.
  - *Delineation from NP-2 (REQ-0147)*: NP-2 addresses strongly NP-hard vector bin packing for structural allocation and interconnect channel multiplexing. In contrast, REQ-0174 synthesizes tabular projections of pre-allocated ICD signal flows and ports without solving multidimensional bin-packing or capacity optimization problems.
  - *Delineation from NP-3 (REQ-0061--REQ-0063)*: NP-3 formalizes subtyping lattice redefinition and multiple inheritance linearization via C3 linearization in $`O(V + E)`$ time. In contrast, REQ-0174 indexes concrete specification handles and AST nodes without computing inheritance lattices, poset meets, or type linearization orders.
  - *Delineation from NP-4 (REQ-0135)*: NP-4 minimizes STPA hazard cut-sets and Unsafe Control Actions via NP-complete Minimal Hitting Set reductions. In contrast, REQ-0174 consumes the already-minimized safety elements (Losses, Hazards, UCAs, Safety Constraints) and projects them into tabular relational matrices via deterministic relational cross-product scans without combinatorial set-covering algorithms.
  - *Delineation from NP-5 (REQ-0124)*: NP-5 analyzes discrete state machine reachability, deadlock, and livelock in orthogonal regions (PSPACE-complete / NP-complete Bounded Model Checking). In contrast, REQ-0174 operates at the static documentation projection layer, evaluating relational incidence matrices between existing AST models and documentation artifacts prior to dynamic simulation.
  - *Delineation from NP-6 (REQ-0105)*: NP-6 solves switched conservative flow networks using linear complementarity problems and Lemke pivoting (NP-complete). In contrast, REQ-0174 documents signal flow attributes and interface matrix topologies without solving switched piecewise-linear flow conservation equations.
  - *Delineation from NP-7 (REQ-0180)*: NP-7 performs register allocation and basic block scheduling in LUMI IR using Chaitin graph coloring (NP-complete). In contrast, REQ-0174 synthesizes downstream documentation matrices and Level 1C ICD tables within Subsystem 9, decoupled from backend machine registers and IR instruction scheduling.
  - *Delineation from NP-8 (REQ-0197)*: NP-8 proves satisfiability of first-order invariant contracts via DPLL(T) SMT solvers. In contrast, REQ-0174 verifies structural matrix completeness through deterministic matrix row and column summation algorithms without quantifier reasoning or SMT solver calls.

  **Asymptotic Complexity Analysis**:
  Let $`N_{\text{spec}} = |\mathcal{S}_{\text{specs}}|`$`, `$`N_{\text{ast}} = |\mathcal{V}_{\text{AST}}|`$`, `$`N_{\text{sub}} = |\mathcal{C}_{\text{sub}}|`$`, and `$`N_{\text{flow}} = |\mathcal{F}_{\text{flows}}|`$.
  1. *Global Realization Incidence Matrix Synthesis Phase*:
     - Traversing specification handles and marking realized AST nodes in the incidence matrix executes in:

```math
  T_{\text{realize}}(N_{\text{spec}}, N_{\text{ast}}) \in O(N_{\text{spec}} \cdot N_{\text{ast}}), \quad S_{\text{realize}}(N_{\text{spec}}, N_{\text{ast}}) \in O(N_{\text{spec}} \cdot N_{\text{ast}})
```

  2. *Coverage Invariant Verification (Row & Column Sums)*:
     - Computing the row sums $`\sum_j R_{ij}`$` and column sums `$`\sum_i R_{ij}`$ requires a single linear pass over matrix cells:

```math
  T_{\text{coverage}}(N_{\text{spec}}, N_{\text{ast}}) \in O(N_{\text{spec}} \cdot N_{\text{ast}}), \quad S_{\text{coverage}} \in O(1)
```

  3. *Hierarchical Specification Cascade Verification*:
     - Multiplying intermediate sparse incidence sub-matrices $`\mathbf{M}_{\text{EF}}`$`, `$`\mathbf{M}_{\text{FS}}`$`, and `$`\mathbf{M}_{\text{SU}}`$ executes in time proportional to non-zero realization edges:

```math
  T_{\text{cascade}} \in O(|\mathcal{E}_{\text{epic}}| \cdot |\mathcal{F}_{\text{proj}}| + |\mathcal{F}_{\text{proj}}| \cdot |\mathcal{S}_{\text{story}}| + |\mathcal{S}_{\text{story}}| \cdot |\mathcal{U}_{\text{case}}|)
```

  4. *STPA Safety Relational Matrix Synthesis*:
     - Cross-referencing Safety Constraints to Hazards and Hazards to Losses executes in:

```math
  T_{\text{stpa}} \in O(|\mathcal{S}\mathcal{C}| \cdot |\mathcal{H}| + |\mathcal{H}| \cdot |\mathcal{L}| + |\mathcal{S}\mathcal{C}| \cdot |\mathcal{U}| + |\mathcal{F}\mathcal{M}| \cdot |\mathcal{H}|)
```

  5. *Level 1C ICD Table Synthesis*:
     - Synthesizing the subsystem N^2 matrix and formatting the 10-column Signal Flow Dictionary executes in:

```math
  T_{\text{icd}}(N_{\text{sub}}, N_{\text{flow}}) \in O(N_{\text{sub}}^2 + N_{\text{flow}}), \quad S_{\text{icd}} \in O(N_{\text{sub}}^2 + N_{\text{flow}})
```

  6. *Aggregate Compilation Unit Complexity*:
     - Summing across all matrix synthesis and verification passes:

```math
  T_{\text{total}} \in O(N_{\text{spec}} \cdot N_{\text{ast}} + N_{\text{sub}}^2 + N_{\text{flow}})
```

     - Aggregate space complexity is strictly $`O(N_{\text{spec}} \cdot N_{\text{ast}} + N_{\text{sub}}^2 + N_{\text{flow}})`$ in contiguous bump arena storage, requiring zero external heap allocations.
  7. *Parallel Work-Stealing Scaling (Directive 2)*:
     - Partitioning independent subsystems across $`N_{\text{max\_workers}}`$ threads on a bounded work-stealing thread pool achieves near-linear speedup:

```math
  T_{\text{parallel}}(N, N_{\text{max\_workers}}) \in O\left( \frac{T_{\text{total}}}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

#### 4. Verification & Conformance Criteria

Automated test suites shall deterministically verify compliance against synthetic abstract MBSE models (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Port_0`, `Port_1`, `Flow_A`, `Flow_B`, `Subsystem_0`, `Subsystem_1`, `Epic_0`, `Epic_1`, `Feature_0`, `Feature_1`, `Story_0`, `Story_1`, `UseCase_0`, `UseCase_1`, `Loss_0`, `Hazard_0`, `UCA_0`, `SafetyConstraint_0`, `FailureMode_0`, `param_x : Real`) across the following 16 verification gates:

  1. **Full Bidirectional Realization Matrix Synthesis Gate**: Ingest a synthetic compilation unit containing $`|\mathcal{V}_{\text{AST}}| = 200`$` nodes and `$`|\mathcal{S}_{\text{specs}}| = 50`$` specification artifacts. Assert that the projection engine synthesizes incidence matrix `$`\mathbf{R}`$`, all row sums satisfy `$`\sum_j R_{ij} \ge 1`$`, all column sums satisfy `$`\sum_i R_{ij} \ge 1`$, and zero diagnostics are emitted.
  2. **Orphan AST Node Detection & Rejection Gate (`E0500`)**: Ingest a synthetic model containing an AST classifier `Classifier_Beta` that is unmapped to any downstream specification artifact. Assert compile-time rejection with diagnostic error code `E0500` (`OrphanASTNodeViolation`) identifying the exact unmapped AST node handle.
  3. **Ungrounded Specification Artifact Rejection Gate (`E0500`)**: Ingest a synthetic model containing a downstream Feature `Feature_1` that lacks an originating AST node mapping. Assert compile-time rejection with diagnostic error code `E0500` (`UngroundedSpecificationViolation`).
  4. **Epic-to-Feature Cascade Linkage Gate**: Verify that the intermediate incidence sub-matrix $`\mathbf{M}_{\text{EF}}`$ maps each synthetic Epic `Epic_0` to at least one Feature `Feature_0`, and that every projected Feature is contained within at least one Epic.
  5. **Feature-to-User-Story Cascade Linkage Gate**: Verify that the intermediate incidence sub-matrix $`\mathbf{M}_{\text{FS}}`$ maps each Feature `Feature_0` to at least one User Story `Story_0`, and that every User Story is linked to its owning Feature.
  6. **User-Story-to-Use-Case Cascade Linkage Gate**: Verify that the intermediate incidence sub-matrix $`\mathbf{M}_{\text{SU}}`$ maps each User Story `Story_0` to at least one Use Case `UseCase_0`, and that every Use Case executes at least one User Story.
  7. **Transitive End-to-End Realization Reachability Gate**: Verify that the transitive matrix product $`\mathbf{M}_{\text{EU}} = \mathbf{M}_{\text{EF}} \cdot \mathbf{M}_{\text{FS}} \cdot \mathbf{M}_{\text{SU}}`$` demonstrates non-zero reachability (`$`\sum_a M_{\text{EU}, ad} \ge 1`$) for 100% of generated Use Cases back to root Epics.
  8. **STPA Unbroken Safety Chain Conformance Gate**: Ingest a synthetic model declaring Losses `Loss_0`, Hazards `Hazard_0`, UCAs `UCA_0`, and Safety Constraints `SafetyConstraint_0`. Assert that the STPA matrix correctly links $`\text{Mitigates}(\text{SafetyConstraint}_0, \text{Hazard}_0) \wedge \text{LeadsTo}(\text{Hazard}_0, \text{Loss}_0)`$ with zero diagnostics emitted.
  9. **Broken Safety Traceability Chain Rejection Gate (`E0500`)**: Ingest a synthetic model declaring a safety constraint `SafetyConstraint_0` that mitigates a hazard that does not lead to any Loss. Assert compile-time rejection with diagnostic error code `E0500` (`BrokenSafetyTraceabilityViolation`).
  10. **Unmitigated System Hazard Rejection Gate (`E0500`)**: Ingest a synthetic model declaring hazard `Hazard_0` lacking any mitigating Safety Constraint. Assert compile-time rejection with diagnostic error code `E0500` (`UnmitigatedHazardViolation`).
  11. **Unconstrained UCA Rejection Gate (`E0500`)**: Ingest a synthetic model declaring unsafe control action `UCA_0` without an enforcing Safety Constraint. Assert compile-time rejection with diagnostic error code `E0500` (`UnconstrainedUCAViolation`).
  12. **FMECA Failure Mode Mapping Rejection Gate (`E0500`)**: Ingest a synthetic model declaring failure mode `FailureMode_0` lacking an associated System Hazard. Assert compile-time rejection with diagnostic error code `E0500` (`UnmappedFailureModeViolation`).
  13. **Level 1C ICD N^2 System Matrix Symmetry Gate**: Verify that the N^2 system interface matrix for synthetic subsystems `Subsystem_0` and `Subsystem_1` correctly maps interconnected boundary ports `Port_0` and `Port_1` with exact flow directional tracking.
