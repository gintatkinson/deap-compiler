### REQ-0042: Circular Dependency & Metamodel Inheritance Cycle Detection

- **Normative Statement**: The Core Metamodel, Node Arena & AST Graph Engine shall implement a deterministic cycle detection engine based on Tarjan's strongly connected components (SCC) algorithm to identify, isolate, and reject circular dependencies across all metamodel relationship graphs during semantic analysis at compile time. The cycle detection engine shall verify the following directed relational subgraphs constructed from the abstract syntax graph:
  1. Specialization and Inheritance Hierarchies (`specializes`, `:>`): Every classifier definition (`ClassifierDef`) participating in single or multiple generalization must form a strictly acyclic specialization graph $`G_{\text{inherit}}`$`. Direct self-specialization (`$`u \text{ specializes } u`$`) and mutual circular specialization chains of arbitrary length (`$`v_1 :> v_2 :> \dots :> v_k :> v_1`$) shall be strictly prohibited.
  2. Structural Composition and Containment Hierarchies (`owns`, `contains`): The structural composition graph $`G_{\text{comp}}`$ linking parent packages, definitions, usages, and nested parts shall be strictly acyclic. No structural entity shall directly or transitively contain itself as an owned element.
  3. Feature Redefinition and Subsetting Hierarchies (`redefines`, `:>>`, `subsets`): All feature redefinition and feature subsetting relations between feature usages (`FeatureUsage`) must form a strictly acyclic dependency graph $`G_{\text{redef}}`$. Circular redefinition chains shall be strictly rejected.
  4. Type Alias and Value Definition Dependencies: Circular equivalence chains in type aliases or mutually dependent expressions lacking base cases must be detected and rejected.

  When any cycle is detected within $`G_{\text{inherit}}`$`, `$`G_{\text{comp}}`$`, or `$`G_{\text{redef}}`$`, the AST engine shall deterministically reconstruct an elementary directed cycle path `$`\mathcal{P}_{\text{cycle}} = \langle v_1, v_2, \dots, v_k, v_1 \rangle`$ and emit structured diagnostic error code `E0203` in accordance with the standardized diagnostic taxonomy of REQ-0191. The emitted diagnostic record must include the primary error code `E0203`, the exact source byte spans and line/column coordinates of all participating relation declarations, the cycle category (`InheritanceCycle`, `ContainmentCycle`, or `RedefinitionCycle`), and an ordered textual traceback representing the directed circular path.

  In accordance with Architectural Directive 4, REQ-0013, and REQ-0190, the cycle detection engine shall implement synchronization token error recovery: upon detecting a cycle and emitting diagnostic error code `E0203`, the engine shall record the diagnostic into the preallocated diagnostic sink buffer $`\mathcal{D}_{\text{sink}}`$`, mark the offending closing back-edge `$`(v_k, v_1)`$` as invalid, and substitute a typed cycle error sentinel `$`\bot_{\text{cycle}}`$` to decouple the circular dependency in a sanitized overlay graph `$`\mathcal{E}_{\text{overlay}}`$`. This decoupling enables the compiler to continue type checking, scope validation, and dependency analysis across remaining independent AST subgraphs without aborting on first fault. If accumulated diagnostics reach the sink capacity limit `$`C_{\text{max\_errors}}`$, the compiler shall emit diagnostic error code `E0199` and terminate compilation gracefully.

  All graph vertices and relational edges shall be addressed exclusively via deterministic 32-bit typed node handles (`NodeHandle<T>`) referencing contiguous typed bump arena storage in accordance with REQ-0009, REQ-0034, and REQ-0035, strictly eliminating raw memory pointers. In accordance with Architectural Directive 1 and REQ-0010, every lowered classifier definition and relational edge node must receive an immutable, deterministic RFC 4122 UUIDv5 identifier computed from the compiler namespace OID and canonical fully qualified symbol path. In accordance with Architectural Directive 3 and REQ-0036, all symbol names and path strings shall be interned into the global deduplicated symbol interner pool. Parallel cycle detection across independent, weakly connected component subgraphs shall be scheduled strictly onto a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with Architectural Directive 2 and REQ-0012. In accordance with Architectural Directive 5, REQ-0011, and REQ-0196, the cycle detection engine shall enforce a deterministic, non-panicking execution contract with total-function termination across all inputs, evaluating performance gates (< 25 ms execution latency, < 100 MB RSS memory) exclusively in compiled Release mode (`--release`). All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Classifier_Gamma`, `Classifier_Delta`, `Part_0`, `Part_1`, `Usage_1`, `Usage_2`, `Port_1`, `param_x : Real`) with zero hardcoded domain concepts.

- **Formal Invariant**: Let $`\mathcal{V} \subset \mathbb{N}_{32}`$` denote the universe of active arena node handles representing metamodel entities, and let `$`\mathcal{E} \subseteq \mathcal{V} \times \mathcal{V} \times \mathcal{K}_{\text{rel}}`$` denote the set of directed relationship edges, where `$`\mathcal{K}_{\text{rel}} = \{ \text{Inheritance}, \text{Containment}, \text{Redefinition}, \text{Subsetting} \}`$`. The metamodel multigraph `$`G_{\text{metamodel}}`$ is partitioned into distinct single-relation directed graphs:

```math
\begin{aligned}
G_{\text{inherit}} &= (\mathcal{V}_{\text{class}}, \mathcal{E}_{\text{inherit}}) \quad \text{where } (u, v) \in \mathcal{E}_{\text{inherit}} \iff \text{Specializes}(u, v) \\
G_{\text{comp}} &= (\mathcal{V}_{\text{elem}}, \mathcal{E}_{\text{comp}}) \quad \text{where } (u, v) \in \mathcal{E}_{\text{comp}} \iff \text{Contains}(u, v) \\
G_{\text{redef}} &= (\mathcal{V}_{\text{feat}}, \mathcal{E}_{\text{redef}}) \quad \text{where } (u, v) \in \mathcal{E}_{\text{redef}} \iff \text{Redefines}(u, v)
\end{aligned}
```

Let $`\to^+`$` denote the non-empty transitive closure of the directed edge relation in any directed graph `$`G = (\mathcal{V}, \mathcal{E})`$:

```math
u \to^+ v \iff \exists \langle w_0, w_1, \dots, w_m \rangle, \; m \ge 1, \; w_0 = u, \; w_m = v, \; \forall i \in \{0, \dots, m-1\}, \, (w_i, w_{i+1}) \in \mathcal{E}
```

The transitive descendant set $`\text{Descendants}(v)`$` for any vertex `$`v \in \mathcal{V}`$ is defined as:

```math
\text{Descendants}(v) = \{ u \in \mathcal{V} \mid v \to^+ u \}
```

Universal Graph Acyclicity Invariant: A directed graph $`G = (\mathcal{V}, \mathcal{E})`$ is strictly acyclic if and only if no vertex is a descendant of itself:

```math
\text{IsAcyclic}(G) \iff \forall v \in \mathcal{V}, \quad v \notin \text{Descendants}(v) \iff \forall v \in \mathcal{V}, \quad \neg(v \to^+ v)
```

Equivalence Partitioning via Strongly Connected Components: Let $`\sim_{\text{SCC}}`$` denote the mutual reachability equivalence relation over `$`\mathcal{V}`$`, where `$`u \to^* v`$ denotes the reflexive-transitive closure:

```math
u \sim_{\text{SCC}} v \iff (u \to^* v) \wedge (v \to^* u)
```

The quotient set $`\mathcal{V} / \sim_{\text{SCC}} \;= \{ C_1, C_2, \dots, C_p \}`$` partitions `$`\mathcal{V}`$ into disjoint strongly connected components:

```math
\bigcup_{i=1}^{p} C_i = \mathcal{V}, \quad \forall i \ne j, \, C_i \cap C_j = \emptyset
```

Tarjan Strongly Connected Component Singleton Invariant: A directed graph $`G`$ is acyclic if and only if every strongly connected component computed by Tarjan's algorithm is a trivial singleton containing zero self-loops:

```math
\text{IsAcyclic}(G) \iff \forall C \in \text{TarjanSCC}(G), \quad (|C| = 1 \wedge \forall v \in C, \, (v, v) \notin \mathcal{E})
```

Conversely, a cycle exists if and only if there exists a component with cardinality greater than one or containing a self-loop:

```math
\text{HasCycle}(G) \iff \exists C \in \text{TarjanSCC}(G) : (|C| \gt 1) \vee (\exists v \in C : (v, v) \in \mathcal{E})
```

Tarjan DFS Discovery Index and Lowlink Recurrence: For each node $`u \in \mathcal{V}`$`, let `$`\text{dfn}(u) \in \mathbb{N}_0`$` denote the depth-first discovery index and `$`\text{lowlink}(u) \in \mathbb{N}_0`$` denote the lowest discovery index reachable via DFS tree edges and back-edges within the active stack `$`\mathcal{S}_{\text{stack}}`$:

```math
\text{lowlink}(u) = \min \left( \{ \text{dfn}(u) \} \cup \{ \text{lowlink}(w) \mid (u, w) \in \mathcal{E}_{\text{tree}} \} \cup \{ \text{dfn}(w) \mid (u, w) \in \mathcal{E} \setminus \mathcal{E}_{\text{tree}}, \, w \in \mathcal{S}_{\text{stack}} \} \right)
```

An entity $`u`$ is the root of a strongly connected component if and only if:

```math
\text{IsSCCRoot}(u) \iff \text{lowlink}(u) = \text{dfn}(u)
```

Deterministic Elementary Cycle Path Extraction: For every non-trivial component $`C \in \text{TarjanSCC}(G)`$` where `$`|C| \gt 1`$` or `$`\exists v \in C, (v, v) \in \mathcal{E}`$`, the engine reconstructs the deterministic elementary directed cycle path `$`\mathcal{P}_{\text{cycle}}`$:

```math
\mathcal{P}_{\text{cycle}} = \langle v_1, v_2, \dots, v_k, v_1 \rangle
```

where $`k \ge 1`$`, `$`v_i \in C`$` for all `$`i \in \{1, \dots, k\}`$`, `$`(v_i, v_{i+1}) \in \mathcal{E}`$` for all `$`i \in \{1, \dots, k-1\}`$`, and `$`(v_k, v_1) \in \mathcal{E}`$` is the closing back-edge. Determinism is enforced by selecting the cycle origin `$`v_1 = \min_{v \in C} \text{Handle}(v)`$` and sorting successor candidates by interned identifier `$`\text{SymbolId}(w)`$.

Diagnostic Code Binding Invariant: Any detected cycle in $`G_{\text{inherit}}`$`, `$`G_{\text{comp}}`$`, or `$`G_{\text{redef}}`$ triggers structured diagnostic error code `E0203` per REQ-0191:

```math
\begin{aligned}
\exists C \in \text{TarjanSCC}(G_{\text{inherit}}) : (|C| \gt 1 \vee \exists v \in C, (v, v) \in \mathcal{E}_{\text{inherit}}) &\implies \text{Diagnostic}(\mathcal{P}_{\text{cycle}}, \text{DiagnosticCode::E0203}, \text{InheritanceCycle}) \in \mathcal{D}_{\text{sink}} \\
\exists C \in \text{TarjanSCC}(G_{\text{comp}}) : (|C| \gt 1 \vee \exists v \in C, (v, v) \in \mathcal{E}_{\text{comp}}) &\implies \text{Diagnostic}(\mathcal{P}_{\text{cycle}}, \text{DiagnosticCode::E0203}, \text{ContainmentCycle}) \in \mathcal{D}_{\text{sink}} \\
\exists C \in \text{TarjanSCC}(G_{\text{redef}}) : (|C| \gt 1 \vee \exists v \in C, (v, v) \in \mathcal{E}_{\text{redef}}) &\implies \text{Diagnostic}(\mathcal{P}_{\text{cycle}}, \text{DiagnosticCode::E0203}, \text{RedefinitionCycle}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
```

Sanitized Overlay Graph Invariant: To support synchronization token error recovery and continue compilation without cascading cycle errors, the engine severs the back-edge $`(v_k, v_1)`$ in the active compilation overlay:

```math
\mathcal{E}_{\text{overlay}} = \mathcal{E} \setminus \{ (v_k, v_1) \}
```

```math
\text{IsAcyclic}((\mathcal{V}, \mathcal{E}_{\text{overlay}})) \equiv \text{true} \quad (\text{upon pruning all closing cycle back-edges})
```

Deterministic UUIDv5 & Handle Addressing Invariant: Every graph vertex $`v`$` and relational edge `$`e`$ possesses an immutable UUIDv5 identifier and an arena handle:

```math
\begin{aligned}
\forall u \in \mathcal{V} \cup \mathcal{E}, \quad \text{UUID}(u) &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(u)) \\
\forall u \in \mathcal{V} \cup \mathcal{E}, \quad \text{Handle}(u) &= \langle \text{ArenaId}, \text{Offset}_u \rangle \in \mathbb{N}_{32}
\end{aligned}
```

- **Computational Complexity & Algorithmic Bounds**: Cycle verification across all metamodel graphs executes strictly within Complexity Class $`\mathbf{P}`$. The algorithmic bounds across data structures and execution phases are formalized as follows:
  1. Dense Array State Allocation: Tarjan's algorithm allocates three auxiliary integer/boolean arrays (`dfn`, `lowlink`, `on_stack`) indexed directly by the 32-bit arena slot offset $`\text{Offset}_u \in [0, |\mathcal{V}| - 1]`$`. Direct slot indexing eliminates hash table lookup overhead and achieves `$`O(1)`$ constant time state queries and updates.
  2. Traversal and SCC Identification: In a directed graph $`G = (\mathcal{V}, \mathcal{E})`$` with `$`V = |\mathcal{V}|`$` vertices and `$`E = |\mathcal{E}|`$` edges, Tarjan's DFS visits each vertex `$`v \in \mathcal{V}`$` exactly once, pushes each vertex to the active stack `$`\mathcal{S}_{\text{stack}}`$` exactly once, pops each vertex exactly once, and inspects each directed edge `$`(u, w) \in \mathcal{E}`$ exactly once:

```math
T_{\text{SCC}}(V, E) = \sum_{v \in \mathcal{V}} \left( O(1) + \sum_{w \in \text{Adj}(v)} O(1) \right) \in O(V + E)
```

  3. Deterministic Cycle Traceback Extraction: For each non-trivial SCC $`C`$` where `$`|C| \gt 1`$` or a self-loop exists, extracting the elementary cycle `$`\mathcal{P}_{\text{cycle}}`$` via breadth-first search or predecessor pointer reversal requires time proportional to the induced subgraph size `$`O(|V_C| + |E_C|)`$`. Summed across all detected cycles, total traceback extraction time is strictly bounded by `$`O(V + E)`$.
  4. Parallel Partitioning Bounds: When independent, weakly connected subgraphs $`\{ G_1, G_2, \dots, G_m \}`$` are partitioned and dispatched across the bounded work-stealing thread pool with `$`N_{\text{max\_workers}}`$ workers:

```math
T_{\text{parallel}}(V, E) \in O\left( \frac{V + E}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

  5. Space Complexity: Auxiliary memory overhead is strictly $`O(V)`$` for the DFS state arrays and the active traversal stack `$`\mathcal{S}_{\text{stack}}`$` (`$`|\mathcal{S}_{\text{stack}}| \le V`$`). Memory overhead for the diagnostic sink is strictly bounded by `$`O(C_{\text{max\_errors}}) = O(1)`$`, guaranteeing that total auxiliary space remains strictly `$`O(V)`$ with zero unbounded heap allocations.

- **Verification & Conformance Criteria**: Automated test suites shall deterministically verify compliance against synthetic abstract MBSE models (e.g., `Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Classifier_Gamma`, `Classifier_Delta`, `Part_0`, `Part_1`, `Usage_1`, `Usage_2`, `Port_1`, `param_x : Real`) across the following verification gates:
  1. Direct Self-Specialization Gate ($`A :> A`$):
     - Ingest a model containing `Classifier_Alpha :> Classifier_Alpha`.
     - Assert that the cycle detection engine detects a trivial SCC with a self-loop.
     - Assert deterministic emission of diagnostic error code `E0203` (`InheritanceCycle`).
     - Assert that the cycle traceback path is exactly $`\langle \text{Classifier\_Alpha}, \text{Classifier\_Alpha} \rangle`$.
  2. Two-Node Mutual Specialization Gate ($`A :> B \wedge B :> A`$):
     - Ingest a model containing `Classifier_Alpha :> Classifier_Beta` and `Classifier_Beta :> Classifier_Alpha`.
     - Assert that Tarjan's algorithm identifies an SCC of cardinality 2.
     - Assert deterministic emission of diagnostic error code `E0203`.
     - Assert that the cycle traceback path contains both nodes in deterministic order: $`\langle \text{Classifier\_Alpha}, \text{Classifier\_Beta}, \text{Classifier\_Alpha} \rangle`$.
  3. Multi-Node Specialization Cycle Gate ($`A \to B \to C \to D \to A`$):
     - Ingest a model containing a 4-node circular inheritance chain: `Classifier_Alpha :> Classifier_Beta`, `Classifier_Beta :> Classifier_Gamma`, `Classifier_Gamma :> Classifier_Delta`, and `Classifier_Delta :> Classifier_Alpha`.
     - Assert deterministic emission of diagnostic error code `E0203` with exact cycle traceback path $`\langle \text{Classifier\_Alpha}, \text{Classifier\_Beta}, \text{Classifier\_Gamma}, \text{Classifier\_Delta}, \text{Classifier\_Alpha} \rangle`$.
     - Assert that the reported byte spans map accurately to the closing specialization declaration.
  4. Structural Composition Containment Cycle Gate:
     - Ingest a model where `Part_0` contains `Part_1`, and `Part_1` contains `Part_0`, or where `Package_0` contains `Package_1` and `Package_1` contains `Package_0`.
     - Assert deterministic emission of diagnostic error code `E0203` (`ContainmentCycle`).
     - Assert that the composition hierarchy is rejected at compile time.
  5. Feature Redefinition Cycle Gate:
     - Ingest a model where `Usage_1` redefines `Usage_2` (`:>>`), and `Usage_2` redefines `Usage_1`.
     - Assert deterministic emission of diagnostic error code `E0203` (`RedefinitionCycle`).
  6. Disjoint Multi-Cycle & Error Recovery Gate:
     - Ingest an AST model containing two disjoint inheritance cycles ($`C_1 = \langle \text{Classifier\_Alpha}, \text{Classifier\_Beta}, \text{Classifier\_Alpha} \rangle`$` and `$`C_2 = \langle \text{Classifier\_Gamma}, \text{Classifier\_Delta}, \text{Classifier\_Gamma} \rangle`$) alongside valid acyclic subgraphs.
     - Assert that synchronization token error recovery accumulates both distinct `E0203` diagnostic records without early termination.
     - Assert that back-edges are pruned in $`\mathcal{E}_{\text{overlay}}`$, allowing semantic analysis on valid subgraphs to proceed without cascading false positives.
     - Inject malformed cyclic declarations exceeding $`C_{\text{max\_errors}}`$ and assert that the compiler terminates gracefully with diagnostic error code `E0199`.
  7. Deterministic Non-Panicking Execution & Performance Gate:
     - Execute cycle detection across pathologically malformed and deeply nested graphs (dense cyclic cliques, disconnected components, self-referential chains).
     - Assert total-function termination with zero panics or stack overflow crashes.
     - In compiled Release mode (`--release`), benchmark cycle detection over a synthetic graph of $`10^5`$` classifier nodes and `$`2 \cdot 10^5`$ specialization edges, asserting execution latency strictly below 25 ms and peak RSS memory strictly below 100 MB in accordance with REQ-0011 and REQ-0196.
  8. Bitwise Determinism Gate:
     - Execute 10 consecutive compilation runs on identical AST models with circular dependencies.
     - Assert that generated diagnostic collections, cycle traceback paths, node handle assignments, and UUIDv5 identifiers are 100% bitwise identical with zero diff churn.
