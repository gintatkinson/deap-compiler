### REQ-0007: Multi-File Compilation Unit Resolution & Hierarchical Package Scoping

- **Normative Statement**: The compiler architecture shall resolve multi-file compilation units and enforce hierarchical package scoping across modular schema libraries without cross-module symbol collision or namespace pollution. Each input compilation unit file ingested from the workspace shall be bound to an explicit or derived hierarchical package namespace corresponding to its declared package path. The compiler must construct and maintain a global package forest wherein every package possesses a globally unique fully qualified name (FQN) formed by delimiter-separated segment identifiers (`::`). Symbol visibility and lexical scoping rules must strictly prevent ambiguous symbol bindings: local declarations within a package shall take precedence over imported symbols, parent package declarations shall be accessible along the lexical ancestor chain, and external symbols shall require explicit qualified access (e.g., `Package_0::Package_1::Classifier_Alpha`) or unambiguous import bindings. If an unqualified symbol reference resolves to multiple imported candidate symbols from distinct target packages, the compiler shall reject the ambiguity as a fatal error. The compiler shall enforce a maximum package nesting depth of $`D_{\max} = 16`$. If a multi-file compilation unit attempts to declare conflicting symbols in the same package scope, references an unresolvable package path, exceeds the maximum nesting depth, or introduces an ambiguous unqualified symbol reference, the compiler shall halt execution and emit diagnostic error code `E0100` citing the offending compilation unit identifier, package path, symbol name, and source byte spans.

- **Formal Invariant**: Let $`\mathcal{U}`$` denote the set of all input compilation units across the workspace. Let `$`\mathcal{P}`$` denote the set of hierarchical packages comprising the global compilation package forest. For each package `$`P \in \mathcal{P}`$`, let `$`\text{FQN}(P) = \langle p_1, p_2, \dots, p_k \rangle`$` represent its fully qualified hierarchical package path with depth `$`\text{Depth}(P) = k \le D_{\max} = 16`$`. Let `$`\text{Declared}(P)`$` represent the set of symbols locally declared within package `$`P`$`, and let `$`\text{Exported}(P) \subseteq \text{Declared}(P)`$ represent the subset of symbols possessing public export visibility.

The qualified symbol namespace of package $`P`$ satisfies:

```math
\text{QualifiedNamespace}(P) = \{ \text{FQN}(P) :: \sigma \mid \sigma \in \text{Exported}(P) \}
```

Disjoint Qualified Namespace Invariant: for all distinct packages $`P_i, P_j \in \mathcal{P}`$` with `$`P_i \neq P_j`$:

```math
\text{FQN}(P_i) \neq \text{FQN}(P_j) \implies \text{QualifiedNamespace}(P_i) \cap \text{QualifiedNamespace}(P_j) = \emptyset
```

Let $`\text{Imports}(P_{\text{src}})`$` denote the set of import declarations active within referencing package `$`P_{\text{src}}`$`. For an unqualified symbol query `$`\sigma`$`, let `$`\text{ImportTargets}(P_{\text{src}}, \sigma)`$` denote the set of imported target packages providing an exported symbol matching `$`\sigma`$:

```math
\text{ImportTargets}(P_{\text{src}}, \sigma) = \{ P_{\text{tgt}} \in \mathcal{P} \mid \text{Import}(P_{\text{src}}, P_{\text{tgt}}) \wedge \sigma \in \text{Exported}(P_{\text{tgt}}) \}
```

Unambiguous Import Invariant: for every referencing package $`P_{\text{src}} \in \mathcal{P}`$` and every referenced unqualified symbol `$`\sigma`$:

```math
|\text{ImportTargets}(P_{\text{src}}, \sigma)| \le 1
```

Symbol Resolution Mapping: the resolution function $`\text{Resolve}(\sigma, P_{\text{src}})`$ evaluates deterministically as:

```math
\text{Resolve}(\sigma, P_{\text{src}}) = \begin{cases}
\text{FQN}(P_{\text{src}}) :: \sigma, & \text{if } \sigma \in \text{Declared}(P_{\text{src}}) \\
\text{FQN}(P_{\text{tgt}}) :: \sigma, & \text{if } \sigma \notin \text{Declared}(P_{\text{src}}) \wedge \exists! P_{\text{tgt}} \in \text{ImportTargets}(P_{\text{src}}, \sigma) \\
\text{Resolve}(\sigma, \text{Parent}(P_{\text{src}})), & \text{if } \sigma \notin \text{Declared}(P_{\text{src}}) \wedge \text{ImportTargets}(P_{\text{src}}, \sigma) = \emptyset \wedge P_{\text{src}} \neq \text{Root} \\
\bot, & \text{otherwise}
\end{cases}
```

Ambiguity and Unresolved Reference Diagnostic Gate:

```math
\forall \sigma \in \text{References}(P_{\text{src}}), \quad (|\text{ImportTargets}(P_{\text{src}}, \sigma)| \gt 1 \lor \text{Resolve}(\sigma, P_{\text{src}}) = \bot) \implies \text{Diagnostic}(\sigma, P_{\text{src}}) = \text{E0100}
```

Bounded Lexical Nesting Depth Invariant:

```math
\forall P \in \mathcal{P}, \quad \text{Depth}(P) \le 16
```

- **Computational Complexity & Algorithmic Bounds**: Multi-file compilation unit resolution and hierarchical package scoping execute within Complexity Class $`\mathbf{P}`$`. Ingestion of compilation units and construction of the package forest execute in deterministic linear time `$`O(|V| + |E|)`$` with respect to package vertices `$`V = \mathcal{P}`$` and containment or import edges `$`E`$`. Symbol table population scales as `$`O(N)`$` with respect to the total declared symbol count `$`N = \sum_{P \in \mathcal{P}} |\text{Declared}(P)|`$`. Scope lookup along the lexical ancestor chain executes in `$`O(D)`$` time where `$`D`$` is the package nesting depth (`$`D \le D_{\max} = 16`$`), bounded by constant `$`O(1)`$` amortized time lookups per scope frame via hash-indexed symbol tables. Unambiguous import candidate validation evaluates in `$`O(K)`$` time where `$`K = |\text{Imports}(P_{\text{src}})| \le |V|`$`. Total symbol resolution across all `$`M`$` symbol reference sites in the compilation suite executes in deterministic time `$`O(M \cdot D) = O(M)`$`. Auxiliary memory consumption is strictly bounded by `$`O(N)`$ for interned symbol identifiers, package symbol tables, and scope frame references.

- **Verification & Conformance Criteria**: Compliance shall be verified via automated deterministic test suites using synthetic MBSE models (e.g., `Package_0`, `Package_1`, `Package_2` declaring classifiers `Classifier_Alpha`, `Classifier_Beta` and ports `Port_1`, `Flow_A`). The test framework shall assert:
  1. Multi-file compilation units distributed across directory hierarchies correctly assemble into hierarchical package trees, and fully qualified path lookups (e.g., `Package_0::Package_1::Classifier_Alpha`) resolve to the exact declared target node.
  2. Identical local symbol names declared across distinct packages (e.g., `Package_0::Classifier_Alpha` and `Package_1::Classifier_Alpha`) maintain complete namespace isolation with zero cross-module symbol collision.
  3. Single imported symbols resolve unambiguously, and local declarations shadow outer ancestor declarations without polluting parent or sibling scopes.
  4. If two imported packages export an identical symbol name $`\sigma`$` and an unqualified reference to `$`\sigma`$` is evaluated in referencing package `$`P_{\text{src}}`$, the compiler halts execution and emits diagnostic error code `E0100` citing the conflicting package paths and source span coordinates.
  5. Any attempt to declare a package hierarchy exceeding nesting depth $`D_{\max} = 16`$, access an unexported private symbol from an external package, or resolve a nonexistent package path halts compilation with diagnostic error code `E0100`.
  6. Recompilation across repeated independent runs produces bitwise-identical symbol tables and AST representations with zero diff churn.
