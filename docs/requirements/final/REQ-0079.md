### REQ-0079: SysML v2 StateDefinition (`state def`), StateUsage (`state`) & ParallelState

#### 1. Normative Statement

The Core Metamodel, Node Arena & AST Graph Engine and OMG SysML v2 metamodel lowering engine shall formalize state machine definitions, hierarchical state usages, and concurrent regions as first-class AST elements specializing KerML `Behavior` and `Occurrence`. In the SysML v2 taxonomic hierarchy:
  - `StateDefinition` (`state def`) shall specialize `ActionDefinition` (which transitively specializes KerML `Behavior`, `OccurrenceDefinition`, `Class`, `Classifier`, `Type`, and `Namespace`). A `StateDefinition` defines a state machine classifier encompassing state configurations, actions, transitions, and sub-states.
  - `StateUsage` (`state`) shall specialize `ActionUsage` (which transitively specializes KerML `OccurrenceUsage`, `Feature`, and `Behavior`), representing an instantiated state within an enclosing state machine, composite state, or structural part context.

  The lowering engine shall formalize hierarchical state machines as a rooted state containment tree $`(S, \sqsubseteq)`$`, wherein `$`s_1 \sqsubset s_2`$` denotes that `$`s_1`$` is an owned sub-state of composite state `$`s_2`$`. A state shall be categorized as either a simple state (an atomic state with zero nested sub-states and zero regions) or a composite state (containing one or more nested sub-states and associated internal transitions). In any non-parallel composite state, the active state configuration at any instant of execution shall be strictly singular: at most one sub-state may be active simultaneously (`$`|\text{active}(s)| \le 1`$).

  A composite state or state definition declared with the `parallel` modifier (`parallel state` or `parallel state def`) shall designate an orthogonal concurrent state container comprising $`k \ge 2`$` orthogonal regions `$`R_1, R_2, \dots, R_k`$`. Each orthogonal region `$`R_i`$` shall constitute an independent state machine region possessing its own entry state, internal sub-states, and transition topology. Any parallel state declaration specifying fewer than two orthogonal regions (`$`k \lt 2`$) shall be classified as degenerate and rejected deterministically at compile time with diagnostic error code `E0200` in accordance with the standardized diagnostic taxonomy of REQ-0191.

  The active state configuration of an orthogonal parallel state $`S_{\text{par}}`$ shall be formalized as a Cartesian product vector across all constituent regions:

```math
\mathbf{s} \in \prod_{i=1}^k \text{States}(R_i) = \text{States}(R_1) \times \text{States}(R_2) \times \dots \times \text{States}(R_k)
```

  wherein each coordinate $`s_i = \pi_i(\mathbf{s}) \in \text{States}(R_i)`$` denotes the unique active sub-state within region `$`R_i`$`, enforcing that exactly one sub-state is active per orthogonal region (`$`|\text{active}(R_i)| = 1`$` for all `$`1 \le i \le k`$). Events dispatched to a parallel state shall be evaluated independently within each region without cross-region interference unless explicit synchronization is modeled.

  Transitions crossing the boundaries of orthogonal parallel states shall adhere to strict synchronization invariants:
  1. Direct transitions between distinct orthogonal regions ($`s_a \in R_i \to s_b \in R_j`$` with `$`i \ne j`$) without traversing enclosing composite state boundaries or synchronization nodes shall be strictly prohibited and deterministically rejected with diagnostic error code `E0200`.
  2. Any transition originating outside a parallel state and activating sub-states across multiple orthogonal regions simultaneously must enter via an explicit `fork` construct (fork pseudo-state or parallel entry connector).
  3. Any transition originating from active sub-states across multiple orthogonal regions and converging to a single target state outside the parallel state must synchronize via an explicit `join` construct (join pseudo-state or parallel exit connector).

  The hierarchical containment relation $`\sqsubset`$` must be strictly acyclic. Static cyclic containment chains (`$`s_1 \sqsubset s_2 \sqsubset \dots \sqsubset s_1`$) shall be detected via topological cycle detection algorithms and rejected at compile time with diagnostic error code `E0203`. All sibling state usages within the same composite state or region scope must possess unique interned symbol identifiers; duplicate state names within identical lexical scope shall be rejected with diagnostic error code `E0200`.

  Every `StateUsage` shall be bound to one or more declared `StateDefinition` classifiers via formal `FeatureTyping` ($`\tau`$). Attempting to type a `StateUsage` with a non-state classifier (such as an identity-free `DataType`, a structural `PartDefinition`, or a non-state `ActionDefinition`) shall be rejected at compile time with diagnostic error code `E0200`. Subsetting (`:>`) and redefinition (`:>>`) of state usages in specializing state machines shall conform to REQ-0061 and REQ-0062: the specializing state usage must specialize or preserve the state classifier type ($`\tau(s_{\text{sub}}) \le \tau(s_{\text{sup}})`$), emitting `E0200` upon violation.

  All state definitions, state usages, and orthogonal regions shall be stored in contiguous bump arena storage in accordance with REQ-0009 and REQ-0034, addressed via stable 32-bit arena node handles per REQ-0035. Every lowered state AST node must receive a deterministic RFC 4122 UUIDv5 identifier computed by namespace-hashing the node fully qualified topological path with the canonical compiler namespace OID in accordance with Architectural Directive 1 and REQ-0010. Scalar symbol identifiers for state names, region labels, and namespace segments shall be interned into the global symbol interner pool per REQ-0036 as the sole permitted exception to zero-copy memory management in accordance with Architectural Directive 3.

  In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, the state lowering engine shall implement synchronization token error recovery on declaration and delimiter boundaries (e.g., `;`, `}`, `end`). Upon detecting an invalid state declaration, invalid parallel state ($`k \lt 2`$), cross-region transition fault (`E0200`), non-state classifier typing (`E0200`), or cyclic containment (`E0203`), the engine shall record structured diagnostics into the diagnostic sink, assign error sentinel $`\bot_{\text{state}}`$`, and continue verifying subsequent declarations. If accumulated diagnostics reach capacity `$`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully.

  Parallel statechart lowering across independent packages shall be scheduled on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$` in accordance with Architectural Directive 2 and REQ-0012. In accordance with Architectural Directive 5, REQ-0011, and REQ-0196, the state lowering engine shall enforce a deterministic, non-panicking execution contract with total-function termination across all inputs; performance latency (`$`\lt 25\text{ ms}`$` for `$`10^4`$` state elements) and peak memory RSS (`$`\lt 100\text{ MB}`$ RSS) performance gates shall be verified exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests. All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `StateDef_Alpha`, `StateDef_Beta`, `StateUsage_1`, `StateUsage_2`, `ParallelState_Omega`, `Region_1`, `Region_2`, `State_A`, `State_B`, `Transition_1`, `Port_1`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts and mock data.

#### 2. Formal Invariant

Let $`\mathcal{V}_{\text{AST}}`$` denote the universe of allocated AST nodes. The state machine metamodel partitions state entities into state definitions `$`\mathcal{S}_{\text{def}} \subset \mathcal{V}_{\text{AST}}`$` and state usages `$`\mathcal{S}_{\text{use}} \subset \mathcal{V}_{\text{AST}}`$:

```math
\mathcal{S}_{\text{all}} = \mathcal{S}_{\text{def}} \cup \mathcal{S}_{\text{use}}, \quad \mathcal{S}_{\text{def}} \cap \mathcal{S}_{\text{use}} = \emptyset
```

  The metamodel subtyping specialization hierarchy satisfies:

```math
\text{StateDef} \le \text{ActionDefinition} \le \text{Behavior} \le \text{OccurrenceDefinition} \le \text{Class} \le \text{Classifier}
```

```math
\text{StateUsage} \le \text{ActionUsage} \le \text{OccurrenceUsage} \le \text{Feature}
```

  Each state definition $`D \in \mathcal{S}_{\text{def}}`$ is formalized as an 8-tuple:

```math
D = \langle \text{id}_D, \text{name}_D, \mathcal{S}_{\text{super}}, \mathcal{U}_D, \mathcal{R}_D, \text{is\_parallel}, \Delta_D, \text{span}_D \rangle
```

  where:

```math
\begin{aligned}
\text{id}_D &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
\text{name}_D &\in \mathcal{S}_{\text{intern}} \quad (\text{interned symbol identifier}) \\
\mathcal{S}_{\text{super}} &\subseteq \mathcal{S}_{\text{def}} \quad (\text{direct supertypes / generalizations}) \\
\mathcal{U}_D &\subseteq \mathcal{S}_{\text{use}} \quad (\text{owned sub-states and nested usages}) \\
\mathcal{R}_D &\subseteq \mathcal{P}(\mathcal{S}_{\text{use}}) \quad (\text{set of orthogonal regions when is\_parallel is true}) \\
\text{is\_parallel} &\in \{ \text{true}, \text{false} \} \quad (\text{orthogonal concurrency discriminant}) \\
\Delta_D &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_D &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
\end{aligned}
```

  Each state usage $`U \in \mathcal{S}_{\text{use}}`$ is formalized as a 9-tuple:

```math
U = \langle \text{id}_U, \text{name}_U, \text{owner}_U, \tau(U), \mathcal{C}_U, \mathcal{R}_U, \text{is\_parallel}, \Delta_U, \text{span}_U \rangle
```

  where:

```math
\begin{aligned}
\text{id}_U &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
\text{name}_U &\in \mathcal{S}_{\text{intern}} \quad (\text{interned symbol identifier}) \\
\text{owner}_U &\in \mathcal{S}_{\text{def}} \cup \mathcal{S}_{\text{use}} \quad (\text{parent composite state or enclosing state definition}) \\
\tau(U) &\subseteq \mathcal{S}_{\text{def}} \setminus \{ \emptyset \} \quad (\text{state definition types bound via FeatureTyping}) \\
\mathcal{C}_U &\subseteq \mathcal{S}_{\text{use}} \quad (\text{set of direct child sub-states}) \\
\mathcal{R}_U &\subseteq \mathcal{P}(\mathcal{S}_{\text{use}}) \quad (\text{orthogonal regions when is\_parallel is true}) \\
\text{is\_parallel} &\in \{ \text{true}, \text{false} \} \quad (\text{orthogonal concurrency discriminant}) \\
\Delta_U &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_U &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
\end{aligned}
```

  Hierarchical State Nesting Invariant: The sub-state containment relation $`\sqsubset \;\subset \mathcal{S}_{\text{use}} \times (\mathcal{S}_{\text{def}} \cup \mathcal{S}_{\text{use}})`$ is defined by direct ownership:

```math
s_1 \sqsubset s_2 \iff s_1 \in \mathcal{C}_{s_2} \vee (\text{owner}(s_1) = s_2)
```

  The state hierarchy forms a rooted tree $`(S, \sqsubseteq)`$`, wherein the transitive closure `$`\sqsubset^+`$ is strictly irreflexive:

```math
\forall s \in \mathcal{S}_{\text{all}}, \quad (s, s) \notin \sqsubset^+
```

  Single-Parent Invariant: Every state usage possesses exactly one immediate parent:

```math
\forall U \in \mathcal{S}_{\text{use}}, \quad \exists ! P \in \mathcal{S}_{\text{def}} \cup \mathcal{S}_{\text{use}} : \text{owner}_U = P
```

  Orthogonal Parallel State Invariant: For every state $`s \in \mathcal{S}_{\text{all}}`$` designated as parallel (`$`\text{is\_parallel}(s) = \text{true}`$`), the region set `$`\mathcal{R}_s = \{ R_1, R_2, \dots, R_k \}`$ contains at least two orthogonal regions:

```math
\text{is\_parallel}(s) = \text{true} \implies |\mathcal{R}_s| = k \ge 2
```

  The orthogonal regions partition the child sub-states of $`s`$ into mutually disjoint subsets:

```math
\bigcup_{i=1}^k R_i = \mathcal{C}_s, \quad \forall i, j \in \{1, \dots, k\} : i \ne j \implies R_i \cap R_j = \emptyset
```

  Cartesian Active State Space Invariant: Let $`\text{States}(R_i)`$` denote the reachable sub-state set of region `$`R_i`$`. The active state configuration vector `$`\mathbf{s}`$` of parallel state `$`s`$ satisfies:

```math
\mathbf{s} \in \prod_{i=1}^k \text{States}(R_i)
```

  enforcing that exactly one sub-state is active per orthogonal region simultaneously:

```math
\forall i \in \{1, \dots, k\}, \quad |\text{active}(R_i)| = 1
```

  Non-Parallel Composite State Disjointness Invariant: In non-parallel composite states, at most one child state is active at any time:

```math
\text{is\_parallel}(s) = \text{false} \wedge \mathcal{C}_s \ne \emptyset \implies |\text{active}(\mathcal{C}_s)| \le 1
```

  Orthogonal Region Boundary Synchronization Invariant: Let $`\mathcal{E}_{\text{trans}}`$ denote the set of transition edges in the state machine. Transitions crossing between distinct orthogonal regions of a common parallel parent without explicit synchronization constructs are prohibited:

```math
\forall (s_{\text{src}}, s_{\text{tgt}}) \in \mathcal{E}_{\text{trans}}, \quad (\exists s \in \mathcal{S}_{\text{all}}, R_i, R_j \in \mathcal{R}_s : i \ne j \wedge s_{\text{src}} \in R_i \wedge s_{\text{tgt}} \in R_j) \implies \text{false}
```

  Multi-region activations entering a parallel state must synchronize through an explicit fork construct $`F \in \mathcal{V}_{\text{fork}}`$`, and multi-region departures must converge through an explicit join construct `$`J \in \mathcal{V}_{\text{join}}`$:

```math
\begin{aligned}
(s_{\text{src}} \notin \mathcal{C}_s \wedge \{ s_{\text{tgt}}^{(1)}, \dots, s_{\text{tgt}}^{(m)} \} \subseteq \mathcal{C}_s) &\implies \exists F \in \mathcal{V}_{\text{fork}} : \text{synchronizes}(F, \{ s_{\text{tgt}}^{(1)}, \dots, s_{\text{tgt}}^{(m)} \}) \\
(\{ s_{\text{src}}^{(1)}, \dots, s_{\text{src}}^{(m)} \} \subseteq \mathcal{C}_s \wedge s_{\text{tgt}} \notin \mathcal{C}_s) &\implies \exists J \in \mathcal{V}_{\text{join}} : \text{synchronizes}(J, \{ s_{\text{src}}^{(1)}, \dots, s_{\text{src}}^{(m)} \})
\end{aligned}
```

  Deterministic RFC 4122 UUIDv5 Anchor Invariant (Architectural Directive 1): Every state definition and state usage AST node binds a deterministic UUIDv5 identifier computed from the compiler namespace OID:

```math
\begin{aligned}
\forall D \in \mathcal{S}_{\text{def}}, \quad \Delta_D &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(D)) \\
\forall U \in \mathcal{S}_{\text{use}}, \quad \Delta_U &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(U))
\end{aligned}
```

  Diagnostic Code Trigger Invariants: Violations of state classifier typing, parallel region degeneracy, cyclic containment, cross-region synchronization, or identifier uniqueness deterministically emit diagnostic error codes per REQ-0191:

```math
\begin{aligned}
\exists U \in \mathcal{S}_{\text{use}}, \exists T \in \tau(U) : T \notin \mathcal{S}_{\text{def}} &\implies \text{Diagnostic}(U, \text{DiagnosticCode::E0200}, \text{InvalidStateClassifierType}) \in \mathcal{D}_{\text{sink}} \\
\exists s \in \mathcal{S}_{\text{all}} : \text{is\_parallel}(s) = \text{true} \wedge |\mathcal{R}_s| \lt 2 &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0200}, \text{DegenerateParallelStateRegions}) \in \mathcal{D}_{\text{sink}} \\
\exists s \in \mathcal{S}_{\text{all}} : (s, s) \in \sqsubset^+ &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0203}, \text{CircularStateContainment}) \in \mathcal{D}_{\text{sink}} \\
\exists (s_{\text{src}}, s_{\text{tgt}}) \in \mathcal{E}_{\text{trans}} : \text{cross\_orthogonal}(s_{\text{src}}, s_{\text{tgt}}) &\implies \text{Diagnostic}(s_{\text{src}}, \text{DiagnosticCode::E0200}, \text{UnsynchronizedCrossRegionTransition}) \in \mathcal{D}_{\text{sink}} \\
\exists s_1, s_2 \in \mathcal{C}_P : s_1 \ne s_2 \wedge \text{name}(s_1) = \text{name}(s_2) &\implies \text{Diagnostic}(s_1, \text{DiagnosticCode::E0200}, \text{DuplicateStateIdentifierInScope}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
```

  Diagnostic Taxonomy Containment Invariant: Emitted diagnostics strictly belong to the Metamodel and Typing family and Ingestion error limit family:

```math
\forall d \in \mathcal{D}_{\text{state}}, \quad \text{code}(d) \in \{ \text{DiagnosticCode::E0200}, \text{DiagnosticCode::E0203}, \text{DiagnosticCode::E0199} \} \subset \mathcal{E}_{\text{type}} \cup \mathcal{E}_{\text{ingest}}
```

#### 3. Computational Complexity & Algorithmic Bounds

Lowering and static structural validation of `StateDefinition`, `StateUsage`, and parallel orthogonal regions execute strictly within Complexity Class $`\mathbf{P}`$.

  **Relation to Algorithmic Bound NP-5**: In dynamic state machine verification, reachability analysis, deadlock detection, and livelock verification over orthogonal concurrent regions is PSPACE-complete (or NP-complete under bounded depth unrolling $`k \le k_{\max}`$), as governed by NP-5 in REQ-0124 via SAT-based Bounded Model Checking (BMC). In contrast, static AST lowering, hierarchical state tree construction, ancestor chain lookup, and structural validation in REQ-0079 operate strictly over the static hierarchical AST graph. Under static compilation, no state space exploration or reachability search is performed; the compiler executes strictly within deterministic polynomial time.

  **Asymptotic Verification Complexity**: For a model containing $`V = |\mathcal{S}_{\text{all}}|`$` state nodes and `$`E = |\mathcal{C}|`$` hierarchical containment edges (`$`E = V - 1`$` for tree structures, so `$`E \in O(V)`$):
  1. *State Node Allocation & Symbol Interning*: Allocating $`V`$` state nodes in contiguous bump arena storage and interning symbol strings requires amortized `$`O(1)`$` time per node, totaling `$`O(V)`$ time.
  2. *Containment Tree Construction & Parent Resolution*: Linking parent-child relationships and partitioning child lists into region arrays executes in $`O(V)`$ time.
  3. *Acyclicity Verification (Tarjan's SCC / DFS)*: Detecting circular state containment chains over $`(\mathcal{S}_{\text{all}}, \sqsubset)`$` executes in deterministic `$`O(V + E) = O(V)`$` time and `$`O(V)`$ auxiliary stack space.
  4. *Ancestor Chain & Depth Lookups*: In a state hierarchy with maximum tree depth bounded by $`h \le 32`$` in well-formed MBSE architectures, retrieving the complete ancestor chain from any state node to the root evaluates in `$`O(\text{depth}) \le O(h) = O(1)`$ bounded steps.
  5. *Lowest Common Ancestor (LCA) Queries*: Evaluating the lowest common composite state ancestor for transition boundary analysis executes in $`O(\text{depth}) \le O(h) = O(1)`$` time using direct parent pointer traversal, or in strictly `$`O(1)`$` query time following `$`O(V)`$ Euler-tour tree preprocessing.
  6. *Orthogonal Region Validation*: Validating that each parallel state satisfies $`k \ge 2`$` and that regions form disjoint partitions executes in `$`O(|\mathcal{C}_s|)`$` time per parallel state, totaling `$`O(V)`$ time across the model.
  7. *Transition Cross-Region Invariant Check*: For each transition edge $`(s_{\text{src}}, s_{\text{tgt}}) \in \mathcal{E}_{\text{trans}}`$`, verifying that source and target do not cross orthogonal regions without fork/join requires testing region membership and LCA in `$`O(\text{depth}) = O(1)`$` time, totaling `$`O(|\mathcal{E}_{\text{trans}}|)`$ time.

  Total sequential verification time across all state definitions and usages is strictly linear in the size of the statechart graph:

```math
T_{\text{validate}}(V, E, \mathcal{E}_{\text{trans}}) \in O(V + |\mathcal{E}_{\text{trans}}|)
```

  **Parallel Work-Stealing Scaling (Architectural Directive 2)**: When statechart lowering and validation across independent package scopes is scheduled on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$:

```math
T_{\text{parallel}}(V, E, N_{\text{max\_workers}}) \in O\left( \frac{V + |\mathcal{E}_{\text{trans}}|}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

  **Space Complexity & Memory Bounds**: Auxiliary working memory is strictly bounded by $`O(V + |\mathcal{E}_{\text{trans}}|)`$` for contiguous arena storage and parent-child adjacency representations. Traversal recursion depth is strictly bounded by hierarchy depth `$`h \le 32`$` (`$`O(1)`$` stack memory). The diagnostic error sink is bounded by `$`O(C_{\text{max\_errors}}) = O(1)`$ allocated records.

#### 4. Verification & Conformance Criteria

Automated test suites shall deterministically verify compliance against synthetic abstract MBSE models containing abstract placeholders (`Package_0`, `StateDef_Alpha`, `StateDef_Beta`, `StateUsage_1`, `StateUsage_2`, `ParallelState_Omega`, `Region_1`, `Region_2`, `State_A`, `State_B`, `Transition_1`, `Port_1`, `Flow_A`, `param_x : Real`). Conformance validation shall enforce the following test gates:

  1. **Canonical State Lowering Gate**: Declare `StateDef_Alpha` containing simple sub-states `State_A` and `State_B`. Lower `StateUsage_1 : StateDef_Alpha`. Assert 100% resolution into contiguous bump arena storage, valid 32-bit arena node handles, correct parent-child linkage, and zero diagnostic emissions.
  2. **Hierarchical State Nesting & Ancestor Chain Lookup Gate**: Construct a nested composite state hierarchy of depth 5 ($`s_5 \sqsubset s_4 \sqsubset s_3 \sqsubset s_2 \sqsubset s_1`$`). Assert that ancestor chain lookups from `$`s_5`$` to `$`s_1`$` evaluate in `$`O(\text{depth})`$` bounded steps and verify Lowest Common Ancestor (LCA) queries in `$`O(1)`$ time.
  3. **Orthogonal Parallel State & Cartesian Space Gate**: Declare composite state `ParallelState_Omega` with the `parallel` modifier, comprising two orthogonal regions `Region_1` (containing sub-states `State_A1`, `State_A2`) and `Region_2` (containing sub-states `State_B1`, `State_B2`). Assert that the lowering engine recognizes $`k = 2`$` orthogonal regions and constructs the Cartesian product state space `$`\text{States}(R_1) \times \text{States}(R_2)`$` with `$`|\text{active}(R_1)| = 1`$` and `$`|\text{active}(R_2)| = 1`$.
  4. **Degenerate Parallel State Region Gate (`E0200`)**: Declare a state with the `parallel` modifier containing only 1 region ($`k = 1`$`) or zero regions (`$`k = 0`$). Assert deterministic compile-time rejection with structured diagnostic error code `E0200` (`DegenerateParallelStateRegions`), assignment of error sentinel $`\bot_{\text{state}}`$, and zero panics.
  5. **Unsynchronized Cross-Region Transition Rejection Gate (`E0200`)**: Construct a parallel state containing orthogonal regions `Region_1` and `Region_2`. Attempt to declare a direct transition from `State_A1 \in Region_1` to `State_B1 \in Region_2` without enclosing composite traversal or synchronization pseudo-states. Assert deterministic compile-time rejection with diagnostic error code `E0200` (`UnsynchronizedCrossRegionTransition`).
  6. **Fork and Join Synchronization Validation Gate**: Declare a fork construct entering `Region_1` and `Region_2` simultaneously from an external source state, and a join construct synchronizing departures from both regions to an external target state. Assert that the lowering engine validates synchronization invariants with zero diagnostics.
  7. **Circular State Containment Rejection Gate (`E0203`)**: Construct a synthetic circular containment chain $`s_1 \sqsubset s_2 \sqsubset s_3 \sqsubset s_1`$. Assert deterministic cycle detection via Tarjan's SCC/DFS, emission of diagnostic error code `E0203` (`CircularStateContainment`) identifying all participating nodes, and graceful recovery.
  8. **Duplicate State Identifier in Lexical Scope Gate (`E0200`)**: Declare two sibling sub-states with identical interned name `State_A` within the same composite state scope. Assert deterministic rejection with diagnostic error code `E0200` (`DuplicateStateIdentifierInScope`) and exact source byte spans.
  9. **State Classifier Type Conformance Gate (`E0200`)**: Declare a structural classifier `PartDef_Alpha`. Attempt to declare `StateUsage_Err : PartDef_Alpha`. Assert deterministic rejection with diagnostic error code `E0200` (`InvalidStateClassifierType`), assignment of error sentinel $`\bot_{\text{state}}`$, and zero panics.
  10. **Synchronization Token Recovery & Error Accumulation Gate (Architectural Directive 4)**: Ingest a model unit containing 5 distinct malformed state declarations (degenerate parallel regions, unsynchronized cross-region transitions, invalid classifier types) separated by delimiter tokens. Assert that the lowering engine resynchronizes on token boundaries, accumulates all 5 `E0200` diagnostics with precise source spans, and when the error count reaches $`C_{\text{max\_errors}}`$, emits terminal diagnostic `E0199` and halts gracefully.
  11. **Deterministic UUIDv5 Topological Identity Gate (Architectural Directive 1)**: Verify that 100% of lowered `StateDefinition` and `StateUsage` AST nodes bind valid RFC 4122 UUIDv5 identifiers computed from the fixed DEAP namespace OID and canonical fully qualified paths, asserting bitwise identical digests and 0-byte diff churn across repeated compilation runs.
  12. **Bounded Work-Stealing Parallelism & Release Mode Budget Gate (Architectural Directives 2 & 5)**: In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196, verify that lowering and validating $`10^4`$` synthetic state machine elements across `$`N_{\text{max\_workers}}`$ threads executes in under 25 ms, peak RSS memory remains strictly under 100 MB, data-race freedom is maintained, zero panics occur, and 0-byte diff churn is preserved.
