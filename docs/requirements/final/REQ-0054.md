### REQ-0054: KerML Root, Element, Relationship & Annotation Abstract Syntax

- **Normative Statement**: The compiler core metamodel and intermediate representation lowering engine shall define and enforce the foundational KerML Kernel abstract syntax root hierarchy as a rooted directed multigraph of semantic elements $`\mathcal{E}`$, directed relationships $`\mathcal{R}`$, non-intrusive metadata annotations $`\mathcal{M}`$, and structural containment ownership relations $`\mathcal{O}`$, providing monotonic identity preservation and structural containment without circular ownership. The abstract syntax hierarchy shall define `Element` as the universal root entity from which all semantic constructs derive. Every `Element` must possess an immutable, monotonic identity represented by a typed 32-bit arena index handle (`NodeHandle<Element>`) referencing uniform, contiguous slot storage in a typed bump arena in accordance with REQ-0009, REQ-0034, and REQ-0035, guaranteeing a pointer indirection depth of zero ($`\text{PointerIndirectionDepth} = 0`$). Every `Element` shall be assigned a deterministic RFC 4122 UUIDv5 identifier computed from the fixed compiler namespace OID ($`\text{OID}_{\text{DEAP}}`$) and the element's canonical fully qualified topological path ($`\text{FQN}(e)`$) in accordance with Architectural Directive 1 and REQ-0010, strictly prohibiting time-based or non-deterministic identifiers. Textual names, aliases, and string literal tokens shall be interned as scalar `SymbolId` tokens into the global symbol interner pool, which constitutes the sole permitted exception to zero-copy memory management in accordance with Architectural Directive 3 and REQ-0036.

  The metamodel shall define `Relationship` as a specialized `Element` establishing directed semantic connections between non-empty collections of source elements ($`\text{source}(r) \subseteq \mathcal{E}`$) and target elements ($`\text{target}(r) \subseteq \mathcal{E}`$). For directed non-reflexive relationships, the engine shall enforce that source and target sets are non-empty and mutually disjoint ($`\text{source}(r) \cap \text{target}(r) = \emptyset`$). All endpoint node handles must resolve to valid, active arena allocations; any relationship with empty endpoints, reflexive self-endpoints in directed links, or dangling/unallocated handles shall deterministically emit structured diagnostic error code `E0200` (or `E0201` for directional multiplicity faults) in accordance with the standardized diagnostic taxonomy of REQ-0191.

  The structural containment ownership relation $`\mathcal{O} \subset \mathcal{E} \times \mathcal{E}`$ shall form a strict directed forest (or rooted tree under the root model package), enforcing the single ownership principle: every element $`e \in \mathcal{E}`$ shall have at most one enclosing owner ($`|\text{owner}(e)| \le 1`$). Direct or transitive ownership cycles ($`(e, e) \in \mathcal{O}^+`$) shall be strictly prohibited. When an ownership cycle is detected during semantic graph validation, the compiler shall reconstruct the elementary cycle path $`\mathcal{P}_{\text{cycle}} = \langle v_1, v_2, \dots, v_k, v_1 \rangle`$ and emit structured diagnostic error code `E0203` in accordance with REQ-0042 and REQ-0191. If an element is assigned multiple conflicting owners, the compiler shall emit structured diagnostic error code `E0200`.

  The metamodel shall define `Annotation` as a specialized `Element` associating metadata, user comments, or documentation payloads with an annotated target `Element`. Annotations must maintain semantic non-interference: attaching, removing, or inspecting an annotation $`\alpha \in \mathcal{M}`$ on element $`e`$ shall leave the algebraic type denotation $`\llbracket e \rrbracket`$, subtyping relations, and runtime operational semantics strictly invariant ($`\llbracket e \oplus \alpha \rrbracket \equiv \llbracket e \rrbracket`$).

  In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, the ingestion and lowering engine shall implement synchronization token error recovery on delimiter boundaries: upon detecting malformed relationship endpoints, conflicting ownership, or circular containment, the engine shall record the diagnostic into the preallocated diagnostic sink $`\mathcal{D}_{\text{sink}}`$, sever the invalid edge or substitute an error sentinel $`\bot_{\text{elem}}`$, and continue parsing and validating subsequent AST subgraphs without aborting on first fault. If accumulated diagnostics reach the sink limit $`C_{\text{max\_errors}}`$, the compiler shall emit terminal diagnostic `E0199` and halt gracefully. Multi-threaded AST lowering across independent compilation units shall be scheduled strictly on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with Architectural Directive 2 and REQ-0012. In accordance with Architectural Directive 5, REQ-0011, and REQ-0196, the engine shall enforce a deterministic, non-panicking execution contract with total-function termination across all inputs; performance latency (< 25 ms) and peak memory RSS (< 100 MB for $`10^5`$ AST nodes) performance gates shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from standard CI logic tests. All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Element_Alpha`, `Element_Beta`, `Element_Gamma`, `Element_Delta`, `Rel_Alpha`, `Rel_Beta`, `Annotation_0`, `Classifier_Alpha`, `param_x : Real`), strictly prohibiting hardcoded domain concepts and mock data.

- **Formal Invariant**: Let $`\mathcal{V}_{\text{arena}} \subset \mathbb{N}_{32}`$ denote the universe of 32-bit contiguous arena node handles. The KerML root abstract syntax is formalized as a 4-tuple multigraph:

$$
G_{\text{KerML}} = \langle \mathcal{E}, \mathcal{R}, \mathcal{M}, \mathcal{O} \rangle
$$

  where:

$$
\mathcal{R} \subseteq \mathcal{E}, \quad \mathcal{M} \subseteq \mathcal{E}, \quad \mathcal{O} \subset \mathcal{E} \times \mathcal{E}
$$

  Each semantic element $`e \in \mathcal{E}`$ is formalized as a 7-tuple:

$$
e = \langle \text{id}_e, \text{name}_e, \text{owner}_e, \mathcal{C}_e, \mathcal{A}_e, \Delta_e, \text{span}_e \rangle \in \mathcal{E}
$$

  where:

$$
\begin{aligned}
\text{id}_e &\in \mathcal{V}_{\text{arena}} \quad (\text{monotonic 32-bit contiguous arena handle}) \\
\text{name}_e &\in \mathcal{S}_{\text{intern}} \cup \{ \bot \} \quad (\text{interned scalar symbol identifier}) \\
\text{owner}_e &\in \mathcal{E} \cup \{ \bot \} \quad (\text{unique enclosing owner element}) \\
\mathcal{C}_e &\subseteq \mathcal{E} \quad (\text{ordered sequence of owned child elements}) \\
\mathcal{A}_e &\subseteq \mathcal{M} \quad (\text{associated metadata annotations}) \\
\Delta_e &\in \Sigma^* \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_e &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance span})
\end{aligned}
$$

  Each relationship $`r \in \mathcal{R}`$ is formalized as a 7-tuple:

$$
r = \langle \text{id}_r, \text{name}_r, \text{source}_r, \text{target}_r, \text{directed}_r, \Delta_r, \text{span}_r \rangle \in \mathcal{R}
$$

  where:

$$
\begin{aligned}
\text{source}(r) &\subseteq \mathcal{E} \setminus \{ \bot \} \\
\text{target}(r) &\subseteq \mathcal{E} \setminus \{ \bot \} \\
\text{directed}(r) &\in \mathbb{B}
\end{aligned}
$$

  Directed Non-Reflexive Relationship Invariant: For every directed relationship $`r \in \mathcal{R}`$ where $`\text{directed}(r) \equiv \text{true}`$, the source and target projections satisfy non-emptiness and mutual disjointness:

$$
\text{directed}(r) \implies (\text{source}(r) \neq \emptyset) \wedge (\text{target}(r) \neq \emptyset) \wedge (\text{source}(r) \cap \text{target}(r) = \emptyset)
$$

  Endpoint Resolution and Allocation Invariant: All referenced source and target endpoints must resolve to allocated arena handles:

$$
\forall r \in \mathcal{R}, \quad \forall u \in (\text{source}(r) \cup \text{target}(r)), \quad \text{id}(u) \in \mathcal{V}_{\text{arena}} \wedge \text{IsAllocated}(\text{id}(u)) \equiv \text{true}
$$

  Structural Containment and Single Ownership Invariant: The structural ownership relation $`\mathcal{O}`$ satisfies the single ownership constraint:

$$
\forall v \in \mathcal{E}, \quad |\{ u \in \mathcal{E} \mid (u, v) \in \mathcal{O} \}| \le 1
$$

  and the owner projection function $`\text{owner} : \mathcal{E} \to \mathcal{E} \cup \{ \bot \}`$ is given by:

$$
\text{owner}(v) = \begin{cases}
u, & \text{if } (u, v) \in \mathcal{O} \\
\bot, & \text{if } \forall u \in \mathcal{E}, \, (u, v) \notin \mathcal{O}
\end{cases}
$$

  Child Containment Bijective Consistency: The owned children set $`\mathcal{C}_u`$ corresponds bijectively with the ownership relation:

$$
\forall u, v \in \mathcal{E}, \quad (u, v) \in \mathcal{O} \iff v \in \mathcal{C}_u \iff \text{owner}(v) = u
$$

  Strict Acyclicity of Ownership Invariant: Let $`\mathcal{O}^+`$ denote the non-empty transitive closure of $`\mathcal{O}`$:

$$
(u, v) \in \mathcal{O}^+ \iff \exists \langle w_0, w_1, \dots, w_m \rangle, \; m \ge 1, \; w_0 = u, \; w_m = v, \; \forall i \in \{0, \dots, m-1\}, \, (w_i, w_{i+1}) \in \mathcal{O}
$$

  Containment is strictly acyclic:

$$
\forall e \in \mathcal{E}, \quad (e, e) \notin \mathcal{O}^+
$$

  Non-Intrusive Annotation Semantics Invariant: Let $`\mathcal{D}`$ denote the domain of metadata descriptors and documentation strings. Each annotation $`\alpha \in \mathcal{M}`$ defines a mapping $`\mu_{\alpha} : \mathcal{E} \to \mathcal{D}`$. Let $`\llbracket e \rrbracket`$ denote the algebraic type denotation and semantic behavior of element $`e`$. For any annotation $`\alpha \in \mathcal{M}`$ attached to $`e`$ (denoted $`e \oplus \alpha`$):

$$
\llbracket e \oplus \alpha \rrbracket \equiv \llbracket e \rrbracket
$$

  Deterministic UUIDv5 Topological Hashing Invariant: Every element $`e \in \mathcal{E}`$ (including relationships and annotations) has an immutable deterministic RFC 4122 UUIDv5 identifier:

$$
\Delta_e = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(e))
$$

  where:

$$
\text{FQN}(e) = \begin{cases}
\text{name}(e), & \text{if } \text{owner}(e) = \bot \\
\text{FQN}(\text{owner}(e)) \mathbin{\Vert} \text{"::"} \mathbin{\Vert} \text{name}(e), & \text{if } \text{owner}(e) \neq \bot \wedge \text{name}(e) \neq \bot \\
\text{FQN}(\text{owner}(e)) \mathbin{\Vert} \text{"::anon\_"} \mathbin{\Vert} \text{id}_e, & \text{otherwise}
\end{cases}
$$

  Diagnostic Code Trigger Invariant: Structural, directional, containment, or endpoint violations deterministically trigger structured diagnostics in accordance with REQ-0191:

$$
\begin{aligned}
\exists r \in \mathcal{R}, \, (\text{source}(r) = \emptyset \vee \text{target}(r) = \emptyset) &\implies \text{Diagnostic}(r, \text{DiagnosticCode::E0200}, \text{EmptyRelationshipEndpointViolation}) \in \mathcal{D}_{\text{sink}} \\
\exists r \in \mathcal{R}, \, \text{directed}(r) \wedge (\text{source}(r) \cap \text{target}(r) \neq \emptyset) &\implies \text{Diagnostic}(r, \text{DiagnosticCode::E0200}, \text{ReflexiveDirectedRelationshipViolation}) \in \mathcal{D}_{\text{sink}} \\
\exists r \in \mathcal{R}, \, \exists u \in (\text{source}(r) \cup \text{target}(r)), \, \neg\text{IsAllocated}(\text{id}(u)) &\implies \text{Diagnostic}(r, \text{DiagnosticCode::E0200}, \text{DanglingRelationshipEndpoint}) \in \mathcal{D}_{\text{sink}} \\
\exists v \in \mathcal{E}, \, |\{ u \in \mathcal{E} \mid (u, v) \in \mathcal{O} \}| \gt 1 &\implies \text{Diagnostic}(v, \text{DiagnosticCode::E0200}, \text{MultipleOwnershipViolation}) \in \mathcal{D}_{\text{sink}} \\
\exists e \in \mathcal{E}, \, (e, e) \in \mathcal{O}^+ &\implies \text{Diagnostic}(\mathcal{P}_{\text{cycle}}, \text{DiagnosticCode::E0203}, \text{ContainmentCycle}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

  Diagnostic Taxonomy Containment Invariant: All diagnostics emitted by the KerML abstract syntax lowering engine belong strictly to the Subsystem 4 Metamodel and Typing family:

$$
\forall d \in \mathcal{D}_{\text{KerML}}, \quad \text{code}(d) \in \{ \text{DiagnosticCode::E0200}, \text{DiagnosticCode::E0201}, \text{DiagnosticCode::E0203}, \text{DiagnosticCode::E0199} \} \subset \mathcal{E}_{\text{type}}
$$

- **Computational Complexity & Algorithmic Bounds**: KerML abstract syntax lowering, relationship endpoint validation, and containment cycle checking execute strictly within Complexity Class $`\mathbf{P}`$. The algorithmic bounds across data structures and execution phases are formalized as follows:
  1. Contiguous Arena Allocation & Handle Dereferencing: Node slot allocation in the typed bump arena requires monotonic pointer offset advancement and integer bounds checking against arena capacity, executing in amortized $`O(1)`$ time (and strict $`O(1)`$ worst-case time within an allocated arena chunk). Dereferencing an arena node handle $`\text{id}_e \in \mathcal{V}_{\text{arena}}`$ to access an element slot uses base-plus-offset address arithmetic $`\text{Base} + i \cdot S_{\text{slot}}`$, executing in strict worst-case $`O(1)`$ constant time with zero pointer indirection hops.
  2. Directed Relationship Endpoint Validation: For a relationship set $`\mathcal{R}`$ containing $`|\mathcal{R}|`$ relationships, each relationship $`r \in \mathcal{R}`$ specifies bounded endpoint sets with $`|\text{source}(r)| \le K_{\text{src}}`$ and $`|\text{target}(r)| \le K_{\text{tgt}}`$, where $`K_{\text{src}}, K_{\text{tgt}} \le 16 = O(1)`$ in practice. Validating endpoint handle non-emptiness, verifying allocation bounds ($`\text{id}(u) \lt |\mathcal{E}|`$), and verifying set disjointness ($`\text{source}(r) \cap \text{target}(r) = \emptyset`$) requires $`O(|\text{source}(r)| \cdot |\text{target}(r)|) = O(1)`$ scalar integer comparisons per relationship. Summed across all relationships, total endpoint validation time is strictly linear:

$$
T_{\text{endpoints}}(|\mathcal{R}|) = \sum_{r \in \mathcal{R}} O(K_{\text{src}} \cdot K_{\text{tgt}}) = O(|\mathcal{R}|)
$$

  3. Single Ownership Verification: Verifying that each element $`e \in \mathcal{E}`$ has at most one owner requires inspecting parent assignments during AST lowering, taking $`O(1)`$ time per element and bounding the total single ownership check across the model to $`O(|\mathcal{E}|)`$.
  4. Ownership Cycle Detection via Tarjan Strongly Connected Components: The containment graph $`G_{\text{own}} = (\mathcal{E}, \mathcal{O})`$ comprises $`|\mathcal{E}|`$ vertices and $`|\mathcal{O}|`$ edges, where $`|\mathcal{O}| \le |\mathcal{E}|`$ because every element possesses at most one parent in a valid hierarchy. Tarjan's SCC algorithm visits each vertex and edge exactly once:

$$
T_{\text{cycle}}(|\mathcal{E}|, |\mathcal{O}|) \in O(|\mathcal{E}| + |\mathcal{O}|) \subseteq O(|\mathcal{E}|)
$$

     Reconstructing the elementary cycle path $`\mathcal{P}_{\text{cycle}}`$ for any detected component of size $`k \ge 1`$ requires $`O(k)`$ time, bounded by $`O(|\mathcal{E}|)`$.
  5. Annotation Attachment & Retrieval: Attaching an annotation $`\alpha \in \mathcal{M}`$ appends its handle to the element's contiguous annotation handle array in $`O(1)`$ amortized time. Inspecting or iterating over an element's annotations executes in $`O(|\mathcal{A}_e|)`$ deterministic linear time.
  6. Parallel Work-Stealing Scaling: When AST lowering and validation across $`K`$ independent compilation units are dispatched across $`N_{\text{max\_workers}}`$ threads in the bounded work-stealing pool:

$$
T_{\text{parallel}} \in O\left( \frac{|\mathcal{E}| + |\mathcal{R}| + |\mathcal{M}|}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  7. Space Complexity & Memory Bounds: Total memory consumption is strictly bounded by $`O(|\mathcal{E}| \cdot S_{\text{elem}} + |\mathcal{R}| \cdot S_{\text{rel}} + |\mathcal{M}| \cdot S_{\text{annot}})`$ contiguous arena storage, completely eliminating dynamic per-node heap allocator metadata headers, object reference counters, and pointer indirection arrays. Auxiliary call stack space for recursive containment traversal is bounded by $`O(D_{\text{max}})`$ where maximum hierarchy nesting depth satisfies $`D_{\text{max}} \le 64`$, requiring $`O(1)`$ auxiliary stack memory. The diagnostic sink buffer is bounded by $`O(C_{\text{max\_errors}}) = O(1)`$ preallocated records.

- **Verification & Conformance Criteria**: Automated test suites shall deterministically verify compliance against synthetic abstract MBSE models containing abstract placeholders (`Package_0`, `Element_Alpha`, `Element_Beta`, `Element_Gamma`, `Element_Delta`, `Rel_Alpha`, `Rel_Beta`, `Annotation_0`, `Classifier_Alpha`, `param_x : Real`). Conformance validation shall enforce the following test gates:
  1. Root Element Identity & Arena Allocation Gate:
     - Ingest a synthetic model containing `Package_0`, `Element_Alpha`, and `Element_Beta`.
     - Assert that every element is allocated within the contiguous typed node arena with 64-bit alignment ($`A_{\text{align}} = 8\text{ bytes}`$).
     - Assert that node handles satisfy $`\text{sizeof}(\text{NodeHandle}) = 4\text{ bytes}`$ with pointer indirection depth of zero ($`\text{PointerIndirectionDepth} = 0`$).
     - Assert that 100% of elements receive deterministic RFC 4122 UUIDv5 identifiers computed from $`\text{OID}_{\text{DEAP}}`$ and canonical fully qualified paths per Architectural Directive 1 and REQ-0010.
  2. Directed Relationship Endpoint Validation Gate:
     - Construct a directed relationship `Rel_Alpha` with source `{Element_Alpha}` and target `{Element_Beta}`.
     - Assert that $`\text{source}(\text{Rel\_Alpha}) \cap \text{target}(\text{Rel\_Alpha}) = \emptyset`$, that endpoints resolve to active arena node handles, and that zero diagnostics are emitted.
  3. Reflexive & Empty Endpoint Rejection Gate:
     - Ingest a model attempting to declare a directed relationship with an empty source set or empty target set (`Rel_Empty`), or a reflexive directed relationship where source and target overlap (`Rel_Self : Element_Alpha -> Element_Alpha`).
     - Assert deterministic emission of structured diagnostic error code `E0200` (`EmptyRelationshipEndpointViolation` or `ReflexiveDirectedRelationshipViolation`) with exact source byte span mapping per REQ-0191.
  4. Dangling Endpoint Diagnostic Gate:
     - Ingest a model containing a relationship referencing an invalid or non-existent node handle ($`h \ge |\mathcal{E}|`$).
     - Assert deterministic emission of diagnostic error code `E0200` (`DanglingRelationshipEndpoint`) and substitution of an error sentinel $`\bot_{\text{elem}}`$ without panicking.
  5. Single Ownership Invariant Gate:
     - Ingest a model declaring `Element_Beta` owned by `Package_0`.
     - Attempt to assign a second owner `Element_Alpha` to `Element_Beta` ($`|\text{owner}(\text{Element\_Beta})| \gt 1`$).
     - Assert deterministic emission of diagnostic error code `E0200` (`MultipleOwnershipViolation`).
  6. Circular Ownership Detection & Error Recovery Gate:
     - Ingest a model declaring a circular containment chain: `Package_0` owns `Element_Alpha`, `Element_Alpha` owns `Element_Beta`, and `Element_Beta` owns `Package_0`.
     - Assert deterministic emission of diagnostic error code `E0203` (`ContainmentCycle`) with complete ordered cycle traceback $`\langle \text{Package\_0}, \text{Element\_Alpha}, \text{Element\_Beta}, \text{Package\_0} \rangle`$.
     - Assert that synchronization token error recovery (Architectural Directive 4) severs the closing containment back-edge in the compilation overlay, continuing semantic validation on disjoint model elements.
     - Inject cyclic errors exceeding $`C_{\text{max\_errors}}`$ and assert that the compiler terminates gracefully with terminal diagnostic `E0199`.
  7. Non-Intrusive Annotation Semantics Gate:
     - Attach metadata annotations `Annotation_0` and `Annotation_1` containing documentation strings and key-value descriptors to `Element_Alpha`.
     - Assert that the algebraic type denotation and semantic signature remain identical: $`\llbracket \text{Element\_Alpha} \oplus \text{Annotation\_0} \rrbracket \equiv \llbracket \text{Element\_Alpha} \rrbracket`$.
     - Assert that annotation payloads are retrievable in $`O(1)`$ time without polluting element type descriptors or altering subtyping relations.
  8. Concurrent Interning & Work-Stealing Parallelism Gate:
     - Ingest $`10^4`$ synthetic elements, relationships, and annotations across $`K`$ compilation units on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with Architectural Directive 2 and REQ-0012.
     - Assert thread safety, string interning of symbol names into the global pool in accordance with Architectural Directive 3 and REQ-0036, and bitwise identical AST output.
  9. Panic-Free Release Paths & Benchmarking Isolation Gate:
     - In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with Architectural Directive 5, REQ-0011, and REQ-0196:
     - Benchmark ingesting and validating $`10^5`$ KerML root elements and relationships; assert total execution latency is strictly under 25 ms and peak RSS memory is strictly under 100 MB.
  10. Bitwise Determinism & Zero Diff Churn Gate:
      - Execute 10 consecutive compilation runs on identical abstract MBSE models.
      - Assert that generated diagnostic collections, node handle assignments, UUIDv5 topological anchors, and AST graphs are 100% bitwise identical with 0-byte diff churn.
