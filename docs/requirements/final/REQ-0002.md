### REQ-0002: Surjective Lexical Provenance Gate & Positive AST Provenance

- **Normative Statement**: The compiler platform shall enforce a strict, surjective lexical provenance gate across all synthesized abstract syntax tree (AST) elements, ensuring that every generated classifier, feature usage, port, connector, attribute, constraint, behavior, action, and state identifier establishes a verifiable derivation link back to a corresponding AST node within parsed schema source files or to a deterministic synthetic topological parent anchor. Generation of ungrounded, fabricated, or hallucinated structural entities is strictly prohibited across all compiler lowering, transformation, optimization, and code generation passes. Every synthesized AST node must maintain an explicit provenance descriptor containing the originating source file identifier, physical source byte span (start and end byte offsets), line and column coordinates, and parent AST node handle. When intermediate representation nodes or scaffolding entities are synthetically generated (such as implicit root namespaces or structural containment boundaries), the compiler shall derive their provenance anchors deterministically via RFC 4122 UUIDv5 namespace hashing rooted in a fixed compiler namespace UUID and the node fully qualified topological path. The compiler must verify surjective range completeness across all parsed schema source nodes, guaranteeing that zero user-defined structural entities are dropped or silently omitted during lowering. The provenance gate shall execute as a mandatory verification barrier immediately following schema ingestion and AST construction, failing closed upon any provenance violation.

- **Formal Invariant**: Let $\mathcal{A}$ denote the synthesized abstract syntax tree, with node set $\text{Nodes}(\mathcal{A})$ and edge set $\text{Edges}(\mathcal{A})$. Let $\mathcal{S}$ denote the set of input schema source files parsed by the ingestion engine, and let $\text{ASTNodes}(\mathcal{S})$ denote the set of all structural AST nodes parsed directly from $\mathcal{S}$. Let $\text{TopologicalAnchors}(\mathcal{S})$ denote the set of deterministic synthetic topological anchor nodes generated for intermediate structural scaffolding. Let $\text{NS}_{\text{DEAP}}$ denote the fixed RFC 4122 namespace UUID. For any canonical topological path $p \in \text{TopologicalPaths}(\mathcal{S})$, its deterministic anchor identifier is defined by:

$$
\text{Anchor}(p) = \text{UUIDv5}(\text{NS}_{\text{DEAP}}, p)
$$

The complete target provenance domain is defined as:

$$
\mathcal{P}_{\text{domain}} = \text{ASTNodes}(\mathcal{S}) \cup \text{TopologicalAnchors}(\mathcal{S})
$$

The compiler establishes a total provenance derivation mapping:

$$
\Pi : \text{Nodes}(\mathcal{A}) \longrightarrow \mathcal{P}_{\text{domain}}
$$

Positive AST Provenance Invariant: every synthesized node $n \in \text{Nodes}(\mathcal{A})$ must resolve to a non-null, valid schema or synthetic anchor origin:

$$
\forall n \in \text{Nodes}(\mathcal{A}), \quad \Pi(n) \ne \bot \quad \wedge \quad \Pi(n) \in \mathcal{P}_{\text{domain}}
$$

Surjective Lexical Range Completeness Invariant: every parsed structural schema node $s \in \text{ASTNodes}(\mathcal{S})$ must be represented in the synthesized AST:

$$
\forall s \in \text{ASTNodes}(\mathcal{S}), \quad \exists n \in \text{Nodes}(\mathcal{A}) \quad \text{such that} \quad \Pi(n) = s
$$

Equivalently, the range of $\Pi$ over synthesized structural elements subsumes all input schema nodes:

$$
\text{Range}(\Pi) \supseteq \text{ASTNodes}(\mathcal{S})
$$

Source Byte Span Validity Invariant: for every schema-grounded node $n \in \text{Nodes}(\mathcal{A})$ where $\Pi(n) = s \in \text{ASTNodes}(\mathcal{S})$, the associated byte span $\text{Span}(n) = \langle \text{FileID}(s), \text{ByteStart}(s), \text{ByteEnd}(s) \rangle$ satisfies strict boundary bounds within source file buffer $\mathcal{B}(\text{FileID}(s))$:

$$
\begin{aligned}
0 &\le \text{ByteStart}(s) \lt \text{ByteEnd}(s) \le \text{Length}(\mathcal{B}(\text{FileID}(s))) \\
\text{SpanLength}(n) &= \text{ByteEnd}(s) - \text{ByteStart}(s) \gt 0
\end{aligned}
$$

Zero Ungrounded Hallucination Invariant: the set of synthesized AST nodes lacking positive provenance is strictly empty:

$$
\text{Ungrounded}(\mathcal{A}) = \{ n \in \text{Nodes}(\mathcal{A}) \mid \Pi(n) \notin \mathcal{P}_{\text{domain}} \lor \Pi(n) = \bot \} = \emptyset
$$

- **Computational Complexity & Algorithmic Bounds**: The surjective lexical provenance verification pipeline executes within Complexity Class $\mathbf{P}$. During schema parsing and lexical ingestion, source byte span capture and initial node registration operate in $O(1)$ amortized time per token, bounded by $O(N)$ for total input token count $N = |\text{Tokens}(\mathcal{S})|$. Synthetic topological anchor generation via RFC 4122 UUIDv5 path hashing operates in $O(V + E)$ where $V = |\text{Nodes}(\mathcal{A})|$ and $E = |\text{Edges}(\mathcal{A})|$. Positive provenance verification traversing $\text{Nodes}(\mathcal{A})$ executes in deterministic linear time $O(V)$ via direct handle and table lookups. Surjective range completeness verification across all parsed schema nodes executes in $O(V + |\text{ASTNodes}(\mathcal{S})|)$ using a dense index coverage table or bitset tracking array. Auxiliary memory consumption is strictly bounded by $O(V + |\text{ASTNodes}(\mathcal{S})|)$ for storing provenance mapping descriptors and source span coordinate tables.

- **Verification & Conformance Criteria**: Compiler verification passes shall enforce the provenance invariant across all compilation units prior to intermediate representation lowering. An automated linter pass must traverse synthesized AST $\mathcal{A}$ and verify that 100% of nodes in $\text{Nodes}(\mathcal{A})$ satisfy $\Pi(n) \ne \bot$ and $\Pi(n) \in \mathcal{P}_{\text{domain}}$. If any AST node fails to resolve a valid source schema reference or deterministic RFC 4122 UUIDv5 anchor, or if $\text{Span}(n)$ violates file buffer boundary conditions, the compiler shall halt execution immediately and emit diagnostic error code `E0100` detailing the offending node identifier, expected parent scope, and invalid provenance pointer. If surjective range completeness is violated ($\text{Range}(\Pi) \nsupseteq \text{ASTNodes}(\mathcal{S})$), indicating a dropped or unrepresented schema entity, the compiler shall abort compilation and emit diagnostic error code `E0100` identifying the unmapped schema source node, source file path, and byte coordinates. Conformance is verified through deterministic regression suites asserting zero ungrounded nodes and 0-byte diff churn across repeated compilations of canonical MBSE schemas.
