### REQ-0050: AST Slice Serialization Contract with Reified Dependency Envelopes

- **Normative Statement**: The AST slicing and serialization engine of Subsystem 3 (Core Metamodel, Node Arena & AST Graph Engine) shall serialize extracted abstract syntax tree (AST) slices according to a formal, self-contained contract that packages the extracted subgraph along with a reified dependency envelope. The serialized slice package must encapsulate all external type definitions, unit systems, metric dimensions, interface contracts, and constraint declarations required to evaluate, type-check, and simulate the sliced component in complete semantic isolation, without requiring reference lookups into the parent AST or external workspace files.

  The AST slicing engine shall structure every serialized slice package into three canonical components:
  1. Slice Manifest (`SliceManifest`): A deterministic metadata header containing the RFC 4122 UUIDv5 identifier of the slice root, the target node handle, traversal query depth bound $`k`$, compiler schema version, 64-bit cryptographic digest (XXH3-64) of the payload, source file coordinates, and symbol export/import rosters.
  2. Primary Sliced Subgraph ($`G_{\text{slice}} = (V_{\text{slice}}, E_{\text{slice}})`$): The contiguous, typed AST nodes and relational edges extracted around the target entity in accordance with the context-bounded slicing criteria of REQ-0049.
  3. Reified Dependency Envelope ($`\text{Deps}(G_{\text{slice}}) = (V_{\text{deps}}, E_{\text{deps}})`$`): The minimal transitive semantic closure of external entities referenced by nodes in `$`V_{\text{slice}}`$` but defined outside `$`V_{\text{slice}}`$, partitioned into:
     - Reified Classifiers and Data Types: Minimal structural stubs (`ClassifierDef`, `DataType`, `Structure`) defining the payload types for all ports, parameters, attributes, and flow channels in $`V_{\text{slice}}`$.
     - Reified Physical Metrology and Unit Systems: 7D rational dimension vectors in $`\mathbb{Q}^7`$, unit definitions, and conversion factors required to validate dimensional homogeneity (REQ-0098, REQ-0101).
     - Reified Constraints and Operational Envelopes: Parametric constraint expressions, numerical boundary intervals $`[v_{\min}, v_{\max}]`$`, and operational invariants asserted against entities within `$`V_{\text{slice}}`$ (REQ-0083, REQ-0112).
     - Reified Port and Interface Contracts: Directionality tags (`in`, `out`, `inout`), flow payload bindings, and conjugate port definitions required for interface compatibility verification (REQ-0038, REQ-0039).

  To guarantee strict context isolation and prevent context bloat when dispatching slices to token-bounded subagents, external classifiers within the dependency envelope must be serialized as minimal interface stubs containing only their public feature signatures, types, and constraints, strictly excluding the internal behavioral bodies and realization details of external components.

  The serialization engine shall support two canonical interchange formats:
  1. Canonical CBOR (Concise Binary Object Representation): A compact, zero-copy binary encoding for cross-thread IPC and high-throughput deserialization into isolated compiler memory arenas (REQ-0044).
  2. Deterministic JSON: A standardized, human-readable format designed for LLM subagent prompt payload injection and diagnostic auditing.

  All node handles within the serialized slice package shall be remapped to contiguous, slice-relative 32-bit integer handles $`[0, |V_{\text{slice}}| + |V_{\text{deps}}| - 1]`$`, decoupling the serialized package from the source arena's virtual memory addresses or chunk offsets. In accordance with Architectural Directive 1 and REQ-0010, every node in `$`V_{\text{slice}}`$` and `$`V_{\text{deps}}`$ must retain a deterministic RFC 4122 UUIDv5 identifier computed by hashing the compiler namespace OID and its canonical fully qualified symbol path. String literals, identifiers, and qualified paths shall reference interned scalar `SymbolId` tokens within the global symbol interner pool, which constitutes the sole permitted exception to zero-copy memory management in accordance with Architectural Directive 3 and REQ-0036.

  When deserialized into an isolated compiler arena instance, the composite graph $`G_{\text{standalone}} = G_{\text{slice}} \cup \text{Deps}(G_{\text{slice}})`$` shall satisfy the Zero Dangling References Invariant (`$`\text{UnresolvedSymbols}(G_{\text{standalone}}) = \emptyset`$`) and the Standalone Validity Invariant (`$`\text{ValidateSlice}(G_{\text{standalone}}) \equiv \text{Valid}`$). If an extracted slice references an external symbol that cannot be resolved in the global symbol table or whose declaration is missing, the engine shall emit structured diagnostic error code `E0200` (`UnresolvedDependencyReference`) per REQ-0191. In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, the engine shall implement synchronization token error recovery: upon encountering an unresolved reference or malformed AST node, it shall record a structured diagnostic with the exact source byte span, substitute a typed error sentinel $`\bot_{\text{type}}`$`, and continue computing the remaining dependency envelope. If accumulated diagnostics reach `$`C_{\text{max\_errors}}`$, the compiler shall emit diagnostic error code `E0199` and terminate gracefully.

  Parallel slice extraction, dependency closure resolution, and serialization across independent subagent workers shall be scheduled strictly onto a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$` in accordance with Architectural Directive 2 and REQ-0012. In accordance with Architectural Directive 5, REQ-0011, and REQ-0196, the slicing serialization engine shall enforce a deterministic, non-panicking execution contract with total-function termination across all inputs, evaluating performance gates (execution latency strictly below 25 ms, peak RSS memory strictly below 100 MB for `$`|V_{\text{slice}}| = 10^4`$` and `$`|V_{\text{deps}}| = 10^3`$) exclusively in compiled Release mode (`--release`). All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Classifier_Alpha`, `Component_A`, `Port_1`, `Port_2`, `Flow_A`, `param_x : Real`, `Type_0`, `Unit_0`, `Constraint_A`) with zero domain contamination.

- **Formal Invariant**: Let $`G = (V, E)`$` be the complete compiler AST graph, where `$`V`$` is the set of typed AST nodes and `$`E \subseteq V \times V \times \mathcal{K}_{\text{rel}}`$` is the set of typed relational edges. Let `$`n_{\text{target}} \in V`$` be the query root node, and let `$`G_{\text{slice}} = (V_{\text{slice}}, E_{\text{slice}})`$` be the extracted AST slice subgraph, where `$`V_{\text{slice}} \subseteq V`$` and `$`E_{\text{slice}} \subseteq E \cap (V_{\text{slice}} \times V_{\text{slice}} \times \mathcal{K}_{\text{rel}})`$.

  Let $`\text{ReferencedSymbols}(G_{\text{slice}}) \subset \mathcal{S}_{\text{sym}}`$` denote the set of interned scalar symbol identifiers referenced across all node attributes, port types, expressions, constraints, and target edge endpoints in `$`G_{\text{slice}}`$:

```math
\text{ReferencedSymbols}(G_{\text{slice}}) = \bigcup_{u \in V_{\text{slice}}} \text{Refs}(u) \;\cup\; \bigcup_{e \in E_{\text{slice}}} \text{Refs}(e)
```

  Let $`\text{DefinedSymbols}(G_{\text{slice}}) \subset \mathcal{S}_{\text{sym}}`$` denote the set of interned scalar symbol identifiers declared or defined within `$`G_{\text{slice}}`$:

```math
\text{DefinedSymbols}(G_{\text{slice}}) = \{ \text{Sym}(u) \mid u \in V_{\text{slice}} \}
```

  The set of external required symbols $`\mathcal{S}_{\text{ext}}(G_{\text{slice}})`$ is the set difference:

```math
\mathcal{S}_{\text{ext}}(G_{\text{slice}}) = \text{ReferencedSymbols}(G_{\text{slice}}) \setminus \text{DefinedSymbols}(G_{\text{slice}})
```

  The reified dependency envelope is formalized as a directed subgraph $`\text{Deps}(G_{\text{slice}}) = (V_{\text{deps}}, E_{\text{deps}})`$`, where `$`V_{\text{deps}} \subset V \setminus V_{\text{slice}}`$ is the minimal set of reified stub nodes satisfying symbol closure:

```math
\mathcal{S}_{\text{ext}}(G_{\text{slice}}) \subseteq \text{DefinedSymbols}(\text{Deps}(G_{\text{slice}}))
```

  1. Transitive Dependency Closure Invariant: Every symbol referenced within the sliced subgraph $`G_{\text{slice}}`$` is defined either within `$`G_{\text{slice}}`$` or within the reified dependency envelope `$`\text{Deps}(G_{\text{slice}})`$:

```math
\text{ReferencedSymbols}(G_{\text{slice}}) \subseteq \text{DefinedSymbols}(G_{\text{slice}}) \cup \text{DefinedSymbols}(\text{Deps}(G_{\text{slice}}))
```

  2. Zero Dangling References Invariant: The set of unresolved symbol references in the composite standalone graph $`G_{\text{standalone}} = G_{\text{slice}} \cup \text{Deps}(G_{\text{slice}})`$ is strictly empty:

```math
\text{UnresolvedSymbols}(G_{\text{slice}} \cup \text{Deps}(G_{\text{slice}})) = \emptyset
```

  where:

```math
\text{UnresolvedSymbols}(G_{\text{standalone}}) = \text{ReferencedSymbols}(G_{\text{standalone}}) \setminus \text{DefinedSymbols}(G_{\text{standalone}})
```

  3. Standalone Validity Invariant: The composite standalone graph evaluates to valid under the complete semantic type checking and constraint verification function $`\text{ValidateSlice}`$:

```math
\text{ValidateSlice}(G_{\text{slice}} \cup \text{Deps}(G_{\text{slice}})) \equiv \text{Valid}
```

  4. Serialized Package Contract Schema: A serialized slice package $`\mathcal{P}_{\text{slice}}`$ is formalized as a 3-tuple:

```math
\mathcal{P}_{\text{slice}} = \langle \mathcal{M}_{\text{manifest}}, G_{\text{slice}}, \text{Deps}(G_{\text{slice}}) \rangle
```

  where the slice manifest $`\mathcal{M}_{\text{manifest}}`$ is defined as:

```math
\mathcal{M}_{\text{manifest}} = \langle \text{UUID}_{\text{slice}}, h_{\text{root}}, k, \nu_{\text{schema}}, \delta_{\text{payload}}, |V_{\text{slice}}|, |V_{\text{deps}}|, |E_{\text{slice}}|, |E_{\text{deps}}| \rangle
```

  where:
  - $`\text{UUID}_{\text{slice}} \in \mathbb{U}_{128}`$ is the deterministic RFC 4122 UUIDv5 identifier of the slice root,
  - $`h_{\text{root}} \in \mathbb{U}_{32}`$ is the slice-relative handle of the query target node,
  - $`k \in \mathbb{N}`$` is the traversal depth bound (`$`1 \le k \le k_{\text{max}}`$),
  - $`\nu_{\text{schema}} \in \mathbb{N}`$ is the compiler schema version number,
  - $`\delta_{\text{payload}} \in \mathbb{U}_{64}`$ is the XXH3-64 cryptographic checksum over the serialized graph bytes,
  - $`|V_{\text{slice}}|, |V_{\text{deps}}|, |E_{\text{slice}}|, |E_{\text{deps}}| \in \mathbb{N}_0`$ denote the entity and relation counts.

  5. Partitioned Dependency Envelope Invariant: The reified dependency envelope node set $`V_{\text{deps}}`$ is partitioned into four disjoint functional categories:

```math
V_{\text{deps}} = V_{\text{type}} \cup V_{\text{unit}} \cup V_{\text{constraint}} \cup V_{\text{interface}}
```

  defined as:

```math
\begin{aligned}
V_{\text{type}} &= \{ \text{Stub}_{\text{type}}(c) \mid c \in \mathcal{C} \setminus V_{\text{slice}} \;\wedge\; \exists u \in V_{\text{slice}} : \tau(u) = c \} \\
V_{\text{unit}} &= \{ \text{Stub}_{\text{unit}}(u) \mid u \in \mathcal{U}_{\mathbb{Q}^7} \setminus V_{\text{slice}} \;\wedge\; \exists v \in V_{\text{slice}} : \text{Unit}(v) = u \} \\
V_{\text{constraint}} &= \{ \text{Stub}_{\text{bound}}(e) \mid e \in \mathcal{E}_{\text{bound}} \setminus V_{\text{slice}} \;\wedge\; \exists p \in V_{\text{slice}} : p \models e \} \\
V_{\text{interface}} &= \{ \text{Stub}_{\text{port}}(p) \mid p \in \mathcal{P}_{\text{ext}} \setminus V_{\text{slice}} \;\wedge\; \exists c \in E_{\text{slice}} : \text{Endpoint}(c) = p \}
\end{aligned}
```

  6. Minimal Interface Stub Projection Invariant: For every reified external node $`v \in V_{\text{deps}}`$`, the node definition consists strictly of the public interface signature projection `$`\pi_{\text{stub}}(v)`$, eliminating internal behavioral bodies, child component hierarchies, and private implementation details:

```math
\forall v \in V_{\text{deps}}, \quad \text{Body}(v) = \emptyset \quad \wedge \quad \text{sizeof}(v) \le S_{\text{stub\_max}}
```

  7. Deterministic UUIDv5 Topological Invariant: Every node $`u \in V_{\text{slice}} \cup V_{\text{deps}}`$ retains an immutable RFC 4122 UUIDv5 identifier hashed from the namespace OID and canonical fully qualified path:

```math
\forall u \in V_{\text{slice}} \cup V_{\text{deps}}, \quad \text{UUID}(u) = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(u))
```

  8. Relocatable Slice Handle Remapping Invariant: Global arena node handles $`\mathcal{H}_{\text{global}} \subset \mathbb{U}_{64}`$` are bijectively mapped to slice-relative 32-bit integer handles `$`\mathcal{H}_{\text{slice}} = \{ 0, 1, \dots, |V_{\text{slice}}| + |V_{\text{deps}}| - 1 \}`$` via remapping function `$`\sigma_{\text{remap}}`$:

```math
\sigma_{\text{remap}} : (V_{\text{slice}} \cup V_{\text{deps}}) \longrightarrow \{ 0, 1, \dots, |V_{\text{slice}}| + |V_{\text{deps}}| - 1 \}
```

```math
\forall u, v \in V_{\text{slice}} \cup V_{\text{deps}}, \quad u \ne v \implies \sigma_{\text{remap}}(u) \ne \sigma_{\text{remap}}(v)
```

  9. Diagnostic Code Binding & Error Recovery Invariant: Any missing external dependency, invalid envelope structure, or validation failure deterministically emits diagnostic error code `E0200` per REQ-0191:

```math
\begin{aligned}
\mathcal{S}_{\text{ext}}(G_{\text{slice}}) \not\subseteq \text{DefinedSymbols}(\text{Deps}(G_{\text{slice}})) &\implies \text{Diagnostic}(G_{\text{slice}}, \text{DiagnosticCode::E0200}, \text{UnresolvedDependencyReference}) \in \mathcal{D}_{\text{sink}} \\
\text{ValidateSlice}(G_{\text{standalone}}) \ne \text{Valid} &\implies \text{Diagnostic}(G_{\text{slice}}, \text{DiagnosticCode::E0200}, \text{SliceValidationFailure}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
```

  10. Diagnostic Taxonomy Containment Invariant: All diagnostics emitted during slice extraction, envelope reification, and serialization belong strictly to the Subsystem 3 Metamodel and Typing family:

```math
\forall D \in \mathcal{D}_{\text{slice}}, \quad \text{code}(D) \in \{ \text{DiagnosticCode::E0200}, \text{DiagnosticCode::E0199} \} \subset \mathcal{E}_{\text{type}} \cup \mathcal{E}_{\text{ingest}}
```

- **Computational Complexity & Algorithmic Bounds**: Slicing and dependency envelope serialization executes strictly within Complexity Class $`\mathbf{P}`$. The algorithmic bounds across execution stages are formalized as follows:
  1. Dependency Envelope Closure Computation: For an extracted slice subgraph $`G_{\text{slice}} = (V_{\text{slice}}, E_{\text{slice}})`$`, each node `$`u \in V_{\text{slice}}`$` has an average reference fan-out degree `$`\bar{d} = \frac{1}{|V_{\text{slice}}|} \sum_{u \in V_{\text{slice}}} |\text{Refs}(u)|`$`. Scanning all symbol references in `$`V_{\text{slice}}`$` and `$`E_{\text{slice}}`$` executes in `$`O(|V_{\text{slice}}| \cdot \bar{d})`$` worst-case time, where `$`\bar{d}`$` is bounded by the metamodel feature fan-out limit (`$`\bar{d} \le d_{\text{max}} = 32 = O(1)`$).
  2. Minimal Stub Extraction & Envelope Construction: Filtering external references $`\mathcal{S}_{\text{ext}}(G_{\text{slice}})`$` against the global symbol table and constructing minimal interface stubs for the `$`|V_{\text{deps}}|`$` unique external symbols executes in `$`O(|V_{\text{deps}}|)`$` time via `$`O(1)`$ amortized hash table lookups.
  3. Relocatable Handle Remapping Table Construction: Computing the dense integer bijection $`\sigma_{\text{remap}}`$` over `$`V_{\text{slice}} \cup V_{\text{deps}}`$` executes in deterministic `$`O(|V_{\text{slice}}| + |V_{\text{deps}}|)`$ linear time.
  4. Package Serialization (CBOR and JSON): Emitting the slice manifest, primary subgraph, and reified dependency envelope into contiguous memory buffers executes in linear time:

```math
T_{\text{serialize}} \in O(|V_{\text{slice}}| + |V_{\text{deps}}| + |E_{\text{slice}}| + |E_{\text{deps}}|)
```

  5. Deserialization and Standalone Validation: Instantiating the serialized slice package into an isolated arena and executing complete semantic type checking and constraint verification executes in:

```math
T_{\text{validate}} \in O(|V_{\text{slice}}| + |V_{\text{deps}}| + |E_{\text{slice}}| + |E_{\text{deps}}|)
```

  6. Total Algorithmic Bound: The aggregate end-to-end execution time for slice extraction, envelope reification, and serialization is:

```math
T_{\text{total}} \in O(|V_{\text{slice}}| \cdot \bar{d} + |V_{\text{deps}}| + |E_{\text{slice}}| + |E_{\text{deps}}|)
```

  7. Parallel Work-Stealing Scheduling: When serializing $`K`$` independent slices across `$`N_{\text{max\_workers}}`$ threads in the bounded work-stealing thread pool:

```math
T_{\text{parallel}} \in O\left(\frac{K \cdot (|V_{\text{slice}}| \cdot \bar{d} + |V_{\text{deps}}| + |E_{\text{slice}}|)}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}}\right)
```

  8. Space Complexity: The memory footprint of the serialized package is strictly $`O(|V_{\text{slice}}| + |V_{\text{deps}}| + |E_{\text{slice}}| + |E_{\text{deps}}|)`$`, requiring zero unmanaged heap allocations. Auxiliary working sets during closure calculation are bounded by hash sets of size `$`O(|V_{\text{deps}}|)`$`. The diagnostic sink is pre-allocated with fixed capacity `$`O(C_{\text{max\_errors}}) = O(1)`$`, ensuring strict `$`O(1)`$ auxiliary heap memory overhead with respect to model size.

- **Verification & Conformance Criteria**: Automated test suites shall deterministically verify compliance using synthetic abstract MBSE models (e.g., `Package_0`, `Classifier_Alpha`, `Component_A`, `Port_1`, `Port_2`, `Flow_A`, `param_x : Real`, `Type_0`, `Unit_0`, `Constraint_A`) across the following verification gates:

  5. Synchronization Token Error Recovery Gate: Inject 5 distinct unresolved references across multiple ports and attributes in an extracted slice.   7. Verify that every node in `$`V_{\text{slice}}`$` and `$`V_{\text{deps}}`$ retains its deterministic RFC 4122 UUIDv5 identifier derived from the namespace OID and canonical qualified path (Directive 1, REQ-0010).
  8. Bounded Work-Stealing Parallelism Gate: Dispatch 100 concurrent slice extraction and serialization queries across an AST model on the bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ (Directive 2, REQ-0012). Assert thread isolation, zero data races, zero lock contention on the symbol interner, and bitwise identical serialized payloads.
  9. Assert total execution latency is strictly below 25 ms and peak RSS memory is strictly below 100 MB.
