### REQ-0017: Dynamic Semantic Header Key Normalization & Order-Independent Binding

- **Normative Statement**: The CommonMark table parser within the Universal Schema Ingestion Engine shall implement dynamic semantic header key normalization and order-independent column binding for all tabular MBSE schema models. The table ingestion engine must accept raw column header strings in arbitrary horizontal column arrangements and normalize each header string into a canonical metamodel attribute key through a deterministic, four-stage transformation pipeline: (1) leading and trailing ASCII whitespace trimming, (2) ASCII case folding to lowercase, (3) punctuation and symbol stripping with separator collapse, and (4) alias equivalence class matching against an immutable canonical attribute dictionary $`\mathcal{K}_{\text{canonical}}`$`. The engine shall construct a deterministic column-to-field binding vector `$`\vec{\beta}`$` mapping each column index `$`j \in \{0, \dots, C-1\}`$` to its unique canonical attribute key `$`k \in \mathcal{K}_{\text{canonical}}`$`. The ingestion engine shall process data rows positionally via `$`\vec{\beta}`$`, guaranteeing that any column permutation `$`\pi`$ of the input table produces an Abstract Syntax Tree (AST) entity structurally and semantically identical to the unpermuted schema. The normalization and binding pipeline must enforce a total, deterministic, non-panicking execution contract with zero panics or unhandled exceptions across all valid and malformed inputs. The engine shall enforce strict deterministic resolution: each recognized column header must resolve to exactly one canonical attribute key. If two or more distinct columns within the same table header row map to the identical canonical attribute key (duplicate column collision), or if an ambiguous header matches multiple canonical keys, the engine shall record structured diagnostic error code `E0102` detailing the conflicting column indices, raw header strings, and conflicting canonical keys, and engage synchronization token recovery. If a schema entity specifies a set of mandatory attribute keys $`\mathcal{M}`$ and one or more mandatory keys are absent from the resolved column binding vector, the engine must emit diagnostic error code `E0102` identifying the missing mandatory attribute, the target entity classifier, and the table header source byte span. If an unrecognized column header is encountered when strict schema validation is enabled, the engine shall emit diagnostic error code `E0102` reporting the unmapped header string, its column index, and source byte coordinates, alongside suggested closest matches from the canonical dictionary. The engine shall enforce a bounded column capacity limit $`C \le C_{\text{max\_cols}} = 32`$; tables exceeding this bound shall be rejected with diagnostic error code `E0102`.

- **Formal Invariant**: Let $`\Sigma`$` denote the byte alphabet, with `$`\Sigma_{\text{ASCII}} \subset \Sigma`$` denoting ASCII characters. Let `$`H \in \Sigma^*`$` be a raw column header string of byte length `$`|H|`$`. The whitespace trimming operator `$`\text{Trim} : \Sigma^* \to \Sigma^*`$` strips leading and trailing characters belonging to the set `$`\{ \text{SYM}_{\text{SPACE}}, \text{SYM}_{\text{TAB}}, \text{SYM}_{\text{LF}}, \text{SYM}_{\text{CR}} \}`$.

The ASCII case folding operator $`\text{CaseFold} : \Sigma^* \to \Sigma^*`$` maps uppercase ASCII bytes `$`[0\text{x}41, 0\text{x}5\text{A}]`$` into lowercase equivalents `$`[0\text{x}61, 0\text{x}7\text{A}]`$:

```math
\text{CaseFold}(b) = 
\begin{cases}
b + 0\text{x}20, & \text{if } 0\text{x}41 \le b \le 0\text{x}5\text{A} \\
b, & \text{otherwise}
\end{cases}
```

The punctuation stripping and separator collapse operator $`\text{StripPunct} : \Sigma^* \to \Sigma^*`$ removes non-alphanumeric punctuation bytes (including `-`, `_`, `.`, `/`, `:`, `(`, `)`, `[`, `]`, `{`, `}`) and collapses contiguous whitespace runs into a single canonical word separator:

```math
\text{StripPunct}(s) = \text{CollapseWhitespace}(\{ b \in s \mid b \in \Sigma_{\text{alphanumeric}} \cup \{ \text{SYM}_{\text{SPACE}} \} \})
```

The composite semantic header normalization operator $`\eta : \Sigma^* \to \Sigma^*`$ is defined as:

```math
\eta(H) = \text{CaseFold}(\text{StripPunct}(\text{Trim}(H)))
```

Let $`\mathcal{K}_{\text{canonical}} = \{ k_1, k_2, \dots, k_M \}`$` denote the finite set of canonical attribute keys defined for entity classifier `$`T_{\text{entity}}`$`. For each canonical key `$`k \in \mathcal{K}_{\text{canonical}}`$`, let `$`\text{Aliases}(k) \subset \Sigma^*`$ define the pairwise disjoint set of authorized normalized alias strings:

```math
\forall k_a, k_b \in \mathcal{K}_{\text{canonical}}, \quad k_a \ne k_b \implies \text{Aliases}(k_a) \cap \text{Aliases}(k_b) = \emptyset
```

Let $`\mathbf{H} = \langle H_0, H_1, \dots, H_{C-1} \rangle`$` denote the ordered sequence of raw column headers for a table containing `$`C`$` columns, where `$`1 \le C \le C_{\text{max\_cols}} = 32`$`. The column-to-attribute binding function `$`\beta : \Sigma^* \to \mathcal{K}_{\text{canonical}} \cup \{ \bot \}`$ is defined as:

```math
\beta(H) = 
\begin{cases}
k, & \text{if } \exists ! \, k \in \mathcal{K}_{\text{canonical}} \text{ such that } \eta(H) \in \text{Aliases}(k) \\
\bot, & \text{if } \forall k \in \mathcal{K}_{\text{canonical}}, \; \eta(H) \notin \text{Aliases}(k)
\end{cases}
```

Deterministic Resolution Invariant: Every recognized header resolves to exactly one canonical attribute key:

```math
\forall H \in \mathbf{H}, \quad \beta(H) \ne \bot \implies |\{ k \in \mathcal{K}_{\text{canonical}} \mid \eta(H) \in \text{Aliases}(k) \}| = 1
```

Injective Column Assignment Invariant: No two distinct table columns within the same header row may bind to the identical canonical key:

```math
\forall i, j \in \{0, \dots, C-1\}, \quad (i \ne j \;\wedge\; \beta(H_i) \ne \bot \;\wedge\; \beta(H_j) \ne \bot) \implies \beta(H_i) \ne \beta(H_j)
```

Mandatory Attribute Coverage Invariant: Let $`\mathcal{M}(T_{\text{entity}}) \subseteq \mathcal{K}_{\text{canonical}}`$` denote the set of mandatory attribute keys required to construct an instance of entity type `$`T_{\text{entity}}`$`. The resolved column binding set must completely cover `$`\mathcal{M}(T_{\text{entity}})`$:

```math
\mathcal{M}(T_{\text{entity}}) \subseteq \{ \beta(H_j) \mid j \in \{0, \dots, C-1\} \}
```

Row Entity Attribute Synthesis: Let data row $`\mathbf{r} = \langle c_0, c_1, \dots, c_{C-1} \rangle`$` denote an ordered sequence of cell value strings. The synthesized entity attribute map `$`\mathcal{E}(\mathbf{H}, \mathbf{r})`$ is defined as:

```math
\mathcal{E}(\mathbf{H}, \mathbf{r}) = \{ (\beta(H_j), c_j) \mid j \in \{0, \dots, C-1\} \;\wedge\; \beta(H_j) \ne \bot \}
```

Column Permutation Invariance Invariant: For any column permutation $`\pi \in \mathfrak{S}_C`$` acting simultaneously on the header sequence `$`\pi(\mathbf{H}) = \langle H_{\pi(0)}, \dots, H_{\pi(C-1)} \rangle`$` and cell sequence `$`\pi(\mathbf{r}) = \langle c_{\pi(0)}, \dots, c_{\pi(C-1)} \rangle`$:

```math
\mathcal{E}(\pi(\mathbf{H}), \pi(\mathbf{r})) \equiv \mathcal{E}(\mathbf{H}, \mathbf{r})
```

AST Synthesis Isomorphism Invariant: Let $`\mathcal{T} = (\mathbf{H}, \mathbf{R})`$` represent the complete table schema comprising header sequence `$`\mathbf{H}`$` and row set `$`\mathbf{R} = \{ \mathbf{r}_1, \dots, \mathbf{r}_M \}`$`. For any column permutation `$`\pi \in \mathfrak{S}_C`$:

```math
\text{SynthesizeAST}(\pi(\mathcal{T})) \equiv \text{SynthesizeAST}(\mathcal{T})
```

Diagnostic Error Code Binding Invariant: Header structural faults trigger structured diagnostic records binding error code `E0102` in accordance with REQ-0191:

```math
\begin{aligned}
\exists i \ne j \text{ s.t. } \beta(H_i) = \beta(H_j) \ne \bot &\implies \text{Diagnostic}(R_0, C_j, \text{DiagnosticCode::E0102}, \text{DuplicateBinding}) \in \mathcal{D} \\
\mathcal{M}(T_{\text{entity}}) \setminus \{ \beta(H_j) \}_{j=0}^{C-1} \ne \emptyset &\implies \text{Diagnostic}(R_0, 0, \text{DiagnosticCode::E0102}, \text{MissingMandatory}) \in \mathcal{D} \\
\exists j \text{ s.t. } \beta(H_j) = \bot \;\wedge\; \text{Strict}(\mathcal{S}) &\implies \text{Diagnostic}(R_0, C_j, \text{DiagnosticCode::E0102}, \text{UnrecognizedHeader}) \in \mathcal{D} \\
C \gt C_{\text{max\_cols}} &\implies \text{Diagnostic}(R_0, C, \text{DiagnosticCode::E0102}, \text{ColumnLimitExceeded}) \in \mathcal{D}
\end{aligned}
```

- **Computational Complexity & Algorithmic Bounds**: Dynamic semantic header key normalization and order-independent column binding execute within Complexity Class $`\mathbf{P}`$`. For each raw header string `$`H_j`$`, string trimming, ASCII case folding, and punctuation stripping execute in a single sequential pass over the byte slice, requiring deterministic `$`O(|H_j|)`$` operations. Given maximum header string length `$`|H_j| \le L_{\text{max}} = 256`$` bytes, normalization runs in `$`O(1)`$` constant time per column. Canonical alias dictionary lookup against `$`\mathcal{K}_{\text{canonical}}`$` with total aliases `$`A_{\text{total}} = \sum_{k} |\text{Aliases}(k)| \le 256`$` is performed using a precomputed static minimal perfect hash table or Trie structure, executing in deterministic `$`O(|H_j|) = O(1)`$` time. For a table containing `$`C`$` columns (`$`1 \le C \le C_{\text{max\_cols}} = 32`$`), header vector normalization and binding vector computation `$`\vec{\beta}`$ execute in:

```math
O\left(\sum_{j=0}^{C-1} |H_j|\right) \le O(C \cdot L_{\text{max}}) = O(C)
```

which is strictly $`O(1)`$` constant operations under the bounded architectural limit `$`C \le 32`$`. Injective column assignment verification and mandatory key completeness verification operate on a 64-bit integer bitmask representation for `$`|\mathcal{K}_{\text{canonical}}| \le 64`$`, executing in `$`O(C)`$` time with `$`O(1)`$` bitwise operations. During data row ingestion across `$`M`$` table rows containing `$`C`$` cells per row with total table byte size `$`N = \sum_{i=1}^M \sum_{j=0}^{C-1} |c_{i, j}|`$`, extracting cells positionally via precomputed binding vector `$`\vec{\beta}`$` requires `$`O(C)`$` operations per row. Total table ingestion and AST entity synthesis execute in deterministic `$`O(N)`$` linear time in total input size. Auxiliary space complexity is strictly bounded by `$`O(C)`$ for maintaining the 32-element column-to-key index mapping array and bitmasks, consuming at most 128 bytes of stack space, with zero dynamic heap allocations in row parsing inner loops.

- **Verification & Conformance Criteria**: Automated test suites shall verify compliance against synthetic CommonMark schema tables containing generic MBSE entities (e.g., `Package_0`, `Component_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`). Conformance shall be validated through the following deterministic test gates: (1) Permutation Invariance Gate: Ingest a canonical schema table defining component assemblies with columns $`\langle \text{Name}, \text{Type}, \text{Multiplicity}, \text{Description} \rangle`$` and evaluate all `$`4! = 24`$` column permutations (such as `$`\langle \text{Description}, \text{Name}, \text{Type}, \text{Multiplicity} \rangle`$); assert that all 24 permuted tables synthesize bitwise and structurally identical AST entities with 0-byte diff churn. (2) Normalization Equivalence Gate: Verify that variations in casing (`"NAME"`, `"name"`, `"Name"`), whitespace (`"  Name  "`, `"\tName\r\n"`), punctuation (`"part-name"`, `"part_name"`, `"part.name"`, `"Part Name:"`, `"Part / Name"`, `"[Part Name]"`), and authorized aliases (`"id"`, `"identifier"`, `"name"`, `"symbol"`) resolve to the exact same canonical key $`k_{\text{name}}`$. (3) Duplicate Column Collision Gate: Ingest a test table containing colliding column headers (such as column 0 `"Name"` and column 2 `"Identifier"`, both resolving to $`k_{\text{name}}`$); assert that entity synthesis halts, error recovery engages, and exactly one structured diagnostic record is emitted binding diagnostic error code `E0102` with colliding column coordinates and token byte spans. (4) Missing Mandatory Column Gate: Ingest a test table omitting a mandatory column (e.g., omitting mandatory attribute $`k_{\text{type}}`$ for a component declaration); assert that the parser emits diagnostic error code `E0102` identifying the missing mandatory field and table header source span. (5) Unrecognized Header Gate: Ingest a test table containing an unknown column header (e.g., `"Unknown_Field_XYZ"`); in strict validation mode, assert emission of diagnostic error code `E0102` with Levenshtein-distance remediation suggestions; in permissive mode, assert that the unknown field is diverted into an auxiliary annotation bag without polluting canonical entity attributes. (6) Column Arity Limit Gate: Ingest a table containing $`C = 33 \gt C_{\text{max\_cols}}`$ columns; assert rejection with diagnostic error code `E0102`. (7) Panic-Free Contract: Fuzz testing with high-entropy, malformed, and pathological header inputs shall verify 100% total function termination with zero panics or unhandled aborts.
