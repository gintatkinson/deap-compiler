### REQ-0123: Complete State Machine Reachability Analysis & Dead State Diagnostics

- **Normative Statement**: The spatio-temporal dynamics solver and discrete state machine verification engine of Subsystem 6 shall perform an exhaustive forward reachability analysis across the complete declared state space of every discrete state machine in the compiled MBSE model, deterministically detecting, diagnosing, and reporting all dead states, dead state islands, unreachable transitions, and unintended dead-end trap states.

  Specifically, the state machine compiler, reachability analyzer, and diagnostic engine shall enforce the following architectural, structural, and algebraic invariants:
  1. **Directed State Machine Graph Representation & Initial State Invariants**:
     - The compiler shall model each discrete state machine as a directed state graph $`\mathcal{G}_{\text{sm}} = \langle \mathcal{S}, \mathcal{E}_{\text{trans}}, s_0, \mathcal{S}_{\text{final}} \rangle`$` within contiguous arena storage, where `$`\mathcal{S}`$` is the set of declared states, `$`\mathcal{E}_{\text{trans}}`$` is the set of directed transitions, `$`s_0 \in \mathcal{S}`$` is the designated initial state, and `$`\mathcal{S}_{\text{final}} \subseteq \mathcal{S}`$ is the set of declared final/terminal states.
     - *Single Initial State Invariant*: Every state machine container and non-orthogonal composite state scope must declare exactly one unique initial entry state $`s_0 \in \mathcal{S}`$` (`$`\text{is\_initial}(s_0) = \text{true}`$).
     - If zero initial states are declared within a state machine container, the compiler shall deterministically reject the model at compile time with diagnostic error code `E0400` (`MissingInitialState`).
     - If multiple initial states are declared within the same scope ($`|\{ s \in \mathcal{S} \mid \text{is\_initial}(s) = \text{true} \}| \gt 1`$), the compiler shall deterministically reject the model at compile time with diagnostic error code `E0400` (`MultipleInitialStates`).
     - The initial state $`s_0`$` is intrinsically reachable (`$`s_0 \in \mathcal{R}`$) and serves as the inductive base for fixed-point reachability computation.
  2. **Exhaustive Forward Reachability Analysis & Least Fixed-Point Computation**:
     - The compiler shall compute the complete set of reachable states $`\mathcal{R} \subseteq \mathcal{S}`$` as the least fixed point (transitive closure) of the forward post-image operator starting from the initial state `$`s_0`$:

```math
       \mathcal{R} = \mu X. \left( \{ s_0 \} \cup \text{Post}(X) \right)
```

     - The post-image operator $`\text{Post}(X)`$` shall compute the set of immediate target states accessible from any currently reached state `$`s \in X`$` via an outgoing transition `$`\tau = (s, s') \in \mathcal{E}_{\text{trans}}`$` whose guard condition `$`g_\tau`$` is statically satisfiable (`$`\text{Sat}(g_\tau) \ne \text{false}`$).
     - Reachability traversal shall execute via deterministic queue-based breadth-first search (BFS) or depth-first search (DFS) over a contiguous bitset marking vector, terminating when the reachability frontier becomes empty ($`\text{Frontier} = \emptyset`$).
  3. **Dead State Detection & Diagnostic Reporting**:
     - Any state $`s \in \mathcal{S}`$` lacking an executable transition path originating from the initial state `$`s_0`$` (i.e., `$`s \notin \mathcal{R}`$`) shall be classified as a dead state (`$`s \in \mathcal{D}_{\text{dead}} = \mathcal{S} \setminus \mathcal{R}`$).
     - Every dead state shall be deterministically detected and flagged at compile time with diagnostic error code `E0400` (`DeadStateDetected`).
     - Emitted diagnostics must report the interned state symbol identifier, fully qualified topological name, source file ID, byte span, line and column coordinates, and parent composite container handle.
     - The diagnostic engine shall identify both isolated dead states (states with an in-degree of zero) and dead state islands (disconnected subgraphs or strongly connected components that possess mutual cyclic transitions among themselves but have zero incoming transition paths from $`s_0`$).
  4. **Transition Reachability & Dead Transition Elimination**:
     - A transition $`\tau = (s_{\text{src}}, s_{\text{tgt}}) \in \mathcal{E}_{\text{trans}}`$` is classified as reachable if and only if its source state is reachable (`$`s_{\text{src}} \in \mathcal{R}`$`) and its guard condition `$`g_\tau`$` is statically satisfiable (`$`\text{Sat}(g_\tau) \ne \text{false}`$).
     - Any transition originating from an unreachable dead state ($`s_{\text{src}} \in \mathcal{D}_{\text{dead}}`$`) or guarded by a statically false condition (`$`g_\tau \equiv \text{false}`$`) shall be classified as an unreachable transition (`$`\tau \in \mathcal{E}_{\text{dead}}`$) and deterministically reported at compile time with diagnostic error code `E0400` (`UnreachableTransitionDetected`).
  5. **Dead-End / Unintended Sink State Diagnostics**:
     - The compiler shall formally distinguish between declared final/terminal states ($`\mathcal{S}_{\text{final}}`$) and active states.
     - Any reachable non-final state $`s \in \mathcal{R} \setminus \mathcal{S}_{\text{final}}`$` that possesses zero outgoing transitions (`$`\text{out-degree}(s) = 0`$`) or whose outgoing transitions all possess statically unsatisfiable guards (`$`\forall \tau \in \mathcal{E}_{\text{trans}}, s_{\text{src}}(\tau) = s \implies g_\tau \equiv \text{false}`$`) shall be classified as an unintended trap/dead-end state (`$`s \in \mathcal{D}_{\text{trap}}`$).
     - Every unintended trap state shall be deterministically reported at compile time with diagnostic error code `E0400` (`DeadEndStateDetected`).
  6. **Hierarchical Composite State Reachability Propagation**:
     - For hierarchical statecharts, if an enclosing composite state $`S_{\text{comp}}`$` is unreachable from the root initial state (`$`S_{\text{comp}} \in \mathcal{D}_{\text{dead}}`$), all of its child sub-states and nested transitions shall be transitively classified as unreachable dead entities.
     - If $`S_{\text{comp}}`$` is reachable (`$`S_{\text{comp}} \in \mathcal{R}`$`), entry into `$`S_{\text{comp}}`$` activates its internal default initial state `$`s_{0,\text{comp}}`$, from which intra-composite reachability is independently and recursively evaluated.
  7. **Compliance with the 5 Executive Architectural Directives**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every state machine, state entity, transition descriptor, and reachability witness record shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical compiler namespace OID and the node fully qualified topological path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))`$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Reachability analysis and dead state diagnostics across independent state machine modules or decoupled packages shall execute strictly on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Memory Allocation Exception)*: State identifiers, transition names, event symbols, guard predicates, and fully qualified path segments shall be interned into the deduplicated global symbol interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The reachability analyzer shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When dead states or invalid transitions occur (`E0400`), diagnostics shall accumulate in the error sink buffer $`\mathcal{D}_{\text{sink}}`$`, substitute typed error sentinels (`$`\bot_{\text{state}}`$`, `$`\bot_{\text{trans}}`$`, `$`\bot_{\text{reach}}`$`), and continue validating subsequent state machines. If accumulated diagnostics reach capacity `$`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully in accordance with REQ-0013 and REQ-0016.
     - *Directive 5 (Panic-Free Release Isolation)*: The state machine reachability pipeline shall strictly enforce a deterministic, non-panicking execution contract with total-function error handling. Verification latency ($`\lt 25\text{ ms}`$` for `$`10^4`$` states and `$`2 \times 10^4`$` transitions) and peak RSS memory (`$`\lt 100\text{ MB}`$) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests in accordance with REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `StateMachine_Alpha`, `StateMachine_Beta`, `State_Alpha`, `State_Beta`, `State_Gamma`, `State_Dead_1`, `State_Dead_2`, `Transition_1`, `Transition_2`, `Port_1`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $`\mathcal{V}_{\text{AST}}`$ denote the universe of allocated AST nodes in contiguous arena storage.

  The discrete state machine graph $`\mathcal{G}_{\text{sm}}`$ is formalized as a 4-tuple:

```math
  \mathcal{G}_{\text{sm}} = \langle \mathcal{S}, \mathcal{E}_{\text{trans}}, s_0, \mathcal{S}_{\text{final}} \rangle
```

  where $`\mathcal{S} \subset \mathcal{V}_{\text{AST}}`$` is the finite set of state entities, `$`\mathcal{E}_{\text{trans}} \subset \mathcal{V}_{\text{AST}}`$` is the finite set of directed transition edges, `$`s_0 \in \mathcal{S}`$` is the designated initial state, and `$`\mathcal{S}_{\text{final}} \subseteq \mathcal{S}`$ is the set of declared final states.

  Each state entity $`s \in \mathcal{S}`$ is formalized as an 8-tuple:

```math
  s = \langle \text{id}_s, \text{name}_s, \kappa_s, \text{parent}_s, \Delta_s, \text{span}_s, \text{is\_initial}_s, \text{is\_final}_s \rangle
```

  where:

```math
  \begin{aligned}
  \text{id}_s &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
  \text{name}_s &\in \mathcal{S}_{\text{intern}} \quad (\text{interned scalar symbol identifier}) \\
  \kappa_s &\in \{ \text{Kind::Atomic}, \text{Kind::Composite}, \text{Kind::Initial}, \text{Kind::Final} \} \\
  \text{parent}_s &\in \mathcal{S} \cup \{ \bot \} \quad (\text{enclosing composite container or root sentinel}) \\
  \Delta_s &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
  \text{span}_s &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance}) \\
  \text{is\_initial}_s &\in \{ \text{true}, \text{false} \} \quad (\text{initial entry state discriminant}) \\
  \text{is\_final}_s &\in \{ \text{true}, \text{false} \} \quad (\text{terminal state discriminant})
  \end{aligned}
```

  Each transition edge $`\tau \in \mathcal{E}_{\text{trans}}`$ is formalized as an 8-tuple:

```math
  \tau = \langle \text{id}_\tau, s_{\text{src}}, s_{\text{tgt}}, e_\tau, g_\tau, a_\tau, \Delta_\tau, \text{span}_\tau \rangle
```

  where:

```math
  \begin{aligned}
  \text{id}_\tau &\in \mathbb{N}_{32} \quad (\text{contiguous arena transition handle}) \\
  s_{\text{src}} &\in \mathcal{S} \quad (\text{source state node handle}) \\
  s_{\text{tgt}} &\in \mathcal{S} \quad (\text{target state node handle}) \\
  e_\tau &\in \Sigma_{\text{event}} \cup \{ \epsilon \} \quad (\text{triggering event symbol or spontaneous transition}) \\
  g_\tau &\in \mathcal{G}_{\text{guard}} \quad (\text{boolean guard predicate expression}) \\
  a_\tau &\in \mathcal{A}_{\text{effect}} \cup \{ \bot \} \quad (\text{associated action effect execution}) \\
  \Delta_\tau &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
  \text{span}_\tau &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
  \end{aligned}
```

  Initial State Existence and Uniqueness Invariant:

```math
  |\{ s \in \mathcal{S} \mid \text{is\_initial}_s = \text{true} \}| = 1
```

```math
  s_0 = \arg\min_{s \in \mathcal{S}, \text{is\_initial}_s = \text{true}} (\text{id}_s)
```

  Forward Post-Image Operator $`\text{Post}(X)`$:

```math
  \text{Post}(X) = \left\{ s' \in \mathcal{S} \;\middle|\; \exists s \in X, \, \exists \tau \in \mathcal{E}_{\text{trans}} : (s_{\text{src}}(\tau) = s) \wedge (s_{\text{tgt}}(\tau) = s') \wedge \text{Sat}(g_\tau) \right\}
```

  where $`\text{Sat}(g_\tau) \equiv \text{true}`$` denotes that guard predicate `$`g_\tau`$ is statically satisfiable (not identically false).

  Transitive Closure & Least Fixed-Point Reachable Set $`\mathcal{R}`$:

```math
  \mathcal{R} = \mu X. \left( \{ s_0 \} \cup \text{Post}(X) \right)
```

  Iterative Fixed-Point Sequence:

```math
  \begin{aligned}
  R_0 &= \{ s_0 \} \\
  R_{k+1} &= R_k \cup \text{Post}(R_k) \\
  \mathcal{R} &= \bigcup_{k=0}^{|\mathcal{S}| - 1} R_k
  \end{aligned}
```

  Fixed-Point Convergence Guarantee:

```math
  \exists k^* \le |\mathcal{S}| - 1 : R_{k^* + 1} = R_{k^*} = \mathcal{R}
```

  Dead State Set Formulation:

```math
  \mathcal{D}_{\text{dead}} = \mathcal{S} \setminus \mathcal{R} = \{ s \in \mathcal{S} \mid s \notin \mathcal{R} \}
```

  Unreachable Transition Set Formulation:

```math
  \mathcal{E}_{\text{dead}} = \{ \tau \in \mathcal{E}_{\text{trans}} \mid (s_{\text{src}}(\tau) \in \mathcal{D}_{\text{dead}}) \lor \neg \text{Sat}(g_\tau) \}
```

  Unintended Dead-End / Trap State Set Formulation:

```math
  \mathcal{D}_{\text{trap}} = \left\{ s \in \mathcal{R} \setminus \mathcal{S}_{\text{final}} \;\middle|\; \forall \tau \in \mathcal{E}_{\text{trans}}, \, s_{\text{src}}(\tau) = s \implies \neg \text{Sat}(g_\tau) \right\}
```

  Complete Reachability Soundness Invariant:

```math
  \text{ReachabilitySound}(\mathcal{G}_{\text{sm}}) \iff (\mathcal{D}_{\text{dead}} = \emptyset) \wedge (\mathcal{D}_{\text{trap}} = \emptyset) \wedge (\mathcal{E}_{\text{dead}} = \emptyset)
```

  Deterministic Diagnostic Emission Invariant (REQ-0191):

```math
  \begin{aligned}
  \exists s \in \mathcal{D}_{\text{dead}} &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0400}, \text{DeadStateDetected}) \in \mathcal{D}_{\text{sink}} \\
  \exists \tau \in \mathcal{E}_{\text{dead}} &\implies \text{Diagnostic}(\tau, \text{DiagnosticCode::E0400}, \text{UnreachableTransitionDetected}) \in \mathcal{D}_{\text{sink}} \\
  \exists s \in \mathcal{D}_{\text{trap}} &\implies \text{Diagnostic}(s, \text{DiagnosticCode::E0400}, \text{DeadEndStateDetected}) \in \mathcal{D}_{\text{sink}} \\
  |\{ s \in \mathcal{S} \mid \text{is\_initial}_s = \text{true} \}| = 0 &\implies \text{Diagnostic}(\mathcal{G}_{\text{sm}}, \text{DiagnosticCode::E0400}, \text{MissingInitialState}) \in \mathcal{D}_{\text{sink}} \\
  |\{ s \in \mathcal{S} \mid \text{is\_initial}_s = \text{true} \}| \gt 1 &\implies \text{Diagnostic}(\mathcal{G}_{\text{sm}}, \text{DiagnosticCode::E0400}, \text{MultipleInitialStates}) \in \mathcal{D}_{\text{sink}} \\
  |\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
  \end{aligned}
```

  Deterministic RFC 4122 UUIDv5 Anchor Invariant (Directive 1):

```math
  \begin{aligned}
  \forall s \in \mathcal{S}, &\quad \Delta_s = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(s)) \\
  \forall \tau \in \mathcal{E}_{\text{trans}}, &\quad \Delta_\tau = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(\tau))
  \end{aligned}
```

- **Computational Complexity & Algorithmic Bounds**: Complete state machine reachability analysis, fixed-point transitive closure computation, dead state identification, and dead-end trap state detection reside strictly in **Complexity Class P** (Deterministic Polynomial Time).

  **Mathematical Delineation from Algorithmic Bound NP-5**:
  In concurrent statecharts containing $`K`$` orthogonal parallel regions, reachability analysis, deadlock freedom, and livelock detection is PSPACE-complete (or NP-complete under bounded depth unrolling `$`k \le k_{\text{max}}`$), as formalized under Algorithmic Bound NP-5 (REQ-0124) via SAT-based Bounded Model Checking (BMC). This state explosion occurs because the composite state space grows exponentially as the Cartesian product:

```math
  |\mathcal{S}_{\text{global}}| = \prod_{i=1}^K |\mathcal{S}_i|
```

  In contrast, REQ-0123 governs the complete reachability analysis of explicit state machine graphs within single-region state machines and non-orthogonal hierarchical statecharts. Because the transition relation operates directly over the explicit state set $`\mathcal{S}`$` without Cartesian product expansion, all reachability and fixed-point algorithms execute in deterministic linear time `$`O(|\mathcal{S}| + |\mathcal{E}_{\text{trans}}|)`$ without combinatorial search or backtracking.

  **Asymptotic Complexity Analysis**:
  For an abstract MBSE discrete state machine model comprising $`V = |\mathcal{S}|`$` state entities and `$`E = |\mathcal{E}_{\text{trans}}|`$ directed transitions:
  1. *Graph Construction & Initial State Resolution*:
     Allocating state descriptors and transitions in contiguous bump arena memory and verifying that exactly one initial state $`s_0`$ exists requires a single linear pass over declared entities:

```math
     T_{\text{construct}}(V, E) \in O(V + E)
```

  2. *Breadth-First / Depth-First Reachability Search*:
     The fixed-point reachability algorithm maintains a FIFO worklist queue $`\mathcal{Q}`$` and a visited bitset vector of length `$`V`$`. Each reachable state `$`s \in \mathcal{R}`$` is enqueued and dequeued exactly once, and each outgoing transition `$`\tau \in \mathcal{E}_{\text{trans}}`$ originating from a reachable state is inspected at most once:

```math
     T_{\text{reach}}(V, E) = \sum_{s \in \mathcal{R}} \left( O(1) + \sum_{\tau \in \text{Outgoing}(s)} O(1) \right) \in O(V + E)
```

  3. *Dead State Complement Identification*:
     After the worklist queue terminates, the dead state set $`\mathcal{D}_{\text{dead}} = \mathcal{S} \setminus \mathcal{R}`$ is extracted by performing a single bitwise NOT and linear sweep over the visited bitset vector in:

```math
     T_{\text{dead}}(V) \in O(V)
```

  4. *Static Guard Satisfiability Evaluation*:
     Evaluating boolean guard expressions for literal truth values ($`g_\tau \equiv \text{false}`$`) requires `$`O(1)`$ operations per transition, totaling:

```math
     T_{\text{guard}}(E) \in O(E)
```

  5. *Dead Transition & Trap State Detection*:
     Scanning transitions originating from dead states to form $`\mathcal{E}_{\text{dead}}`$` and checking out-degrees of reachable non-final states to form `$`\mathcal{D}_{\text{trap}}`$ inspects each state and transition exactly once:

```math
     T_{\text{trap}}(V, E) \in O(V + E)
```

  6. *Deterministic Diagnostic Ordering*:
     Sorting emitted diagnostics by interned fully qualified names to preserve bitwise determinism and zero diff churn per REQ-0003 takes:

```math
     T_{\text{sort}}(|\mathcal{D}_{\text{dead}}|) \in O(|\mathcal{D}_{\text{dead}}| \log |\mathcal{D}_{\text{dead}}|) \subseteq O(V \log V)
```

  7. *Aggregate Worst-Case Time Complexity*:
     Combining all evaluation phases, the total deterministic worst-case execution time is:

```math
     T_{\text{total}}(V, E) \in O(V \log V + E) \subseteq O((V + E) \log V)
```

     Operating without backtracking, recursive depth unrolling, or heuristic search, the algorithm guarantees deterministic polynomial-time execution.
  8. *Parallel Work-Stealing Scaling (Architectural Directive 2)*:
     When evaluating $`P`$` independent state machines or decoupled packages across `$`N_{\text{max\_workers}}`$ threads on a bounded work-stealing thread pool:

```math
     T_{\text{parallel}}(V, E, N_{\text{max\_workers}}) \in O\left( \frac{V \log V + E}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
```

  9. *Space Complexity & Arena Memory Bounds*:
     State descriptors and transition adjacency lists are allocated in contiguous bump arena storage, requiring $`O(V + E)`$` bytes. Visited bitsets consume `$`\lceil V / 64 \rceil \times 8`$` bytes (`$`O(V)`$` bits). The FIFO queue contains at most `$`V`$` node handles (`$`O(V)`$` space). Interned symbol tokens require `$`O(V)`$` space in the global symbol pool. The diagnostic error sink buffer is strictly bounded by `$`O(C_{\text{max\_errors}}) = O(1)`$ capacity.
