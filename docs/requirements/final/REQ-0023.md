### REQ-0023: Tabular Schema Ingestion for Attributes, Data Types & Numerical Envelopes

- **Normative Statement**: The ingestion engine within the Universal Schema Ingestion Engine shall parse tabular schemas defining classifier attributes, scalar data types, optional default values, engineering units, and numerical bounds into strongly typed `IngestedAttr` intermediate AST entities. The ingestion parser shall extract numerical envelopes as closed, open, half-open, or unbounded intervals over real or rational numbers with associated dimensional unit tags. Front-end table ingestion passes shall operate directly on tokenized table rows resolved via dynamic column binding vectors, extracting attribute declarations without materializing unneeded intermediate string representations. Every ingested attribute entity shall capture exact source provenance, including 0-indexed byte offset intervals and 1-indexed line and column coordinates. The parser shall enforce strict interval consistency: the lower envelope bound $`L`$ must not exceed the upper envelope bound $`U`$ ($`L \le U`$); degenerate singleton intervals ($`L = U`$) shall be permitted if and only if both boundaries are closed; and any specified default value $`v_{\text{default}}`$ must strictly reside within the declared interval envelope ($`v_{\text{default}} \in [L, U]`$). Engineering unit expressions shall be parsed and mapped into canonical 7-dimensional rational exponent vectors $`\mathbf{u} \in \mathbb{Q}^7`$ over the SI base dimensions, or assigned the dimensionless zero vector $`\mathbf{0}`$ when no unit is declared or for non-numeric types. Any schema violation--including inverted interval bounds ($`L \gt U`$), default values violating envelope boundaries, malformed numeric or interval syntax, incompatible data type assignments (such as assigning numerical ranges to boolean or string types), or unresolvable unit expressions--shall deterministically emit structured diagnostic code `E0103` in accordance with the standardized diagnostic taxonomy of REQ-0191. In accordance with Architectural Directive 4, the attribute ingestion pass shall implement synchronization recovery upon encountering an attribute row fault, recording the localized diagnostic `E0103`, substituting a typed error sentinel $`\bot_{\text{attr}}`$ into the owning classifier AST, and resuming parsing at the subsequent table row without abandoning subsequent declarations. Attribute parsing and validation shall enforce a deterministic, non-panicking execution contract with total-function termination across all inputs.

- **Formal Invariant**: Let $`\mathcal{A}`$ denote the set of ingested attribute entities. Each ingested attribute entity $`A \in \mathcal{A}`$ is formalized as a 7-tuple:

$$
A = \langle \text{id}, \text{owner}, \tau, v_{\text{default}}, \mathcal{I}, \mathbf{u}, \text{span} \rangle
$$

where the constituent fields and domains are defined as:

$$
\begin{aligned}
\text{id} &\in \Sigma^* \quad (\text{sanitized attribute identifier}) \\
\text{owner} &\in \Sigma^* \quad (\text{fully qualified owning classifier identifier}) \\
\tau &\in \mathcal{T}_{\text{type}} = \{ \text{Real}, \text{Integer}, \text{Boolean}, \text{String}, \text{ClassifierRef}(\text{id}) \} \\
v_{\text{default}} &\in \text{Domain}(\tau) \cup \{ \bot \} \\
\mathcal{I} &= \langle L, U, o_L, o_U \rangle \in \mathbb{E} \quad (\text{numerical envelope interval}) \\
\mathbf{u} &= \langle q_1, q_2, q_3, q_4, q_5, q_6, q_7 \rangle \in \mathbb{Q}^7 \quad (\text{SI base dimension exponent vector}) \\
\text{span} &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle
\end{aligned}
$$

The numerical envelope domain $`\mathbb{E}`$ defines boundary limits and boundary openness flags:

$$
L \in \mathbb{R} \cup \{ -\infty \}, \quad U \in \mathbb{R} \cup \{ +\infty \}, \quad o_L, o_U \in \{ \text{true}, \text{false} \}
$$

where $`o_L = \text{true}`$ indicates an open lower boundary ($`(L`$), $`o_L = \text{false}`$ indicates a closed lower boundary ($`[L`$), $`o_U = \text{true}`$ indicates an open upper boundary ($`U)`$), and $`o_U = \text{false}`$ indicates a closed upper boundary ($`U]`$). Unbounded intervals are represented via infinite limits with open boundary flags:

$$
L = -\infty \implies o_L = \text{true}, \quad U = +\infty \implies o_U = \text{true}
$$

The Envelope Ordering & Well-Formedness Invariant mandates:

$$
\text{ValidInterval}(\mathcal{I}) \iff (L \le U) \;\wedge\; (L = U \implies (\neg o_L \wedge \neg o_U \wedge L \in \mathbb{R}))
$$

Envelope Value Containment Predicate: for any value $`v \in \mathbb{R}`$, $`v \in \mathcal{I}`$ is evaluated by:

$$
v \in \mathcal{I} \iff 
\begin{cases}
(L \le v \le U), & \text{if } \neg o_L \wedge \neg o_U \\
(L \lt v \le U), & \text{if } o_L \wedge \neg o_U \\
(L \le v \lt U), & \text{if } \neg o_L \wedge o_U \\
(L \lt v \lt U), & \text{if } o_L \wedge o_U
\end{cases}
$$

Default Value Conformance Invariant: whenever a default value is specified ($`v_{\text{default}} \ne \bot`$), it must satisfy domain typing and interval envelope containment:

$$
v_{\text{default}} \ne \bot \implies (v_{\text{default}} \in \text{Domain}(\tau) \;\wedge\; (\tau \in \{ \text{Real}, \text{Integer} \} \implies v_{\text{default}} \in \mathcal{I}))
$$

Integer Type Boundary Invariant: when $`\tau = \text{Integer}`$, all finite bounds and default values must be elements of the integer domain:

$$
\tau = \text{Integer} \implies (L \in \mathbb{Z} \cup \{ -\infty \} \;\wedge\; U \in \mathbb{Z} \cup \{ +\infty \} \;\wedge\; (v_{\text{default}} \ne \bot \implies v_{\text{default}} \in \mathbb{Z}))
$$

Type-Envelope Compatibility Invariant: non-numerical types are prohibited from declaring restrictive numerical envelopes:

$$
\tau \in \{ \text{Boolean}, \text{String} \} \implies (\mathcal{I} = \langle -\infty, +\infty, \text{true}, \text{true} \rangle \;\wedge\; \mathbf{u} = \mathbf{0}_{\mathbb{Q}^7})
$$

Engineering Unit Dimensional Invariant: engineering unit mapping function $`\mu : \Sigma^* \to \mathbb{Q}^7 \cup \{ \bot \}`$ evaluates the unit string against the SI rational vector space:

$$
\mathbf{u} = \mu(\text{unit\_str}) \in \mathbb{Q}^7, \quad \text{where } \mathbf{u} = [d_{\text{length}}, d_{\text{mass}}, d_{\text{time}}, d_{\text{current}}, d_{\text{temp}}, d_{\text{amount}}, d_{\text{luminous}}]^{\top}
$$

Diagnostic Code Trigger Invariant: any violation of interval ordering, default containment, type compatibility, or unit synthesis deterministically triggers diagnostic `E0103`:

$$
\begin{aligned}
\neg \text{ValidInterval}(\mathcal{I}) &\implies \text{Diagnostic}(A, \text{DiagnosticCode::E0103}, \text{InvalidIntervalBounds}) \in \mathcal{D} \\
(v_{\text{default}} \ne \bot \wedge v_{\text{default}} \notin \mathcal{I}) &\implies \text{Diagnostic}(A, \text{DiagnosticCode::E0103}, \text{DefaultValueOutOfRange}) \in \mathcal{D} \\
(\tau \notin \{ \text{Real}, \text{Integer} \} \wedge \mathcal{I} \ne \mathcal{I}_{\text{unbounded}}) &\implies \text{Diagnostic}(A, \text{DiagnosticCode::E0103}, \text{EnvelopeTypeMismatch}) \in \mathcal{D} \\
\mu(\text{unit\_str}) = \bot &\implies \text{Diagnostic}(A, \text{DiagnosticCode::E0103}, \text{InvalidUnitExpression}) \in \mathcal{D}
\end{aligned}
$$

Diagnostic Taxonomy Containment Invariant: all emitted diagnostics adhere to the Subsystem 2 ingestion family established in REQ-0191:

$$
\forall D \in \mathcal{D}_{\text{attr}}, \quad \text{code}(D) = \text{DiagnosticCode::E0103} \in \mathcal{E}_{\text{ingest}}
$$

- **Computational Complexity & Algorithmic Bounds**: Tabular schema ingestion for attributes, data types, and numerical envelopes executes within Complexity Class $`\mathbf{P}`$. For an input table containing $`R`$ rows and $`C`$ columns ($`C \le C_{\text{max\_cols}} = 32`$), processing each attribute row involves: (1) extracting cell slices via precomputed column binding vector $`\vec{\beta}`$ in $`O(C) = O(1)`$ operations, (2) identifier sanitization and scope lookup in $`O(L_{\text{id}}) = O(1)`$ time for bounded identifier length $`L_{\text{id}} \le 256`$, (3) scalar data type parsing via static minimal perfect hash table in $`O(1)`$ time, (4) numeric scalar literal parsing in $`O(L_{\text{num}}) = O(1)`$ time for literal length $`L_{\text{num}} \le 64`$, (5) interval consistency validation ($`L \le U`$) in $`O(1)`$ scalar comparisons, (6) default value envelope verification ($`v_{\text{default}} \in \mathcal{I}`$) in $`O(1)`$ scalar comparisons, and (7) engineering unit parsing and exponent vector calculation in $`O(L_{\text{unit}}) = O(1)`$ operations for unit string length $`L_{\text{unit}} \le 64`$. Aggregate execution time across all $`R`$ attribute rows is strictly linear:

$$
T(R) = \sum_{i=1}^{R} O(C + L_{\text{id}} + L_{\text{num}} + L_{\text{unit}}) = O(R)
$$

Auxiliary space complexity is strictly bounded by $`O(1)`$ per row, as token slices are validated in place and parsed attributes are written directly into preallocated contiguous arena storage. The memory overhead of the diagnostic sink is bounded by $`O(C_{\text{max\_errors}}) = O(1)`$ records, preserving strict $`O(1)`$ auxiliary heap memory overhead with respect to table row count $`R`$.

- **Verification & Conformance Criteria**: Automated test suites shall verify compliance against synthetic CommonMark schema tables using abstract MBSE entity placeholders (e.g., `Package_0`, `Classifier_Alpha`, `Attribute_1`, `param_x : Real`, `param_count : Integer`, `flag_ready : Boolean`, `label_text : String`). Conformance shall be validated through the following deterministic test gates: (1) Valid Numerical Envelope Ingestion Gate: Ingest table rows defining attributes across diverse data types (`Real`, `Integer`), interval envelopes (`[0.0, 100.0]`, `(0.0, 1.0]`, `[-10, 10]`, `[0.0, +inf)`), default values, and valid SI engineering units (`"m/s"`, `"kg"`, `"s"`, `"rad/s"`); assert that all attributes synthesize bitwise-exact `IngestedAttr` structures with exact rational $`\mathbb{Q}^7`$ unit vectors and zero diagnostics. (2) Degenerate Singleton Interval Gate: Ingest an attribute with $`L = U = 10.0`$ and $`v_{\text{default}} = 10.0`$; assert that closed interval $`[10.0, 10.0]`$ succeeds, whereas open interval $`(10.0, 10.0)`$ deterministically triggers diagnostic code `E0103`. (3) Inverted Envelope Bounds Gate: Ingest a malformed row where $`L \gt U`$ (e.g., `[100.0, 50.0]`); assert that parsing fails closed for the attribute, substitutes $`\bot_{\text{attr}}`$, and emits structured diagnostic error code `E0103` (`InvalidIntervalBounds`) with exact source byte span and line/column coordinates. (4) Default Value Envelope Violation Gate: Ingest an attribute row where $`v_{\text{default}}`$ falls outside $`[L, U]`$ (e.g., default `150.0` for interval `[0.0, 100.0]`, or boundary collision on open interval default `0.0` for `(0.0, 10.0]`); assert deterministic emission of diagnostic code `E0103` (`DefaultValueOutOfRange`). (5) Type-Envelope Incompatibility Gate: Ingest a non-numeric attribute (e.g., `flag_ready : Boolean` or `label_text : String`) with a non-trivial numeric interval `[0, 1]`; assert deterministic emission of diagnostic code `E0103` (`EnvelopeTypeMismatch`). (6) Unit Syntax & Dimensional Gate: Ingest an attribute row with an unrecognized or malformed unit string (e.g., `"m^^2/s"`, `"unknown_sym"` ); assert deterministic emission of diagnostic code `E0103` (`InvalidUnitExpression`). (7) Directive 4 Synchronization Recovery Gate: Ingest a synthetic 5-row table where row 2 contains inverted bounds `[50.0, 10.0]` and row 4 contains default value `200.0` for `[0.0, 100.0]`; assert that valid rows 1, 3, and 5 parse into canonical `IngestedAttr` entities, rows 2 and 4 substitute sentinel $`\bot_{\text{attr}}`$, exactly two `E0103` diagnostic records are accumulated in the sink, and compilation proceeds without abortion. (8) Directive 5 Non-Panicking & Release Latency Gate: Execute benchmark stress tests over $`10^5`$ synthetic attribute declarations in compiled Release mode (`--release`); assert total-function execution with zero panics, processing throughput exceeding $`100{,}000`$ rows per second, execution latency under 15 ms, peak RSS memory under 20 MB, and 0-byte diff churn across consecutive compiler runs.
