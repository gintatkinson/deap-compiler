## 1. Normative Statement

Subsystem 9 SHALL perform bidirectional incremental AST patching and synchronization via `SyncEngine_Alpha` across upstream AST models and downstream projections against base AST $``T_{\text{base}}``$.

Pipeline execution MUST enforce:
1. **3-Way AST Diffing**: Given $``T_{\text{base}}``$, $``T_{\text{upstream}}``$, and $``T_{\text{downstream}}``$, `SyncEngine_Alpha` SHALL compute diffs $``\Delta_{\text{up}}``$ and $``\Delta_{\text{down}}``$ via UUIDv5 anchors. Operations `ASTDiff_0` MUST classify node insertions, deletions, and attribute updates. Dangling references emit `E0300`.
2. **Incremental Patching**: `SyncEngine_Alpha` SHALL synthesize patch `Patch_1` merging disjoint edits from $``\Delta_{\text{up}}``$ and $``\Delta_{\text{down}}``$. Applying `Patch_1` to $``T_{\text{base}}``$ MUST yield $``T_{\text{merged}} = \text{Apply}(\text{Patch}_1, T_{\text{base}})``$ preserving unmodified subtrees.
3. **Conflict Rejection**: Conflicting concurrent mutations on node $v$ ($``\text{Val}_{\text{up}}(v) \ne \text{Val}_{\text{down}}(v)``$, both modified) MUST emit `E0313`, preserve base state, and bind sentinel $``\bot_{\text{patch}}``$.
4. **Structural Validity**: Tree $``T_{\text{merged}}``$ MUST satisfy single-root, acyclic containment, and typed edge invariants. Violations emit `E0300`, record in $``\mathcal{D}_{\text{sink}}``$, and recover on delimiters (`;`, `|`, `}`).
5. **Directives**: UUIDv5 anchors (Directive 1); work-stealing pool $``N_{\text{max\_workers}}``$ (Directive 2); symbol interning (Directive 3); recovery on delimiters halting at $``C_{\text{max\_errors}}``$ with `E0199` (Directive 4); Release budget ($< 25\text{ ms}$ for $10^4$ nodes, $< 100\text{ MB}$) (Directive 5). Placeholders (`SyncEngine_Alpha`, `ASTDiff_0`, `Patch_1`, `Package_0`, `Classifier_Alpha`, `Port_1`, `param_x : Real`) used.

## 2. Formal Invariant

The 3-way synchronization, diffing operations, conflict predicates, and diagnostic mappings satisfy:

```math
\begin{aligned}
\Delta_{\text{up}}=\text{Diff}(T_{\text{base}},T_{\text{upstream}}),&\quad\Delta_{\text{down}}=\text{Diff}(T_{\text{base}},T_{\text{downstream}}) \\
\text{Conflict}(v)&\iff(v\in\text{Mod}(\Delta_{\text{up}})\cap\text{Mod}(\Delta_{\text{down}}))\land(\text{Val}_{\text{up}}(v)\ne\text{Val}_{\text{down}}(v)) \\
\text{Conflict}(v)&\implies\text{Diagnostic}(v,\text{E0313})\in\mathcal{D}_{\text{sink}}\land\text{Patch}_1(v)\gets\bot_{\text{patch}} \\
(v\in\text{Mod}(\Delta_{\text{up}})\land\neg\text{Conflict}(v))&\implies\text{Val}_{\text{merged}}(v)=\text{Val}_{\text{up}}(v) \\
(v\in\text{Mod}(\Delta_{\text{down}})\land\neg\text{Conflict}(v))&\implies\text{Val}_{\text{merged}}(v)=\text{Val}_{\text{down}}(v) \\
(\text{IsCycle}(T_{\text{merged}})\lor\text{Orphan}(v))&\implies\text{Diagnostic}(v,\text{E0300})\in\mathcal{D}_{\text{sink}}\land T_{\text{merged}}\gets\bot_{\text{patch}} \\
|\mathcal{D}_{\text{sink}}|\ge C_{\text{max\_errors}}&\implies\text{Diagnostic}(\text{E0199})\in\mathcal{D}_{\text{sink}},\quad\Delta_v=\text{UUIDv5}(\text{OID}_{\text{DEAP}},\text{FQN}(v))
\end{aligned}
```

| Symbol / Term | Domain / Formal Definition |
| :--- | :--- |
| $``T_{\text{base}}, T_{\text{upstream}}, T_{\text{downstream}}, T_{\text{merged}}``$ | Base, upstream, downstream, and merged AST instances |
| $``\Delta_{\text{up}}, \Delta_{\text{down}}, \text{Diff}, \text{Patch}_1``$ | Diffs, 3-way diff operator, and unified patch |
| $\text{Mod}(\Delta), \text{Val}(v), \text{Conflict}(v)$ | Modified vertex set, attribute value, and conflict predicate |
| $``\bot_{\text{patch}}, \mathcal{D}_{\text{sink}}, C_{\text{max\_errors}}``$ | Fault sentinel, diagnostic sink, and error limit |
| $``\Delta_v, \text{OID}_{\text{DEAP}}, \text{FQN}(v)``$ | UUIDv5 anchor, namespace OID, and topological path |

## 3. Computational Complexity & Algorithmic Bounds

- **Complexity Class:** Class $\mathbf{P}$.
- **Asymptotic Bound:** $O(|V|)$ 3-way AST diff and patch ($``|V| = |V_{\text{base}}| + |V_{\text{upstream}}| + |V_{\text{downstream}}|``$). Traversal and UUIDv5 diffing run in $O(|V|)$ time. Work-stealing scales as $``O(|V| / N_{\text{max\_workers}} + \log N_{\text{max\_workers}})``$. Arena memory scales as $O(|V|)$.
- **Tractable Subclass and Frontier:** N/A (Deterministic P). Fixed-anchor alignment avoids NP-hard subtree isomorphism and NP-8 SMT solving (REQ-0197).

## 4. Verification & Conformance Criteria (IEEE 29148 Acceptance Criteria)

### AC-01: 3-Way AST Diff and Non-Conflicting Patch Application
- **Given:** Base $``T_{\text{base}}``$ with upstream addition of `Classifier_Alpha` in `Package_0` and downstream update of `param_x : Real` on `Port_1`.
- **When:** `SyncEngine_Alpha` computes diff `ASTDiff_0` and applies patch `Patch_1`.
- **Then:** Reconciles edits into $``T_{\text{merged}}``$ preserving all modifications.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-02: Idempotent Patch Re-Application Boundary
- **Given:** Synchronized tree $``T_{\text{merged}}``$ with base $``T_{\text{base}} = T_{\text{merged}}``$.
- **When:** `SyncEngine_Alpha` computes diff across identical trees.
- **Then:** Generates empty diff $\Delta = \emptyset$ with 0-byte state churn.
- **Diagnostic:** Diagnostic sink remains empty.

### AC-03: Concurrent Conflicting Modification Rejection
- **Given:** Base node `Classifier_Alpha` where upstream sets `param_x = 10.0` and downstream sets `param_x = 20.0`.
- **When:** `SyncEngine_Alpha` evaluates 3-way merge rules.
- **Then:** Fails closed, emits `E0313`, and binds sentinel $``\bot_{\text{patch}}``$.
- **Diagnostic:** `E0313` (SynchronizationConflictViolation).

### AC-04: Structural Cycle Violation and Delimiter Recovery
- **Given:** Patch with cycle in `Package_0`, delimiter `;`, and valid `Port_1`.
- **When:** Structural validation detects cycle and recovers across `;`.
- **Then:** Emits `E0300`, binds sentinel $``\bot_{\text{patch}}``$, resumes on `Port_1`, halting at $``C_{\text{max\_errors}}``$ with `E0199`.
- **Diagnostic:** `E0300`, `E0199`.

### AC-05: UUIDv5 Determinism and Release Performance Bounds
- **Given:** AST with $|V| = 10^4$ nodes on $``N_{\text{max\_workers}}``$ threads.
- **When:** Diffing and patching in Release mode (`--release`).
- **Then:** Emits bitwise identical UUIDv5 anchors; latency $< 25\text{ ms}$, RSS $< 100\text{ MB}$.
- **Diagnostic:** Diagnostic sink remains empty.
