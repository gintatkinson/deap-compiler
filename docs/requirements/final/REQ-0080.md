### REQ-0080: SysML v2 TransitionUsage (`transition`) with Triggers, Guards & Effects

- **Normative Statement**: The statechart compiler and behavioral lowering engine of Subsystem 4 shall formalize `transition` usages (`TransitionUsage`) as discrete, directed, event-triggered behavioral edges between source and target state configurations within hierarchical and orthogonal state machine classifiers (`StateDefinition` and `StateUsage`), specializing KerML `ActionUsage` and `Step`.

  The lowering engine must statically verify and enforce the following core structural and behavioral invariants for every transition usage:
  1. **Endpoint Resolution and Multiplicity**: Every transition usage must declare one or more valid source state vertices and one or more valid target state vertices. For simple transitions, source and target cardinalities shall equal one ($`|\mathcal{S}_{\text{src}}| = 1`$ and $`|\mathcal{S}_{\text{tgt}}| = 1`$). If any referenced source or target vertex fails to resolve to a valid state usage, pseudostate, or entry/exit point within the lexical or behavioral scope, the compiler shall reject the declaration and emit structured diagnostic error code `E0200` per REQ-0191.
  2. **Orthogonal Fork and Join Synchronization**:
     - *Fork Transitions*: A fork transition shall transition control from one or more source states into two or more target states ($`k \ge 2`$) that reside in distinct, pairwise orthogonal regions of a composite parallel state. If any two target states belong to the same orthogonal region, or if target regions fail to share a common parallel state ancestor, the compiler shall emit structured diagnostic error code `E0200`.
     - *Join Transitions*: A join transition shall synchronize control from two or more source states ($`m \ge 2`$) residing in distinct, pairwise orthogonal regions into one or more target states. If any two source states belong to the same orthogonal region, or if source regions fail to share a common parallel state ancestor, the compiler shall emit structured diagnostic error code `E0200`.
  3. **Trigger Event Typing and Binding**: A transition usage may bind zero or more trigger declarations ($`e_{\text{trigger}}`$) modeling signal reception, change conditions, or temporal elapse. Trigger event types must specialize KerML `EventOccurrence` or standard library event classifiers. Declarations specifying incompatible event payload signatures or non-event classifiers shall be rejected with structured diagnostic error code `E0201` per REQ-0191. Transitions without an explicit trigger shall be treated as completion transitions triggered automatically upon termination of all internal behaviors and child state activities within the source state.
  4. **Guard Constraint Expression Typing**: A transition usage may specify an optional guard expression ($`g_{\text{guard}}`$). The guard expression must statically evaluate to a scalar `Boolean` type within the semantic evaluation environment ($`\tau(g_{\text{guard}}) \equiv \text{Boolean}`$). Guard expressions evaluating to non-boolean types or producing ambiguous type constraints shall be rejected with structured diagnostic error code `E0202` per REQ-0191.
  5. **Inner-First Conflict Precedence**: When two or more enabled transitions conflict (such that firing one transition exits states required by or overlapping with the other), precedence shall be strictly resolved by inner-first source state depth. The transition originating from the deeper source state in the statechart containment hierarchy shall take absolute priority over ancestor transitions ($`\text{Priority}(t_1) \gt \text{Priority}(t_2) \iff \text{Depth}(t_1.s_{\text{src}}) \gt \text{Depth}(t_2.s_{\text{src}})`$).
  6. **Deterministic Guard Disjointness at Equal Hierarchy Depth**: If two or more conflicting transitions originate from the same state node ($`\text{Depth}(t_1.s_{\text{src}}) = \text{Depth}(t_2.s_{\text{src}})`$) and share identical trigger events, their guard predicates must be statically disjoint ($`\forall \sigma \in \Sigma, \; \neg(g_1(\sigma) \wedge g_2(\sigma))`$). The lowering engine shall detect overlapping, non-disjoint guard predicates across sibling transitions and emit structured diagnostic error code `E0200`.
  7. **Instant Triggerless Cycle Detection**: Directed paths composed exclusively of triggerless, guardless transitions that form a closed cycle without intervening state residence or external event consumption shall be detected via topological cycle analysis and rejected with structured diagnostic error code `E0203` per REQ-0191.
  8. **Atomic Run-to-Completion Execution Ordering**: Firing a validated transition $`t`$ between source $`s_{\text{src}}`$ and target $`s_{\text{tgt}}`$ with Least Common Ancestor $`s_{\text{LCA}} = \text{LCA}(s_{\text{src}}, s_{\text{tgt}})`$ shall strictly execute the following deterministic three-phase sequence:
     - *Phase 1 (Exit)*: Exit active states along the upward hierarchy path from $`s_{\text{src}}`$ up to (but excluding) $`s_{\text{LCA}}`$ in innermost-first (child before parent) order, invoking each state's exit action hook.
     - *Phase 2 (Effect)*: Execute the transition effect action $`a_{\text{effect}}`$ atomically.
     - *Phase 3 (Enter)*: Enter target states along the downward hierarchy path from $`s_{\text{LCA}}`$ down to $`s_{\text{tgt}}`$ in outermost-first (parent before child) order, invoking each state's entry action hook and initializing default substates.

  In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, the engine shall implement synchronization token error recovery: upon recording any diagnostic (`E0200`, `E0201`, `E0202`, or `E0203`) into the preallocated diagnostic sink buffer $`\mathcal{D}_{\text{sink}}`$, the engine shall assign an error sentinel node $`\bot_{\text{transition}}`$ to malformed transition elements and continue evaluating subsequent transitions and states up to the error threshold $`C_{\text{max\_errors}}`$. If accumulated diagnostics reach $`C_{\text{max\_errors}}`$, the compiler shall emit terminal diagnostic `E0199` and halt gracefully.

  All transition definitions, trigger bindings, guard expressions, and effect actions shall be allocated sequentially into contiguous typed bump arena storage in accordance with REQ-0009, REQ-0034, and REQ-0035, addressed exclusively via stable 32-bit typed node handles. In accordance with Architectural Directive 1 and REQ-0010, every lowered transition AST node must receive an immutable, deterministic RFC 4122 UUIDv5 identifier derived from the compiler namespace OID and the fully qualified symbol path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(t))`$). In accordance with Architectural Directive 3 and REQ-0036, scalar identifier tokens for transition names, state handles, and event triggers shall be interned into the global deduplicated symbol interner pool. Parallel verification of independent state machines across separate compilation units shall be scheduled strictly onto a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with Architectural Directive 2 and REQ-0012. In accordance with Architectural Directive 5, REQ-0011, and REQ-0196, the engine shall enforce a deterministic, non-panicking execution contract with total-function termination across all inputs, evaluating performance gates (execution latency strictly below 25 ms, peak RSS memory strictly below 100 MB) exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests. All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `StateMachine_Alpha`, `State_Root`, `State_A`, `State_B`, `State_Composite`, `State_Sub_1`, `State_Sub_2`, `Region_1`, `Region_2`, `Transition_1`, `Transition_2`, `Event_0`, `Event_1`, `param_x : Real`) with zero hardcoded domain concepts.

- **Formal Invariant**: Let $`\mathcal{T}_{\text{metamodel}}`$ denote the KerML classifier specialization poset ordered by subtyping relation $`\le_{\text{sub}}`$. The taxonomic specialization of `TransitionUsage` satisfies:

$$
\text{TransitionUsage} \le_{\text{sub}} \text{ActionUsage} \le_{\text{sub}} \text{Step} \le_{\text{sub}} \text{OccurrenceUsage}
$$

Let $`\mathcal{S}_{\text{states}}`$ denote the finite set of state vertices within enclosing state machine $`M`$, and let $`\mathcal{T}_{\text{transitions}}`$ denote the set of lowered transition usages. Each transition usage $`t \in \mathcal{T}_{\text{transitions}}`$ is formalized as a 9-tuple:

$$
t = \langle \text{id}_t, \mathcal{S}_{\text{src}}(t), \mathcal{S}_{\text{tgt}}(t), e_{\text{trigger}}(t), g_{\text{guard}}(t), a_{\text{effect}}(t), \kappa(t), \Delta_t, \text{span}_t \rangle
$$

where:

$$
\begin{aligned}
\text{id}_t &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
\mathcal{S}_{\text{src}}(t) &\subseteq \mathcal{S}_{\text{states}} \setminus \emptyset \quad (\text{finite set of source state vertices}) \\
\mathcal{S}_{\text{tgt}}(t) &\subseteq \mathcal{S}_{\text{states}} \setminus \emptyset \quad (\text{finite set of target state vertices}) \\
e_{\text{trigger}}(t) &\in \mathcal{E}_{\text{event}} \cup \{ \epsilon \} \quad (\text{event trigger or completion trigger } \epsilon) \\
g_{\text{guard}}(t) &\in \mathcal{G}_{\text{expr}} \quad (\text{Boolean guard expression predicate}) \\
a_{\text{effect}}(t) &\in \mathcal{A}_{\text{action}} \cup \{ \emptyset \} \quad (\text{optional effect action usage}) \\
\kappa(t) &\in \{ \text{External}, \text{Internal}, \text{Local} \} \quad (\text{transition semantics kind}) \\
\Delta_t &\in \Sigma^* \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_t &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
\end{aligned}
$$

The hierarchical state structure forms a rooted tree $`(\mathcal{S}_{\text{states}}, \sqsubseteq)`$ with strict ancestor relation $`\sqsubset`$, where $`s_1 \sqsubset s_2`$ denotes that $`s_1`$ is a descendant substate of composite state $`s_2`$. The tree depth function $`\text{Depth} : \mathcal{S}_{\text{states}} \to \mathbb{N}_0`$ is inductively defined:

$$
\text{Depth}(s) = \begin{cases}
0 & \text{if } s = s_{\text{root}} \\
\text{Depth}(\text{parent}(s)) + 1 & \text{otherwise}
\end{cases}
$$

For any subset of state vertices $`S \subseteq \mathcal{S}_{\text{states}}`$, the Least Common Ancestor $`\text{LCA}(S) \in \mathcal{S}_{\text{states}}`$ is the unique minimal state satisfying:

$$
\text{LCA}(S) = \sup_{\sqsubseteq} \{ u \in \mathcal{S}_{\text{states}} \mid \forall s \in S, \; s \sqsubseteq u \}
$$

The exit set $`\text{ExitSet}(t)`$ and entry set $`\text{EnterSet}(t)`$ for transition $`t`$ with $`s_{\text{LCA}} = \text{LCA}(\mathcal{S}_{\text{src}}(t) \cup \mathcal{S}_{\text{tgt}}(t))`$ are defined as:

$$
\begin{aligned}
\text{ExitSet}(t) &= \{ s \in \mathcal{S}_{\text{states}} \mid \exists u \in \mathcal{S}_{\text{src}}(t) : u \sqsubseteq s \;\wedge\; s \sqsubset s_{\text{LCA}} \} \\
\text{EnterSet}(t) &= \{ s \in \mathcal{S}_{\text{states}} \mid \exists v \in \mathcal{S}_{\text{tgt}}(t) : v \sqsubseteq s \;\wedge\; s \sqsubset s_{\text{LCA}} \}
\end{aligned}
$$

Given active state configuration $`C \subseteq \mathcal{S}_{\text{states}}`$, dispatched event $`e \in \mathcal{E}_{\text{event}}`$, and machine data state $`\sigma \in \Sigma`$, transition enabledness is formalized as:

$$
\text{Enabled}(t, C, e, \sigma) \iff (\mathcal{S}_{\text{src}}(t) \subseteq C) \;\wedge\; (e_{\text{trigger}}(t) \approx e) \;\wedge\; (g_{\text{guard}}(t)(\sigma) = \text{true})
$$

where $`e_{\text{trigger}}(t) \approx e`$ denotes event match ($`e_{\text{trigger}}(t) = e`$ or $`e_{\text{trigger}}(t) = \epsilon`$).

Two simultaneously enabled transitions $`t_1, t_2 \in \mathcal{T}_{\text{transitions}}`$ conflict if their exit state sets intersect:

$$
\text{Conflicting}(t_1, t_2) \iff \text{ExitSet}(t_1) \cap \text{ExitSet}(t_2) \ne \emptyset
$$

Conflict Precedence Invariant (Inner-First Depth Priority): For any two simultaneously enabled conflicting transitions $`t_1, t_2`$, priority is strictly determined by maximal source state hierarchy depth:

$$
\begin{aligned}
\text{Enabled}(t_1, C, e, \sigma) \wedge \text{Enabled}(t_2, C, e, \sigma) \wedge \text{Conflicting}(t_1, t_2) &\implies \\
\text{Priority}(t_1) \gt \text{Priority}(t_2) &\iff \max_{s \in \mathcal{S}_{\text{src}}(t_1)} \text{Depth}(s) \gt \max_{s \in \mathcal{S}_{\text{src}}(t_2)} \text{Depth}(s)
\end{aligned}
$$

Deterministic Guard Disjointness Invariant: Sibling transitions sharing identical source states and trigger events must have mutually unsatisfiable guard predicates:

$$
\begin{aligned}
\forall t_1, t_2 \in \mathcal{T}_{\text{transitions}}, \quad (&t_1 \ne t_2 \;\wedge\; \mathcal{S}_{\text{src}}(t_1) = \mathcal{S}_{\text{src}}(t_2) \;\wedge\; e_{\text{trigger}}(t_1) = e_{\text{trigger}}(t_2)) \implies \\
&\forall \sigma \in \Sigma, \quad \neg(g_{\text{guard}}(t_1)(\sigma) \wedge g_{\text{guard}}(t_2)(\sigma))
\end{aligned}
$$

Orthogonal Fork Transition Invariant: For any fork transition $`t_{\text{fork}}`$ where $`|\mathcal{S}_{\text{tgt}}(t_{\text{fork}})| = k \ge 2`$:

$$
\begin{aligned}
\exists s_{\text{par}} \in \mathcal{S}_{\text{states}} &\text{ with orthogonal regions } \mathcal{R} = \{ R_1, R_2, \dots, R_k \} \text{ such that:} \\
&\forall i \in \{ 1, \dots, k \}, \quad \exists ! v \in \mathcal{S}_{\text{tgt}}(t_{\text{fork}}) : v \sqsubseteq R_i \;\wedge\; (\forall i \ne j, \; R_i \cap R_j = \emptyset)
\end{aligned}
$$

Orthogonal Join Transition Invariant: For any join transition $`t_{\text{join}}`$ where $`|\mathcal{S}_{\text{src}}(t_{\text{join}})| = m \ge 2`$:

$$
\begin{aligned}
\exists s_{\text{par}} \in \mathcal{S}_{\text{states}} &\text{ with orthogonal regions } \mathcal{R} = \{ R_1, R_2, \dots, R_m \} \text{ such that:} \\
&\forall i \in \{ 1, \dots, m \}, \quad \exists ! u \in \mathcal{S}_{\text{src}}(t_{\text{join}}) : u \sqsubseteq R_i \;\wedge\; (\forall i \ne j, \; R_i \cap R_j = \emptyset)
\end{aligned}
$$

Run-to-Completion Step Sequencing Invariant: Firing transition $`t`$ transitions active configuration from $`C`$ to $`C'`$ through three strictly ordered, non-overlapping occurrence intervals:

$$
\begin{aligned}
\tau_{\text{start}}(\text{ExitPhase}(t)) &\le \tau_{\text{end}}(\text{ExitPhase}(t)) \\
&\le \tau_{\text{start}}(a_{\text{effect}}(t)) \le \tau_{\text{end}}(a_{\text{effect}}(t)) \\
&\le \tau_{\text{start}}(\text{EnterPhase}(t)) \le \tau_{\text{end}}(\text{EnterPhase}(t))
\end{aligned}
$$

with configuration transformation:

$$
C' = (C \setminus \text{ExitSet}(t)) \cup \text{EnterSet}(t)
$$

Topological Acyclicity of Triggerless Transitions: Let $`G_{\epsilon} = (\mathcal{S}_{\text{states}}, \mathcal{T}_{\epsilon})`$ denote the directed graph of triggerless, guardless transitions where $`\mathcal{T}_{\epsilon} = \{ t \in \mathcal{T}_{\text{transitions}} \mid e_{\text{trigger}}(t) = \epsilon \;\wedge\; g_{\text{guard}}(t) \equiv \text{true} \}`$. Graph $`G_{\epsilon}`$ must be strictly acyclic:

$$
\forall s \in \mathcal{S}_{\text{states}}, \quad (s, s) \notin \mathcal{T}_{\epsilon}^+
$$

Deterministic RFC 4122 UUIDv5 Topological Anchor (Architectural Directive 1):

$$
\forall t \in \mathcal{T}_{\text{transitions}}, \quad \Delta_t = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(t))
$$

Diagnostic Code Trigger Invariant: Compiler diagnostic codes are deterministically emitted in accordance with REQ-0191:

$$
\begin{aligned}
(\exists u \in \mathcal{S}_{\text{src}}(t) \cup \mathcal{S}_{\text{tgt}}(t) : u \notin \mathcal{S}_{\text{states}}) &\implies \text{Diagnostic}(t, \text{DiagnosticCode::E0200}, \text{InvalidStateVertex}) \in \mathcal{D}_{\text{sink}} \\
(|\mathcal{S}_{\text{tgt}}(t)| \ge 2 \;\wedge\; \neg\text{IsOrthogonalFork}(t)) &\implies \text{Diagnostic}(t, \text{DiagnosticCode::E0200}, \text{InvalidForkOrthogonality}) \in \mathcal{D}_{\text{sink}} \\
(|\mathcal{S}_{\text{src}}(t)| \ge 2 \;\wedge\; \neg\text{IsOrthogonalJoin}(t)) &\implies \text{Diagnostic}(t, \text{DiagnosticCode::E0200}, \text{InvalidJoinOrthogonality}) \in \mathcal{D}_{\text{sink}} \\
(\text{Conflicting}(t_1, t_2) \wedge \text{EqualDepth}(t_1, t_2) \wedge \text{SAT}(g_1 \wedge g_2)) &\implies \text{Diagnostic}(t_1, \text{DiagnosticCode::E0200}, \text{AmbiguousTransitionConflict}) \in \mathcal{D}_{\text{sink}} \\
(e_{\text{trigger}}(t) \ne \epsilon \;\wedge\; \tau(e_{\text{trigger}}(t)) \not\le_{\text{sub}} \text{EventOccurrence}) &\implies \text{Diagnostic}(t, \text{DiagnosticCode::E0201}, \text{InvalidTriggerType}) \in \mathcal{D}_{\text{sink}} \\
\tau(g_{\text{guard}}(t)) \not\equiv \text{Boolean} &\implies \text{Diagnostic}(t, \text{DiagnosticCode::E0202}, \text{InvalidGuardType}) \in \mathcal{D}_{\text{sink}} \\
\exists s \in \mathcal{S}_{\text{states}} : (s, s) \in \mathcal{T}_{\epsilon}^+ &\implies \text{Diagnostic}(t, \text{DiagnosticCode::E0203}, \text{InstantTransitionCycle}) \in \mathcal{D}_{\text{sink}} \\
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
\end{aligned}
$$

- **Computational Complexity & Algorithmic Bounds**: Verification, conflict analysis, and lowering of transition usages execute strictly within Complexity Class $`\mathbf{P}`$. For a statechart model containing $`V = |\mathcal{S}_{\text{states}}|`$ state vertices and $`E = |\mathcal{T}_{\text{transitions}}|`$ transition usages, asymptotic bounds are established as follows:
  1. *Hierarchy Depth & Ancestor Bitset Construction*: Precomputing state depths $`\text{Depth}(s)`$ and ancestor bitset tables over tree depth $`h \le \text{Depth}_{\max} \le 32`$ executes via a single depth-first traversal of the state tree in deterministic $`O(V)`$ time.
  2. *Least Common Ancestor (LCA) Queries*: Using precomputed ancestor depth vectors, querying $`\text{LCA}(s_1, s_2)`$ executes in strictly $`O(h)`$ deterministic scalar lookups per pair. For bounded depth $`h \le 32`$, this evaluates in $`O(1)`$ constant time. For a transition $`t`$, evaluating $`s_{\text{LCA}} = \text{LCA}(\mathcal{S}_{\text{src}}(t) \cup \mathcal{S}_{\text{tgt}}(t))`$ executes in $`O((|\mathcal{S}_{\text{src}}(t)| + |\mathcal{S}_{\text{tgt}}(t)|) \cdot h)`$ time.
  3. *Conflict Resolution & Precedence Sorting*: Comparing conflict priorities between enabled transitions relies on scalar integer comparison of precomputed source state depths ($`\text{Depth}(t.s_{\text{src}})`$), executing in strictly $`O(1)`$ time per comparison. Sorting $`k`$ enabled candidate transitions executes in $`O(k \log k)`$ time, where $`k \ll E`$.
  4. *Orthogonal Region Validation for Fork and Join*: Verifying that fork target states or join source states reside in mutually disjoint orthogonal regions of a common parallel parent executes in $`O(k \cdot h)`$ time, where $`k`$ is the fork/join degree ($`k \ll V`$).
  5. *Triggerless Cycle Detection*: Cycle detection over the triggerless transition subgraph $`G_{\epsilon} = (\mathcal{S}_{\text{states}}, \mathcal{T}_{\epsilon})`$ using Tarjan's strongly connected components algorithm executes in deterministic $`O(V + |\mathcal{T}_{\epsilon}|) \subseteq O(V + E)`$ time.
  6. *Total Sequential Lowering Complexity*: Combining all structural checks, type verifications, LCA path computations, and cycle detections, total sequential compilation time is strictly linear in the size of the state machine graph:

$$
T_{\text{validate}}(V, E) \in O(V + E \cdot h) \subseteq O(V + E) \quad (\text{for bounded hierarchy depth } h \le 32)
$$

  7. *Parallel Work-Stealing Scaling (Architectural Directive 2)*: When independent statechart classifiers across separate compilation packages are validated concurrently on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$:

$$
T_{\text{parallel}}(V, E, N_{\text{max\_workers}}) \in O\left( \frac{V + E}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  8. *Space Complexity & Memory Bounds*: Auxiliary working memory for depth tables, ancestor bitsets, and LCA query structures is bounded by $`O(V \cdot \lceil h / 64 \rceil) = O(V)`$ words. Arena allocations for transition AST nodes and exit/enter sequence vectors require $`O(V + E)`$ contiguous bytes. Traversal call stacks are bounded by recursion depth $`O(h) \le 32`$ frames ($`O(1)`$ stack allocation). The diagnostic sink buffer is bounded by $`O(C_{\text{max\_errors}}) = O(1)`$ allocated memory.
