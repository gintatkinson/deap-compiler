### REQ-0118: Directed Causal Precedence DAG Construction & Cycle Detection

- **Normative Statement**: The spatio-temporal dynamics solver and discrete state machine verification engine of Subsystem 6 shall construct an explicit directed causal precedence graph $`G_{\text{prec}} = (V, E)`$ across all action executions (performances), behavioral steps, and discrete state transitions declared in the compiled system model, asserting strict acyclicity to guarantee deadlock-free, causally sound execution sequences.

  Specifically, the dynamics solver and AST graph verification engine shall enforce the following normative semantics, graph construction rules, and cycle rejection invariants:
  1. **Directed Causal Precedence Graph Model**:
     - The solver shall construct $`G_{\text{prec}} = (V, E)`$ where the vertex set $`V`$ represents causal behavioral entities, including action executions, sub-step performances, discrete state transitions, and event occurrences.
     - Directed edges $`(u, v) \in E`$ represent immediate causal precedence relations ($`u \prec v`$), signifying that the execution or completion of entity $`u`$ is a strict prerequisite for the activation, initiation, or transition firing of entity $`v`$.
     - Vertices and edges in $`G_{\text{prec}}`$ shall be extracted deterministically from five primary model semantics:
       * *Explicit Sequential Control Flows*: Sequential composition constructs (`first A then B`, step sequences, semicolon chaining) generate directed edges $`(A, B) \in E_{\text{seq}}`$ with causal precedence $`A \prec B`$.
       * *Data, Item, and Token Flow Dependencies*: When action $`v`$ consumes a data token, item payload, or parameter produced by action $`u`$ ($`u.\text{out\_port} \to v.\text{in\_port}`$ with mandatory availability dependency), a directed edge $`(u, v) \in E_{\text{flow}}`$ shall be established.
       * *State Transition Sequences*: In discrete statecharts, the entry transition $`\tau_{\text{in}}`$ into a state $`S`$, the internal activity or state occupancy of $`S`$, and the subsequent outgoing transition $`\tau_{\text{out}}`$ shall establish the directed causal chain $`(\tau_{\text{in}}, S) \in E_{\text{state}}`$ and $`(S, \tau_{\text{out}}) \in E_{\text{state}}`$.
       * *Event Signaling and Asynchronous Trigger Dependencies*: When an action or state transition emits an asynchronous trigger event $`e`$ that enables or activates a downstream transition $`\tau_{\text{trig}}`$, a directed edge shall be instantiated from the emitter to the triggered transition.
       * *Qualitative Temporal Interval Constraints*: Explicit Allen temporal relations asserting precedence, including `before` ($`I(u) \mathbf{b} I(v)`$) and `meets` ($`I(u) \mathbf{m} I(v)`$), shall map directly into directed causal edges $`(u, v) \in E_{\text{temp}}`$.
  2. **Strict Acyclicity & Deadlock Prevention Invariant**:
     - The causal precedence graph must be a strict directed acyclic graph (DAG).
     - Any directed cycle $`\langle v_1, v_2, \dots, v_k, v_1 \rangle`$ in $`G_{\text{prec}}`$ represents an unresolvable causal circular wait condition (deadlock), wherein each entity in the cycle cannot initiate without requiring its own prior execution.
     - The compiler shall verify that no vertex in $`V`$ is causally reachable from itself:

$$
\forall v \in V, \quad v \notin \text{Reach}(v, G_{\text{prec}})
$$

     - Direct self-precedence ($`v \prec v`$) and indirect multi-step circular causal dependencies ($`v_1 \prec v_2 \prec \dots \prec v_k \prec v_1`$) of arbitrary length shall be deterministically detected and rejected at compile time.
  3. **Tarjan Strongly Connected Component (SCC) Cycle Detection & Traceback**:
     - The dynamics solver shall implement Tarjan's linear-time depth-first search algorithm to decompose $`G_{\text{prec}}`$ into maximal strongly connected components $`\mathcal{C} = \{ C_1, C_2, \dots, C_p \}`$.
     - A directed graph is acyclic if and only if every strongly connected component is a trivial singleton ($`|C| = 1`$) containing zero self-loops.
     - For every non-trivial component ($`|C| \gt 1`$ or containing a reflexive self-loop $`(v, v) \in E`$), the solver shall isolate the cyclic subgraph, reconstruct an exact elementary circular traceback path $`\mathcal{P}_{\text{cycle}} = \langle v_1, v_2, \dots, v_k, v_1 \rangle`$, and emit structured diagnostic error code `E0400` (`CausalPrecedenceCycleDetected`).
     - The emitted diagnostic record must include the participating entity identifiers, exact source byte spans, line/column coordinates, and the ordered circular traceback sequence.
  4. **Temporal Interval Bounds Consistency with Precedence**:
     - For every directed causal precedence edge $`(u, v) \in E`$, the dynamics solver shall verify temporal interval consistency against the interval bounds $`[t_{\text{start}}, t_{\text{end}}]`$ assigned per REQ-0114:

$$
t_{\text{start}}(u) \le t_{\text{start}}(v)
$$

     - For sequential action step executions where $`u`$ must complete before $`v`$ begins ($`(u, v) \in E_{\text{seq}}`$):

$$
t_{\text{end}}(u) \le t_{\text{start}}(v)
$$

     - Any causal precedence declaration where the assigned temporal intervals contradict causality ($`t_{\text{start}}(v) \lt t_{\text{start}}(u)`$ or $`t_{\text{start}}(v) \lt t_{\text{end}}(u)`$ under strict sequential semantics) shall be deterministically rejected at compile time with diagnostic error code `E0400` (`CausalTemporalOrderingConflict`).
  5. **Deterministic Topological Linearization (Kahn's Algorithm)**:
     - When $`G_{\text{prec}}`$ is verified acyclic, the solver shall execute Kahn's algorithm with dynamic in-degree reduction to synthesize an authoritative linear execution schedule $`\mathcal{L} = \langle v_1, v_2, \dots, v_n \rangle`$ satisfying:

$$
\forall (u, v) \in E, \quad \text{Index}(u, \mathcal{L}) \lt \text{Index}(v, \mathcal{L})
$$

     - When multiple candidate vertices simultaneously possess an in-degree of zero in the ready set $`Q`$, the engine must dequeue vertices strictly in ascending lexicographical byte order of their interned fully qualified names ($`\arg\min_{v \in Q} \text{QualifiedName}(v)`$). Non-deterministic hash iteration, insertion-order arbitrary scheduling, or pointer-based sorting are strictly prohibited, ensuring bitwise determinism and zero diff churn per REQ-0003.
  6. **Compliance with the 5 Executive Architectural Directives**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every causal vertex node and causal precedence edge in $`G_{\text{prec}}`$ shall receive an immutable deterministic RFC 4122 UUIDv5 identifier derived from the canonical compiler namespace OID and the node fully qualified topological path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))`$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel construction of causal precedence graphs, SCC cycle audits, and topological linearization across independent action packages or orthogonal state regions shall execute strictly on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Memory Allocation Exception)*: Action names, transition labels, state symbols, and fully qualified paths shall be interned into the deduplicated global symbol interner pool during lexical ingestion per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The dynamics solver shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When causal cycles or temporal contradictions are detected (`E0400`), diagnostics shall accumulate in the error sink buffer $`\mathcal{D}_{\text{sink}}`$, substitute typed error sentinels ($`\bot_{\text{prec}}`$), sever the closing cycle edge in an overlay graph, and continue validating subsequent independent behavioral actions and statecharts. If accumulated diagnostics reach $`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully in accordance with REQ-0013 and REQ-0016.
     - *Directive 5 (Panic-Free Release Isolation)*: The causal precedence analysis pipeline shall strictly enforce a deterministic, non-panicking execution contract with total-function termination across all inputs, including cyclic, disconnected, or malformed graphs. Verification latency ($`\lt 25\text{ ms}`$ for $`10^4`$ actions and edges) and peak RSS memory ($`\lt 100\text{ MB}`$) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Action_1`, `Action_2`, `Action_3`, `Action_4`, `State_1`, `State_2`, `Transition_1`, `Transition_2`, `Precedence_0`, `Port_1`, `Flow_A`, `param_x : Real`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $`\mathcal{V}_{\text{AST}} \subset \mathbb{N}_{32}`$ denote the universe of allocated AST entity handles in contiguous bump arena storage. The directed causal precedence graph $`G_{\text{prec}}`$ is formalized as:

$$
  G_{\text{prec}} = (V, E), \quad V \subset \mathcal{V}_{\text{AST}}, \quad E \subseteq V \times V \times \mathcal{K}_{\text{causal}}
$$

  where the causal edge classification set $`\mathcal{K}_{\text{causal}}`$ partitions $`E`$:

$$
  \mathcal{K}_{\text{causal}} = \{ \text{Sequential}, \text{DataFlow}, \text{StateTransition}, \text{EventTrigger}, \text{TemporalConstraint} \}
$$

$$
  E = E_{\text{seq}} \cup E_{\text{flow}} \cup E_{\text{state}} \cup E_{\text{trig}} \cup E_{\text{temp}}
$$

  Each causal vertex $`v \in V`$ is represented by a structured tuple:

$$
  v = \langle \text{id}_v, \text{name}_v, \kappa_v, I(v), \Delta_v, \text{span}_v \rangle
$$

  where:

$$
  \begin{aligned}
  \text{id}_v &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
  \text{name}_v &\in \mathcal{S}_{\text{intern}} \quad (\text{interned scalar symbol identifier}) \\
  \kappa_v &\in \{ \text{Kind::Action}, \text{Kind::Step}, \text{Kind::Transition}, \text{Kind::Event} \} \quad (\text{causal entity kind}) \\
  I(v) &= [t_{\text{start}}(v), t_{\text{end}}(v)] \subset \mathbb{R} \cup \{ -\infty, +\infty \} \quad (\text{temporal interval bounds per REQ-0114}) \\
  \Delta_v &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
  \text{span}_v &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
  \end{aligned}
$$

  Immediate Causal Precedence & Transitive Reachability:

$$
  u \prec v \iff \exists k \in \mathcal{K}_{\text{causal}} : (u, v, k) \in E
$$

$$
  u \prec^+ v \iff \exists \langle w_0, w_1, \dots, w_m \rangle, \; m \ge 1, \; w_0 = u, \; w_m = v, \; \forall i \in \{0, \dots, m-1\}, \, w_i \prec w_{i+1}
$$

$$
  \text{Reach}(v, G_{\text{prec}}) = \{ u \in V \mid v \prec^+ u \}
$$

  Fundamental Acyclicity & Deadlock-Free Invariant:

$$
  \text{Acyclic}(G_{\text{prec}}) \iff \forall v \in V, \quad v \notin \text{Reach}(v, G_{\text{prec}}) \iff \forall v \in V, \quad \neg(v \prec^+ v)
$$

  Strongly Connected Components Decomposition:
  Let $`\sim_{\text{SCC}}`$ denote the mutual reachability equivalence relation over $`V`$:

$$
  u \sim_{\text{SCC}} v \iff (u \prec^* v) \wedge (v \prec^* u)
$$

  The quotient set $`\text{TarjanSCC}(G_{\text{prec}}) = \{ C_1, C_2, \dots, C_p \}`$ partitions $`V`$ into disjoint maximal strongly connected components:

$$
  \bigcup_{i=1}^p C_i = V, \quad \forall i \ne j, \, C_i \cap C_j = \emptyset
$$

  Tarjan SCC Acyclicity Condition:

$$
  \text{Acyclic}(G_{\text{prec}}) \iff \forall C \in \text{TarjanSCC}(G_{\text{prec}}), \quad (|C| = 1 \wedge \forall v \in C, \, (v, v) \notin E)
$$

$$
  \text{HasCycle}(G_{\text{prec}}) \iff \exists C \in \text{TarjanSCC}(G_{\text{prec}}) : (|C| \gt 1) \vee (\exists v \in C : (v, v) \in E)
$$

  Tarjan DFS Discovery Index and Lowlink Recurrence:

$$
  \begin{aligned}
  \text{dfn}(u) &\in \mathbb{N}_0 \\
  \text{lowlink}(u) &= \min \left( \{ \text{dfn}(u) \} \cup \{ \text{lowlink}(w) \mid (u, w) \in E_{\text{tree}} \} \cup \{ \text{dfn}(w) \mid (u, w) \in E \setminus E_{\text{tree}}, \, w \in \mathcal{S}_{\text{stack}} \} \right)
  \end{aligned}
$$

$$
  \text{IsSCCRoot}(u) \iff \text{lowlink}(u) = \text{dfn}(u)
$$

  Deterministic Elementary Cycle Traceback Path Extraction:
  For each non-trivial component $`C \in \text{TarjanSCC}(G_{\text{prec}})`$:

$$
  \mathcal{P}_{\text{cycle}} = \langle v_1, v_2, \dots, v_k, v_1 \rangle
$$

$$
  v_1 = \arg\min_{v \in C} (\text{QualifiedName}(v))
$$

  where $`k \ge 1`$, $`v_i \in C`$ for all $`i \in \{1, \dots, k\}`$, $`(v_i, v_{i+1}) \in E`$ for all $`i \in \{1, \dots, k-1\}`$, and $`(v_k, v_1) \in E`$ is the closing back-edge.

  Temporal Interval Bounds Consistency Invariant:

$$
  \begin{aligned}
  \forall (u, v) \in E, &\quad t_{\text{start}}(u) \le t_{\text{start}}(v) \\
  \forall (u, v) \in E_{\text{seq}}, &\quad t_{\text{end}}(u) \le t_{\text{start}}(v)
  \end{aligned}
$$

  Deterministic Kahn Topological Schedule & Tie-Breaking:
  For an acyclic graph $`G_{\text{prec}}`$, Kahn's algorithm computes a total linear order $`\mathcal{L} = \langle v_1, v_2, \dots, v_n \rangle`$ where $`n = |V|`$:

$$
  \forall (u, v) \in E, \quad \text{Index}(u, \mathcal{L}) \lt \text{Index}(v, \mathcal{L})
$$

  At step $`t \in \{1, \dots, |V|\}`$, given prefix $`\mathcal{L}_{t-1} = \langle v_1, \dots, v_{t-1} \rangle`$ (with $`\mathcal{L}_0 = \langle \rangle`$):

$$
  \begin{aligned}
  Q_t &= \{ v \in V \setminus \{ v_1, \dots, v_{t-1} \} \mid \text{deg}^{-}_t(v) = 0 \} \\
  v_t &= \arg\min_{v \in Q_t} (\text{QualifiedName}(v)) \\
  \mathcal{L}_t &= \mathcal{L}_{t-1} \mathbin{\Vert} \langle v_t \rangle
  \end{aligned}
$$

  where $`\mathbin{\Vert}`$ denotes sequence concatenation, and dynamic in-degrees update monotonically:

$$
  \forall w \in \text{Adj}(v_t), \quad \text{deg}^{-}_{t+1}(w) = \text{deg}^{-}_t(w) - |\{ (v_t, w) \in E \}|
$$

  Deterministic Diagnostic Code Binding Invariant (REQ-0191):

$$
  \begin{aligned}
  \exists C \in \text{TarjanSCC}(G_{\text{prec}}) : (|C| \gt 1 \lor \exists v \in C, (v, v) \in E) &\implies \text{Diagnostic}(\mathcal{P}_{\text{cycle}}, \text{DiagnosticCode::E0400}, \text{CausalPrecedenceCycleDetected}) \in \mathcal{D}_{\text{sink}} \\
  (u, v) \in E \land (t_{\text{start}}(v) \lt t_{\text{start}}(u)) &\implies \text{Diagnostic}(\langle u, v \rangle, \text{DiagnosticCode::E0400}, \text{CausalTemporalOrderingConflict}) \in \mathcal{D}_{\text{sink}} \\
  (u, v) \in E_{\text{seq}} \land (t_{\text{start}}(v) \lt t_{\text{end}}(u)) &\implies \text{Diagnostic}(\langle u, v \rangle, \text{DiagnosticCode::E0400}, \text{CausalTemporalOrderingConflict}) \in \mathcal{D}_{\text{sink}} \\
  |\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} &\implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
  \end{aligned}
$$

  Sanitized Overlay Graph Invariant (Directive 4):
  To continue validating independent actions and statecharts following cycle detection, the engine severs the back-edge $`(v_k, v_1)`$ in the active compilation overlay:

$$
  E_{\text{overlay}} = E \setminus \{ (v_k, v_1) \}
$$

$$
  \text{Acyclic}((V, E_{\text{overlay}})) \equiv \text{true} \quad (\text{upon pruning all closing cycle back-edges})
$$

  Deterministic RFC 4122 UUIDv5 Anchor Invariant (Directive 1):

$$
  \begin{aligned}
  \forall v \in V, \quad \Delta_v &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(v)) \\
  \forall e = (u, v) \in E, \quad \Delta_e &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(u) \mathbin{\Vert} \text{"->"} \mathbin{\Vert} \text{FQN}(v))
  \end{aligned}
$$

- **Computational Complexity & Algorithmic Bounds**: Directed causal precedence graph construction, cycle detection, temporal interval consistency checking, and topological linearization reside strictly in **Complexity Class P** (Deterministic Polynomial Time).

  For a model comprising $`N = |V|`$ causal vertices (actions, steps, transitions) and $`M = |E|`$ causal precedence edges:
  1. *Graph Construction Phase*:
     Traversing the AST to extract actions, steps, transitions, item flows, and temporal constraints, allocating vertex descriptors and edge adjacency lists in contiguous typed bump arena memory, requires:

$$
T_{\text{construct}}(N, M) \in O(N + M)
$$

  2. *Tarjan SCC Cycle Detection Phase*:
     Tarjan's algorithm executes depth-first search visiting every vertex $`v \in V`$ and traversing every directed edge $`(u, w) \in E`$ exactly once:

$$
T_{\text{SCC}}(N, M) = \sum_{v \in V} \left( O(1) + \sum_{w \in \text{Adj}(v)} O(1) \right) \in O(N + M)
$$

     Auxiliary storage for `dfn`, `lowlink`, and `on_stack` arrays indexed by contiguous 32-bit arena offsets requires strictly $`O(N)`$ space.
  3. *Deterministic Cycle Traceback Extraction*:
     For each detected cyclic component $`C`$, reconstructing the elementary cycle path $`\mathcal{P}_{\text{cycle}}`$ via predecessor tracking takes time proportional to the component size:

$$
T_{\text{traceback}}(C) \in O(|V_C| + |E_C|)
$$

     Summed across all non-trivial components, total traceback extraction time is strictly bounded by $`O(N + M)`$.
  4. *Temporal Interval Consistency Checking*:
     Inspecting interval bounds $`t_{\text{start}}`$ and $`t_{\text{end}}`$ across all causal edges $`(u, v) \in E`$ takes:

$$
T_{\text{temporal}}(M) \in O(M)
$$

  5. *Kahn Topological Linearization Phase*:
     Computing initial in-degrees takes $`O(N + M)`$ time. Maintaining the ready set $`Q`$ via a binary min-heap keyed by interned qualified names requires at most $`N`$ insertions and $`N`$ deletions, with each heap comparison taking $`O(1)`$ scalar integer comparison time on cached symbol IDs:

$$
T_{\text{Kahn}}(N, M) \in O(N \log N + M)
$$

  6. *Aggregate Worst-Case Time Complexity*:
     Combining all evaluation phases, the total deterministic worst-case execution time is:

$$
T_{\text{total}}(N, M) \in O(N \log N + M) \subseteq O((N + M) \log N)
$$

     The algorithm operates without backtracking or exponential search, ensuring deterministic polynomial execution.
  7. *Parallel Work-Stealing Scaling (Directive 2)*:
     When evaluating $`P`$ independent action packages, decoupled statecharts, or orthogonal execution regions across $`N_{\text{max\_workers}}`$ threads on a bounded work-stealing thread pool:

$$
T_{\text{parallel}}(N, M, N_{\text{max\_workers}}) \in O\left( \frac{N \log N + M}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}} \right)
$$

  8. *Space Complexity & Memory Bounds*:
     Allocations for causal vertices, edges, and adjacency lists reside in contiguous typed bump arena memory requiring $`O(N + M)`$ bytes. Interned identifier tokens require $`O(N)`$ space in the global symbol pool. The diagnostic error sink buffer is strictly bounded by $`O(C_{\text{max\_errors}}) = O(1)`$ capacity.
