### REQ-0097: SysML v2 Quantities Library: `SI` Base & Derived Unit Definitions

- **Normative Statement**: The semantic metamodel lowering engine, metrology subsystem, and standard library bootstrapping pipeline of Subsystem 4 shall bootstrap, lower, and formalize the normative OMG SysML v2 standard library packages `SI` and `SIPrefixes` into strongly typed, immutable abstract syntax tree (AST) arena representations. The lowering engine shall establish the canonical mapping between the seven-dimensional physical quantity dimension space over the integer lattice $`\mathbb{Z}^7`$ (and rational vector space $`\mathbb{Q}^7`$) and concrete physical measurement units, standard decimal metric prefixes ($`10^k`$), and exact rational conversion constants.

  Specifically, the lowering engine and metrology pipeline shall strictly enforce the following structural, semantic, and metrological invariants:
  1. **Standard Library Bootstrapping & Metamodel Classifier Hierarchy**:
     - The compiler shall bootstrap the normative SysML v2 standard library packages `SI` and `SIPrefixes` as immutable, pre-compiled root packages within the global compilation unit namespace.
     - Lowered measurement unit declarations (`unit def`, `UnitDefinition`) shall specialize KerML `Feature` and `Structure` (and transitively `Classifier`, `Type`, and SysML v2 `MeasurementUnit`). Every unit definition shall represent an extensional measurement standard possessing an immutable dimensional signature, rational conversion factor, optional additive offset, and interned symbol.
     - Lowered metric prefix declarations (`prefix def`, `PrefixDefinition`) shall specialize KerML `Feature` and SysML v2 `Prefix`, defining a discrete decimal power multiplier $`10^k`$.
     - Incompatible classifier specializations (such as a unit attempting to specialize a behavioral action, state definition, or interface) shall be strictly rejected at compile time with diagnostic error code `E0200` in accordance with REQ-0191.
  2. **The Seven Coherent SI Base Units**:
     - The metrology engine shall bootstrap the seven coherent SI base units forming the orthogonal basis set $`\mathcal{B} = \{ \text{kg}, \text{m}, \text{s}, \text{A}, \text{K}, \text{mol}, \text{cd} \}`$, corresponding directly to the International System of Quantities (ISQ) base dimensions $`[M]`$ (Mass), $`[L]`$ (Length), $`[T]`$ (Time), $`[I]`$ (Electric Current), $`[\Theta]`$ (Thermodynamic Temperature), $`[N]`$ (Amount of Substance), and $`[J]`$ (Luminous Intensity):
       * `kg` (`kilogram`): Base unit of Mass, dimension $`[M] = (1, 0, 0, 0, 0, 0, 0)`$, exact scale factor $`c = 1`$, additive offset $`o = 0`$. In accordance with SI conventions, while `kg` serves as the coherent base unit in the dimensional lattice, metric prefixes in `SIPrefixes` apply to the sub-unit gram (`g`, where $`1\text{ g} = 10^{-3}\text{ kg}`$).
       * `m` (`metre` / `meter`): Base unit of Length, dimension $`[L] = (0, 1, 0, 0, 0, 0, 0)`$, exact scale factor $`c = 1`$, additive offset $`o = 0`$.
       * `s` (`second`): Base unit of Time, dimension $`[T] = (0, 0, 1, 0, 0, 0, 0)`$, exact scale factor $`c = 1`$, additive offset $`o = 0`$.
       * `A` (`ampere`): Base unit of Electric Current, dimension $`[I] = (0, 0, 0, 1, 0, 0, 0)`$, exact scale factor $`c = 1`$, additive offset $`o = 0`$.
       * `K` (`kelvin`): Base unit of Thermodynamic Temperature, dimension $`[\Theta] = (0, 0, 0, 0, 1, 0, 0)`$, exact scale factor $`c = 1`$, additive offset $`o = 0`$.
       * `mol` (`mole`): Base unit of Amount of Substance, dimension $`[N] = (0, 0, 0, 0, 0, 1, 0)`$, exact scale factor $`c = 1`$, additive offset $`o = 0`$.
       * `cd` (`candela`): Base unit of Luminous Intensity, dimension $`[J] = (0, 0, 0, 0, 0, 0, 1)`$, exact scale factor $`c = 1`$, additive offset $`o = 0`$.
  3. **Coherent Derived SI Units with Special Names & Symbols**:
     - The metrology engine shall bootstrap all coherent derived SI units as pure rational power-products of the seven base units with exact scale factor $`c = 1`$ and zero offset $`o = 0`$:
       * `rad` (`radian`): Plane angle, dimensionless $`(0, 0, 0, 0, 0, 0, 0)`$, derived as $`\text{m} \cdot \text{m}^{-1}`$.
       * `sr` (`steradian`): Solid angle, dimensionless $`(0, 0, 0, 0, 0, 0, 0)`$, derived as $`\text{m}^2 \cdot \text{m}^{-2}`$.
       * `Hz` (`hertz`): Frequency, dimension $`[T]^{-1} = (0, 0, -1, 0, 0, 0, 0)`$, derived as $`\text{s}^{-1}`$.
       * `N` (`newton`): Force, dimension $`[M]^1 [L]^1 [T]^{-2} = (1, 1, -2, 0, 0, 0, 0)`$, derived as $`\text{kg} \cdot \text{m} \cdot \text{s}^{-2}`$.
       * `Pa` (`pascal`): Pressure / stress, dimension $`[M]^1 [L]^{-1} [T]^{-2} = (1, -1, -2, 0, 0, 0, 0)`$, derived as $`\text{N} \cdot \text{m}^{-2}`$.
       * `J` (`joule`): Energy / work / heat, dimension $`[M]^1 [L]^2 [T]^{-2} = (1, 2, -2, 0, 0, 0, 0)`$, derived as $`\text{N} \cdot \text{m}`$.
       * `W` (`watt`): Power / radiant flux, dimension $`[M]^1 [L]^2 [T]^{-3} = (1, 2, -3, 0, 0, 0, 0)`$, derived as $`\text{J} \cdot \text{s}^{-1}`$.
       * `C` (`coulomb`): Electric charge, dimension $`[T]^1 [I]^1 = (0, 0, 1, 1, 0, 0, 0)`$, derived as $`\text{A} \cdot \text{s}`$.
       * `V` (`volt`): Electric potential / electromotive force, dimension $`[M]^1 [L]^2 [T]^{-3} [I]^{-1} = (1, 2, -3, -1, 0, 0, 0)`$, derived as $`\text{W} \cdot \text{A}^{-1}`$.
       * `F` (`farad`): Capacitance, dimension $`[M]^{-1} [L]^{-2} [T]^4 [I]^2 = (-1, -2, 4, 2, 0, 0, 0)`$, derived as $`\text{C} \cdot \text{V}^{-1}`$.
       * `ohm` (`ohm`): Electrical resistance, dimension $`[M]^1 [L]^2 [T]^{-3} [I]^{-2} = (1, 2, -3, -2, 0, 0, 0)`$, derived as $`\text{V} \cdot \text{A}^{-1}`$.
       * `S` (`siemens`): Electrical conductance, dimension $`[M]^{-1} [L]^{-2} [T]^3 [I]^2 = (-1, -2, 3, 2, 0, 0, 0)`$, derived as $`\text{A} \cdot \text{V}^{-1}`$.
       * `Wb` (`weber`): Magnetic flux, dimension $`[M]^1 [L]^2 [T]^{-2} [I]^{-1} = (1, 2, -2, -1, 0, 0, 0)`$, derived as $`\text{V} \cdot \text{s}`$.
       * `T` (`tesla`): Magnetic flux density, dimension $`[M]^1 [L]^0 [T]^{-2} [I]^{-1} = (1, 0, -2, -1, 0, 0, 0)`$, derived as $`\text{Wb} \cdot \text{m}^{-2}`$.
       * `H` (`henry`): Inductance, dimension $`[M]^1 [L]^2 [T]^{-2} [I]^{-2} = (1, 2, -2, -2, 0, 0, 0)`$, derived as $`\text{Wb} \cdot \text{A}^{-1}`$.
       * `lm` (`lumen`): Luminous flux, dimension $`[J]^1 = (0, 0, 0, 0, 0, 0, 1)`$, derived as $`\text{cd} \cdot \text{sr}`$.
       * `lx` (`lux`): Illuminance, dimension $`[L]^{-2} [J]^1 = (0, -2, 0, 0, 0, 0, 1)`$, derived as $`\text{lm} \cdot \text{m}^{-2}`$.
       * `Bq` (`becquerel`): Radionuclide activity, dimension $`[T]^{-1} = (0, 0, -1, 0, 0, 0, 0)`$, derived as $`\text{s}^{-1}`$.
       * `Gy` (`gray`): Absorbed dose, dimension $`[L]^2 [T]^{-2} = (0, 2, -2, 0, 0, 0, 0)`$, derived as $`\text{J} \cdot \text{kg}^{-1}`$.
       * `Sv` (`sievert`): Dose equivalent, dimension $`[L]^2 [T]^{-2} = (0, 2, -2, 0, 0, 0, 0)`$, derived as $`\text{J} \cdot \text{kg}^{-1}`$.
       * `kat` (`katal`): Catalytic activity, dimension $`[T]^{-1} [N]^1 = (0, 0, -1, 0, 0, 1, 0)`$, derived as $`\text{mol} \cdot \text{s}^{-1}`$.
  4. **Non-Coherent Derived Units & Affine Temperature Scale**:
     - The metrology engine shall bootstrap non-coherent SI-accepted units with exact rational scale factors:
       * `min` (`minute`): Time, dimension $`[T]`$, scale factor $`c = 60 \in \mathbb{Q}`$.
       * `h` (`hour`): Time, dimension $`[T]`$, scale factor $`c = 3600 \in \mathbb{Q}`$.
       * `d` (`day`): Time, dimension $`[T]`$, scale factor $`c = 86400 \in \mathbb{Q}`$.
       * `L` (`litre` / `liter`): Volume, dimension $`[L]^3`$, scale factor $`c = 1/1000 = 10^{-3} \in \mathbb{Q}`$.
       * `t` (`tonne`): Mass, dimension $`[M]`$, scale factor $`c = 1000 = 10^3 \in \mathbb{Q}`$.
       * `g` (`gram`): Mass, dimension $`[M]`$, scale factor $`c = 1/1000 = 10^{-3} \in \mathbb{Q}`$.
       * `eV` (`electronvolt`): Energy, dimension $`[M]^1 [L]^2 [T]^{-2}`$, exact conversion factor $`c = 1602176634 / 10^{28} \in \mathbb{Q}`$.
     - Degree Celsius (`degC`): Derived temperature unit defined on an affine interval scale:
       * Dimension: $`[\Theta] = (0, 0, 0, 0, 1, 0, 0)`$,
       * Scale factor: $`c = 1 \in \mathbb{Q}`$,
       * Additive offset: $`o = 5463 / 20 = 273.15 \in \mathbb{Q}`$,
       * Conversion relation: $`T_{[\text{K}]} = T_{[^\circ\text{C}]} + \frac{5463}{20}`$.
  5. **`SIPrefixes` Package & Metric Decimal Scaling**:
     - The compiler shall bootstrap the 20 normative SI metric decimal prefixes in `SIPrefixes` representing integer power-of-ten scale multipliers $`10^k`$:
       * Multiples ($`k \gt 0`$): `da` (`deca`, $`10^1`$), `h` (`hecto`, $`10^2`$), `k` (`kilo`, $`10^3`$), `M` (`mega`, $`10^6`$), `G` (`giga`, $`10^9`$), `T` (`tera`, $`10^{12}`$), `P` (`peta`, $`10^{15}`$), `E` (`exa`, $`10^{18}`$), `Z` (`zetta`, $`10^{21}`$), `Y` (`yotta`, $`10^{24}`$).
       * Submultiples ($`k \lt 0`$): `d` (`deci`, $`10^{-1}`$), `c` (`centi`, $`10^{-2}`$), `m` (`milli`, $`10^{-3}`$), `u` (`micro`, $`10^{-6}`$), `n` (`nano`, $`10^{-9}`$), `p` (`pico`, $`10^{-12}`$), `f` (`femto`, $`10^{-15}`$), `a` (`atto`, $`10^{-18}`$), `z` (`zepto`, $`10^{-21}`$), `y` (`yocto`, $`10^{-24}`$).
     - Applying a prefix with decimal exponent $`k`$ to a base or derived unit $`U`$ with scale factor $`c_U`$ shall yield prefixed scale factor $`c_{\text{prefixed}} = 10^k \cdot c_U`$ computed strictly in exact rational arithmetic $`\mathbb{Q}`$.
  6. **Exact Rational Arithmetic & Zero Floating-Point Drift**:
     - All unit scale factors $`c`$, offsets $`o`$, conversion multipliers, and prefix factors must be stored and manipulated strictly as exact irreducible rational numbers $`\frac{p}{q}`$ ($`p \in \mathbb{Z}`$, $`q \in \mathbb{Z}^+`$, $`\gcd(|p|, q) = 1`$).
     - The use of floating-point representations (e.g., IEEE 754 `f32`, `f64`) in unit definitions, dimensional vectors, and conversion calculations is strictly prohibited to eliminate numerical drift and non-deterministic behavior across target platforms.
     - Commensurability Verification: Conversion between two units $`U_1`$ and $`U_2`$ is valid if and only if their dimension vectors are strictly identical: $`\mathbf{d}(U_1) \equiv \mathbf{d}(U_2)`$. Any attempted conversion or dimensional assignment between incommensurable units shall be rejected deterministically at compile time with diagnostic error code `E0201` (`IncommensurableUnitsError`).
     - Acyclic Unit Derivations: Unit derivations and alias definitions shall form a directed acyclic graph. Mutual recursion or cyclic derivations ($`U_A \to U_B \to U_A`$) shall be detected via topological sort and rejected with diagnostic error code `E0203` (`CircularUnitDependency`).
  7. **Architectural Directives Compliance**:
     - *Directive 1 (Deterministic UUIDv5 Anchors)*: Every lowered unit definition, prefix definition, and standard library symbol node shall be assigned an immutable deterministic RFC 4122 UUIDv5 identifier derived from the compiler namespace OID and canonical fully qualified path ($`\text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(n))`$) in accordance with REQ-0010.
     - *Directive 2 (Bounded Work-Stealing Parallelism)*: Parallel unit lowering, dimensional consistency checking, and package bootstrapping across independent compilation units shall execute on a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ in accordance with REQ-0012.
     - *Directive 3 (String Interner Allocation Exception)*: Unit symbols, long names, prefix labels, and fully qualified path tokens shall be interned into the deduplicated global string interner pool during lexical analysis per REQ-0036 as the sole permitted exception to zero-copy memory management.
     - *Directive 4 (Synchronization Token Error Recovery)*: The unit parser and type checker shall implement synchronization token error recovery on statement delimiters (`;`) and block boundaries (`}`). When semantic violations occur (`E0200`, `E0201`, `E0203`), diagnostics shall accumulate in error sink buffer $`\mathcal{D}_{\text{sink}}`$, substitute typed error sentinel $`\bot_{\text{unit}}`$, and continue parsing. If accumulated diagnostics reach $`C_{\text{max\_errors}}`$, terminal diagnostic `E0199` shall be emitted and compilation halted gracefully.
     - *Directive 5 (Panic-Free Release Isolation)*: The unit lowering and conversion pipeline shall enforce a deterministic, non-panicking execution contract with total-function error handling. Performance latency ($`\lt 25\text{ ms}`$) and peak RSS memory ($`\lt 100\text{ MB}`$ for $`10^4`$ unit expressions) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (`Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Unit_Alpha`, `Unit_Beta`, `Prefix_Alpha`, `param_x : Real`, `Quantity_1`), strictly prohibiting hardcoded domain concepts, mock data, and non-ASCII dashes.

- **Formal Invariant**: Let $`\mathcal{V}_{\text{AST}}`$ denote the universe of allocated AST nodes in contiguous bump arena storage. Let $`\mathcal{U} \subset \mathcal{V}_{\text{AST}}`$ denote the set of lowered measurement unit definitions, and $`\mathcal{P}_{\text{prefix}} \subset \mathcal{V}_{\text{AST}}`$ denote the set of metric prefix definitions.

  Let $`\mathcal{B} = \{ \text{kg}, \text{m}, \text{s}, \text{A}, \text{K}, \text{mol}, \text{cd} \}`$ be the ordered sequence of 7 coherent SI base units. Every physical dimension $`\mathbf{d} \in \mathbb{Z}^7`$ is represented as an integer vector:

$$
\mathbf{d} = (\alpha, \beta, \gamma, \delta, \epsilon, \zeta, \eta) \in \mathbb{Z}^7
$$

  corresponding to the base quantity power product:

$$
[M]^\alpha [L]^\beta [T]^\gamma [I]^\delta [\Theta]^\epsilon [N]^\zeta [J]^\eta
$$

  Each unit definition $`U \in \mathcal{U}`$ is formalized as a 10-tuple:

$$
U = \langle \text{id}_U, \text{name}_U, \text{symbol}_U, \mathbf{d}_U, c_U, o_U, \text{is\_ratio}_U, \mathcal{S}_U, \Delta_U, \text{span}_U \rangle
$$

  where:

$$
\begin{aligned}
\text{id}_U &\in \mathbb{N}_{32} \quad (\text{contiguous arena node handle}) \\
\text{name}_U &\in \mathcal{S}_{\text{intern}} \quad (\text{interned unit name identifier}) \\
\text{symbol}_U &\in \mathcal{S}_{\text{intern}} \quad (\text{interned unit textual symbol}) \\
\mathbf{d}_U &\in \mathbb{Z}^7 \quad (\text{integer dimensional lattice coordinates}) \\
c_U &\in \mathbb{Q}^+ \quad (\text{exact rational scale factor relative to coherent base units}) \\
o_U &\in \mathbb{Q} \quad (\text{exact rational additive offset, } o_U = 0 \text{ for ratio scale units}) \\
\text{is\_ratio}_U &\in \mathbb{B} \quad (\text{boolean flag: true for ratio scale, false for interval scale}) \\
\mathcal{S}_U &\subseteq \mathcal{V}_{\text{AST}} \quad (\text{direct supertypes specializing MeasurementUnit}) \\
\Delta_U &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor}) \\
\text{span}_U &= \langle \text{file\_id}, p_{\text{start}}, p_{\text{end}}, \text{line}, \text{col} \rangle \quad (\text{source lexical provenance})
\end{aligned}
$$

  Each metric prefix definition $`P \in \mathcal{P}_{\text{prefix}}`$ is formalized as a 4-tuple:

$$
P = \langle \text{name}_P, \text{symbol}_P, k_P, \Delta_P \rangle
$$

  where:

$$
\begin{aligned}
\text{name}_P &\in \mathcal{S}_{\text{intern}} \quad (\text{interned prefix name, e.g., ``kilo''}) \\
\text{symbol}_P &\in \mathcal{S}_{\text{intern}} \quad (\text{interned prefix symbol, e.g., ``k''}) \\
k_P &\in \{ -24, -21, -18, -15, -12, -9, -6, -3, -2, -1, 1, 2, 3, 6, 9, 12, 15, 18, 21, 24 \} \\
\Delta_P &\in \{0, 1\}^{128} \quad (\text{deterministic RFC 4122 UUIDv5 topological anchor})
\end{aligned}
$$

  Coherent Base Unit Basis Invariant: For each base unit $`B_i \in \mathcal{B}`$ with canonical basis vector $`\mathbf{e}_i \in \mathbb{Z}^7`$:

$$
\begin{aligned}
\mathbf{d}(\text{kg}) &= (1, 0, 0, 0, 0, 0, 0), \quad c_{\text{kg}} = 1, \quad o_{\text{kg}} = 0, \quad \text{is\_ratio}_{\text{kg}} = \text{true} \\
\mathbf{d}(\text{m}) &= (0, 1, 0, 0, 0, 0, 0), \quad c_{\text{m}} = 1, \quad o_{\text{m}} = 0, \quad \text{is\_ratio}_{\text{m}} = \text{true} \\

\mathbf{d}(\text{mol}) &= (0, 0, 0, 0, 0, 1, 0), \quad c_{\text{mol}} = 1, \quad o_{\text{mol}} = 0, \quad \text{is\_ratio}_{\text{mol}} = \text{true} \\

  General Unit Definition Invariant: Every SI unit $`U \in \mathcal{U}`$ is defined relative to the coherent base units by:

$$
1 \text{ Unit} = c_U \cdot \text{kg}^\alpha \cdot \text{m}^\beta \cdot \text{s}^\gamma \cdot \text{A}^\delta \cdot \text{K}^\epsilon \cdot \text{mol}^\zeta \cdot \text{cd}^\eta
$$

  where $`c_U \in \mathbb{Q}^+`$ is the exact rational scaling factor and $`(\alpha, \beta, \gamma, \delta, \epsilon, \zeta, \eta) = \mathbf{d}_U \in \mathbb{Z}^7`$.

  Metric Prefix Scaling Invariant: Applying prefix $`P(k) \in \mathcal{P}_{\text{prefix}}`$ scales the rational factor by power of ten:

$$
\text{Prefix}(k) \implies c_{\text{prefixed}} = 10^k \cdot c_U, \quad 10^k = \begin{cases} \frac{10^k}{1} \in \mathbb{Q}, & \text{if } k \ge 0 \\ \frac{1}{10^{|k|}} \in \mathbb{Q}, & \text{if } k \lt 0 \end{cases}
$$

  Algebraic Operations over Units: For units $`U_1, U_2 \in \mathcal{U}`$ and integer exponent $`p \in \mathbb{Z}`$:

$$
\begin{aligned}
U_1 \cdot U_2 &\implies \mathbf{d}(U_1 \cdot U_2) = \mathbf{d}(U_1) + \mathbf{d}(U_2), \quad c(U_1 \cdot U_2) = c(U_1) \cdot c(U_2) \\
U_1 / U_2 &\implies \mathbf{d}(U_1 / U_2) = \mathbf{d}(U_1) - \mathbf{d}(U_2), \quad c(U_1 / U_2) = c(U_1) / c(U_2) \\
U_1^p &\implies \mathbf{d}(U_1^p) = p \cdot \mathbf{d}(U_1), \quad c(U_1^p) = (c(U_1))^p
\end{aligned}
$$

  Commensurability Equivalence Relation ($`\sim`$):

$$
U_1 \sim U_2 \iff \mathbf{d}(U_1) = \mathbf{d}(U_2)
$$

  Exact Rational Unit Conversion Invariant: For commensurable units $`U_1, U_2`$ with $`\mathbf{d}(U_1) = \mathbf{d}(U_2)`$:

$$
\begin{aligned}
\text{Ratio Scale } (\text{is\_ratio}_{U_1} \wedge \text{is\_ratio}_{U_2}): &\quad \text{convert}(v, U_1, U_2) = v \cdot \left( \frac{c_{U_1}}{c_{U_2}} \right) \\
\text{Affine Scale } (\neg \text{is\_ratio}_{U_1} \vee \neg \text{is\_ratio}_{U_2}): &\quad \text{convert}_{\text{affine}}(v, U_1, U_2) = \frac{c_{U_1} \cdot v + o_{U_1} - o_{U_2}}{c_{U_2}}
\end{aligned}
$$

  Unit Derivation Acyclicity Invariant: Let $`\mathcal{G}_{\text{unit\_dep}} = (\mathcal{U}, \mathcal{R}_{\text{unit\_dep}})`$ denote the directed unit derivation graph where $`(U_1, U_2) \in \mathcal{R}_{\text{unit\_dep}}`$ if $`U_1`$ is defined in terms of $`U_2`$. The transitive closure $`\mathcal{R}_{\text{unit\_dep}}^+`$ must be irreflexive:

$$
\forall U \in \mathcal{U}, \quad (U, U) \notin \mathcal{R}_{\text{unit\_dep}}^+

  Deterministic RFC 4122 UUIDv5 Anchor Invariant (Architectural Directive 1):

$$
\begin{aligned}
\forall U \in \mathcal{U}, &\quad \Delta_U = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(U)) \\
\forall P \in \mathcal{P}_{\text{prefix}}, &\quad \Delta_P = \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(P))

- **Computational Complexity & Algorithmic Bounds**: Bootstrapping, unit lowering, commensurability verification, and exact rational unit conversion execute strictly within Complexity Class $`\mathbf{P}`$.

  For a standard library environment containing $`N_U = |\mathcal{U}|`$ unit definitions, $`N_P = |\mathcal{P}_{\text{prefix}}|`$ metric prefixes, and an abstract MBSE model containing $`K`$ unit conversion expressions:
  1. *Arena Allocation & Symbol Interning*: Allocating each unit definition $`U`$ and prefix definition $`P`$ in contiguous bump arena storage requires amortized $`O(1)`$ time and $`O(1)`$ auxiliary space per node, yielding $`O(N_U + N_P)`$ total bootstrapping time.
  2. *Dimensional Commensurability Verification*: Comparing two 7-dimensional integer vectors $`\mathbf{d}_1, \mathbf{d}_2 \in \mathbb{Z}^7`$ evaluates 7 integer equality comparisons, executing in deterministic $`O(1)`$ time and requiring zero auxiliary memory:

$$
T_{\text{commensurable}} \in O(1)
$$

  3. *Unit Algebra & Rational Conversion Factor Calculation*: Multiplying, dividing, or inverting exact rational numbers $`\frac{p_1}{q_1} \cdot \frac{p_2}{q_2}`$ requires integer multiplication and Euclidean algorithm greatest common divisor ($`\gcd`$) reduction. For 64-bit or 128-bit integer words, Euclidean reduction terminates in at most $`2 \log_2(\min(|p|, q))`$ steps, executing in deterministic $`O(1)`$ time:

$$
