### REQ-0019: Table Row-to-Entity Structural Mapping & Identifier Sanitization

- **Normative Statement**: The CommonMark table parser within the Universal Schema Ingestion Engine shall map each valid schema table row to a corresponding intermediate representation (IR) entity in the contiguous node arena while sanitizing raw entity names into valid OMG SysML v2 / KerML basic identifiers using deterministic character replacement, collapse of contiguous delimiters, prefixing, and scope collision avoidance. For each input table row $`R_i = \langle c_{i, 0}, c_{i, 1}, \dots, c_{i, C-1} \rangle`$`, the ingestion engine shall extract cell values positionally using the precomputed column-to-attribute binding vector `$`\vec{\beta}`$` and instantiate an IR entity corresponding to the target structural element (such as a part, port, connection, action, attribute, constraint, or state). The engine shall extract the raw identifier string `$`S_{\text{raw}}`$` from the cell mapped to canonical name attribute `$`k_{\text{name}}`$. If a data row omits the name cell or contains only whitespace when an entity identifier is mandatory, the engine shall record structured diagnostic error code `E0102` (table row structural mapping fault per REQ-0191) with exact 1-indexed line and column coordinates and byte span, and synthesize a deterministic fallback identifier `id_anonymous_<row_index>` to maintain continuous error recovery and forward stream progress. The engine shall transform $`S_{\text{raw}}`$ into a valid SysML v2 / KerML basic identifier satisfying lexical grammar `[a-zA-Z_][a-zA-Z0-9_]*` without colliding with reserved keywords: (1) strip leading and trailing ASCII whitespace; (2) map any non-alphanumeric byte outside $`[a\text{-}z, A\text{-}Z, 0\text{-}9]`$ and underscore `_` to an underscore `_`; (3) collapse contiguous runs of underscores into a single underscore; (4) if the initial character is an ASCII digit ($`0\text{--}9`$), or if the sanitized token matches a reserved OMG SysML v2 / KerML keyword, prepend the deterministic prefix `id_`; (5) preserve trailing punctuation marks mapped to underscores in accordance with the canonical specification invariant $`\sigma_{\text{id}}(\text{"123-Alpha (Beta)"}) = \text{"id\_123\_Alpha\_Beta\_"}`$`. The ingestion engine shall maintain an active lexical scope tracking all declared sibling identifiers within the enclosing parent entity or package; if a sanitized name collides with an existing sibling identifier in the active scope, the engine shall append an underscore followed by the monotonic occurrence count `$`k \ge 2`$ within that scope (yielding `_2`, `_3`, etc.) until an unassigned identifier is achieved. In accordance with REQ-0002, the synthesized IR entity shall retain both the sanitized, disambiguated identifier for AST lowering and the exact original raw string $`S_{\text{raw}}`$` with source byte span `$`[p_{\text{start}}, p_{\text{end}}]`$` for full provenance fidelity. Sanitization and structural mapping shall enforce a total, deterministic, non-panicking execution contract with zero panics across all inputs, bounding raw identifiers to `$`L_{\text{max}} = 256`$ bytes.

- **Formal Invariant**: Let $`\Sigma = \{ b \in \mathbb{N} \mid 0 \le b \le 255 \}`$` denote the byte alphabet, with ASCII alphanumeric subsets `$`\Sigma_{\text{alpha}} = \{ b \in \Sigma \mid (0\text{x}41 \le b \le 0\text{x}5\text{A}) \vee (0\text{x}61 \le b \le 0\text{x}7\text{A}) \}`$`, `$`\Sigma_{\text{digit}} = \{ b \in \Sigma \mid 0\text{x}30 \le b \le 0\text{x}39 \}`$`, and `$`\Sigma_{\text{alphanumeric}} = \Sigma_{\text{alpha}} \cup \Sigma_{\text{digit}}`$`. Let `$`\Sigma_{\text{ident\_char}} = \Sigma_{\text{alphanumeric}} \cup \{ 0\text{x}5\text{F} \}`$` where `$`0\text{x}5\text{F}`$ is ASCII `_`. Let $`\mathcal{K}_{\text{reserved}} \subset \Sigma^*`$ denote the finite set of reserved OMG SysML v2 and KerML keywords.

The formal language of valid SysML v2 / KerML basic identifiers $`\text{BasicIdentifier} \subset \Sigma^*`$ is defined as:

```math
\text{BasicIdentifier} = \{ s \in \Sigma^+ \mid s[0] \in (\Sigma_{\text{alpha}} \cup \{ 0\text{x}5\text{F} \}) \;\wedge\; (\forall i \in \{1, \dots, |s|-1\}, \, s[i] \in \Sigma_{\text{ident\_char}}) \;\wedge\; s \notin \mathcal{K}_{\text{reserved}} \}
```

The whitespace trimming operator $`\text{Trim} : \Sigma^* \to \Sigma^*`$` strips leading and trailing characters belonging to `$`\{ \text{SYM}_{\text{SPACE}}, \text{SYM}_{\text{TAB}}, \text{SYM}_{\text{LF}}, \text{SYM}_{\text{CR}} \}`$.

The character replacement operator $`\rho : \Sigma \to \Sigma`$ maps non-alphanumeric characters to underscores:

```math
\rho(b) = \begin{cases}
b, & \text{if } b \in \Sigma_{\text{alphanumeric}} \\
0\text{x}5\text{F}, & \text{otherwise}
\end{cases}
```

Let $`\rho^*(s) = \langle \rho(s[0]), \rho(s[1]), \dots, \rho(s[|s|-1]) \rangle`$` denote the character-wise mapping over string `$`s \in \Sigma^*`$.

The underscore collapsing operator $`\text{Collapse} : \Sigma^* \to \Sigma^*`$ reduces contiguous runs of underscores:

```math
\text{Collapse}(s_1 \mathbin{\Vert} \text{"\_\_"} \mathbin{\Vert} s_2) = \text{Collapse}(s_1 \mathbin{\Vert} \text{"\_"} \mathbin{\Vert} s_2)
```

The prefixing operator $`\pi_{\text{id}} : \Sigma^* \to \Sigma^*`$ guarantees non-numeric initial characters and keyword disambiguation:

```math
\pi_{\text{id}}(s) = \begin{cases}
\text{"id\_"} \mathbin{\Vert} s, & \text{if } s = \varepsilon \;\vee\; s[0] \in \Sigma_{\text{digit}} \;\vee\; s \in \mathcal{K}_{\text{reserved}} \\
s, & \text{otherwise}
\end{cases}
```

The sanitization function $`\sigma_{\text{id}} : \Sigma^* \to \Sigma^*`$ satisfies:

```math
\sigma_{\text{id}}(S_{\text{raw}}) = \begin{cases}
S_{\text{raw}}, & \text{if } S_{\text{raw}} \in \text{BasicIdentifier} \\
\pi_{\text{id}}(\text{Collapse}(\rho^*(\text{Trim}(S_{\text{raw}})))), & \text{otherwise}
\end{cases}
```

Canonical Example Sanitization Invariant:

```math
\sigma_{\text{id}}(\text{"123-Alpha (Beta)"}) = \text{"id\_123\_Alpha\_Beta\_"}
```

Let $`\text{Scope} \subset \text{BasicIdentifier}`$` denote the active set of registered sibling identifiers in the current namespace. Let `$`\text{Count}(\sigma, \text{Scope})`$` denote the count of existing instances of base identifier `$`\sigma`$` registered within `$`\text{Scope}`$:

```math
\text{Count}(\sigma, \text{Scope}) = |\{ s \in \text{Scope} \mid s = \sigma \;\vee\; \exists k \in \mathbb{N}_{\ge 2} : s = \sigma \mathbin{\Vert} \text{"\_"} \mathbin{\Vert} \text{Str}(k) \}|
```

The deterministic disambiguation function $`\text{Disambiguate} : \Sigma^* \times \mathcal{P}(\Sigma^*) \to \Sigma^*`$ satisfies:

```math
\text{Disambiguate}(\sigma, \text{Scope}) = \begin{cases}
\sigma, & \text{if } \sigma \notin \text{Scope} \\
\sigma \mathbin{\Vert} \text{"\_"} \mathbin{\Vert} \text{Str}(\text{Count}(\sigma, \text{Scope}) + 1), & \text{if } \sigma \in \text{Scope}
\end{cases}
```

Scope Injectivity Invariant:

```math
\forall \sigma \in \text{BasicIdentifier}, \; \forall \text{Scope} \subset \text{BasicIdentifier}, \quad \text{Disambiguate}(\sigma, \text{Scope}) \notin \text{Scope}
```

Let data row $`\mathbf{r}_i = \langle c_{i, 0}, c_{i, 1}, \dots, c_{i, C-1} \rangle`$` have column binding vector `$`\vec{\beta} : \{0, \dots, C-1\} \to \mathcal{K}_{\text{canonical}} \cup \{ \bot \}`$` and designated name column `$`j_{\text{name}} = \beta^{-1}(k_{\text{name}})`$`. The resolved entity identifier for row `$`\mathbf{r}_i`$ is:

```math
\text{ResolveIdent}(\mathbf{r}_i, \text{Scope}_{i-1}) = \begin{cases}
\text{Disambiguate}(\sigma_{\text{id}}(c_{i, j_{\text{name}}}), \text{Scope}_{i-1}), & \text{if } j_{\text{name}} \ne \bot \;\wedge\; \text{Trim}(c_{i, j_{\text{name}}}) \ne \varepsilon \\
\text{Disambiguate}(\text{"id\_entity\_"} \mathbin{\Vert} \text{Str}(i), \text{Scope}_{i-1}), & \text{otherwise}
\end{cases}
```

The synthesized Intermediate Representation entity $`\mathcal{E}_i`$` for row `$`\mathbf{r}_i`$ is an 8-tuple:

```math
\mathcal{E}_i = \langle \text{NodeId}_i, T_{\text{entity}}, \text{ResolveIdent}(\mathbf{r}_i, \text{Scope}_{i-1}), c_{i, j_{\text{name}}}, \mathcal{A}_i, \text{span}(\mathbf{r}_i), i, \text{ScopeId} \rangle
```

where canonical attribute mapping $`\mathcal{A}_i`$ binds non-name canonical attributes:

```math
\mathcal{A}_i = \{ (\beta(j), c_{i, j}) \mid 0 \le j \lt C \;\wedge\; \beta(j) \ne \bot \;\wedge\; \beta(j) \ne k_{\text{name}} \}
```

The active scope evolves monotonically across data rows:

```math
\text{Scope}_i = \text{Scope}_{i-1} \cup \{ \text{ResolveIdent}(\mathbf{r}_i, \text{Scope}_{i-1}) \}
```

Lexical Provenance Invariant (REQ-0002):

```math
\forall i \in \{1, \dots, M\}, \quad \text{SourceSpan}(\mathcal{E}_i) = [p_{\text{start}}^{(i)}, p_{\text{end}}^{(i)}] \;\wedge\; \text{Slice}(\text{SourceBuffer}, p_{\text{start}}^{(i)}, p_{\text{end}}^{(i)}) \equiv \text{RawRowBytes}(\mathbf{r}_i)
```

Diagnostic Error Code Binding Invariant: Structural row mapping anomalies trigger diagnostic error code `E0102` in accordance with REQ-0191:

```math
\begin{aligned}
(j_{\text{name}} = \bot \;\vee\; \text{Trim}(c_{i, j_{\text{name}}}) = \varepsilon) \;\wedge\; \text{Strict}(\mathcal{T}) &\implies \text{Diagnostic}(i, j_{\text{name}}, \text{DiagnosticCode::E0102}, \text{MissingIdentifier}) \in \mathcal{D} \\
|c_{i, j_{\text{name}}}| \gt L_{\text{max}} &\implies \text{Diagnostic}(i, j_{\text{name}}, \text{DiagnosticCode::E0102}, \text{IdentifierTooLong}) \in \mathcal{D}
\end{aligned}
```

- **Computational Complexity & Algorithmic Bounds**: Table row-to-entity structural mapping and identifier sanitization execute within Complexity Class $`\mathbf{P}`$`. For any raw identifier string `$`S_{\text{raw}}`$` bounded by `$`|S_{\text{raw}}| \le L_{\text{max}} = 256`$` bytes, whitespace trimming, character-wise mapping `$`\rho`$`, underscore collapsing, and prefixing `$`\pi_{\text{id}}`$` execute in a single linear forward scan over the byte slice, requiring deterministic `$`O(|S_{\text{raw}}|) = O(1)`$` operations with zero backtracking. Reserved keyword checking against `$`\mathcal{K}_{\text{reserved}}`$` operates via a static minimal perfect hash table or Trie in `$`O(|S_{\text{raw}}|) = O(1)`$` time. Sibling collision checking and insertion into the active namespace scope `$`\text{Scope}`$` execute in `$`O(|S_{\text{raw}}|) = O(1)`$` amortized and expected time using a symbol table with deterministic open-address Robin Hood hashing. Disambiguation string formatting of occurrence integer `$`k \le M`$` requires `$`O(\log_{10} M) \le O(1)`$` operations for tables up to `$`M \le 10^5`$` rows. For each data row containing `$`C`$` columns (`$`1 \le C \le C_{\text{max\_cols}} = 32`$`), mapping cell values to entity attributes via precomputed binding vector `$`\vec{\beta}`$` requires `$`O(C) = O(1)`$` operations. Across an entire tabular schema consisting of `$`M`$` rows and total byte size `$`N = \sum_{i=1}^M |\mathbf{r}_i|`$`, aggregate row-to-entity transformation and AST generation execute in deterministic `$`O(N)`$` linear time in total input size. Auxiliary memory complexity is bounded by `$`O(M)`$ for storing the scope symbol table and IR entity references in the contiguous node arena, requiring zero dynamic heap allocations in row processing loops.

- **Verification & Conformance Criteria**: Automated test suites shall verify compliance against synthetic CommonMark schema tables containing generic MBSE entities (e.g., `Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`). Conformance shall be validated through the following deterministic test gates: (1) Basic Identifier Passthrough Gate: Verify that valid SysML v2 / KerML basic identifiers (e.g., `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x`) pass through $`\sigma_{\text{id}}`$` unaltered, asserting that `$`\sigma_{\text{id}}(S) \equiv S`$ with 0-byte difference. (2) Non-Alphanumeric Character Replacement & Delimiter Normalization Gate: Verify that raw identifiers containing whitespace, hyphens, parentheses, and slashes (specifically `"123-Alpha (Beta)"`) lower deterministically to `"id_123_Alpha_Beta_"`, asserting that non-alphanumeric characters map to underscores, consecutive underscores collapse, leading digits receive the `id_` prefix, and trailing delimiters are preserved as underscores. (3) Leading Numeric Prefix Gate: Verify that identifiers with leading digits (`"1"`, `"007_Node"`, `"42_Port"`) prepend `"id_"`, yielding `"id_1"`, `"id_007_Node"`, `"id_42_Port"`. (4) Reserved Keyword Disambiguation Gate: Verify that identifiers matching reserved SysML v2 / KerML keywords (`"part"`, `"port"`, `"connection"`, `"action"`, `"state"`, `"package"`, `"def"`) prepend `"id_"`, yielding `"id_part"`, `"id_port"`, `"id_action"`, etc. (5) Scope Sibling Collision Disambiguation Gate: Ingest a CommonMark table containing three identical raw identifiers (`"Component_Alpha"`, `"Component_Alpha"`, `"Component_Alpha"`) within the same enclosing package scope; assert that the synthesized entities receive distinct disambiguated identifiers: `"Component_Alpha"`, `"Component_Alpha_2"`, and `"Component_Alpha_3"`. (6) Lexical Provenance Gate: Verify that every synthesized IR entity retains the exact source byte span $`[p_{\text{start}}, p_{\text{end}}]`$ and 1-indexed line and column coordinates, asserting that slicing the original source buffer by the entity's span yields the exact raw row byte sequence with bitwise fidelity. (7) Missing Identifier & Error Gate: Ingest a table row where the name column is empty, whitespace-only, or missing mandatory identifier cells; assert that under strict validation mode, the parser records structured diagnostic error code `E0102` with 1-indexed row and column coordinates, while synthesizing fallback identifier `id_anonymous_<row_idx>` to enable error accumulation and synchronization token recovery. (8) Bounded Latency & Panic-Free Gate: Benchmark suites evaluate identifier sanitization and row-to-entity mapping in compiled Release mode (`--release`), verifying that per-row processing latency does not exceed $`5\,\mu\text{s}`$` (`$`p_{99} \le 5\,\mu\text{s}`$`), with zero panics or memory leaks across fuzzing suites containing `$`10^5`$ malformed inputs.
