### REQ-0048: Topological Sort Dependency Scheduling (Tarjan SCC & Kahn Algorithms)

- **Normative Statement**: The Core Metamodel, Node Arena & AST Graph Engine shall provide deterministic topological dependency scheduling and graph analysis routines via Kahn's algorithm and Tarjan's strongly connected components (SCC) algorithm to determine valid compilation sequences, dependency linearization, cycle detection with cycle traceback paths, and shortest-path interconnection routing across model elements. The graph engine shall operate directly on abstract syntax tree (AST) graph representations where vertices represent lowered model entities (such as packages, classifier definitions, feature usages, and ports) and edges represent directed dependency, specialization, structural containment, or interconnect relations.

  All graph vertices and edges shall be stored in contiguous typed bump arena memory in accordance with REQ-0009 and REQ-0034, referenced exclusively via deterministic 32-bit typed node handles (`NodeHandle<T>`) in accordance with REQ-0035, prohibiting raw memory pointers and unmanaged virtual memory addresses. In accordance with Architectural Directive 1 and REQ-0010, every node participating in dependency scheduling shall possess an immutable deterministic RFC 4122 UUIDv5 identifier generated by hashing the fixed namespace OID and the node fully qualified topological symbol path. In accordance with Architectural Directive 3 and REQ-0036, symbol strings and fully qualified names shall be interned into the global symbol interner pool as scalar `SymbolId` tokens during lexical ingestion, which constitutes the sole permitted exception to zero-copy memory management.

  The graph engine shall enforce the following normative scheduling and graph traversal behaviors:
  1. Kahn Topological Sort with Deterministic Lexicographical Tie-Breaking: For all directed acyclic dependency graphs (DAGs), Kahn's algorithm shall evaluate vertex in-degrees and compute an authoritative linear compilation schedule $\mathcal{L} = \langle v_1, v_2, \dots, v_n \rangle$ such that for every directed dependency edge $(u, v) \in E$, dependency predecessor $u$ strictly precedes dependent successor $v$ in the sequence ($\text{Index}(u, \mathcal{L}) \lt \text{Index}(v, \mathcal{L})$). When multiple candidate vertices simultaneously possess an in-degree of zero in the ready queue $Q$, the engine must dequeue vertices strictly in ascending lexicographical byte order of their interned fully qualified names (`QualifiedName(v)`). Arbitrary pointer ordering, non-deterministic hash iteration, or insertion-order scheduling are strictly prohibited, ensuring 100% bitwise determinism and zero diff churn across compilations per REQ-0003.
  2. Tarjan Strongly Connected Components (SCC) Decomposition: The graph engine shall implement Tarjan's linear-time depth-first search algorithm to decompose arbitrary directed AST graphs into disjoint maximal strongly connected components $\mathcal{C} = \{ C_1, C_2, \dots, C_k \}$. The engine shall construct the condensed acyclic graph (condensation DAG) $G^{\text{scc}} = (\mathcal{C}, E^{\text{scc}})$ wherein each component $C_i$ forms a single super-vertex, and schedule the condensation graph via topological ordering.
  3. Cycle Detection, Traceback & Diagnostic Error Recovery: In graph contexts where acyclicity is strictly mandated by MBSE semantics (including type specialization hierarchies, structural containment, and causal execution sequences), any non-trivial strongly connected component ($|C| \gt 1$ or containing a reflexive self-loop $(v, v) \in E$) shall be identified as an invalid circular dependency. In accordance with Architectural Directive 4, REQ-0013, and REQ-0016, the engine shall implement synchronization token error recovery: upon cycle detection, the engine shall extract an exact ordered circular traceback path $\mathcal{P}_{\text{cycle}} = \langle v_1, v_2, \dots, v_m, v_1 \rangle$, record a structured diagnostic record binding diagnostic error code `E0203` (Circular Dependency & Metamodel Inheritance Cycle Detection per REQ-0191) with exact source byte spans and symbol identifiers, isolate the cyclic component, mark its constituent node handles with an invalid status tag, and resume scheduling of remaining independent acyclic subgraphs. If accumulated diagnostics reach the preallocated sink capacity limit $C_{\text{max\_errors}}$, the compiler shall emit diagnostic error code `E0199` and terminate type checking gracefully.
  4. Shortest-Path Interconnect Query Facility: The graph engine shall provide a deterministic breadth-first search (BFS) query engine to compute the shortest topological routing path $\mathcal{P}^*$ between any source port $P_{\text{src}}$ and target port $P_{\text{tgt}}$ over directed interconnect multigraphs. If multiple equidistant shortest paths exist, the query engine shall break ties deterministically by selecting the path whose concatenated sequence of intermediate node qualified names is lexicographically minimal.
  5. Bounded Work-Stealing Parallel Traversal: In accordance with Architectural Directive 2 and REQ-0012, parallel execution of topological scheduling and SCC decomposition across independent, disconnected weakly connected components (WCCs) or independent compilation units shall be dispatched strictly onto a bounded work-stealing thread pool with worker bound $N_{\text{max\_workers}}$. Unbounded manual thread spawning is strictly prohibited.
  6. Panic-Free Total-Function Execution & Performance Isolation: In accordance with Architectural Directive 5, REQ-0011, and REQ-0196, the graph engine shall enforce a deterministic, non-panicking execution contract with total-function termination across all inputs, including pathologically cyclic, disconnected, or malformed graphs. Performance throughput gates (execution latency strictly below 25 ms for graphs up to $10^5$ vertices and edges, peak RSS memory strictly below 100 MB) shall be evaluated exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses, isolated from logic tests.

  All diagnostic messages, test models, and illustrative examples shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Package_1`, `Classifier_Alpha`, `Classifier_Beta`, `Classifier_Gamma`, `Classifier_Delta`, `Component_Alpha`, `Component_Beta`, `Part_0`, `Port_1`, `Port_2`, `Port_3`, `Port_Src`, `Port_Tgt`, `Conn_0`, `Node_A`, `Node_B`, `Node_C`, `Node_D`, `param_x : Real`) with zero domain contamination and zero mock data.

- **Formal Invariant**: Let $G = (V, E)$ denote a directed AST dependency graph where $V \subset \mathbb{U}_{32}$ represents contiguous typed arena node handles and $E \subseteq V \times V$ represents directed dependency edges:

$$
G = (V, E), \quad V \subset \mathbb{U}_{32}, \quad E \subseteq V \times V
$$

The in-degree function $\text{deg}^{-} : V \to \mathbb{N}_0$ is defined as:

$$
\text{deg}^{-}(v) = |\{ u \in V \mid (u, v) \in E \}|
$$

1. Topological Linear Ordering Invariant:
For an acyclic graph $G$, Kahn's algorithm produces a linear permutation sequence $\mathcal{L} = \langle v_1, v_2, \dots, v_n \rangle$ where $n = |V|$ satisfying:

$$
\forall (u, v) \in E, \quad \text{Index}(u, \mathcal{L}) \lt \text{Index}(v, \mathcal{L})
$$

2. Ready Queue Dynamic State and Deterministic Tie-Breaking Invariant:
At scheduling step $t \in \{ 1, \dots, |V| \}$, let $\mathcal{L}_{t-1} = \langle v_1, \dots, v_{t-1} \rangle$ denote the prefix of already scheduled vertices (with $\mathcal{L}_0 = \langle \rangle$). The active ready set $Q_t$, selected vertex $v_t$, and extended sequence $\mathcal{L}_t$ satisfy:

$$
\begin{aligned}
Q_t &= \{ v \in V \setminus \{ v_1, \dots, v_{t-1} \} \mid \text{deg}^{-}_t(v) = 0 \} \\
v_t &= \arg\min_{v \in Q_t} (\text{QualifiedName}(v)) \\
\mathcal{L}_t &= \mathcal{L}_{t-1} \mathbin{\Vert} \langle v_t \rangle
\end{aligned}
$$

where $\mathbin{\Vert}$ denotes sequence concatenation, and $\arg\min$ evaluates strict lexicographical byte-order comparison over interned qualified names $\text{QualifiedName}(v) \in \mathcal{S}_{\text{intern}}$.

3. In-Degree Dynamic Reduction Invariant:
Upon scheduling vertex $v_t$, the in-degree state for each successor vertex $w \in \text{Adj}(v_t)$ updates monotonically:

$$
\forall w \in \text{Adj}(v_t), \quad \text{deg}^{-}_{t+1}(w) = \text{deg}^{-}_t(w) - |\{ (v_t, w) \in E \}|
$$

4. Tarjan Strongly Connected Components (SCC) Invariant:
During depth-first traversal with discovery counter $\text{index}_{\text{dfs}}$, each vertex $v \in V$ is assigned discovery index $\text{df\_num}(v) \in \mathbb{N}$ and lowest reachable index $\text{low\_link}(v) \in \mathbb{N}$:

$$
\begin{aligned}
\text{df\_num}(v) &\in \mathbb{N} \\
\text{low\_link}(v) &= \min \left( \{ \text{df\_num}(v) \} \cup \{ \text{low\_link}(w) \mid (v, w) \in E_{\text{tree}} \} \cup \{ \text{df\_num}(w) \mid (v, w) \in E_{\text{back}} \cup E_{\text{cross}} \wedge w \in S \} \right)
\end{aligned}
$$

where $S$ is the active Tarjan DFS stack, $E_{\text{tree}}$ denotes DFS tree edges, $E_{\text{back}}$ denotes back edges, and $E_{\text{cross}}$ denotes cross edges. A vertex $v$ is the root of a maximal strongly connected component if and only if:

$$
\text{IsSCCRoot}(v) \iff \text{low\_link}(v) = \text{df\_num}(v)
$$

5. Condensation DAG Decomposition Invariant:
Let $\mathcal{C} = \text{TarjanSCC}(G) = \{ C_1, C_2, \dots, C_k \}$ denote the partition of $V$ into disjoint maximal strongly connected components ($V = \bigcup_{i=1}^k C_i$ with $C_i \cap C_j = \emptyset$ for $i \ne j$). The condensation graph $G^{\text{scc}} = (\mathcal{C}, E^{\text{scc}})$ is defined as:

$$
E^{\text{scc}} = \{ (C_i, C_j) \in \mathcal{C} \times \mathcal{C} \mid i \ne j \wedge \exists u \in C_i, v \in C_j : (u, v) \in E \}
$$

The condensation graph $G^{\text{scc}}$ is unconditionally acyclic:

$$
\text{IsAcyclic}(G^{\text{scc}}) \equiv \text{true}
$$

6. Cycle Detection & Diagnostic Code Binding Invariant:
For each strongly connected component $C \in \mathcal{C}$, the acyclicity predicate $\text{AcyclicSCC}(C)$ is:

$$
\text{AcyclicSCC}(C) \iff (|C| = 1) \wedge (\forall v \in C, (v, v) \notin E)
$$

Any component violating acyclicity in an acyclic dependency context triggers structured diagnostic error code `E0203` accompanied by the circular directed traceback path $\mathcal{P}_{\text{cycle}}$:

$$
\begin{aligned}
\neg \text{AcyclicSCC}(C) &\implies \exists \mathcal{P}_{\text{cycle}} = \langle v_1, v_2, \dots, v_m, v_1 \rangle \subseteq C \\
&\implies \text{Diagnostic}(C, \text{DiagnosticCode::E0203}, \mathcal{P}_{\text{cycle}}) \in \mathcal{D}_{\text{sink}}
\end{aligned}
$$

Diagnostic sink capacity bounding invariant:

$$
|\mathcal{D}_{\text{sink}}| \ge C_{\text{max\_errors}} \implies \exists D_{\text{term}} \in \mathcal{D}_{\text{sink}} : \text{Code}(D_{\text{term}}) = \text{DiagnosticCode::E0199}
$$

7. Shortest-Path Interconnect Query Invariant:
For any source port handle $u \in \mathcal{V}_{\text{port}}$ and target port handle $v \in \mathcal{V}_{\text{port}}$ in directed interconnect graph $G_{\text{conn}} = (\mathcal{V}_{\text{port}}, \mathcal{E}_{\text{conn}})$:

$$
\text{ShortestPath}(u, v) = \arg\min_{\mathcal{P} \in \text{Paths}(u, v)} |\mathcal{P}|
$$

Deterministic tie-breaking across path candidates of equal minimum hop count evaluates lexicographical ordering on concatenated qualified names:

$$
\mathcal{P}^* = \arg\min_{\mathcal{P} \in \text{MinPaths}(u, v)} \left( \sum_{i=1}^{|\mathcal{P}|} \text{QualifiedName}(\mathcal{P}[i]) \right)
$$

8. Deterministic RFC 4122 UUIDv5 and Arena Node Handle Invariant:
Every lowered graph node $u \in V$ receives an immutable UUIDv5 identifier and a stable arena node handle:

$$
\begin{aligned}
\forall u \in V, \quad \text{UUID}(u) &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(u)) \\
\forall u \in V, \quad \text{Handle}(u) &= \langle \text{ArenaId}, \text{Offset}_u \rangle
\end{aligned}
$$

- **Computational Complexity & Algorithmic Bounds**: Dependency scheduling, component decomposition, and shortest-path routing operations execute strictly within Complexity Class $\mathbf{P}$. The algorithmic bounds across data structures and operations are formalized as follows:
  1. Kahn Topological Sort: Computing initial in-degrees iterates over all vertices and edges in $O(|V| + |E|)$ time. Maintaining the ready queue $Q$ via a binary min-heap keyed by interned qualified names requires $O(|V| \log |V|)$ comparison steps in the worst case, with $O(1)$ scalar integer comparisons for cached interned symbols. Total worst-case execution time is:

$$
T_{\text{Kahn}}(V, E) \in O(|V| \log |V| + |E|) \subseteq O((|V| + |E|) \log |V|)
$$

  2. Tarjan Strongly Connected Components (SCC) Algorithm: Tarjan's algorithm executes depth-first search visiting every vertex and traversing every directed edge exactly once, achieving optimal linear time:

$$
T_{\text{Tarjan}}(V, E) \in O(|V| + |E|)
$$

  Auxiliary memory for the DFS numbering array, low-link array, vertex state flags, and component recursion stack is strictly bounded by $O(|V|)$ contiguous arena space.
  3. Condensation Graph Construction: Building the condensed graph $G^{\text{scc}} = (\mathcal{C}, E^{\text{scc}})$ and pruning intra-component edges executes in $O(|V| + |E|)$ time and $O(|V| + |E|)$ space.
  4. Breadth-First Search (BFS) Shortest-Path Routing: For any port query pair $(u, v)$, BFS explores vertices and edges in unweighted graph $G_{\text{conn}}$ in $O(|V| + |E|)$ time and $O(|V|)$ auxiliary FIFO queue space.
  5. Bounded Work-Stealing Parallel Scheduling: Under bounded work-stealing multithreading scheduled over $N_{\text{max\_workers}}$ worker threads across $K$ independent graph components:

$$
T_{\text{parallel}}(V, E) \in O\left(\frac{|V| + |E|}{N_{\text{max\_workers}}} + \log N_{\text{max\_workers}}\right)
$$

  6. Auxiliary Memory Footprint: Auxiliary memory overhead is strictly $O(|V|)$ beyond contiguous arena node storage and the preallocated diagnostic sink buffer $O(C_{\text{max\_errors}})$, guaranteeing zero uncontrolled dynamic heap allocation.
