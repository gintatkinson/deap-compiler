### REQ-0018: Multi-Line Table Cell Block Token Preservation & Normalization

- **Normative Statement**: The table ingestion engine within the Universal Schema Ingestion Engine shall preserve multi-line cell content, nested bullet points, list items, and inline code spans within CommonMark table cells without dropping formatting, truncating text, or losing structural hierarchy. The engine must normalize embedded HTML line break variants (`<br>`, `<br/>`, `<br />`, `<BR>`, `<BR/>`, `<BR />`) and escaped linefeeds (`\n`, `\r\n`) into canonical newline-delimited block tokens ($\text{SYM}_{\text{LF}}$) via deterministic byte prefix scanning strictly without regular expressions and strictly without exploratory backtracking. Inline code spans delimited by single or multiple backticks shall be preserved verbatim, strictly prohibiting line break normalization, delimiter interpretation, or escape sequence expansion within active code spans. The ingestion engine shall parse nested list items inside table cells into an ordered sequence of structured sub-item tokens, extracting indentation levels into discrete bullet depths bounded by $D_{\text{max\_bullet}} \le 8$, and capturing list marker types including unordered hyphens, asterisks, plus signs, and ordered numeric sequences. The normalizer shall operate with zero dynamic buffer reallocations, projecting token spans directly from contiguous input byte buffers or contiguous arena allocations. When encountering malformed cell structures--including unclosed code spans, unclosed HTML brackets at cell boundaries, illegal ASCII control characters (byte values $b \lt 32$ where $b \notin \{9, 10, 13\}$), or bullet nesting depths exceeding $D_{\text{max\_bullet}}$--the engine shall construct a structured diagnostic record binding diagnostic error code `E0100` (lexical syntax fault) or `E0102` (table cell delimiter synchronization fault) per REQ-0191, recording the exact 1-indexed line and column coordinates and 0-indexed byte span $[p_{\text{start}}, p_{\text{end}}]$. In accordance with Architectural Directive 4, upon encountering a cell normalization fault, the engine shall insert a typed error sentinel token $\bot_{\text{block}}$, preserve preceding valid cell tokens, and resynchronize at the nearest column delimiter pipe (`|`) or record line break without aborting the compilation unit. The normalizer shall enforce a total, non-panicking execution contract with deterministic termination across all inputs, including empty cells, truncated tags, and binary byte streams. When table cells are normalized across multi-file compilation units in parallel, worker tasks shall be dispatched strictly onto a bounded work-stealing thread pool with worker bound $N_{\text{max\_workers}}$ in accordance with Architectural Directive 2. Cell normalization latency and memory efficiency shall be evaluated exclusively in compiled Release mode (`--release`) under isolated benchmark harnesses in accordance with Architectural Directive 5.

- **Formal Invariant**: Let $C_{\text{raw}} = \langle b_0, b_1, \dots, b_{N-1} \rangle$ denote the raw byte stream of a table cell, where $b_i \in \Sigma = \{ b \in \mathbb{N}_0 \mid 0 \le b \le 255 \}$ and $N = |C_{\text{raw}}|$. Let $\text{span}(C_{\text{raw}}) = [p_{\text{start}}, p_{\text{end}}]$ be the byte span within the parent compilation unit. The deterministic block normalizer $\Phi_{\text{block}}$ is formalized as a mapping from the raw cell byte stream to an ordered sequence of structured block tokens:

$$
\Phi_{\text{block}} : \Sigma^* \longrightarrow \mathcal{T}_{\text{block}}^*
$$

where the token domain $\mathcal{T}_{\text{block}}$ is defined by:

$$
\mathcal{T}_{\text{block}} = \{ \text{TextRun}(s), \text{LineBreak}(\text{SYM}_{\text{LF}}), \text{ListItem}(d, m, s), \text{CodeSpan}(s), \bot_{\text{block}} \}
$$

where $d \in \{1, \dots, D_{\text{max\_bullet}}\}$ represents the nesting depth, $m \in \{ \text{Unordered}, \text{Ordered}(k) \}$ represents the list marker kind, and $s$ represents the associated byte slice.

Let $\mathcal{P}_{\text{break}}$ denote the closed set of break prefix byte sequences:

$$
\begin{aligned}
\\mathcal{P}_{\text{break}} = \{ 
  & \langle \text{0x3C}, \text{0x62}, \text{0x72}, \text{0x3E} \rangle, \quad && (\text{literal } \langle \text{br} \rangle) \\
  & \langle \text{0x3C}, \text{0x62}, \text{0x72}, \text{0x2F}, \text{0x3E} \rangle, \quad && (\text{literal } \langle \text{br/} \rangle) \\
  & \langle \text{0x3C}, \text{0x62}, \text{0x72}, \text{0x20}, \text{0x2F}, \text{0x3E} \rangle, \quad && (\text{literal } \langle \text{br /} \rangle) \\
  & \langle \text{0x3C}, \text{0x42}, \text{0x52}, \text{0x3E} \rangle, \quad && (\text{literal } \langle \text{BR} \rangle) \\
  & \langle \text{0x3C}, \text{0x42}, \text{0x52}, \text{0x2F}, \text{0x3E} \rangle, \quad && (\text{literal } \langle \text{BR/} \rangle) \\
  & \langle \text{0x3C}, \text{0x42}, \text{0x52}, \text{0x20}, \text{0x2F}, \text{0x3E} \rangle, \quad && (\text{literal } \langle \text{BR /} \rangle) \\
  & \langle \text{0x5C}, \text{0x6E} \rangle, \quad && (\text{escaped } \texttt{\textbackslash n}) \\
  & \langle \text{0x5C}, \text{0x72}, \text{0x5C}, \text{0x6E} \rangle \quad && (\text{escaped } \texttt{\textbackslash r\textbackslash n})
\}
\end{aligned}
$$

Let $\text{PrefixMatch}(C_{\text{raw}}, p, \pi)$ be the Boolean prefix predicate at byte offset $p$:

$$
\text{PrefixMatch}(C_{\text{raw}}, p, \pi) \iff \big( p + |\pi| \le |C_{\text{raw}}| \;\wedge\; \forall k \in \{0, \dots, |\pi| - 1\}, \; C_{\text{raw}}[p + k] = \pi[k] \big)
$$

The break detection operator $\text{MatchBreak}(C_{\text{raw}}, p)$ evaluates:

$$
\text{MatchBreak}(C_{\text{raw}}, p) = 
\begin{cases}
\pi, & \text{if } \exists \pi \in \mathcal{P}_{\text{break}} \text{ such that } \text{PrefixMatch}(C_{\text{raw}}, p, \pi) \\
\emptyset, & \text{otherwise}
\end{cases}
$$

The deterministic normalizer automaton operates across the state space $Q_{\text{norm}}$:

$$
Q_{\text{norm}} = \{ q_{\text{text}}, q_{\text{code}}, q_{\text{lead}}, q_{\text{error}}, q_{\text{halt}} \}
$$

with deterministic state transition function:

$$
\delta_{\text{norm}} : Q_{\text{norm}} \times \Sigma \longrightarrow Q_{\text{norm}} \times \mathcal{T}_{\text{block}}^*
$$

subject to the following invariant operational rules:

1. Inside backtick code spans ($q_{\text{code}}$), entered upon encountering backtick byte $\text{0x60}$, all characters are emitted verbatim and break detection is strictly suppressed:

$$
\forall p \in \text{Span}(\text{CodeSpan}), \quad \text{MatchBreak}(C_{\text{raw}}, p) \neq \emptyset \implies \text{PreserveLiteral}(p)
$$

2. In ordinary text state ($q_{\text{text}}$), matching any $\pi \in \mathcal{P}_{\text{break}}$ emits a canonical line break token and transitions to line-leading state:

$$
\text{MatchBreak}(C_{\text{raw}}, p) = \pi \neq \emptyset \implies \text{EmitToken}(\text{LineBreak}(\text{SYM}_{\text{LF}})) \;\wedge\; \text{Advance}(|\pi|)
$$

3. In line-leading state ($q_{\text{lead}}$), leading spaces determine bullet nesting depth $d$:

$$
d = \min \left( \left\lfloor \frac{\text{indent}}{2} \right\rfloor + 1, \; D_{\text{max\_bullet}} \right)
$$

where maximum bullet nesting is strictly bounded by $D_{\text{max\_bullet}} = 8$.

Zero Regex Invariant:

$$
\text{RegexEvaluations}(\Phi_{\text{block}}) = 0
$$

Zero Backtracking Invariant:

$$
\text{BacktrackCount}(\Phi_{\text{block}}) = 0
$$

Monotonic Forward Stream Progress Invariant: let $\text{pos}_t \in \{0, \dots, N\}$ denote the byte position of the normalizer at discrete execution step $t$. For all execution steps $t$, the byte position advances monotonically:

$$
\forall t \in \mathbb{N}_0, \quad \text{pos}_{t+1} \ge \text{pos}_t
$$

with strictly positive advance $\text{pos}_{t+1} = \text{pos}_t + |\pi|$ on break token consumption ($|\pi| \ge 2$), and $\text{pos}_{t+1} = \text{pos}_t + 1$ on scalar byte consumption.

Verbatim Code Span Preservation Invariant: for every code span interval $[p_{\text{open}}, p_{\text{close}}]$ delimited by backtick delimiter $\text{0x60}$, the emitted code span token $\text{CodeSpan}(s)$ satisfies strict byte identity:

$$
s = \langle b_{p_{\text{open}} + 1}, \dots, b_{p_{\text{close}} - 1} \rangle
$$

Bijective Round-Trip Equivalence Invariant: let $\Psi_{\text{emit}} : \mathcal{T}_{\text{block}}^* \longrightarrow \Sigma^*$ be the canonical table cell serialization function mapping $\text{LineBreak}(\text{SYM}_{\text{LF}})$ to literal `"<br>"`. For any well-formed cell token sequence $\mathcal{T} = \Phi_{\text{block}}(C_{\text{raw}})$:

$$
\Phi_{\text{block}}(\Psi_{\text{emit}}(\mathcal{T})) = \mathcal{T}
$$

Total Non-Panicking Contract:

$$
\forall C_{\text{raw}} \in \Sigma^*, \quad \text{Panic}(\Phi_{\text{block}}(C_{\text{raw}})) \equiv \text{false} \quad \wedge \quad \Phi_{\text{block}}(C_{\text{raw}}) \in \mathcal{T}_{\text{block}}^*
$$

Diagnostic Taxonomy & Error Containment Invariant: any structural fault encountered during cell normalization triggers structured diagnostics adhering to REQ-0191:

$$
\forall D \in \mathcal{D}_{\text{cell}}, \quad \text{code}(D) \in \{ \text{E0100}, \text{E0102} \} \subset \mathcal{E}_{\text{ingest}}
$$

with total diagnostic emissions bounded by capacity limit $|\mathcal{D}_{\text{cell}}| \le C_{\text{max\_errors}}$.

- **Computational Complexity & Algorithmic Bounds**: The table cell block token normalizer executes strictly within Complexity Class $\mathbf{P}$. Break prefix pattern matching inspects at most $L_{\text{max}} = 6$ bytes per stream position ($L_{\text{max}} = |\langle \text{0x3C}, \text{0x62}, \text{0x72}, \text{0x20}, \text{0x2F}, \text{0x3E} \rangle|$), ensuring $O(1)$ scalar operations per byte position. Because forward scanning is strictly monotonic ($\text{pos}_{t+1} \ge \text{pos}_t$) and regular expressions and exploratory backtracking are strictly prohibited ($\text{RegexEvaluations} = 0, \text{BacktrackCount} = 0$), each byte in the raw cell input stream $C_{\text{raw}}$ of length $N = |C_{\text{raw}}|$ is inspected at most $O(1)$ times. Normalization across the cell executes in deterministic $O(N)$ linear time. Bullet indentation scanning operates in $O(S)$ time where $S \le N$ is the leading whitespace byte count, and bullet depth computation executes in $O(1)$ arithmetic operations. Code span scanning is strictly linear $O(K)$ in code span length $K$. For a table containing $M$ rows and $K_{\text{cols}}$ columns, total tabular cell normalization executes in $O(M \cdot K_{\text{cols}} \cdot \bar{N}_{\text{cell}}) = O(N_{\text{total}})$ linear time with respect to total tabular source bytes $N_{\text{total}}$. When executed across a bounded work-stealing thread pool with $N_{\text{max\_workers}}$ workers, parallel execution time scales as $O(N_{\text{total}} / N_{\text{max\_workers}})$. Memory complexity is strictly bounded by $O(1)$ auxiliary space when streaming token events directly to a consumer sink. When token arrays are materialized, token slice descriptors $(p_{\text{start}}, p_{\text{end}})$ reference the immutable source buffer directly, incurring zero dynamic heap reallocations and requiring $O(T_{\text{count}}) \le O(N)$ bounded arena storage. The problem is strictly deterministic and lies entirely within Complexity Class $\mathbf{P}$, operating well below the NP-completeness frontiers (NP-1 through NP-8).

- **Verification & Conformance Criteria**: Deterministic compliance shall be validated via automated integration and benchmark test suites using synthetic MBSE schema elements (`Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`). The primary test suite shall verify: (1) multi-line cells containing HTML break variants (`<br>`, `<br/>`, `<br />`, `<BR>`, `<BR/>`, `<BR />`) normalize to canonical $\text{SYM}_{\text{LF}}$ line breaks with 100% token preservation, (2) cells containing escaped linefeeds (`\n`, `\r\n`) correctly normalize without corrupting subsequent text, (3) nested bulleted list items with indentation depths 1 through 3 (e.g., `- Item_1<br>  - Item_2<br>    - Item_3`) correctly parse into structured `ListItem` tokens with exact depths $d \in \{1, 2, 3\}$, (4) inline code spans containing embedded `<br>` or pipe characters (e.g., `` `Port_A<br>Port_B` `` or `` `x | y` ``) preserve interior characters verbatim without normalizing breaks or splitting cells on pipes, and (5) round-trip serialization satisfies $\Phi_{\text{block}}(\Psi_{\text{emit}}(\mathcal{T})) = \mathcal{T}$ with zero diff churn. Malformed input test suites shall verify that unclosed code spans (e.g., `` `Port_Alpha `` unclosed before cell delimiter `|`), illegal ASCII control characters ($b \lt 32$ where $b \notin \{9, 10, 13\}$), or bullet depth overflow ($d \gt 8$) construct structured diagnostic records binding error code `E0100` or `E0102` with exact byte span coordinates and non-panicking recovery, inserting typed sentinel $\bot_{\text{block}}$ and resynchronizing at the next cell delimiter pipe (`|`). Static call graph analysis and symbol inspection shall assert that zero regular expression libraries or backtracking engines are linked or invoked ($\text{RegexEvaluations} = 0$). Performance benchmarks executed strictly in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from logic tests shall assert that cell normalization throughput exceeds 50 MB/s, total compiler execution latency remains below 25 ms, and scaling exhibits zero quadratic degradation ($T(2N) / T(N) \le 2.05$). Determinism shall be asserted by verifying 0-byte diff churn across repeated compilations of identical tabular inputs.
