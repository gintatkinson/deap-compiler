### REQ-0020: Disambiguation of Array Indexing Syntax in Tabular Schemas

- **Normative Statement**: The CommonMark table parser and lexical scanner within the Universal Schema Ingestion Engine shall implement deterministic disambiguation of array indexing syntax across all tabular MBSE schemas. When ingesting cell tokens representing structural identifiers, component references, port bindings, or interconnect endpoints, the ingestion engine must decompose bracketed identifier strings into a distinct base symbol identifier and an integer index qualifier without lexical backtracking or confusion with type multiplicity brackets (`Type[1..*]`). The engine shall support four distinct syntactic forms: (1) scalar unindexed identifiers (`base`, e.g., `part_alpha`), which shall be lowered directly into a scalar symbol reference $`\langle \text{base}, \bot \rangle`$; (2) single-dimensional indexed identifiers (`base[index]`, e.g., `part_alpha[0]`, `port_1[4]`), which shall be decomposed into base identifier `part_alpha` and non-negative integer index qualifier $`k \in \mathbb{N}_0`$; (3) multi-dimensional indexed identifiers (`base[i_1][i_2]...[i_K]`, e.g., `matrix_node[2][3]`), bounded by maximum array dimensionality $`K \le K_{\text{max\_rank}} = 8`$, which shall be decomposed into base identifier `matrix_node` and an ordered tuple of integer index qualifiers $`\langle i_1, i_2, \dots, i_K \rangle`$; and (4) type multiplicity brackets (`Type[lower..upper]`, e.g., `Classifier_Alpha[1..*]`, `DataType_Beta[0..1]`), which shall be decomposed into a classifier type symbol and multiplicity range bounds $`\langle L, U \rangle`$ rather than instance array indices. The ingestion engine shall enforce lexical discrimination between instance array indexing and type multiplicity brackets based on token content and column context: if the bracket contents contain the range delimiter `..` or the unbounded wildcard `*`, the token shall be classified as type multiplicity syntax $`\theta_{\text{multiplicity}}`$` and rejected if present in an instance column; if the bracket contents contain strictly decimal digits `$`[0-9]+`$`, the token shall be classified as array indexing syntax `$`\theta_{\text{array}}`$. In accordance with Architectural Directive 3 and REQ-0036, the extracted base identifier string slice shall be interned into the global scalar symbol interner pool to yield an immutable `SymbolId`, while the parsed integer index qualifier shall be stored as an unboxed 32-bit unsigned integer value ($`k \in [0, 2^{32}-1]`$) within the resulting AST node. If an identifier column contains bracket content that is not purely unsigned decimal digits (e.g., non-digit characters `name[abc]`, unclosed brackets `name[0`, empty brackets `name[]`, negative integers `name[-1]`, or floating-point literals `name[1.5]`), or if trailing non-whitespace characters follow the closing bracket (e.g., `name[0]extra`), or if the index value overflows the unsigned 32-bit integer range ($`k \ge 2^{32}`$), the engine shall construct a structured diagnostic record binding diagnostic error code `E0102` (table row lexical syntax error) per REQ-0191 with precise byte span $`[p_{\text{start}}, p_{\text{end}}]`$`, line, and column coordinates, substitute an error sentinel `$`\bot_{\text{ident}}`$ for the malformed cell, and engage synchronization token recovery per REQ-0016. The parser must execute under a total, deterministic, non-panicking execution contract with zero unhandled panics or unwinding exceptions across all malformed inputs.

- **Formal Invariant**: Let $`\Sigma`$` denote the ASCII byte alphabet. Let `$`\Sigma_{\text{alpha}} \subset \Sigma`$` denote the set of ASCII alphabetic characters (`$`[0\text{x}41, 0\text{x}5\text{A}] \cup [0\text{x}61, 0\text{x}7\text{A}]`$`) and `$`\Sigma_{\text{digit}} \subset \Sigma`$` denote the set of ASCII decimal digits (`$`[0\text{x}30, 0\text{x}39]`$`). Let `$`\Sigma_{\text{ident\_start}} = \Sigma_{\text{alpha}} \cup \{ \text{\_} \}`$` and `$`\Sigma_{\text{ident\_tail}} = \Sigma_{\text{ident\_start}} \cup \Sigma_{\text{digit}}`$`. An identifier string `$`\text{Ident} \in \Sigma^+`$ satisfies:

```math
\text{Ident} \in \Sigma_{\text{ident\_start}} \cdot \Sigma_{\text{ident\_tail}}^*
```

A non-empty decimal digit sequence $`\text{Digits} \in \Sigma_{\text{digit}}^+`$ satisfies:

```math
\text{Digits} \in \{ d_0 d_1 \dots d_{m-1} \mid m \ge 1, \, d_i \in \Sigma_{\text{digit}} \}
```

The unsigned integer valuation function $`\text{Val} : \Sigma_{\text{digit}}^+ \to \mathbb{N}_0`$ is defined as:

```math
\text{Val}(d_0 d_1 \dots d_{m-1}) = \sum_{i=0}^{m-1} (d_i - 0\text{x}30) \cdot 10^{m - 1 - i}
```

Let $`S \in \Sigma^*`$` denote a trimmed cell token string. The deterministic array decomposition operator `$`\theta_{\text{array}} : \Sigma^* \to (\Sigma^+ \times (\mathbb{N}_0 \cup \{ \bot \})) \cup \{ \bot_{\text{err}} \}`$ is defined as:

```math
\theta_{\text{array}}(S) = 
\begin{cases}
\langle \text{base}(S), \text{index}(S) \rangle, & \text{if } \text{IsIndexedIdentifier}(S) \;\wedge\; \text{Val}(\text{index\_str}(S)) \lt 2^{32} \\
\langle S, \bot \rangle, & \text{if } \text{IsScalarIdentifier}(S) \\
\bot_{\text{err}}, & \text{otherwise}
\end{cases}
```

The single-dimensional indexed identifier predicate $`\text{IsIndexedIdentifier}(S)`$ is defined as:

```math
\text{IsIndexedIdentifier}(S) \iff \exists u \in \Sigma_{\text{ident\_start}} \cdot \Sigma_{\text{ident\_tail}}^*, \, v \in \Sigma_{\text{digit}}^+ \text{ s.t. } S = u \mathbin{\Vert} \text{"["} \mathbin{\Vert} v \mathbin{\Vert} \text{"]"}
```

where $`\text{base}(S) = u`$`, `$`\text{index\_str}(S) = v`$`, and `$`\text{index}(S) = \text{Val}(v)`$.

The scalar identifier predicate $`\text{IsScalarIdentifier}(S)`$ is defined as:

```math
\text{IsScalarIdentifier}(S) \iff S \in \Sigma_{\text{ident\_start}} \cdot \Sigma_{\text{ident\_tail}}^*
```

For multi-dimensional indexing with array dimensionality $`K \in \{1, \dots, K_{\text{max\_rank}}\}`$` where `$`K_{\text{max\_rank}} = 8`$`, the generalized array decomposition operator `$`\theta_{\text{multi\_array}}`$ satisfies:

```math
\theta_{\text{multi\_array}}(S) = 
\begin{cases}
\langle u, \langle \text{Val}(v_1), \dots, \text{Val}(v_K) \rangle \rangle, & \text{if } S = u \mathbin{\Vert} \text{"["} \mathbin{\Vert} v_1 \mathbin{\Vert} \text{"]"} \mathbin{\Vert} \dots \mathbin{\Vert} \text{"["} \mathbin{\Vert} v_K \mathbin{\Vert} \text{"]"} \;\wedge\; 1 \le K \le K_{\text{max\_rank}} \\
\bot_{\text{err}}, & \text{otherwise}
\end{cases}
```

Let $`\text{RangeExpr}`$ define the grammar of type multiplicity range expressions:

```math
\text{RangeExpr} = (v_L \mathbin{\Vert} \text{".."} \mathbin{\Vert} v_U) \;\vee\; (v_L \mathbin{\Vert} \text{"..*"}) \;\vee\; \text{"*"} \;\vee\; v_L
```

where $`v_L, v_U \in \Sigma_{\text{digit}}^+`$`. The type multiplicity decomposition operator `$`\theta_{\text{multiplicity}} : \Sigma^* \to (\Sigma^+ \times (\mathbb{N}_0 \times (\mathbb{N}_0 \cup \{ \infty \}))) \cup \{ \bot_{\text{err}} \}`$ satisfies:

```math
\theta_{\text{multiplicity}}(S) = 
\begin{cases}
\langle \text{Type}(S), \langle L(S), U(S) \rangle \rangle, & \text{if } S = \text{Ident} \mathbin{\Vert} \text{"["} \mathbin{\Vert} \text{RangeExpr} \mathbin{\Vert} \text{"]"} \\
\langle S, \langle 1, 1 \rangle \rangle, & \text{if } S \in \Sigma_{\text{ident\_start}} \cdot \Sigma_{\text{ident\_tail}}^* \\
\bot_{\text{err}}, & \text{otherwise}
\end{cases}
```

The Language Disjointness Invariant establishes that array indexing syntax and multiplicity range syntax form disjoint regular languages:

```math
\mathcal{L}(\text{IndexedIdentifier}) \cap \mathcal{L}(\text{MultiplicityRangeType}) = \emptyset
```

Let $`\kappa \in \{ \text{ColKind}_{\text{Instance}}, \text{ColKind}_{\text{Type}} \}`$` denote the semantic classification of the table column containing cell `$`S`$. Contextual evaluation obeys:

```math
\text{Dispatch}(S, \kappa) = 
\begin{cases}
\theta_{\text{array}}(S), & \text{if } \kappa = \text{ColKind}_{\text{Instance}} \\
\theta_{\text{multiplicity}}(S), & \text{if } \kappa = \text{ColKind}_{\text{Type}}
\end{cases}
```

Diagnostic Error Code Binding Invariant: Any syntactic or semantic failure during token disambiguation triggers a structured diagnostic record binding error code `E0102` in accordance with REQ-0191:

```math
\begin{aligned}
\kappa = \text{ColKind}_{\text{Instance}} \;\wedge\; \theta_{\text{array}}(S) = \bot_{\text{err}} &\implies \exists D \in \mathcal{D} : \text{Code}(D) = \text{DiagnosticCode::E0102} \\
\kappa = \text{ColKind}_{\text{Type}} \;\wedge\; \theta_{\text{multiplicity}}(S) = \bot_{\text{err}} &\implies \exists D \in \mathcal{D} : \text{Code}(D) = \text{DiagnosticCode::E0102} \\
\text{IsIndexedIdentifier}(S) \;\wedge\; \text{Val}(\text{index\_str}(S)) \ge 2^{32} &\implies \exists D \in \mathcal{D} : \text{Code}(D) = \text{DiagnosticCode::E0102} \\
S = u \mathbin{\Vert} \text{"["} \mathbin{\Vert} v_1 \mathbin{\Vert} \text{"]"} \mathbin{\Vert} \dots \mathbin{\Vert} \text{"["} \mathbin{\Vert} v_K \mathbin{\Vert} \text{"]"} \;\wedge\; K \gt K_{\text{max\_rank}} &\implies \exists D \in \mathcal{D} : \text{Code}(D) = \text{DiagnosticCode::E0102}
\end{aligned}
```

- **Computational Complexity & Algorithmic Bounds**: Disambiguation of array indexing syntax executes within Complexity Class $`\mathbf{P}`$`. The disambiguation scanner operates via a single-pass deterministic scan over the input token string `$`S`$` of byte length `$`|S|`$`. Because character evaluation advances the stream pointer monotonically without lookbehind or backtracking, each byte `$`b_p \in S`$` is visited exactly once (`$`O(1)`$ operations per byte). Parsing of the base identifier slice, detection of the opening bracket `[`, verification of decimal digits, integer accumulation via Horner's method, and validation of the closing bracket `]` execute in deterministic $`O(|S|)`$` linear time in token length. Given the table cell string length bound `$`|S| \le L_{\text{max\_cell}} = 256`$` bytes, disambiguation executes in deterministic `$`O(1)`$` constant time per cell token. For an entire tabular schema containing `$`M`$` rows and `$`C`$` columns (`$`1 \le C \le C_{\text{max\_cols}} = 32`$`) with total table byte size `$`N = \sum_{i=1}^M \sum_{j=0}^{C-1} |c_{i, j}|`$, the total execution time across all cells is strictly bounded by:

```math
O\left( \sum_{i=1}^M \sum_{j=0}^{C-1} |c_{i, j}| \right) = O(N)
```

yielding overall deterministic $`O(N)`$` linear time. Auxiliary space complexity is strictly bounded by `$`O(K_{\text{max\_rank}}) = O(1)`$ on the stack for storing up to 8 index integer values during multi-dimensional indexing. In accordance with Architectural Directive 3 and REQ-0036, interning the base identifier string slice into the global symbol interner pool is the sole memory allocation performed during token lowering, resulting in zero dynamic heap allocations in the character scanning inner loop.

- **Verification & Conformance Criteria**: Automated test suites shall verify compliance against synthetic CommonMark tables containing abstract MBSE schema entities (e.g., `Package_0`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`). Conformance shall be validated through the following deterministic test gates: (1) Positive Array Indexing Disambiguation Gate: Ingest cell tokens `item_alpha[0]`, `part_beta[42]`, and `port_gamma[65535]`; assert that the lexer correctly extracts base symbols (`item_alpha`, `part_beta`, `port_gamma`) and index integers ($`0`$`, `$`42`$`, `$`65535`$) with 100% classification accuracy into `IndexedReferenceNode`. (2) Scalar Identifier Gate: Ingest cell tokens `part_alpha`, `subsystem_0`, and `port_in`; assert that the lexer extracts base symbols with null index ($`\bot`$) without engaging array indexing logic. (3) Multi-Dimensional Array Gate: Ingest cell tokens `matrix_node[2][5]` and `tensor_block[1][0][7]`; assert decomposition into base symbol and ordered index vectors $`\langle 2, 5 \rangle`$` and `$`\langle 1, 0, 7 \rangle`$ respectively. (4) Type Multiplicity Separation Gate: Ingest type column tokens `Classifier_Alpha[1..*]`, `Interface_Beta[0..1]`, `DataType_Gamma[*]`, and `Type_Delta[4]`; assert that the lexer decomposes them into classifier symbols and multiplicity ranges ($`\langle 1, \infty \rangle`$`, `$`\langle 0, 1 \rangle`$`, `$`\langle 0, \infty \rangle`$`, `$`\langle 4, 4 \rangle`$) without confounding them with instance array indexing. (5) Malformed Syntax and Error Code Binding Gate: Ingest malformed tokens including unclosed brackets (`part_alpha[0`), empty brackets (`part_alpha[]`), non-digit index characters (`part_alpha[index]`, `part_alpha[foo_bar]`), negative integers (`part_alpha[-1]`), floating-point numbers (`part_alpha[1.5]`), trailing garbage (`part_alpha[0]suffix`), range syntax in instance columns (`part_alpha[1..*]`), integer overflow (`part_alpha[4294967296]`), and rank overflow (`node[0][1][2][3][4][5][6][7][8]`); assert that each malformed token triggers a structured diagnostic record binding diagnostic error code `E0102` per REQ-0191 with exact byte coordinates $`[p_{\text{start}}, p_{\text{end}}]`$` and remediation hints. (6) Synchronization Token Recovery Gate: Verify that upon detecting a malformed bracketed cell in row `$`R_i`$`, the parser substitutes `$`\bot_{\text{ident}}`$, preserves preceding valid cells, resynchronizes at the next column delimiter pipe (`|`) or record delimiter (`\n`), and successfully ingests subsequent rows $`R_{i+1}`$ without aborting compilation. (7) Panic-Free Contract: Fuzz testing over 100,000 randomized and pathological bracketed strings shall verify 100% total-function completion with zero panics or unhandled exceptions.
