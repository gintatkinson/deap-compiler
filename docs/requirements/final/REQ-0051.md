### REQ-0051: Incremental Compilation Cache Invalidation via Module Dependency DAG

- **Normative Statement**: The compiler core metamodel and AST graph engine shall implement a deterministic incremental compilation caching subsystem structured upon an explicit module dependency directed acyclic graph (DAG). The compilation engine must compute a 64-bit cryptographic or collision-resistant content hash for each modular compilation unit (module) upon source ingestion, capturing the exact normalized source bytes, lexed tokens, and syntactic AST structures. The compiler shall construct and maintain the module dependency DAG $`G = (V, E)`$, wherein each vertex represents an ingested module and each directed edge $`(U, V) \in E`$ denotes that downstream module $`V`$ depends upon upstream module $`U`$.

  For each module $`M \in V`$, the incremental engine shall compute a composite module state hash $`H_{\text{state}}(M)`$ that deterministically combines the module's own source hash $`H_{\text{source}}(M)`$ with the cumulative state hashes of all its direct upstream dependencies $`\text{Deps}(M)`$. The state hash propagation shall proceed in deterministic topological sort order over $`G`$. During an incremental compilation cycle, the compiler shall compare each module's freshly evaluated state hash against the cached state hash $`H_{\text{cached}}(M)`$ persisted in the compilation cache manifest. If $`H_{\text{state}}(M) = H_{\text{cached}}(M)`$, the compiler must bypass re-analysis and re-emission for module $`M`$, loading the pre-lowered AST subgraphs, typed symbol tables, and generated artifacts directly from the persistent cache without disk re-reads, re-lexing, or re-parsing.

  If any module $`M`$ exhibits source modification such that $`H_{\text{source}}(M) \ne H_{\text{cached\_source}}(M)`$, or if any of its upstream dependencies change such that $`H_{\text{state}}(M) \ne H_{\text{cached}}(M)`$, the compiler shall mark module $`M`$ as invalidated and immediately compute the forward reachability closure (the transitive downstream dependent set) across $`G`$. The compiler must invalidate the cache entries for module $`M`$ and for all modules within its transitive downstream dependent set, scheduling strictly these affected modules for re-analysis, type-checking, AST lowering, and artifact re-emission. All modules strictly outside the transitive invalidation closure shall be preserved and reused directly from the cache.

  All recomputed state hashes, source hashes, and artifact descriptors must be committed atomically to the persistent compilation cache manifest (e.g., `.pipeline/incremental-cache.json`) upon successful completion of the compilation pass, guaranteeing that abnormal termination leaves the pre-existing cache intact without corruption. If a dependency cycle is detected during DAG construction or topological sorting, the compiler shall reject the invalid dependency graph, record structured diagnostic error code `E0203` with the exact cyclic dependency path, and terminate gracefully in accordance with Architectural Directive 5. If the cache manifest is missing, unreadable, or corrupted, the compiler shall record diagnostic error code `E0200`, discard the corrupted cache directory, and execute a complete clean build from scratch.

  Every module node and cache entry shall receive a deterministic RFC 4122 UUIDv5 identifier hashed from the compiler namespace OID and canonical module qualified path (e.g., `Package_0::Module_Alpha`), adhering to Architectural Directive 1 and REQ-0010. Re-analysis of invalidated independent modules shall be scheduled concurrently onto a bounded work-stealing thread pool with worker bound $`N_{\text{max\_workers}}`$ using thread-isolated arena allocators, adhering to Architectural Directive 2 and REQ-0012. Interning of module symbol identifiers into the global symbol interner pool shall constitute the sole permitted exception to zero-copy memory management per Architectural Directive 3 and REQ-0036. The compilation engine shall implement synchronization token error recovery during module dependency resolution per Architectural Directive 4, REQ-0013, and REQ-0016, accumulating diagnostics rather than terminating on the first invalid reference. The compiler must enforce Architectural Directive 5, guaranteeing a total, non-panicking execution contract with structured error propagation, evaluating latency (`< 25 ms`) and peak RSS memory (`< 100 MB`) performance gates exclusively in compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per REQ-0011 and REQ-0196. All illustrative examples, diagnostics, and test fixtures shall strictly employ synthetic abstract MBSE placeholders (e.g., `Package_0`, `Module_Alpha`, `Module_Beta`, `Module_Gamma`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`) with zero domain contamination.

- **Formal Invariant**: Let $`G = (V, E)`$ be the module dependency directed acyclic graph, where $`V`$ is the finite set of modules and directed edge $`(U, V) \in E`$ denotes that module $`V`$ directly depends on upstream module $`U`$.

  Let $`\text{Deps}(M)`$ denote the set of immediate upstream dependencies of module $`M \in V`$:

$$
\text{Deps}(M) = \{ U \in V \mid (U, M) \in E \}
$$

  Let $`\text{Dependents}(M)`$ denote the set of immediate downstream dependents of module $`M \in V`$:

$$
\text{Dependents}(M) = \{ W \in V \mid (M, W) \in E \}
$$

  The transitive downstream dependent set $`\text{TransitiveDependents}(M) \subseteq V`$ is defined as the non-empty forward reachability set:

$$
\text{TransitiveDependents}(M) = \{ D \in V \mid M \to^+ D \}
$$

  where $`M \to^+ D`$ denotes the existence of a directed path of length $`\ge 1`$ from $`M`$ to $`D`$ in $`G`$. The reflexive-transitive reachability closure $`\text{Closure}(M)`$ is:

$$
\text{Closure}(M) = \{ M \} \cup \text{TransitiveDependents}(M) = \{ D \in V \mid M \to^* D \}
$$

  Let $`\text{Hash64} : \{0, 1\}^* \to \{0, 1\}^{64}`$ be a deterministic 64-bit collision-resistant hashing function. Let $`H_{\text{source}}(M) \in \{0, 1\}^{64}`$ be the 64-bit cryptographic digest of the canonical source content of module $`M`$.

  The composite module state hash $`H_{\text{state}}(M) \in \{0, 1\}^{64}`$ satisfies:

$$
H_{\text{state}}(M) = \text{Hash64}\left( H_{\text{source}}(M) \mathbin{\Vert} \bigoplus_{D \in \text{Deps}(M)} H_{\text{state}}(D) \right)
$$

  where $`\mathbin{\Vert}`$ denotes byte concatenation and $`\bigoplus`$ denotes the bitwise XOR reduction operator over all upstream dependency state hashes, with $`\bigoplus_{D \in \emptyset} H_{\text{state}}(D) = 0^{64}`$.

  Topological Evaluation Invariant: Let $`\pi = (v_1, v_2, \dots, v_{|V|})`$ be a valid topological sort of $`G`$ such that:

$$
\forall (v_j, v_k) \in E \implies j \lt k
$$

  The evaluation of $`H_{\text{state}}(v_k)`$ occurs strictly after $`H_{\text{state}}(v_j)`$ has been evaluated for all $`v_j \in \text{Deps}(v_k)`$:

$$
\forall k \in \{1, 2, \dots, |V|\}, \quad \forall U \in \text{Deps}(v_k), \quad \text{IsEvaluated}(H_{\text{state}}(U)) = \text{true}
$$

  Cache Hit Bypass Invariant: Let $`H_{\text{cached}}(M)`$ denote the persisted state hash from the previous compilation cycle. If the state hash matches the cached state hash, the module artifacts are reused without recompilation:

$$
H_{\text{state}}(M) = H_{\text{cached}}(M) \implies \text{ReuseCachedArtifacts}(M) \quad \wedge \quad T_{\text{recompile}}(M) = 0
$$

  Downstream Transitive Invalidation Invariant: If the source hash of module $`M`$ differs from its cached source hash $`H_{\text{cached\_source}}(M)`$, all transitive downstream dependents of $`M`$ are invalidated:

$$
H_{\text{source}}(M) \ne H_{\text{cached\_source}}(M) \implies \forall D \in \text{TransitiveDependents}(M), \quad \text{InvalidateCache}(D)
$$

  State Hash Invalidation Completeness Invariant: A module $`M`$ is recompiled if and only if its state hash diverges from the cache:

$$
\text{MustRecompile}(M) \iff H_{\text{state}}(M) \ne H_{\text{cached}}(M)
$$

  The set of recompiled modules $`\mathcal{R} \subseteq V`$ for a mutated source set $`\mathcal{M}_{\text{mut}} = \{ M \in V \mid H_{\text{source}}(M) \ne H_{\text{cached\_source}}(M) \}`$ satisfies:

$$
\mathcal{R} = \bigcup_{M \in \mathcal{M}_{\text{mut}}} \text{Closure}(M) = \{ D \in V \mid \exists M \in \mathcal{M}_{\text{mut}}, \; M \to^* D \}
$$

  Cache Semantic Equivalence & Zero Churn Invariant: Let $`\mathcal{A}_{\text{inc}}`$ denote the AST synthesized via incremental compilation and $`\mathcal{A}_{\text{clean}}`$ denote the AST produced by an exhaustive non-incremental compilation from scratch. The incremental pipeline guarantees total structural identity and zero diff churn:

$$
\begin{aligned}
\forall M \in V \setminus \mathcal{R}, \quad \text{AST}_{\text{cached}}(M) &\equiv \text{AST}_{\text{clean}}(M) \\
\forall M \in \mathcal{R}, \quad \text{AST}_{\text{recomputed}}(M) &\equiv \text{AST}_{\text{clean}}(M) \\
\text{MerkleRoot}(\mathcal{A}_{\text{inc}}) &= \text{MerkleRoot}(\mathcal{A}_{\text{clean}})
\end{aligned}
$$

  Atomic Manifest Commit Invariant: Let $`\mathcal{M}_{\text{manifest}}`$ denote the persistent compilation cache manifest and $`\mathcal{M}_{\text{staged}}`$ denote the newly computed manifest in volatile memory. Writing the manifest to disk satisfies atomic transaction semantics:

$$
\text{Commit}(\mathcal{M}_{\text{staged}}) \implies \left( \mathcal{M}_{\text{manifest}} \leftarrow \mathcal{M}_{\text{staged}} \quad \text{via atomic filesystem rename} \right)
$$

  Diagnostic Code Binding Invariant:
  1. Dependency Cycle Detection: If the module dependency graph contains any directed cycle, the compiler records structured diagnostic `E0203`:

$$
\left( \exists (u_1, u_2, \dots, u_k) \subseteq V : (u_k, u_1) \in E \wedge \bigwedge_{i=1}^{k-1} (u_i, u_{i+1}) \in E \right) \implies \text{Diagnostic}(\text{span}(u_1), \text{DiagnosticCode::E0203}, \text{CircularModuleDependency}) \in \mathcal{D}
$$

  2. Cache Corruption or Deserialization Failure: If the manifest or cached artifact records fail integrity verification, the compiler emits structured diagnostic `E0200` and resets the cache:

$$
\text{IsCorrupt}(\mathcal{M}_{\text{manifest}}) \implies \text{Diagnostic}(\text{span}(\text{manifest}), \text{DiagnosticCode::E0200}, \text{CacheManifestCorrupted}) \in \mathcal{D} \quad \wedge \quad \mathcal{R} = V
$$

  Deterministic UUIDv5 & Symbol Interning Invariant: Every module node $`M \in V`$ and cache record receives a deterministic RFC 4122 UUIDv5 identifier and interned symbol handle:

$$
\begin{aligned}
\forall M \in V, \quad \text{UUID}(M) &= \text{UUIDv5}(\text{OID}_{\text{DEAP}}, \text{FQN}(M)) \\
\forall M \in V, \quad \text{SymbolHandle}(M) &\in \mathcal{S}_{\text{interner}}
\end{aligned}
$$

- **Computational Complexity & Algorithmic Bounds**: The incremental compilation cache invalidation engine operates within Complexity Class $`\mathbf{P}`$. The asymptotic upper bounds for each phase across graph size parameters $`V = |V|`$ (module count) and $`E = |E|`$ (module dependency edge count) are formalized as follows:
  1. Module Dependency DAG Construction: Parsing module import declarations and instantiating vertices and directed edges in the adjacency list executes in $`O(|V| + |E|)`$ deterministic time.
  2. Cycle Detection & Topological Sort: Traversal via Tarjan's strongly connected components (SCC) algorithm or Kahn's in-degree queue algorithm executes in $`O(|V| + |E|)`$ time and $`O(|V| + |E|)`$ auxiliary space.
  3. Source Hash Computation: For modified modules $`\mathcal{M}_{\text{mut}}`$, computing 64-bit source hashes $`H_{\text{source}}(M)`$ executes in $`O(B_{\text{mut}})`$ time, where $`B_{\text{mut}} = \sum_{M \in \mathcal{M}_{\text{mut}}} |\text{Bytes}(M)|`$.
  4. State Hash Propagation: Propagating $`H_{\text{state}}(M)`$ in topological order over $`G`$ evaluates the XOR reduction over $`\text{Deps}(M)`$ for each module. The aggregate time across all vertices satisfies:

$$
T_{\text{propagate}} = \sum_{M \in V} O(1 + |\text{Deps}(M)|) = O(|V| + |E|)
$$

  5. Transitive Invalidation Closure: Computing $`\mathcal{R} = \bigcup_{M \in \mathcal{M}_{\text{mut}}} \text{Closure}(M)`$ via breadth-first search (BFS) on the forward adjacency list executes in $`O(|\mathcal{R}| + |E_{\mathcal{R}}|) \subseteq O(|V| + |E|)`$ time.
  6. Cache Hit Lookup & Artifact Reuse: For all unimpacted modules $`M \in V \setminus \mathcal{R}`$, querying the hash manifest and reusing cached AST subgraphs executes in $`O(1)`$ amortized time per module, yielding $`O(|V \setminus \mathcal{R}|) \subseteq O(|V|)`$ aggregate lookup time.
  7. Parallel Invalidation Re-analysis: Scheduling re-analysis of the invalidated modules $`\mathcal{R}`$ across $`N_{\text{max\_workers}}`$ threads in the bounded work-stealing thread pool achieves wall-clock recomputation time bounded by:

$$
T_{\text{recompute}}(\mathcal{R}) \in O\left( \frac{\sum_{M \in \mathcal{R}} T_{\text{compile}}(M)}{N_{\text{max\_workers}}} + |V| + |E| \right)
$$

  8. Atomic Cache Manifest Persistence: Serializing updated module descriptors and committing the manifest via atomic filesystem rename requires $`O(|V|)`$ time and $`O(|V|)`$ auxiliary space.
  9. Space Complexity: The auxiliary memory required for the module DAG adjacency lists, in-degree arrays, topological traversal queues, and manifest hash tables is strictly bounded by $`O(|V| + |E|)`$ linear space.

- **Verification & Conformance Criteria**: Deterministic verification shall be executed via automated test suites operating on synthetic MBSE compilation units (`Package_0` comprising modular units `Module_Alpha`, `Module_Beta`, `Module_Gamma`, `Module_Delta`, `Classifier_Alpha`, `Port_1`, `Flow_A`, `param_x : Real`). Conformance shall be validated across the following mandatory test gates:
  1. Single Module Mutation & Transitive Propagation Gate: Configure a linear dependency chain `Module_Alpha -> Module_Beta -> Module_Gamma`, alongside an independent disjoint module `Module_Delta`. Mutate `Module_Alpha`. Assert that re-analysis counters verify that `Module_Alpha`, `Module_Beta`, and `Module_Gamma` are re-analyzed and re-emitted, while `Module_Delta` is loaded directly from cache with zero re-parsing.
  2. Intermediate Module Mutation Gate: Mutate intermediate module `Module_Beta` in the chain `Module_Alpha -> Module_Beta -> Module_Gamma`. Assert that `Module_Alpha` and `Module_Delta` are 100% cache hits, and strictly `Module_Beta` and `Module_Gamma` are re-compiled.
  3. Disjoint Leaf Mutation Gate: Mutate `Module_Delta`. Assert that only `Module_Delta` is re-compiled, while `Module_Alpha`, `Module_Beta`, and `Module_Gamma` are reused from cache without modification.
  4. Clean No-Op Invalidation Gate: Execute compilation on an unmodified workspace where all source hashes match $`H_{\text{cached\_source}}`$. Assert that zero modules undergo re-lexing, re-parsing, or re-lowering, with 100% cache hits and total execution latency bounded by manifest verification.
  5. Circular Dependency Diagnostic Gate: Inject a cyclical import relation (`Module_Alpha` depends on `Module_Beta`, and `Module_Beta` depends on `Module_Alpha`). Assert that DAG cycle detection triggers deterministically, recording structured diagnostic error code `E0203` with the exact cycle path (`Module_Alpha -> Module_Beta -> Module_Alpha`), terminating gracefully without panicking or infinite recursion per Architectural Directive 5.
  6. Corrupted Manifest Recovery Gate: Inject byte corruption or truncate `.pipeline/incremental-cache.json`. Assert that the compiler detects the corrupted manifest, records structured diagnostic error code `E0200`, discards the invalid cache directory, and executes a full clean compilation from scratch, regenerating a valid manifest.
  7. Bitwise Parity & Merkle Root Identity Gate: Assert that the AST $`\mathcal{A}_{\text{inc}}`$ and emitted artifacts resulting from an incremental build match the AST $`\mathcal{A}_{\text{clean}}`$ and emitted artifacts from a clean scratch build with a 0-byte diff and identical Merkle tree roots.
  8. Atomic Manifest Swap Gate: Verify that updating the cache manifest executes via an atomic write-and-rename sequence, guaranteeing that simulated process termination during commit leaves the previous valid manifest intact.
  9. Deterministic UUIDv5 Anchor Gate: Verify that 100% of module nodes and cache records bear deterministic RFC 4122 UUIDv5 identifiers generated from the compiler namespace OID and canonical qualified paths per Architectural Directive 1 and REQ-0010.
  10. Bounded Work-Stealing Parallelism Gate: Execute incremental compilation across $`K`$ invalidated modules concurrently on a thread pool bounded by $`N_{\text{max\_workers}}`$; assert thread-isolated memory allocation, zero data races, and bitwise deterministic output per Architectural Directive 2 and REQ-0012.
  11. Release Mode Latency & Memory Gate: In compiled Release mode (`--release`) under dedicated benchmark harnesses isolated from CI logic tests per Architectural Directive 5, REQ-0011, and REQ-0196, verify that state hash propagation and invalidation closure computation across $`10^4`$ modules executes in under 25 ms, with peak RSS memory under 100 MB.
