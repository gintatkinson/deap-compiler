### REQ-0034: Contiguous Memory Lowering & Linear Allocation Complexity
- **Normative Statement**: The compiler core shall lower AST nodes (Packages, PartDefs, PortDefs, ActionDefs, ConstraintDefs) into contiguous memory representations with $O(1)$ index access and $O(N)$ allocation complexity, eliminating pointer indirection overhead, cache misses, and heap fragmentation.
- **Formal Invariant**: Ingested schema models lower into the contiguous node arena in strict linear time $O(N)$ with spatial buffer locality, providing constant-time indexed node access:
$$
T_{\text{lower}}(N) \le c_1 \cdot N, \quad T_{\text{access}}(i) \le c_2 \cdot 1
$$
Contiguous Memory Layout Invariant:
$$
\text{Address}(\text{Node}_{i+1}) = \text{Address}(\text{Node}_i) + \text{sizeof}(\text{NodeSlot})
$$
where node slot sizes are uniform within node families, guaranteeing sequential cache line utilization without dynamic pointer chasing:
$$
\text{PointerIndirectionDepth}(\text{NodeArena}) = 0
$$
- **Computational Complexity & Algorithmic Bounds**: Node insertion is $O(1)$ amortized; full AST lowering is $O(N)$ linear time where $N$ is total AST node count.
- **Verification & Conformance Criteria**: Memory profiler confirms contiguous virtual memory layout and asserts linear $O(N)$ lowering throughput up to $10^6$ AST nodes.
