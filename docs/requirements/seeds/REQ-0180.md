### REQ-0180: Register Allocation & SSA Basic Block Scheduling in LUMI IR (NP-7)
- **Normative Statement**: The code generation engine shall execute global register allocation and intra-block instruction scheduling over LUMI IR basic blocks to produce optimized machine representations. Because both optimal register allocation (Chaitin Graph $K$-Coloring) and latency-constrained DAG instruction scheduling are NP-complete, the compiler shall implement Kempe's heuristic with optimistic spilling for register assignment, and critical-path list scheduling for instruction reordering, guaranteeing deterministic polynomial-time compilation bounds.
- **Formal Invariant**: Let $\mathcal{G}_{\text{interf}} = (\mathcal{V}, \mathcal{E})$ be the variable interference graph where $\mathcal{V}$ is the set of SSA variable live ranges and $(u, v) \in \mathcal{E}$ indicates overlapping liveness. The register allocator implements Kempe's heuristic for target machine register count $K$:
$$
\text{degree}(v) < K \implies \text{push}(v, \mathcal{S}_{\text{alloc}}) \quad \wedge \quad \mathcal{G}_{\text{interf}} \leftarrow \mathcal{G}_{\text{interf}} \setminus \{v\}
$$
If all remaining vertices satisfy $\text{degree}(v) \ge K$, the engine selects an optimistic spill candidate:
$$
v_{\text{spill}} = \arg\min_{v \in \mathcal{V}} \frac{\text{spill\_cost}(v)}{\text{degree}(v)}
$$
pushes $v_{\text{spill}}$ optimistically to $\mathcal{S}_{\text{alloc}}$, and continues elimination. On stack reconstruction, each variable is assigned a color $c(v) \in \{1, \dots, K\} \setminus \{ c(u) \mid (u, v) \in \mathcal{E} \}$. If an optimistic node encounters a conflict, it is spilled to a static memory frame slot.

For basic block instruction scheduling, let $\mathcal{D}_{\text{bb}} = (\mathcal{I}, \mathcal{E}_{\text{dep}})$ be the directed acyclic graph of instruction data and control dependencies with latency function $\lambda : \mathcal{E}_{\text{dep}} \to \mathbb{N}$. The critical-path list scheduler assigns static priorities:
$$
\text{Priority}(u) = \text{latency}(u) + \max_{v \in \text{succ}(u)} \left( \text{Priority}(v) + \lambda(u, v) \right)
$$
scheduling ready instructions greedily by highest priority to minimize pipeline stall cycles.
Complexity Class: NP-complete for optimal coloring and scheduling; Kempe allocation executes in $O(|\mathcal{V}|^2)$ and critical-path list scheduling executes in deterministic linear time $O(|\mathcal{I}| + |\mathcal{E}_{\text{dep}}|)$.
