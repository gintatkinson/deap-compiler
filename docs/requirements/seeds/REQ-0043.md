### REQ-0043: Multi-File Module Ingestion & Directory-to-Namespace Hierarchy Mapping
- **Normative Statement**: The compiler shall support multi-file models partitioned across directory hierarchies, deterministically mapping directory paths to nested SysML package namespaces such that a file located at `schema/packages/module_a/unit_b/storage.sysml` automatically binds to `package Packages::ModuleA::UnitB`.
- **Formal Invariant**: Let $P_{\text{rel}}$ be the file path relative to the schema root directory. The namespace mapping function $\Omega_{\text{ns}}$ decomposes $P_{\text{rel}}$ into hierarchical segments:
$$
\Omega_{\text{ns}}(p_1 / p_2 / \dots / p_k / \text{name}.\text{ext}) = \text{SymbolId}(\text{PascalCase}(p_1) \mathbin{\Vert} \text{"::"} \mathbin{\Vert} \dots \mathbin{\Vert} \text{PascalCase}(p_k))
$$
Implicit Package Creation Invariant: If enclosing package namespaces $\text{PascalCase}(p_i)$ do not exist in the AST, the compiler synthesizes intermediate package container nodes deterministically:
$$
\forall i \in [1, k], \quad \exists P \in \text{Packages}(\mathcal{A}) \text{ with qualified name } \bigodot_{j=1}^i \text{PascalCase}(p_j)
$$
File-to-Package Containment: All top-level declarations within the source file are owned by the resolved leaf package $\Omega_{\text{ns}}(P_{\text{rel}})$.
- **Computational Complexity & Algorithmic Bounds**: Namespace path normalization executes in $O(|P_{\text{rel}}|)$ time with zero recursive filesystem re-traversal.
- **Verification & Conformance Criteria**: Verification suite tests deeply nested folder hierarchies ($> 5$ levels) and confirms accurate hierarchical package binding without name collisions.
