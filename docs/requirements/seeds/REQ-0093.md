### REQ-0093: KerML Standard Library: `Collections` Package (Set, Sequence, OrderedSet, Bag)
- **Normative Statement**: The compiler shall bootstrap the normative KerML `Collections` standard library package, providing generic collection types (`Set`, `Sequence`, `OrderedSet`, `Bag`) categorized along two orthogonal Boolean dimensions ($\text{Unique}$ and $\text{Ordered}$) with functional operations.
- **Formal Invariant**: Generic collection types parameterize over element type $T$: $\mathcal{C}\langle T \rangle$. The collection matrix partitions:
$$
\begin{aligned}
\text{Set}\langle T \rangle &: \text{Unique} = \text{true}, \quad \text{Ordered} = \text{false} \\
\text{Sequence}\langle T \rangle &: \text{Unique} = \text{false}, \quad \text{Ordered} = \text{true} \\
\text{OrderedSet}\langle T \rangle &: \text{Unique} = \text{true}, \quad \text{Ordered} = \text{true} \\
\text{Bag}\langle T \rangle &: \text{Unique} = \text{false}, \quad \text{Ordered} = \text{false}
\end{aligned}
$$
Subtyping co-variance: $T_1 \le T_2 \implies \mathcal{C}\langle T_1 \rangle \le \mathcal{C}\langle T_2 \rangle$.
Complexity bound: Standard functional operations (`size`, `includes`, `select`, `collect`) obey algebraic set and list axioms, evaluating in $O(|C|)$ linear time over finite collections.
