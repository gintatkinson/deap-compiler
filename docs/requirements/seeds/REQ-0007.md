### REQ-0007: Multi-File Compilation Unit Resolution & Hierarchical Package Scoping
- **Normative Statement**: The compiler architecture shall resolve multi-file compilation units and enforce hierarchical package scoping across modular schema libraries without cross-module symbol collision or namespace pollution. Symbol visibility and resolution rules must strictly prevent ambiguous symbol bindings.
- **Formal Invariant**: Let $\mathcal{P}$ be the set of hierarchical packages and $\text{Symbols}(P)$ be the exported symbols of package $P \in \mathcal{P}$. For distinct packages $P_i \neq P_j$:
$$
\text{QualifiedNamespace}(P_i) \cap \text{QualifiedNamespace}(P_j) = \emptyset
$$
Symbol resolution within a referencing package $P_{\text{src}}$ satisfies:
$$
\text{Resolve}(\sigma, P_{\text{src}}) = \begin{cases}
\sigma, & \text{if } \sigma \in \text{Declared}(P_{\text{src}}) \\
P_{\text{tgt}}::\sigma', & \text{if } \exists \text{Import}(P_{\text{src}}, P_{\text{tgt}}) \wedge \sigma' \in \text{Exported}(P_{\text{tgt}}) \\
\bot, & \text{otherwise}
\end{cases}
$$
Unambiguous Import Invariant:
$$
|\{ P_{\text{tgt}} \mid \text{Import}(P_{\text{src}}, P_{\text{tgt}}) \wedge \sigma \in \text{Exported}(P_{\text{tgt}}) \}| \le 1
$$
Any ambiguous unqualified reference yields an explicit compile-time diagnostic error.
- **Computational Complexity & Algorithmic Bounds**: Scope lookup executes in $O(D)$ where $D$ is lexical nesting depth ($D \le 16$), bounded by constant $O(1)$ amortized table lookups.
- **Verification & Conformance Criteria**: Verification suite tests cross-package references with duplicate local names, asserting zero collision and clean qualified path resolution.
