### REQ-0025: Tabular Schema Ingestion for Topological Connections & Interconnects
- **Normative Statement**: The ingestion engine shall parse tabular schemas defining connections and interconnects between ports into `IngestedConnection` intermediate entities, extracting source and destination endpoints using fully qualified port paths and validating structural hierarchy endpoints.
- **Formal Invariant**: Each topological connection $C$ establishes a directed link between structural ports:
$$
C = \langle \text{id}, P_{\text{src}}, P_{\text{tgt}}, \text{protocol}, \text{latency\_bound} \rangle
$$
Endpoint Path Well-Formedness Invariant:
$$
\text{Segments}(P_{\text{src}}) \ge 2 \quad \wedge \quad \text{Segments}(P_{\text{tgt}}) \ge 2
$$
where each endpoint path decomposes into owner part and port identifier:
$$
P = \text{OwnerPath} \mathbin{\Vert} \text{"::"} \mathbin{\Vert} \text{PortIdentifier}
$$
Graph Topology Invariant: Connection establishes a directed edge $E = (P_{\text{src}}, P_{\text{tgt}})$ in the topological interconnect graph. Self-loops without explicit delay models ($P_{\text{src}} = P_{\text{tgt}}$) trigger compile-time diagnostic error $\text{DiagnosticCode::E0104}$.
- **Computational Complexity & Algorithmic Bounds**: Connection parsing and path splitting execute in $O(R)$ linear time with respect to connection table rows.
- **Verification & Conformance Criteria**: Verification suite confirms that extracted connections form valid directed edges between declared ports in the intermediate metamodel.
