### REQ-0183: OMG DDS IDL Schema Generation & CDR Binary Serialization Codecs
- **Normative Statement**: The code generation engine shall translate AST data structures into standard OMG DDS Interface Definition Language (IDL) schemas and synthesize zero-allocation Common Data Representation (CDR) binary serialization and deserialization codecs.
- **Formal Invariant**: Binary CDR wire serialization aligns all data elements to natural type boundaries:
$$
\text{Offset}(\text{field}_i) \equiv 0 \pmod{\min(8, \text{sizeof}(\text{type}_i))}
$$
with explicit padding bytes inserted to preserve field alignment:
$$
\text{PadBytes}(\phi_i) = \left( A_i - (\text{Offset}(\phi_i) \pmod A_i) \right) \pmod A_i \quad \text{where } A_i = \min(8, \text{sizeof}(\text{type}_i))
$$
Codec contract: Serialization and deserialization reconstruct the original strongly-typed struct with zero dynamic memory allocation:
$$
\text{Deserialize}(\text{Serialize}(x)) \equiv x \quad \wedge \quad \text{HeapAllocations}(\text{Codec}) \equiv 0
$$
Complexity bound: IDL schema emission and codec generation executes in deterministic linear time $O(|\text{Fields}|)$.
