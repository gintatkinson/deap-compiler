### REQ-0014: File Format Detection Engine by Extension & Magic Signatures
- **Normative Statement**: The ingestion engine shall classify input schema files into target schema formats using file extensions and deterministic content prefix signatures across 5 formats: CommonMark Markdown tables, Protocol Buffers (`.proto`), OMG IDL (`.idl`), OpenAPI (`.json`/`.yaml`), and XML Schema Definitions (`.xml`/`.xsd`). Detection must execute using deterministic byte prefix scanning without regular expressions or exploratory backtracking.
- **Formal Invariant**: Let $F$ be an input file with extension $\text{ext}(F)$ and initial byte prefix $\text{head}(F, K)$ where $K = 512$ bytes. The format classifier function $\Delta$ is defined as:
$$
\Delta(F) = \begin{cases}
\text{MarkdownTable}, & \text{if } \text{ext}(F) \in \{\text{".md"}, \text{".markdown"}\} \wedge \text{ContainsMarkdownTable}(\text{head}(F, K)) \\
\text{Protobuf}, & \text{if } \text{ext}(F) = \text{".proto"} \vee \text{ContainsPrefix}(\text{head}(F, K), \text{"syntax = \"proto"}) \\
\text{OmgIdl}, & \text{if } \text{ext}(F) = \text{".idl"} \vee \text{ContainsKeyword}(\text{head}(F, K), \text{"module"}) \\
\text{OpenApi}, & \text{if } \text{ext}(F) \in \{\text{".json"}, \text{".yaml"}\} \wedge \text{ContainsKeys}(\text{head}(F, K), \{\text{"openapi"}, \text{"swagger"}\}) \\
\text{XmlSchema}, & \text{if } \text{ext}(F) \in \{\text{".xml"}, \text{".xsd"}\} \wedge \text{ContainsXmlRoot}(\text{head}(F, K)) \\
\text{Unknown}, & \text{otherwise}
\end{cases}
$$
Strict Regex Prohibition Invariant:
$$
\text{RegexEvaluations}(\Delta) = 0
$$
Prefix inspection executes via single-pass token matching over fixed byte window $[0, K]$.
- **Computational Complexity & Algorithmic Bounds**: Classification executes in strict $O(K) = O(1)$ constant time with respect to total file size.
- **Verification & Conformance Criteria**: Verification harness classifies representative test files across all 5 formats with 100% precision and zero false positives.
