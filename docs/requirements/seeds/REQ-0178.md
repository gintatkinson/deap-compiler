### REQ-0178: Manifest-Driven File Persistence (`CodegenManifest`) with XXH3 Content Fingerprinting
- **Normative Statement**: The code emission engine shall track and persist artifacts through a content-addressed manifest using XXH3 64-bit hashing, skipping redundant disk writes for unchanged artifacts to guarantee deterministic, idempotent builds and minimize filesystem write churn.
- **Formal Invariant**: For an artifact at destination path $p$ with newly synthesized content bytes $B$:
$$
\text{WriteSkipped}(p) \iff \text{XXH3}_{64}(B) = \text{ManifestHash}(p)
$$
Manifest state persistence:
$$
\text{Manifest}_{\text{new}}(p) = \langle p, \text{XXH3}_{64}(B), \text{ByteLength}(B), \text{Timestamp} \rangle
$$
Idempotency guarantee: Re-running code generation with identical AST inputs produces an exact zero-write pass ($\Delta_{\text{writes}} = 0$).
Complexity bound: XXH3 hashing operates at memory bus throughput ($> 10\text{ GB/s}$), executing in deterministic linear time $O(|B|)$.
