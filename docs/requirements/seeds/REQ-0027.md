### REQ-0027: Protocol Buffer (Proto3) AST Ingestion for Messages, Fields & RPCs
- **Normative Statement**: The ingestion engine shall provide a native Protocol Buffer (Proto3) parser that parses `.proto` schemas into intermediate schema IR, converting Protobuf messages to `IngestedPart` definitions, primitive and message fields to `IngestedAttr` properties, service RPCs to `IngestedAction` operations, and enums to classifier data types without external compiler dependencies.
- **Formal Invariant**: Let $\mathcal{P}_{\text{proto}}$ be a parsed Protobuf file. The lowering transformation $\mathcal{T}_{\text{proto}}$ maps:
$$
\begin{aligned}
\text{message } M \{ \dots \} &\longmapsto \text{IngestedPart}(M) \\
\text{field } T \, f = i &\longmapsto \text{IngestedAttr}(f, \text{type}: T, \text{tag}: i) \\
\text{rpc } R(A) \text{ returns } (B) &\longmapsto \text{IngestedAction}(R, \text{inputs}: [(A)], \text{outputs}: [(B)]) \\
\text{enum } E \{ \dots \} &\longmapsto \text{IngestedClassifierDef}(E, \text{kind}: \text{Enum})
\end{aligned}
$$
Field Tag Preservation Invariant:
$$
\forall f \in \text{Fields}(M), \quad \text{Tag}(f) \in [1, 2^{29}-1] \setminus [19000, 19999]
$$
Nested message scoping: Nested message declarations map to hierarchical child classifiers scoped under the parent message package.
- **Computational Complexity & Algorithmic Bounds**: Ingestion complexity is strictly linear $O(N)$ with respect to Protobuf file size $N$, executing via deterministic recursive descent without backtracking.
- **Verification & Conformance Criteria**: Standard Google Protobuf test schemas lower cleanly into canonical SysML v2 representations preserving all field types and numerical tags.
