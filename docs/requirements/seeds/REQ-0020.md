### REQ-0020: Disambiguation of Array Indexing Syntax in Tabular Schemas
- **Normative Statement**: The ingestion engine shall disambiguate array indexing syntax in tabular schemas, decomposing bracketed identifiers (`name[index]`) into distinct base identifiers and integer index qualifiers without lexical backtracking or confusion with type parameter brackets (`Type[1..*]`).
- **Formal Invariant**: Let $S$ be an identifier string. The deterministic decomposition operator $\theta_{\text{array}}$ decomposes $S$ into:
$$
\theta_{\text{array}}(S) = \begin{cases}
\langle \text{base}(S), \text{index}(S) \rangle, & \text{if } \text{IsIndexedIdentifier}(S) \\
\langle S, \bot \rangle, & \text{otherwise}
\end{cases}
$$
Syntax Disambiguation Invariant:
$$
\text{IsIndexedIdentifier}(S) \iff S = \text{Ident} \mathbin{\Vert} \text{"["} \mathbin{\Vert} \text{Digits} \mathbin{\Vert} \text{"]"}
$$
Type Multiplicity Separation Invariant:
$$
S = \text{Type} \mathbin{\Vert} \text{"["} \mathbin{\Vert} \text{Range} \mathbin{\Vert} \text{"]"} \implies \theta_{\text{multiplicity}}(S) = \langle \text{Type}, \text{Range} \rangle
$$
- **Computational Complexity & Algorithmic Bounds**: Disambiguation executes in single-pass linear time $O(|S|)$ via deterministic character scanning without backtracking.
- **Verification & Conformance Criteria**: Token stream distinguishes `sensor[0]` (instance index) from `Sensor[0..*]` (multiplicity bound) with 100% classification accuracy.
