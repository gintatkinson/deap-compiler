### REQ-0004: Workspace Sovereignty & Dynamic Relative Path Resolution
- **Normative Statement**: The compiler platform shall operate in a completely self-contained, sovereign repository architecture where all filesystem operations, cross-module imports, schema references, and output artifact paths resolve dynamically using workspace-relative paths derived from the repository root. The compiler shall ensure bitwise determinism of all outputs regardless of the absolute workspace mount location on disk.
- **Formal Invariant**: Let $\mathcal{R}$ denote the sovereign repository root path determined dynamically via version-control discovery or explicit CLI configuration. All resolved filesystem paths $P$ satisfy:
$$
P = \mathcal{R} \bowtie p_{\text{rel}}, \quad \text{where } p_{\text{rel}} \in \text{Path}(\mathcal{R})
$$
Bitwise determinism invariance across distinct repository root locations $\mathcal{R}_A \neq \mathcal{R}_B$:
$$
\text{SHA256}(\mathcal{C}(\mathcal{I}, \mathcal{R}_A)) \equiv \text{SHA256}(\mathcal{C}(\mathcal{I}, \mathcal{R}_B))
$$
Absolute Path Non-Leakage Invariant:
$$
\forall a \in \text{Artifacts}(\mathcal{C}(\mathcal{I}, \mathcal{R})), \quad \text{ContainsSubstring}(a, \text{PathString}(\mathcal{R})) \equiv \text{false}
$$
Hardcoded absolute machine paths, user home directory references, and external repository URLs are strictly rejected during path validation.
- **Computational Complexity & Algorithmic Bounds**: Dynamic path normalization executes in $O(|P|)$ time with zero recursive filesystem traversal.
- **Verification & Conformance Criteria**: Compiling identical schema inputs from two distinct root mount locations yields identical SHA256 artifact digests.
