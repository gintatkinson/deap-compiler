### REQ-0089: SysML v2 Expose Filtering & Viewpoint Conformance Grammar
- **Normative Statement**: The query engine shall formalize `expose` statements as model selection expressions supporting element inclusion, recursive namespace expansion, and tag-based element predicates, verifying viewpoint conformance across exposed subgraphs.
- **Formal Invariant**: An expose declaration $\mathcal{E}$ specifies target element paths and query predicates:
$$
\text{ExposedElements}(\mathcal{E}) = \bigcup_{p \in \text{paths}(\mathcal{E})} \text{ResolvePath}(p) \cup \{ e \in \mathcal{M} \mid \text{Predicate}(e) = \text{true} \}
$$
Conformant projection: The rendered view model graph $G_{\text{view}} = (V_{\text{exp}}, E_{\text{exp}})$ preserves induced edges between exposed vertices:
$$
E_{\text{exp}} = \{ (u, v) \in E_{\text{model}} \mid u, v \in V_{\text{exp}} \}
$$
Complexity bound: Model filtering and induced subgraph extraction execute in deterministic linear time $O(N)$ with respect to total AST node count.
