### REQ-0040: Two-Pass Symbol Hoisting & Lexical Scope Table Construction
- **Normative Statement**: The core AST engine shall execute a two-pass symbol resolution pipeline where Pass 1 hoists all package, classifier, and port definitions into a hierarchical lexical symbol table and Pass 2 resolves all cross-references, feature typings, connection endpoints, and constraint variable expressions.
- **Formal Invariant**: Let $\mathcal{A}$ be the raw AST. Pass 1 constructs the global hierarchical symbol table $\Gamma$:
$$
\Gamma = \text{Pass1}(\mathcal{A}) = \bigcup_{n \in \text{Defs}(\mathcal{A})} \{ \text{QualifiedName}(n) \mapsto \text{NodeId}(n) \}
$$
Pass 2 resolves references against symbol table $\Gamma$:
$$
\mathcal{A}_{\text{resolved}} = \text{Pass2}(\mathcal{A}, \Gamma)
$$
Mutual Recursion & Forward Reference Invariant:
$$
\forall r \in \text{References}(\mathcal{A}), \quad \text{SourcePosition}(r) < \text{SourcePosition}(\text{Target}(r)) \implies \text{ResolvesSuccessfully}(r, \Gamma)
$$
This two-pass architecture decouples symbol declaration ordering from referencing ordering, eliminating file ordering artifacts and circular hoisting deadlocks.
- **Computational Complexity & Algorithmic Bounds**: Pass 1 and Pass 2 execute in strict linear time $O(N)$ with respect to total AST nodes $N$, achieving $O(1)$ amortized lookups per symbol.
- **Verification & Conformance Criteria**: Verification suite tests mutual recursion across different packages and asserts deterministic resolution without order sensitivity.
