### REQ-0008: Sovereign Single Source of Truth (SSOT) Multi-File AST Model
- **Normative Statement**: The multi-file SysML v2 / KerML AST synthesized from schemas in `schema/` shall serve as the sovereign Single Source of Truth (SSOT) for all architectural structures, interfaces, and constraints across the system lifecycle. All downstream representations (Epics, Features, ICDs, Simulation Models, and Target Source Code) function strictly as deterministic formal projections of this central AST model.
- **Formal Invariant**: Let $\mathcal{A}_{\text{SSOT}}$ be the resolved root AST model graph. For every downstream artifact $D_k \in \mathcal{D}_{\text{downstream}}$, there exists a formal deterministic projection mapping $\psi_k$:
$$
D_k = \psi_k(\mathcal{A}_{\text{SSOT}})
$$
Bidirectional Consistency & Anti-Drift Invariant:
$$
\text{Drift}(D_k) \iff D_k \neq \psi_k(\mathcal{A}_{\text{SSOT}})
$$
Direct manual modification of downstream artifacts without corresponding upstream AST mutation is detected and flagged by automated bidirectional reconciliation gates:
$$
\forall D_k, \quad \text{Reconcile}(D_k, \mathcal{A}_{\text{SSOT}}) \implies \mathcal{A}_{\text{SSOT}} \text{ is authoritative}
$$
- **Computational Complexity & Algorithmic Bounds**: Model projection execution $\psi_k$ exhibits linear time complexity $O(|\text{Nodes}(\mathcal{A}_{\text{SSOT}})|)$ with respect to AST size.
- **Verification & Conformance Criteria**: Parity audit gate asserts 100% bidirectional parity between generated artifacts and the authoritative SysML v2 model.
