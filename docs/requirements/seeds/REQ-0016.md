### REQ-0016: Synchronization Token Recovery on Table Delimiter Boundaries
- **Normative Statement**: The CommonMark table parser shall implement synchronization token recovery on table delimiter boundaries (`|`, `\n`) such that when a cell contains unexpected formatting, unescaped pipe characters, or malformed data, the parser records a localized diagnostic and resynchronizes at the next pipe delimiter or newline boundary without abandoning subsequent cells or rows.
- **Formal Invariant**: Let $C_j$ be cell $j$ in row $R_i$. If lexical parsing or semantic extraction of $C_j$ fails:
$$
\text{State} \longleftarrow \text{RecoverToNextDelimiter}(\{|\}, \{\backslash n\})
$$
Diagnostic accumulation without abort:
$$
\mathcal{D} \longleftarrow \mathcal{D} \cup \{ \text{Diagnostic}(R_i, C_j, \text{DiagnosticCode::E0102}) \}
$$
The parser increments the error counter, retains valid preceding cells $C_1, \dots, C_{j-1}$, and resumes analysis at $C_{j+1}$.
Progress Invariant:
$$
\text{ByteOffset}_{t+1} \ge \text{ByteOffset}_t + 1
$$
- **Computational Complexity & Algorithmic Bounds**: Delimiter scanning operates in monotonic single-pass forward direction, preserving strict $O(N)$ linear execution across malformed table rows.
- **Verification & Conformance Criteria**: A test table containing malformed cells in rows 2 and 4 successfully extracts all valid rows 1, 3, and 5 while emitting 2 precise diagnostic spans.
