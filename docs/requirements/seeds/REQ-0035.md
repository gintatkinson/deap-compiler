### REQ-0035: Deterministic Node Handle Addressing & Reference Safety
- **Normative Statement**: AST nodes shall be addressed throughout the compiler pipeline via deterministic typed integer handles (`NodeHandle<T>`) rather than raw memory pointers, ensuring complete memory safety, cache-friendly indexing, cross-process serializability, and deterministic traversal order across all platforms.
- **Formal Invariant**: Each node handle $H$ is a compact integer value combining arena slot index, generation counter, and type discriminator:
$$
H = \langle \text{Index}, \text{Generation}, \text{TypeTag} \rangle
$$
Generational Reference Safety Invariant: Dereferencing handle $H$ in arena $\mathcal{A}$ evaluates:
$$
\text{Deref}(H, \mathcal{A}) = \begin{cases}
\& \mathcal{A}.\text{slots}[H.\text{Index}].\text{node}, & \text{if } \mathcal{A}.\text{slots}[H.\text{Index}].\text{gen} = H.\text{Generation} \\
\bot, & \text{otherwise (stale reference)}
\end{cases}
$$
No Dangling Pointers Invariant:
$$
\text{DanglingPointers}(\text{NodeArena}) = 0
$$
Handle Compactness Invariant: The handle representation size is strictly bounded:
$$
\text{sizeof}(H) \le S_{\text{handle}}
$$
where $S_{\text{handle}} = 8\text{ bytes}$ (64 bits).
- **Computational Complexity & Algorithmic Bounds**: Handle dereferencing executes in $O(1)$ constant time via array index and generation equality check.
- **Verification & Conformance Criteria**: Automated test asserts that reusing an arena slot increments the generation counter and immediately invalidates all prior handles to that slot.
