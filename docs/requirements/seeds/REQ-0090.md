### REQ-0090: SysML v2 MetadataDefinition (`metadata def`) & Semantic Annotation Usage (`@`)
- **Normative Statement**: The metadata subsystem shall formalize `metadata def` as typed annotation classifiers specializing KerML `Classifier`, and `@Annotation` usages as non-intrusive semantic metadata attachments binding typed attribute dictionaries to AST nodes without altering base metamodel semantics.
- **Formal Invariant**: A metadata definition $M$ defines typed attributes $a_1: T_1, \dots, a_p: T_p$. An annotation `@M(v_1, \dots, v_p)` attached to AST element $e \in \text{Nodes}(\mathcal{A})$ defines an extrinsic metadata mapping:
$$
\alpha : \text{NodeHandle} \times \text{SymbolId} \longrightarrow \text{Value}
$$
Metamodel neutrality: Attaching or detaching metadata annotations preserves underlying core typing and operational semantics:
$$
\llbracket e \rrbracket \equiv \llbracket e \mathbin{\Vert} @M \rrbracket
$$
Complexity bound: Metadata attachment, indexing, and lookup validate in $O(1)$ amortized dictionary time per node handle.
