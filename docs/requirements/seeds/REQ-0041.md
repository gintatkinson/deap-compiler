### REQ-0041: Lexical Scope Lookup & Fully Qualified Path Resolution (`::`)
- **Normative Statement**: The AST resolver shall implement lexical scope resolution using standard double-colon scoping (`::`) to search inward from local scopes through enclosing parent scopes up to the root namespace, respecting public and private package visibility rules.
- **Formal Invariant**: Let $\sigma$ be a symbol reference requested within lexical scope $S_i$. The hierarchical lookup function $\text{Find}(\sigma, S_i)$ searches scopes recursively:
$$
\text{Find}(\sigma, S_i) = \begin{cases}
e, & \text{if } \exists e \in S_i \text{ such that } \text{symbol}(e) = \sigma \wedge \text{IsVisible}(e, S_i) \\
\text{Find}(\sigma, \text{parent}(S_i)), & \text{if } \text{parent}(S_i) \neq \bot \\
\bot, & \text{otherwise}
\end{cases}
$$
Fully Qualified Path Invariant: For absolute paths prefixed with `::` or root package identifiers:
$$
\text{FindQualified}(p_1::p_2::\dots::p_k) = \text{Lookup}(\text{Lookup}(\text{Root}, p_1), p_2 \dots p_k)
$$
Private Visibility Boundary Invariant: Private members of a package $P$ are unreachable from scopes outside $P$ unless granted explicit friending or export visibility.
- **Computational Complexity & Algorithmic Bounds**: Scope traversal depth is bounded by lexical nesting depth $D \le 16$, executing in $O(D) = O(1)$ constant time.
- **Verification & Conformance Criteria**: Verification suite confirms shadow resolution where local variables correctly shadow parent package symbols while qualified paths access shadowed targets.
