### REQ-0017: Dynamic Semantic Header Key Normalization & Order-Independent Binding
- **Normative Statement**: The table ingestion engine shall match column headers in an order-independent manner by normalizing header strings (ASCII case folding, whitespace trimming, punctuation stripping, and alias lookup) to bind schema attributes dynamically to table columns regardless of column ordering.
- **Formal Invariant**: Let $H$ be a raw column header string. The normalization function $\eta(H)$ is defined as:
$$
\eta(H) = \text{CaseFold}(\text{StripPunctuation}(\text{Trim}(H)))
$$
The column-to-field binding $\beta$ maps $\eta(H)$ against a dictionary of canonical attribute keys $\mathcal{K}_{\text{canonical}}$:
$$
\beta(H) = k \in \mathcal{K}_{\text{canonical}} \iff \eta(H) \in \text{Aliases}(k)
$$
Permutation Invariance Invariant: For any column permutation $\pi$:
$$
\text{Record}(\pi(\text{Columns})) \equiv \text{Record}(\text{Columns})
$$
Deterministic Resolution Invariant:
$$
|\{ k \in \mathcal{K}_{\text{canonical}} \mid \eta(H) \in \text{Aliases}(k) \}| = 1
$$
Collisions or unrecognized mandatory columns trigger structured diagnostic recovery.
- **Computational Complexity & Algorithmic Bounds**: Header normalization executes in $O(|H|)$ time, with column-to-field binding resolved in $O(C)$ time where $C$ is the number of table columns ($C \le 32$).
- **Verification & Conformance Criteria**: Tables with permuted column orders (e.g., Name, Type, Description vs. Description, Name, Type) synthesize identical AST entities.
