### REQ-0019: Table Row-to-Entity Structural Mapping & Identifier Sanitization
- **Normative Statement**: The ingestion engine shall map each valid table row to a corresponding intermediate representation entity while sanitizing raw entity names into valid SysML v2 / KerML basic identifiers using deterministic replacement of invalid characters and collision avoidance.
- **Formal Invariant**: Let $S_{\text{raw}}$ be the raw string identifier extracted from the table row. The sanitization function $\sigma_{\text{id}}$ satisfies:
$$
\sigma_{\text{id}}(S_{\text{raw}}) = \begin{cases}
S_{\text{raw}}, & \text{if } S_{\text{raw}} \in \text{BasicIdentifier} \\
\text{SanitizeIdentifier}(S_{\text{raw}}), & \text{otherwise}
\end{cases}
$$
where `SanitizeIdentifier` maps non-alphanumeric characters to underscores (`_`), prepends `id_` if the initial character is numeric, and trims trailing delimiters:
$$
\sigma_{\text{id}}(\text{"123-Alpha (Beta)"}) = \text{"id_123_Alpha_Beta_"}
$$
Collision Resolution Invariant: If sanitized name $\sigma_{\text{id}}(S)$ collides with an existing sibling identifier in the same namespace, append deterministic integer index `_2`, `_3`:
$$
\text{Disambiguate}(\sigma, \text{Scope}) = \sigma \mathbin{\Vert} \text{"\_"} \mathbin{\Vert} \text{Count}(\sigma, \text{Scope})
$$
- **Computational Complexity & Algorithmic Bounds**: Identifier sanitization and scope collision checking execute in $O(|S_{\text{raw}}|)$ time via character classification and hash set lookup.
- **Verification & Conformance Criteria**: Malformed entity names containing spaces, dashes, parentheses, and leading digits lower to valid SysML v2 basic identifiers without lexer rejection.
