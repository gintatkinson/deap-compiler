### REQ-0048: Topological Sort Dependency Scheduling (Tarjan SCC & Kahn Algorithms)
- **Normative Statement**: The AST graph engine shall provide deterministic topological scheduling via Kahn's algorithm and Tarjan's strongly connected components algorithm to determine valid compilation orders, dependency linearization, and shortest-path connection routing between model elements.
- **Formal Invariant**: Let $G = (V, E)$ be the dependency DAG. The topological sort algorithm produces a linear ordering sequence $\mathcal{L} = \langle v_1, v_2, \dots, v_n \rangle$ satisfying:
$$
\forall (u, v) \in E, \quad \text{Index}(u, \mathcal{L}) < \text{Index}(v, \mathcal{L})
$$
Deterministic Tie-Breaking Invariant: When multiple vertices possess zero in-degree during Kahn evaluation, vertices are dequeued strictly by lexicographical qualified name:
$$
\text{NextVertex}(Q) = \arg\min_{v \in Q} (\text{QualifiedName}(v))
$$
Shortest-Path Interconnect Query: Breadth-first search discovers shortest routing paths between ports:
$$
\text{ShortestPath}(u, v) = \arg\min_{\mathcal{P} \in \text{Paths}(u, v)} |\mathcal{P}|
$$
- **Computational Complexity & Algorithmic Bounds**: Topological sorting and BFS path queries execute in $O(|V| + |E|)$ linear time and $O(|V|)$ auxiliary space.
- **Verification & Conformance Criteria**: Verification suite tests scheduling across complex diamond DAGs, confirming identical deterministic topological orderings across repeated runs.
