### REQ-0196: Standardized Diagnostic Error Code Family E04xx: Safety, Traceability & Regulatory Errors (`E0400`--`E0499`)
- **Normative Statement**: The diagnostic engine shall standardize all errors originating in formal safety compilation, hazard analysis, requirement completeness gates, traceability trees, and regulatory profiles into the `E04xx` code space (`E0400` through `E0499`).
- **Formal Semantics & Invariants**:
  The `E04xx` family includes:
  - `E0401`: Statically Refuted Assert Constraint
  - `E0405`: Missing Failsafe Fallback Transition
  - `E0406`: Traceability Tier Inversion Violation
  - `E0407`: Unsatisfied Requirement Allocation Gate
  - `E0408`: Unjustified Design Element Gate
  - `E0409`: Missing Verification Witness Gate
  - `E0411`: Merkle Root Attestation Divergence
  - `E0412`: Open Control Loop Lacking Feedback
  - `E0414`: UCA Combinatorial Expansion Bound Exceeded
  - `E0421`: Uncontrollable State Boundary Breach
  - `E0440`--`E0451`: Level 1C ICD, Schedulability, and Signal Dictionary Errors
- **Error Diagnostics & Quality Boundaries**:
  All safety, verification, and traceability failures shall strictly map to unique codes within `E0400`--`E0499`.
- **Acceptance Criteria**:
  - **AC-1**: Safety compilation errors assign documented `E04xx` diagnostic codes.
  - **AC-2**: Traceability gate failures specify missing requirement or element IDs.
  - **AC-3**: Hazard analysis violations cite responsible controllers and control action tuples.
