### REQ-0164: Epics Projection: System-Level UML Class & Component Architecture Diagrams
- **Normative Statement**: Every generated Epic shall include a system-level UML class diagram and component architecture diagram (rendered in Mermaid). Diagrams shall illustrate subsystem component boundaries, provided/required interfaces, and structural composition relationships.
- **Formal Semantics & Invariants**:
  Diagram generation follows strict Mermaid syntax rules:
  - First non-comment line must declare `classDiagram`.
  - Subsystems carry `<<component>>` stereotypes.
  - Member lines shall use parentheses or simple brackets for constraints and double-quoted labels for comparison operations.
  - Closing fence ```` ``` ```` must reside on an isolated line.
- **Error Diagnostics & Quality Boundaries**:
  Syntax violations in emitted Mermaid blocks shall fail validation with `E0504` (Mermaid Syntax Projection Error).
- **Acceptance Criteria**:
  - **AC-1**: Emits valid, renderable Mermaid class diagrams in every Epic.
  - **AC-2**: Diagrams illustrate components, provided/required interfaces, and composition (`*--`).
  - **AC-3**: Complies strictly with all Mermaid syntax and escaping rules.
