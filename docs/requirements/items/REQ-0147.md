### REQ-0147: Automated $N^2$ System Interface Matrix Construction & Topology Indexing
- **Normative Statement**: The ICD engine shall automatically construct the $N^2$ System Interface Matrix representing all interactions between the $N$ subsystems and components in the model. Subsystems shall occupy diagonal cells $(i, i)$, while off-diagonal cells $(i, j)$ shall catalog all directed interfaces and item flows from subsystem $i$ to subsystem $j$.
- **Formal Semantics & Invariants**:
  The $N^2$ matrix $\mathbf{M} \in \mathcal{P}(\text{Interfaces})^{N \times N}$ satisfies:
  $$
  M_{ij} = \{ c \in \text{Connections} \mid \text{source}(c) \in S_i \wedge \text{target}(c) \in S_j \}, \quad i \ne j
  $$
  Diagonal cells $M_{ii} = S_i$ store subsystem internal definitions and attributes.
- **Error Diagnostics & Quality Boundaries**:
  Subsystem indexing failures or missing boundary components shall emit compiler error `E0440` (Malformed Subsystem Decomposition in N2 Matrix).
- **Acceptance Criteria**:
  - **AC-1**: Assembles complete $N^2$ matrix for arbitrary multi-subsystem models.
  - **AC-2**: Off-diagonal cells accurately list all connecting ports, signals, and protocols.
  - **AC-3**: Emits publication-grade Markdown tables for ICD 01 documentation.
