### REQ-0026: Tabular Schema Ingestion for Behaviors, Actions & State Transitions
- **Normative Statement**: The ingestion engine shall parse tabular schemas defining behavioral actions, activities, and state transitions into `IngestedAction` entities, capturing action inputs, outputs, preconditions, postconditions, trigger events, and guard conditions.
- **Formal Invariant**: Each behavioral action is modeled as an input-output transformation tuple:
$$
A = \langle \text{id}, \text{owner}, \mathcal{I}, \mathcal{O}, e_{\text{trigger}}, g_{\text{guard}}, \mathcal{P}_{\text{pre}}, \mathcal{P}_{\text{post}} \rangle
$$
where typed parameter sets satisfy:
$$
\mathcal{I} = \{ (p_i, \tau_i) \mid 1 \le i \le m \}, \quad \mathcal{O} = \{ (q_j, \tau_j) \mid 1 \le j \le k \}
$$
State Transition Binding Invariant: For actions representing statechart transitions:
$$
T = \langle s_{\text{source}}, s_{\text{target}}, e_{\text{trigger}}, g_{\text{guard}}, A_{\text{effect}} \rangle
$$
where $s_{\text{source}}, s_{\text{target}} \in \text{States}(\text{owner})$.
- **Computational Complexity & Algorithmic Bounds**: Action table ingestion executes in $O(R)$ linear time with respect to behavioral rows.
- **Verification & Conformance Criteria**: Verification suite confirms 100% extraction of action signatures, trigger events, and state transition endpoints into the intermediate metamodel.
