### REQ-0026: Tabular Schema Ingestion for Topological Connections & Interconnects
- **Normative Statement**: The ingestion engine shall parse tabular schemas defining connections and interconnects between ports into `IngestedConnection` intermediate entities. The parser shall extract source and destination endpoints using fully qualified port paths (`Part_A::Port_1` to `Part_B::Port_2`).
- **Formal Semantics & Invariants**:
  An `IngestedConnection` node is defined as:
  ```rust
  pub struct IngestedConnection {
      pub id: Spur,
      pub source_path: Vec<Spur>,
      pub target_path: Vec<Spur>,
      pub item_flow_type: Option<Spur>,
  }
  ```
  The parser validates that each endpoint path contains at least two segments (owning part and port).
- **Error Diagnostics & Quality Boundaries**:
  Malformed connection endpoint syntax (e.g. missing port name) shall emit `E0111` (Malformed Connection Endpoint).
- **Acceptance Criteria**:
  - **AC-1**: Parses connection tables and establishes source-to-target endpoint links.
  - **AC-2**: Extracts associated item flow types when specified in connection rows.
  - **AC-3**: Rejects connections with missing or malformed endpoint paths.
