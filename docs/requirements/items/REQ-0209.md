### REQ-0209: Array-Indexed Instance Disambiguation & Subscript Multiplicity Allocation
- **Normative Statement**: The schema ingestion engine shall deterministically disambiguate array-indexed entity identifiers (`Port[1]`, `Port[2]`) into distinct AST nodes with unique generational handles while allocating explicit multiplicity subscript metadata.
- **Formal Semantics & Invariants**:
  For distinct array instances $S[i]$ and $S[j]$ ($i \ne j$):
  $$
  \text{NodeId}(S[i]) \ne \text{NodeId}(S[j]) \quad \wedge \quad \text{QualifiedName}(S[i]) \ne \text{QualifiedName}(S[j])
  $$
  Both nodes share identical base classifier typing while retaining independent connection bindings.
- **Error Diagnostics & Quality Boundaries**:
  Duplicate array indices declared within the same scope shall emit `E0106` (Duplicate Array Index Declaration).
- **Acceptance Criteria**:
  - **AC-1**: Parses schemas containing array-indexed ports and parts into distinct arena nodes.
  - **AC-2**: Connections bind independently to individual indexed array elements.
  - **AC-3**: Emitted SysML models reflect distinct sanitized instance identifiers with index annotations.
