### REQ-0027: Tabular Schema Ingestion for Behaviors, Actions & State Transitions
- **Normative Statement**: The ingestion engine shall parse tabular schemas defining behavioral actions, activities, and state transitions into `IngestedAction` entities. The parser shall capture action inputs, outputs, preconditions, postconditions, and trigger events.
- **Formal Semantics & Invariants**:
  An `IngestedAction` node is represented as:
  ```rust
  pub struct IngestedAction {
      pub id: Spur,
      pub owner: Spur,
      pub inputs: Vec<(Spur, Spur)>,  // (name, type)
      pub outputs: Vec<(Spur, Spur)>, // (name, type)
      pub trigger_event: Option<Spur>,
      pub guard_condition: Option<String>,
  }
  ```
- **Error Diagnostics & Quality Boundaries**:
  Action declarations missing mandatory parameter type bindings shall emit `E0112` (Untyped Action Parameter).
- **Acceptance Criteria**:
  - **AC-1**: Ingests actions with explicit input and output parameter lists.
  - **AC-2**: Captures state transition triggers and guard conditions from behavioral tables.
  - **AC-3**: Binds actions to owning structural parts or state machine regions.
