### REQ-0121: Hierarchical State Machine (Statechart) Containment & Orthogonal Regions
- **Normative Statement**: The state machine compiler shall model hierarchical statecharts supporting nested composite states, parent-child state containment, and orthogonal parallel regions with independent active sub-states.
- **Formal Semantics & Invariants**:
  A state machine configuration $C$ is a tree of active states:
  $$
  C \subseteq \text{States}, \quad s \in C \implies \text{ancestors}(s) \subset C
  $$
  For an orthogonal state $S_{\text{orth}}$ with regions $R_1, \dots, R_m$, an active configuration must contain exactly one active leaf state in each region:
  $$
  S_{\text{orth}} \in C \implies \forall i \in \{1 \dots m\}, \quad |C \cap \text{States}(R_i)| = 1
  $$
- **Error Diagnostics & Quality Boundaries**:
  A composite state without a defined initial state shall emit `E0254` (Missing Initial State in Composite State).
- **Acceptance Criteria**:
  - **AC-1**: Supports arbitrarily deep nested composite state hierarchies.
  - **AC-2**: Accurately tracks active state configurations across concurrent orthogonal regions.
  - **AC-3**: Enforces proper state entry and exit cascading when transitioning between hierarchy levels.
