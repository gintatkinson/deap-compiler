### REQ-0092: KerML Standard Library: `Base` Package & Primitive Equality Lowering
- **Normative Statement**: The KerML lowering engine shall provide built-in semantic bindings for the normative KerML `Base` library (`sysml.library/Kernel Libraries/Kernel Semantic Library/Base.kerml`), including root classifiers `Anything`, `Element`, `DataValue`, and primitive equality (`==`).
- **Formal Semantics & Invariants**:
  The `Base` package establishes universal top-types:
  $$
  \forall T \in \text{KerMLTypes}, \quad T \le \text{Anything}
  $$
  Primitive equality `==` evaluates value equality for data values and identity equality for objects:
  $$
  a == b \iff \begin{cases}
  \text{val}(a) = \text{val}(b), & \text{if } a, b \in \text{DataValue} \\
  \text{id}(a) = \text{id}(b), & \text{if } a, b \in \text{Object}
  \end{cases}
  $$
- **Error Diagnostics & Quality Boundaries**:
  Failure to load or bind the canonical `Base` library shall emit fatal compiler error `E0257` (Standard Library Missing: Base).
- **Acceptance Criteria**:
  - **AC-1**: Pre-loads and binds KerML `Base` library definitions into the compiler symbol table.
  - **AC-2**: Resolves `Base::Anything` and `Base::DataValue` as canonical root types.
  - **AC-3**: Equality operator `==` lowers to type-appropriate equality checks.
