### REQ-0201: Unified Headless CLI Architecture & Deterministic Subcommand Interface
- **Normative Statement**: The compiler platform shall provide a unified, headless command-line interface (`deap`) with deterministic subcommands: `ingest`, `conops`, `safety-compile`, `model-merge`, `icd-compile`, `codegen`, and `drift-check`. The CLI shall return standard POSIX exit codes (0 for success, non-zero for diagnostics).
- **Formal Semantics & Invariants**:
  The CLI entrypoint dispatches commands:
  ```bash
  deap ingest --schema <dir> --out schema/model.sysml --digest .pipeline/schema-digest.json
  deap safety-compile --model schema/model.sysml --out docs/safety/
  deap icd-compile --model schema/model.sysml --out docs/icd/
  deap codegen --target spec|formal|interfaces|simulation --out docs/
  ```
  Exit code invariant: Any fatal diagnostic or unhandled error strictly returns exit code $\ne 0$.
- **Error Diagnostics & Quality Boundaries**:
  Invalid CLI arguments or unrecognized subcommand flags shall emit `E0100` and display targeted usage syntax.
- **Acceptance Criteria**:
  - **AC-1**: CLI supports all modular subcommands independently without monolithic script execution.
  - **AC-2**: Returns exit code 0 on clean builds and exit code 1 on compilation failures.
  - **AC-3**: Supports non-interactive automated invocation in continuous integration pipelines.
