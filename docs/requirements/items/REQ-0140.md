### REQ-0140: Structured `ConstraintExpr` AST Invariant Generation with De Morgan Normalization
- **Normative Statement**: The safety compiler shall construct invariants as strongly-typed `ConstraintExpr` AST structures, applying De Morgan's laws and algebraic normalization to emit clean Conjunctive Normal Form (CNF) representations.
- **Formal Semantics & Invariants**:
  The `ConstraintExpr` AST enum supports structured Boolean logic:
  ```rust
  pub enum ConstraintExpr<'a> {
      Literal(bool),
      Variable(Spur),
      Not(Box<ConstraintExpr<'a>>),
      And(Vec<ConstraintExpr<'a>>),
      Or(Vec<ConstraintExpr<'a>>),
      Relational(RelOp, Box<ConstraintExpr<'a>>, Box<ConstraintExpr<'a>>),
  }
  ```
  De Morgan normalization: $\neg(A \wedge B) \equiv (\neg A \vee \neg B)$ and $\neg(A \vee B) \equiv (\neg A \wedge \neg B)$.
- **Error Diagnostics & Quality Boundaries**:
  An unparsable or malformed constraint expression tree shall emit compiler error `E0416` (Malformed ConstraintExpr AST).
- **Acceptance Criteria**:
  - **AC-1**: Synthesizes invariants directly into `ConstraintExpr` AST structures without string concatenation.
  - **AC-2**: Normalizes complex negated expressions using De Morgan transformations.
  - **AC-3**: Serializes clean, parenthesized SysML v2 textual constraint syntax.
