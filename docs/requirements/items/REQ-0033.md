### REQ-0033: Deterministic Qualified-Name Symbol Sorting for Canonical Model Emission
- **Normative Statement**: The textual emitter shall sort all packages, classifiers, ports, attributes, and constraints strictly by alphabetical qualified name prior to emission. This guarantees 100% deterministic, bit-for-bit identical text output and eliminates git diff churn across compilations.
- **Formal Semantics & Invariants**:
  Let $\mathcal{D}$ be the list of declarations in an AST package. Prior to text emission:
  $$
  \mathcal{D}_{\text{sorted}} = \text{SortBy}(\mathcal{D}, \lambda d. \, \text{QualifiedName}(d))
  $$
  Where string ordering follows standard lexicographical ASCII byte comparison.
- **Error Diagnostics & Quality Boundaries**:
  Unstable or non-deterministic ordering in emitted model files shall fail validation with `E0118` (Non-Deterministic Model Serialization).
- **Acceptance Criteria**:
  - **AC-1**: All emitted AST declarations appear in strictly ascending alphabetical order by qualified name.
  - **AC-2**: Multiple runs with randomly shuffled input rows generate identical textual outputs.
  - **AC-3**: SHA-256 hash of `schema/model.sysml` is completely invariant across repeated runs.
