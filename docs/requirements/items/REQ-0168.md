### REQ-0168: Feature Layer 2: Logic, Dynamic Operations & Hierarchical State Machines
- **Normative Statement**: Feature specifications shall document Layer 2 by detailing all behavioral operations, action algorithms, input/output parameter signatures, precondition and postcondition constraints, and local state machine transitions.
- **Formal Semantics & Invariants**:
  Layer 2 emission extracts operational contracts:
  $$
  \text{OpContract}(A) = \langle \text{name}, \text{params}_{\text{in}}, \text{params}_{\text{out}}, \text{preconditions}, \text{postconditions} \rangle
  $$
  Operations must declare 100% typed parameter signatures matching AST `ActionDefNode`s for automated code synthesis.
- **Error Diagnostics & Quality Boundaries**:
  Operations missing typed parameter signatures shall emit compiler error `E0112`.
- **Acceptance Criteria**:
  - **AC-1**: Documents all operations with explicit typed parameter directions (`in`, `out`).
  - **AC-2**: Details precondition and postcondition invariant assertions.
  - **AC-3**: Embeds local component statecharts illustrating operational states.
