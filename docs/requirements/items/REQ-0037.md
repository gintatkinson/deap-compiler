### REQ-0037: High-Throughput String Interning (`lasso::Rodeo`) & 4-Byte `Spur` Tokens
- **Normative Statement**: The core compiler shall intern all identifier strings, type names, docstrings, and qualified paths using a high-throughput multi-threaded string interner pool (`lasso::Rodeo`), mapping all string occurrences to compact 4-byte `Spur` tokens.
- **Formal Semantics & Invariants**:
  Let $\mathcal{S}$ be the set of all string occurrences across schemas. The interner $\mathcal{I}$ establishes an injective mapping:
  $$
  \forall s_1, s_2 \in \mathcal{S}, \quad s_1 = s_2 \iff \mathcal{I}(s_1) = \mathcal{I}(s_2) \in \text{Spur}
  $$
  Memory footprint: Replacing arbitrary-length string structs with 4-byte `Spur` handles reduces AST node memory consumption by greater than 60%.
- **Error Diagnostics & Quality Boundaries**:
  Attempting to resolve an uninterned `Spur` token shall trigger `E0203` (Unresolved String Interner Key).
- **Acceptance Criteria**:
  - **AC-1**: String interning throughput exceeds 5,000,000 strings per second in single-threaded benchmarks.
  - **AC-2**: AST node structs contain only `Spur` handles for name and type fields.
  - **AC-3**: Resolving a `Spur` handle returns the exact original UTF-8 string slice.
