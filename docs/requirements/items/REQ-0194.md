### REQ-0194: Standardized Diagnostic Error Code Family E02xx: Metamodel, Typing & Dimensional Errors (`E0200`--`E0299`)
- **Normative Statement**: The diagnostic engine shall standardize all errors originating in metamodel resolution, type checking, scope lookups, cyclic hierarchies, and physical metrology into the `E02xx` code space (`E0200` through `E0299`).
- **Formal Semantics & Invariants**:
  The `E02xx` family includes:
  - `E0200`: Dangling Relationship Endpoints
  - `E0201`: Arena Handle Bounds Violation
  - `E0202`: Stale AST Handle Dereference
  - `E0204`: Untyped Feature Usage
  - `E0205`: Incompatible Port Direction Binding
  - `E0208`: Unresolved Symbol Reference
  - `E0210`: Cyclic Specialization Hierarchy
  - `E0220`: Dimensional Incoherence Fault
  - `E0221`: Non-Dimensionless Transcendental Argument
  - `E0226`: Parametric Value Outside Operational Envelope
  - `E0250`: Temporal Interval Relation Contradiction
  - `E0256`: Non-Deterministic State Transition Ambiguity
- **Error Diagnostics & Quality Boundaries**:
  All type checking and metrology failures shall strictly map to unique codes within `E0200`--`E0299`.
- **Acceptance Criteria**:
  - **AC-1**: Metamodel and typing errors assign documented `E02xx` diagnostic codes.
  - **AC-2**: Metrology and dimensional mismatches provide exact dimensional vector comparisons.
  - **AC-3**: Symbol resolution failures include candidate suggestions within visible scopes.
