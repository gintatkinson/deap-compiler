### REQ-0028: OMG IDL AST Ingestion for Structs, Interfaces & Directional Parameters
- **Normative Statement**: The ingestion engine shall provide an OMG IDL parser that parses `.idl` interface specifications into intermediate schema IR, lowering IDL structs and unions into data types, interfaces into component parts, and operations with directional parameters (`in`, `out`, `inout`) into typed action operations.
- **Formal Invariant**: Let $\mathcal{I}_{\text{idl}}$ be an IDL abstract syntax tree. The mapping $\mathcal{T}_{\text{idl}}$ satisfies:
$$
\begin{aligned}
\text{interface } I &\longmapsto \text{IngestedPart}(I, \text{is\_interface}: \text{true}) \\
\text{struct } S &\longmapsto \text{IngestedClassifierDef}(S, \text{kind}: \text{Struct}) \\
\text{union } U &\longmapsto \text{IngestedClassifierDef}(U, \text{kind}: \text{Union}) \\
\text{op}(in\, T_1\, p_1, out\, T_2\, p_2) &\longmapsto \text{IngestedAction}(\text{op}, \text{inputs}: [(p_1, T_1)], \text{outputs}: [(p_2, T_2)])
\end{aligned}
$$
Directional Parameter Invariant: Each parameter in an IDL operation binds an explicit direction:
$$
\forall p \in \text{Params}(\text{op}), \quad \text{dir}(p) \in \{ \text{In}, \text{Out}, \text{InOut} \}
$$
Module containment mapping: IDL `module` statements lower to nested `IngestedPackage` namespaces.
- **Computational Complexity & Algorithmic Bounds**: Parsing executes in linear $O(N)$ time with respect to IDL token count $N$, using deterministic recursive descent.
- **Verification & Conformance Criteria**: Verification suite compiles OMG IDL specifications for distributed middleware, ensuring bidirectional interface parity.
