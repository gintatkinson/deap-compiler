### REQ-0025: Tabular Schema Ingestion for Formal Constraints & Operational Envelopes
- **Normative Statement**: The ingestion engine shall parse tabular schemas defining formal constraints, safety conditions, and operational envelopes into `IngestedConstraint` entities. The parser shall capture constraint expressions, formal invariant types (`assert`, `assume`), and severity classifications.
- **Formal Semantics & Invariants**:
  An `IngestedConstraint` node is defined as:
  ```rust
  pub struct IngestedConstraint {
      pub id: Spur,
      pub owner: Spur,
      pub is_assertion: bool,
      pub raw_expression: String,
      pub severity: ConstraintSeverity, // Critical, Degraded, Advisory
  }
  ```
  Constraint text is preserved verbatim for downstream Boolean AST parsing and formal verification.
- **Error Diagnostics & Quality Boundaries**:
  An empty constraint expression string shall emit compiler error `E0110` (Empty Constraint Expression).
- **Acceptance Criteria**:
  - **AC-1**: Extracts constraints declared in tabular schemas and binds them to owning parts.
  - **AC-2**: Distinguishes between invariant assertions (`assert`) and operational assumptions (`assume`).
  - **AC-3**: Captures constraint docstrings and rationale descriptions.
