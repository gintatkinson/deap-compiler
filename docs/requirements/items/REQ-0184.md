### REQ-0184: ROS2 Node Architecture Emission: Publishers, Subscribers & QoS Profiles
- **Normative Statement**: The code generation engine shall generate native ROS2 C++ (`rclcpp`) node packages from structural components. Ports shall lower to ROS2 Publishers and Subscribers with user-configured Quality of Service (QoS) profiles (History, Depth, Reliability, Durability).
- **Formal Semantics & Invariants**:
  Mapping rules:
  - `part def C` $\Longrightarrow$ `class CNode : public rclcpp::Node`
  - `out port p : T` $\Longrightarrow$ `rclcpp::Publisher<T>::SharedPtr pub_p;`
  - `in port p : T` $\Longrightarrow$ `rclcpp::Subscription<T>::SharedPtr sub_p;`
  QoS profiles configure `rmw_qos_profile_t` based on AST port attributes.
- **Error Diagnostics & Quality Boundaries**:
  Attempting to emit ROS2 code for an un-typed port payload shall emit `E0204`.
- **Acceptance Criteria**:
  - **AC-1**: Generates complete, compilable ROS2 package directories (`CMakeLists.txt`, `package.xml`, source files).
  - **AC-2**: Correctly maps port directions to ROS2 publisher and subscriber handles.
  - **AC-3**: Configures reliable and best-effort QoS profiles based on model metadata.
