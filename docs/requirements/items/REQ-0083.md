### REQ-0083: SysML v2 CalculationDefinition (`calc def`) & CalculationUsage Lowering
- **Normative Statement**: The SysML v2 lowering engine shall lower `calc def` and `calc` usages into `CalculationDefNode` and `CalculationUsageNode` entities. Calculations shall model mathematical functions that compute output results from input parameters according to explicit expression bodies.
- **Formal Semantics & Invariants**:
  In SysML v2, `calc def` specializes KerML `Function`:
  $$
  \text{CalcDef} \le \text{Function}
  $$
  A calculation evaluates an expression $E(x_1, \dots, x_k)$ without mutating external state.
- **Error Diagnostics & Quality Boundaries**:
  A calculation expression with unresolvable variable names shall emit `E0224` (Operator Type Mismatch).
- **Acceptance Criteria**:
  - **AC-1**: Parses `calc def ComputePower { in v : Real; in i : Real; return v * i; }`.
  - **AC-2**: Binds calculations to component parametric analyses.
  - **AC-3**: Evaluates constant calculation expressions at compile time.
