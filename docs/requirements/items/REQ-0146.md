### REQ-0146: Declarative Pluggable Regulatory Safety Profiles Engine
- **Normative Statement**: The safety compiler shall implement a declarative, pluggable regulatory safety profiles engine. Safety profiles shall define domain-specific severity classifications, hazard log schema formats, and verification evidence checklists without polluting the core metamodel.
- **Formal Semantics & Invariants**:
  A safety profile $\mathcal{P}$ is defined as a declarative manifest:
  ```rust
  pub struct SafetyProfile {
      pub profile_id: Spur,
      pub severity_levels: Vec<Spur>,
      pub mandatory_artifacts: Vec<Spur>,
      pub compliance_rules: Vec<RuleId>,
  }
  ```
  Profiles are applied dynamically via CLI (`--safety-profile=<id>`), leaving `deap-ast` standard-agnostic.
- **Error Diagnostics & Quality Boundaries**:
  Encountering an unregistered or malformed regulatory profile identifier shall emit `E0422` (Unknown Regulatory Profile Identifier).
- **Acceptance Criteria**:
  - **AC-1**: Supports multiple pluggable safety profiles cleanly through external configuration.
  - **AC-2**: Core AST engine retains zero standard-specific keywords or hardcoded constants.
  - **AC-3**: Profile compliance checker validates required artifacts before declaring compliance.
