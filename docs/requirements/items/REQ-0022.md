### REQ-0022: Tabular Schema Ingestion for Directed Ports & Structural Interfaces
- **Normative Statement**: The ingestion engine shall parse tabular schemas specifying ports and structural interfaces into `IngestedPort` intermediate entities, extracting port identifiers, owning parts, port directions (`in`, `out`, `inout`), payload types, and conjugated interface markers (`~`).
- **Formal Invariant**: Port directions conform strictly to the direction enumeration $\text{Dir} \in \{\text{In}, \text{Out}, \text{InOut}\}$. Conjugated ports invert directionality according to algebraic involution $\tau_{\text{conj}}$:
$$
\tau_{\text{conj}}(\text{In}) = \text{Out}, \quad \tau_{\text{conj}}(\text{Out}) = \text{In}, \quad \tau_{\text{conj}}(\text{InOut}) = \text{InOut}
$$
Involution Identity Invariant:
$$
\tau_{\text{conj}}(\tau_{\text{conj}}(d)) \equiv d \quad \forall d \in \text{Dir}
$$
Port Typing Relation: Every `IngestedPort` entity maps to an owned parent part definition and binds an interface payload data type handle:
$$
\text{PortDef} = \langle \text{id}, \text{owner}, d \in \text{Dir}, \tau_{\text{payload}}, \text{is\_conjugated} \in \mathbb{B} \rangle
$$
- **Computational Complexity & Algorithmic Bounds**: Port ingestion executes in $O(R)$ time with respect to port table rows, with $O(1)$ constant-time involution mapping.
- **Verification & Conformance Criteria**: Verification tests confirm conjugated ports correctly invert input and output flows while preserving payload typing.
