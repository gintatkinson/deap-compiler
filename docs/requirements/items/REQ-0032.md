### REQ-0032: Canonical SysML v2 Textual Model Emission (`schema/model.sysml`)
- **Normative Statement**: The ingestion engine shall provide a canonical SysML v2 textual emitter (`emitter.rs`) that synthesizes parsed intermediate schema IR entities into standard-compliant SysML v2 textual notation, writing the unified canonical model to `schema/model.sysml`.
- **Formal Semantics & Invariants**:
  The emission function $\mathcal{E}_{\text{sysml}}$ translates intermediate entities into normative syntax:
  $$
  \begin{aligned}
  \text{IngestedPackage}(P) &\Longrightarrow \text{"package "} \mathbin{\Vert} P \mathbin{\Vert} \text{" { ... }"} \\
  \text{IngestedPart}(C) &\Longrightarrow \text{"part def "} \mathbin{\Vert} C \mathbin{\Vert} \text{" { ... }"} \\
  \text{IngestedPort}(p) &\Longrightarrow \text{"port "} \mathbin{\Vert} p \mathbin{\Vert} \text(" : ") \mathbin{\Vert} T \mathbin{\Vert} \text(";") \\
  \text{IngestedConstraint}(k) &\Longrightarrow \text{"assert constraint { "} \mathbin{\Vert} \text{expr} \mathbin{\Vert} \text{" };"}
  \end{aligned}
  $$
- **Error Diagnostics & Quality Boundaries**:
  Failure to format or write the synthesized textual model shall emit `E0117` (Canonical Model Emission Failure).
- **Acceptance Criteria**:
  - **AC-1**: Emits valid, parseable SysML v2 syntax conforming to the official OMG grammar.
  - **AC-2**: Includes packages, part definitions, port usages, attribute usages, and constraint blocks.
  - **AC-3**: Output file `schema/model.sysml` is written atomically and formatted cleanly.
