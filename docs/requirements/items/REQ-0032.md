### REQ-0032: Deterministic Qualified-Name Symbol Sorting for Canonical Model Emission
- **Normative Statement**: The textual emitter shall sort all packages, classifiers, ports, attributes, and constraints strictly by alphabetical qualified name prior to emission to guarantee 100% deterministic, bit-for-bit identical text output and eliminate git diff churn across compilations.
- **Formal Invariant**: Let $\mathcal{D}$ be the list of declarations in an AST package. Prior to text emission:
$$
\mathcal{D}_{\text{sorted}} = \text{SortBy}(\mathcal{D}, \lambda d. \, \text{QualifiedName}(d))
$$
where string comparison follows standard lexicographical ASCII byte ordering:
$$
s_1 < s_2 \iff \exists i \ge 0 : (\forall j < i, s_1[j] = s_2[j]) \wedge (s_1[i] < s_2[i])
$$
Strict Total Ordering Invariant:
$$
\forall d_1 \neq d_2 \in \mathcal{D}, \quad \text{QualifiedName}(d_1) < \text{QualifiedName}(d_2) \vee \text{QualifiedName}(d_2) < \text{QualifiedName}(d_1)
$$
Zero Diff Churn Invariant: Repeated emission passes over unchanged AST representations produce identical line-by-line textual files.
- **Computational Complexity & Algorithmic Bounds**: Sorting $M$ declarations executes in deterministic $O(M \log M)$ time, bounded by total declaration count.
- **Verification & Conformance Criteria**: Automated test asserts zero git diff across repeated runs on randomly shuffled declaration inputs.
