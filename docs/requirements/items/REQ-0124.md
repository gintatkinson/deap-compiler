### REQ-0124: Complete State Machine Reachability Analysis & Dead State Diagnostics
- **Normative Statement**: The state machine compiler shall perform an exhaustive reachability analysis across the complete state space. Any declared state lacking an execution path from the initial state shall be flagged as a dead state.
- **Formal Semantics & Invariants**:
  Let $S_0$ be the initial state and $\delta : \text{States} \times \text{Events} \times \text{Guards} \longrightarrow \text{States}$ be the transition function. The reachable state set $\mathcal{R}$ is the transitive closure:
  $$
  \mathcal{R} = \mu X. \left( \{ S_0 \} \cup \{ s' \in \text{States} \mid \exists s \in X, \, \exists e \text{ such that } s' \in \delta(s, e) \} \right)
  $$
  Dead states: $\mathcal{D}_{\text{dead}} = \text{States} \setminus \mathcal{R}$.
- **Error Diagnostics & Quality Boundaries**:
  Discovery of an unreachable dead state shall emit compiler error `E0257` (Unreachable State Detected).
- **Acceptance Criteria**:
  - **AC-1**: Computes full reachable state space for all state machines in the model.
  - **AC-2**: Flags dead, disconnected states with explicit file and line diagnostic spans.
  - **AC-3**: Validates reachability across nested hierarchical statecharts.
