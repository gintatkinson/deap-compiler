### REQ-0174: Use Cases Projection: Operational Flows, Primary Path & Step Traversal
- **Normative Statement**: The projection engine shall synthesize Use Cases (`docs/use-cases/uc-*.md`) modeling end-to-end operational workflows. Every Use Case shall specify primary operational paths, participating actors, preconditions, postconditions, and sequential step traversals derived from AST `Interaction` and `Activity` models.
- **Formal Semantics & Invariants**:
  A Use Case $U$ formalizes an operational sequence:
  $$
  U = \langle \text{actors}, \text{preconditions}, \text{steps}: \langle s_1, s_2, \dots, s_k \rangle, \text{postconditions} \rangle
  $$
  Each step $s_i$ references a specific AST `ActionUsage` or message transfer between system actors.
- **Error Diagnostics & Quality Boundaries**:
  A Use Case step referencing an undefined actor or action shall emit `E0509` (Unresolved Element in Use Case Step).
- **Acceptance Criteria**:
  - **AC-1**: Generates structured Use Case specifications from AST interaction models.
  - **AC-2**: Catalogs all external actors and system boundaries cleanly.
  - **AC-3**: Primary flow steps trace directly to executable action nodes.
