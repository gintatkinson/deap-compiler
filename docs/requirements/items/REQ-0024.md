### REQ-0024: Tabular Schema Ingestion for Attributes, Data Types & Numerical Envelopes
- **Normative Statement**: The ingestion engine shall parse tabular schemas defining attributes, data types, default values, engineering units, and numerical bounds into `IngestedAttr` intermediate entities. Numerical envelopes shall be extracted as closed, half-open, or open real intervals.
- **Formal Semantics & Invariants**:
  An `IngestedAttr` node is defined as:
  ```rust
  pub struct IngestedAttr {
      pub id: Spur,
      pub owner: Spur,
      pub data_type: Spur,
      pub unit: Option<Spur>,
      pub default_val: Option<String>,
      pub lower_bound: Option<f64>,
      pub upper_bound: Option<f64>,
  }
  ```
  Invariant: If both $\text{lower\_bound}$ ($L$) and $\text{upper\_bound}$ ($U$) exist, then $L \le U$.
- **Error Diagnostics & Quality Boundaries**:
  Attribute bound violation where lower bound exceeds upper bound ($L > U$) shall emit `E0109` (Inverted Attribute Bounds).
- **Acceptance Criteria**:
  - **AC-1**: Ingests attributes with primitive data types (`Real`, `Integer`, `Boolean`, `String`).
  - **AC-2**: Extracts upper, lower, and nominal bounds into typed numeric fields.
  - **AC-3**: Preserves engineering unit tokens (e.g. `m/s`, `V`, `kg`) for subsequent metrology analysis.
