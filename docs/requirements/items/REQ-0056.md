### REQ-0056: KerML Namespace, Membership, OwningMembership & Qualified Naming
- **Normative Statement**: The KerML lowering engine shall implement the normative KerML namespace membership model. A `Namespace` element shall contain `Membership` relationships that bind member names to referenced elements, distinguishing between owning memberships (`OwningMembership`) and non-owning reference memberships.
- **Formal Semantics & Invariants**:
  Let $N$ be a `Namespace`. Membership $M \in \text{memberships}(N)$ binds a member name $\text{name}(M) \in \text{Spur}$ to element $E$. The qualified name $\text{QN}(E)$ is recursively defined as:
  $$
  \text{QN}(E) = \begin{cases}
  \text{name}(E), & \text{if } \text{owner}(E) = \text{None} \\
  \text{QN}(\text{owner}(E)) \mathbin{\Vert} \text{"::"} \mathbin{\Vert} \text{name}(E), & \text{otherwise}
  \end{cases}
  $$
  Uniqueness invariant: Within a single namespace $N$, all member names must be pairwise distinct.
- **Error Diagnostics & Quality Boundaries**:
  Duplicate member names declared within the same namespace shall emit compiler error `E0215` (Duplicate Member Name in Namespace).
- **Acceptance Criteria**:
  - **AC-1**: Correctly constructs namespaces with owning and non-owning memberships.
  - **AC-2**: Fully qualified names compute deterministically for deeply nested elements.
  - **AC-3**: Rejects naming collisions within a namespace with clear source location pointers.
