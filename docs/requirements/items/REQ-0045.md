### REQ-0045: Immutable AST Graph Traversal Engine with Bounded Linear Complexity
- **Normative Statement**: The AST engine shall provide an immutable graph traversal engine that visits nodes in topological, depth-first, or breadth-first order with strictly bounded $O(V + E)$ linear time complexity. Traversal algorithms must operate strictly over immutable references without allocating temporary graph structures or mutating node payloads.
- **Formal Invariant**: Graph traversal over AST model multigraph $G = (V, E)$ visits all reachable vertices and directed edges satisfying:
$$
T_{\text{traversal}}(G) \le c \cdot (|V| + |E|)
$$
Immutability & Zero Heap Mutation Invariant:
$$
\text{Mutations}(\text{Traverse}(G, \text{Visitor})) = 0, \quad \text{HeapAllocs}(\text{Traverse}) = 0
$$
Visiting Completeness Invariant:
$$
\forall v \in V \text{ reachable from } v_0, \quad \text{VisitedCount}(v) = 1
$$
Cycle Resilience: Visited bitsets or generational markers guarantee termination without infinite looping on cyclic reference graphs.
- **Computational Complexity & Algorithmic Bounds**: Traversal execution is $O(|V| + |E|)$ time with $O(|V|)$ bitset memory overhead for cycle protection.
- **Verification & Conformance Criteria**: Verification suite executes traversal across complex graph topologies with $10^5$ nodes and confirms exact linear runtime scaling.
