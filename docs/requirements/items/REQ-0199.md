### REQ-0199: Non-Destructive Markdown Parser & Memory-Mapped AST Mutation Engine
- **Normative Statement**: The reverse synchronization engine shall implement a non-destructive Markdown parser that extracts edits to parameters, docstrings, and constraints while preserving custom human prose sections, explanatory diagrams, and formatting untouched.
- **Formal Semantics & Invariants**:
  Let $D_{\text{orig}}$ be the on-disk markdown text. The non-destructive reconciliation $\mathcal{R}_{\text{md}}$ produces updated text $D_{\text{updated}}$:
  $$
  D_{\text{updated}} = \text{MergePreservingProse}(D_{\text{orig}}, \Delta_{\text{AST}})
  $$
  All non-generated markdown sections (user notes, rationale blocks) are preserved byte-for-byte.
- **Error Diagnostics & Quality Boundaries**:
  Parsing collisions or ambiguous markdown structural modifications shall emit `E0514` (Non-Destructive Markdown Parse Collision).
- **Acceptance Criteria**:
  - **AC-1**: Merges AST updates into existing Markdown documents without overwriting human prose.
  - **AC-2**: Preserves user-authored comments and custom explanatory notes.
  - **AC-3**: Memory-mapped parsing prevents reading files into slow intermediate heap strings.
