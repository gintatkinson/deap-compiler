### REQ-0023: Tabular Schema Ingestion for Directed Ports & Physical Interfaces
- **Normative Statement**: The ingestion engine shall parse tabular schemas specifying ports and physical interfaces into `IngestedPort` intermediate entities. The parser shall extract port identifiers, owning parts, port directions (`in`, `out`, `inout`), protocol types, and conjugated interface markers (`~`).
- **Formal Semantics & Invariants**:
  An `IngestedPort` node is represented as:
  ```rust
  pub struct IngestedPort {
      pub id: Spur,
      pub owner: Spur,
      pub direction: PortDirection, // In, Out, InOut
      pub payload_type: Spur,
      pub is_conjugated: bool,
      pub protocol: Option<Spur>,
  }
  ```
  Port directions must conform strictly to the direction enumeration; missing or invalid direction tokens fail validation.
- **Error Diagnostics & Quality Boundaries**:
  An unrecognized port direction token shall emit compiler error `E0108` (Invalid Port Direction).
- **Acceptance Criteria**:
  - **AC-1**: Ports table extracts all declared ports with correct directions (`in`, `out`, `inout`).
  - **AC-2**: Conjugated ports (`~PortType`) are flagged with `is_conjugated = true`.
  - **AC-3**: Port payload types correctly resolve against known data types during symbol resolution.
