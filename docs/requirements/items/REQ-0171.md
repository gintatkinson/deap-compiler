### REQ-0171: User Stories Projection: Deterministic Gherkin BDD Synthesis from AST Constraints
- **Normative Statement**: The projection engine shall synthesize User Stories (`docs/user-stories/us-*.md`) containing formal Given-When-Then BDD Gherkin scenarios. Scenarios shall be deterministically derived from AST `ConstraintDefNode`s and `ActionDefNode`s rather than hallucinated from prose.
- **Formal Semantics & Invariants**:
  A synthesized BDD scenario is structured as:
  ```gherkin
  Scenario: [Scenario Title Derived from Constraint]
    Given the system is in state "[StatePrecondition]"
    And parameter "[ParamName]" is initialized to [NominalValue] [Unit]
    When action "[ActionName]" is invoked with input "[InputValue]"
    Then state variable "[OutputName]" shall satisfy "[ConstraintPredicate]"
    And system state shall transition to "[TargetState]"
  ```
- **Error Diagnostics & Quality Boundaries**:
  Generating a Gherkin scenario with unbound or synthetic parameter names shall emit `E0119`.
- **Acceptance Criteria**:
  - **AC-1**: Derives Given-When-Then scenarios directly from AST constraint predicates.
  - **AC-2**: Scenario parameters match declared AST attributes and units.
  - **AC-3**: Formats standard Gherkin syntax ready for automated test execution.
