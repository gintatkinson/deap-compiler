### REQ-0065: KerML Disjoining, Differencing, Intersecting & Unioning Type Algebra
- **Normative Statement**: The KerML lowering engine shall implement the normative KerML set-theoretic type operators: type union (`union`), type intersection (`intersect`), type differencing (`diff`), and type disjoining (`disjoint`).
- **Formal Semantics & Invariants**:
  Let $T_1$ and $T_2$ be types with instance sets $\mathcal{I}(T_1)$ and $\mathcal{I}(T_2)$. The type algebra operators evaluate as:
  $$
  \begin{aligned}
  \mathcal{I}(T_1 \cup T_2) &= \mathcal{I}(T_1) \cup \mathcal{I}(T_2) \\
  \mathcal{I}(T_1 \cap T_2) &= \mathcal{I}(T_1) \cap \mathcal{I}(T_2) \\
  \mathcal{I}(T_1 \setminus T_2) &= \mathcal{I}(T_1) \setminus \mathcal{I}(T_2) \\
  T_1 \text{ disjoint } T_2 &\iff \mathcal{I}(T_1) \cap \mathcal{I}(T_2) = \emptyset
  \end{aligned}
  $$
- **Error Diagnostics & Quality Boundaries**:
  Declaring an instance of two types marked `disjoint` shall emit compiler error `E0223` (Disjoint Type Intersection Violation).
- **Acceptance Criteria**:
  - **AC-1**: Parses union, intersect, and difference type expressions.
  - **AC-2**: Enforces disjointness assertions during classifier instantiation.
  - **AC-3**: Type checker correctly computes common supertypes and subtypes using the type algebra lattice.
