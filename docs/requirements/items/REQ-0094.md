### REQ-0094: KerML Standard Library: `Collections` Package (Set, Sequence, OrderedSet, Bag)
- **Normative Statement**: The KerML lowering engine shall provide built-in bindings for the normative KerML `Collections` library (`sysml.library/Kernel Libraries/Kernel Data Type Library/Collections.kerml`), supporting collection data structures: `Set`, `Sequence`, `OrderedSet`, and `Bag`, along with collection operations (size, contains, union, intersection).
- **Formal Semantics & Invariants**:
  Collection types parameterize over element type $T$: `Collection<T>`. Collection kinds enforce uniqueness and ordering:
  $$
  \begin{aligned}
  \text{Set}<T> &: \text{Unique} = \text{true}, \quad \text{Ordered} = \text{false} \\
  \text{Sequence}<T> &: \text{Unique} = \text{false}, \quad \text{Ordered} = \text{true} \\
  \text{OrderedSet}<T> &: \text{Unique} = \text{true}, \quad \text{Ordered} = \text{true} \\
  \text{Bag}<T> &: \text{Unique} = \text{false}, \quad \text{Ordered} = \text{false}
  \end{aligned}
  $$
- **Error Diagnostics & Quality Boundaries**:
  Invoking unsupported collection operations or element type mismatches shall emit `E0259` (Collection Type Error).
- **Acceptance Criteria**:
  - **AC-1**: Pre-loads and binds KerML `Collections` library definitions.
  - **AC-2**: Evaluates collection operations (e.g. `size()`, `includes()`) in constant folding.
  - **AC-3**: Enforces collection uniqueness and ordering constraints during AST validation.
