### REQ-0094: KerML Standard Library: `ControlFunctions` Package (Decision, Merge, Fork, Join)
- **Normative Statement**: The compiler shall bootstrap the normative KerML `ControlFunctions` standard library package, formalizing Petri net token-passing primitives (`Decision`, `Merge`, `Fork`, `Join`) for behavioral action control graphs.
- **Formal Invariant**: Control flow primitives operate on execution token multisets:
$$
\begin{aligned}
\text{Fork} &: \bullet t \to \{ t_1, \dots, t_k \} \quad (1 \text{ token produces } k \text{ concurrent tokens}) \\
\text{Join} &: \{ t_1, \dots, t_k \} \to t_\bullet \quad (\text{requires arrival of tokens from all } k \text{ incoming paths}) \\
\text{Decision} &: \bullet t \to t_i \quad (\text{token routed to unique outgoing branch where } g_i(\sigma) = \text{true}) \\
\text{Merge} &: t_j \to t_\bullet \quad (\text{first arriving incoming token immediately passes through})
\end{aligned}
$$
Join deadlock freedom: Invariant requires that all $k$ incoming branches to a `Join` originate from a common ancestor `Fork` without conflicting guard muting.
Complexity bound: Token dispatch and control node evaluation execute in deterministic $O(1)$ amortized time.
