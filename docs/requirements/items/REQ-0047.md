### REQ-0047: Mutable AST Transformer Trait API (`VisitorMut`) for In-Place Rewrites
- **Normative Statement**: The AST engine shall provide a mutable transformer trait (`VisitorMut`) enabling in-place AST rewrites, constant folding, constraint injection, and dead node elimination across the model arena.
- **Formal Semantics & Invariants**:
  The `VisitorMut` trait allows in-place mutation of arena elements:
  ```rust
  pub trait VisitorMut {
      fn mutate_part_def(&mut self, node: &mut PartDefNode) {}
      fn mutate_constraint(&mut self, node: &mut ConstraintDefNode) {}
  }
  ```
  Generational counters on modified nodes increment upon mutation to invalidate stale external handles.
- **Error Diagnostics & Quality Boundaries**:
  Illegal AST transformations violating metamodel invariants shall emit `E0214` (AST Mutation Invariant Violation).
- **Acceptance Criteria**:
  - **AC-1**: Transforms AST expressions in-place without reallocating node containers.
  - **AC-2**: Automatically increments node generational counters upon mutation.
  - **AC-3**: Preserves arena integrity and reference consistency throughout complex multi-pass rewrites.
