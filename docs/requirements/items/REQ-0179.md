### REQ-0179: Streaming Artifact Sink Trait (`ArtifactSink`) & Direct IO Writer Closures
- **Normative Statement**: The code emission engine shall implement a streaming artifact sink architecture via the `ArtifactSink` trait. Emission shall use closure-based streaming dispatch (`emit_artifact(PathBuf, Box<dyn FnOnce(&mut dyn Write)>)`), streaming text directly into memory-mapped buffers or file descriptors to eliminate batch-collected in-memory buffering spikes.
- **Formal Semantics & Invariants**:
  The `Emitter` trait is defined as:
  ```rust
  pub trait Emitter {
      fn emit_stream(
          &self,
          ctx: &GenerationContext,
          sink: &mut dyn ArtifactSink
      ) -> Result<(), CodegenError>;
  }
  ```
  Memory bound: Peak memory consumption during multi-gigabyte codebase emission remains strictly bounded to under 100 MB RSS.
- **Error Diagnostics & Quality Boundaries**:
  IO write errors during streaming dispatch shall emit compiler error `E0503` (Artifact Streaming IO Error).
- **Acceptance Criteria**:
  - **AC-1**: Emits artifacts via direct writer closures without buffering full file contents in RAM.
  - **AC-2**: Avoids multi-megabyte heap allocation spikes during large batch emission runs.
  - **AC-3**: Supports streaming to both filesystem destinations and in-memory test sinks.
