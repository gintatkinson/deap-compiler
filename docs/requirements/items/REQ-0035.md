### REQ-0035: Zero-Copy Contiguous Typed Node Arena Allocation (`CompiledModelArena`)
- **Normative Statement**: The compiler core shall implement a contiguous, typed node arena architecture (`CompiledModelArena`) in `crates/deap-core`. All AST nodes (Packages, PartDefs, PortDefs, ActionDefs, ConstraintDefs) shall be allocated in flat, cache-friendly vectors, eliminating pointer indirection and heap allocator thrashing.
- **Formal Semantics & Invariants**:
  The arena structure is defined as:
  ```rust
  pub struct CompiledModelArena {
      pub packages: Vec<PackageNode>,
      pub part_defs: Vec<PartDefNode>,
      pub port_defs: Vec<PortDefNode>,
      pub action_defs: Vec<ActionDefNode>,
      pub constraint_defs: Vec<ConstraintDefNode>,
      pub string_pool: lasso::Rodeo,
  }
  ```
  Lowering time complexity: Ingested schemas lower into `CompiledModelArena` in strict linear time $O(N)$ with zero per-node heap allocations.
- **Error Diagnostics & Quality Boundaries**:
  Arena index out of bounds shall emit fatal compiler diagnostic `E0201` (Arena Handle Bounds Violation).
- **Acceptance Criteria**:
  - **AC-1**: Ingests and lowers 100,000 AST nodes in under 4 milliseconds into `CompiledModelArena`.
  - **AC-2**: Node allocations execute entirely within pre-allocated contiguous memory pools.
  - **AC-3**: Arena traversal exhibits zero cache-miss pointer chasing during linear iteration.
