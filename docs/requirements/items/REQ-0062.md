### REQ-0062: KerML Subsetting Relationship (`:>`) Lowering & Co-variance Invariants
- **Normative Statement**: The KerML lowering engine shall implement KerML feature subsetting (`:>`). Subsetting shall declare that the value set of a subsetting feature is contained within the value set of the subsetted feature, enforcing co-variant type specialization and multiplicity narrowing.
- **Formal Semantics & Invariants**:
  Let $f_1$ subset $f_2$ ($f_1 :> f_2$). The subsetting invariant requires:
  $$
  \forall o \in \text{Instances}, \quad \text{Values}(o, f_1) \subseteq \text{Values}(o, f_2)
  $$
  Type conformance: $\text{type}(f_1) \le \text{type}(f_2)$ (co-variant specialization).
  Multiplicity conformance: $\text{mult}(f_1).\max \le \text{mult}(f_2).\max$.
- **Error Diagnostics & Quality Boundaries**:
  Subsetting with an incompatible or contravariant type shall emit compiler error `E0220` (Contravariant Subsetting Type Violation).
- **Acceptance Criteria**:
  - **AC-1**: Parses `:>` subsetting syntax and establishes subsetting AST relations.
  - **AC-2**: Verifies that the subsetting feature's type specializes the subsetted feature's type.
  - **AC-3**: Verifies that multiplicity bounds narrow or match the parent feature.
