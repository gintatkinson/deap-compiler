### REQ-0051: AST Slice Serialization Contract with Reified Dependency Envelopes
- **Normative Statement**: The AST slicing engine shall serialize extracted slices according to a strict contract containing a reified dependency envelope. The envelope shall include all referenced type definitions, unit systems, and constraint declarations required to evaluate the sliced component in isolation.
- **Formal Semantics & Invariants**:
  The serialized slice envelope contains:
  ```rust
  pub struct SliceEnvelope {
      pub target_node: NodeId,
      pub boundary_ports: Vec<PortDefNode>,
      pub internal_parts: Vec<PartDefNode>,
      pub reified_types: Vec<ClassifierDefNode>,
      pub active_constraints: Vec<ConstraintDefNode>,
  }
  ```
  Closure property: Every symbol referenced within $G_{\text{slice}}$ is defined either within $G_{\text{slice}}$ or within `reified_types`.
- **Error Diagnostics & Quality Boundaries**:
  Dangling type references in sliced envelopes shall emit `E0231` (Incomplete Slice Dependency Closure).
- **Acceptance Criteria**:
  - **AC-1**: Slice envelope parses and validates independently as a standalone SysML model.
  - **AC-2**: No unresolved symbol errors occur when analyzing the isolated slice envelope.
  - **AC-3**: Serializes cleanly to both minified JSON and compact textual SysML notation.
