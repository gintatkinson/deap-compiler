### REQ-0016: Event-Driven CommonMark Table Lexer & Token Streaming
- **Normative Statement**: The ingestion engine shall implement an event-driven CommonMark table lexer (`readers/markdown.rs`) utilizing a pull-parser token stream (`pulldown-cmark`) to eliminate regular expression catastrophic backtracking. The lexer shall extract structured table rows, columns, and cell tokens directly from the document AST.
- **Formal Semantics & Invariants**:
  The Markdown lexer is modeled as an event stream $\mathcal{S}_{\text{events}} = \langle e_1, e_2, \dots, e_n \rangle$, where $e_i \in \{ \text{Start(Table)}, \text{Start(TableHead)}, \text{Start(TableRow)}, \text{Start(TableCell)}, \text{Text}(s), \text{End}(...) \}$.
  Parsing complexity is bounded strictly to $O(N)$ where $N$ is input byte length, eliminating super-linear regular expression evaluation.
- **Error Diagnostics & Quality Boundaries**:
  Malformed table syntax (e.g. unclosed tables or mismatched cell counts) shall emit `E0101` (Malformed Markdown Table Syntax).
- **Acceptance Criteria**:
  - **AC-1**: Successfully lexes CommonMark tables of arbitrary row counts without invoking regular expressions.
  - **AC-2**: Zero catastrophic backtracking vulnerabilities when processing tables with deeply nested or repeated characters.
  - **AC-3**: Accurately extracts table headers, row boundaries, and individual cell content strings.
