### REQ-0076: SysML v2 InterfaceDefinition (`interface def`) & InterfaceUsage Lowering
- **Normative Statement**: The SysML v2 lowering engine shall lower `interface def` and `interface` usages into `InterfaceDefNode` and `InterfaceUsageNode` entities. Interfaces shall model contracts specifying compatible port pairs and allowable interaction protocols between connecting parts.
- **Formal Semantics & Invariants**:
  An `interface def` $I$ defines complementary end roles: `end role_a: Port_A` and `end role_b: ~Port_A`.
  An `interface` usage binds specific component ports to these contract roles, enforcing protocol adherence.
- **Error Diagnostics & Quality Boundaries**:
  Connecting ports that do not satisfy the interface definition contract shall emit `E0302` (Interface Contract Violation).
- **Acceptance Criteria**:
  - **AC-1**: Parses `interface def BusInterface { ... }` with declared end roles.
  - **AC-2**: Validates that connected ports conform to the specified interface roles.
  - **AC-3**: Preserves protocol state machine constraints attached to interface definitions.
