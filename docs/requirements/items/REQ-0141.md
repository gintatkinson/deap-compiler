### REQ-0141: FMECA Failure Mode Synthesis across 4 Universal Dimensions (Interface, State, Action, Resource)
- **Normative Statement**: The safety compiler shall synthesize Failure Mode, Effects, and Criticality Analysis (FMECA) records across the 4 universal failure dimensions: Interface (signal loss/corruption), State (stuck/invalid mode), Action (failed execution/timing fault), and Resource (energy/memory exhaustion).
- **Formal Semantics & Invariants**:
  For every component $C$, failure modes are generated across the product space:
  $$
  \mathcal{F}(C) = \{ (c, d, m) \mid c \in \text{Elements}(C), \, d \in \{ \text{Interface}, \text{State}, \text{Action}, \text{Resource} \}, \, m \in \text{FailureKinds}(d) \}
  $$
  Failure propagation: Effects cascade through connected ports in `AstModelGraph` to determine system-level consequences.
- **Error Diagnostics & Quality Boundaries**:
  Unmapped or unpropagated failure modes in critical components shall emit warning `E0417` (Unpropagated Failure Mode in Critical Path).
- **Acceptance Criteria**:
  - **AC-1**: Systematically generates failure modes across all 4 universal failure dimensions.
  - **AC-2**: Traces failure propagation across component connection graphs to system boundaries.
  - **AC-3**: Emits structured FMECA markdown tables into verification documentation.
