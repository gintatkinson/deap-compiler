### REQ-0093: KerML Standard Library: `ScalarValues` Package (Boolean, Integer, Real, String)
- **Normative Statement**: The KerML lowering engine shall provide built-in bindings for the normative KerML `ScalarValues` library (`sysml.library/Kernel Libraries/Kernel Data Type Library/ScalarValues.kerml`), providing canonical representations and operations for `Boolean`, `Integer`, `Real`, `Natural`, `Positive`, and `String` data types.
- **Formal Semantics & Invariants**:
  The scalar types are bound to native compiler primitives:
  $$
  \begin{aligned}
  \text{ScalarValues::Boolean} &\longleftrightarrow \text{bool} \\
  \text{ScalarValues::Integer} &\longleftrightarrow \text{i64} \\
  \text{ScalarValues::Real} &\longleftrightarrow \text{f64} \\
  \text{ScalarValues::String} &\longleftrightarrow \text{Spur}
  \end{aligned}
  $$
  Subtyping: $\text{Positive} \le \text{Natural} \le \text{Integer} \le \text{Real}$.
- **Error Diagnostics & Quality Boundaries**:
  Out-of-range integer literals violating subrange bounds (e.g. negative value for `Positive`) shall emit `E0258` (Scalar Subrange Bound Violation).
- **Acceptance Criteria**:
  - **AC-1**: Pre-loads and binds `ScalarValues` package definitions into the type lattice.
  - **AC-2**: Validates numeric literals against scalar type bounds at compile time.
  - **AC-3**: Type promotion rules correctly promote `Integer` to `Real` in mixed arithmetic expressions.
