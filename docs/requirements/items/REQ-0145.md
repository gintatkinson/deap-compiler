### REQ-0145: Control Barrier Function (CBF) Forward Invariance Contract Formulation
- **Normative Statement**: The safety compiler shall formulate Control Barrier Function (CBF) forward invariance contracts for critical state constraints. For a safe set $\mathcal{C} = \{ \mathbf{x} \mid h(\mathbf{x}) \ge 0 \}$, the compiler shall enforce that the control law maintains forward invariance of $\mathcal{C}$.
- **Formal Semantics & Invariants**:
  Let $h(\mathbf{x})$ be a continuously differentiable function. The CBF condition requires:
  $$
  \sup_{u \in U} \left[ \nabla h(\mathbf{x}) \cdot f(\mathbf{x}, u) + \alpha(h(\mathbf{x})) \right] \ge 0, \quad \forall \mathbf{x} \in \mathcal{C}
  $$
  Where $\alpha$ is an extended class $\mathcal{K}$ function. This guarantees that if $\mathbf{x}(0) \in \mathcal{C}$, then $\mathbf{x}(t) \in \mathcal{C}$ for all $t \ge 0$.
- **Error Diagnostics & Quality Boundaries**:
  An unresolvable CBF inequality indicating an uncontrollable state boundary shall emit `E0421` (Uncontrollable State Boundary Breach).
- **Acceptance Criteria**:
  - **AC-1**: Synthesizes formal CBF constraints from operational envelope bounds.
  - **AC-2**: Formulates Quadratic Program (QP) barrier filter contracts for online control.
  - **AC-3**: Emits SMT-LIB2 proof obligations verifying forward invariance of the safe set.
