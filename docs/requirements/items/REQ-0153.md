### REQ-0153: Dangling Port Gate & Unconnected Interface Compile-Time Failure
- **Normative Statement**: The ICD engine shall enforce a compile-time dangling port gate. Every mandatory component boundary port declared in the architecture must be connected to a valid destination port or explicitly terminated with an approved termination marker. Unconnected dangling ports shall cause compilation failure.
- **Formal Semantics & Invariants**:
  Let $\mathcal{P}_{\text{mandatory}}$ be the set of non-optional ports. The dangling port gate verifies:
  $$
  \forall p \in \mathcal{P}_{\text{mandatory}}, \quad \exists c \in \text{Connections} \quad \text{such that } p \in \text{endpoints}(c) \vee \text{IsTerminated}(p)
  $$
- **Error Diagnostics & Quality Boundaries**:
  Discovery of an unconnected mandatory port shall emit compiler error `E0301` (Dangling Port Gate Violation).
- **Acceptance Criteria**:
  - **AC-1**: Scans entire model graph for unconnected input or output ports.
  - **AC-2**: Rejects builds containing unlinked interfaces with precise source location diagnostics.
  - **AC-3**: Supports explicit termination annotations (`@Terminated`) for intentionally unused ports.
