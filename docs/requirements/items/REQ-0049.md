### REQ-0049: Topological Sort Dependency Scheduling (Tarjan SCC & Kahn Algorithms)
- **Normative Statement**: The compiler engine shall provide topological sorting and strongly connected component algorithms (Kahn and Tarjan algorithms) over `AstModelGraph` to determine optimal compilation orders, code generation schedules, and initialization sequences.
- **Formal Semantics & Invariants**:
  Let $G = (V, E)$ be the dependency DAG. The topological sort algorithm produces an ordered sequence $\mathcal{L} = \langle v_1, v_2, \dots, v_n \rangle$ satisfying:
  $$
  \forall (u, v) \in E, \quad \text{Index}(u, \mathcal{L}) < \text{Index}(v, \mathcal{L})
  $$
  Complexity: $O(|V| + |E|)$ time and $O(|V|)$ auxiliary space.
- **Error Diagnostics & Quality Boundaries**:
  Cyclic dependencies preventing topological sorting shall emit `E0210` with the complete cycle trace.
- **Acceptance Criteria**:
  - **AC-1**: Produces a valid linear ordering of components for code emission.
  - **AC-2**: Accurately isolates independent components for parallel processing.
  - **AC-3**: Identifies strongly connected components to assist in cyclic dependency remediation.
