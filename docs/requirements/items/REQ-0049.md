### REQ-0049: Context-Bounded AST Slicing (`query_slice`) for Token-Isolated Subagents
- **Normative Statement**: The AST graph engine shall implement depth-bounded semantic AST slicing (`query_slice`) to extract self-contained subgraphs surrounding a target element for focused LLM reasoning, code generation, and micro-verification with guaranteed context isolation and token reduction.
- **Formal Invariant**: Let $n_{\text{target}} \in V$ be a target node and $k$ be a positive integer traversal depth bound. The slice function $\text{Slice}(n_{\text{target}}, k)$ extracts subgraph $G_{\text{slice}} = (V_{\text{slice}}, E_{\text{slice}})$:
$$
V_{\text{slice}} = \{ v \in V \mid \text{dist}(n_{\text{target}}, v) \le k \} \cup \text{RequiredTypes}(V_{\text{slice}})
$$
where $\text{dist}(u, v)$ is the unweighted shortest-path distance in the undirected projection of $G$.
Token Reduction Invariant: Serialized token volume of the extracted slice is strictly bounded relative to the complete model:
$$
|\text{Tokens}(\text{Slice}(n_{\text{target}}, k))| \le \alpha \cdot |\text{Tokens}(\mathcal{A})|
$$
where $\alpha \le 0.15$ for localized subgraphs, guaranteeing context isolation without context bloat.
Semantic Closure Invariant: Any type or constraint referenced by a node in $V_{\text{slice}}$ is included in the slice boundary.
- **Computational Complexity & Algorithmic Bounds**: Slice extraction executes in $O(|V_{\text{slice}}| + |E_{\text{slice}}|)$ time via bounded-depth breadth-first search.
- **Verification & Conformance Criteria**: Verification suite confirms that extracted AST slices compile and type-check independently in isolated subagent contexts.
