### REQ-0180: Manifest-Driven File Persistence (`CodegenManifest`) with XXH3 Content Fingerprinting
- **Normative Statement**: The code generator shall maintain a centralized emission manifest (`CodegenManifest`) tracking relative output paths and 64-bit XXH3 content fingerprints. Artifacts whose XXH3 fingerprint matches existing on-disk content shall bypass file rewriting, preserving filesystem timestamps.
- **Formal Semantics & Invariants**:
  For an artifact at path $P$ with content stream $S$:
  $$
  h_{\text{new}} = \text{XXH3\_64}(S)
  $$
  If $\text{Manifest}[P] == h_{\text{new}}$ and $\text{FileExists}(P)$, the disk write is safely bypassed.
- **Error Diagnostics & Quality Boundaries**:
  Manifest deserialization corruption shall trigger automatic rebuild without failing compilation; formal verification encoding errors or SMT-LIB2 / SLDV translation mismatches encountered during artifact persistence shall emit compiler error `E0508` (SMT-LIB2 / SLDV formal verification encoding error).
- **Acceptance Criteria**:
  - **AC-1**: Maintains `.pipeline/codegen-manifest.json` recording paths and XXH3 hashes.
  - **AC-2**: Bypasses file writes on content cache hits, preserving file modification timestamps.
  - **AC-3**: Tracks generated files for subsequent automated tombstone pruning.
