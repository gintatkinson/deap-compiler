### REQ-0172: User Story BDD Patterns: Pattern A (State Preconditions), Pattern B (Value Constraints), Pattern C (Transitions)
- **Normative Statement**: The projection engine shall classify synthesized BDD scenarios into three canonical patterns: Pattern A (State Preconditions & Invariants), Pattern B (Parametric Value Constraints & Ranges), and Pattern C (State Transitions & Behavioral Triggers).
- **Formal Semantics & Invariants**:
  - **Pattern A (State Preconditions)**: Verifies that operations are rejected when invoked from invalid initial states.
  - **Pattern B (Value Constraints)**: Verifies that inputs outside declared operational envelopes trigger validation failures.
  - **Pattern C (Transitions)**: Verifies nominal state transitions upon occurrence of triggering events when guards hold.
- **Error Diagnostics & Quality Boundaries**:
  A scenario failing to conform to any canonical BDD pattern shall emit warning `E0507` (Non-Conforming BDD Scenario Pattern).
- **Acceptance Criteria**:
  - **AC-1**: Generates Pattern A scenarios for all operational preconditions.
  - **AC-2**: Generates Pattern B scenarios for all attribute boundary limits.
  - **AC-3**: Generates Pattern C scenarios for all statechart transitions.
