### REQ-0193: Standardized Diagnostic Error Code Family E01xx: Ingestion, Schema & Lexer Errors (`E0100`--`E0199`)
- **Normative Statement**: The diagnostic engine shall standardize all errors originating in front-end ingestion, schema file parsing, CommonMark tables, and protocol deserializers into the `E01xx` code space (`E0100` through `E0199`).
- **Formal Semantics & Invariants**:
  The `E01xx` family includes:
  - `E0100`: Unrecognized Schema Format
  - `E0101`: Malformed Markdown Table Syntax
  - `E0102`: Table Cell Token Error
  - `E0103`: Missing Mandatory Table Header
  - `E0105`: Identifier Sanitization Collision
  - `E0107`: Invalid Multiplicity Interval
  - `E0108`: Invalid Port Direction
  - `E0113`: Protobuf Ingestion Syntax Error
  - `E0114`: OMG IDL Ingestion Error
  - `E0119`: Bijective Lexical Provenance Violation
  - `E0120`: Lexical Provenance Resolution Failure
- **Error Diagnostics & Quality Boundaries**:
  All front-end syntax and ingestion failures shall strictly map to unique codes within `E0100`--`E0199`.
- **Acceptance Criteria**:
  - **AC-1**: Every front-end parser fault assigns a specific, documented `E01xx` diagnostic code.
  - **AC-2**: No generic, unclassified error messages are emitted from `crates/deap-ingest`.
  - **AC-3**: Comprehensive documentation catalogs all `E01xx` codes with causes and resolutions.
