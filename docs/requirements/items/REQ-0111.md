### REQ-0111: Flow Conservation Network Incidence Matrix Construction & Rank Verification
- **Normative Statement**: The flow solver shall construct the structural incidence matrix $\mathbf{A} \in \{-1, 0, 1\}^{n \times b}$ representing $n$ junctions and $b$ branches. The solver shall verify the matrix rank and calculate the fundamental cut-set and cycle matrices to establish system solvability.
- **Formal Semantics & Invariants**:
  The incidence matrix element $A_{ij}$ is defined as:
  $$
  A_{ij} = \begin{cases}
  +1, & \text{if branch } j \text{ leaves junction } i \\
  -1, & \text{if branch } j \text{ enters junction } i \\
  0, & \text{otherwise}
  \end{cases}
  $$
  Solvability invariant: For a connected network with $n$ nodes, $\text{rank}(\mathbf{A}) = n - 1$.
- **Error Diagnostics & Quality Boundaries**:
  A singular or rank-deficient incidence matrix indicating disconnected network components shall emit `E0307` (Singular Flow Network Topology).
- **Acceptance Criteria**:
  - **AC-1**: Assembles topological incidence matrix $\mathbf{A}$ directly from connection AST nodes.
  - **AC-2**: Computes matrix rank and identifies disconnected network partitions.
  - **AC-3**: Provides structural validation of network solvability before numerical solver invocation.
