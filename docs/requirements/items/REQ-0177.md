### REQ-0177: LUMI Intermediate Representation (LUMI IR): SSA Basic Blocks & Control Flow Graph
- **Normative Statement**: The code generation engine shall lower AST behaviors, statecharts, and mathematical constraints into a clean, strongly-typed Static Single Assignment (SSA) intermediate representation (`LUMI IR`). LUMI IR shall model control flow as a directed graph of basic blocks terminated by explicit control-flow branches.
- **Formal Semantics & Invariants**:
  A LUMI IR function is represented as a Control Flow Graph (CFG) $\mathcal{G} = (\mathcal{B}, \mathcal{E}_{\text{cfg}})$:
  ```rust
  pub struct LumiBasicBlock {
      pub id: BlockId,
      pub instructions: Vec<LumiInstruction>,
      pub terminator: LumiTerminator, // Branch, BranchIf, Return
  }
  ```
  SSA invariant: Every SSA value register $\%v_k$ is assigned exactly once in the entire function body.
- **Error Diagnostics & Quality Boundaries**:
  SSA property violation (multiple assignments or use before definition) shall emit compiler error `E0501` (LUMI IR SSA Invariant Violation).
- **Acceptance Criteria**:
  - **AC-1**: Lowers SysML state machines and action sequences into clean LUMI IR CFG basic blocks.
  - **AC-2**: Validates SSA dominance properties across all basic blocks.
  - **AC-3**: Serves as the common intermediate representation for all target code generators.
