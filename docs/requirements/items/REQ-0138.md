### REQ-0138: Bounded Work-Stealing Parallelism (`rayon`) for Combinatorial Safety Expansions
- **Normative Statement**: The safety compiler shall evaluate the combinatorial UCA candidate tensor using bounded work-stealing thread pools via `rayon`. Task execution shall parallelize across independent control loops to maintain sub-second evaluation latencies.
- **Formal Semantics & Invariants**:
  The evaluation function $\text{EvalUCA}$ runs via parallel iterators:
  $$
  U_{\text{evaluated}} = U.\text{par\_iter}().\text{map}(\lambda u. \, \text{EvaluateHazardContext}(u)).\text{collect}()
  $$
  All worker threads borrow read-only references from `CompiledModelArena` without locks or contention.
- **Error Diagnostics & Quality Boundaries**:
  Thread worker timeout during parallel evaluation shall emit compiler error `E0130`.
- **Acceptance Criteria**:
  - **AC-1**: Parallelizes UCA generation across available CPU cores using `rayon`.
  - **AC-2**: Evaluates a 10,000-candidate hazard space in under 50 milliseconds.
  - **AC-3**: Memory footprint remains strictly bounded during parallel execution.
