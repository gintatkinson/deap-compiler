### REQ-0088: SysML v2 ViewDefinition (`view def`), ViewUsage & Viewpoint Lowering
- **Normative Statement**: The model projection engine shall formalize `view def`, `view`, `viewpoint def`, and `viewpoint` usages as declarative query filters over the AST model graph, projecting targeted stakeholder subgraphs according to formal concern specifications.
- **Formal Invariant**: A viewpoint $VP$ specifies a set of stakeholder concerns $\mathcal{C}$ and filter rules $\Phi_{\text{filter}}$. A view $V$ conforms to viewpoint $VP$ ($V \models VP$) and defines model projection:
$$
\pi_V : \mathcal{M}_{\text{model}} \longrightarrow \mathcal{M}_{\text{view}}
$$
Projection completeness: The projected view contains all and only those elements satisfying viewpoint filter criteria:
$$
\forall n \in \mathcal{M}_{\text{model}}, \quad n \in \mathcal{M}_{\text{view}} \iff \Phi_{\text{filter}}(n) = \text{true}
$$
Complexity bound: View graph projection executes in deterministic linear time $O(|V| + |E|)$ over model vertices and edges.
