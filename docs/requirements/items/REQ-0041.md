### REQ-0041: Two-Pass Symbol Hoisting & Lexical Scope Table Construction
- **Normative Statement**: The core AST engine shall execute a two-pass symbol resolution pipeline. Pass 1 shall hoist all package, classifier, and port definitions into a hierarchical lexical symbol table. Pass 2 shall resolve all cross-references, feature typings, connection endpoints, and constraint variable expressions.
- **Formal Semantics & Invariants**:
  Let $\mathcal{A}$ be the raw AST. Pass 1 constructs the symbol table $\Gamma$:
  $$
  \Gamma = \text{Pass1}(\mathcal{A}) = \bigcup_{n \in \text{Defs}(\mathcal{A})} \{ \text{QualifiedName}(n) \mapsto \text{NodeId}(n) \}
  $$
  Pass 2 resolves references against $\Gamma$:
  $$
  \mathcal{A}_{\text{resolved}} = \text{Pass2}(\mathcal{A}, \Gamma)
  $$
  This two-pass architecture allows forward references and mutual recursion between classifiers without order dependency.
- **Error Diagnostics & Quality Boundaries**:
  Failure to resolve a referenced symbol in Pass 2 shall emit `E0208` (Unresolved Symbol Reference).
- **Acceptance Criteria**:
  - **AC-1**: Forward references between parts declared later in the file resolve cleanly without errors.
  - **AC-2**: Circular type definitions that are semantically valid (e.g. mutual references via pointers) resolve correctly.
  - **AC-3**: Diagnostic for unresolved symbols lists available matching candidate symbols within scope.
