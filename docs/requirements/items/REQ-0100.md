### REQ-0100: Base Dimension Tuple Representation: $[M]^\alpha [L]^\beta [T]^\gamma [I]^\delta [\Theta]^\epsilon [N]^\zeta [J]^\eta$
- **Normative Statement**: The metrology engine shall represent physical dimensions internally using a dedicated, zero-allocation struct `RationalDimension7D` storing 7 pairs of 16-bit signed integers for rational numerators and denominators.
- **Formal Semantics & Invariants**:
  The data structure definition:
  ```rust
  #[derive(Clone, Copy, PartialEq, Eq, Hash)]
  pub struct RationalDimension7D {
      pub m: (i16, i16),      // Mass [M]
      pub l: (i16, i16),      // Length [L]
      pub t: (i16, i16),      // Time [T]
      pub i: (i16, i16),      // Current [I]
      pub theta: (i16, i16),  // Temperature [Theta]
      pub n: (i16, i16),      // Substance [N]
      pub j: (i16, i16),      // Intensity [J]
  }
  ```
  Canonical reduced invariant: For every component $(p, q)$, $q > 0$ and $\gcd(|p|, q) = 1$.
- **Error Diagnostics & Quality Boundaries**:
  A rational component with denominator zero ($q = 0$) shall trigger panic-free constructor error `E0264` (Division by Zero in Rational Dimension).
- **Acceptance Criteria**:
  - **AC-1**: Struct size is 28 bytes, fitting cleanly within CPU registers and cache lines.
  - **AC-2**: All fractions are automatically reduced to irreducible lowest terms upon construction.
  - **AC-3**: Equality comparison between equivalent dimensions evaluates to `true` in $O(1)$ time.
