### REQ-0046: Read-Only AST Visitor Trait API (`Visitor`) for Immutable Traversals
- **Normative Statement**: The AST engine shall provide a high-performance, read-only visitor trait (`Visitor`) enabling immutable traversals across hierarchical packages, parts, ports, actions, and constraints without allocating heap memory.
- **Formal Semantics & Invariants**:
  The `Visitor` trait definition:
  ```rust
  pub trait Visitor {
      fn visit_package(&mut self, node: &PackageNode) {}
      fn visit_part_def(&mut self, node: &PartDefNode) {}
      fn visit_port_def(&mut self, node: &PortDefNode) {}
      fn visit_constraint(&mut self, node: &ConstraintDefNode) {}
  }
  ```
  Visitor dispatch uses static trait monomorphization rather than dynamic `vtable` dispatch for maximum execution speed.
- **Error Diagnostics & Quality Boundaries**:
  Visitor traversal recursion limits shall be bounded to depth 1,000 to prevent stack exhaustion on adversarial models; encountering invalid state machine actions or violating action signatures during traversal shall emit compiler error `E0215` (State machine entry/do/exit action signature violation).
- **Acceptance Criteria**:
  - **AC-1**: Visitor iterates across complete AST models with zero heap allocations.
  - **AC-2**: Default trait method implementations allow selective overriding of specific node types.
  - **AC-3**: In-order and post-order traversal orders are cleanly supported.
