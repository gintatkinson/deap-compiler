### REQ-0030: XML Schema Definition (XSD) & ADL Schema Ingestion for Component Topologies
- **Normative Statement**: The ingestion engine shall provide an XML Schema Definition (XSD) and Architecture Description Language (ADL) parser that parses XML-based structural schemas into intermediate schema IR, mapping complex types and component prototypes to `IngestedPart` entities, elements and attributes to `IngestedAttr` properties, provided/required ports (P-Ports, R-Ports) to `IngestedPort` entities with directionality, and assembly connectors to `IngestedConnection` links.
- **Formal Invariant**: Let $\mathcal{X}_{\text{xml}}$ be an ingested XML document tree. The schema lowering transformation $\mathcal{T}_{\text{xml}}$ maps:
$$
\begin{aligned}
\text{xs:complexType } T &\longmapsto \text{IngestedPart}(T) \\
\text{xs:element } e \text{ of type } T &\longmapsto \text{IngestedAttr}(e, \text{type}: T) \\
\text{adl:component } C &\longmapsto \text{IngestedPart}(C) \\
\text{adl:port } p \text{ (P-Port / R-Port)} &\longmapsto \text{IngestedPort}(p, \text{dir}: \text{Direction}(p)) \\
\text{adl:connector } c &\longmapsto \text{IngestedConnection}(c.\text{src}, c.\text{tgt})
\end{aligned}
$$
Port directionality mapping:
$$
\text{Direction}(p) = \begin{cases}
\text{Out}, & \text{if } p \in \text{ProvidedPorts} \text{ (P-Port)} \\
\text{In}, & \text{if } p \in \text{RequiredPorts} \text{ (R-Port)} \\
\text{InOut}, & \text{if } p \in \text{BidirectionalPorts}
\end{cases}
$$
Zero Regex XML Processing Invariant: XML parsing is performed via single-pass event-driven or tree-based pushdown automata without regular expressions.
- **Computational Complexity & Algorithmic Bounds**: XML parsing executes in $O(N)$ linear time where $N$ is document byte size, using $O(D)$ stack space bounded by element nesting depth $D$.
- **Verification & Conformance Criteria**: Verification suite tests XSD models and ADL XML component topologies, ensuring 100% extraction of components, ports, and connections into the AST.
