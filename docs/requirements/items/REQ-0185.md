### REQ-0185: OMG DDS IDL Schema Generation & CDR Binary Serialization Codecs
- **Normative Statement**: The code generation engine shall emit OMG DDS-compliant IDL schemas (`.idl`) and native Common Data Representation (CDR) binary serialization codecs for all AST item definitions and message data types.
- **Formal Semantics & Invariants**:
  Every SysML `item def` lowers to a corresponding IDL `struct`:
  ```idl
  struct ItemData {
      long param_id;
      double value;
      boolean status;
  };
  ```
  Binary codecs implement OMG CDR encoding with strict alignment (4-byte alignment for integers, 8-byte for doubles).
- **Error Diagnostics & Quality Boundaries**:
  Unsupported field data types for DDS serialization shall emit `E0506` (Unsupported DDS Data Type).
- **Acceptance Criteria**:
  - **AC-1**: Emits standard OMG IDL 4.2 compliant schema files.
  - **AC-2**: Generates zero-copy CDR serialization and deserialization routines.
  - **AC-3**: Serialized byte representations conform bit-for-bit to OMG CDR specifications.
