### REQ-0190: SMT-LIB2 / Z3 First-Order Constraint Encoding & Proof Framework Generation
- **Normative Statement**: The code generation engine shall translate formal AST constraints into standard SMT-LIB2 benchmark scripts targeting first-order SMT solvers (Z3, CVC5). The generator shall encode data types, state variables, and invariant assertions into SMT assertions (`(assert ...)`).
- **Formal Semantics & Invariants**:
  The SMT-LIB2 encoder translates typed variables and assertions:
  ```smt2
  (set-logic QF_NRA)
  (declare-const param_x Real)
  (assert (>= param_x 0.0))
  (assert (<= param_x 100.0))
  (check-sat)
  ```
  The proof verification asserts the negation of the safety invariant to prove unsatisfiability (UNSAT = verified safe).
- **Error Diagnostics & Quality Boundaries**:
  Unsupported logic theories or nonlinear expressions outside solver capabilities shall emit `E0511` (Unsupported SMT Logic Theory).
- **Acceptance Criteria**:
  - **AC-1**: Translates AST constraint expressions into valid SMT-LIB2 syntax.
  - **AC-2**: Proves safety invariant validity by demonstrating unsatisfiability of the inverted hazard state.
  - **AC-3**: Compatible with standard automated SMT solvers (Z3, CVC5).
