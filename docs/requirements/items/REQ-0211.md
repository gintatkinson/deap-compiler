### REQ-0211: Closed-World Parameter Dictionary Projection & Static Provenance Verification
- **Normative Statement**: The specification projection engine shall enforce static closed-world parameter provenance. All numerical values, physical limits, operating rates, and engineering tolerances emitted into downstream specifications must resolve with positive provenance against the parsed AST parameter dictionary.
- **Formal Semantics & Invariants**:
  Let $\mathcal{P}_{\text{spec}}$ be the set of numeric parameters in emitted specifications and $\mathcal{P}_{\text{AST}}$ be the closed-world parameter dictionary extracted from the schema:
  $$
  \forall p \in \mathcal{P}_{\text{spec}}, \quad p \in \mathcal{P}_{\text{AST}}
  $$
  Any parameter not in $\mathcal{P}_{\text{AST}}$ must carry an explicit verified source citation comment.
- **Error Diagnostics & Quality Boundaries**:
  Discovery of an ungrounded numeric claim or fabricated parameter shall emit compiler error `E0119`.
- **Acceptance Criteria**:
  - **AC-1**: Automated test scans emitted specifications against the projected parameter dictionary.
  - **AC-2**: Asserts zero ungrounded numeric metrics across all generated Markdown files.
  - **AC-3**: Enforces that specification generators emit exclusively documented parameter values.
