### REQ-0044: Multi-File Module Ingestion & Directory-to-Namespace Hierarchy Mapping
- **Normative Statement**: The compiler shall support multi-file models partitioned across directory hierarchies, deterministically mapping directory paths to nested SysML package namespaces. A file located at `schema/segments/power/battery.sysml` shall automatically bind to `package Segments::Power::Battery`.
- **Formal Semantics & Invariants**:
  Let $P_{\text{rel}}$ be the file path relative to `schema/`. The namespace mapping function $\Omega_{\text{ns}}$ decomposes $P_{\text{rel}}$:
  $$
  \Omega_{\text{ns}}(p_1 / p_2 / \dots / p_k.\text{sysml}) = \text{Spur}("P_1::P_2::\dots::P_k")
  $$
  Where each path component is converted to TitleCase identifier syntax.
- **Error Diagnostics & Quality Boundaries**:
  Namespace collisions arising from conflicting file naming shall emit compiler error `E0212` (Namespace Collision).
- **Acceptance Criteria**:
  - **AC-1**: Ingests multi-file models distributed across deep directory trees.
  - **AC-2**: Automatically creates synthetic enclosing packages matching directory structures.
  - **AC-3**: Cross-file imports between sibling packages resolve cleanly.
