### REQ-0050: Context-Bounded AST Slicing (`query_slice`) for Token-Isolated Subagents
- **Normative Statement**: The AST engine shall implement a context-bounded slicing engine (`query_slice`) that extracts minimal, self-contained subgraphs centered on target classifiers, ports, or control loops. Slicing shall drastically reduce context token consumption for autonomous subagents while preserving necessary type and interface dependencies.
- **Formal Semantics & Invariants**:
  Let $n_{\text{target}} \in V$ be a target node and $k$ be a traversal depth bound. The slice function $\text{Slice}(n_{\text{target}}, k)$ extracts subgraph $G_{\text{slice}} = (V_{\text{slice}}, E_{\text{slice}})$:
  $$
  V_{\text{slice}} = \{ v \in V \mid \text{dist}(n_{\text{target}}, v) \le k \} \cup \text{RequiredTypes}(V_{\text{slice}})
  $$
  Token reduction metric: The slice shall achieve greater than 85% reduction in serialized token volume compared to full-model ingestion.
- **Error Diagnostics & Quality Boundaries**:
  Querying a non-existent target node identifier shall emit compiler error `E0230` (AST Slice Target Not Found).
- **Acceptance Criteria**:
  - **AC-1**: Querying a single subsystem part extracts only that part, its ports, connections, and direct type dependencies.
  - **AC-2**: Extracted slice serializes to self-contained, valid SysML v2 textual representation.
  - **AC-3**: Demonstrates verified >85% context token reduction across reference benchmark schemas.
