### REQ-0036: Concurrent String Interning & Scalar Symbol Deduplication Architecture
- **Normative Statement**: The core compiler platform shall intern all identifier strings, type names, docstrings, and qualified paths using a high-throughput concurrent string interner pool, mapping all string occurrences to compact scalar symbol handles ($\text{sizeof}(\sigma) \le 4\text{ bytes}$) with $O(1)$ constant-time scalar equality comparison. Slicing and copying bytes from memory-mapped source buffers into this global symbol interner pool represents the sole permitted architectural exception to zero-copy memory management.
- **Formal Invariant**: The string interner function maps arbitrary UTF-8 strings to 32-bit scalar symbol handles:
$$
\text{intern}(s) = \sigma \in \text{SymbolId}, \quad \text{sizeof}(\sigma) \le S_{\max}
$$
Scalar Equality Invariant: Equality comparisons across interned symbols execute in $O(1)$ constant time via primitive integer scalar equality:
$$
\forall s_1, s_2 \in \mathcal{S}, \quad s_1 = s_2 \iff \text{intern}(s_1) == \text{intern}(s_2)
$$
Buffer Allocation Boundary Exception Invariant:
$$
\text{Allocations}_{\text{heap}}(\mathcal{C}) \subseteq \text{Storage}(\text{StringInternerPool})
$$
All other AST components borrow slices or reside in pre-allocated node arenas without dynamic string duplication.
- Parameter Definitions:
  - $\sigma$: Interned scalar symbol identifier handle.
  - $S_{\max}$: Maximum handle memory footprint bound ($4\text{ bytes}$, or 32-bit unsigned scalar index).
- **Computational Complexity & Algorithmic Bounds**: String interning is $O(|s|)$ for the initial occurrence and $O(1)$ constant time for subsequent lookups and comparisons. Replacing strings with scalar symbol handles reduces AST memory consumption by greater than 60%.
- **Verification & Conformance Criteria**: Profiling asserts that 100% of identifier comparisons during type-checking and name-resolution execute via integer scalar comparison with zero string character scans.
