### REQ-0036: Generational Node Index Addressing (`NodeId(u32, u16)`) & Handle Safety
- **Normative Statement**: All references between AST nodes shall utilize compact generational handles `NodeId(u32, u16)` consisting of a 32-bit index and a 16-bit generation counter. Generational handles shall prevent dangling pointer dereferences and handle-reuse hazards during AST transformations and incremental compilation.
- **Formal Semantics & Invariants**:
  A handle $H$ is defined as `NodeId { index: u32, generation: u16 }`. Handle dereference against arena $\mathcal{A}$ satisfies:
  $$
  \text{deref}(\mathcal{A}, H) = \begin{cases}
  \&\mathcal{A}[H.\text{index}], & \text{if } \mathcal{A}.\text{gen}[H.\text{index}] == H.\text{generation} \\
  \text{Err}(\text{StaleHandle}), & \text{otherwise}
  \end{cases}
  $$
- **Error Diagnostics & Quality Boundaries**:
  Dereferencing an invalid or stale generational handle shall emit compiler error `E0202` (Stale AST Handle Dereference).
- **Acceptance Criteria**:
  - **AC-1**: Size of `NodeId` is exactly 6 bytes (or 8 bytes aligned), enabling high-density storage.
  - **AC-2**: Attempting to access a node modified in a newer compilation generation safely returns an error.
  - **AC-3**: Generational validation incurs zero runtime overhead in release mode when generation checking is verified.
