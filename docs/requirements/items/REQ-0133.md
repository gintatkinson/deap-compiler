### REQ-0133: Extraneous Node Detection & Dead Code Elimination in Safety Contexts
- **Normative Statement**: The safety compiler shall detect and eliminate extraneous AST nodes and unreachable realization elements that do not contribute to any requirement, safety constraint, or operational interface in safety-critical contexts.
- **Formal Semantics & Invariants**:
  Let $G = (V, E)$ be the full model graph and $V_{\text{roots}}$ be the set of active mission entrypoints and safety requirements. The live node set is:
  $$
  V_{\text{live}} = \mu X. \left( V_{\text{roots}} \cup \{ v \in V \mid \exists u \in X \text{ such that } (u, v) \in E \} \right)
  $$
  Extraneous nodes $V_{\text{dead}} = V \setminus V_{\text{live}}$ are purged from code generation outputs.
- **Error Diagnostics & Quality Boundaries**:
  Discovery of dead code in safety-certified modules shall emit warning `E0410` (Extraneous Unreachable Element in Safety Context).
- **Acceptance Criteria**:
  - **AC-1**: Performs reachability tree-shaking from root safety requirements.
  - **AC-2**: Purges unreferenced helper components from safety-critical generated binaries.
  - **AC-3**: Emits dead code audit reports documenting all pruned elements.
