### REQ-0150: Master Signal Flow Dictionary: Canonical 10-Column Structural Specification
- **Normative Statement**: The ICD engine shall generate the canonical Master Signal Flow Dictionary (ICD 02) strictly adhering to the standardized 10-column tabular specification format: Signal Identifier, Source Subsystem, Source Port, Destination Subsystem, Destination Port, Payload Data Type, Dimensional Unit, Update Rate / Frequency, Failsafe Default Value, and Network Protocol.
- **Formal Semantics & Invariants**:
  Every record in the dictionary is an exact 10-tuple:
  $$
  \sigma = \langle \text{ID}, S_{\text{src}}, P_{\text{src}}, S_{\text{tgt}}, P_{\text{tgt}}, \tau_{\text{payload}}, u_{\text{unit}}, f_{\text{rate}}, v_{\text{failsafe}}, \pi_{\text{protocol}} \rangle
  $$
  Every column must contain validated, non-empty metadata; finalized specifications require concrete domain values exclusively.
- **Error Diagnostics & Quality Boundaries**:
  A signal dictionary entry with missing mandatory columns or placeholder strings shall emit compiler error `E0443` (Incomplete Master Signal Dictionary Record).
- **Acceptance Criteria**:
  - **AC-1**: Emits 10-column Markdown table covering 100% of signals in the model.
  - **AC-2**: Validates that all signal IDs are unique across the global dictionary.
  - **AC-3**: Rejects any entries containing ungrounded placeholder text.
