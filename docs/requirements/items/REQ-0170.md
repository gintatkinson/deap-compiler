### REQ-0170: Feature Class Diagram Emission with Ancestor Containment & No Isolated Classes
- **Normative Statement**: Every generated feature specification shall include a UML class diagram (Mermaid `classDiagram`) illustrating the feature classifier, its owned attributes and operations, and its complete ancestral containment hierarchy back to the root package, ensuring zero isolated classes.
- **Formal Semantics & Invariants**:
  Let $C$ be the target classifier and $\text{Ancestors}(C) = \langle P_{\text{root}}, \dots, P_{\text{parent}} \rangle$. The diagram graph $G_{\text{dia}} = (V_{\text{dia}}, E_{\text{dia}})$ satisfies:
  $$
  V_{\text{dia}} = \{ C \} \cup \text{Ancestors}(C), \quad E_{\text{dia}} = \{ (A_i, A_{i+1}, \text{Composition}) \} \cup \{ (P_{\text{parent}}, C, \text{Composition}) \}
  $$
  No isolated vertex: $\forall v \in V_{\text{dia}}, \, \text{degree}(v) \ge 1$.
- **Error Diagnostics & Quality Boundaries**:
  An isolated class without relationship lines in the diagram shall emit `E0504`.
- **Acceptance Criteria**:
  - **AC-1**: Emits class diagrams containing complete ancestor containment chains.
  - **AC-2**: All classes in the diagram are connected via composition (`*--`) or specialization (`<|--`).
  - **AC-3**: Member lines use valid Mermaid syntax with visibility indicators (`+`, `-`) and multiplicities.
