### REQ-0123: Deterministic Transition Guard Disjointness Verification ($G_1 \wedge G_2 \equiv \text{false}$)
- **Normative Statement**: The state machine compiler shall verify that outgoing transitions from any state triggered by the same event have mutually disjoint guard conditions. The logical conjunction of guards on competing transitions must evaluate to identically false ($G_1 \wedge G_2 \equiv \text{false}$), guaranteeing deterministic state changes.
- **Formal Semantics & Invariants**:
  Let $T_1$ and $T_2$ be two transitions exiting state $S$ on identical trigger $e$ with guards $G_1$ and $G_2$. The determinism check requires:
  $$
  \text{UNSAT}(G_1 \wedge G_2) \iff \neg \exists \mathbf{x} \text{ such that } G_1(\mathbf{x}) = \text{true} \wedge G_2(\mathbf{x}) = \text{true}
  $$
  The compiler uses an integrated SMT-LIB2 / Z3 solver check to formally verify guard disjointness.
- **Error Diagnostics & Quality Boundaries**:
  Overlapping or non-disjoint guard conditions on competing transitions shall emit compiler error `E0256` (Non-Deterministic State Transition Ambiguity).
- **Acceptance Criteria**:
  - **AC-1**: Formulates SMT proof queries for all competing transition guard pairs.
  - **AC-2**: Proves guard disjointness at compile time using automated theorem proving.
  - **AC-3**: Pinpoints overlapping input assignments when competing guards are not disjoint.
