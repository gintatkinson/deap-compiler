### REQ-0189: Formal Verification Script Emission: Proof Obligation Synthesis (`.m`)
- **Normative Statement**: The code generation engine shall emit formal verification proof obligation scripts targeting commercial formal verification engines (MATLAB / Simulink Design Verifier, SLDV). The generator shall synthesize assertion scripts (`.m`) with mandatory algebraic parenthesization to prevent operator precedence corruption.
- **Formal Semantics & Invariants**:
  For an `assert constraint` AST node, the generator emits an SLDV assertion block:
  ```matlab
  % SLDV Proof Obligation for Constraint: [ConstraintId]
  sldv_assert((param_x >= 0.0) && (param_x <= 100.0), '[Proof Obligation Assertion]');
  ```
  Algebraic expressions are strictly enclosed in parentheses to preserve operator precedence.
- **Error Diagnostics & Quality Boundaries**:
  Unresolved parameter variables in emitted verification scripts shall emit `E0510` (Unresolved Parameter in Verification Script).
- **Acceptance Criteria**:
  - **AC-1**: Emits valid MATLAB `.m` proof obligation scripts from SysML constraints.
  - **AC-2**: Enforces exhaustive parenthesization across all relational and Boolean expressions.
  - **AC-3**: Generated proof scripts execute cleanly in automated formal verification test frameworks.
