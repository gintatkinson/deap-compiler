### REQ-0136: Control Action 6-Tuple Synthesis with Graph-Grounded Node References
- **Normative Statement**: The safety compiler shall synthesize formal Control Action 6-Tuples representing every discrete control authority relationship. The 6-tuples shall strictly employ strongly-typed graph node references (`NodeId`), eliminating opaque stringly-typed tuples.
- **Formal Semantics & Invariants**:
  A Control Action tuple $\tau$ is defined as:
  ```rust
  pub struct ControlActionTuple {
      pub controller: NodeId,
      pub actuator: NodeId,
      pub sensor: NodeId,
      pub process: NodeId,
      pub control_action: NodeId,
      pub context_state: NodeId,
  }
  ```
  All 6 elements resolve to active classifiers or port instances in `AstModelGraph`.
- **Error Diagnostics & Quality Boundaries**:
  A control action tuple referencing an unresolvable or disconnected node handle shall emit `E0413` (Malformed Control Action Reference).
- **Acceptance Criteria**:
  - **AC-1**: Generates strongly-typed 6-tuples for all control actions in the system model.
  - **AC-2**: All tuple elements contain verified generational `NodeId` handles.
  - **AC-3**: Associates context states with active operational statechart modes.
