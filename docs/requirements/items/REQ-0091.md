### REQ-0091: KerML Standard Library: `Base` Package & Primitive Equality Lowering
- **Normative Statement**: The compiler shall bootstrap the normative KerML `Base` standard library package into the root symbol table, providing the universal top-type `Anything`, base classifiers `Element` and `Relationship`, and primitive equivalence operator (`==`) axiomatized over data values and object identities.
- **Formal Invariant**: Universal top-type axiom: `Anything` is the top element of the subtyping poset $(\text{Types}, \le)$:
$$
\forall T \in \text{Types}, \quad T \le \text{Anything}
$$
Equivalence relation: The equality operator `==` satisfies reflexivity, symmetry, and transitivity:
$$
\begin{aligned}
a == b \iff \begin{cases}
\text{val}(a) \equiv_{\text{struct}} \text{val}(b), & \text{if } a, b \in \llbracket \text{DataType} \rrbracket \\
\text{id}(a) = \text{id}(b), & \text{if } a, b \in \llbracket \text{Class} \rrbracket
\end{cases}
\end{aligned}
$$
Complexity bound: Bootstrapped core symbols are permanently interned at compiler initialization in $O(1)$ time; primitive equality evaluates in $O(1)$ scalar or identity comparison.
