### REQ-0091: SysML v2 MetadataDefinition (`metadata def`) & Semantic Annotation Usage (`@`)
- **Normative Statement**: The SysML v2 lowering engine shall lower `metadata def` and semantic metadata annotations (`@AnnotationName`) into `MetadataDefNode` and `MetadataUsageNode` entities. Metadata shall attach custom typed attributes, engineering standards markers, and traceability tags to AST elements.
- **Formal Semantics & Invariants**:
  A `metadata def` declares an extensible typed annotation record:
  ```rust
  pub struct MetadataUsageNode {
      pub metadata_def_id: NodeId,
      pub annotated_element_id: NodeId,
      pub attribute_values: Vec<(Spur, LiteralValue)>,
  }
  ```
  Annotations (`@SecurityClassification(level = "Confidential")`) attach cleanly to any AST node without mutating underlying metamodel semantics.
- **Error Diagnostics & Quality Boundaries**:
  Applying an undefined metadata annotation or passing mismatched attribute types shall emit `E0256` (Metadata Type Violation).
- **Acceptance Criteria**:
  - **AC-1**: Parses `metadata def SafetyCritical { attr dal : Integer; }` into a metadata definition node.
  - **AC-2**: Parses `@SafetyCritical(dal = 1) part controller;` attaching metadata to the part.
  - **AC-3**: Preserves all attached metadata during AST traversal and code generation.
