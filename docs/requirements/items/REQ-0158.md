### REQ-0158: Earliest Deadline First (EDF) Dynamic Schedulability Verification ($U \le 1.0$)
- **Normative Statement**: The ICD engine shall perform Earliest Deadline First (EDF) dynamic schedulability analysis for aperiodic and periodic tasks with dynamic deadlines, verifying that total utilization satisfies the exact schedulability condition ($U \le 1.0$).
- **Formal Semantics & Invariants**:
  For tasks where relative deadlines equal periods ($D_i = T_i$):
  $$
  U = \sum_{i=1}^n \frac{C_i}{T_i} \le 1.0
  $$
  For tasks with arbitrary deadlines ($D_i < T_i$), the processor demand criterion $h(t) \le t$ is evaluated for all $t \ge 0$.
- **Error Diagnostics & Quality Boundaries**:
  Utilization exceeding 100% ($U > 1.0$) shall emit compiler error `E0449` (EDF Schedulability Violation).
- **Acceptance Criteria**:
  - **AC-1**: Evaluates dynamic EDF schedulability bounds for signal tasks.
  - **AC-2**: Checks processor demand criterion for tasks with constrained deadlines.
  - **AC-3**: Identifies deadline miss risks under worst-case task arrival conditions.
