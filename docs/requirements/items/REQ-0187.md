### REQ-0187: Formal Verification Script Emission: Proof Obligation Synthesis (`.m`)
- **Normative Statement**: The code generation engine shall emit formal verification proof obligation scripts targeting verification engines (MATLAB / Simulink Design Verifier SLDV / Embedded Coder), generating assertion scripts with algebraic parenthesization to guarantee operator precedence preservation and semantic equivalence with AST constraints.
- **Formal Invariant**: Every invariant predicate $\psi$ declared in the AST model is emitted as an assertion proof obligation:
$$
\text{Emit}(\psi) = \text{AssertObligation}\left(\text{Parenthesize}(\psi)\right)
$$
ensuring syntax tree isomorphism between AST constraints and solver scripts:
$$
\text{AST}(\psi) \cong \text{AST}(\text{Parse}(\text{Emit}(\psi)))
$$
Verification obligation contract:
$$
\text{Obligation}(\psi) = \langle \text{InvariantID}, \text{ContextClassifier}, \text{ProofExpression}(\psi), \text{SLDVObjective} \rangle
$$
Complexity bound: Script synthesis runs in deterministic linear time $O(|\Psi_{\text{invariants}}|)$ over model constraints.
