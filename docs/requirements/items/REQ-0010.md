### REQ-0010: String Interner Buffer-Copy Exception & Deduplication Engine
- **Normative Statement**: The compiler platform shall implement an explicit string interner buffer-copy exception to zero-copy memory management. Copying string slice bytes from memory-mapped source buffers into the global symbol interner pool (`lasso::Rodeo`) to produce compact 4-byte `Spur` tokens is the sole permitted exception to zero-copy memory management.
- **Formal Semantics & Invariants**:
  Let $\mathcal{I}_{\text{sym}}$ be the global string interner. For any string slice $s \in \mathcal{B}_{\text{file}}$:
  $$
  \text{intern}(s) = \sigma \in \text{Spur}, \quad \text{sizeof}(\sigma) = 4 \text{ bytes}
  $$
  Equality comparisons across interned symbols execute in $O(1)$ constant time via integer scalar equality:
  $$
  s_1 = s_2 \iff \text{intern}(s_1) == \text{intern}(s_2)
  $$
- **Error Diagnostics & Quality Boundaries**:
  Interner capacity exhaustion beyond $2^{32}-1$ distinct symbols shall emit `E0128` (Symbol Interner Overflow).
- **Acceptance Criteria**:
  - **AC-1**: All repetitive identifier lookups and comparisons evaluate via 4-byte `Spur` integer comparisons.
  - **AC-2**: Memory consumption of the symbol table scales with unique symbol count, not total occurrence count.
  - **AC-3**: Resolved symbols can be cleanly resolved back to original `&str` text for diagnostic reporting.
