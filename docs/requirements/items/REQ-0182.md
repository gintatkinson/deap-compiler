### REQ-0182: Continuous-Time Numerical Solvers: 4th-Order Runge-Kutta (RK4) Integration Engine
- **Normative Statement**: The code generation engine shall generate high-fidelity 4th-Order Runge-Kutta (RK4) numerical integration solvers for nonlinear continuous plant dynamics, providing $O(\Delta t^4)$ local truncation error accuracy.
- **Formal Semantics & Invariants**:
  The RK4 solver evaluates 4 intermediate slope stages:
  $$
  \begin{aligned}
  k_1 &= f(x_k, u_k, t_k) \\
  k_2 &= f\left( x_k + \frac{\Delta t}{2} k_1, \, u\left(t_k + \frac{\Delta t}{2}\right), \, t_k + \frac{\Delta t}{2} \right) \\
  k_3 &= f\left( x_k + \frac{\Delta t}{2} k_2, \, u\left(t_k + \frac{\Delta t}{2}\right), \, t_k + \frac{\Delta t}{2} \right) \\
  k_4 &= f(x_k + \Delta t \cdot k_3, \, u(t_k + \Delta t), \, t_k + \Delta t) \\
  x_{k+1} &= x_k + \frac{\Delta t}{6} (k_1 + 2 k_2 + 2 k_3 + k_4)
  \end{aligned}
  $$
- **Error Diagnostics & Quality Boundaries**:
  Numerical instability or NaN detection during simulation runs shall emit runtime diagnostic `E0505`.
- **Acceptance Criteria**:
  - **AC-1**: Emits standalone RK4 solver code in C++20 or C99.
  - **AC-2**: Evaluates complex nonlinear differential equations with 4th-order accuracy.
  - **AC-3**: Memory footprint is strictly bounded to the state vector size without heap allocations.
