### REQ-0183: Linear State-Space Matrix Evaluation ($\dot{x} = Ax + Bu, y = Cx + Du$)
- **Normative Statement**: The code generation engine shall evaluate linear state-space dynamic systems specified by matrices $\mathbf{A}, \mathbf{B}, \mathbf{C}, \mathbf{D}$. The engine shall emit optimized dense and sparse matrix-vector multiplication routines for computing state derivatives $\dot{x} = \mathbf{A}x + \mathbf{B}u$ and outputs $y = \mathbf{C}x + \mathbf{D}u$.
- **Formal Semantics & Invariants**:
  Matrix dimensions for state vector $x \in \mathbb{R}^n$, input vector $u \in \mathbb{R}^m$, and output vector $y \in \mathbb{R}^p$:
  $$
  \mathbf{A} \in \mathbb{R}^{n \times n}, \quad \mathbf{B} \in \mathbb{R}^{n \times m}, \quad \mathbf{C} \in \mathbb{R}^{p \times n}, \quad \mathbf{D} \in \mathbb{R}^{p \times m}
  $$
  Static dimension invariant: The compiler verifies matrix dimension conformance at compile time.
- **Error Diagnostics & Quality Boundaries**:
  Matrix dimension mismatch in state-space declarations shall emit compiler error `E0228` (State-Space Matrix Dimension Mismatch).
- **Acceptance Criteria**:
  - **AC-1**: Ingests state-space matrices from SysML parametric constraints.
  - **AC-2**: Validates dimensional conformance of $\mathbf{A}, \mathbf{B}, \mathbf{C}, \mathbf{D}$ matrices.
  - **AC-3**: Emits vectorized matrix-vector multiplication code optimized for SIMD execution.
