### REQ-0125: State Machine Livelock Diagnostic & Cyclic Non-Progress Detection
- **Normative Statement**: The state machine compiler shall implement livelock and non-progress cycle detection. The compiler shall detect cyclic transition loops where the state machine repeatedly transitions between states without consuming external inputs or performing progress actions.
- **Formal Semantics & Invariants**:
  A livelock cycle is a directed cycle $C = \langle s_1, s_2, \dots, s_k, s_1 \rangle$ in the state transition graph where:
  $$
  \forall (s_i, s_{i+1}) \in C, \quad \text{trigger}(s_i, s_{i+1}) = \text{None} \wedge \text{progress}(s_i, s_{i+1}) = \text{false}
  $$
  Such cycles consume infinite execution steps without advancing the system's operational mission.
- **Error Diagnostics & Quality Boundaries**:
  Discovery of an instantaneous non-progress cycle shall emit compiler error `E0258` (State Machine Livelock Detected).
- **Acceptance Criteria**:
  - **AC-1**: Identifies cycles of epsilon (untriggered) transitions in statechart graphs.
  - **AC-2**: Flags livelock risks that would freeze execution loops at runtime.
  - **AC-3**: Recommends insertion of explicit external triggers or progress events.
