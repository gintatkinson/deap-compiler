### REQ-0071: SysML v2 Package & Subsystem Model Organization Grammar
- **Normative Statement**: The SysML v2 lowering engine shall implement the normative SysML v2 `package` grammar (`bnf/SysML-textual-bnf.kebnf`), supporting hierarchical model partitioning, package imports, visibility modifiers, and subsystem model libraries.
- **Formal Semantics & Invariants**:
  A SysML `package` $P$ is lowered to a `PackageNode` in `CompiledModelArena`:
  $$
  P = \langle \text{name}: \text{Spur}, \text{members}: \text{Vec}<\text{NodeId}>, \text{imports}: \text{Vec}<\text{ImportDecl}> \rangle
  $$
  Nested packages establish hierarchical namespace boundaries conforming to KerML namespace semantics.
- **Error Diagnostics & Quality Boundaries**:
  Syntax errors inside package bodies shall emit `E0101` with precise file, line, and column coordinates.
- **Acceptance Criteria**:
  - **AC-1**: Parses SysML v2 package declarations matching the official OMG grammar.
  - **AC-2**: Supports nested packages and multi-package file structures cleanly.
  - **AC-3**: Package docstrings and metadata annotations are preserved in the AST.
