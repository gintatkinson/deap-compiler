### REQ-0104: Dimensionless Constraint Enforcement for Transcendental Arguments ($\sin, \cos, \exp, \ln$)
- **Normative Statement**: The type checker shall enforce that all arguments to transcendental and trigonometric functions ($\sin, \cos, \tan, \exp, \ln, \log_{10}$) must evaluate to the dimensionless vector $\mathbf{0} \in \mathbb{Q}^7$. The result of the transcendental function shall likewise be dimensionless.
- **Formal Semantics & Invariants**:
  Let $f_{\text{trans}} \in \{ \sin, \cos, \tan, \exp, \ln \}$ and $E$ be the argument expression:
  $$
  \text{expr} = f_{\text{trans}}(E) \implies \mathbf{d}_E \equiv \mathbf{0} = (0, 0, 0, 0, 0, 0, 0)
  $$
  Result dimension: $\mathbf{d}_{\text{expr}} = \mathbf{0}$.
- **Error Diagnostics & Quality Boundaries**:
  Passing an argument with a non-zero physical dimension to a transcendental function shall emit `E0221` (Non-Dimensionless Transcendental Argument).
- **Acceptance Criteria**:
  - **AC-1**: Accepts $\sin(\theta)$ where $\theta$ is typed as dimensionless `Radian` or raw `Real`.
  - **AC-2**: Rejects expressions like $\exp(v)$ where $v$ has dimension of velocity or voltage.
  - **AC-3**: Evaluates nested transcendental expressions with complete dimensional verification.
