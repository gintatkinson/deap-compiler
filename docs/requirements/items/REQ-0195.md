### REQ-0195: Standardized Diagnostic Error Code Family E03xx: Interface, Topology & Connection Errors (`E0300`--`E0399`)
- **Normative Statement**: The diagnostic engine shall standardize all errors originating in component connections, interface contracts, topological flow networks, and port interconnects into the `E03xx` code space (`E0300` through `E0399`).
- **Formal Semantics & Invariants**:
  The `E03xx` family includes:
  - `E0301`: Dangling Port / Connection Endpoint Gate
  - `E0302`: Interface Contract Violation
  - `E0303`: Invalid Allocation Mapping
  - `E0304`: Conservative / Non-Conservative Port Type Mismatch
  - `E0305`: Unbalanced Flow Junction Divergence
  - `E0306`: Contradictory Potential Loop Invariant
  - `E0307`: Singular Flow Network Topology
- **Error Diagnostics & Quality Boundaries**:
  All topological and connection faults shall strictly map to unique codes within `E0300`--`E0399`.
- **Acceptance Criteria**:
  - **AC-1**: Network topology errors assign documented `E03xx` diagnostic codes.
  - **AC-2**: Connection binding errors identify both source and destination endpoint paths.
  - **AC-3**: Kirchhoff conservation violations pinpoint unbalanced topological junction nodes.
