### REQ-0042: Lexical Scope Lookup & Fully Qualified Path Resolution (`::`)
- **Normative Statement**: The AST resolver shall implement lexical scope resolution using standard double-colon scoping (`::`). Identifier lookup shall search inward from local scopes through enclosing parent scopes up to the root namespace, respecting public and private package visibility rules.
- **Formal Semantics & Invariants**:
  Let $S$ be a symbol reference requested within lexical scope $\sigma = \langle P_1, P_2, \dots, P_k \rangle$. The lookup function $\text{Resolve}(S, \sigma)$ searches scopes in sequence:
  $$
  \text{Resolve}(S, \sigma) = \begin{cases}
  \Gamma(P_k :: S), & \text{if } P_k :: S \in \Gamma \\
  \dots & \\
  \Gamma(P_1 :: S), & \text{if } P_1 :: S \in \Gamma \\
  \Gamma(S), & \text{if } S \in \Gamma \text{ (root)} \\
  \text{None}, & \text{otherwise}
  \end{cases}
  $$
- **Error Diagnostics & Quality Boundaries**:
  Ambiguous symbol references matching multiple imported scopes shall emit compiler error `E0209` (Ambiguous Symbol Reference).
- **Acceptance Criteria**:
  - **AC-1**: Correctly resolves relative paths within nested package hierarchies.
  - **AC-2**: Fully qualified paths (`Root::Subpackage::Part`) resolve directly without ambiguity.
  - **AC-3**: Private elements in foreign packages are inaccessible unless explicitly exported.
