### REQ-0042: Circular Dependency & Metamodel Inheritance Cycle Detection
- **Normative Statement**: The AST engine shall implement a cycle detection algorithm using Tarjan's strongly connected components (SCC) algorithm to detect circular specialization hierarchies (`specializes`, `:>`) and direct containment loops, rejecting any circular dependency at compile time with a cycle traceback path.
- **Formal Invariant**: Let $G_{\text{inherit}} = (V, E)$ be the directed specialization graph where $(u, v) \in E \iff u \text{ specializes } v$. The compiler asserts acyclicity:
$$
\text{IsAcyclic}(G_{\text{inherit}}) \iff \forall v \in V, \quad v \notin \text{Descendants}(v)
$$
Equivalently, all strongly connected components of $G_{\text{inherit}}$ are trivial singletons:
$$
\forall C \in \text{TarjanSCC}(G_{\text{inherit}}), \quad |C| = 1 \wedge (v \in C \implies (v, v) \notin E)
$$
Containment Acyclicity Invariant: The structural composition graph $G_{\text{comp}}$ is strictly acyclic:
$$
\text{IsAcyclic}(G_{\text{comp}}) \equiv \text{true}
$$
Cycle diagnostic emission: Any detected cycle emits $\text{DiagnosticCode::E0203}$ accompanied by the directed path:
$$
\mathcal{P}_{\text{cycle}} = \langle v_1, v_2, \dots, v_k, v_1 \rangle
$$
- **Computational Complexity & Algorithmic Bounds**: Cycle verification executes in $O(|V| + |E|)$ time and $O(|V|)$ auxiliary space via depth-first search numbering.
- **Verification & Conformance Criteria**: Verification suite tests deliberate inheritance cycles ($A \to B \to C \to A$) and asserts deterministic compiler diagnostic rejection.
