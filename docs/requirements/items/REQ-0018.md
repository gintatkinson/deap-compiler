### REQ-0018: Multi-Line Table Cell Block Token Preservation & Normalization
- **Normative Statement**: The table ingestion engine shall preserve multi-line cell content, nested bullet points, and code spans within table cells without dropping formatting or truncating text, normalizing embedded HTML breaks (`<br>`, `<br/>`, `<br />`) and escaped linefeeds into canonical newline-delimited block tokens via deterministic prefix scanning strictly without regular expressions.
- **Formal Invariant**: Let $C_{\text{raw}}$ be the raw cell byte stream. The deterministic block normalizer $\Phi_{\text{block}}$ satisfies:
$$
\Phi_{\text{block}}(C_{\text{raw}}) = \text{NormalizeLineBreaks}(C_{\text{raw}})
$$
where `NormalizeLineBreaks` performs single-pass linear byte scanning matching literal prefixes:
$$
\forall p \in \{\text{"<br>"}, \text{"<br/>"}, \text{"<br />"}, \text{"<BR>"}, \text{"<BR/>"}, \text{"<BR />"}\}, \quad \text{MatchPrefix}(p) \implies \text{EmitToken}(\text{"\n"})
$$
Zero Regex Invariant:
$$
\text{RegexEvaluations}(\Phi_{\text{block}}) = 0
$$
Nested list items inside cells are parsed into an ordered sequence of sub-item tokens preserving cell text, bullet levels, and code spans.
- **Computational Complexity & Algorithmic Bounds**: Normalization executes in single-pass linear time $O(|C_{\text{raw}}|)$ with zero dynamic buffer reallocations.
- **Verification & Conformance Criteria**: Cells containing embedded HTML breaks and bulleted lists preserve complete multi-line content across serialization round-trips.
