### REQ-0015: Event-Driven CommonMark Table Lexer & Token Streaming
- **Normative Statement**: The ingestion engine shall parse CommonMark Markdown tables containing component declarations, interfaces, attributes, and constraints using an explicit deterministic pushdown automaton (DPDA) that emits an event stream of structural tokens. Lexing and tokenization must strictly prohibit regular expressions and catastrophic backtracking.
- **Formal Invariant**: The CommonMark table lexer is formalized as a deterministic pushdown automaton:
$$
M_{\text{table}} = (Q, \Sigma, \Gamma, \delta, q_0, Z_0, F)
$$
where $Q = \{ q_{\text{scan}}, q_{\text{header}}, q_{\text{delimiter}}, q_{\text{row}}, q_{\text{cell}}, q_{\text{escape}} \}$, input alphabet $\Sigma$ is ASCII/UTF-8 byte stream, stack alphabet $\Gamma = \{ Z_0, \text{TableFrame}, \text{RowFrame}, \text{CellFrame} \}$, and token stream $\mathcal{S}_{\text{events}} = \langle e_1, e_2, \dots, e_n \rangle$ emits:
$$
e_i \in \{ \text{StartTable}, \text{StartHeader}, \text{StartRow}, \text{StartCell}, \text{CellText}(s), \text{EndCell}, \text{EndRow}, \text{EndTable} \}
$$
Zero Backtracking & Zero Regex Invariant:
$$
\text{BacktrackCount}(M_{\text{table}}) = 0, \quad \text{RegexEvaluations}(M_{\text{table}}) = 0
$$
- **Computational Complexity & Algorithmic Bounds**: Parsing complexity is strictly bounded to $O(N)$ linear time where $N$ is input byte length, requiring $O(D)$ stack space bounded by maximum table cell nesting depth $D \le 4$.
- **Verification & Conformance Criteria**: Automated benchmark verifies streaming throughput exceeds 50 MB/s on large tabular schemas with zero stack overflow or quadratic degradation.
