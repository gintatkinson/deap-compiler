### REQ-0015: File Format Detection Engine by Extension & Magic Signatures
- **Normative Statement**: The ingestion engine shall provide a format detection subsystem (`detect.rs`) that classifies input schema files into target schema formats using file extensions and content-based magic signatures. Supported formats shall include CommonMark Markdown tables, Protocol Buffers (`.proto`), OMG IDL (`.idl`), OpenAPI (`.json`/`.yaml`), and Architecture Description Languages (`.arxml`/`.xml`).
- **Formal Semantics & Invariants**:
  Let $F$ be an input file with extension $\text{ext}(F)$ and initial byte prefix $\text{head}(F, 512)$. The format classifier function $\Delta$ is defined as:
  $$
  \Delta(F) = \begin{cases}
  \text{MarkdownTable}, & \text{if } \text{ext}(F) \in \{\text{".md"}, \text{".markdown"}\} \wedge \text{ContainsMarkdownTable}(\text{head}(F)) \\
  \text{Protobuf}, & \text{if } \text{ext}(F) = \text{".proto"} \vee \text{MatchesRegex}(\text{head}(F), \text{"syntax\\s*=\\s*\"proto[23]\""}) \\
  \text{OmgIdl}, & \text{if } \text{ext}(F) = \text{".idl"} \vee \text{MatchesRegex}(\text{head}(F), \text("module\\s+\\w+\\s*\\{")) \\
  \text{OpenApi}, & \text{if } \text{ext}(F) \in \{\text{".json"}, \text{".yaml"}\} \wedge \text{ContainsKeys}(\text{head}(F), \{\text{"openapi"}, \text{"swagger"}\}) \\
  \text{AdlXml}, & \text{if } \text{ext}(F) \in \{\text{".xml"}, \text{".arxml"}\} \wedge \text{ContainsXmlRoot}(\text{head}(F)) \\
  \text{Unknown}, & \text{otherwise}
  \end{cases}
  $$
- **Error Diagnostics & Quality Boundaries**:
  Failure to classify an input file into a recognized schema format shall emit compiler error `E0100` (Unrecognized Schema Format).
- **Acceptance Criteria**:
  - **AC-1**: Correctly identifies Markdown tables, Protobuf files, OMG IDL files, and OpenAPI specs based on extension and content.
  - **AC-2**: Ambiguous `.json` or `.yaml` files without OpenAPI root declarations fall back gracefully with clear error messages.
  - **AC-3**: Format detection operates on memory-mapped file slices without reading entire multi-megabyte files into memory.
